1. JAVASCRIPT TYPE SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

JavaScript has two categories of types:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │ PRIMITIVES (7 types)          │ OBJECTS (non-primitives)                 │
  │ Immutable, stored by VALUE    │ Mutable, stored by REFERENCE             │
  ├───────────────────────────────┼──────────────────────────────────────────┤
  │ 1. number                     │ Object  {}                               │
  │ 2. string                     │ Array   []                               │
  │ 3. boolean                    │ Function function(){}                    │
  │ 4. undefined                  │ Date, RegExp, Map, Set, etc.             │
  │ 5. null                       │                                          │
  │ 6. symbol    (ES6)            │                                          │
  │ 7. bigint    (ES2020)         │                                          │
  └───────────────────────────────┴──────────────────────────────────────────┘

2. PRIMITIVES IN DEPTH
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A) NUMBER
  - 64-bit floating point (IEEE 754 double precision)
  - Represents both integers and floats
  - Range: ±(2^53 - 1) safely (Number.MAX_SAFE_INTEGER = 9007199254740991)
  - Special values: Infinity, -Infinity, NaN

  0.1 + 0.2 === 0.3          // false! (floating point imprecision)
  0.1 + 0.2                  // 0.30000000000000004
  Math.abs(0.1+0.2-0.3) < Number.EPSILON  // true (correct comparison)

  Number.MAX_SAFE_INTEGER     // 9007199254740991
  Number.MIN_SAFE_INTEGER     // -9007199254740991
  Number.isInteger(5)         // true
  Number.isInteger(5.0)       // true
  Number.isFinite(Infinity)   // false
  Number.isNaN(NaN)           // true
  parseInt("42px")            // 42
  parseFloat("3.14em")        // 3.14
  +"42"                       // 42 (unary + converts to number)
  +"hello"                    // NaN

B) STRING
  - Immutable sequence of UTF-16 code units
  - Can use single '', double "", or template literals ``
  - Strings are primitives but have object-like methods via autoboxing

  const s = "hello";
  s.length           // 5
  s[0]               // "h"
  s.toUpperCase()    // "HELLO"
  s.slice(1, 3)      // "el"
  s.indexOf("l")     // 2
  s.includes("ell")  // true
  s.startsWith("he") // true
  s.endsWith("lo")   // true
  s.replace("l","L") // "heLlo" (first occurrence only)
  s.replaceAll("l","L")  // "heLLo"
  s.split("")        // ["h","e","l","l","o"]
  s.trim()           // removes whitespace from both ends
  s.padStart(8, "0") // "000hello"
  s.padEnd(8, ".")   // "hello..."
  s.repeat(2)        // "hellohello"
  " hi ".trimStart() // "hi " (trimEnd for end)

  // String is immutable:
  let str = "hello";
  str[0] = "H";     // silently ignored
  console.log(str); // "hello"

C) BOOLEAN
  - Only two values: true and false
  - Falsy values (convert to false): false, 0, -0, 0n, "", null,
    undefined, NaN
  - Everything else is truthy (including "0", [], {}, -1)

  Boolean(0)          // false
  Boolean("")         // false
  Boolean(null)       // false
  Boolean(undefined)  // false
  Boolean(NaN)        // false
  Boolean("0")        // true  ← string "0" is truthy!
  Boolean([])         // true  ← empty array is truthy!
  Boolean({})         // true  ← empty object is truthy!

D) UNDEFINED
  - Default value of declared but uninitialized variables
  - Default return value of functions that don't return anything
  - Value of missing object properties or array elements
  - typeof undefined === "undefined"

  let x;                 // undefined
  function fn() {}
  fn();                  // undefined (return value)
  const obj = {};
  obj.missing;           // undefined
  const arr = [1,,3];
  arr[1];                // undefined (sparse array)

E) NULL
  - Intentional absence of any value (explicit empty)
  - Must be explicitly assigned
  - typeof null === "object" ← famous bug (kept for backward compat)
  - null == undefined is true (loose equality)
  - null === undefined is false (strict equality)

  const nothing = null;
  console.log(nothing == undefined);   // true
  console.log(nothing === undefined);  // false
  console.log(typeof null);            // "object" (quirk!)

F) SYMBOL (ES6)
  - Unique and immutable primitive
  - Used as unique property keys (won't clash with other keys)
  - Not enumerable in for...in or Object.keys()
  - Cannot be implicitly converted to string

  const id1 = Symbol("id");
  const id2 = Symbol("id");
  id1 === id2                    // false — always unique!
  id1.toString()                 // "Symbol(id)"
  id1.description                // "id"

  // Global registry:
  const s1 = Symbol.for("shared");
  const s2 = Symbol.for("shared");
  s1 === s2                      // true — shared from registry

  // As object key:
  const key = Symbol("key");
  const obj = { [key]: "secret" };
  obj[key]                       // "secret"
  Object.keys(obj)               // []  ← symbol key hidden!
  Object.getOwnPropertySymbols(obj) // [Symbol(key)]

G) BIGINT (ES2020)
  - Integers of arbitrary precision
  - Appended with n suffix or via BigInt() constructor
  - Cannot mix with regular numbers in arithmetic

  const big = 9007199254740993n;    // safely beyond MAX_SAFE_INTEGER
  const b2 = BigInt("12345678901234567890");
  big + 1n                           // 9007199254740994n
  big + 1                            // TypeError: Cannot mix BigInt and Number
  typeof 42n                         // "bigint"

3. TYPEOF OPERATOR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  typeof 42           // "number"
  typeof "hi"         // "string"
  typeof true         // "boolean"
  typeof undefined    // "undefined"
  typeof null         // "object"  ← BUG (historical)
  typeof Symbol()     // "symbol"
  typeof 42n          // "bigint"
  typeof {}           // "object"
  typeof []           // "object"  ← not "array"!
  typeof function(){} // "function"
  typeof class{}      // "function" ← classes are functions

  // Check for null properly:
  value === null      // correct
  typeof value === "object" && value !== null  // correct object check

  // Check for array:
  Array.isArray([])   // true (preferred)
  [] instanceof Array // true (can fail cross-frame)

4. OBJECT TYPE (REFERENCE TYPE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  - Objects, Arrays, Functions, Date, RegExp, Map, Set, Promise are all objects
  - Stored in heap, referenced by pointer
  - Equality checks compare references, not values!

  const a = { x: 1 };
  const b = { x: 1 };
  a === b   // false (different references)
  a == b    // false

  const c = a;
  a === c   // true (same reference)

  // Deep equality: use JSON.stringify (limited) or libraries like lodash
  JSON.stringify(a) === JSON.stringify(b)  // true (structural equality)

5. AUTOBOXING (WRAPPER OBJECTS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  When you call a method on a primitive, JS temporarily wraps it in an
  object (Number, String, Boolean) to access the method, then discards it.

  "hello".toUpperCase()
  // JS internally: new String("hello").toUpperCase() → "HELLO"

  // Don't use wrapper constructors:
  const s = new String("hi");  // string OBJECT, not primitive!
  typeof s                     // "object" (not "string")
  s === "hi"                   // false!

6. COMMON INTERVIEW QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What are the primitive types in JavaScript?
A: number, string, boolean, undefined, null, symbol, bigint — 7 types.
   They are immutable and stored by value on the stack.

Q: What is the difference between primitives and objects?
A: Primitives: immutable, stored by value, compared by value.
   Objects: mutable, stored in heap by reference, compared by reference.

Q: Why does typeof null return "object"?
A: Historical bug from the early days of JS (1995). Null's binary type tag
   was 0 (same as object). Kept for backward compatibility.

Q: How do you check if something is an array?
A: Array.isArray(value) — most reliable.
   instanceof Array can fail when crossing iframe boundaries.
   typeof returns "object" for arrays, so it's insufficient alone.

Q: What is NaN and how to check for it?
A: NaN (Not-a-Number) is produced by invalid math. It's the only value not
   equal to itself (NaN !== NaN). Use Number.isNaN() to check (strict).
   Avoid global isNaN() — it coerces strings first.

Q: What's the difference between null and undefined?
A: undefined: JS's own default — variable declared but not assigned.
   null: developer's explicit signal — intentionally empty value.

Q: What is the difference between 0.1 + 0.2 and 0.3?
A: Due to IEEE 754 floating-point representation, 0.1 + 0.2 ≈
   0.30000000000000004. Compare using:
   Math.abs(a - b) < Number.EPSILON

Q: Can you have a string with a million characters?
A: Yes, strings have no practical length limit up to available memory.
   String.prototype.length returns the number of UTF-16 code units.
   Emoji/complex characters can have length > 1:
   "😀".length === 2  (surrogate pair)
