1. THE THREE PHASES OF EVENT PROPAGATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  When an event occurs, it travels through the DOM in three phases:

  1. CAPTURE PHASE  — event travels DOWN from document root to the target
  2. TARGET PHASE   — event is on the actual target element
  3. BUBBLE PHASE   — event travels UP from target back to the document root

  ┌──────────────────────────────────────────────────────────────┐
  │                        document                              │
  │                           │  ▲                               │
  │                    Capture│  │Bubble                         │
  │                           ▼  │                               │
  │                         <html>                               │
  │                           │  ▲                               │
  │                           ▼  │                               │
  │                         <body>                               │
  │                           │  ▲                               │
  │                           ▼  │                               │
  │                         <div>                                │
  │                           │  ▲                               │
  │                           ▼  │                               │
  │                        <button>  ← TARGET (user clicked)     │
  └──────────────────────────────────────────────────────────────┘

  addEventListener(event, handler, useCapture)
  - useCapture = false (default) → runs in BUBBLE phase
  - useCapture = true            → runs in CAPTURE phase

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. BUBBLING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Most events bubble. After the target handles the event, it propagates
  up through every ancestor.

  // HTML: <div id="outer"><div id="inner"><button id="btn">Click</button></div></div>

  document.getElementById("btn").addEventListener("click", () => console.log("btn"));
  document.getElementById("inner").addEventListener("click", () => console.log("inner"));
  document.getElementById("outer").addEventListener("click", () => console.log("outer"));

  // Clicking the button:
  // Output: btn → inner → outer
  // (event bubbles up through all ancestors)

  // Events that DO NOT bubble:
  // focus, blur, mouseenter, mouseleave, load, unload, scroll (on elements)
  // Alternatives that DO bubble: focusin, focusout, mouseover, mouseout

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. CAPTURING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Capture phase runs BEFORE bubbling. Use capture: true to intercept events
  before they reach the target.

  document.getElementById("outer").addEventListener("click", () => console.log("outer capture"), true);
  document.getElementById("inner").addEventListener("click", () => console.log("inner capture"), true);
  document.getElementById("btn").addEventListener("click", () => console.log("btn"));

  // Clicking the button outputs:
  // outer capture → inner capture → btn

  // Mixing capture and bubble:
  document.getElementById("outer").addEventListener("click", () => console.log("outer bubble"));  // bubble
  document.getElementById("outer").addEventListener("click", () => console.log("outer capture"), true); // capture

  // outer capture → btn → outer bubble

4. STOPPING PROPAGATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  event.stopPropagation()
  - Stops the event from moving to the next element in the propagation chain
  - Other listeners on the SAME element still fire

  event.stopImmediatePropagation()
  - Stops propagation AND prevents other listeners on the SAME element

  // Example:
  inner.addEventListener("click", (e) => {
    console.log("inner 1");
    e.stopImmediatePropagation();  // stops all further propagation
  });
  inner.addEventListener("click", () => console.log("inner 2")); // won't run
  outer.addEventListener("click", () => console.log("outer"));   // won't run

  // Clicking inner: only "inner 1" is logged.

5. PRACTICAL USE CASES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  // Close modal when clicking backdrop (not modal content):
  backdrop.addEventListener("click", (e) => {
    closeModal();  // click on backdrop
  });
  modal.addEventListener("click", (e) => {
    e.stopPropagation();  // prevent backdrop handler from firing
  });

  // Global document click to close dropdowns:
  document.addEventListener("click", closeDropdown);
  dropdownToggle.addEventListener("click", (e) => {
    e.stopPropagation();  // prevent document listener from immediately closing
    toggleDropdown();
  });

  // Capture use case — analytics tracking before any handler:
  document.addEventListener("click", (e) => {
    analytics.track("click", e.target);  // always fires first
  }, { capture: true });

6. COMMON INTERVIEW QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What is event bubbling?
A: After an event fires on a target element, it propagates upward through
   each ancestor in the DOM tree, firing on each one (if they have listeners).
   Most events bubble. Example: click on a button fires on button → div → body.

Q: What is event capturing?
A: The phase before bubbling where the event travels DOWN from document to the
   target. Listeners added with { capture: true } or the 3rd argument as true
   fire in this phase, before bubble-phase listeners.

Q: What is the difference between stopPropagation and stopImmediatePropagation?
A: stopPropagation() stops the event from moving to the next element but
   lets other listeners on the SAME element run. stopImmediatePropagation()
   stops all further listeners — both on the same element AND up/down the tree.

Q: What is the difference between event.target and event.currentTarget?
A: event.target is the element the event originated from (the click target).
   event.currentTarget is the element whose listener is currently running.
   During bubbling, currentTarget changes at each ancestor while target stays fixed.

Q: Which events don't bubble?
A: focus, blur, mouseenter, mouseleave, load, unload. Use focusin/focusout
   and mouseover/mouseout as bubbling alternatives for the mouse/focus events.

Q: How do you use event capturing for a practical use case?
A: A global click analytics tracker using capture:true ensures it runs before
   any handler can call stopPropagation(), guaranteeing all clicks are tracked.
