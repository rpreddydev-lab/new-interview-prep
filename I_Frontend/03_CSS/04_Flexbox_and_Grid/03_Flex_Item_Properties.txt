COMPLETE FLEX ITEM PROPERTIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  flex-grow: <number>      /* default: 0 */
  flex-shrink: <number>    /* default: 1 */
  flex-basis: <length> | auto | content   /* default: auto */
  flex: <grow> <shrink> <basis>           /* shorthand */
  align-self: auto | flex-start | flex-end | center | baseline | stretch
  order: <integer>         /* default: 0 */

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. flex-grow
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Controls how much the item GROWS relative to others to fill available space.
It's a unitless ratio of positive free space distribution.

  flex-grow: 0;  /* default — does NOT grow (item keeps its natural/basis size) */
  flex-grow: 1;  /* grows to fill available space */
  flex-grow: 2;  /* gets twice the share of available space compared to grow:1 */

  Example:
  .container { display: flex; width: 600px; }
  .item-a { flex-grow: 1; width: 100px; }  /* gets 1/3 of remaining 300px = 100 extra */
  .item-b { flex-grow: 2; width: 100px; }  /* gets 2/3 of remaining 300px = 200 extra */

  Total: item-a = 200px, item-b = 300px  (sum = 600px)

  Practical use:
  /* Sidebar fixed, main content fills remaining space */
  .sidebar { flex-grow: 0; width: 240px; }
  .main    { flex-grow: 1; }  /* takes all remaining space */

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. flex-shrink
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Controls how much the item SHRINKS relative to others when there's NOT enough space.
Applies when total flex-basis exceeds container size.

  flex-shrink: 1;  /* default — shrinks proportionally */
  flex-shrink: 0;  /* does NOT shrink — maintains its size (overflow possible) */
  flex-shrink: 2;  /* shrinks twice as much as shrink:1 */

  Example:
  .container { display: flex; width: 400px; }
  .item-a { flex-shrink: 1; width: 200px; }  /* shrinks 1 part */
  .item-b { flex-shrink: 2; width: 200px; }  /* shrinks 2 parts */

  Overflow = 200+200-400 = 0 (no overflow in this case)
  If container = 300px: overflow = 100px
    item-a shrinks by 1/3 × 100 = ~33px → 167px
    item-b shrinks by 2/3 × 100 = ~67px → 133px

  .logo { flex-shrink: 0; }       /* logo never shrinks */
  .nav  { flex-shrink: 1; }       /* nav can shrink */

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. flex-basis
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Sets the INITIAL main-size of the flex item BEFORE free space is distributed.
Think of it as the "ideal starting size" that grow/shrink work from.

  flex-basis: auto;    /* default — use the item's width/height property */
  flex-basis: 0;       /* ignore natural size; all space is distributed via grow */
  flex-basis: 200px;   /* starts at 200px, then grows/shrinks */
  flex-basis: 30%;     /* 30% of the flex container */
  flex-basis: content; /* size based on content (like auto but ignores width/height) */

  flex-basis vs width:
    flex-basis is the preferred way to set initial size in a flex container.
    It's applied before grow/shrink. If flex-basis is auto, width is used.
    If both are set, flex-basis wins.

  /* Equal-width items (ignore content size) */
  .item { flex: 1 1 0; }  /* flex-basis:0 → all space shared equally via grow */

  /* Min 200px, grow if space available */
  .card { flex: 1 1 200px; }

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. flex SHORTHAND — THE MOST IMPORTANT FLEX ITEM PROPERTY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  flex: <flex-grow> <flex-shrink> <flex-basis>

⚠ CRITICAL: When using the shorthand, unspecified values are NOT the same as defaults!

  flex: auto          → flex: 1 1 auto     (grow, shrink, use natural size)
  flex: none          → flex: 0 0 auto     (don't grow, don't shrink, natural size)
  flex: 1             → flex: 1 1 0%       (grow, shrink, basis=0 — equal sizes)
  flex: 0             → flex: 0 1 0%       (don't grow, shrink, basis=0)
  flex: 2             → flex: 2 1 0%       (grow 2x, shrink, basis=0)
  flex: 1 200px       → flex: 1 1 200px    (grow, shrink, start at 200px)
  flex: 0 0 200px     → exact 200px (no grow, no shrink) — rigid item

Common patterns:
  .flexible { flex: 1; }           /* equal-size, fills available space */
  .fixed    { flex: none; }        /* stays exactly natural size */
  .sidebar  { flex: 0 0 280px; }  /* fixed 280px sidebar */
  .main     { flex: 1; }           /* fills remaining space */
  .card     { flex: 1 1 300px; }  /* responsive cards: min 300px, grow */

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. align-self — CROSS AXIS OVERRIDE (per item)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Overrides the container's align-items for this specific item.

  align-self: auto;        /* inherits align-items from container */
  align-self: flex-start;  /* align to cross start */
  align-self: flex-end;    /* align to cross end */
  align-self: center;      /* centered on cross axis */
  align-self: stretch;     /* stretch to fill cross axis */
  align-self: baseline;    /* align by text baseline */

  Example:
  .container {
    display: flex;
    align-items: stretch;   /* all items stretch by default */
  }
  .special {
    align-self: center;     /* only this item is centered */
  }

6. order — VISUAL REORDERING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Changes the visual order of flex items WITHOUT changing the DOM order.
Lower order → appears first.

  order: 0;   /* default for all items */
  order: -1;  /* appears before order:0 items */
  order: 1;   /* appears after order:0 items */
  order: 999; /* appears last */

  /* Move footer to top visually (e.g., on mobile) */
  @media (max-width: 768px) {
    .footer { order: -1; }
  }

  ⚠ order only affects visual presentation, NOT DOM order.
  Screen readers still read in DOM order.
  Avoid for content that has a logical reading order (accessibility concern).
  Use for purely visual reordering that doesn't affect semantics.

7. AUTO MARGINS ON FLEX ITEMS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

auto margins on flex items consume available space — VERY powerful pattern:

  /* Push last nav item to the right */
  .nav-item:last-child { margin-left: auto; }

  /* Push items after index to right */
  .nav-item.active ~ .nav-item:first-of-type { margin-left: auto; }

  /* Space between logo and nav */
  .logo { margin-right: auto; }  /* logo + space + nav */

  /* Center a single item in a flex row */
  .centered { margin: auto; }

  /* Sticky footer with flex column: */
  .footer { margin-top: auto; }

  /* Push two items to opposite ends */
  .container { display: flex; }
  .left  { margin-right: auto; }  /* or: .right { margin-left: auto; } */

8. flex: 0 0 auto vs flex: 1 vs flex: 1 1 auto
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

flex: 0 0 auto (= flex: none):
  • Rigid item — maintains exact width/height
  • Use for: logos, icons, fixed sidebars, any element that must not change size

flex: 1 (= flex: 1 1 0):
  • Grows and shrinks equally; all items start from 0 basis
  • Use for: equal-width items, main content area

flex: 1 1 auto (= flex: auto):
  • Grows and shrinks, but starts from content/width size
  • Use for: items that should fill space but maintain a sensible min size

flex: 0 1 auto (DEFAULT):
  • Won't grow, but will shrink; natural size starting point
  • Use for: items that should have natural size by default

9. KEY INTERVIEW QUESTIONS — FLEX ITEM PROPERTIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What is the difference between flex-grow, flex-shrink, and flex-basis?
A: flex-grow: determines how much a flex item grows relative to others when there's
   extra space. 0 = no growth; 1 = grows proportionally.
   flex-shrink: determines how much an item shrinks when there's not enough space.
   0 = never shrinks; 1 = shrinks proportionally.
   flex-basis: the initial/ideal size before growth/shrink is applied. The starting
   point for growth/shrink calculations.

Q: What does flex: 1 mean?
A: flex: 1 is shorthand for flex: 1 1 0. It means:
   - flex-grow: 1 (can grow)
   - flex-shrink: 1 (can shrink)
   - flex-basis: 0 (start from 0, so all available space is shared equally via grow)
   With flex:1 on all siblings, they all get equal width.

Q: What is the difference between flex: 1 and flex: auto?
A: flex: 1 = flex: 1 1 0   → All items start from 0 basis, space shared equally
   flex: auto = flex: 1 1 auto → Items start from their content/declared size,
   THEN remaining space is shared equally. Items may end up different sizes.

Q: How do you make one flex item take up remaining space?
A: Use flex: 1 or flex-grow: 1 on that item. It will grow to fill all available
   space that other items don't claim.

Q: What is align-self?
A: It overrides the flex container's align-items for a specific item. Useful when
   most items need one alignment but a specific item needs a different one.

Q: Can you reorder flex items without changing the HTML?
A: Yes, using the order property. Lower order values appear first. Default is 0.
   ⚠ This is visual only — DOM order (for screen readers) stays unchanged.
   Avoid using order for content that has semantic/reading order.

Q: How do auto margins work with flexbox?
A: Auto margins on flex items consume all available free space in that direction.
   margin-left: auto pushes everything to the right of it to the far right.
   margin-top: auto in a column pushes item to the bottom.
   This is extremely useful for layouts like navbars (margin-right: auto on logo).
