1. WHAT ARE CSS CUSTOM PROPERTIES?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CSS Custom Properties (commonly called CSS Variables) are entities defined by
authors that can hold values and be reused throughout a document. They:

  • Are NATIVE to CSS (no preprocessor needed)
  • Are DYNAMIC — can be changed at runtime via JavaScript or media queries
  • INHERIT down the DOM tree
  • Follow the cascade (can be overridden by more specific rules)
  • Support any CSS value type

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. SYNTAX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Declaration (must start with --):
  :root {
    --primary-color: #3498db;
    --font-size-base: 16px;
    --spacing-unit: 8px;
    --border-radius: 4px;
    --transition-speed: 0.3s;
  }

Usage with var():
  .button {
    background-color: var(--primary-color);
    font-size: var(--font-size-base);
    padding: var(--spacing-unit) calc(var(--spacing-unit) * 2);
    border-radius: var(--border-radius);
  }

Fallback value:
  color: var(--text-color, black);
  /* If --text-color is not defined, use black */

Nested fallbacks:
  color: var(--text-color, var(--fallback-color, #333));

3. SCOPE AND INHERITANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Custom properties are SCOPED to the element they're declared on and INHERITED
by all descendant elements:

  :root {
    --color: blue;   /* global scope */
  }

  .section {
    --color: red;    /* overrides for .section and all its children */
  }

  .section .child {
    color: var(--color);   /* uses red, not blue */
  }

  .other-child {
    color: var(--color);   /* uses blue */
  }

  /* Block-level scoping (useful in components): */
  .card {
    --card-bg: white;
    --card-text: #333;
    background: var(--card-bg);
    color: var(--card-text);
  }

  .card.dark {
    --card-bg: #1a1a1a;
    --card-text: #f5f5f5;
    /* no other changes needed — children auto-update */
  }

4. CSS VARIABLES vs SASS/LESS VARIABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Feature               | CSS Custom Properties     | SASS/LESS Variables
───────────────────────┼───────────────────────────┼───────────────────────
Runtime dynamic       | YES (live DOM)             | NO (compile-time only)
JS accessible         | YES (getPropertyValue)     | NO
Inheritance/cascade   | YES                        | NO
Scope                 | DOM-based (inherited)      | Lexical (block-scope)
Fallback value        | YES (var(--x, fallback))   | NO
Media query aware     | YES                        | NO
Output in browser     | YES (as custom properties) | NO (compiled away)
Preprocessor needed   | NO                         | YES

SASS variable ($var) is resolved at compile time and baked into CSS.
CSS variable (--var) lives in the browser and can change dynamically.

5. DYNAMIC THEMING WITH CSS VARIABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A) Light/Dark theme toggle:

  :root {
    --bg-color: #ffffff;
    --text-color: #333333;
    --primary: #0077cc;
  }

  [data-theme="dark"] {
    --bg-color: #1a1a1a;
    --text-color: #f0f0f0;
    --primary: #66b3ff;
  }

  body {
    background: var(--bg-color);
    color: var(--text-color);
  }

  /* Toggle with JS: */
  document.documentElement.setAttribute('data-theme', 'dark');

B) OS-level dark mode with @media:

  :root {
    --bg-color: #ffffff;
    --text-color: #333;
  }
  @media (prefers-color-scheme: dark) {
    :root {
      --bg-color: #1a1a1a;
      --text-color: #f0f0f0;
    }
  }

6. JAVASCRIPT INTERACTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Reading a CSS variable:
  const root = document.documentElement;
  const value = getComputedStyle(root).getPropertyValue('--primary-color');
  // → ' #3498db'  (note: may have leading space, use .trim())

Setting a CSS variable via JS:
  root.style.setProperty('--primary-color', '#e74c3c');
  /* This updates all elements using this variable immediately */

  /* Set on a specific element: */
  document.querySelector('.card').style.setProperty('--card-bg', 'pink');

Removing a CSS variable:
  root.style.removeProperty('--primary-color');

Practical use — draggable slider controlling CSS:
  rangeInput.addEventListener('input', (e) => {
    document.documentElement.style.setProperty('--font-size', e.target.value + 'px');
  });

7. CSS VARIABLES IN calc()
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CSS variables work seamlessly with calc():

  :root {
    --base-space: 8px;
    --columns: 12;
    --gutter: 16px;
  }

  .grid-col-4 {
    width: calc(100% / var(--columns) * 4 - var(--gutter));
  }

  .padding-2x {
    padding: calc(var(--base-space) * 2);  /* 16px */
  }

⚠ IMPORTANT: CSS variables store the raw token, not a computed value.
  :root { --size: 10; }
  /* This FAILS:  width: var(--size)px;  */
  /* Use calc:    width: calc(var(--size) * 1px); */
  /* Or include unit in variable: --size: 10px; */

8. ADVANCED PATTERNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A) Space-toggling trick (Lea Verou pattern):
  /* Boolean-like CSS variable */
  :root { --is-dark: ;  }         /* empty = falsy */
  [data-theme="dark"] { --is-dark: initial; }  /* truthy */

  .element {
    --on-light: var(--is-dark) red;  /* only active in dark mode */
    --on-dark:  var(--is-dark, blue); /* only active in light mode */
  }

B) Component design tokens:
  :root {
    /* Core tokens */
    --color-brand-primary: #0077cc;
    --color-brand-secondary: #00aaff;
    --space-xs:  4px;
    --space-sm:  8px;
    --space-md:  16px;
    --space-lg:  32px;
    --space-xl:  64px;
    --radius-sm: 4px;
    --radius-md: 8px;
    --radius-full: 9999px;
    /* Semantic tokens */
    --color-text-primary: var(--color-brand-primary);
    --color-bg-surface: #fff;
  }

C) Responsive variables:
  :root {
    --fluid-font-size: clamp(1rem, 2.5vw, 2rem);
  }

  p { font-size: var(--fluid-font-size); }

D) Animation with variables:
  @keyframes spin {
    from { transform: rotate(var(--start-angle, 0deg)); }
    to   { transform: rotate(var(--end-angle, 360deg)); }
  }

9. INVALID AND UNSET VARIABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If a var() reference cannot be resolved:
  • If NO fallback: property becomes its inherited value (or initial)
  • If WITH fallback: fallback is used
  • If value is invalid at substitution point:
    → property is set to 'unset' (not the fallback!)

  :root { --color: 20px; }   /* invalid color value */
  p { color: var(--color); } /* → becomes 'unset' for color, not 20px */

10. KEY INTERVIEW QUESTIONS — CSS VARIABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What are CSS custom properties and how do they differ from SASS variables?
A: CSS custom properties are runtime variables defined with -- and consumed via
   var(). They live in the browser, are inherited via the DOM, can be changed
   via JS, and respond to media queries. SASS variables are preprocessed at
   compile time and compiled away — they don't exist in the browser.

Q: Can CSS variables be changed dynamically?
A: Yes. JavaScript can read them with getComputedStyle().getPropertyValue()
   and set them with element.style.setProperty(). This enables runtime theming
   without reloading any stylesheet.

Q: What happens when you use a CSS variable that hasn't been defined?
A: The property falls back to: (1) the fallback value if provided in var(),
   (2) the inherited value, or (3) the initial value. If the variable resolves
   to an invalid type (e.g., a length where a color is expected), the property
   is set to 'unset'.

Q: Can CSS variables be used inside @media queries?
A: CSS variable definitions CAN be placed inside @media (scoped to that context),
   but you cannot use var() as the media query value itself.
   /* VALID: */
   @media (max-width: 768px) { :root { --font-size: 14px; } }
   /* INVALID: */
   @media (max-width: var(--breakpoint)) { ... }

Q: How do CSS variables support theming?
A: Define semantic tokens as CSS variables on :root or a theme attribute.
   Toggle the theme class/attribute on the root element with JS. All components
   using those variables update immediately without any style re-injection.

Q: Are CSS variables animatable/transitionable?
A: CSS variables themselves are not directly transitionable (they're not
   typed by default). However, using @property you can register a typed
   custom property that IS animatable:
   @property --progress {
     syntax: '<number>';
     initial-value: 0;
     inherits: false;
   }
   Then: transition: --progress 0.5s ease;
