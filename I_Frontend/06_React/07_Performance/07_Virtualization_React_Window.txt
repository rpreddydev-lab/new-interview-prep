1. THE PROBLEM WITH LONG LISTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Rendering 10,000 items in a list means:
  - 10,000 DOM nodes created
  - 10,000 React elements in the Virtual DOM
  - Huge memory usage
  - Slow initial render
  - Scrolling jank

But the user can only see ~20-30 items at a time!

Solution: Windowing / Virtualization
  - Only render the items currently visible in the viewport
  - As the user scrolls, remove items that left the viewport, add new ones
  - Always ≈ same number of DOM nodes regardless of list size

react-window is the lightweight, modern virtualization library (by bvaughn).
Replacement for the older react-virtualized (same author, lighter weight).

  npm install react-window

  Components:
  - FixedSizeList    — all items same height
  - VariableSizeList — items have different heights
  - FixedSizeGrid    — fixed-size 2D grid
  - VariableSizeGrid — variable-size 2D grid

3. FixedSizeList — BASIC EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  import { FixedSizeList as List } from 'react-window';

  const ITEM_COUNT = 10_000;
  const ITEM_HEIGHT = 50;  // px

  // Row renderer — must be stable (not an inline arrow function)
  function Row({ index, style }) {
    return (
      // IMPORTANT: Must apply the style prop to set position/height
      <div style={style} className="list-item">
        Item {index + 1}
      </div>
    );
  }

  function VirtualList() {
    return (
      <List
        height={600}          // visible area height (px)
        itemCount={ITEM_COUNT}
        itemSize={ITEM_HEIGHT}
        width="100%"
      >
        {Row}
      </List>
    );
  }

  How it works:
  - Only renders items whose position falls within [scrollTop, scrollTop + height]
  - Positions items absolutely using the style prop (must be applied!)
  - As user scrolls, destroyed items → created items at new positions

4. PASSING DATA TO ROWS WITH itemData
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  const users = [ ... ];  // array of 10,000 users

  // Row needs access to users array and a click handler
  function UserRow({ index, style, data }) {
    const { users, onSelect } = data;
    const user = users[index];
    return (
      <div style={style} onClick={() => onSelect(user)}>
        {user.name} — {user.email}
      </div>
    );
  }

  function UserList({ users, onSelect }) {
    // itemData must be stable! Wrap in useMemo or define outside component.
    const itemData = useMemo(() => ({ users, onSelect }), [users, onSelect]);

    return (
      <List
        height={500}
        itemCount={users.length}
        itemSize={60}
        width="100%"
        itemData={itemData}  // passed as data prop to Row
      >
        {UserRow}
      </List>
    );
  }

5. VARIABLE SIZE LIST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  import { VariableSizeList } from 'react-window';

  // Function that returns the height for each item
  function getItemHeight(index) {
    return index % 3 === 0 ? 100 : 50;  // every 3rd item is tall
  }

  function VariableList({ items }) {
    const listRef = useRef(null);

    // If items change heights, notify list to recalculate
    useEffect(() => {
      listRef.current?.resetAfterIndex(0);
    }, [items]);

    return (
      <VariableSizeList
        ref={listRef}
        height={600}
        itemCount={items.length}
        itemSize={getItemHeight}  // function instead of number
        width="100%"
        estimatedItemSize={60}
      >
        {({ index, style }) => (
          <div style={style}>{items[index].content}</div>
        )}
      </VariableSizeList>
    );
  }

7. COMMON INTERVIEW QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What is list virtualization and when do you use it?
A: Virtualization renders only the DOM nodes visible in the viewport. As the
   user scrolls, nodes are recycled. Use it for lists with hundreds or
   thousands of items where rendering all at once would cause slow initial
   render, memory issues, and scrolling jank.

Q: Why must you apply the style prop to each row in react-window?
A: react-window positions each item absolutely using transform/top calculated
   from item index and size. If you don't apply the style prop, all items
   render at position 0 and overlap each other.

Q: What is the difference between FixedSizeList and VariableSizeList?
A: FixedSizeList assumes every item has the same height — simpler and faster
   (O(1) to calculate which items are visible). VariableSizeList accepts a
   function for item height — needed when items have different sizes, but
   requires maintaining a cumulative size cache.

Q: How do you handle dynamic data in a virtual list (items changing size)?
A: Call resetAfterIndex(0) on the VariableSizeList ref when item data changes.
   This invalidates the cached size calculations from that index onward.

Q: At what list size should you consider virtualization?
A: There's no exact threshold, but consider it when rendering > 100-200 items
   causes a noticeable performance issue. Always measure first — many apps work
   fine without virtualization for lists under a few hundred items.
