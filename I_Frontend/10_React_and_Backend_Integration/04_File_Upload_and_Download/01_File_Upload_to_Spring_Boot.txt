1. OVERVIEW — MULTIPART FORM DATA
================================================================

File uploads use multipart/form-data content type.
Files are sent as binary blobs attached to an HTTP form.

HTTP Request structure for file upload:
  POST /api/files/upload HTTP/1.1
  Content-Type: multipart/form-data; boundary=----Boundary123

  ------Boundary123
  Content-Disposition: form-data; name="file"; filename="report.pdf"
  Content-Type: application/pdf

  [binary file data]
  ------Boundary123
  Content-Disposition: form-data; name="description"

  Annual report 2024
  ------Boundary123--

2. REACT — BASIC FILE UPLOAD
================================================================

FILE: src/components/FileUpload.jsx
  import { useState } from 'react';
  import apiClient from '../api/axiosConfig';

  function FileUpload() {
    const [file, setFile] = useState(null);
    const [uploading, setUploading] = useState(false);
    const [uploadedUrl, setUploadedUrl] = useState(null);
    const [error, setError] = useState(null);

    const handleFileChange = (e) => {
      setFile(e.target.files[0]);
      setError(null);
    };

    const handleUpload = async () => {
      if (!file) return;

      const formData = new FormData();
      formData.append('file', file);
      formData.append('description', 'My uploaded file');

      setUploading(true);
      setError(null);

      try {
        const { data } = await apiClient.post('/files/upload', formData, {
          headers: {
            'Content-Type': 'multipart/form-data',
            // ↑ Axios sets this automatically with FormData,
            //   including the boundary. You can omit this.
          },
        });

        setUploadedUrl(data.url);
      } catch (err) {
        setError(err.response?.data?.message || 'Upload failed');
      } finally {
        setUploading(false);
      }
    };

    return (
      <div>
        <input type="file" onChange={handleFileChange} accept=".pdf,.jpg,.png" />
        <button onClick={handleUpload} disabled={!file || uploading}>
          {uploading ? 'Uploading...' : 'Upload'}
        </button>
        {uploadedUrl && <a href={uploadedUrl}>View file</a>}
        {error && <p style={{ color: 'red' }}>{error}</p>}
      </div>
    );
  }

  export default FileUpload;

NOTE: When using FormData, DO NOT manually set Content-Type header.
Axios detects FormData and sets the correct multipart boundary automatically.
Setting it manually breaks the boundary.

3. SPRING BOOT — FILE UPLOAD ENDPOINT
================================================================

Controller:
  @RestController
  @RequestMapping("/api/files")
  public class FileController {

      @Autowired
      private FileStorageService fileStorageService;

      @PostMapping("/upload")
      public ResponseEntity<FileResponse> upload(
          @RequestParam("file") MultipartFile file,
          @RequestParam(value = "description", required = false) String description
      ) {
          if (file.isEmpty()) {
              return ResponseEntity.badRequest()
                  .body(new FileResponse(null, "File is empty"));
          }

          // Validate file type
          String contentType = file.getContentType();
          if (!isAllowedContentType(contentType)) {
              return ResponseEntity.badRequest()
                  .body(new FileResponse(null, "File type not allowed"));
          }

          // Validate file size (also in application.yml)
          if (file.getSize() > 10 * 1024 * 1024) { // 10MB
              return ResponseEntity.badRequest()
                  .body(new FileResponse(null, "File too large"));
          }

          String url = fileStorageService.store(file);
          return ResponseEntity.ok(new FileResponse(url, "Upload successful"));
      }

      private boolean isAllowedContentType(String contentType) {
          return contentType != null && (
              contentType.equals("image/jpeg") ||
              contentType.equals("image/png") ||
              contentType.equals("application/pdf")
          );
      }
  }

application.yml:
  spring:
    servlet:
      multipart:
        enabled: true
        max-file-size: 10MB     # per file
        max-request-size: 50MB  # total request

4. FILE STORAGE SERVICE (Spring Boot)
================================================================

A) LOCAL FILE SYSTEM (Dev/Simple)
  @Service
  public class LocalFileStorageService {
      private final Path storageDir = Paths.get("uploads");

      public String store(MultipartFile file) throws IOException {
          Files.createDirectories(storageDir);
          String filename = UUID.randomUUID() + "_" + file.getOriginalFilename();
          Path destination = storageDir.resolve(filename);
          Files.copy(file.getInputStream(), destination, REPLACE_EXISTING);
          return "/files/" + filename;
      }
  }

B) AWS S3 (Production)
  @Service
  public class S3FileStorageService {
      @Autowired
      private S3Client s3Client;

      @Value("${aws.s3.bucket}")
      private String bucket;

      public String store(MultipartFile file) throws IOException {
          String key = "uploads/" + UUID.randomUUID() + "/" + file.getOriginalFilename();

          s3Client.putObject(
              PutObjectRequest.builder()
                  .bucket(bucket)
                  .key(key)
                  .contentType(file.getContentType())
                  .build(),
              RequestBody.fromInputStream(file.getInputStream(), file.getSize())
          );

          return "https://" + bucket + ".s3.amazonaws.com/" + key;
      }
  }

5. DRAG AND DROP UPLOAD
================================================================

  function DragDropUpload({ onFilesSelected }) {
    const [dragOver, setDragOver] = useState(false);

    const handleDragOver = (e) => {
      e.preventDefault();
      setDragOver(true);
    };

    const handleDragLeave = () => setDragOver(false);

    const handleDrop = (e) => {
      e.preventDefault();
      setDragOver(false);
      const files = Array.from(e.dataTransfer.files);
      onFilesSelected(files);
    };

    return (
      <div
        onDragOver={handleDragOver}
        onDragLeave={handleDragLeave}
        onDrop={handleDrop}
        style={{
          border: `2px dashed ${dragOver ? 'blue' : 'gray'}`,
          padding: '40px',
          textAlign: 'center',
          borderRadius: '8px',
          backgroundColor: dragOver ? '#f0f8ff' : 'white',
        }}
      >
        <p>Drag files here or <label htmlFor="fileInput" style={{cursor:'pointer',color:'blue'}}>browse</label></p>
        <input
          id="fileInput"
          type="file"
          multiple
          onChange={(e) => onFilesSelected(Array.from(e.target.files))}
          style={{ display: 'none' }}
        />
      </div>
    );
  }

  const handleMultipleUpload = async (files) => {
    const formData = new FormData();

    files.forEach((file, index) => {
      formData.append('files', file); // same key for all files

    const { data } = await apiClient.post('/files/upload-multiple', formData);
    return data;
  };

  // Spring Boot handler
  @PostMapping("/upload-multiple")
  public ResponseEntity<List<String>> uploadMultiple(
      @RequestParam("files") List<MultipartFile> files,
      @RequestParam("albumName") String albumName
  ) {
      List<String> urls = files.stream()
          .map(file -> fileStorageService.store(file))
          .collect(Collectors.toList());
      return ResponseEntity.ok(urls);
  }

7. FILE VALIDATION IN REACT
================================================================

  const validateFile = (file) => {
    const errors = [];

    // Size validation
    const MAX_SIZE = 10 * 1024 * 1024; // 10MB
    if (file.size > MAX_SIZE) {
      errors.push(`File too large (max 10MB). Current: ${(file.size / 1024 / 1024).toFixed(1)}MB`);
    }

    // Type validation
    const ALLOWED_TYPES = ['image/jpeg', 'image/png', 'application/pdf'];
    if (!ALLOWED_TYPES.includes(file.type)) {
      errors.push('Invalid file type. Allowed: JPEG, PNG, PDF');
    }

    // Name validation
    if (file.name.length > 255) {
      errors.push('Filename too long (max 255 characters)');
    }

    return errors;
  };

  IMPORTANT: Client-side validation is for UX only.
             Always validate on the server too!

8. PRESIGNED URL PATTERN (Cloud Upload)
================================================================

For large files, avoid sending through your backend.
Upload directly from browser to S3/Azure Blob using a presigned URL.

  FLOW:
  1. React calls your backend: GET /api/files/presigned-url?filename=report.pdf
  2. Backend generates a presigned PUT URL from AWS S3
  3. React uses the URL to upload directly to S3 (no backend in the middle)
  4. React notifies backend of successful upload: POST /api/files/confirm

  // Step 1: Get presigned URL
  const getPresignedUrl = async (filename, contentType) => {
    const { data } = await apiClient.get('/files/presigned-url', {
      params: { filename, contentType },
    });
    return data; // { uploadUrl, fileKey }
  };

  // Step 3: Upload directly to S3
  const uploadToS3 = async (presignedUrl, file) => {
    await fetch(presignedUrl, {
      method: 'PUT',
      body: file,
      headers: { 'Content-Type': file.type },
    });
  };

  // Combined flow
  const handleUpload = async (file) => {
    const { uploadUrl, fileKey } = await getPresignedUrl(file.name, file.type);
    await uploadToS3(uploadUrl, file);
    await apiClient.post('/files/confirm', { fileKey, filename: file.name });
  };

9. INTERVIEW QUESTIONS
================================================================

Q: How do you send a file and metadata together in one request from React?
A: Use FormData. Append the file with formData.append('file', file)
   and metadata with formData.append('description', 'some text').
   Pass formData as the request body. Do NOT manually set Content-Type —
   let Axios set it with the correct multipart boundary automatically.

Q: How do you configure Spring Boot to accept file uploads?
A: Add @RequestParam("file") MultipartFile file to the controller method.
   Set spring.servlet.multipart.max-file-size and max-request-size in
   application.yml. Spring Boot auto-configures multipart support.

Q: What is a presigned URL and when would you use it?
A: A presigned URL is a time-limited URL generated by your backend
   for a specific S3 object. The browser uploads directly to S3 using
   this URL, bypassing your backend. Use this for large files (100MB+)
   to reduce backend load, network costs, and latency.

Q: Why shouldn't you manually set Content-Type when uploading FormData?
A: The Content-Type for multipart/form-data must include a unique
   boundary string that separates form fields. Axios detects FormData
   and generates this boundary automatically. If you manually set
   Content-Type: multipart/form-data (without boundary), the server
   can't parse the request and the upload fails.

Q: What client-side validations should you perform before uploading?
A: Check file size (prevent wasted bandwidth/server load), file type
   (MIME type check for basic validation), and file name length.
   Always re-validate on the server — client-side checks are for UX
   only, not security. Never trust the MIME type from the browser alone.
