================================================================
AXIOS SETUP AND CONFIGURATION — IN DEPTH
================================================================

================================================================
1. INSTALLATION
================================================================

  npm install axios

  For TypeScript projects, Axios ships with its own type definitions
  in @types/axios — no separate @types/axios installation needed.

================================================================
2. CREATING AN AXIOS INSTANCE (BEST PRACTICE)
================================================================

Always create a custom instance rather than using global axios.
This gives you isolated config and interceptors.

FILE: src/api/axiosConfig.js (or axiosConfig.ts)

  import axios from 'axios';

  const apiClient = axios.create({
    baseURL: import.meta.env.VITE_API_BASE_URL,  // Vite
    // baseURL: process.env.REACT_APP_API_BASE_URL, // CRA
    timeout: 10_000,         // 10 seconds
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'application/json',
    },
    withCredentials: false,  // set true if using cookies (CSRF)
  });

  export default apiClient;

================================================================
3. ALL axios.create() OPTIONS
================================================================

  axios.create({
    // Base URL prepended to relative URLs
    baseURL: 'https://api.example.com',

    // Default headers for ALL requests
    headers: {
      'Content-Type': 'application/json',
    },

    // Request timeout in milliseconds (0 = no timeout)
    timeout: 5000,

    // Whether to send cookies with cross-origin requests
    withCredentials: true,

    // Response type: 'arraybuffer' | 'blob' | 'document' | 'json' | 'text' | 'stream'
    responseType: 'json',   // default

    // Max URL length for GET params
    maxContentLength: 2000,

    // URL params serializer (for complex query strings)
    paramsSerializer: (params) => qs.stringify(params, { arrayFormat: 'brackets' }),

    // Transform request data before sending
    transformRequest: [(data, headers) => {
      // e.g. convert data to snake_case
      return JSON.stringify(data);
    }],

    // Transform response data after receiving
    transformResponse: [(data) => {
      return JSON.parse(data);
    }],

    // HTTP auth (sets Authorization header)
    auth: { username: 'user', password: 'pass' },

    // Proxy config (Node.js only)
    proxy: { host: '127.0.0.1', port: 9000 },
  });

================================================================
5. MULTIPLE API INSTANCES
================================================================

For apps that call multiple backends (internal API + 3rd party):

  // Internal API (with auth)
  export const internalApi = axios.create({
    baseURL: import.meta.env.VITE_INTERNAL_API_URL,
    timeout: 10_000,
  });

  // Payment API (no auth header needed, different timeout)
  export const paymentApi = axios.create({
    baseURL: import.meta.env.VITE_PAYMENT_API_URL,
    timeout: 30_000,
  });

  // Content Delivery API (public, no auth)
  export const contentApi = axios.create({
    baseURL: import.meta.env.VITE_CONTENT_API_URL,
  });

  // Attach interceptors only to internalApi
  internalApi.interceptors.request.use(authInterceptor);

6. REQUEST CONFIG OPTIONS (Per-Request)
================================================================

These can be passed to any individual request to override defaults:

  apiClient.get('/users', {
    // Query parameters (auto-serialized)
    params: { page: 1, size: 20, sort: 'name,asc' },

    // Override headers for this request
    headers: { 'X-Custom-Header': 'value' },

    // Override timeout for this request
    timeout: 30_000,

    // AbortController signal
    signal: controller.signal,

    // Override responseType
    responseType: 'blob',  // for file downloads

    // Upload progress callback
    onUploadProgress: (event) => {
      const percent = Math.round((event.loaded / event.total) * 100);
      setProgress(percent);
    },

    // Download progress callback
    onDownloadProgress: (event) => {
      const percent = Math.round((event.loaded / event.total) * 100);
      setDownloadProgress(percent);
    },
  });

7. TYPED REQUESTS (TYPESCRIPT)
================================================================

  import axios, { AxiosResponse, AxiosError } from 'axios';

  interface User {
    id: number;
    name: string;
    email: string;
  }

  interface ApiError {
    message: string;
    code: string;
  }

  // Generic typed request
  const getUser = async (id: number): Promise<User> => {
    const response: AxiosResponse<User> = await apiClient.get(`/users/${id}`);
    return response.data;
  };

  // Typed POST
  const createUser = async (dto: Omit<User, 'id'>): Promise<User> => {
    const { data } = await apiClient.post<User>('/users', dto);
    return data;
  };

  // Typed error handling
  const handleAxiosError = (error: unknown): void => {
    if (axios.isAxiosError<ApiError>(error)) {
      console.log(error.response?.data.message);
      console.log(error.response?.status);
    }
  };

8. QUERY STRING SERIALIZATION — ADVANCED
================================================================

Default Axios serializes arrays as: tags[]=a&tags[]=b
Some APIs expect: tags=a&tags=b

Use qs library for custom serialization:
  import qs from 'qs';

  const apiClient = axios.create({
    baseURL: '...',
    paramsSerializer: (params) =>
      qs.stringify(params, { arrayFormat: 'repeat' }),
    // 'repeat': tags=a&tags=b
    // 'brackets': tags[]=a&tags[]=b
    // 'indices': tags[0]=a&tags[1]=b
  });

  apiClient.get('/products', { params: { tags: ['react', 'ts'] } });
  // → /products?tags=react&tags=ts

================================================================
9. TRANSFORMING REQUESTS AND RESPONSES
================================================================

Use transformRequest to convert camelCase to snake_case (common when
backend uses snake_case but frontend uses camelCase):

  import humps from 'humps';

  const apiClient = axios.create({
    transformRequest: [
      (data) => humps.decamelizeKeys(data),
      ...axios.defaults.transformRequest, // apply default JSON stringify
    ],
    transformResponse: [
      ...axios.defaults.transformResponse, // JSON parse
      (data) => humps.camelizeKeys(data),
    ],
  });

  // Now you can send { userId: 1 } and it goes as { user_id: 1 }
  // And receive { user_id: 1 } and it comes as { userId: 1 }

================================================================
10. COMPLETE PRODUCTION-READY SETUP
================================================================

FILE: src/api/axiosConfig.ts

  import axios, {
    AxiosInstance,
    InternalAxiosRequestConfig,
    AxiosResponse,
    AxiosError,
  } from 'axios';
  import { getToken, clearAuth } from '../store/authStore';

  const createApiClient = (): AxiosInstance => {
    const client = axios.create({
      baseURL: import.meta.env.VITE_API_BASE_URL,
      timeout: 10_000,
      headers: {
        'Content-Type': 'application/json',
        'Accept': 'application/json',
      },
    });

    // REQUEST INTERCEPTOR
    client.interceptors.request.use(
      (config: InternalAxiosRequestConfig) => {
        const token = getToken();
        if (token) {
          config.headers.Authorization = `Bearer ${token}`;
        }
        return config;
      },
      (error: AxiosError) => Promise.reject(error)
    );

    // RESPONSE INTERCEPTOR
    client.interceptors.response.use(
      (response: AxiosResponse) => response,
      async (error: AxiosError) => {
        if (error.response?.status === 401) {
          clearAuth();
          window.location.href = '/login';
        }
        return Promise.reject(error);
      }
    );

    return client;
  };

  const apiClient = createApiClient();
  export default apiClient;

11. INTERVIEW QUESTIONS
================================================================

Q: Why should you create an Axios instance instead of using axios directly?
A: axios.create() returns an isolated instance with its own config
   (baseURL, timeout, headers) and interceptors. This prevents global
   state pollution, allows multiple API configurations for different
   services, and ensures interceptors don't accidentally apply to
   unintended requests.

Q: How do you configure Axios for different environments?
A: Use .env files with VITE_ or REACT_APP_ prefixed variables.
   Set baseURL in axios.create() using the environment variable.
   The correct .env file is loaded at build time.

Q: How do you handle query parameters in Axios?
A: Pass them in the params option. Axios serializes them into the
   URL automatically. For complex serialization (arrays, nested objects),
   use a custom paramsSerializer with the qs library.

Q: How do you make Axios work with TypeScript?
A: Axios ships with built-in TypeScript types. Use generic type parameters:
   axios.get<User>('/users/1') types response.data as User.
   For errors, use axios.isAxiosError<ErrorShape>(error) to narrow types.

Q: How do you set up request/response transformation in Axios?
A: Use transformRequest and transformResponse arrays in the config.
   These are middleware functions applied to the data before sending
   and after receiving. Common use: camelCase ↔ snake_case conversion.
