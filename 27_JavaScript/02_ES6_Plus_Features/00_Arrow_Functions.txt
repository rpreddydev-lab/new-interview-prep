1. SYNTAX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  // No params:
  const greet = () => "Hello!";

  // One param (parens optional):
  const double = n => n * 2;
  const double2 = (n) => n * 2;

  // Multiple params (parens required):
  const add = (a, b) => a + b;

  // Multi-line body (need explicit return):
  const process = (x) => {
    const doubled = x * 2;
    return doubled + 1;
  };

  // Return object literal (wrap in parens to avoid ambiguity with block):
  const makeObj = (x) => ({ value: x });
  // NOT: const makeObj = (x) => { value: x };  ← {} is block, not object!

3. LEXICAL `this`
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  // Problem with regular function inside method:
  const timer = {
    seconds: 0,
    start() {
      setInterval(function() {
        this.seconds++;  // this = window/global, NOT timer!
      }, 1000);
    }
  };

  // Arrow function fix — inherits this from start():
  const timer2 = {
    seconds: 0,
    start() {
      setInterval(() => {
        this.seconds++;  // this = timer2 ✓
      }, 1000);
    }
  };

  // Old-style fix using variable:
  const timer3 = {
    seconds: 0,
    start() {
      const self = this;  // capture this
      setInterval(function() {
        self.seconds++;   // use self
      }, 1000);
    }
  };

4. WHEN NOT TO USE ARROW FUNCTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  A) Object methods (when you need `this` = the object):
  const user = {
    name: "Alice",
    greet: () => `Hello, ${this.name}`,   // WRONG: this = outer (undefined/global)
    greet2() { return `Hello, ${this.name}`; }  // CORRECT: this = user
  };

  B) Event handlers (when you need `this` = DOM element):
  button.addEventListener("click", () => {
    this.classList.toggle("active");  // WRONG: this = outer, not button
  });
  button.addEventListener("click", function() {
    this.classList.toggle("active");  // CORRECT: this = button
  });

  C) Constructor functions:
  const Person = (name) => { this.name = name; };  // No prototype, no new
  new Person("Alice");  // TypeError: Person is not a constructor

  D) Prototype methods:
  function Animal(name) { this.name = name; }
  Animal.prototype.speak = () => `${this.name} speaks`;  // WRONG
  Animal.prototype.speak = function() { return `${this.name} speaks`; };  // CORRECT

  E) Generator functions:
  const gen = function*() { yield 1; };    // OK
  const arrowGen = *() => { yield 1; };   // SyntaxError

5. ARROW FUNCTIONS AND IMPLICIT RETURNS

  // Implicit return — single expression:
  const square = x => x * x;

  // Chaining:
  const process = arr => arr
    .filter(x => x > 0)
    .map(x => x * 2)
    .reduce((sum, x) => sum + x, 0);

  // With conditionals:
  const classify = n => n > 0 ? "positive" : n < 0 ? "negative" : "zero";

6. COMMON INTERVIEW QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What is the difference between arrow functions and regular functions?
A: Arrow functions: lexical this, no arguments object, cannot be
   constructors, no prototype property, always anonymous expressions.
   Regular functions: dynamic this, own arguments, can be constructors.

Q: What does "lexical this" mean?
A: The `this` value is determined by the surrounding scope where the arrow
   function is DEFINED, not by how it is called. It captures the outer
   `this` at the time of creation and it cannot be changed.

Q: Can you use call/apply/bind with an arrow function?
A: call/apply will still INVOKE the arrow function but cannot change its
   `this`. bind returns a new function but `this` is still ignored.
   Arrow's `this` is permanently the lexical one.

Q: Why does () => ({}) need the parentheses?
A: Without parens, {} is interpreted as a block statement, not an object
   literal. Wrapping in () forces JS to parse it as an expression.

Q: What is the output?
   const obj = {
     x: 1,
     getX: () => this.x
   };
   obj.getX();
A: undefined (or TypeError in strict mode). Arrow function inherits `this`
   from the enclosing context of the object literal definition (outer scope
   or module), not from obj itself.
