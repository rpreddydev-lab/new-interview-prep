================================================================
  BIT MANIPULATION PATTERN — INTRODUCTION
================================================================

  Bit manipulation uses bitwise operators to perform operations at
  the binary level. It is often the key to O(1) time or O(n/32) space
  solutions that would otherwise be O(n) or O(n log n).

  All integers in Java are stored as 32-bit (int) or 64-bit (long) two's complement.

----------------------------------------------------------------
BITWISE OPERATORS
----------------------------------------------------------------

  Operator   Symbol   Description                         Example
  --------   ------   --------------------------------    -------------------
  AND        &        1 if both bits are 1                5 & 3 = 1  (101 & 011 = 001)
  OR         |        1 if at least one bit is 1          5 | 3 = 7  (101 | 011 = 111)
  XOR        ^        1 if bits differ                    5 ^ 3 = 6  (101 ^ 011 = 110)
  NOT        ~        flip all bits                       ~5 = -6    (flip 000...0101)
  Left shift  <<      multiply by 2^k                     1 << 3 = 8
  Right shift >>      divide by 2^k (signed, fills sign)  8 >> 2 = 2
  Unsigned   >>>      divide by 2^k (fills 0)             -1 >>> 1 = Integer.MAX_VALUE

----------------------------------------------------------------
ESSENTIAL BIT TRICKS
----------------------------------------------------------------

  Operation                     Code                     Notes
  --------------------------    ----------------------   -------------------------
  Check if bit k is set         (n >> k) & 1             result is 1 or 0
  Set bit k                     n | (1 << k)             forces bit k to 1
  Clear bit k                   n & ~(1 << k)            forces bit k to 0
  Toggle bit k                  n ^ (1 << k)             flips bit k
  Get lowest set bit            n & (-n)   or  n & ~(n-1)  isolates rightmost 1
  Remove lowest set bit         n & (n - 1)              turns off rightmost 1
  Check if power of 2           n > 0 && (n & (n-1)) == 0
  Count set bits (popcount)     Integer.bitCount(n)      Java built-in
  Check parity (odd/even)       n & 1  (1=odd, 0=even)
  Swap a and b (no temp)        a^=b; b^=a; a^=b;
  Absolute value (no branch)    tricky — avoid in interviews
  Multiply by 2^k               n << k
  Divide by 2^k (floor)         n >> k

----------------------------------------------------------------
KEY IDENTITIES
----------------------------------------------------------------

  XOR properties:
    n ^ n = 0           (a number XORed with itself is 0)
    n ^ 0 = n           (XOR with 0 is identity)
    XOR is commutative and associative
    a ^ b ^ a = b       (cancellation)

  AND/OR:
    n & 0 = 0, n & n = n, n | 0 = n, n | n = n
    n & (n-1) removes lowest set bit
    n & (-n) = n & (~n + 1) isolates lowest set bit

  Two's complement:
    -n = ~n + 1
    -1 in 32-bit = all 1s (0xFFFFFFFF)
    Integer.MIN_VALUE = -2^31 = 0x80000000

----------------------------------------------------------------
COMMON PATTERNS
----------------------------------------------------------------

  1. XOR to find unique elements (singles cancel out pairs):
       Single Number (LC 136)

  2. n & (n-1) to process/count set bits:
       Number of 1 Bits (LC 191), Power of Two (LC 231)

  3. Bitmask to represent subsets of n elements (n ≤ 20-32):
       Subsets (LC 78), TSP DP

  4. n & (-n) to isolate lowest set bit:
       Fenwick Tree / BIT operations

  5. XOR in intervals [1,n] or prefix XOR arrays

  6. Bit shifting for multiplication/division tricks

----------------------------------------------------------------
JAVA BIT OPERATIONS REFERENCE
----------------------------------------------------------------

  Integer.bitCount(n)          // count of 1 bits (popcount)
  Integer.highestOneBit(n)     // returns power of 2 <= n
  Integer.lowestOneBit(n)      // returns n & (-n)
  Integer.numberOfLeadingZeros(n)
  Integer.numberOfTrailingZeros(n)
  Integer.toBinaryString(n)    // for debugging
  Integer.reverse(n)           // reverse bits
  Integer.MAX_VALUE            // 2^31 - 1 = 2147483647
  Integer.MIN_VALUE            // -2^31 = -2147483648

----------------------------------------------------------------
VISUALIZATION: BINARY REPRESENTATION
----------------------------------------------------------------

  n = 12 (decimal) = 0000...1100 (binary, 32-bit int)

  Bit position:  31 30 ... 4  3  2  1  0
  Bit value:      0  0 ... 0  1  1  0  0

  Check bit 2:  (12 >> 2) & 1 = (0011) & 1 = 1  ✓ (bit 2 is set)
  Check bit 1:  (12 >> 1) & 1 = (0110) & 1 = 0  ✓ (bit 1 is NOT set)
  Remove low bit: 12 & 11 = 1100 & 1011 = 1000 = 8  (removed bit 2)
  Isolate low bit: 12 & -12 = 1100 & 0100 = 0100 = 4

----------------------------------------------------------------
WHEN BIT MANIPULATION IS THE RIGHT TOOL
----------------------------------------------------------------

  - Problem mentions "only one element appears once/three times" → XOR
  - Need O(1) extra space to track elements → bitmask (if ≤ 64 elements)
  - "Check if N is power of 2/4/8" → bit properties
  - Enumerate all subsets of small set → bitmask for loop (1 << n iterations)
  - Competitive: any O(n) solution that seems "impossible" via normal DS

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Know `n & (n-1)` (remove lowest bit) and `n & (-n)` (isolate lowest bit) by heart.
  - XOR identities: n^n=0, n^0=n, a^b^a=b. These appear constantly.
  - Java uses signed integers — be careful with >> vs >>>.
  - Use `long` for problems that might overflow 32-bit.
  - Always test with n=0, n=1, n=negative numbers.
  - For bitmask DP: state space 2^n. Feasible up to n=20 (2^20 ≈ 1M), tight at n=25.
