================================================================
  GAS STATION (LC 134) AND RELATED CIRCULAR GREEDY
================================================================

  LC 134: n gas stations in a circle. gas[i] = fuel at station i.
          cost[i] = fuel to travel from i to i+1.
          Find starting station to complete the circuit once, or -1.

  Input:  gas=[1,2,3,4,5], cost=[3,4,5,1,2]
  Output: 3

----------------------------------------------------------------
SOLUTION: ONE-PASS GREEDY
----------------------------------------------------------------

  Key observations:
  1. If total gas >= total cost, a valid starting station ALWAYS EXISTS (and is unique).
  2. If we "run out" of gas at position k (cumulative sum < 0), then NO station
     between `start` and k can be a valid starting point.
     → Reset start = k + 1, reset cumulative sum.

  Java:
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int total = 0, tank = 0, start = 0;
        for (int i = 0; i < gas.length; i++) {
            int diff = gas[i] - cost[i];
            total += diff;
            tank += diff;
            if (tank < 0) {          // can't continue from `start` through i
                start = i + 1;       // try starting from next station
                tank = 0;            // reset tank
            }
        }
        return total >= 0 ? start : -1;
    }

  Time: O(n)   Space: O(1)

----------------------------------------------------------------
TRACED EXAMPLE: gas=[1,2,3,4,5], cost=[3,4,5,1,2]
----------------------------------------------------------------

  diff = gas - cost = [-2,-2,-2,3,3]
  total = sum(diff) = 0 >= 0 → solution exists.

  i=0: diff=-2. tank=-2 < 0 → start=1, tank=0.
  i=1: diff=-2. tank=-2 < 0 → start=2, tank=0.
  i=2: diff=-2. tank=-2 < 0 → start=3, tank=0.
  i=3: diff=3. tank=3 >= 0 → no reset.
  i=4: diff=3. tank=6 >= 0 → no reset.

  total=0 >= 0 → return start=3 ✓

  Verify starting at 3:
    At 3: tank=0+4-1=3
    At 4: tank=3+5-2=6
    At 0: tank=6+1-3=4
    At 1: tank=4+2-4=2
    At 2: tank=2+3-5=0 ≥ 0 → successfully completes circuit ✓

----------------------------------------------------------------
WHY THE ALGORITHM IS CORRECT
----------------------------------------------------------------

  Claim: if total >= 0, starting at the final `start` value works.

  Proof sketch:
  1. If total >= 0, a valid solution exists (otherwise impossible).
  2. When we reset start = i+1, we've proven no station in [old_start..i] works
     (accumulated deficit means we can't get past i from any earlier start).
  3. The final `start` covers a suffix of the array from `start` to n-1.
     The prefix [0..start-1] we "skipped" must have a net deficit (we reset past it).
     But since total >= 0, the suffix has surplus >= the prefix's deficit.
     So starting at `start`, we can complete the circuit.

----------------------------------------------------------------
LC 1 (VARIANT): CAN YOU COMPLETE THE CIRCUIT?
----------------------------------------------------------------

  Just check: return sum(gas) >= sum(cost).
  If yes, a valid start exists.

RELATED PROBLEM: LARGEST RECTANGLE / PARTITION LABELS
----------------------------------------------------------------

  LC 763 Partition Labels:
    Partition string s into as many parts as possible so each letter appears in at most one part.
    Return list of part lengths.

    Greedy: last occurrence of each character defines the partition boundary.
    Track `end` = farthest last-occurrence seen so far.
    When i == end, record part length, start new part.

    Java:
      public List<Integer> partitionLabels(String s) {
          int[] last = new int[26];
          for (int i = 0; i < s.length(); i++) last[s.charAt(i)-'a'] = i;

          List<Integer> result = new ArrayList<>();
          int start = 0, end = 0;
          for (int i = 0; i < s.length(); i++) {
              end = Math.max(end, last[s.charAt(i)-'a']);
              if (i == end) {
                  result.add(end - start + 1);
                  start = end + 1;
              }
          }
          return result;
      }

    Example: s = "ababcbacadefegdehijhklij"
      last: a=8,b=5,c=7,d=14,e=15,f=11,g=13,h=19,i=22,j=23,k=20,l=21
      i=0(a): end=max(0,8)=8
      i=1(b): end=max(8,5)=8
      ...
      i=8(a): i==end → part=[9]. start=9.
      i=9(d): end=max(9,14)=14
      ...
      i=15(e): i≠end(15)... etc.
      Result: [9,7,8] ✓

LC 2271: MAXIMUM WHITE TILES COVERED
----------------------------------------------------------------

  (Another interval greedy, less common)
  Tiles cover [l,r]. Pick k consecutive segment. Max tiles covered.
  Sort tiles, binary search + greedy.

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. Gas Station: comparing tank < 0 (should be strictly < 0, 0 is fine).
  2. Not resetting tank = 0 when starting over.
  3. Confusing "total" (overall sum) with "tank" (running sum from current start).
  4. Partition Labels: using first occurrence instead of last occurrence.
  5. Returning start even when total < 0. Always check total >= 0 first.

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why does the gas station problem always have a unique answer if total >= 0?
  A: The "deficit" regions force a unique restart point. The final `start` in the
     greedy is the only one that covers a sufficient surplus prefix to overcome
     all earlier deficits.

  Q: Can you solve Gas Station in O(n) with no extra space?
  A: Yes — the one-pass greedy above does exactly that.

  Q: What's the key insight for Partition Labels?
  A: Once a character appears in a partition, ALL occurrences must be in that partition.
     So the partition extends to the last occurrence of every character seen so far.
     When current index reaches the partition end, we've fully contained all chars.

  Q: What if gas and cost have length 1?
  A: gas[0] >= cost[0] → return 0. Else → return -1.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Gas Station: draw the diff[] array, explain: "restart whenever running sum goes negative."
  - Emphasize: "If total is negative, impossible. Otherwise greedy finds the start."
  - Partition Labels: "last occurrence defines partition boundary — extend as characters are seen."
  - Both are O(n) single-pass greedy — mention space O(1) for Gas Station.
