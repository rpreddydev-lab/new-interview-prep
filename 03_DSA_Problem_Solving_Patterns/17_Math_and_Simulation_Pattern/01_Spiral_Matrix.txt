================================================================
  SPIRAL MATRIX — LC 54 / LC 59
================================================================

  LC 54: Given an m×n matrix, return elements in spiral order (clockwise).
  LC 59: Given n, generate an n×n matrix filled with 1..n² in spiral order.

----------------------------------------------------------------
LC 54 — SPIRAL MATRIX (TRAVERSAL)
----------------------------------------------------------------

  Approach: 4 boundary pointers (top, bottom, left, right).
            Peel off one layer at a time, shrinking boundaries.

  Java:
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> result = new ArrayList<>();
        if (matrix.length == 0) return result;
        int top = 0, bottom = matrix.length - 1;
        int left = 0, right = matrix[0].length - 1;

        while (top <= bottom && left <= right) {
            // Traverse right along top row
            for (int c = left; c <= right; c++) result.add(matrix[top][c]);
            top++;

            // Traverse down along right column
            for (int r = top; r <= bottom; r++) result.add(matrix[r][right]);
            right--;

            // Traverse left along bottom row (if top <= bottom)
            if (top <= bottom) {
                for (int c = right; c >= left; c--) result.add(matrix[bottom][c]);
                bottom--;
            }

            // Traverse up along left column (if left <= right)
            if (left <= right) {
                for (int r = bottom; r >= top; r--) result.add(matrix[r][left]);
                left++;
            }
        }
        return result;
    }

  Time: O(m * n)  Space: O(1) extra (output not counted).

----------------------------------------------------------------
TRACED EXAMPLE: LC 54
----------------------------------------------------------------

  Matrix:
    1  2  3
    4  5  6
    7  8  9

  Initial: top=0, bottom=2, left=0, right=2.

  Round 1:
    Right (top=0): 1, 2, 3. top→1.
    Down (right=2): 6, 9. right→1.
    Left (top=1≤bottom=2): 8, 7. bottom→1.
    Up (left=0≤right=1): 4. left→1.

  Round 2 (top=1, bottom=1, left=1, right=1):
    Right: 5. top→2.
    Down: (top=2 > bottom=1, no elements).
    top > bottom → exit.

  Result: [1,2,3,6,9,8,7,4,5] ✓

  Why check `if (top <= bottom)` and `if (left <= right)` inside loop?
    For single-row or single-column matrices, top may exceed bottom
    after the right traversal, which would double-count elements.

----------------------------------------------------------------
LC 54 — DIRECTION ARRAY APPROACH (ALTERNATIVE)
----------------------------------------------------------------

  Use direction arrays: right→down→left→up.
  Track current direction; when hitting boundary or visited cell, turn right.

  Java:
    public List<Integer> spiralOrder(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int[][] dirs = {{0,1},{1,0},{0,-1},{-1,0}};
        boolean[][] visited = new boolean[m][n];
        List<Integer> result = new ArrayList<>();
        int r = 0, c = 0, dir = 0;
        for (int i = 0; i < m * n; i++) {
            result.add(matrix[r][c]);
            visited[r][c] = true;
            int nr = r + dirs[dir][0], nc = c + dirs[dir][1];
            if (nr < 0 || nr >= m || nc < 0 || nc >= n || visited[nr][nc]) {
                dir = (dir + 1) % 4;  // turn right
                nr = r + dirs[dir][0]; nc = c + dirs[dir][1];
            }
            r = nr; c = nc;
        }
        return result;
    }

  Time: O(m*n)  Space: O(m*n) for visited array.
  Boundary approach is more memory-efficient.

LC 59 — SPIRAL MATRIX II (GENERATION)
----------------------------------------------------------------

  Same spiral traversal but fill in values 1..n².

  Java:
    public int[][] generateMatrix(int n) {
        int[][] matrix = new int[n][n];
        int top = 0, bottom = n - 1, left = 0, right = n - 1, num = 1;

        while (top <= bottom && left <= right) {
            for (int c = left; c <= right; c++) matrix[top][c] = num++;
            top++;
            for (int r = top; r <= bottom; r++) matrix[r][right] = num++;
            right--;
            if (top <= bottom) {
                for (int c = right; c >= left; c--) matrix[bottom][c] = num++;
                bottom--;
            }
            if (left <= right) {
                for (int r = bottom; r >= top; r--) matrix[r][left] = num++;
                left++;
            }
        }
        return matrix;
    }

  Time: O(n²)  Space: O(1) extra (output matrix not counted).

  Trace for n=3:
    Round 1: fill top row [1,2,3], right col [6,9], bottom row [8,7], left col [4].
    Round 2: center [5].
    Result:
      1 2 3
      8 9 4
      7 6 5  ✓

LC 885 — SPIRAL MATRIX III (WALKING ON INFINITE GRID)
----------------------------------------------------------------

  Start at (r0,c0) in rows×cols grid, walk clockwise spiral,
  return positions in the order visited.

  Pattern: walk right 1, down 1, left 2, up 2, right 3, down 3, left 4...
           Each direction is walked twice with the same step count, then step++.

  Java:
    public int[][] spiralMatrixIII(int rows, int cols, int r0, int c0) {
        int[][] result = new int[rows * cols][2];
        int[][] dirs = {{0,1},{1,0},{0,-1},{-1,0}};
        int r = r0, c = c0, steps = 1, dir = 0, idx = 0;
        while (idx < rows * cols) {
            for (int d = 0; d < 2; d++) {          // each step count used twice
                for (int s = 0; s < steps; s++) {
                    if (r >= 0 && r < rows && c >= 0 && c < cols) {
                        result[idx++] = new int[]{r, c};
                    }
                    r += dirs[dir][0]; c += dirs[dir][1];
                }
                dir = (dir + 1) % 4;
            }
            steps++;
        }
        return result;
    }

----------------------------------------------------------------
EDGE CASES
----------------------------------------------------------------

  - Single row: only traverse left-to-right, no up/down.
  - Single column: only traverse top-to-bottom, no left/right.
  - 1×1 matrix: just [matrix[0][0]].
  - The inner `if (top <= bottom)` and `if (left <= right)` guards are crucial.

  Example: 1×3 matrix [1,2,3].
    top=0, bottom=0, left=0, right=2.
    Right: [1,2,3]. top→1.
    Down: top=1 > bottom=0, no elements.
    Left guard: top(1) <= bottom(0)? NO → skip. (prevents adding 3,2,1 backwards)
    Up guard: left(0) <= right(2)? YES → up loop from r=bottom(0) to r>=top(1) → no iterations.
    Result: [1,2,3] ✓

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why do we need the guard checks for left/bottom traversal?
  A: For single-row matrices, after the top-row traversal, top > bottom.
     Without the guard, the bottom-row traversal would run in reverse and
     double-count elements. Same logic for single-column.

  Q: What is the time complexity of spiral traversal?
  A: O(m*n) — each cell is visited exactly once.

  Q: Can we do spiral matrix without the 4 boundary variables?
  A: Yes, direction array + visited matrix works. But the 4-boundary approach
     is more space-efficient (O(1) extra vs O(m*n) for visited).

  Q: LC 59 uses the same skeleton as LC 54?
  A: Yes — same boundary-shrinking loop, just assign values instead of reading.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Draw the spiral on paper before coding: show the 4 traversal directions.
  - Start with the 4-boundary variables named top/bottom/left/right.
  - Mention the guard checks explicitly and explain WHY they're needed.
  - Common bug: starting Down loop from `top` (after incrementing) not from original `top`.
  - Common bug: forgetting to increment/decrement the boundary after each traversal.
