================================================================
  NEXT GREATER ELEMENT
  (LC 496, LC 503, LC 739, LC 901)
================================================================

----------------------------------------------------------------
CONCEPT: NEXT GREATER ELEMENT
----------------------------------------------------------------

  For each element in an array, find the next element (to the right)
  that is strictly greater than it. If none exists, return -1.

  Example:
    nums = [4, 1, 2]  -->  [-1, 2, -1]
    nums = [2, 1, 2, 4, 3]  -->  [4, 2, 4, -1, -1]

----------------------------------------------------------------
APPROACH: MONOTONE DECREASING STACK
----------------------------------------------------------------

  Maintain a stack that is monotone DECREASING (bottom to top: large to small).

  For each element nums[i]:
    - While stack is not empty AND nums[stack.top()] < nums[i]:
        The current element nums[i] IS the "next greater" for stack.top().
        Pop and record the answer.
    - Push current index onto stack.

  After the loop: remaining elements in stack have no next-greater (-1).

  Why decreasing? We push elements waiting for a larger successor.
  When a larger element arrives, it pops (and answers) all smaller ones below it.

----------------------------------------------------------------
JAVA SOLUTION (LC 496)
----------------------------------------------------------------

  LC 496: nums1 is a subset of nums2 (no duplicates). For each element
  in nums1, find its next greater element in nums2.

  public int[] nextGreaterElement(int[] nums1, int[] nums2) {
      // Build next greater map for nums2
      Map<Integer, Integer> nextGreater = new HashMap<>();
      Deque<Integer> stack = new ArrayDeque<>();  // stores values

      for (int num : nums2) {
          while (!stack.isEmpty() && stack.peek() < num) {
              nextGreater.put(stack.pop(), num);
          }
          stack.push(num);
      }
      // Remaining in stack have no next greater
      while (!stack.isEmpty()) nextGreater.put(stack.pop(), -1);

      int[] result = new int[nums1.length];
      for (int i = 0; i < nums1.length; i++) {
          result[i] = nextGreater.get(nums1[i]);
      }
      return result;
  }

  Time: O(m + n)  Space: O(n)

----------------------------------------------------------------
JAVA SOLUTION: BASIC NEXT GREATER (array)
----------------------------------------------------------------

  public int[] nextGreaterElement(int[] nums) {
      int n = nums.length;
      int[] result = new int[n];
      Arrays.fill(result, -1);
      Deque<Integer> stack = new ArrayDeque<>();  // stores indices

      for (int i = 0; i < n; i++) {
          while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
              int j = stack.pop();
              result[j] = nums[i];
          }
          stack.push(i);
      }
      return result;
  }

  Time: O(n)  Space: O(n)

----------------------------------------------------------------
TRACED EXAMPLE: nums=[2,1,2,4,3]
----------------------------------------------------------------

  i=0: num=2, stack empty, push 0. stack=[0]
  i=1: num=1, nums[0]=2 < 1? NO. push 1. stack=[0,1]
  i=2: num=2, nums[1]=1 < 2? YES. pop 1, result[1]=2. stack=[0]
           nums[0]=2 < 2? NO (equal, not strictly less). push 2. stack=[0,2]
  i=3: num=4, nums[2]=2 < 4? YES. pop 2, result[2]=4. stack=[0]
           nums[0]=2 < 4? YES. pop 0, result[0]=4. stack=[]
           push 3. stack=[3]
  i=4: num=3, nums[3]=4 < 3? NO. push 4. stack=[3,4]

  Remaining: result[3]=-1, result[4]=-1 (default)

  result = [4, 2, 4, -1, -1] ✓

PROBLEM (LC 503): NEXT GREATER ELEMENT II (CIRCULAR)
----------------------------------------------------------------

  Array is treated as CIRCULAR. After the last element, wrap around.

  Trick: simulate circular by iterating the array TWICE (indices 0..2n-1).
  Use i % n to get the actual array index.
  Only push indices from the FIRST pass (0..n-1) to avoid duplicates.

  public int[] nextGreaterElements(int[] nums) {
      int n = nums.length;
      int[] result = new int[n];
      Arrays.fill(result, -1);
      Deque<Integer> stack = new ArrayDeque<>();

      for (int i = 0; i < 2 * n; i++) {
          while (!stack.isEmpty() && nums[stack.peek()] < nums[i % n]) {
              result[stack.pop()] = nums[i % n];
          }
          if (i < n) stack.push(i);  // only push in first pass
      }
      return result;
  }

  Time: O(n)  Space: O(n)

  Trace: nums=[1,2,1]
    i=0: num=1, stack=[], push 0. stack=[0]
    i=1: num=2, nums[0]=1<2? YES, pop 0, result[0]=2. stack=[]. push 1. stack=[1]
    i=2: num=1, nums[1]=2<1? NO. push 2. stack=[1,2]
    i=3 (i%n=0): num=1, nums[2]=1<1? NO. (i>=n, no push)
    i=4 (i%n=1): num=2, nums[2]=1<2? YES, pop 2, result[2]=2.
                          nums[1]=2<2? NO. (i>=n, no push)
    i=5 (i%n=2): num=1, nums[1]=2<1? NO.
    result = [2, -1, 2] ✓

PROBLEM (LC 739): DAILY TEMPERATURES
----------------------------------------------------------------

  Given daily temperatures, find for each day how many days until
  a warmer day. Return 0 if no future warmer day.

  Input:  [73,74,75,71,69,72,76,73]
  Output: [1,1,4,2,1,1,0,0]

  Same pattern: next greater element, but return DISTANCE (not value).

  public int[] dailyTemperatures(int[] temperatures) {
      int n = temperatures.length;
      int[] result = new int[n];
      Deque<Integer> stack = new ArrayDeque<>();  // stores indices

      for (int i = 0; i < n; i++) {
          while (!stack.isEmpty() && temperatures[stack.peek()] < temperatures[i]) {
              int j = stack.pop();
              result[j] = i - j;  // distance to next warmer day
          }
          stack.push(i);
      }
      return result;  // default 0 for no warmer day
  }

  Time: O(n)  Space: O(n)

  Trace (first few): [73,74,75,71,69,72,76,73]
    i=0: push 0. stack=[0]
    i=1: 74>73, pop 0, result[0]=1-0=1. stack=[]. push 1. stack=[1]
    i=2: 75>74, pop 1, result[1]=2-1=1. stack=[]. push 2. stack=[2]
    i=3: 71<75. push 3. stack=[2,3]
    i=4: 69<71. push 4. stack=[2,3,4]
    i=5: 72>69, pop 4, result[4]=5-4=1.
         72>71, pop 3, result[3]=5-3=2.
         72<75. push 5. stack=[2,5]
    i=6: 76>72, pop 5, result[5]=6-5=1.
         76>75, pop 2, result[2]=6-2=4.
         push 6. stack=[6]
    i=7: 73<76. push 7. stack=[6,7]
    result[6]=0, result[7]=0

  result = [1,1,4,2,1,1,0,0] ✓

PROBLEM (LC 901): ONLINE STOCK SPAN
----------------------------------------------------------------

  At each day, find the span = consecutive days with price <= today's price
  (including today).

  Span = distance to previous greater element (exclusive) = i - prev_greater_index.

  Use a monotone DECREASING stack of (price, span) pairs.
  When pushing, accumulate spans of all popped elements.

  public class StockSpanner {
      private Deque<int[]> stack;  // [price, span]

      public StockSpanner() {
          stack = new ArrayDeque<>();
      }

      public int next(int price) {
          int span = 1;
          while (!stack.isEmpty() && stack.peek()[0] <= price) {
              span += stack.pop()[1];  // absorb span of smaller/equal element
          }
          stack.push(new int[]{price, span});
          return span;
      }
  }

  Time: O(1) amortized per call  Space: O(n)

----------------------------------------------------------------
PREVIOUS GREATER ELEMENT
----------------------------------------------------------------

  For each element, find the nearest previous element that is greater.

  Process left to right. When about to push, peek at stack top.
  The stack top IS the previous greater element (or stack empty = none).

  public int[] previousGreater(int[] nums) {
      int n = nums.length;
      int[] result = new int[n];
      Deque<Integer> stack = new ArrayDeque<>();  // decreasing

      for (int i = 0; i < n; i++) {
          while (!stack.isEmpty() && nums[stack.peek()] <= nums[i]) {
              stack.pop();
          }
          result[i] = stack.isEmpty() ? -1 : nums[stack.peek()];
          stack.push(i);
      }
      return result;
  }

----------------------------------------------------------------
SUMMARY TABLE
----------------------------------------------------------------

  Problem              Stack Type    Pop When           Result
  -------              ----------    --------           ------
  Next Greater         Decreasing    curr > top         result[popped] = curr
  Next Smaller         Increasing    curr < top         result[popped] = curr
  Previous Greater     Decreasing    curr >= top        result[curr] = peek
  Previous Smaller     Increasing    curr <= top        result[curr] = peek
  Daily Temperatures   Decreasing    curr > top         result[popped] = i - j
  Circular next-great  Decreasing    same, 2 passes     result[popped] = curr

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. Using values vs indices in stack.
     For problems needing distance (daily temps), store INDICES.
     For problems just needing the value (LC 496), values work.

  2. Strict vs non-strict comparison (< vs <=).
     For "strictly greater": pop when stack.top < current (strict <).
     For "greater or equal": pop when stack.top <= current.

  3. Circular array: forgetting to only push indices in first pass (i < n).

  4. Remaining stack elements: don't forget, they have answer -1 or 0.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Explain: stack holds elements "waiting for their answer."
  - When a bigger element arrives, it "answers" all smaller ones it pops.
  - Trace daily temperatures step by step (most common asked).
  - Mention amortized O(n): each element pushed/popped at most once.
