================================================================
  DECODE STRING AND STACK-BASED STRING PROBLEMS
  (LC 394, LC 71, LC 1047, LC 735)
================================================================

----------------------------------------------------------------
PROBLEM (LC 394): DECODE STRING
----------------------------------------------------------------

  Encoded string format: k[encoded_string]
  Decode: repeat encoded_string k times.
  Nesting is possible: 3[a2[c]] = accaccacc.

  Input:  "3[a]2[bc]"   --> "aaabcbc"
  Input:  "3[a2[c]]"    --> "accaccacc"
  Input:  "2[abc]3[cd]ef" --> "abcabccdcdcdef"

----------------------------------------------------------------
APPROACH: TWO STACKS (count stack + string stack)
----------------------------------------------------------------

  One stack for current number (multiplier).
  One stack for current string (being built before current bracket).

  When we see:
    digit:    accumulate into currentNum (handle multi-digit: k=10*k+digit)
    '[':      push currentNum and currentStr onto stacks, reset both
    ']':      pop count and prevStr. new currentStr = prevStr + count*currentStr
    letter:   append to currentStr

  Java:
    public String decodeString(String s) {
        Deque<Integer> countStack = new ArrayDeque<>();
        Deque<StringBuilder> strStack = new ArrayDeque<>();
        StringBuilder current = new StringBuilder();
        int k = 0;

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                k = k * 10 + (c - '0');        // handle multi-digit
            } else if (c == '[') {
                countStack.push(k);
                strStack.push(current);
                current = new StringBuilder();  // reset for inner string
                k = 0;
            } else if (c == ']') {
                int count = countStack.pop();
                StringBuilder prev = strStack.pop();
                for (int i = 0; i < count; i++) prev.append(current);
                current = prev;
            } else {
                current.append(c);
            }
        }
        return current.toString();
    }

  Time: O(maxK^depth * n)  where maxK is max multiplier, depth is nesting
  Space: O(depth)  for stacks

----------------------------------------------------------------
TRACED EXAMPLE: "3[a2[c]]"
----------------------------------------------------------------

  c='3':  k=3
  c='[':  push k=3 to countStack, push ""  to strStack. current="", k=0
           countStack=[3], strStack=[""]
  c='a':  current="a"
  c='2':  k=2
  c='[':  push k=2 to countStack, push "a" to strStack. current="", k=0
           countStack=[3,2], strStack=["","a"]
  c='c':  current="c"
  c=']':  count=pop(2)=2, prev=pop("a")="a"
           prev = "a" + "c"*2 = "acc"
           current="acc". countStack=[3], strStack=[""]
  c=']':  count=pop(3)=3, prev=pop("")=""
           prev = "" + "acc"*3 = "accaccacc"
           current="accaccacc". stacks empty.

  Return "accaccacc" ✓

----------------------------------------------------------------
RECURSIVE APPROACH (ALTERNATIVE)
----------------------------------------------------------------

  Maintain a global index. For each '[', recurse. For each ']', return.

  private int idx = 0;

  public String decodeString(String s) {
      idx = 0;
      return decode(s);
  }

  private String decode(String s) {
      StringBuilder sb = new StringBuilder();
      while (idx < s.length() && s.charAt(idx) != ']') {
          if (Character.isDigit(s.charAt(idx))) {
              int k = 0;
              while (idx < s.length() && Character.isDigit(s.charAt(idx))) {
                  k = k * 10 + (s.charAt(idx++) - '0');
              }
              idx++;  // skip '['
              String inner = decode(s);
              idx++;  // skip ']'
              for (int i = 0; i < k; i++) sb.append(inner);
          } else {
              sb.append(s.charAt(idx++));
          }
      }
      return sb.toString();
  }

  Both approaches work. Iterative stack is preferred in interviews.

PROBLEM (LC 71): SIMPLIFY PATH
----------------------------------------------------------------

  Given a Unix file path, simplify it.
    ".." = go up one directory
    "."  = current directory (ignore)
    Extra "/" = ignored
    "//" = same as "/"

  Input:  "/home//foo/"  --> "/home/foo"
  Input:  "/../"         --> "/"
  Input:  "/a/./b/../../c/" --> "/c"

  Java:
    public String simplifyPath(String path) {
        Deque<String> stack = new ArrayDeque<>();

        for (String part : path.split("/")) {
            if (part.equals("..")) {
                if (!stack.isEmpty()) stack.pop();
            } else if (!part.equals(".") && !part.isEmpty()) {
                stack.push(part);
            }
        }

        StringBuilder sb = new StringBuilder();
        for (String dir : stack) sb.insert(0, "/" + dir);  // stack is LIFO

        return sb.length() == 0 ? "/" : sb.toString();
    }

  Simpler with LinkedList (preserve insertion order):
    Deque<String> deque = new LinkedList<>();
    // ... push to addLast, pop from removeLast
    // Then join: "/" + String.join("/", deque)

    public String simplifyPath(String path) {
        Deque<String> deque = new LinkedList<>();
        for (String part : path.split("/")) {
            if (part.equals("..")) {
                if (!deque.isEmpty()) deque.removeLast();
            } else if (!part.isEmpty() && !part.equals(".")) {
                deque.addLast(part);
            }
        }
        return "/" + String.join("/", deque);
    }

  Time: O(n)  Space: O(n)

PROBLEM (LC 1047): REMOVE ALL ADJACENT DUPLICATES IN STRING
----------------------------------------------------------------

  Repeatedly remove adjacent duplicate pairs until no duplicates remain.

  Input:  "abbaca"  --> "ca"
    "abbaca" -> "aaca" -> "ca"

  Stack approach: push character. If top == current, pop (remove pair).
  Otherwise push.

  Java:
    public String removeDuplicates(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (!stack.isEmpty() && stack.peek() == c) {
                stack.pop();  // remove pair
            } else {
                stack.push(c);
            }
        }

        StringBuilder sb = new StringBuilder();
        while (!stack.isEmpty()) sb.append(stack.pollLast());  // preserve order
        return sb.toString();
    }

  Time: O(n)  Space: O(n)

  Or using StringBuilder directly as a stack:
    StringBuilder sb = new StringBuilder();
    for (char c : s.toCharArray()) {
        if (sb.length() > 0 && sb.charAt(sb.length() - 1) == c) {
            sb.deleteCharAt(sb.length() - 1);
        } else {
            sb.append(c);
        }
    }
    return sb.toString();

PROBLEM (LC 735): ASTEROID COLLISION
----------------------------------------------------------------

  Array of integers representing asteroids. Positive = moving right.
  Negative = moving left. Same-direction never collide.
  When colliding: smaller magnitude explodes. Equal magnitude: both explode.

  Input:  [5, 10, -5]   --> [5, 10]  (10 wins over -5)
  Input:  [8, -8]       --> []       (both explode)
  Input:  [10, 2, -5]   --> [10]     (10 wins)
  Input:  [-2, -1, 1, 2] --> [-2,-1,1,2] (no collision: left-moving then right-moving)

  Java:
    public int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (int a : asteroids) {
            boolean alive = true;
            // Collision: right-moving (top > 0) meets left-moving (a < 0)
            while (alive && a < 0 && !stack.isEmpty() && stack.peek() > 0) {
                if (stack.peek() < -a) {
                    stack.pop();        // stack's asteroid explodes
                } else if (stack.peek() == -a) {
                    stack.pop();        // both explode
                    alive = false;
                } else {
                    alive = false;      // new asteroid explodes
                }
            }
            if (alive) stack.push(a);
        }

        int[] result = new int[stack.size()];
        for (int i = stack.size() - 1; i >= 0; i--) result[i] = stack.pop();
        return result;
    }

  Time: O(n)  Space: O(n)

----------------------------------------------------------------
COMMON PATTERN: STACK FOR STRING BUILDING
----------------------------------------------------------------

  Use stack (or StringBuilder as stack) when:
    - Processing left to right, but decision at position i depends on previous chars
    - Removing matching pairs, adjacent duplicates, or invalid characters
    - Building result incrementally, potentially undoing (backspace problem)

  Backspace String Compare (LC 844):
    Simulate typing with a stack: '#' = pop, letter = push.
    Compare final stacks.

  Remove K Digits (LC 402):
    Monotone increasing stack. Pop while top > current AND k > 0.

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. LC 394 decode: multi-digit numbers. k = k*10 + digit (not just digit).
  2. LC 394: when hitting ']', need to repeat current string, then append to prev.
     (Not append prev to current.)
  3. LC 1047: pollLast (bottom of stack) to preserve left-to-right order in result.
     Or build with StringBuilder in reverse.
  4. LC 735: the while loop must also check alive (asteroid might explode mid-loop).
  5. LC 71: empty parts from split("/"): ignore with !part.isEmpty().

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: For decode string, why do we need TWO stacks?
  A: One stack tracks the repeat count at each nesting level, and the other
     tracks the accumulated string before the current '['. Both are needed
     to reconstruct the decoded string when we hit ']'.

  Q: Why does simplify path use a deque instead of just a stack?
  A: To preserve insertion order when building the final path. We add
     directories to the back and read them in order. With a stack,
     we'd need to reverse.

  Q: How do you handle multi-digit numbers like "12[a]"?
  A: Accumulate digit by digit: k = k * 10 + (c - '0').
     Reset k to 0 only when we push it (on '[').

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - For LC 394: draw the stack state at each '[' and ']'.
  - Trace "3[a2[c]]" step by step (common in interviews).
  - For asteroid: the key insight is left-moving asteroids can only collide
    with right-moving asteroids already in the stack.
  - Mention StringBuilder as a practical "stack" for single-character stacks.
