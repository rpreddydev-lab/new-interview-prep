================================================================
  REPLACE WORDS AND RELATED TRIE PROBLEMS — LC 648 / LC 720 / LC 336
================================================================

  LC 648: Given dictionary of roots and a sentence,
          replace each word in the sentence with its shortest root.
          If no root matches, keep the original word.

  Input: dictionary = ["cat","bat","rat"], sentence = "the cattle was rattled by the battery"
  Output: "the cat was rat by the bat"

----------------------------------------------------------------
LC 648 — REPLACE WORDS
----------------------------------------------------------------

  Approach: Build a Trie from the dictionary roots.
            For each word in sentence, search trie → return shortest matching root.

  Java:
    class Solution {
        private static class TrieNode {
            TrieNode[] ch = new TrieNode[26];
            String root = null;  // store root word at end node
        }

        public String replaceWords(List<String> dictionary, String sentence) {
            TrieNode trie = new TrieNode();
            for (String root : dictionary) {
                TrieNode cur = trie;
                for (char c : root.toCharArray()) {
                    int i = c - 'a';
                    if (cur.ch[i] == null) cur.ch[i] = new TrieNode();
                    cur = cur.ch[i];
                }
                cur.root = root;  // mark root word at end
            }

            String[] words = sentence.split(" ");
            StringBuilder sb = new StringBuilder();
            for (String word : words) {
                if (sb.length() > 0) sb.append(' ');
                sb.append(findRoot(trie, word));
            }
            return sb.toString();
        }

        private String findRoot(TrieNode trie, String word) {
            TrieNode cur = trie;
            for (char c : word.toCharArray()) {
                int i = c - 'a';
                if (cur.ch[i] == null) return word;  // no matching prefix
                cur = cur.ch[i];
                if (cur.root != null) return cur.root;  // found shortest root!
            }
            return word;
        }
    }

  Time: O(D*L + S*L) where D=dict size, L=avg root length, S=sentence word count.
  Space: O(D*L) for trie.

  Key: return cur.root as soon as we find any root node. This guarantees SHORTEST root
       because trie traversal moves character by character and we stop at first match.

----------------------------------------------------------------
ALTERNATIVE: HASHSET APPROACH
----------------------------------------------------------------

  For each word in sentence, try all prefixes, check if in dict set.

  Java:
    public String replaceWords(List<String> dictionary, String sentence) {
        Set<String> dictSet = new HashSet<>(dictionary);
        String[] words = sentence.split(" ");
        StringBuilder sb = new StringBuilder();
        for (String word : words) {
            String replacement = word;
            for (int i = 1; i <= word.length(); i++) {
                String prefix = word.substring(0, i);
                if (dictSet.contains(prefix)) { replacement = prefix; break; }
            }
            if (sb.length() > 0) sb.append(' ');
            sb.append(replacement);
        }
        return sb.toString();
    }

  Time: O(S * L²) — substring creates new string O(L) for each of L prefixes.
  Trie approach is faster when L is large.

LC 720 — LONGEST WORD IN DICTIONARY
----------------------------------------------------------------

  Given array of words, find longest word that can be built one character at a time
  by other words in the array. If tie, return lexicographically smallest.

  Strategy: Build trie. BFS/DFS — a word is "buildable" if every prefix is also in the dict.
            In trie terms: a word is valid only if all its ancestor nodes have isEnd=true.

  Java:
    public String longestWord(String[] words) {
        // Sort: ensures we process shorter words first (BFS-like)
        // OR use trie with isEnd tracking
        Arrays.sort(words);  // sort lex; shorter words of same prefix come first
        Set<String> built = new HashSet<>();
        built.add("");
        String longest = "";
        for (String w : words) {
            String prefix = w.substring(0, w.length() - 1);
            if (built.contains(prefix)) {
                built.add(w);
                if (w.length() > longest.length()) longest = w;
                // if same length, 'words' is sorted so earlier = lex smaller
            }
        }
        return longest;
    }

  Time: O(N * L log N) — sorting. O(N * L) for HashSet operations.

  Trie approach: insert all, then DFS only through nodes with isEnd=true.
    The DFS path length is the word length; track maximum.

  Java (Trie):
    public String longestWord(String[] words) {
        TrieNode root = new TrieNode();
        for (String w : words) {
            TrieNode cur = root; int i = 0;
            for (char c : w.toCharArray()) {
                int idx = c - 'a';
                if (cur.ch[idx] == null) cur.ch[idx] = new TrieNode();
                cur = cur.ch[idx];
                if (i == w.length() - 1) cur.word = w;
                i++;
            }
        }
        // BFS from root, only traverse nodes with word != null
        String longest = "";
        Queue<TrieNode> q = new LinkedList<>();
        q.offer(root);
        while (!q.isEmpty()) {
            TrieNode node = q.poll();
            for (TrieNode child : node.ch) {
                if (child != null && child.word != null) {
                    q.offer(child);
                    if (child.word.length() > longest.length() ||
                        (child.word.length() == longest.length()
                         && child.word.compareTo(longest) < 0)) {
                        longest = child.word;
                    }
                }
            }
        }
        return longest;
    }

LC 336 — PALINDROME PAIRS (TRIE APPLICATION)
----------------------------------------------------------------

  Given array of unique strings, find all pairs (i,j) where
  words[i] + words[j] is a palindrome.

  Approach 1 (HashMap): O(N * L²)
    For each word, try all splits. Use reversed dict.

  Java (HashMap):
    public List<List<Integer>> palindromePairs(String[] words) {
        Map<String, Integer> map = new HashMap<>();
        for (int i = 0; i < words.length; i++) map.put(words[i], i);
        List<List<Integer>> res = new ArrayList<>();

        for (int i = 0; i < words.length; i++) {
            String w = words[i];
            for (int cut = 0; cut <= w.length(); cut++) {
                String left = w.substring(0, cut);
                String right = w.substring(cut);
                // Case 1: right is palindrome, reverse of left is in dict
                if (isPalin(right)) {
                    String revLeft = new StringBuilder(left).reverse().toString();
                    if (map.containsKey(revLeft) && map.get(revLeft) != i) {
                        res.add(Arrays.asList(i, map.get(revLeft)));
                    }
                }
                // Case 2: left is palindrome (non-empty), reverse of right is in dict
                if (cut > 0 && isPalin(left)) {
                    String revRight = new StringBuilder(right).reverse().toString();
                    if (map.containsKey(revRight) && map.get(revRight) != i) {
                        res.add(Arrays.asList(map.get(revRight), i));
                    }
                }
            }
        }
        return res;
    }

    boolean isPalin(String s) {
        int l = 0, r = s.length() - 1;
        while (l < r) if (s.charAt(l++) != s.charAt(r--)) return false;
        return true;
    }

  Time: O(N * L²)   Space: O(N * L)

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: In LC 648, why does trie guarantee shortest root?
  A: Trie traversal goes char by char. First time we hit a node with root!=null,
     that root has length = current depth = shortest matching prefix.

  Q: Could we solve LC 648 with a sorted dictionary?
  A: Sort by length, then for each word scan sorted dict for prefix match.
     O(S * D * L) — worse than trie approach.

  Q: LC 720: why does BFS/DFS only through isEnd nodes work?
  A: A word is "buildable" iff all its prefixes are also words.
     Trie node with isEnd=false means that prefix isn't in the dict,
     so any longer path through it is not fully buildable.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - LC 648: "traverse trie along word chars; return the root string as soon as we hit a node
    with a stored root value" — this is cleaner than checking after every char.
  - LC 720: sorting approach is quick to code; mention trie approach as optimization.
  - For LC 336, the HashMap approach is standard; trie approach is more complex with little gain.
