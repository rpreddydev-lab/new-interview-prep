================================================================
  WORD SEARCH II — LC 212 (TRIE + BACKTRACKING)
================================================================

  Given an m×n grid of characters and a list of words,
  return all words that can be found in the grid.
  A word is found by traversing adjacent (4-directional) cells,
  each cell used at most once per word path.

  This is LC 79 (Word Search I) for multiple words simultaneously.
  Naive approach: run LC 79 for each word → O(words * m * n * 4^L).
  Trie approach: build trie of all words, DFS grid once → much faster.

----------------------------------------------------------------
APPROACH: TRIE + DFS BACKTRACKING
----------------------------------------------------------------

  1. Insert all words into a Trie.
  2. DFS each grid cell as a potential starting point.
  3. At each DFS step: check if current char leads to a trie node.
     If no matching trie child → prune (backtrack early).
     If node.isEnd → add word to result, mark isEnd=false (avoid duplicates).
  4. Mark cell visited during DFS, restore after backtrack.

  Key optimization: store the word at the TrieNode (not just isEnd bool).
                    Avoids reconstructing word from path.

  Java:
    class Solution {
        private static class TrieNode {
            TrieNode[] children = new TrieNode[26];
            String word = null;  // stores complete word at end node
        }

        private TrieNode root = new TrieNode();

        private void insert(String word) {
            TrieNode cur = root;
            for (char c : word.toCharArray()) {
                int i = c - 'a';
                if (cur.children[i] == null) cur.children[i] = new TrieNode();
                cur = cur.children[i];
            }
            cur.word = word;  // store word at leaf
        }

        public List<String> findWords(char[][] board, String[] words) {
            for (String w : words) insert(w);
            int m = board.length, n = board[0].length;
            List<String> result = new ArrayList<>();
            for (int r = 0; r < m; r++) {
                for (int c = 0; c < n; c++) {
                    dfs(board, r, c, root, result);
                }
            }
            return result;
        }

        private void dfs(char[][] board, int r, int c, TrieNode node, List<String> result) {
            if (r < 0 || r >= board.length || c < 0 || c >= board[0].length) return;
            char ch = board[r][c];
            if (ch == '#') return;  // visited cell
            int idx = ch - 'a';
            TrieNode next = node.children[idx];
            if (next == null) return;  // no trie path → prune

            if (next.word != null) {
                result.add(next.word);
                next.word = null;  // mark as found to avoid duplicates
            }

            board[r][c] = '#';  // mark visited
            dfs(board, r+1, c, next, result);
            dfs(board, r-1, c, next, result);
            dfs(board, r, c+1, next, result);
            dfs(board, r, c-1, next, result);
            board[r][c] = ch;   // restore

            // Optional pruning: remove leaf node after finding word
            // (reduces trie size as search continues)
        }
    }

  Time: O(M * N * 4 * 3^(L-1)) per DFS path, pruned by trie.
        Overall: O(M*N*L + sum(4*3^(L-1))) — much better than naive.
  Space: O(total chars in all words) for trie.

----------------------------------------------------------------
TRIE PRUNING OPTIMIZATION
----------------------------------------------------------------

  After finding a word (and setting node.word=null), if that node
  has no children and no word, it's dead — remove it from parent.
  This shrinks the trie progressively, speeding up remaining DFS.

  Java (add to dfs after recursion):
    // In dfs, after the 4 recursive calls and restoring board[r][c]:
    // Check if 'next' node has become empty (no children, no word)
    // and remove it from parent (node.children[idx] = null)

    private void dfs(char[][] board, int r, int c, TrieNode node, List<String> result) {
        // ... (same as before up to restore) ...
        board[r][c] = ch;
        // Pruning: if next is now a dead leaf, remove from trie
        if (next.word == null) {
            boolean hasChild = false;
            for (TrieNode child : next.children) {
                if (child != null) { hasChild = true; break; }
            }
            if (!hasChild) node.children[idx] = null;
        }
    }

  This makes the algorithm more efficient for large word lists.

----------------------------------------------------------------
LC 79 — WORD SEARCH I (SINGLE WORD)
----------------------------------------------------------------

  Java:
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (dfs79(board, word, r, c, 0)) return true;
            }
        }
        return false;
    }

    private boolean dfs79(char[][] board, String word, int r, int c, int idx) {
        if (idx == word.length()) return true;
        if (r < 0 || r >= board.length || c < 0 || c >= board[0].length) return false;
        if (board[r][c] != word.charAt(idx)) return false;
        board[r][c] = '#';
        boolean found = dfs79(board,word,r+1,c,idx+1) || dfs79(board,word,r-1,c,idx+1)
                      || dfs79(board,word,r,c+1,idx+1) || dfs79(board,word,r,c-1,idx+1);
        board[r][c] = word.charAt(idx);  // restore
        return found;
    }

  Time: O(M*N * 4 * 3^(L-1))   Space: O(L) recursion stack.

----------------------------------------------------------------
TRACED EXAMPLE: LC 212
----------------------------------------------------------------

  Board:
    o  a  a  n
    e  t  a  e
    i  h  k  r
    i  f  l  v

  Words: ["oath","pea","eat","rain"]

  Trie after inserting all words:
    o→a→t→h (word="oath")
    p→e→a   (word="pea")
    e→a→t   (word="eat")
    r→a→i→n (word="rain")

  DFS from (0,3) 'n': trie has no child 'n' at root → skip.
  DFS from (1,3) 'e': root has child 'e'. Move to 'e' node.
    DFS (2,3) 'r': 'e' node has no child 'r'.
    DFS (0,3) 'n': 'e' node has no child 'n'.
    DFS (1,2) 'a': 'e' node has child 'a'! Move to 'a' node.
      DFS (0,2) 'a': 'a' node has no child 'a' on path to end. Stop.
      DFS (2,2) 'k': 'a' node has no child 'k'. Stop.
      DFS (1,3) visited '#'. Stop.
      DFS (1,1) 't': 'a' node has child 't'! Move to 't' node.
        t node word = "eat" → add "eat" to result! ✓

  Continue DFS... eventually finds "oath" starting from (1,1).

  Result: ["eat", "oath"]

----------------------------------------------------------------
COMPARISON: LC 79 VS LC 212
----------------------------------------------------------------

  Feature            LC 79 (single word)       LC 212 (multiple words)
  ----------------   -----------------------   -----------------------
  Words to find      1                         Many
  Approach           DFS + backtrack           Trie + DFS + backtrack
  Pruning            char mismatch             trie child null
  Dedup handling     N/A                       node.word=null after found
  Complexity         O(M*N*4*3^L)              O(M*N*4*3^L) but shared

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why not just run LC 79 for each word?
  A: O(W * M*N * 4^L) where W = number of words. Trie shares prefix traversal
     across words, effectively O(M*N * 4^L) for the DFS (prefix pruning).

  Q: Why store the full word at the TrieNode instead of just isEnd?
  A: During DFS, we only have (row, col, trieNode) — not the path taken.
     Storing word at node allows result.add(node.word) without path reconstruction.

  Q: Why set node.word = null after adding to result?
  A: The same word path could be found starting from different grid cells.
     Setting null prevents duplicate entries in result.

  Q: What does marking board[r][c] = '#' accomplish?
  A: Prevents revisiting the same cell within the current word's path.
     Must restore after DFS to allow other paths to use this cell.
