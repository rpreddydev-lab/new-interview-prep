================================================================
  IMPLEMENT TRIE — LC 208 / LC 211
================================================================

  LC 208: Implement a Trie (prefix tree) with:
    - insert(word)
    - search(word)      → true if full word exists
    - startsWith(prefix) → true if any word has this prefix

  LC 211: Design Add and Search Words Data Structure.
    - addWord(word)
    - search(word) where word may contain '.' (matches any letter)

----------------------------------------------------------------
LC 208 — FULL SOLUTION
----------------------------------------------------------------

  Java:
    class Trie {

        private static class TrieNode {
            TrieNode[] children = new TrieNode[26];
            boolean isEnd = false;
        }

        private final TrieNode root = new TrieNode();

        public void insert(String word) {
            TrieNode cur = root;
            for (char c : word.toCharArray()) {
                int i = c - 'a';
                if (cur.children[i] == null) cur.children[i] = new TrieNode();
                cur = cur.children[i];
            }
            cur.isEnd = true;
        }

        public boolean search(String word) {
            TrieNode node = findNode(word);
            return node != null && node.isEnd;
        }

        public boolean startsWith(String prefix) {
            return findNode(prefix) != null;
        }

        private TrieNode findNode(String s) {
            TrieNode cur = root;
            for (char c : s.toCharArray()) {
                int i = c - 'a';
                if (cur.children[i] == null) return null;
                cur = cur.children[i];
            }
            return cur;
        }
    }

  Complexity:
    insert      : O(L) time, O(L) space for new nodes
    search      : O(L) time
    startsWith  : O(L) time
    L = length of word/prefix

----------------------------------------------------------------
LC 208 — TRACED EXAMPLE
----------------------------------------------------------------

  Operations:
    insert("apple")
    search("apple")     → true
    search("app")       → false  (isEnd=false at 'p' node)
    startsWith("app")   → true   (node exists at 'p')
    insert("app")
    search("app")       → true   (isEnd=true now)

  Trie after inserting "apple" and "app":

    root
     |
     a
     |
     p
     |
     p(*)        ← isEnd=true (for "app")
     |
     l
     |
     e(*)        ← isEnd=true (for "apple")

LC 211 — WILDCARD SEARCH (. matches any char)
----------------------------------------------------------------

  Strategy: Recursive DFS. At each '.', try all 26 children.

  Java:
    class WordDictionary {

        private static class TrieNode {
            TrieNode[] children = new TrieNode[26];
            boolean isEnd = false;
        }

        private final TrieNode root = new TrieNode();

        public void addWord(String word) {
            TrieNode cur = root;
            for (char c : word.toCharArray()) {
                int i = c - 'a';
                if (cur.children[i] == null) cur.children[i] = new TrieNode();
                cur = cur.children[i];
            }
            cur.isEnd = true;
        }

        public boolean search(String word) {
            return dfs(root, word, 0);
        }

        private boolean dfs(TrieNode node, String word, int idx) {
            if (idx == word.length()) return node.isEnd;
            char c = word.charAt(idx);
            if (c == '.') {
                for (TrieNode child : node.children) {
                    if (child != null && dfs(child, word, idx + 1)) return true;
                }
                return false;
            } else {
                int i = c - 'a';
                if (node.children[i] == null) return false;
                return dfs(node.children[i], word, idx + 1);
            }
        }
    }

  Time: O(L) for exact words. O(26^L) worst case for all-dots.
  Space: O(L) recursion stack.

----------------------------------------------------------------
LC 211 — TRACED EXAMPLE
----------------------------------------------------------------

  addWord("bad"), addWord("dad"), addWord("mad")

  search("pad") → false   (p is not in trie)
  search("bad") → true    (exact match)
  search(".ad") → true    (. tries b,d,m — bDFS finds "bad")
  search("b..") → true    (b→a→d found)

  DFS for "b..":
    dfs(root, "b..", 0): c='b' → go to 'b' node.
    dfs(bNode, "b..", 1): c='.' → try all children of bNode.
      bNode has child 'a'. dfs(aNode, "b..", 2): c='.' → try all children of aNode.
        aNode has child 'd'. dfs(dNode, "b..", 3): idx==length. isEnd=true → return true.

RELATED: LC 745 — PREFIX AND SUFFIX SEARCH
----------------------------------------------------------------

  Create a map from "{suffix}#{prefix" → word index.
  Iterate all suffix,prefix pairs for each word.

  Java (simplified):
    class WordFilter {
        Map<String, Integer> map = new HashMap<>();

        public WordFilter(String[] words) {
            for (int i = 0; i < words.length; i++) {
                String w = words[i];
                for (int s = 0; s <= w.length(); s++) {
                    // key = suffix + "#" + prefix → covers all combos
                    for (int p = 0; p <= w.length(); p++) {
                        map.put(w.substring(s) + "#" + w.substring(0, p), i);
                    }
                }
            }
        }

        public int f(String pref, String suff) {
            return map.getOrDefault(suff + "#" + pref, -1);
        }
    }

  Time constructor: O(N * L²)   Time query: O(L)   Space: O(N * L²)

RELATED: LC 677 — MAP SUM PAIRS
----------------------------------------------------------------

  Insert (key, val) pairs. Return sum of all values whose key starts with prefix.

  Java:
    class MapSum {
        private static class TrieNode {
            TrieNode[] ch = new TrieNode[26];
            int val = 0;
        }
        TrieNode root = new TrieNode();

        public void insert(String key, int val) {
            TrieNode cur = root;
            for (char c : key.toCharArray()) {
                int i = c - 'a';
                if (cur.ch[i] == null) cur.ch[i] = new TrieNode();
                cur = cur.ch[i];
            }
            cur.val = val;
        }

        public int sum(String prefix) {
            TrieNode cur = root;
            for (char c : prefix.toCharArray()) {
                int i = c - 'a';
                if (cur.ch[i] == null) return 0;
                cur = cur.ch[i];
            }
            return dfsSum(cur);
        }

        int dfsSum(TrieNode node) {
            if (node == null) return 0;
            int s = node.val;
            for (TrieNode child : node.ch) s += dfsSum(child);
            return s;
        }
    }

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: What does search vs startsWith differ?
  A: search requires the full word to exist (isEnd=true at last node).
     startsWith only requires the path to exist (node != null after last char).

  Q: Why is '.' in LC 211 potentially slow?
  A: At each '.', we branch into all 26 children. For word "...", 26*26*26 paths.
     Worst case O(26^L), but in practice much better with pruning (null children).

  Q: Can a node exist with isEnd=false?
  A: Yes! Intermediate nodes of longer words have isEnd=false.
     E.g., in "apple", nodes for 'a','p','p','l' all have isEnd=false. Only 'e' has isEnd=true.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Lead with the TrieNode class structure before writing Trie class.
  - Always check `if (cur.children[i] == null) return null` in findNode.
  - For LC 211 DFS, show the branching at '.' explicitly in explanation.
  - Common bug: forgetting to check `node.isEnd` in `search()` (returning true just because node exists).
