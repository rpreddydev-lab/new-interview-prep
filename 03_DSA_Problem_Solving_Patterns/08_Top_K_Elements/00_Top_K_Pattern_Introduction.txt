================================================================
  TOP-K ELEMENTS PATTERN — INTRODUCTION
================================================================

  The Top-K pattern selects the K largest, K smallest, K most frequent,
  or K closest elements from a dataset.

  Core tool: HEAP (Priority Queue in Java)
    - Min-Heap of size K  -->  maintains the K largest elements
    - Max-Heap of size K  -->  maintains the K smallest elements

  Why not just sort?
    - Sorting is O(n log n). Heap gives O(n log k) — much better when k << n.
    - For streaming data, heap works without knowing n upfront.

----------------------------------------------------------------
TOOL 1: MIN-HEAP OF SIZE K (Top-K Largest)
----------------------------------------------------------------

  Logic:
    - Maintain a min-heap of exactly K elements.
    - For each new element: if heap.size() < k or element > heap.peek(), add it.
    - If heap.size() > k, remove the minimum (heap.poll()).
    - At end, heap contains the K largest. Minimum of those is heap.peek().

  Java:
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();  // natural order = min

    for (int num : nums) {
        minHeap.offer(num);
        if (minHeap.size() > k) minHeap.poll();
    }
    return minHeap.peek();  // kth largest

  Time: O(n log k)   Space: O(k)

----------------------------------------------------------------
TOOL 2: MAX-HEAP (Top-K Smallest or Kth Smallest)
----------------------------------------------------------------

  Java:
    PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());

    for (int num : nums) {
        maxHeap.offer(num);
        if (maxHeap.size() > k) maxHeap.poll();
    }
    return maxHeap.peek();  // kth smallest

----------------------------------------------------------------
TOOL 3: QUICKSELECT (Kth Element, Average O(n))
----------------------------------------------------------------

  Partition-based selection. Average O(n), worst O(n²).
  Not stable. Modifies input array.

  public int findKthLargest(int[] nums, int k) {
      return quickSelect(nums, 0, nums.length - 1, nums.length - k);
  }

  private int quickSelect(int[] nums, int lo, int hi, int targetIdx) {
      int pivot = partition(nums, lo, hi);
      if (pivot == targetIdx) return nums[pivot];
      else if (pivot < targetIdx) return quickSelect(nums, pivot + 1, hi, targetIdx);
      else return quickSelect(nums, lo, pivot - 1, targetIdx);
  }

  private int partition(int[] nums, int lo, int hi) {
      int pivot = nums[hi], i = lo;
      for (int j = lo; j < hi; j++) {
          if (nums[j] <= pivot) swap(nums, i++, j);
      }
      swap(nums, i, hi);
      return i;
  }

----------------------------------------------------------------
TOOL 4: BUCKET SORT / COUNTING SORT (Top-K Frequent, O(n))
----------------------------------------------------------------

  When values are bounded or working with frequencies:
    1. Count frequencies.
    2. Create buckets[frequency] = list of elements.
    3. Walk buckets from high frequency to low, collect K elements.

  Frequency range is [1..n] so buckets has n+1 slots.

  Time: O(n)   Space: O(n)

----------------------------------------------------------------
COMPARISON TABLE
----------------------------------------------------------------

  Approach          Time          Space    When to use
  -----------------------------------------------------------
  Min-Heap size k   O(n log k)    O(k)     Streaming, large n, small k
  Sort              O(n log n)    O(n)     Simple, one-time, small n
  QuickSelect       O(n) avg      O(1)     Single Kth, modifying OK
  Bucket Sort       O(n)          O(n)     Frequencies, bounded values

----------------------------------------------------------------
HEAP API IN JAVA
----------------------------------------------------------------

  PriorityQueue (Min-Heap by default):
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    PriorityQueue<Integer> maxPQ = new PriorityQueue<>(Collections.reverseOrder());

  Custom comparator (e.g., by distance):
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);

  Key methods:
    offer(e) / add(e)   -- O(log n) insert
    poll()              -- O(log n) remove + return min
    peek()              -- O(1) view min
    size()              -- O(1)

  WARNING: Do not use pq[0] or iterate assuming order.
           Only peek() and poll() are guaranteed to give min/max.

----------------------------------------------------------------
DECISION GUIDE
----------------------------------------------------------------

  "Kth largest/smallest in array"       --> Min/Max-Heap or QuickSelect
  "Top K frequent elements"             --> HashMap + Heap OR Bucket Sort
  "K closest points"                    --> Heap with distance comparator
  "Running median"                      --> Two heaps (max + min)
  "Merge K sorted lists/arrays"         --> Min-Heap of (value, list-index)
  "Streaming top-K"                     --> Min-Heap of size K
