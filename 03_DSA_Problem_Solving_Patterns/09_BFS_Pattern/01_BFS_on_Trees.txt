================================================================
  BFS ON TREES (LEVEL ORDER TRAVERSAL)
================================================================

  Tree BFS processes nodes level by level using a queue.
  No visited set needed (trees have no cycles).
  Returns a List<List<Integer>> for level-order problems.

----------------------------------------------------------------
CORE: BINARY TREE LEVEL ORDER TRAVERSAL (LC 102)
----------------------------------------------------------------

  Input:
        3
       / \
      9  20
        /  \
       15   7

  Output: [[3],[9,20],[15,7]]

  Java:
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();          // freeze current level
            List<Integer> level = new ArrayList<>();

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            result.add(level);
        }
        return result;
    }

  Time: O(n)   Space: O(n) -- queue holds at most one full level (n/2 at last level)

----------------------------------------------------------------
TRACED EXAMPLE
----------------------------------------------------------------

  Initial: queue=[3], result=[]

  Level 0: size=1
    poll(3), add 9 and 20. level=[3]. result=[[3]]
    queue=[9,20]

  Level 1: size=2
    poll(9), no children. poll(20), add 15 and 7. level=[9,20]. result=[[3],[9,20]]
    queue=[15,7]

  Level 2: size=2
    poll(15), poll(7). level=[15,7]. result=[[3],[9,20],[15,7]]
    queue=[]

----------------------------------------------------------------
VARIANT: ZIGZAG LEVEL ORDER (LC 103)
----------------------------------------------------------------

  Alternate direction each level:
    Level 0: left to right  [3]
    Level 1: right to left  [20,9]
    Level 2: left to right  [15,7]

  Java:
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        boolean leftToRight = true;

        while (!queue.isEmpty()) {
            int size = queue.size();
            LinkedList<Integer> level = new LinkedList<>();  // LinkedList for addFirst

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (leftToRight) level.addLast(node.val);
                else level.addFirst(node.val);   // reverse direction
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            result.add(level);
            leftToRight = !leftToRight;
        }
        return result;
    }

  Key: use LinkedList.addFirst() for right-to-left levels.
  Queue always processes children left-to-right; addFirst reverses at result.

----------------------------------------------------------------
VARIANT: RIGHT SIDE VIEW (LC 199)
----------------------------------------------------------------

  For each level, the rightmost node is visible.
  Simply take the LAST node in each level.

  Java:
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (i == size - 1) result.add(node.val);  // last of level
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return result;
    }

  Left side view: take first node (i == 0).

----------------------------------------------------------------
VARIANT: MINIMUM DEPTH (LC 111)
----------------------------------------------------------------

  Minimum depth = first level where a LEAF node is found.
  A leaf has no left and no right child.

  BFS naturally finds the closest leaf first.

  Java:
    public int minDepth(TreeNode root) {
        if (root == null) return 0;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int depth = 1;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node.left == null && node.right == null) return depth;
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            depth++;
        }
        return depth;
    }

  Contrast with MAX depth:
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int depth = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            depth++;
        }
        return depth;
    }

VARIANT: LEVEL AVERAGES / SUMS
----------------------------------------------------------------

  Java (LC 637 Average of Levels):
    public List<Double> averageOfLevels(TreeNode root) {
        List<Double> result = new ArrayList<>();
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            double sum = 0;
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                sum += node.val;
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            result.add(sum / size);
        }
        return result;
    }

----------------------------------------------------------------
VARIANT: CONNECT NEXT RIGHT POINTERS (LC 116, 117)
----------------------------------------------------------------

  Populate next pointer for each node pointing to the next right node.

  BFS approach: process level by level, link consecutive nodes in each level.

  Java:
    public Node connect(Node root) {
        if (root == null) return null;
        Queue<Node> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                Node node = queue.poll();
                // Link to next in queue (if not last in level)
                if (i < size - 1) node.next = queue.peek();
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return root;
    }

  Note: queue.peek() before offering children gives the next node in same level.

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. Forgetting to freeze size: if (queue.size()) inside the loop changes.
     ALWAYS capture int size = queue.size() BEFORE the inner loop.

  2. Returning result before adding to result at end of level.

  3. For min depth: checking if root is a leaf (no children) is crucial.
     A node with one child is NOT a leaf — don't return early for it.

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why do we freeze queue size before the inner for loop?
  A: During the inner loop, we add children (next level) to the queue.
     If we check queue.size() dynamically, we'd process children of the
     current level in the same iteration, mixing levels.

  Q: What's the space complexity of level order traversal?
  A: O(n) -- in the worst case (complete binary tree), the last level has
     n/2 nodes, all in the queue simultaneously.

  Q: When would you prefer DFS for a tree problem over BFS?
  A: When you don't need level information (e.g., path sum, serialize tree,
     max depth with recursion). DFS is simpler and uses O(h) stack vs
     O(n) BFS queue.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - The `int size = queue.size()` freeze is the KEY technique — mention it.
  - For zigzag: LinkedList.addFirst() vs addLast() is the trick.
  - For right side view: just take last node per level.
  - Min depth trap: a single-child node is not a leaf.
