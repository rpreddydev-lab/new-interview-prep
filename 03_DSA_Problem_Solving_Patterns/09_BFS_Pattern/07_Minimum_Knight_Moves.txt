================================================================
  MINIMUM KNIGHT MOVES (LC 1197)
================================================================

  In an infinite chessboard, find the minimum number of moves for
  a knight to go from (0,0) to (x,y).

  A knight moves in an L-shape: 2 squares in one direction,
  1 square perpendicular (8 possible moves).

  Input:  x=2, y=1   --> 1
  Input:  x=5, y=5   --> 4

----------------------------------------------------------------
KNIGHT MOVES
----------------------------------------------------------------

  From (r, c), a knight can move to:
    (r+2,c+1), (r+2,c-1),
    (r-2,c+1), (r-2,c-1),
    (r+1,c+2), (r+1,c-2),
    (r-1,c+2), (r-1,c-2)

  Java:
    int[][] dirs = {{2,1},{2,-1},{-2,1},{-2,-1},{1,2},{1,-2},{-1,2},{-1,-2}};

----------------------------------------------------------------
APPROACH 1: BFS WITH COORDINATE ENCODING
----------------------------------------------------------------

  State: (row, col). BFS finds minimum moves.
  For infinite board: need to bound the search space.

  Key insight: by symmetry, we can restrict to the first quadrant (x>=0, y>=0).
  Take abs(x) and abs(y). The answer is the same by 4-fold symmetry.

  Bound: we never need to go beyond (|x|+2, |y|+2) -- the target is at (|x|, |y|),
  and going slightly beyond can be optimal due to L-shape constraints.

  Java:
    public int minKnightMoves(int x, int y) {
        x = Math.abs(x); y = Math.abs(y);  // symmetry

        int[][] dirs = {{2,1},{2,-1},{-2,1},{-2,-1},{1,2},{1,-2},{-1,2},{-1,-2}};

        // Offset by 2 to handle slight negative positions (e.g., -1,-2 from (1,2))
        // Limit search to [-(2), x+2] x [-(2), y+2]
        Set<String> visited = new HashSet<>();
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0});
        visited.add("0,0");
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int[] curr = queue.poll();
                if (curr[0] == x && curr[1] == y) return steps;

                for (int[] dir : dirs) {
                    int nr = curr[0]+dir[0], nc = curr[1]+dir[1];
                    String key = nr + "," + nc;
                    // Restrict: don't go too far in wrong direction
                    if (!visited.contains(key) && nr >= -2 && nc >= -2
                        && nr <= x+2 && nc <= y+2) {
                        visited.add(key);
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
            steps++;
        }
        return -1;
    }

  Time: O(|x| * |y|)   Space: O(|x| * |y|)

----------------------------------------------------------------
APPROACH 2: BFS WITH 2D VISITED ARRAY (FIXED GRID)
----------------------------------------------------------------

  Since we use symmetry (first quadrant), coordinates in [0, x+2] x [0, y+2].
  Use a 2D array for visited.

  Java:
    public int minKnightMoves(int x, int y) {
        x = Math.abs(x); y = Math.abs(y);

        int bound = Math.max(x, y) + 3;
        boolean[][] visited = new boolean[bound][bound];

        int[][] dirs = {{2,1},{2,-1},{-2,1},{-2,-1},{1,2},{1,-2},{-1,2},{-1,-2}};
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0});
        visited[0][0] = true;
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int[] curr = queue.poll();
                if (curr[0] == x && curr[1] == y) return steps;
                for (int[] dir : dirs) {
                    int nr = curr[0]+dir[0], nc = curr[1]+dir[1];
                    if (nr >= 0 && nr < bound && nc >= 0 && nc < bound && !visited[nr][nc]) {
                        visited[nr][nc] = true;
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
            steps++;
        }
        return -1;
    }

----------------------------------------------------------------
APPROACH 3: MATH FORMULA (O(1))
----------------------------------------------------------------

  Interviewers may ask for the mathematical solution.
  For (a, b) in the first quadrant (a >= b >= 0):

  Base cases:
    (0,0) = 0
    (1,1) = 4  (can't do in fewer)
    (2,2) = 4

  Formula:
    If a+b == 1: return 3
    If a+b == 2: return 4
    Otherwise, on the diagonal towards (a,b):
      t = max((a+2)/3, (b+2)/3, (a+b+3)/4) * 2  -- but complex

  The math formula is not expected in interviews. BFS is the intended approach.

OPEN THE LOCK (LC 752) — SIMILAR STATE SPACE BFS
----------------------------------------------------------------

  A lock with 4 wheels, each 0-9. Turn one wheel up/down.
  Dead ends = forbidden combinations. Find min turns to reach target.

  State: 4-char string "0000" to "9999" (10^4 states).

  Java:
    public int openLock(String[] deadends, String target) {
        Set<String> dead = new HashSet<>(Arrays.asList(deadends));
        if (dead.contains("0000")) return -1;
        if (target.equals("0000")) return 0;

        Queue<String> queue = new ArrayDeque<>();
        Set<String> visited = new HashSet<>();
        queue.offer("0000");
        visited.add("0000");
        int turns = 0;

        while (!queue.isEmpty()) {
            turns++;
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                String curr = queue.poll();
                for (int j = 0; j < 4; j++) {
                    // Turn up and down
                    for (int d : new int[]{1, -1}) {
                        char[] chars = curr.toCharArray();
                        chars[j] = (char)((chars[j]-'0'+d+10)%10 + '0');
                        String next = new String(chars);
                        if (next.equals(target)) return turns;
                        if (!visited.contains(next) && !dead.contains(next)) {
                            visited.add(next);
                            queue.offer(next);
                        }
                    }
                }
            }
        }
        return -1;
    }

  Time: O(10^4 * 4 * 2) = O(8 * 10^4)   Space: O(10^4)

JUMP GAME IV (LC 1345) — BFS WITH SAME-VALUE JUMPS
----------------------------------------------------------------

  From position i, can jump to i-1, i+1, or any j where arr[j]==arr[i].
  Find minimum jumps from index 0 to last index.

  BFS where each group of same-value indices is precomputed.
  Once a group is processed, remove it (to avoid O(n^2) repeat visits).

  Java:
    public int minJumps(int[] arr) {
        int n = arr.length;
        Map<Integer, List<Integer>> sameVal = new HashMap<>();
        for (int i = 0; i < n; i++) sameVal.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);

        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(0); visited[0] = true;
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int curr = queue.poll();
                if (curr == n-1) return steps;

                List<int[]> neighbors = new ArrayList<>();
                // Adjacent
                if (curr-1 >= 0 && !visited[curr-1]) { visited[curr-1]=true; queue.offer(curr-1); }
                if (curr+1 < n  && !visited[curr+1]) { visited[curr+1]=true; queue.offer(curr+1); }
                // Same value
                List<Integer> same = sameVal.getOrDefault(arr[curr], Collections.emptyList());
                for (int j : same) {
                    if (!visited[j]) { visited[j]=true; queue.offer(j); }
                }
                sameVal.remove(arr[curr]);  // CRITICAL: remove to avoid revisiting this group
            }
            steps++;
        }
        return -1;
    }

  Time: O(n)   Space: O(n)

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why do we use symmetry (abs(x), abs(y)) for knight moves?
  A: The chessboard is symmetric. Minimum moves from (0,0) to (x,y) is the
     same as to (|x|,|y|), (-x,y), (x,-y), etc. This reduces the search space
     to the first quadrant.

  Q: What's the bound for the search space in knight moves?
  A: We limit to (|x|+2, |y|+2). Sometimes a knight must "overshoot" slightly
     in the first quadrant to reach the target efficiently.

  Q: For Open Lock, why is the string representation of state useful?
  A: Strings serve as hashable state keys for the visited set.
     Alternatively, encode 4 digits as a single integer: d0*1000+d1*100+d2*10+d3.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Knight moves: state = (row, col). The 8 moves are the adjacency list.
  - Symmetry reduces infinite board to bounded search.
  - For Open Lock: 4 * 2 = 8 transitions per state, elegant BFS.
  - For Jump Game IV: the key optimization is removing same-value groups
    from the map after visiting them (avoids O(n^2) worst case).
