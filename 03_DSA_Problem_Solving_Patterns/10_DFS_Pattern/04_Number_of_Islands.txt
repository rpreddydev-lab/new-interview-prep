================================================================
  NUMBER OF ISLANDS (LC 200) — DEEP DIVE
================================================================

  Given a 2D grid of '1' (land) and '0' (water), count the number of islands.
  An island is surrounded by water and formed by connecting adjacent lands
  horizontally or vertically.

  Input:
    11110
    11010
    11000
    00000
  Output: 1

  Input:
    11000
    11000
    00100
    00011
  Output: 3

----------------------------------------------------------------
APPROACH 1: DFS (MOST COMMON)
----------------------------------------------------------------

  For each unvisited '1', increment count and DFS to sink the entire island.

  Java:
    public int numIslands(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int count = 0;

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == '1') {
                    count++;
                    dfs(grid, r, c, m, n);
                }
            }
        }
        return count;
    }

    private void dfs(char[][] grid, int r, int c, int m, int n) {
        if (r<0 || r>=m || c<0 || c>=n || grid[r][c] != '1') return;
        grid[r][c] = '0';  // sink (mark visited)
        dfs(grid, r+1, c, m, n);
        dfs(grid, r-1, c, m, n);
        dfs(grid, r, c+1, m, n);
        dfs(grid, r, c-1, m, n);
    }

  Time: O(m*n)   Space: O(m*n) recursion stack

----------------------------------------------------------------
APPROACH 2: BFS
----------------------------------------------------------------

  Java:
    public int numIslands(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        int count = 0;

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == '1') {
                    count++;
                    Queue<int[]> queue = new ArrayDeque<>();
                    queue.offer(new int[]{r, c});
                    grid[r][c] = '0';

                    while (!queue.isEmpty()) {
                        int[] curr = queue.poll();
                        for (int[] dir : dirs) {
                            int nr = curr[0]+dir[0], nc = curr[1]+dir[1];
                            if (nr>=0 && nr<m && nc>=0 && nc<n && grid[nr][nc]=='1') {
                                grid[nr][nc] = '0';
                                queue.offer(new int[]{nr, nc});
                            }
                        }
                    }
                }
            }
        }
        return count;
    }

  BFS avoids stack overflow for large grids.
  Time: O(m*n)   Space: O(min(m,n)) -- queue holds at most one diagonal

----------------------------------------------------------------
APPROACH 3: UNION-FIND
----------------------------------------------------------------

  Each land cell is a node. Union adjacent land cells.
  Count distinct roots at the end.

  Java:
    public int numIslands(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] parent = new int[m * n];
        int[] rank = new int[m * n];
        int count = 0;

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == '1') {
                    int idx = r * n + c;
                    parent[idx] = idx;
                    count++;
                }
            }
        }

        int[][] dirs = {{0,1},{1,0}};  // only right and down (to avoid double-processing)
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == '1') {
                    for (int[] dir : dirs) {
                        int nr = r+dir[0], nc = c+dir[1];
                        if (nr<m && nc<n && grid[nr][nc]=='1') {
                            int rootA = find(parent, r*n+c);
                            int rootB = find(parent, nr*n+nc);
                            if (rootA != rootB) {
                                union(parent, rank, rootA, rootB);
                                count--;
                            }
                        }
                    }
                }
            }
        }
        return count;
    }

    int find(int[] parent, int x) {
        if (parent[x] != x) parent[x] = find(parent, parent[x]);
        return parent[x];
    }

    void union(int[] parent, int[] rank, int a, int b) {
        if (rank[a] < rank[b]) { int t = a; a = b; b = t; }
        parent[b] = a;
        if (rank[a] == rank[b]) rank[a]++;
    }

  Time: O(m*n * alpha(m*n))  ~O(m*n)   Space: O(m*n)

----------------------------------------------------------------
TRACED EXAMPLE: [[1,1,0],[0,1,0],[0,0,1]]
----------------------------------------------------------------

  Initial: count=0

  (0,0)='1': count=1, dfs sinks (0,0)
    (0,1)='1': sink, recurse
      (1,1)='1': sink, recurse
        neighbors all '0' or out-of-bounds, return
    Return to (0,0)
  All 1s connected to (0,0) sunk.

  (0,1)='0', skip. (1,1)='0', skip. (0,2)='0', skip. ...

  (2,2)='1': count=2, dfs sinks (2,2)
    All neighbors '0', return.

  Final count = 2 ✓

----------------------------------------------------------------
VARIANT: NUMBER OF ISLANDS II (LC 305) — ONLINE QUERIES
----------------------------------------------------------------

  Start with empty grid. Add land cells one at a time.
  After each addition, return current island count.

  Approach: Union-Find.
  When adding cell (r,c): count++. Then check 4 neighbors. For each
  land neighbor with different root, union (count--).

  Java:
    public List<Integer> numIslands2(int m, int n, int[][] positions) {
        int[] parent = new int[m*n];
        Arrays.fill(parent, -1);
        int[] rank = new int[m*n];
        int count = 0;
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        List<Integer> result = new ArrayList<>();

        for (int[] pos : positions) {
            int r = pos[0], c = pos[1], idx = r*n+c;
            if (parent[idx] == -1) {
                parent[idx] = idx;
                count++;
                for (int[] dir : dirs) {
                    int nr=r+dir[0], nc=c+dir[1], nidx=nr*n+nc;
                    if (nr>=0&&nr<m&&nc>=0&&nc<n&&parent[nidx]!=-1) {
                        int rootA = find(parent, idx), rootB = find(parent, nidx);
                        if (rootA != rootB) { parent[rootA] = rootB; count--; }
                    }
                }
            }
            result.add(count);
        }
        return result;
    }

    int find(int[] parent, int x) {
        if (parent[x] != x) parent[x] = find(parent, parent[x]);
        return parent[x];
    }

  Time: O(k * alpha(m*n)) per query, k = number of positions

----------------------------------------------------------------
COMPARISON TABLE
----------------------------------------------------------------

  Approach      Time          Space         Best for
  -----------------------------------------------------------
  DFS           O(m*n)        O(m*n) stack  Simple, clean
  BFS           O(m*n)        O(min(m,n))   Large grids (no stack overflow)
  Union-Find    O(m*n*alpha)  O(m*n)        Online updates (LC 305)

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why does sinking ('1'->'0') work as visited marking?
  A: We're guaranteed no cell needs to be counted twice. Sinking it prevents
     DFS from revisiting. If the grid must be preserved, use boolean[][] visited.

  Q: What's the space complexity of DFS?
  A: O(m*n) in the worst case (when the entire grid is one island,
     DFS recursion depth = m*n).

  Q: When would Union-Find be preferred over DFS/BFS?
  A: When islands are added dynamically (LC 305 Number of Islands II).
     Union-Find supports incremental updates efficiently.

  Q: BFS queue space is O(min(m,n)) -- why?
  A: The queue holds cells at the frontier. The widest the frontier can be
     is bounded by the shorter dimension of the grid (like a diagonal sweep).

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - DFS + sink is the cleanest solution. Know it cold.
  - Mention all 3 approaches and tradeoffs.
  - For follow-up "what if grid is very large?": BFS avoids stack overflow.
  - For follow-up "what if cells are added online?": Union-Find.
  - LC 200 is one of the most commonly asked graph problems at FAANG.
