================================================================
  DFS ON GRAPHS
================================================================

  Graph DFS explores deeply before backtracking.
  Must track visited nodes (graphs have cycles, unlike trees).

----------------------------------------------------------------
CONNECTED COMPONENTS
----------------------------------------------------------------

  Each call to DFS from an unvisited node covers one connected component.

  Java:
    public int countComponents(int n, int[][] edges) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        boolean[] visited = new boolean[n];
        int count = 0;

        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                dfs(i, adj, visited);
                count++;
            }
        }
        return count;
    }

    private void dfs(int node, List<List<Integer>> adj, boolean[] visited) {
        visited[node] = true;
        for (int neighbor : adj.get(node)) {
            if (!visited[neighbor]) dfs(neighbor, adj, visited);
        }
    }

  Time: O(V + E)   Space: O(V)

CYCLE DETECTION — UNDIRECTED GRAPH
----------------------------------------------------------------

  During DFS, if we visit an already-visited neighbor that is NOT
  the parent, there's a back edge = cycle.

  Java:
    public boolean hasCycle(int n, int[][] edges) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        boolean[] visited = new boolean[n];
        for (int i = 0; i < n; i++) {
            if (!visited[i] && dfsCycle(i, -1, adj, visited)) return true;
        }
        return false;
    }

    private boolean dfsCycle(int node, int parent, List<List<Integer>> adj, boolean[] visited) {
        visited[node] = true;
        for (int neighbor : adj.get(node)) {
            if (!visited[neighbor]) {
                if (dfsCycle(neighbor, node, adj, visited)) return true;
            } else if (neighbor != parent) {
                return true;  // back edge to non-parent = cycle
            }
        }
        return false;
    }

----------------------------------------------------------------
CYCLE DETECTION — DIRECTED GRAPH (3-COLOR DFS)
----------------------------------------------------------------

  Colors:
    0 = WHITE (unvisited)
    1 = GRAY  (in current DFS path/recursion stack)
    2 = BLACK (fully processed)

  If we encounter a GRAY node during DFS, there's a back edge = cycle.

  Java:
    int[] color = new int[n];  // all 0

    public boolean hasCycleDirected(int n, List<List<Integer>> adj) {
        for (int i = 0; i < n; i++) {
            if (color[i] == 0 && dfsCycleDir(i, adj)) return true;
        }
        return false;
    }

    private boolean dfsCycleDir(int node, List<List<Integer>> adj) {
        color[node] = 1;  // GRAY (in stack)
        for (int neighbor : adj.get(node)) {
            if (color[neighbor] == 1) return true;   // back edge to gray node
            if (color[neighbor] == 0 && dfsCycleDir(neighbor, adj)) return true;
        }
        color[node] = 2;  // BLACK (done)
        return false;
    }

TOPOLOGICAL SORT — DFS POST-ORDER
----------------------------------------------------------------

  Valid for DAG (Directed Acyclic Graph).
  Process all dependencies of a node before the node itself.

  Java:
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());
        for (int[] p : prerequisites) adj.get(p[1]).add(p[0]);

        int[] color = new int[numCourses];
        List<Integer> order = new ArrayList<>();

        for (int i = 0; i < numCourses; i++) {
            if (color[i] == 0) {
                if (!dfsTopoSort(i, adj, color, order)) return new int[0];  // cycle
            }
        }

        Collections.reverse(order);
        return order.stream().mapToInt(Integer::intValue).toArray();
    }

    private boolean dfsTopoSort(int node, List<List<Integer>> adj, int[] color, List<Integer> order) {
        color[node] = 1;
        for (int next : adj.get(node)) {
            if (color[next] == 1) return false;  // cycle
            if (color[next] == 0 && !dfsTopoSort(next, adj, color, order)) return false;
        }
        color[node] = 2;
        order.add(node);  // POST-ORDER: add after all dependencies done
        return true;
    }

  Time: O(V + E)   Space: O(V + E)

PROBLEM: COURSE SCHEDULE (LC 207) — CONCISE
----------------------------------------------------------------

  Can all courses be completed? = Is the DAG a valid DAG (no cycles)?

  Java (short version):
    public boolean canFinish(int n, int[][] prerequisites) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] p : prerequisites) adj.get(p[1]).add(p[0]);

        int[] state = new int[n];  // 0=unvisited, 1=visiting, 2=done
        for (int i = 0; i < n; i++) {
            if (!dfs(i, adj, state)) return false;
        }
        return true;
    }

    boolean dfs(int node, List<List<Integer>> adj, int[] state) {
        if (state[node] == 1) return false;  // cycle
        if (state[node] == 2) return true;   // already processed
        state[node] = 1;
        for (int next : adj.get(node)) {
            if (!dfs(next, adj, state)) return false;
        }
        state[node] = 2;
        return true;
    }

PROBLEM: NUMBER OF PROVINCES (LC 547)
----------------------------------------------------------------

  isConnected[i][j] = 1 if cities i and j are directly connected.
  Find number of provinces (connected components).

  Java:
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        boolean[] visited = new boolean[n];
        int provinces = 0;

        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                dfs(i, isConnected, visited, n);
                provinces++;
            }
        }
        return provinces;
    }

    private void dfs(int city, int[][] grid, boolean[] visited, int n) {
        visited[city] = true;
        for (int j = 0; j < n; j++) {
            if (grid[city][j] == 1 && !visited[j]) {
                dfs(j, grid, visited, n);
            }
        }
    }

PROBLEM: REDUNDANT CONNECTION (LC 684)
----------------------------------------------------------------

  Given n nodes and n edges forming a tree plus one extra edge.
  Find the redundant edge.

  DFS approach: for each edge (u,v), check if u and v are already connected
  (DFS from u to v). If yes, this is the redundant edge.
  Otherwise add the edge.

  Union-Find approach is O(n * alpha(n)) and cleaner.

  Java (Union-Find for reference):
    public int[] findRedundantConnection(int[][] edges) {
        int n = edges.length;
        int[] parent = new int[n+1];
        for (int i = 0; i <= n; i++) parent[i] = i;

        for (int[] edge : edges) {
            int p = find(parent, edge[0]), q = find(parent, edge[1]);
            if (p == q) return edge;      // same component = cycle
            parent[p] = q;                // union
        }
        return new int[]{};
    }

    int find(int[] parent, int x) {
        if (parent[x] != x) parent[x] = find(parent, parent[x]);
        return parent[x];
    }

STRONGLY CONNECTED COMPONENTS (OVERVIEW)
----------------------------------------------------------------

  SCC: subset of vertices where every vertex is reachable from every other.

  Kosaraju's Algorithm (2-pass DFS):
    Pass 1: DFS on original graph, collect finish order (post-order).
    Pass 2: DFS on reversed graph in reverse finish order.
    Each DFS tree in pass 2 is one SCC.

  Tarjan's Algorithm (1-pass DFS):
    Track discovery time and low-link values.
    Uses a stack.

  Both O(V+E). Not commonly asked in interviews, but good to know exists.

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: For cycle detection in directed vs undirected, why different approaches?
  A: Undirected: any already-visited non-parent neighbor = cycle (back edge).
     Directed: a visited neighbor in the CURRENT recursion stack = back edge.
     A visited neighbor that's already fully processed (BLACK) is a cross edge,
     NOT a cycle.

  Q: Why post-order for topological sort?
  A: A node is added to the result AFTER all its outgoing neighbors are done.
     This ensures dependencies come before dependent nodes.

  Q: What's the difference between color[i]==1 and color[i]==2?
  A: 1 = currently in the recursion stack (GRAY). Encountering it = cycle.
     2 = fully processed (BLACK). Encountering it = safe cross edge.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Always draw the adjacency list before coding.
  - For topological sort: emphasize "add to result in post-order, then reverse."
  - For cycle detection: the 3-color approach is cleaner than just boolean visited.
  - LC 207 (Course Schedule) combines graph construction + DFS cycle detection.
  - Practice stating time complexity: O(V+E) for most graph DFS problems.
