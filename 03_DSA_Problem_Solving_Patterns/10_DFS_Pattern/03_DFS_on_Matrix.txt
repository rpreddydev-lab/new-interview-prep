================================================================
  DFS ON MATRIX (FLOOD FILL, CONNECTED REGIONS)
================================================================

  2D grid DFS: each cell is a node, neighbors are adjacent cells.
  DFS explores all connected cells from a starting cell.

  Primary use cases:
    - Flood fill / paint connected region
    - Count connected components
    - Find largest connected region
    - Check if cells are reachable

----------------------------------------------------------------
STANDARD MATRIX DFS TEMPLATE
----------------------------------------------------------------

  Java:
    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

    void dfs(int[][] grid, boolean[][] visited, int r, int c) {
        // bounds + validity check
        if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length) return;
        if (visited[r][c] || grid[r][c] == 0) return;  // invalid cell

        visited[r][c] = true;
        // process cell

        for (int[] dir : dirs) {
            dfs(grid, visited, r + dir[0], c + dir[1]);
        }
    }

  Alternative: mark visited by modifying grid (in-place):
    grid[r][c] = 0;  // sink visited cell
    // recurse neighbors

PROBLEM: FLOOD FILL (LC 733)
----------------------------------------------------------------

  From cell (sr, sc) with color oldColor, change all connected cells
  of oldColor to newColor.

  Java:
    public int[][] floodFill(int[][] image, int sr, int sc, int color) {
        int oldColor = image[sr][sc];
        if (oldColor == color) return image;   // no change needed
        dfs(image, sr, sc, oldColor, color);
        return image;
    }

    private void dfs(int[][] img, int r, int c, int oldColor, int newColor) {
        if (r<0 || r>=img.length || c<0 || c>=img[0].length) return;
        if (img[r][c] != oldColor) return;

        img[r][c] = newColor;   // mark visited + update
        dfs(img, r+1, c, oldColor, newColor);
        dfs(img, r-1, c, oldColor, newColor);
        dfs(img, r, c+1, oldColor, newColor);
        dfs(img, r, c-1, oldColor, newColor);
    }

  Time: O(m*n)   Space: O(m*n) recursion stack

  Guard: if oldColor == newColor, return early to prevent infinite recursion.

PROBLEM: MAX AREA OF ISLAND (LC 695)
----------------------------------------------------------------

  Find the largest island (connected 1s) in the grid.

  Java:
    public int maxAreaOfIsland(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int maxArea = 0;

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) {
                    maxArea = Math.max(maxArea, dfs(grid, r, c, m, n));
                }
            }
        }
        return maxArea;
    }

    private int dfs(int[][] grid, int r, int c, int m, int n) {
        if (r<0 || r>=m || c<0 || c>=n || grid[r][c] == 0) return 0;
        grid[r][c] = 0;   // mark visited
        return 1
            + dfs(grid, r+1, c, m, n)
            + dfs(grid, r-1, c, m, n)
            + dfs(grid, r, c+1, m, n)
            + dfs(grid, r, c-1, m, n);
    }

  Returns the area of the island starting at (r,c).

PROBLEM: SURROUNDED REGIONS (LC 130)
----------------------------------------------------------------

  Flip all 'O' to 'X' except those connected to the border.

  Approach: DFS from all border 'O's, mark them 'S' (safe).
  Then flip: 'O' -> 'X', 'S' -> 'O'.

  Java:
    public void solve(char[][] board) {
        int m = board.length, n = board[0].length;

        // Mark all border-connected 'O's as safe
        for (int r = 0; r < m; r++) {
            if (board[r][0] == 'O') dfs(board, r, 0, m, n);
            if (board[r][n-1] == 'O') dfs(board, r, n-1, m, n);
        }
        for (int c = 0; c < n; c++) {
            if (board[0][c] == 'O') dfs(board, 0, c, m, n);
            if (board[m-1][c] == 'O') dfs(board, m-1, c, m, n);
        }

        // Flip: 'O'=surrounded->'X', 'S'=safe->'O'
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if      (board[r][c] == 'O') board[r][c] = 'X';
                else if (board[r][c] == 'S') board[r][c] = 'O';
            }
        }
    }

    private void dfs(char[][] board, int r, int c, int m, int n) {
        if (r<0 || r>=m || c<0 || c>=n || board[r][c] != 'O') return;
        board[r][c] = 'S';
        dfs(board, r+1, c, m, n);
        dfs(board, r-1, c, m, n);
        dfs(board, r, c+1, m, n);
        dfs(board, r, c-1, m, n);
    }

PROBLEM: PACIFIC ATLANTIC WATER FLOW (LC 417)
----------------------------------------------------------------

  DFS from Pacific borders (top + left) and Atlantic borders (bottom + right).
  "Reverse flow": expand to cells with >= height (water flows from there).

  Java:
    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        int m = heights.length, n = heights[0].length;
        boolean[][] pac = new boolean[m][n], atl = new boolean[m][n];

        for (int r = 0; r < m; r++) {
            dfs(heights, pac, r, 0, m, n, Integer.MIN_VALUE);
            dfs(heights, atl, r, n-1, m, n, Integer.MIN_VALUE);
        }
        for (int c = 0; c < n; c++) {
            dfs(heights, pac, 0, c, m, n, Integer.MIN_VALUE);
            dfs(heights, atl, m-1, c, m, n, Integer.MIN_VALUE);
        }

        List<List<Integer>> result = new ArrayList<>();
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++)
                if (pac[r][c] && atl[r][c]) result.add(Arrays.asList(r, c));
        return result;
    }

    private void dfs(int[][] h, boolean[][] reach, int r, int c, int m, int n, int prevHeight) {
        if (r<0 || r>=m || c<0 || c>=n) return;
        if (reach[r][c]) return;
        if (h[r][c] < prevHeight) return;  // can't flow backward (uphill)
        reach[r][c] = true;
        dfs(h, reach, r+1, c, m, n, h[r][c]);
        dfs(h, reach, r-1, c, m, n, h[r][c]);
        dfs(h, reach, r, c+1, m, n, h[r][c]);
        dfs(h, reach, r, c-1, m, n, h[r][c]);
    }

STACK OVERFLOW CONCERN WITH MATRIX DFS
----------------------------------------------------------------

  For very large grids, recursive DFS can cause StackOverflowError.
  E.g., 300x300 grid: DFS stack depth up to 90,000.

  Solutions:
    1. Convert to iterative DFS with an explicit stack.
    2. Use BFS instead (queue-based, no deep recursion).

  Iterative DFS (flood fill example):
    Deque<int[]> stack = new ArrayDeque<>();
    stack.push(new int[]{r, c});
    while (!stack.isEmpty()) {
        int[] curr = stack.pop();
        // process curr
        // push valid unvisited neighbors
    }

  BFS is generally safer for large grids in interviews.

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. Not marking visited BEFORE recursing (can revisit cells).
  2. Forgetting base case: out-of-bounds OR already-visited OR invalid cell.
  3. For flood fill: forgetting oldColor == newColor guard --> infinite recursion.
  4. For LC 417: confusing direction -- BFS/DFS goes UPHILL (from ocean to high cells).
  5. Stack overflow on large grids if using recursion.

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: When is DFS preferred over BFS for matrix problems?
  A: DFS: when you don't need shortest path -- just need to explore/count
     a connected region (flood fill, area of island, connected component count).
     BFS: when you need shortest distance (01 Matrix, Rotting Oranges).

  Q: How do you handle the stack overflow risk with matrix DFS?
  A: Convert to iterative DFS using ArrayDeque, or use BFS.
     For most LeetCode problems, the grids are small enough for recursion.

  Q: For LC 130, why mark as 'S' instead of a boolean array?
  A: Saves a separate data structure. We overload the grid to store 3 states:
     'X' (wall/already flipped), 'O' (potential to flip), 'S' (safe, won't flip).

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - State the in-place vs separate visited tradeoffs upfront.
  - For flood fill, guard against same-color early return.
  - For LC 417 (Pacific Atlantic): the "reverse flow" insight is the key.
  - DFS functions on grids often look cleaner without the dirs array
    (just 4 explicit recursive calls), but dirs is more scalable.
