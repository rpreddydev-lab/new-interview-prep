================================================================
  DFS PATTERN — INTRODUCTION
  (Depth-First Search)
================================================================

  DFS explores as far as possible along a branch before backtracking.
  Uses a STACK (call stack for recursion, or explicit stack for iteration).

  Key properties:
    - Explores ALL paths from source.
    - Does NOT guarantee shortest path.
    - Natural fit for: connected components, cycle detection, paths,
      flood fill, topological sort, tree traversals.

----------------------------------------------------------------
RECURSIVE DFS TEMPLATE (GRAPH)
----------------------------------------------------------------

  Java:
    void dfs(int node, boolean[] visited, List<List<Integer>> adj) {
        visited[node] = true;
        // process node

        for (int neighbor : adj.get(node)) {
            if (!visited[neighbor]) {
                dfs(neighbor, visited, adj);
            }
        }
    }

  Call: for (int i = 0; i < n; i++) if (!visited[i]) dfs(i, visited, adj);

----------------------------------------------------------------
ITERATIVE DFS TEMPLATE (EXPLICIT STACK)
----------------------------------------------------------------

  Java:
    Deque<Integer> stack = new ArrayDeque<>();
    boolean[] visited = new boolean[n];

    stack.push(start);
    visited[start] = true;

    while (!stack.isEmpty()) {
        int curr = stack.pop();
        // process curr

        for (int neighbor : adj.get(curr)) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                stack.push(neighbor);
            }
        }
    }

  NOTE: Iterative DFS with explicit stack does NOT always produce the
  same visit order as recursive DFS (due to stack reversal).
  For tree traversal, order depends on push order.

----------------------------------------------------------------
DFS ON TREES: THREE ORDERS
----------------------------------------------------------------

  Preorder  (root, left, right):  good for serialization, copying
  Inorder   (left, root, right):  gives sorted order in BST
  Postorder (left, right, root):  good for deletion, size computation

  Java (recursive inorder):
    void inorder(TreeNode node, List<Integer> result) {
        if (node == null) return;
        inorder(node.left, result);
        result.add(node.val);
        inorder(node.right, result);
    }

  Java (iterative inorder — important for interviews):
    List<Integer> inorderIterative(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode curr = root;

        while (curr != null || !stack.isEmpty()) {
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;  // go left
            }
            curr = stack.pop();
            result.add(curr.val);   // visit
            curr = curr.right;      // go right
        }
        return result;
    }

----------------------------------------------------------------
DFS ON GRAPH: CYCLE DETECTION
----------------------------------------------------------------

  Undirected graph (via DFS):
    Track parent. If a visited neighbor is not the parent, cycle exists.

  Directed graph (via DFS):
    Use 3-color (WHITE=0, GRAY=1, BLACK=2).
    If we visit a GRAY node, there's a back edge = cycle.

  Java (directed cycle detection):
    int[] color = new int[n];  // 0=unvisited, 1=in-stack, 2=done

    boolean hasCycle(int node) {
        color[node] = 1;
        for (int neighbor : adj.get(node)) {
            if (color[neighbor] == 1) return true;      // back edge
            if (color[neighbor] == 0 && hasCycle(neighbor)) return true;
        }
        color[node] = 2;
        return false;
    }

----------------------------------------------------------------
DFS ON GRAPH: TOPOLOGICAL SORT
----------------------------------------------------------------

  Post-order DFS. Add node to result AFTER all its dependencies are done.
  Reverse the result.

  Java:
    List<Integer> topoOrder = new ArrayList<>();

    void dfs(int node) {
        visited[node] = true;
        for (int next : adj.get(node)) {
            if (!visited[next]) dfs(next);
        }
        topoOrder.add(node);  // POST-order: add after all neighbors
    }

    // After all DFS calls:
    Collections.reverse(topoOrder);

----------------------------------------------------------------
DFS vs BFS COMPARISON
----------------------------------------------------------------

  Property             DFS                  BFS
  -------------------------------------------------------
  Data structure       Stack (recursion)    Queue
  Shortest path        No (usually)         Yes (unweighted)
  Memory               O(depth)             O(width)
  All paths            Yes                  No (naturally)
  Tree traversal       Yes (3 orders)       Level order
  Connected components Yes                  Yes
  Cycle detection      Yes                  Yes (Kahn's)
  Topological sort     Yes (post-order)     Yes (Kahn's)

  DFS is usually SIMPLER to implement recursively.
  BFS requires explicit queue but gives shortest paths.

----------------------------------------------------------------
COMMON DFS MISTAKES
----------------------------------------------------------------

  1. Forgetting base case in recursion (null check for trees).
  2. Not marking visited BEFORE recursive call (undirected graph loops).
  3. In backtracking: not un-doing the choice after recursive call.
  4. Tree DFS: returning too early (forgetting to check both subtrees).
  5. Directed cycle detection: confusing VISITED with IN-RECURSION-STACK.
