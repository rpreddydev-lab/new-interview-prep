================================================================
  DFS ON TREES
================================================================

  Tree DFS covers: path problems, subtree properties, ancestor queries,
  tree structure validation.

  Key: Every tree problem has a recursive substructure.
  Think: "What do I need from my left child? From right? How do I combine?"

----------------------------------------------------------------
PROBLEM: PATH SUM (LC 112)
----------------------------------------------------------------

  Does the tree have a root-to-leaf path with the given sum?

  Java:
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) return false;
        if (root.left == null && root.right == null) return root.val == targetSum;
        return hasPathSum(root.left, targetSum - root.val) ||
               hasPathSum(root.right, targetSum - root.val);
    }

  Time: O(n)   Space: O(h) where h = tree height

  Pattern: subtract current node's value, ask children if they have the remaining.

----------------------------------------------------------------
PROBLEM: PATH SUM II — ALL PATHS (LC 113)
----------------------------------------------------------------

  Return all root-to-leaf paths with the given sum.

  Java:
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        dfs(root, targetSum, new ArrayList<>(), result);
        return result;
    }

    private void dfs(TreeNode node, int remaining, List<Integer> path, List<List<Integer>> result) {
        if (node == null) return;
        path.add(node.val);
        if (node.left == null && node.right == null && remaining == node.val) {
            result.add(new ArrayList<>(path));  // copy!
        }
        dfs(node.left,  remaining - node.val, path, result);
        dfs(node.right, remaining - node.val, path, result);
        path.remove(path.size() - 1);  // BACKTRACK
    }

  Critical: result.add(new ArrayList<>(path)) -- must copy, not add path reference.
  Critical: backtrack by removing last element after recursion.

PROBLEM: DIAMETER OF BINARY TREE (LC 543)
----------------------------------------------------------------

  Diameter = longest path between any two nodes.
  The path may or may not pass through root.

  At each node: diameter through it = height(left) + height(right).
  Return max over all nodes.

  Java:
    private int maxDiameter = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        maxDiameter = 0;
        height(root);
        return maxDiameter;
    }

    private int height(TreeNode node) {
        if (node == null) return 0;
        int leftH  = height(node.left);
        int rightH = height(node.right);
        maxDiameter = Math.max(maxDiameter, leftH + rightH);
        return 1 + Math.max(leftH, rightH);
    }

  Time: O(n)   Space: O(h)

  Pattern: post-order DFS. Return height, update global max at each node.

PROBLEM: MAXIMUM PATH SUM (LC 124)
----------------------------------------------------------------

  A path is any sequence of connected nodes (no repeating nodes).
  Each node appears at most once.

  At each node: contribution going UP = node.val + max(0, left gain, right gain)
  Path through this node = left gain + node.val + right gain

  Java:
    private int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        maxSum = Integer.MIN_VALUE;
        gain(root);
        return maxSum;
    }

    private int gain(TreeNode node) {
        if (node == null) return 0;
        int leftGain  = Math.max(0, gain(node.left));   // discard negative subtrees
        int rightGain = Math.max(0, gain(node.right));
        maxSum = Math.max(maxSum, leftGain + node.val + rightGain);
        return node.val + Math.max(leftGain, rightGain);  // can only go one direction
    }

  Time: O(n)   Space: O(h)

  Key: return only ONE direction (left or right) because the path
  going up can't branch. But when updating maxSum, use BOTH.

  Contrast with diameter: here values can be negative (don't always add subtrees).

PROBLEM: LOWEST COMMON ANCESTOR (LC 236)
----------------------------------------------------------------

  Find LCA of nodes p and q in a binary tree.

  Recursive logic:
    If current node is null, p, or q: return it.
    Recurse left and right.
    If both return non-null: current node is LCA.
    Otherwise: return whichever is non-null.

  Java:
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;
        TreeNode left  = lowestCommonAncestor(root.left,  p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);
        if (left != null && right != null) return root;  // p and q on different sides
        return left != null ? left : right;
    }

  Time: O(n)   Space: O(h)

  For BST (LC 235): use BST property.
    If both p,q < root: go left.
    If both p,q > root: go right.
    Otherwise: root is LCA.

PROBLEM: VALIDATE BINARY SEARCH TREE (LC 98)
----------------------------------------------------------------

  Each node must satisfy: min < node.val < max (strict bounds from ancestors).

  Java:
    public boolean isValidBST(TreeNode root) {
        return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean validate(TreeNode node, long min, long max) {
        if (node == null) return true;
        if (node.val <= min || node.val >= max) return false;
        return validate(node.left,  min, node.val) &&
               validate(node.right, node.val, max);
    }

  Use Long.MIN_VALUE / Long.MAX_VALUE to handle Integer.MIN_VALUE / MAX_VALUE edge cases.

  Common mistake: only checking immediate parent, not the full ancestor bounds.
    e.g., [5,4,6,null,null,3,7] -- node 3 in right subtree of 6 but left subtree of 5,
    violates BST because 3 < 5.

ITERATIVE INORDER TRAVERSAL (INTERVIEW FAVORITE)
----------------------------------------------------------------

  Without recursion. Uses a stack. Essential for Morris traversal / kth smallest.

  Java:
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode curr = root;

        while (curr != null || !stack.isEmpty()) {
            while (curr != null) {       // go left as far as possible
                stack.push(curr);
                curr = curr.left;
            }
            curr = stack.pop();
            result.add(curr.val);         // visit
            curr = curr.right;            // go right
        }
        return result;
    }

  Kth Smallest in BST (LC 230): stop after k-th pop.

PROBLEM: SERIALIZE/DESERIALIZE BINARY TREE (LC 297)
----------------------------------------------------------------

  Preorder DFS with null markers.

  Java:
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        serDFS(root, sb);
        return sb.toString();
    }

    private void serDFS(TreeNode node, StringBuilder sb) {
        if (node == null) { sb.append("#,"); return; }
        sb.append(node.val).append(",");
        serDFS(node.left, sb);
        serDFS(node.right, sb);
    }

    private int idx = 0;
    public TreeNode deserialize(String data) {
        idx = 0;
        String[] vals = data.split(",");
        return deserDFS(vals);
    }

    private TreeNode deserDFS(String[] vals) {
        if (vals[idx].equals("#")) { idx++; return null; }
        TreeNode node = new TreeNode(Integer.parseInt(vals[idx++]));
        node.left  = deserDFS(vals);
        node.right = deserDFS(vals);
        return node;
    }

  Time: O(n)   Space: O(n)

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: In LC 124 (max path sum), why return only one direction up?
  A: A path from ancestor to descendant can only go DOWN one direction
     at each node. We can't take both left and right children because
     that would create a fork (the path would loop back).

  Q: For LCA, what if the tree is very deep and p,q are at the bottom?
  A: The recursive approach uses O(h) stack space. For very deep trees,
     iterative approaches or parent-pointer approach can be used.

  Q: Why use Long.MIN/MAX_VALUE in BST validation?
  A: If a node has value Integer.MIN_VALUE, then min=-inf must be strictly
     less than it. Using Integer.MIN_VALUE as the bound fails.

  Q: What's the difference between path sum and max path sum?
  A: Path sum: fixed target, root-to-leaf only.
     Max path sum: any node-to-node path, values can be negative.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - "Return something from left and right, combine at current node" = DFS pattern.
  - For path problems: pass down remaining sum; collect at leaves.
  - For height/diameter: return height up; update global max at each node.
  - Always handle null nodes as base case FIRST.
  - Iterative inorder is a must-know for BST problems.
