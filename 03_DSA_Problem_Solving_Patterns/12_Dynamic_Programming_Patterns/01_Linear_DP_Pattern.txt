================================================================
  LINEAR DP PATTERN
================================================================

  Linear DP: dp[i] depends on dp[i-1], dp[i-2], or earlier entries.
  State is 1D (index into sequence).

  Core problems: Climbing Stairs, House Robber, Decode Ways,
  Coin Change, Longest Increasing Subsequence, Jump Game, Max Subarray.

----------------------------------------------------------------
CLIMBING STAIRS (LC 70)
----------------------------------------------------------------

  n steps. Can climb 1 or 2 at a time. How many distinct ways?
  dp[i] = number of ways to reach step i.
  dp[0]=1, dp[1]=1, dp[i] = dp[i-1] + dp[i-2]

  Java:
    public int climbStairs(int n) {
        if (n <= 1) return 1;
        int prev2 = 1, prev1 = 1;
        for (int i = 2; i <= n; i++) {
            int curr = prev1 + prev2;
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }

  This is Fibonacci sequence. Space optimized to O(1).

----------------------------------------------------------------
HOUSE ROBBER (LC 198)
----------------------------------------------------------------

  Row of houses. Can't rob two adjacent. Maximize total.
  dp[i] = max money robbing first i houses.
  dp[i] = max(dp[i-1],  dp[i-2] + nums[i])
            skip i       rob i

  Java:
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];
        int prev2 = nums[0];
        int prev1 = Math.max(nums[0], nums[1]);
        for (int i = 2; i < n; i++) {
            int curr = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }

  Time: O(n)   Space: O(1)

  LC 213 House Robber II (circular): run 1D robber twice.
    rob1 = rob(nums[0..n-2])   (exclude last)
    rob2 = rob(nums[1..n-1])   (exclude first)
    return max(rob1, rob2)

  LC 337 House Robber III (tree): post-order DFS.
    int[] dfs(node) returns [rob_node, skip_node]:
      left = dfs(node.left), right = dfs(node.right)
      rob   = node.val + left[1] + right[1]
      skip  = max(left) + max(right)
      return [rob, skip]

DECODE WAYS (LC 91)
----------------------------------------------------------------

  Encoded string of digits. '1'->'A', ..., '26'->'Z'.
  Count number of ways to decode.

  dp[i] = number of ways to decode s[0..i-1].
  Base: dp[0]=1 (empty string), dp[1]=1 if s[0]!='0' else 0.

  Transitions:
    Single digit: if s[i-1] != '0' → dp[i] += dp[i-1]
    Two digits:   if 10 <= s[i-2..i-1] <= 26 → dp[i] += dp[i-2]

  Java:
    public int numDecodings(String s) {
        int n = s.length();
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = s.charAt(0) == '0' ? 0 : 1;

        for (int i = 2; i <= n; i++) {
            int oneDigit = s.charAt(i - 1) - '0';
            int twoDigit = Integer.parseInt(s.substring(i - 2, i));

            if (oneDigit != 0) dp[i] += dp[i - 1];
            if (twoDigit >= 10 && twoDigit <= 26) dp[i] += dp[i - 2];
        }
        return dp[n];
    }

  Example: "226"
    dp[0]=1, dp[1]=1 ('2'!=0)
    i=2: oneDigit=2≠0 → dp[2]+=dp[1]=1. twoDigit=22 → 22∈[10,26] → dp[2]+=dp[0]=1. dp[2]=2
    i=3: oneDigit=6≠0 → dp[3]+=dp[2]=2. twoDigit=26 → dp[3]+=dp[1]=1. dp[3]=3
    return 3 ✓ ("226" → "2|2|6", "22|6", "2|26")

  LC 639 Decode Ways II (with '*'): same structure, multiply by wildcard counts.

LONGEST INCREASING SUBSEQUENCE (LC 300)
----------------------------------------------------------------

  Find length of longest strictly increasing subsequence.

  Approach 1 — O(n^2) DP:
    dp[i] = LIS ending at index i.
    dp[i] = max(dp[j] + 1) for all j < i where nums[j] < nums[i].
    Answer: max(dp[i]).

  Java O(n^2):
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        int maxLen = 1;
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            maxLen = Math.max(maxLen, dp[i]);
        }
        return maxLen;
    }

  Approach 2 — O(n log n) with patience sorting:
    Maintain `tails` array: tails[i] = smallest tail of all increasing subseqs of length i+1.
    For each num: binary search in tails for first value >= num (lower_bound).
    Replace tails[pos] = num. If pos == tails.size(), append.

  Java O(n log n):
    public int lengthOfLIS(int[] nums) {
        List<Integer> tails = new ArrayList<>();
        for (int num : nums) {
            int lo = 0, hi = tails.size();
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (tails.get(mid) < num) lo = mid + 1;
                else hi = mid;
            }
            if (lo == tails.size()) tails.add(num);
            else tails.set(lo, num);
        }
        return tails.size();
    }

  Trace for [10,9,2,5,3,7,101,18]:
    tails=[10]→[9]→[2]→[2,5]→[2,3]→[2,3,7]→[2,3,7,101]→[2,3,7,18]
    Length = 4 ✓ (LIS: [2,3,7,101] or [2,3,7,18])

  Note: tails does NOT represent actual subsequence, only its length.

JUMP GAME (LC 55, 45)
----------------------------------------------------------------

  LC 55: Can you reach last index? (Greedy)
    maxReach = 0. At each i: if i > maxReach → stuck. Update maxReach.

  LC 45: Minimum number of jumps. (Greedy / DP)
    Greedy O(n): track current range [l..r] and furthest reachable.
    When you reach r, you MUST jump → jumps++, l=r+1, r=furthest.

  Java (LC 45):
    public int jump(int[] nums) {
        int jumps = 0, curEnd = 0, farthest = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            farthest = Math.max(farthest, i + nums[i]);
            if (i == curEnd) {
                jumps++;
                curEnd = farthest;
            }
        }
        return jumps;
    }

  Example: [2,3,1,1,4]
    i=0: farthest=2. i==curEnd(0) → jumps=1, curEnd=2
    i=1: farthest=max(2,4)=4. i≠curEnd
    i=2: farthest=max(4,3)=4. i==curEnd(2) → jumps=2, curEnd=4
    return 2 ✓

MAXIMUM SUBARRAY (LC 53) — KADANE'S ALGORITHM
----------------------------------------------------------------

  dp[i] = maximum subarray sum ending at i.
  dp[i] = max(nums[i], dp[i-1] + nums[i])
  If dp[i-1] < 0, start new subarray at i.

  Java:
    public int maxSubArray(int[] nums) {
        int maxSum = nums[0], currSum = nums[0];
        for (int i = 1; i < nums.length; i++) {
            currSum = Math.max(nums[i], currSum + nums[i]);
            maxSum = Math.max(maxSum, currSum);
        }
        return maxSum;
    }

  Time: O(n)   Space: O(1)

  Example: [-2,1,-3,4,-1,2,1,-5,4]
    currSum: -2→1→-2→4→3→5→6→1→5
    maxSum:  -2→1→1→4→4→5→6→6→6   → 6 ✓

  LC 152 Maximum Product Subarray: track both max and min (negative * negative = positive).
    maxProd[i] = max(nums[i], maxProd[i-1]*nums[i], minProd[i-1]*nums[i])
    minProd[i] = min(nums[i], maxProd[i-1]*nums[i], minProd[i-1]*nums[i])

WORD BREAK (LC 139)
----------------------------------------------------------------

  dp[i] = true if s[0..i-1] can be segmented using dictionary.
  dp[0] = true (empty prefix).
  dp[i] = OR of dp[j] && dict.contains(s[j..i-1]) for all j < i.

  Java:
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> dict = new HashSet<>(wordDict);
        int n = s.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && dict.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }

  Example: s="leetcode", dict=["leet","code"]
    dp[0]=T
    i=4: j=0: dp[0]&&"leet"∈dict → dp[4]=T
    i=8: j=4: dp[4]&&"code"∈dict → dp[8]=T
    return true ✓

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: How do you handle the O(1) space optimization for House Robber?
  A: We only need dp[i-1] and dp[i-2] at each step, so two variables (prev1, prev2) suffice.

  Q: Why does the O(n log n) LIS algorithm work?
  A: The `tails` array is always sorted. Binary search finds the correct position to
     replace, maintaining the minimum possible tail for each subsequence length.
     The final length of `tails` equals LIS length, though tails itself may not be valid LIS.

  Q: What's the difference between Jump Game I and II?
  A: LC 55 asks if reachable (greedy scan, O(n)), LC 45 asks minimum jumps (BFS-level greedy, O(n)).

  Q: When does Decode Ways return 0 for dp[1]?
  A: When s[0] == '0'. A leading zero has no valid encoding.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Always define dp[i] precisely before writing code.
  - For rolling variables, draw the dependency arrow: dp[i] ← dp[i-1], dp[i-2].
  - LIS: mention both O(n^2) and O(n log n) — the latter shows depth.
  - Kadane's is a classic O(n) greedy-DP hybrid — know it cold.
