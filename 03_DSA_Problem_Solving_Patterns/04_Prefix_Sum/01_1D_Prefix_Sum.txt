PROBLEM 1: RANGE SUM QUERY - IMMUTABLE (LC 303)
----------------------------------------------------------------

  Given a static integer array, handle multiple queries
  of the form sumRange(l, r) efficiently.

  Example:
    nums = [-2, 0, 3, -5, 2, -1]
    sumRange(0, 2) = -2 + 0 + 3 = 1
    sumRange(2, 5) = 3 + -5 + 2 + -1 = -1
    sumRange(0, 5) = -3

  Java (class-based):
    class NumArray {
        private int[] prefix;

        public NumArray(int[] nums) {
            prefix = new int[nums.length + 1];
            for (int i = 1; i <= nums.length; i++) {
                prefix[i] = prefix[i - 1] + nums[i - 1];
            }
        }

        public int sumRange(int l, int r) {
            return prefix[r + 1] - prefix[l];
        }
    }

  Time: O(n) constructor, O(1) query
  Space: O(n)

  Key: the prefix array is built ONCE. All queries are O(1).
  Without preprocessing: each query is O(n). For q queries: O(qn) vs O(n+q).

PROBLEM 2: RUNNING SUM OF 1D ARRAY (LC 1480)
----------------------------------------------------------------

  Return an array where running[i] = sum of nums[0..i].
  Essentially, build a prefix sum (0-indexed version).

  Input:  [1, 2, 3, 4]
  Output: [1, 3, 6, 10]

  Java:
    public int[] runningSum(int[] nums) {
        for (int i = 1; i < nums.length; i++) {
            nums[i] += nums[i - 1];
        }
        return nums;
    }

  Time: O(n)  Space: O(1) in-place

PROBLEM 3: SUBARRAY SUM EQUALS K (LC 560)
----------------------------------------------------------------

  Find the count of contiguous subarrays with sum = k.

  Input:  nums = [1, 1, 1], k = 2
  Output: 2  (subarrays [0,1] and [1,2])

  Approach: prefix sum + HashMap.

  Java:
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0, 1);  // base: empty prefix
        int sum = 0, count = 0;

        for (int num : nums) {
            sum += num;
            count += prefixCount.getOrDefault(sum - k, 0);
            prefixCount.merge(sum, 1, Integer::sum);
        }
        return count;
    }

  Time: O(n)  Space: O(n)

  Trace: nums=[1,1,1], k=2
    sum=0, map={0:1}
    sum=1, lookup(1-2=-1)=0, map={0:1,1:1}
    sum=2, lookup(2-2=0)=1, count=1, map={0:1,1:1,2:1}
    sum=3, lookup(3-2=1)=1, count=2, map={0:1,1:1,2:1,3:1}
    Answer: 2 ✓

PROBLEM 4: CONTIGUOUS ARRAY (LC 525)
----------------------------------------------------------------

  Find the maximum length subarray with equal number of 0s and 1s.
  Transform: replace 0s with -1. Problem becomes: longest subarray
  with sum = 0.

  Longest subarray with sum 0 --> find two indices with same prefix sum.
  Store: first occurrence of each prefix sum.

  Java:
    public int findMaxLength(int[] nums) {
        Map<Integer, Integer> firstSeen = new HashMap<>();
        firstSeen.put(0, -1);  // sum=0 seen before index 0
        int sum = 0, maxLen = 0;

        for (int i = 0; i < nums.length; i++) {
            sum += (nums[i] == 0) ? -1 : 1;
            if (firstSeen.containsKey(sum)) {
                maxLen = Math.max(maxLen, i - firstSeen.get(sum));
            } else {
                firstSeen.put(sum, i);  // store FIRST occurrence only
            }
        }
        return maxLen;
    }

  Time: O(n)  Space: O(n)

  Why firstSeen.put(0, -1)?
    Handles subarrays starting from index 0.
    If sum at index i is 0, length = i - (-1) = i + 1. ✓

  Example: [0,1,0,1]  (transformed: [-1,1,-1,1])
    i=0: sum=-1, store(-1,0)
    i=1: sum=0, firstSeen(0)=-1, len=1-(-1)=2, maxLen=2
    i=2: sum=-1, firstSeen(-1)=0, len=2-0=2, maxLen=2
    i=3: sum=0, firstSeen(0)=-1, len=3-(-1)=4, maxLen=4
    Answer: 4 ✓

PROBLEM 5: SUBARRAY SUMS DIVISIBLE BY K (LC 974)
----------------------------------------------------------------

  Count subarrays with sum divisible by k.

  Key: sum(l,r) divisible by k iff prefix[r] % k == prefix[l-1] % k.
  Store: count of each prefix % k.

  Java:
    public int subarraysDivByK(int[] nums, int k) {
        Map<Integer, Integer> remainderCount = new HashMap<>();
        remainderCount.put(0, 1);
        int sum = 0, count = 0;

        for (int num : nums) {
            sum += num;
            int rem = ((sum % k) + k) % k;  // handle negative remainders
            count += remainderCount.getOrDefault(rem, 0);
            remainderCount.merge(rem, 1, Integer::sum);
        }
        return count;
    }

  Time: O(n)  Space: O(k)

  Why ((sum % k) + k) % k?
    In Java, % can return negative results for negative dividends.
    E.g., -7 % 3 = -1 in Java, but we want the positive remainder 2.
    ((sum % k) + k) % k normalizes to [0, k-1].

PROBLEM 6: PRODUCT OF ARRAY EXCEPT SELF (LC 238)
----------------------------------------------------------------

  For each index i, output[i] = product of all elements except nums[i].
  NO division allowed.

  Approach: prefix product * suffix product.

  Java:
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] output = new int[n];
        output[0] = 1;

        // Left pass: output[i] = product of nums[0..i-1]
        for (int i = 1; i < n; i++) {
            output[i] = output[i - 1] * nums[i - 1];
        }

        // Right pass: multiply by product of nums[i+1..n-1]
        int rightProduct = 1;
        for (int i = n - 1; i >= 0; i--) {
            output[i] *= rightProduct;
            rightProduct *= nums[i];
        }
        return output;
    }

  Time: O(n)  Space: O(1) extra (output array doesn't count)

----------------------------------------------------------------
KEY PATTERNS SUMMARY
----------------------------------------------------------------

  Pattern                     HashMap Key        HashMap Value
  -------                     -----------        -------------
  Subarray sum = k            prefix sum         count of occurrences
  Equal 0s and 1s (max len)   prefix sum         first occurrence index
  Divisible by k              prefix sum mod k   count of occurrences
  Max length sum = 0          prefix sum         first occurrence index

  Rule of thumb:
    - COUNT (how many subarrays) --> store count, add to answer
    - LENGTH (longest subarray) --> store first index, compute length

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. HashMap: put(0, 1) for counting problems.
     HashMap: put(0, -1) for length/index problems.
     These are DIFFERENT. Get them right.

  2. Negative remainder in Java: always use ((sum%k)+k)%k.

  3. For LENGTH problems: put into map only if NOT present
     (firstSeen.putIfAbsent). We want the EARLIEST occurrence
     to maximize the subarray length.

  4. For COUNT problems: always put into map (every occurrence counts).

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why does equal 0s and 1s reduce to prefix sum = 0?
  A: Transform 0 -> -1. Then sum of a subarray with equal 0s and
     1s = 0 (positives and negatives cancel). We find the longest
     subarray with sum 0.

  Q: Why store first occurrence for length problems?
  A: If prefix[i] == prefix[j] (i < j), the subarray [i+1..j] has
     sum 0. To maximize j - i, we want the SMALLEST possible i, so
     store first seen.

  Q: For divisible by k, why do we count pairs of remainders?
  A: sum(l..r) % k == 0 iff (prefix[r] - prefix[l-1]) % k == 0 iff
     prefix[r] % k == prefix[l-1] % k. So count pairs with equal
     remainder in the prefix array.
