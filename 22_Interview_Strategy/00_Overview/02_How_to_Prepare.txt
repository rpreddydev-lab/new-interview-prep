1. THE PREPARATION MINDSET
--------------------------------------------------------------------------------

Before diving into schedules and resources, internalize these truths:

  TRUTH 1: Interview prep is a skill, separate from your job skills.
    - Being a great engineer does NOT automatically make you great at interviews.
    - Companies test a narrow slice of your abilities.
    - You must practice for the TEST, not just the job.

  TRUTH 2: Consistency beats cramming.
    - 1 hour/day for 60 days >> 8 hours/day for 8 days
    - Spaced repetition cements patterns in memory
    - Fatigue destroys recall; rest is preparation

  TRUTH 3: Active practice beats passive learning.
    - Reading a solution is NOT the same as writing one
    - If you can't explain it without looking, you don't know it
    - Teach concepts out loud to yourself (the Feynman technique)

  TRUTH 4: Understand, don't memorize.
    - Interviewers modify problems; pattern-matching breaks, understanding doesn't
    - Focus on WHY a solution works, not just what it is

  TRUTH 5: Quality over quantity.
    - 50 problems deeply understood >> 200 problems barely glanced at
    - Master the 14 core patterns; most problems are variants

3. THE 14 CORE ALGORITHM PATTERNS
--------------------------------------------------------------------------------

Most LeetCode-style problems are instances of one of these patterns.
Master the pattern, and you can handle any problem variation.

PATTERN 1: TWO POINTERS
  - Use when: Sorted array, finding pairs/triplets, in-place manipulation
  - Template: left=0, right=n-1; move based on comparison
  - Problems: Two Sum II, 3Sum, Container With Most Water, Palindrome

PATTERN 2: SLIDING WINDOW
  - Use when: Substring/subarray of size k or with constraint
  - Template: Expand right pointer; shrink left when constraint violated
  - Problems: Longest Substring Without Repeat, Max Sum Subarray of Size K

PATTERN 3: FAST & SLOW POINTERS (Floyd's Algorithm)
  - Use when: Linked list cycles, finding middle, detecting duplicates
  - Template: slow moves 1 step, fast moves 2 steps
  - Problems: Linked List Cycle, Find Middle, Happy Number

PATTERN 4: MERGE INTERVALS
  - Use when: Overlapping intervals, scheduling problems
  - Template: Sort by start, iterate and merge or check overlap
  - Problems: Merge Intervals, Insert Interval, Meeting Rooms

PATTERN 5: CYCLIC SORT
  - Use when: Array contains values 1-N, find missing/duplicate
  - Template: Place each number at its correct index (num-1)
  - Problems: Find Missing Number, Find All Duplicates

PATTERN 6: IN-PLACE REVERSAL (LINKED LIST)
  - Use when: Reverse a linked list or a sublist
  - Template: prev=null, curr=head; reverse next pointers
  - Problems: Reverse Linked List, Reverse Sub-list

PATTERN 7: TREE BFS (LEVEL ORDER)
  - Use when: Level-by-level traversal, minimum depth, zigzag
  - Template: Queue; process all nodes at each level
  - Problems: Level Order Traversal, Connect Level Order Siblings

PATTERN 8: TREE DFS
  - Use when: Path problems, tree validation, diameter
  - Template: Recursive pre/in/post order with state accumulation
  - Problems: Path Sum, Max Path Sum, Diameter of Tree

PATTERN 9: TWO HEAPS
  - Use when: Tracking median, balancing a stream
  - Template: Max-heap for lower half, min-heap for upper half
  - Problems: Find Median from Data Stream, Sliding Window Median

PATTERN 10: SUBSETS / COMBINATIONS / PERMUTATIONS
  - Use when: Generate all possibilities (backtracking)
  - Template: Recursive with start index; add/remove element
  - Problems: Subsets, Permutations, Combination Sum, Letter Combos

PATTERN 11: BINARY SEARCH
  - Use when: Sorted array, or can binary search on the ANSWER
  - Template: lo, hi, mid; decide which half to eliminate
  - Problems: Search in Rotated Array, Koko Eating Bananas, Median of 2 Arrays

PATTERN 12: TOP K ELEMENTS
  - Use when: Need K largest/smallest/most frequent
  - Template: Min-heap of size K; or quickselect (O(n) avg)
  - Problems: K Closest Points, Top K Frequent Elements, Kth Largest

PATTERN 13: K-WAY MERGE
  - Use when: Merge K sorted lists/arrays
  - Template: Min-heap initialized with first elements; pop and push next
  - Problems: Merge K Sorted Lists, Kth Smallest in Sorted Matrix

PATTERN 14: DYNAMIC PROGRAMMING
  Sub-patterns:
  a) 0/1 Knapsack: Include/exclude item at each step
  b) Unbounded Knapsack: Coin change, rod cutting
  c) Fibonacci variant: Each state depends on previous 1-2 states
  d) Palindrome: Expand around center or DP table
  e) Longest Common Subsequence: 2D DP table
  f) Matrix Chain / Interval DP: Range [i,j] with split point k

4. RECOMMENDED PROBLEM SETS (PRIORITIZED)
--------------------------------------------------------------------------------

TIER 1 - MUST SOLVE (These appear in real interviews regularly):
  - Blind 75 (NeetCode list): https://neetcode.io/practice
  - Grind 75: https://www.techinterviewhandbook.org/grind75
  Total: ~75 problems; target completion in 4-6 weeks

TIER 2 - SHOULD SOLVE (Increases depth and pattern recognition):
  - NeetCode 150 (adds to Blind 75)
  - LeetCode Top Interview 150
  Total: additional ~75 problems; 3-4 more weeks

TIER 3 - COMPANY SPECIFIC (2-3 weeks before interview):
  - LeetCode company tags (filter by company)
  - Glassdoor / levels.fyi interview reports for your target company
  - Recent OA/phone screen problems shared on Reddit (r/cscareerquestions)

DIFFICULTY DISTRIBUTION TARGET:
  - Easy: 20% (master these, never fail them)
  - Medium: 60% (this is the main battleground)
  - Hard: 20% (aim for intuition, not perfect solutions)

TRACKING PROGRESS:
  - Use a spreadsheet: Problem | Date | Pattern | Time | Notes | Revisit?
  - Mark problems for revisit if: took >45 min, looked at hint, or got wrong
  - Re-solve all revisit problems after 1 week

5. STUDY SCHEDULE TEMPLATES
--------------------------------------------------------------------------------

TEMPLATE A: 8-WEEK FULL PREPARATION PLAN

  WEEK 1-2: FOUNDATIONS
  ----------------------
  Daily focus: 2-3 LeetCode problems (Easy/Medium)
  Topics: Arrays, Strings, Hash Maps, Two Pointers, Sliding Window
  System Design: Read "System Design Primer" intro
  Behavioral: Write your "Tell me about yourself" (2-min version)
  LeetCode goals: Complete 15-20 Easy + 10 Medium

  WEEK 3-4: TREES, GRAPHS, RECURSION
  ------------------------------------
  Daily focus: 2-3 problems (Medium focus)
  Topics: Trees (DFS/BFS), Graphs (DFS/BFS/Topological), Backtracking
  System Design: Study 3 fundamentals: Load Balancing, Caching, Databases
  Behavioral: Prepare 5 core STAR stories; practice out loud
  LeetCode goals: 20 Medium from tree/graph/backtracking categories

  WEEK 5: DYNAMIC PROGRAMMING
  ----------------------------
  Daily focus: 1-2 DP problems (takes longer)
  Approach: Pattern by pattern (Fibonacci → 0/1 Knapsack → LCS → etc.)
  System Design: Deep dive 2 design problems (URL shortener, Twitter feed)
  LeetCode goals: 10-15 DP problems across all sub-patterns

  WEEK 6: ADVANCED TOPICS + SYSTEM DESIGN INTENSIVE
  --------------------------------------------------
  Daily focus: 1 hard problem + 1 system design problem
  Topics: Heaps, Binary Search on Answer, Union-Find, Trie, Segment Tree
  System Design: Practice 2 more problems (Uber, WhatsApp, YouTube)
  Behavioral: Complete all 8-10 STAR stories; record yourself

  WEEK 7: MOCK INTERVIEWS
  -----------------------
  Daily: 1 full mock interview (coding) - Pramp, Interviewing.io, or peer
  System Design: 2 full SD mock interviews
  Behavioral: 1 full behavioral mock
  Review: Go through all "revisit" problems

  WEEK 8: COMPANY-SPECIFIC + POLISH
  ----------------------------------
  Daily: Company-specific LeetCode problems
  Research: Company engineering blog, recent news, team culture
  Offer/Negotiation: Read through 04_Offer_and_Negotiation/ folder
  Mental: Focus on confidence, sleep, exercise

TEMPLATE B: 4-WEEK ACCELERATED PLAN

  Week 1: Blind 75 - Half (patterns 1-7)
  Week 2: Blind 75 - Second half (patterns 8-14) + 3 SD problems
  Week 3: NeetCode 150 additions + 5 SD problems + behavioral stories
  Week 4: Mocks, company research, negotiation prep

TEMPLATE C: 2-WEEK EMERGENCY PREP

  Days 1-3: Blind 75 Easy/Medium arrays+strings+hashmap (do 5/day)
  Days 4-6: Trees and graphs essentials (10 problems)
  Day 7: Rest + review weak areas
  Days 8-10: Dynamic programming basics (5 problems)
  Days 11-12: System Design fundamentals (3 problems)
  Days 13-14: 2 mock interviews, behavioral stories, company research

6. DAILY PRACTICE ROUTINE
--------------------------------------------------------------------------------

MORNING BLOCK (1-2 hours, before work or early):
  - Solve 1-2 LeetCode problems
  - Time yourself (45 min per medium problem)
  - After solving: compare with optimal solution; understand the delta

EVENING BLOCK (30-60 min):
  - Review flash cards (algorithm complexities, patterns)
  - Read one system design topic
  - Practice speaking one STAR story out loud

WEEKLY REVIEW (Sunday, 1 hour):
  - Re-solve all "revisit" problems from the week
  - Update progress spreadsheet
  - Adjust next week's focus based on weak areas

DAILY HABITS:
  - Time every problem you solve (builds interview pacing instinct)
  - Write complexity EVERY TIME you finish a solution
  - After each problem, ask: "Which pattern does this fit? How would I
    recognize it next time?"

9. WHAT TO DO THE DAY BEFORE AN INTERVIEW
--------------------------------------------------------------------------------

  DO:
  ✓ Light review of 2-3 easy/medium problems (confidence building only)
  ✓ Re-read your STAR stories silently
  ✓ Research the company one more time (latest news, team, products)
  ✓ Prepare your question list for the interviewer
  ✓ Test your tech setup (video, audio, shared editor access)
  ✓ Get 8 hours of sleep - this is NOT optional
  ✓ Lay out your clothes / plan your commute if in-person
  ✓ Have water, coffee/tea ready for the interview

  DON'T:
  ✗ Attempt Hard LeetCode problems (creates anxiety)
  ✗ Cram new algorithms
  ✗ Stay up past midnight
  ✗ Drink excessive caffeine
  ✗ Obsessively check Glassdoor reviews
  ✗ Read negative experiences on Reddit

--------------------------------------------------------------------------------
10. WHAT TO DO THE DAY OF AN INTERVIEW
--------------------------------------------------------------------------------

  2 HOURS BEFORE:
  - Solve 1 easy problem (warm up your brain, don't stress)
  - Eat a real meal
  - Do 5 min of light exercise or a walk (reduces cortisol)

  30 MINUTES BEFORE:
  - Review your "Tell me about yourself" once
  - Set up your workspace (quiet, good lighting, second monitor if virtual)
  - Close all distractions (Slack, email, other browser tabs)
  - Have pen and paper ready for diagrams/scratch work

  5 MINUTES BEFORE:
  - Do 3 deep breaths (physiological sigh: inhale, short second inhale, long exhale)
  - Remind yourself: "This is a conversation, not an exam"
  - Log in early to the interview link
