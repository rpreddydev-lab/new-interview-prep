AWS OVERVIEW — PRICING MODEL AND FREE TIER
Complete Interview Preparation Guide
================================================================

1. AWS PRICING FUNDAMENTALS
================================================================

Three fundamental pricing drivers:
  1. Compute        — EC2 instance hours, Lambda invocations/GB-seconds
  2. Storage        — S3 GB stored, EBS GB provisioned
  3. Data Transfer  — Data OUT from AWS (data IN is free)

Core Pricing Principles:
  - Pay-as-you-go    — no long-term contracts (On-Demand)
  - Pay less when you reserve — commit 1 or 3 years → up to 75% off
  - Pay less with more usage  — S3 tiered pricing: more storage = lower per-GB price
  - Free inbound data transfer (almost always)
  - Free data transfer within the same region between services
  - Data transfer OUT to internet = charged

================================================================
2. EC2 PRICING MODELS
================================================================

On-Demand:
  - Pay per hour or per second (Linux) / per hour (Windows)
  - No commitment; highest price
  - Use for: unpredictable workloads, short-term use, testing

Reserved Instances (RI):
  - 1-year or 3-year commitment
  - Up to 72% discount vs On-Demand
  - Standard RI: locked to instance type/AZ (best discount)
  - Convertible RI: can change instance type/OS (up to 54% off)
  - Scheduled RI: reserved for specific time windows
  - Use for: steady-state, predictable workloads (prod databases, app servers)

Savings Plans:
  - Flexible commitment ($/hour for 1 or 3 years)
  - Compute Savings Plan: up to 66% off, applies across EC2, Lambda, Fargate
  - EC2 Instance Savings Plan: up to 72% off, locked to instance family
  - More flexible than RIs — recommended over RIs

Spot Instances:
  - Use AWS spare capacity at up to 90% discount
  - AWS can reclaim with 2-minute warning
  - Use for: fault-tolerant batch jobs, big data, CI/CD, ML training
  - NOT suitable for: databases, stateful workloads, anything that can't be interrupted

Dedicated Hosts:
  - Physical server dedicated to you
  - Bring Your Own License (BYOL) support
  - Compliance requirements (no shared hardware)
  - Most expensive

Dedicated Instances:
  - Instance runs on dedicated hardware (but not entire server)
  - Hardware not shared with other AWS accounts
  - Less control than Dedicated Host

Cost Comparison (relative):
  On-Demand: 1.0x (baseline)
  Reserved:  0.28-0.4x (3-year)
  Spot:      0.1-0.3x
  Savings Plans: similar to Reserved

================================================================
3. S3 PRICING
================================================================

  Pricing components:
    - Storage: per GB per month (varies by storage class)
    - Requests: GET, PUT, COPY, POST, LIST (per 1000 requests)
    - Data transfer OUT to internet
    - Data retrieval fees (Glacier)
  
  S3 Standard pricing tiers:
    First 50 TB/month    → lowest per-GB price
    Next 450 TB/month    → lower
    Over 500 TB/month    → lowest
    
  Data transfer:
    - Into S3 from internet: FREE
    - S3 to EC2 in same region: FREE
    - S3 to internet: ~$0.09/GB (first 10TB/month, decreases)
    - S3 to CloudFront: FREE

================================================================
4. OTHER KEY PRICING CONCEPTS
================================================================

Lambda Pricing:
  - $0.20 per 1M requests (first 1M free/month)
  - Duration: $0.0000166667 per GB-second
  - Free tier: 1M requests + 400,000 GB-seconds per month (always free)

RDS Pricing:
  - Instance hours (db.t3.micro → db.r6g.large etc.)
  - Storage: per GB provisioned
  - Multi-AZ: ~2x instance cost (runs standby replica)
  - I/O requests (for magnetic storage)
  - Data transfer out

Data Transfer Pricing:
  ✅ FREE: Data IN from internet
  ✅ FREE: Data between EC2 and S3 in same region
  ✅ FREE: Data between AZs for same EC2 instance (private IP)
  ❌ CHARGED: Data between AZs between different EC2 instances
  ❌ CHARGED: Data OUT to internet
  ❌ CHARGED: Data transfer between regions

================================================================
5. AWS FREE TIER
================================================================

Three types:
  1. Always Free — doesn't expire
     - Lambda: 1M requests + 400K GB-seconds/month
     - DynamoDB: 25 GB storage + 25 WCU + 25 RCU
     - CloudWatch: 10 custom metrics, 1M API requests
     - SNS: 1M mobile push notifications

  2. 12 Months Free — starts from AWS account creation date
     - EC2: 750 hours/month of t2.micro or t3.micro (Linux/Windows)
     - S3: 5 GB standard storage, 20K GET, 2K PUT requests
     - RDS: 750 hours of db.t2.micro, 20 GB storage
     - CloudFront: 1 TB data transfer out + 10M HTTP(S) requests

  3. Trials — short-term free for specific services
     - SageMaker: 250 hours of ml.t2.medium for 2 months
     - Inspector: 90-day free trial

Free Tier Traps to Avoid:
  - EC2 t2.micro is free, but EBS volume charges still apply
  - Data transfer OUT beyond free tier = charge
  - Multiple regions don't each get their own free tier quota
  - Elastic IP address charges when NOT attached to running instance

6. COST MANAGEMENT TOOLS
================================================================

AWS Cost Explorer:
  - Visualize costs and usage over time
  - Forecast future costs
  - Identify cost drivers

AWS Budgets:
  - Set cost, usage, or RI/Savings Plans budgets
  - Get alerts when approaching/exceeding thresholds
  - Can trigger automated actions (stop EC2, apply SCP)

AWS Cost Allocation Tags:
  - Tag resources with keys like Environment, Team, Project
  - Tags appear in billing reports
  - Must activate user-defined tags for billing

AWS Pricing Calculator:
  - Estimate costs before deploying: calculator.aws

Trusted Advisor:
  - Cost optimization recommendations
  - Identifies idle EC2 instances, underutilized RIs, etc.

7. INTERVIEW QUESTIONS
================================================================

Q: What is the difference between On-Demand, Reserved Instances, and Spot Instances?
A: On-Demand: pay per hour/second, no commitment, highest price. Use for
   unpredictable workloads. Reserved: 1 or 3-year commitment for up to 72%
   discount. Use for steady-state production workloads. Spot: AWS spare
   capacity at up to 90% off, but AWS can reclaim with 2-min notice. Use for
   fault-tolerant batch jobs, big data processing, CI builds.

Q: When would you use Spot Instances and when wouldn't you?
A: USE Spot for: batch processing, big data jobs, CI/CD pipelines, ML training,
   rendering — workloads that are fault-tolerant and can be interrupted.
   AVOID Spot for: production web servers, databases, stateful applications,
   anything that needs to run continuously without interruption.

Q: What is AWS Savings Plans and how is it different from Reserved Instances?
A: Savings Plans are a flexible commitment pricing model. Instead of committing
   to a specific instance type (like Standard RIs), you commit to a dollar
   amount of compute usage ($/hour). Compute Savings Plans apply across EC2,
   Lambda, and Fargate automatically. More flexible than RIs (can change
   instance types, sizes, regions) while providing similar discounts.

Q: Data transfer between two EC2 instances in different AZs — is it free?
A: If they communicate via public IPs → charged both ways. If using private
   IPs within the same region → $0.01/GB per direction (both ways). It's not
   free between AZs even with private IPs. Only data transfer between an EC2
   instance and S3 in the same region, or to the internet (in, not out), is free.

Q: What tools help you manage and forecast AWS costs?
A: AWS Cost Explorer (visualize + forecast), AWS Budgets (alerts when threshold
   approached), AWS Cost Allocation Tags (track by team/project), Trusted
   Advisor (optimization recommendations), and Compute Optimizer (right-sizing
   EC2 recommendations). Use all together for comprehensive FinOps practice.
