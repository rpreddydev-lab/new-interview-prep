  1. WHAT IS MOCKMVC?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MockMvc is a Spring Test utility that tests Spring MVC controllers
WITHOUT starting a real HTTP server. It simulates the full DispatcherServlet
pipeline: routing, filter chain, controller invocation, JSON serialization.

Benefits:
  - Faster than starting a real server
  - Full Spring MVC pipeline tested (filters, interceptors, exception handlers)
  - Fluent, readable assertion API

Two setups:
  1. @WebMvcTest (slice) → only loads MVC layer, fast, controller unit test
  2. @SpringBootTest(webEnvironment=MOCK) + @AutoConfigureMockMvc → full context

@Test
void shouldReturnOrderById() throws Exception {
    // Given
    Order order = new Order(1L, OrderStatus.PENDING, new BigDecimal("49.99"));
    given(orderService.findById(1L)).willReturn(order);

    // When & Then
    mockMvc.perform(get("/api/orders/1")
            .accept(MediaType.APPLICATION_JSON))
        .andExpect(status().isOk())
        .andExpect(content().contentType(MediaType.APPLICATION_JSON))
        .andExpect(jsonPath("$.id").value(1))
        .andExpect(jsonPath("$.status").value("PENDING"))
        .andExpect(jsonPath("$.total").value(49.99));
}

@Test
void shouldCreateOrder() throws Exception {
    // Given
    CreateOrderRequest request = new CreateOrderRequest(1L, 2, new BigDecimal("49.99"));
    Order createdOrder = new Order(10L, OrderStatus.PENDING, new BigDecimal("49.99"));
    given(orderService.placeOrder(any(CreateOrderRequest.class))).willReturn(createdOrder);

    // When & Then
    mockMvc.perform(post("/api/orders")
            .contentType(MediaType.APPLICATION_JSON)
            .content(objectMapper.writeValueAsString(request)))
        .andExpect(status().isCreated())
        .andExpect(jsonPath("$.id").value(10))
        .andExpect(header().string("Location", containsString("/api/orders/10")));
}

@Test
void shouldReturn404WhenOrderNotFound() throws Exception {
    given(orderService.findById(9999L))
        .willThrow(new OrderNotFoundException("Order not found"));

    mockMvc.perform(get("/api/orders/9999"))
        .andExpect(status().isNotFound())
        .andExpect(jsonPath("$.title").value("Not Found"));
}

@Test
void shouldDeleteOrder() throws Exception {
    doNothing().when(orderService).deleteOrder(1L);

    mockMvc.perform(delete("/api/orders/1"))
        .andExpect(status().isNoContent());
}

// Status matchers
.andExpect(status().isOk())              // 200
.andExpect(status().isCreated())         // 201
.andExpect(status().isNoContent())       // 204
.andExpect(status().isBadRequest())      // 400
.andExpect(status().isUnauthorized())    // 401
.andExpect(status().isForbidden())       // 403
.andExpect(status().isNotFound())        // 404
.andExpect(status().is5xxServerError())  // 5xx

// Content matchers
.andExpect(content().contentType(MediaType.APPLICATION_JSON))
.andExpect(content().string("OK"))
.andExpect(content().json("{\"id\":1}"))  // lenient JSON match

// Header matchers
.andExpect(header().string("Content-Type", startsWith("application/json")))
.andExpect(header().exists("Location"))
.andExpect(header().doesNotExist("X-Secret"))

// JSONPath matchers (json-path library)
.andExpect(jsonPath("$.id").value(1))
.andExpect(jsonPath("$.name").value("Alice"))
.andExpect(jsonPath("$.orders").isArray())
.andExpect(jsonPath("$.orders").isEmpty())
.andExpect(jsonPath("$.orders", hasSize(3)))
.andExpect(jsonPath("$.orders[0].status").value("PENDING"))
.andExpect(jsonPath("$.total").value(closeTo(49.99, 0.001)))

// Cookie matchers
.andExpect(cookie().value("session", "abc"))
.andExpect(cookie().exists("refresh_token"))

// View matchers (Thymeleaf / JSP)
.andExpect(view().name("orders/detail"))
.andExpect(model().attribute("order", hasProperty("id", equalTo(1L))))

    .andDo(result -> {

        log.info("Response: {}", body);
    })
    .andExpect(status().isOk());

// andReturn() — inspect result for complex assertions
MvcResult result = mockMvc.perform(get("/api/orders/1"))
    .andExpect(status().isOk())
    .andReturn();

OrderResponse order = objectMapper.readValue(body, OrderResponse.class);
assertThat(order.getId()).isEqualTo(1L);

Q: What is the difference between @WebMvcTest and @SpringBootTest with MockMvc?
A: @WebMvcTest only loads the MVC layer (controllers, filters, exception handlers)
   — no service or JPA beans. It's faster and focused on the web layer.
   @SpringBootTest with @AutoConfigureMockMvc loads the FULL context but
   uses MockMvc for testing. Use @WebMvcTest for controller unit tests,
   and @SpringBootTest + MockMvc when you need real service/repository beans.

Q: How do you test a secured endpoint with MockMvc?
A: Use @WithMockUser(roles={"ROLE"}) for simple role-based tests — it
   creates a fake authenticated user in the SecurityContext. For JWT-based
   tests, generate a test JWT token and pass it as an Authorization header.
   For loading real user details, use @WithUserDetails.

Q: What is JSONPath and how is it used in MockMvc?
A: JSONPath is a query language for JSON (like XPath for XML). In MockMvc,
   .andExpect(jsonPath("$.fieldName").value(x)) extracts a value from the
   JSON response and asserts on it. $.orders[0].status accesses the first
   element's status. $.orders.size() checks array size (or use hasSize()).

Q: How do you test file uploads with MockMvc?
A: Create a MockMultipartFile with the field name, filename, content type,
   and byte content. Use mockMvc.perform(multipart("/path").file(file)).
   You can add multiple files and form fields to the multipart request.

Q: What does andReturn() do?
A: andReturn() returns the MvcResult after the request. Use it when you
   need to perform complex assertions that go beyond the fluent matcher API
   — for example, deserializing the JSON body into an object, or inspecting
   multiple properties of the response together.
