================================================================
WHAT IS A STARTER?
================================================================

  A Spring Boot Starter is a curated set of Maven/Gradle
  dependencies that work well together.

  Problem they solve: Instead of manually picking 10 compatible
  JARs for JPA + Hibernate + Spring Data, just add ONE artifact:
    spring-boot-starter-data-jpa

  Convention: spring-boot-starter-{technology}
  Third-party: {technology}-spring-boot-starter

================================================================
STARTER POM STRUCTURE
================================================================

  A starter is a Maven module with:
    • pom.xml listing dependencies (no source code usually)
    • Parent: spring-boot-starter-parent (or spring-boot-dependencies BOM)

  Example — what spring-boot-starter-web pulls in:
    spring-boot-starter (core)
      ├── spring-boot (core Boot classes)
      ├── spring-boot-autoconfigure
      ├── spring-boot-starter-logging (Logback + SLF4J)
      └── spring-core, spring-context
    spring-boot-starter-json
      └── jackson-databind, jackson-datatype-jdk8, etc.
    spring-boot-starter-tomcat
      └── tomcat-embed-core, tomcat-embed-el, tomcat-embed-websocket
    spring-web
    spring-webmvc

================================================================
USING THE PARENT POM FOR DEPENDENCY MANAGEMENT
================================================================

  <!-- Option 1: Spring Boot parent POM (simplest) -->
  <parent>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-parent</artifactId>
      <version>3.2.5</version>
  </parent>

  <dependencies>
      <!-- Version omitted — managed by parent -->
      <dependency>
          <groupId>org.springframework.boot</groupId>
          <artifactId>spring-boot-starter-web</artifactId>
      </dependency>
  </dependencies>

  <!-- Option 2: BOM import (if you have your own parent) -->
  <dependencyManagement>
      <dependencies>
          <dependency>
              <groupId>org.springframework.boot</groupId>
              <artifactId>spring-boot-dependencies</artifactId>
              <version>3.2.5</version>
              <type>pom</type>
              <scope>import</scope>
          </dependency>
      </dependencies>
  </dependencyManagement>

================================================================
SWAPPING EMBEDDED SERVERS
================================================================

  <!-- Exclude default Tomcat, use Jetty instead -->
  <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-web</artifactId>
      <exclusions>
          <exclusion>
              <groupId>org.springframework.boot</groupId>
              <artifactId>spring-boot-starter-tomcat</artifactId>
          </exclusion>
      </exclusions>
  </dependency>

  <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-jetty</artifactId>
  </dependency>

  Comparison:
    Tomcat   -- Battle-tested, default. Best for most use cases.
    Jetty    -- Lighter, good for microservices, WebSocket-heavy apps.
    Undertow -- Highest throughput, best for reactive/non-blocking.

================================================================
EXCLUDING TRANSITIVE DEPENDENCIES — COMMON SCENARIOS
================================================================

  // Replace Logback with Log4j2
  <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter</artifactId>
      <exclusions>
          <exclusion>
              <groupId>org.springframework.boot</groupId>
              <artifactId>spring-boot-starter-logging</artifactId>
          </exclusion>
      </exclusions>
  </dependency>
  <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-log4j2</artifactId>
  </dependency>

  // Exclude Hibernate Validator version conflicts
  <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-web</artifactId>
      <exclusions>
          <exclusion>
              <groupId>org.hibernate.validator</groupId>
              <artifactId>hibernate-validator</artifactId>
          </exclusion>
      </exclusions>
  </dependency>

SPRING BOOT PLUGIN
================================================================

  <!-- Maven Plugin — packages executable JAR with embedded server -->
  <build>
      <plugins>
          <plugin>
              <groupId>org.springframework.boot</groupId>
              <artifactId>spring-boot-maven-plugin</artifactId>
              <configuration>
                  <!-- Exclude dev-only deps from production JAR -->
                  <excludeDevtools>true</excludeDevtools>
              </configuration>
          </plugin>
      </plugins>
  </build>

  Commands:
    mvn spring-boot:run       -- start app (development)
    mvn package               -- build executable JAR
    mvn spring-boot:build-image -- build OCI Docker image (Buildpacks)

================================================================
SPRING BOOT DEVTOOLS
================================================================

  <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-devtools</artifactId>
      <scope>runtime</scope>
      <optional>true</optional>  <!-- not included in production JAR -->
  </dependency>

  Features:
    • Automatic restart when classpath files change
    • LiveReload server for browser refresh
    • Caches disabled (Thymeleaf, Freemarker etc.) for instant changes
    • Remote development mode

  Configuration:
    spring.devtools.restart.enabled=true
    spring.devtools.livereload.enabled=true

      <jackson.version>2.17.0</jackson.version>
  </properties>

  <!-- Or in gradle -->
  ext['jackson-bom.version'] = '2.17.0'

================================================================
INTERVIEW QUESTIONS — STARTERS
================================================================

  Q: What is a Spring Boot Starter?
  A: A curated dependency bundle that brings in all compatible
     libraries for a specific technology. It replaces manual,
     error-prone dependency version management.

  Q: What is the difference between spring-boot-starter-parent
     and spring-boot-dependencies?
  A: Both manage dependency versions via BOM. starter-parent is a
     parent POM that also provides plugin config and compile settings.
     spring-boot-dependencies is the pure BOM — use it when you have
     your own corporate parent POM.

  Q: How do you switch from Tomcat to Undertow?
  A: Exclude spring-boot-starter-tomcat from spring-boot-starter-web
     and add spring-boot-starter-undertow.

  Q: How do you use Log4j2 instead of Logback in Spring Boot?
  A: Exclude spring-boot-starter-logging from spring-boot-starter,
     then add spring-boot-starter-log4j2.

  Q: What does spring-boot-starter-test include?
  A: JUnit 5 (JUnit Platform + Jupiter), Mockito, AssertJ, Hamcrest,
     MockMvc, TestRestTemplate, Spring Test utilities, and JsonPath.
