━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. REQUIREMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CLARIFICATIONS:
  - What products? Physical items (drinks, snacks). Multiple types.
  - Payment methods? Coins only (simplification), or card too?
    → Coins + notes for this design.
  - Change dispensing? Yes — machine gives change.
  - Multiple items per transaction? No — one item per transaction.
  - Admin operations? Restock inventory, collect cash.
  - What if no change available? Cancel transaction, return money.

CORE OPERATIONS:
  Customer:
    1. View available products
    2. Select a product
    3. Insert money
    4. Get product (if payment sufficient)
    5. Get change (if overpaid)
    6. Cancel and get refund

  Admin:
    1. Restock products
    2. Collect cash

ENTITIES:
  VendingMachine, Product, Slot, Coin, Denomination, Payment, Transaction, State

2. STATE MACHINE (Key Design Decision)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A vending machine is a CLASSIC STATE MACHINE problem.
The machine's behavior depends on its current STATE.

States:
  IDLE            → Waiting for product selection
  PRODUCT_SELECTED → Product chosen, waiting for payment
  PAYMENT_PENDING  → Collecting coins/notes
  DISPENSING       → Delivering product + change
  OUT_OF_STOCK     → Selected product unavailable

Transitions:
  IDLE → PRODUCT_SELECTED         : selectProduct(productCode)
  PRODUCT_SELECTED → PAYMENT_PENDING : insertMoney(amount)
  PAYMENT_PENDING → PAYMENT_PENDING  : insertMoney(amount) [more money needed]
  PAYMENT_PENDING → DISPENSING        : insertMoney(amount) [sufficient]
  PAYMENT_PENDING → IDLE             : cancel() [refund inserted money]
  DISPENSING → IDLE                  : dispenseComplete()
  IDLE → OUT_OF_STOCK               : selectProduct() [if out of stock]

Design Pattern used: STATE PATTERN
  Each state is a class implementing VendingMachineState interface.
  VendingMachine delegates all operations to the current state object.
  State objects encapsulate behavior and transition logic.

3. CLASS DESIGN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// --- Enums ---

enum Denomination {
    PENNY(0.01), NICKEL(0.05), DIME(0.10), QUARTER(0.25),
    ONE(1.00), FIVE(5.00), TEN(10.00), TWENTY(20.00);
    
    private final double value;
    Denomination(double value) { this.value = value; }
    public double getValue() { return value; }
}

// --- Product ---

class Product {
    private final String code;       // e.g., "A1", "B3"
    private final String name;
    private final double price;
    
    Product(String code, String name, double price) {
        this.code = code;
        this.name = name;
        this.price = price;
    }
    
    public String getCode() { return code; }
    public String getName() { return name; }
    public double getPrice() { return price; }
}

// --- Slot (holds product inventory) ---

class Slot {
    private final Product product;
    private int quantity;
    
    Slot(Product product, int quantity) {
        this.product = product;
        this.quantity = quantity;
    }
    
    public boolean isAvailable()     { return quantity > 0; }
    public Product getProduct()      { return product; }
    public int getQuantity()         { return quantity; }
    
    public void dispense() {
        if (quantity == 0) throw new IllegalStateException("Slot is empty");
        quantity--;
    }
    
    public void restock(int count) { quantity += count; }
}

// --- State Interface ---

interface VendingMachineState {
    void selectProduct(String productCode);
    void insertMoney(Denomination denomination);
    void cancel();
    void dispense();
    String getStateName();
}

// --- VendingMachine (Context in State Pattern) ---

class VendingMachine {
    private final Map<String, Slot> slots;        // productCode → Slot
    private final Map<Denomination, Integer> cashInventory; // change reserve
    
    private VendingMachineState currentState;
    private Product selectedProduct;
    private double insertedAmount;
    
    // States
    private final VendingMachineState idleState;
    private final VendingMachineState productSelectedState;
    private final VendingMachineState paymentPendingState;
    private final VendingMachineState dispensingState;
    
    VendingMachine() {
        this.slots = new HashMap<>();
        this.cashInventory = new HashMap<>();
        
        // Initialize states (each holds a reference back to machine)
        this.idleState           = new IdleState(this);
        this.productSelectedState = new ProductSelectedState(this);
        this.paymentPendingState  = new PaymentPendingState(this);
        this.dispensingState      = new DispensingState(this);
        
        this.currentState = idleState;
        this.insertedAmount = 0.0;
    }
    
    // Delegate to current state
    public void selectProduct(String code) { currentState.selectProduct(code); }
    public void insertMoney(Denomination d) { currentState.insertMoney(d); }
    public void cancel()                    { currentState.cancel(); }
    public void dispense()                  { currentState.dispense(); }
    
    // State transitions (called by State objects)
    void setState(VendingMachineState state) { this.currentState = state; }
    VendingMachineState getIdleState()       { return idleState; }
    VendingMachineState getProductSelectedState() { return productSelectedState; }
    VendingMachineState getPaymentPendingState()  { return paymentPendingState; }
    VendingMachineState getDispensingState()      { return dispensingState; }
    
    // Business logic helpers
    Slot getSlot(String code)            { return slots.get(code); }
    void setSelectedProduct(Product p)   { this.selectedProduct = p; }
    Product getSelectedProduct()         { return selectedProduct; }
    void addInsertedAmount(double amount){ this.insertedAmount += amount; }
    double getInsertedAmount()           { return insertedAmount; }
    void resetTransaction()              { selectedProduct = null; insertedAmount = 0.0; }
    
    boolean canMakeChange(double amount) {
        // Greedy algorithm: check if we can make exact change
        double remaining = amount;
        Denomination[] denoms = Denomination.values();
        // Sort by value descending
        Arrays.sort(denoms, (a, b) -> Double.compare(b.getValue(), a.getValue()));
        for (Denomination d : denoms) {
            int needed = (int)(remaining / d.getValue());
            int available = cashInventory.getOrDefault(d, 0);
            int used = Math.min(needed, available);
            remaining -= used * d.getValue();
            remaining = Math.round(remaining * 100.0) / 100.0;
        }
        return remaining == 0.0;
    }
    
    Map<Denomination, Integer> calculateChange(double amount) {
        Map<Denomination, Integer> change = new EnumMap<>(Denomination.class);
        double remaining = amount;
        Denomination[] denoms = Denomination.values();
        Arrays.sort(denoms, (a, b) -> Double.compare(b.getValue(), a.getValue()));
        for (Denomination d : denoms) {
            int needed = (int)(remaining / d.getValue());
            int available = cashInventory.getOrDefault(d, 0);
            int used = Math.min(needed, available);
            if (used > 0) {
                change.put(d, used);
                cashInventory.merge(d, -used, Integer::sum);
                remaining -= used * d.getValue();
                remaining = Math.round(remaining * 100.0) / 100.0;
            }
        }
        return change;
    }
    
    // Admin operations
    void restock(String productCode, int quantity) {
        Slot slot = slots.get(productCode);
        if (slot == null) throw new IllegalArgumentException("Unknown product code");
        slot.restock(quantity);
    }
    
    void addProduct(Product product, int quantity) {
        slots.put(product.getCode(), new Slot(product, quantity));
    }
    
    void loadCash(Denomination denomination, int count) {
        cashInventory.merge(denomination, count, Integer::sum);
    }
    
    void displayStatus() {
        System.out.println("=== Vending Machine Status ===");
        System.out.println("State: " + currentState.getStateName());
        slots.forEach((code, slot) ->
            System.out.printf("  %s: %s - $%.2f (%d left)%n",
                code, slot.getProduct().getName(), slot.getProduct().getPrice(), slot.getQuantity()));
        System.out.printf("Inserted: $%.2f%n", insertedAmount);
    }
}

// --- IdleState ---

class IdleState implements VendingMachineState {
    private final VendingMachine machine;
    
    IdleState(VendingMachine machine) { this.machine = machine; }
    
    @Override
    public void selectProduct(String productCode) {
        Slot slot = machine.getSlot(productCode);
        if (slot == null) {
            System.out.println("Invalid product code: " + productCode);
            return;
        }
        if (!slot.isAvailable()) {
            System.out.println("Product out of stock.");
            return;
        }
        machine.setSelectedProduct(slot.getProduct());
        System.out.printf("Selected: %s - $%.2f. Please insert money.%n",
            slot.getProduct().getName(), slot.getProduct().getPrice());
        machine.setState(machine.getPaymentPendingState());
    }
    
    @Override public void insertMoney(Denomination d) {
        System.out.println("Please select a product first."); }
    @Override public void cancel()   { System.out.println("Nothing to cancel."); }
    @Override public void dispense() { System.out.println("Select a product first."); }
    @Override public String getStateName() { return "IDLE"; }
}

// --- PaymentPendingState ---

class PaymentPendingState implements VendingMachineState {
    private final VendingMachine machine;
    
    PaymentPendingState(VendingMachine machine) { this.machine = machine; }
    
    @Override public void selectProduct(String code) {
        System.out.println("Payment in progress. Cancel first to select different product."); }
    
    @Override
    public void insertMoney(Denomination denomination) {
        machine.addInsertedAmount(denomination.getValue());
        machine.loadCash(denomination, 1); // add to cash inventory
        double price = machine.getSelectedProduct().getPrice();
        double inserted = machine.getInsertedAmount();
        System.out.printf("Inserted: $%.2f / Required: $%.2f%n", inserted, price);
        
        if (inserted >= price) {
            machine.setState(machine.getDispensingState());
            machine.dispense();
        }
    }
    
    @Override
    public void cancel() {
        System.out.printf("Cancelled. Returning $%.2f.%n", machine.getInsertedAmount());
        // Return inserted money (from cash inventory)
        machine.resetTransaction();
        machine.setState(machine.getIdleState());
    }
    
    @Override public void dispense()       { System.out.println("Insert more money."); }
    @Override public String getStateName() { return "PAYMENT_PENDING"; }
}

// --- DispensingState ---

class DispensingState implements VendingMachineState {
    private final VendingMachine machine;
    
    DispensingState(VendingMachine machine) { this.machine = machine; }
    
    @Override
    public void dispense() {
        Product product = machine.getSelectedProduct();
        double change = machine.getInsertedAmount() - product.getPrice();
        change = Math.round(change * 100.0) / 100.0;
        
        // Dispense product
        machine.getSlot(product.getCode()).dispense();
        System.out.println("Dispensing: " + product.getName());
        
        // Give change
        if (change > 0) {
            if (machine.canMakeChange(change)) {
                Map<Denomination, Integer> changeMap = machine.calculateChange(change);
                System.out.printf("Returning change: $%.2f%n", change);
                changeMap.forEach((d, count) ->
                    System.out.printf("  %dx %s ($%.2f each)%n", count, d.name(), d.getValue()));
            } else {
                System.out.println("Cannot make exact change. Returning all money.");
                // In real implementation: return all inserted money, cancel transaction
            }
        }
        
        machine.resetTransaction();
        machine.setState(machine.getIdleState());
        System.out.println("Thank you! Machine is ready.");
    }
    
    @Override public void selectProduct(String c) { /* ignore */ }
    @Override public void insertMoney(Denomination d) { /* ignore */ }
    @Override public void cancel() { System.out.println("Dispensing in progress."); }
    @Override public String getStateName() { return "DISPENSING"; }
}

4. USAGE EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

VendingMachine machine = new VendingMachine();

// Admin setup
machine.loadCash(Denomination.QUARTER, 20);
machine.loadCash(Denomination.DIME, 20);
machine.loadCash(Denomination.NICKEL, 20);
machine.addProduct(new Product("A1", "Coke", 1.50), 10);
machine.addProduct(new Product("A2", "Water", 1.00), 5);
machine.addProduct(new Product("B1", "Chips", 2.00), 8);

// Customer interaction
machine.selectProduct("A1");          // Select Coke ($1.50)
machine.insertMoney(Denomination.ONE); // Insert $1.00
machine.insertMoney(Denomination.ONE); // Insert another $1.00
// → Dispenses Coke, returns $0.50 change

machine.selectProduct("B1");           // Select Chips ($2.00)
machine.cancel();                       // Change mind, cancel

5. DESIGN PATTERNS USED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STATE PATTERN:
  Each state (Idle, PaymentPending, Dispensing) is its own class.
  VendingMachine (Context) delegates to current state.
  States handle transitions by calling machine.setState().
  Avoids large if-else chains with complex state checking.

STRATEGY PATTERN (for change-making):
  The change-making algorithm (greedy) is encapsulated.
  Could be swapped for different algorithm (exact-change DP).

SINGLETON PATTERN (optionally):
  VendingMachine could be singleton in a real embedded system.
  In enterprise Java: managed as a Spring @Component.

6. EDGE CASES TO DISCUSS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- Cannot make exact change → return all money, cancel transaction.
- Concurrent access → synchronize (or use locks per machine).
- Product dispensed but machine jams → needs sensor + recovery state.
- Admin collecting cash → clear cashInventory, record transaction.
- Multiple machines → Machine Registry / Factory pattern.
- Network-connected vending machines → Event-driven inventory updates to backend.
