================================================================
  INTRODUCTION TO DATA STRUCTURES
================================================================

----------------------------------------------------------------
WHAT IS A DATA STRUCTURE?
----------------------------------------------------------------
A data structure is a way of organizing, storing, and managing
data in memory so it can be accessed and modified efficiently.

Choosing the right data structure is critical — it directly
impacts time complexity, space complexity, and code clarity.

----------------------------------------------------------------
WHY DATA STRUCTURES MATTER
----------------------------------------------------------------
- Enable efficient algorithms
- Poor choices cause bottlenecks at scale
- Interviewers test this to evaluate engineering judgment

----------------------------------------------------------------
CLASSIFICATION
----------------------------------------------------------------

BY MEMORY LAYOUT
  Contiguous (single block of memory)
    - Array
    - 2D Array / Matrix

  Non-Contiguous (pointer/reference based)
    - Linked List
    - Tree
    - Graph

BY LOGICAL STRUCTURE
  Linear (sequential)
    - Array, Linked List, Stack, Queue, Deque, Priority Queue

  Non-Linear (hierarchical or networked)
    - Binary Tree, BST, AVL Tree, Red-Black Tree
    - Heap, Trie, Graph

  Hash-Based (key-value, O(1) average access)
    - HashMap, HashSet, LinkedHashMap

  Advanced / Specialized
    - Segment Tree, Fenwick Tree (BIT)
    - Disjoint Set (Union-Find)
    - Monotonic Stack / Queue
    - Skip List, Bloom Filter, Sparse Table

----------------------------------------------------------------
ADT vs DATA STRUCTURE
----------------------------------------------------------------
  Abstract Data Type (ADT)
    - Defines WHAT operations are supported
    - Example: Stack supports push, pop, peek

  Data Structure
    - Defines HOW it is implemented
    - Example: Stack backed by an array or linked list

  ADT is the contract. Data structure is the implementation.

----------------------------------------------------------------
CORE OPERATIONS TO EVALUATE
----------------------------------------------------------------
  Access    - retrieve element by index or key
  Search    - find element by value
  Insert    - add a new element
  Delete    - remove an element
  Traversal - visit all elements

----------------------------------------------------------------
BIG-O QUICK REFERENCE
----------------------------------------------------------------
  Structure         Access    Search    Insert    Delete    Space
  ---------------------------------------------------------------
  Array             O(1)      O(n)      O(n)      O(n)      O(n)
  Linked List       O(n)      O(n)      O(1)      O(1)      O(n)
  Stack             O(n)      O(n)      O(1)      O(1)      O(n)
  Queue             O(n)      O(n)      O(1)      O(1)      O(n)
  HashMap           O(1)*     O(1)*     O(1)*     O(1)*     O(n)
  BST (balanced)    O(log n)  O(log n)  O(log n)  O(log n)  O(n)
  Heap              O(n)      O(n)      O(log n)  O(log n)  O(n)

  * Average case. HashMap worst case is O(n) due to collisions.

----------------------------------------------------------------
HOW TO CHOOSE A DATA STRUCTURE
----------------------------------------------------------------
  Need fast random access?                  --> Array
  Frequent insert/delete at any position?   --> Linked List
  LIFO (last in, first out)?                --> Stack
  FIFO (first in, first out)?               --> Queue
  Fast key-value lookup?                    --> HashMap
  Sorted data with fast search?             --> BST / TreeMap
  Min or max element quickly?               --> Heap / PriorityQueue
  Prefix-based search?                      --> Trie
  Model relationships or networks?          --> Graph
  Range queries on an array?                --> Segment Tree / BIT

----------------------------------------------------------------
JAVA COLLECTIONS CHEAT SHEET
----------------------------------------------------------------
  ADT               Java Class          Notes
  ---------------------------------------------------------------
  Dynamic Array     ArrayList           O(1) amortized add
  Linked List       LinkedList          Implements List + Deque
  Stack             ArrayDeque          Prefer over legacy Stack
  Queue             ArrayDeque          FIFO
  Priority Queue    PriorityQueue       Min-heap by default
  HashMap           HashMap             O(1) avg, unordered
  Sorted Map        TreeMap             O(log n), sorted by key
  HashSet           HashSet             O(1) avg, no duplicates
  Sorted Set        TreeSet             O(log n), sorted

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. State your data structure choice and justify it before coding
  2. Know trade-offs: time vs space, ordered vs unordered,
     contiguous vs linked
  3. Know worst-case vs average-case (HashMap: O(1) avg, O(n) worst)
  4. Be ready to implement from scratch (LRU Cache, Min Stack)
  5. Know Comparable vs Comparator for custom ordering in Java
