----------------------------------------------------------------
WHAT IS AN ADJACENCY LIST?
----------------------------------------------------------------
An adjacency list represents a graph as an array (or map) of
lists, where list[i] contains all vertices adjacent to vertex i.

  Space: O(V + E) -- stores only existing edges.

  Visualization for undirected graph:
    Vertices: 0, 1, 2, 3
    Edges: 0-1, 0-2, 1-3, 2-3

    0: [1, 2]
    1: [0, 3]
    2: [0, 3]
    3: [1, 2]

----------------------------------------------------------------
JAVA IMPLEMENTATIONS
----------------------------------------------------------------
  1. Integer vertex IDs (most common in interviews):

    // Unweighted
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < V; i++) adj.add(new ArrayList<>());

    // Add undirected edge
    adj.get(u).add(v);
    adj.get(v).add(u);

    // Add directed edge
    adj.get(u).add(v);

    // BFS
    Queue<Integer> q = new LinkedList<>();
    boolean[] visited = new boolean[V];
    visited[src] = true; q.offer(src);
    while (!q.isEmpty()) {
      int node = q.poll();
      for (int nb : adj.get(node)) {
        if (!visited[nb]) { visited[nb] = true; q.offer(nb); }
      }
    }

  2. Weighted graph:

    // Using int[] pairs [neighbor, weight]
    List<int[]>[] adj = new ArrayList[V];
    for (int i = 0; i < V; i++) adj[i] = new ArrayList<>();
    adj[u].add(new int[]{v, weight});

    // Or using Map for string/arbitrary keys
    Map<String, List<String>> adj = new HashMap<>();
    adj.computeIfAbsent(u, k -> new ArrayList<>()).add(v);

  3. Build from edge list input (common interview input format):
    int[][] edges;  // edges[i] = [u, v] or [u, v, weight]
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
    for (int[] e : edges) {
      adj.get(e[0]).add(e[1]);
      adj.get(e[1]).add(e[0]);  // if undirected
    }

  4. Using HashMap for string vertices:
    Map<String, List<String>> graph = new HashMap<>();
    for (String[] e : edges) {
      graph.computeIfAbsent(e[0], k -> new ArrayList<>()).add(e[1]);
      graph.computeIfAbsent(e[1], k -> new ArrayList<>()).add(e[0]);
    }

COMPLEXITY
----------------------------------------------------------------
  Operation             Time            Notes
  ---------------------------------------------------------------
  Add edge              O(1)            Append to list
  Remove edge           O(degree)       Must scan list
  Edge check (u,v)      O(degree(u))    Scan list of u
  Get all neighbors     O(degree)       Return list directly
  Space                 O(V + E)        Proportional to edges
  BFS / DFS             O(V + E)        Each edge visited once

SHORTEST PATH WITH ADJACENCY LIST
----------------------------------------------------------------
  UNWEIGHTED (BFS):
    int[] dist = new int[V];
    Arrays.fill(dist, -1);
    dist[src] = 0;
    Queue<Integer> q = new LinkedList<>();
    q.offer(src);
    while (!q.isEmpty()) {
      int node = q.poll();
      for (int nb : adj.get(node)) {
        if (dist[nb] == -1) {
          dist[nb] = dist[node] + 1;
          q.offer(nb);
        }
      }
    }

  WEIGHTED POSITIVE (Dijkstra):
    int[] dist = new int[V];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>((a,b)->a[0]-b[0]);
    pq.offer(new int[]{0, src});  // [dist, node]
    while (!pq.isEmpty()) {
      int[] curr = pq.poll();
      int d = curr[0], node = curr[1];
      if (d > dist[node]) continue;  // stale entry
      for (int[] nb : adj.get(node)) {  // [neighbor, weight]
        int newDist = dist[node] + nb[1];
        if (newDist < dist[nb[0]]) {
          dist[nb[0]] = newDist;
          pq.offer(new int[]{newDist, nb[0]});
        }
      }
    }

  Dijkstra time: O((V + E) log V) with binary heap PQ

CONNECTED COMPONENTS
----------------------------------------------------------------
  Count connected components in undirected graph:

    int components = 0;
    boolean[] visited = new boolean[V];
    for (int i = 0; i < V; i++) {
      if (!visited[i]) {
        dfs(i, visited, adj);
        components++;
      }
    }

  Islands problem: same idea on an implicit grid graph.

----------------------------------------------------------------
CYCLE DETECTION IN DIRECTED GRAPH (DFS + 3 colors)
----------------------------------------------------------------
  0 = WHITE (unvisited)
  1 = GRAY (in current DFS path)
  2 = BLACK (fully processed)

  boolean hasCycle(int node, int[] color, List<List<Integer>> adj) {
    color[node] = 1;  // GRAY: in current path
    for (int nb : adj.get(node)) {
      if (color[nb] == 1) return true;  // back edge -> cycle
      if (color[nb] == 0 && hasCycle(nb, color, adj)) return true;
    }
    color[node] = 2;  // BLACK: done
    return false;
  }

  GRAY node encountered = back edge = cycle.
  BLACK node encountered = cross/forward edge = no cycle here.

----------------------------------------------------------------
INTERVIEW QUESTIONS
----------------------------------------------------------------

Q: How do you build a graph from a list of edges in Java?
A: Create an array of ArrayLists: List<List<Integer>> adj =
   new ArrayList<>(), then for i in [0,n): adj.add(new ArrayList<>()).
   For each edge [u, v]: adj.get(u).add(v). For undirected:
   also adj.get(v).add(u). For string vertices, use a HashMap
   with computeIfAbsent for clean initialization.

Q: What is the difference between DFS cycle detection in
   directed vs undirected graphs?
A: In an undirected graph: if DFS visits a neighbor that's
   already visited (and is not the parent), there's a cycle.
   In a directed graph: you need 3 colors (WHITE/GRAY/BLACK).
   A back edge (to a GRAY node = ancestor in current DFS path)
   indicates a cycle. A cross edge (to a BLACK node = already
   fully processed) does NOT indicate a cycle in a directed graph.
   Using only "visited" boolean for directed graphs gives false
   positives.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. For most interview problems, build adjacency list from
     edges input immediately as the first step
  2. adj.computeIfAbsent(key, k -> new ArrayList<>()).add(val)
     is the cleanest one-liner for map-based adjacency lists
  3. For Dijkstra, the stale-entry check (if d > dist[node] continue)
     is essential when using lazy deletion with PriorityQueue
  4. Cycle detection: 2-color for undirected, 3-color for directed
  5. When building weighted adjacency lists, int[] {neighbor, weight}
     is simpler than creating an Edge class in interviews
