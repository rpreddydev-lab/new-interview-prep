================================================================
  BIT MANIPULATION & BITMASK DP
================================================================

----------------------------------------------------------------
FUNDAMENTAL BIT OPERATIONS
----------------------------------------------------------------
  Operator  Symbol  Example
  -----------------------------------------------
  AND        &      5 & 3  = 101 & 011 = 001 = 1
  OR         |      5 | 3  = 101 | 011 = 111 = 7
  XOR        ^      5 ^ 3  = 101 ^ 011 = 110 = 6
  NOT        ~      ~5     = -(5+1) = -6
  Left shift <<     5 << 1 = 1010 = 10  (* 2)
  Right shift>>     5 >> 1 = 10   = 2   (/ 2)

  Key XOR properties:
    a ^ 0 = a        (XOR with 0 = identity)
    a ^ a = 0        (XOR with itself = 0)
    a ^ b ^ a = b    (XOR is commutative and associative)
    a ^ (~a) = -1    (all bits set)

----------------------------------------------------------------
MUST-KNOW BIT TRICKS
----------------------------------------------------------------
  1. CHECK if i-th bit is set:
     (n >> i) & 1  == 1    OR    (n & (1 << i)) != 0

  2. SET the i-th bit:
     n | (1 << i)

  3. CLEAR the i-th bit:
     n & ~(1 << i)

  4. TOGGLE the i-th bit:
     n ^ (1 << i)

  5. CLEAR the lowest set bit:
     n & (n - 1)
     Example: n=12 (1100), n-1=11 (1011), n&(n-1)=8 (1000)
     Use: count set bits (Kernighan), check power of 2

  6. EXTRACT the lowest set bit (isolate rightmost 1):
     n & (-n)   or equivalently   n & (~n + 1)
     Example: n=12 (1100), -12=...0100, n&(-n)=4 (0100)
     Use: Fenwick Tree update/query, determine position of lowest set bit

  7. CHECK power of 2:
     n > 0 && (n & (n-1)) == 0

  8. COUNT set bits (popcount):
     Integer.bitCount(n)  -- Java built-in
     Manual: while (n != 0) { count++; n &= n-1; }

  9. XOR to find single number:
     XOR of all elements -- pairs cancel, single remains.

  10. SWAP two integers without temp:
      a ^= b; b ^= a; a ^= b;
      (Rarely useful in practice; mention only if asked)

  11. GET position of highest set bit:
      31 - Integer.numberOfLeadingZeros(n)  (Java)

  12. ROUND UP to next power of 2:
      int p = 1; while (p < n) p <<= 1;
      Or: Integer.highestOneBit(n) << 1

----------------------------------------------------------------
SINGLE NUMBER VARIANTS
----------------------------------------------------------------
  Single Number I (one number appears once, rest twice):
    XOR all numbers. Pairs cancel. Answer is the single XOR result.
    return Arrays.stream(nums).reduce(0, (a, b) -> a ^ b);

  Single Number II (one number appears once, rest three times):
    For each bit position, count 1s modulo 3.
    The bit in the answer has count % 3 != 0.
    Or: use two variables (ones, twos) to simulate a 2-bit counter.
    ones = (ones ^ n) & ~twos;  twos = (twos ^ n) & ~ones;

  Single Number III (two numbers appear once, rest twice):
    XOR all -> xor = a ^ b.
    Find any set bit in xor (use xor & -xor).
    Divide numbers into two groups by that bit.
    XOR each group separately -> get a and b.

----------------------------------------------------------------
MISSING / DUPLICATE NUMBER
----------------------------------------------------------------
  Missing Number (0..n, one missing):
    XOR: 0 ^ 1 ^ 2 ^ ... ^ n ^ nums[0] ^ nums[1] ^ ...
    Or: expected_sum - actual_sum = n*(n+1)/2 - sum(nums)

  Find All Duplicates / Missing (1..n range, array length n):
    Use array elements as indices (negate visited values)
    or XOR-based approach.

----------------------------------------------------------------
BITMASK DP (key DP pattern)
----------------------------------------------------------------
Used when the state can be represented as a subset of n items.
Common when n <= 20 (2^20 = 1M states manageable).

  dp[mask] = optimal value using the subset represented by mask
  mask has bit i set iff item i is included in the subset

  Iterate through all subsets: for (int mask = 0; mask < (1 << n); mask++)

  ENUMERATE all subsets of a given mask:
    for (int sub = mask; sub > 0; sub = (sub - 1) & mask)
      // process subset 'sub'
      // (sub - 1) & mask removes the lowest set bit from sub
      // and then masks to valid bits

  COUNT bits in mask:
    Integer.bitCount(mask)

  TRAVELING SALESMAN PROBLEM (TSP) with Bitmask DP:

  int tsp(int[][] dist, int n) {
    int FULL = (1 << n) - 1;
    int[][] dp = new int[1 << n][n];
    for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
    dp[1][0] = 0;  // start at node 0, visited = {0}

    for (int mask = 1; mask <= FULL; mask++) {
      for (int u = 0; u < n; u++) {
        if ((mask & (1 << u)) == 0) continue;  // u not in mask
        if (dp[mask][u] == Integer.MAX_VALUE / 2) continue;
        for (int v = 0; v < n; v++) {
          if ((mask & (1 << v)) != 0) continue;  // v already visited
          int newMask = mask | (1 << v);
          dp[newMask][v] = Math.min(dp[newMask][v], dp[mask][u] + dist[u][v]);
        }
      }
    }
    int result = Integer.MAX_VALUE;
    for (int u = 1; u < n; u++)
      result = Math.min(result, dp[FULL][u] + dist[u][0]);
    return result;
  }

  Time: O(2^n * n^2)  Space: O(2^n * n)

  Other bitmask DP problems:
    - Minimum XOR sum of two arrays (assignment problem)
    - Maximum AND sum
    - Partition subsets with equal sum
    - State compression in grid-based DP

----------------------------------------------------------------
INTERVIEW QUESTIONS
----------------------------------------------------------------

Q: How does n & (n-1) work and what is it used for?
A: Subtracting 1 from n flips all bits from the rightmost 1 bit
   downward (the rightmost 1 becomes 0, all lower bits become 1).
   ANDing with n preserves all bits ABOVE the rightmost 1 and
   clears the rightmost 1. So n & (n-1) removes the lowest set
   bit from n. Uses:
   1. Count set bits: loop until n=0, incrementing count each time
   2. Check power of 2: a power of 2 has exactly one set bit,
      so n & (n-1) == 0 for powers of 2 (and n > 0)

Q: Why is bitmask DP used for the Traveling Salesman Problem?
A: TSP has n! possible routes, exponentially large. But if we
   represent "which cities have been visited" as a bitmask,
   there are only 2^n subsets. For each subset and ending city,
   we store the optimal cost: dp[mask][u] = min cost to visit
   exactly the cities in `mask`, ending at city u. This reduces
   TSP from O(n!) to O(2^n * n^2), feasible for n <= 20.

Q: What is the time and space complexity of bitmask DP?
A: For n items:
   - 2^n possible subsets (states)
   - Each state stores n values (one per item)
   - Time: O(2^n * n^2) for TSP-style, O(2^n * n) for simpler
   - Space: O(2^n * n)
   This is tractable for n <= 20 (2^20 = ~1M) but infeasible
   for large n. Problems with n <= 15-20 are the signal that
   bitmask DP is intended.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Always use `1 << i` not `i << 1` (common bug: << and >>
     precedence is lower than most operators; use parentheses)
  2. In Java, use int for up to 32 items, long for up to 64
  3. Integer.bitCount(mask) in Java is a single CPU instruction
     (POPCNT) -- much faster than manual loops
  4. When you see n <= 20 in a problem with "all subsets" or
     "visit all nodes": think bitmask DP immediately
  5. XOR properties: a ^ a = 0, a ^ 0 = a -- commit these to memory
  6. The subset enumeration trick (sub = (sub-1) & mask) is an
     advanced pattern worth knowing for bitmask DP optimization
