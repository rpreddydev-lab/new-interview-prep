1. MAPPING ENUMS — @ENUMERATED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

public enum OrderStatus {
    PENDING, PROCESSING, SHIPPED, DELIVERED, CANCELLED
}

Option A: EnumType.ORDINAL (DEFAULT — AVOID)
  @Enumerated(EnumType.ORDINAL)
  private OrderStatus status;
  // Stores: 0, 1, 2, 3, 4
  // Problem: adding a new enum value between existing ones CHANGES all values!
  // PENDING=0, PROCESSING=1... if you add PAYMENT_PENDING before PROCESSING,
  // all existing PROCESSING become PAYMENT_PENDING silently!

Option B: EnumType.STRING (RECOMMENDED)
  @Enumerated(EnumType.STRING)
  @Column(length = 20)
  private OrderStatus status;
  // Stores: "PENDING", "PROCESSING", etc.
  // Safe to add new values or reorder
  // Readable in DB

Best practice:
  ALWAYS use EnumType.STRING unless you have a very specific performance
  reason (STRING uses slightly more storage but is safe and readable).

2. ATTRIBUTECONVERTER — Custom Type Mapping (JPA 2.1+)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

AttributeConverter<X, Y> converts between:
  X = Java type
  Y = DB column type

Use cases:
- Enum to a custom DB code (e.g., "A", "P", "S" instead of full names)
- Encrypt/decrypt sensitive fields
- Store a List<String> as a comma-separated column
- Map a Money value type
- Map custom Java 8+ types (MonthDay, YearMonth, etc.)

Example 1: Enum → Custom DB Code
  public enum OrderStatus {
      PENDING("P"), PROCESSING("PR"), SHIPPED("SH"), DELIVERED("D"), CANCELLED("C");

      private final String code;
      OrderStatus(String code) { this.code = code; }
      public String getCode() { return code; }

      public static OrderStatus fromCode(String code) {
          for (OrderStatus s : values()) {
              if (s.code.equals(code)) return s;
          }
          throw new IllegalArgumentException("Unknown code: " + code);
      }
  }

  @Converter
  public class OrderStatusConverter implements AttributeConverter<OrderStatus, String> {
      @Override
      public String convertToDatabaseColumn(OrderStatus status) {
          return status == null ? null : status.getCode();
      }

      @Override
      public OrderStatus convertToEntityAttribute(String code) {
          return code == null ? null : OrderStatus.fromCode(code);
      }
  }

  // Apply to field:
  @Convert(converter = OrderStatusConverter.class)
  @Column(name = "status", length = 5)
  private OrderStatus status;

Example 2: List<String> → comma-separated VARCHAR
  @Converter
  public class StringListConverter implements AttributeConverter<List<String>, String> {
      @Override
      public String convertToDatabaseColumn(List<String> list) {
          return (list == null || list.isEmpty()) ? null : String.join(",", list);
      }

      @Override
      public List<String> convertToEntityAttribute(String csv) {
          if (csv == null || csv.isBlank()) return new ArrayList<>();
          return Arrays.asList(csv.split(","));
      }
  }

  @Convert(converter = StringListConverter.class)
  @Column(name = "tags", length = 500)
  private List<String> tags;

Example 3: Auto-apply to all fields of a type
  @Converter(autoApply = true)   // applies globally to all LocalDate fields
  public class LocalDateConverter implements AttributeConverter<LocalDate, java.sql.Date> {
      @Override
      public java.sql.Date convertToDatabaseColumn(LocalDate date) {
          return date == null ? null : java.sql.Date.valueOf(date);
      }
      @Override
      public LocalDate convertToEntityAttribute(java.sql.Date date) {
          return date == null ? null : date.toLocalDate();
      }
  }
  // No @Convert annotation needed on fields when autoApply=true

3. HIBERNATE @TYPE (Hibernate 6 — @JdbcType / @JavaType)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Hibernate 6 (Spring Boot 3) replaced legacy @Type with new type system:

// Store enum as lowercase in DB:
@Column(name = "status")
@Enumerated(EnumType.STRING)
@ColumnTransformer(read = "UPPER(status)", write = "LOWER(?)")
private OrderStatus status;

// Map PostgreSQL JSONB column:
@JdbcTypeCode(SqlTypes.JSON)
@Column(name = "metadata", columnDefinition = "jsonb")
private Map<String, Object> metadata;

// Map PostgreSQL ARRAY:
@Array(length = 10)
private String[] tags;

// UUID — stored as native UUID type (PostgreSQL):
@Id
@UuidGenerator(style = UuidGenerator.Style.RANDOM)
private UUID id;

4. MAPPING BOOLEAN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// Standard JPA — maps to BOOLEAN / BIT:
@Column(name = "is_active")
private boolean active;

// Legacy schema stores boolean as Y/N char:
@Converter(autoApply = false)
public class BooleanToYNConverter implements AttributeConverter<Boolean, String> {
    @Override
    public String convertToDatabaseColumn(Boolean flag) {
        return (flag != null && flag) ? "Y" : "N";
    }
    @Override
    public Boolean convertToEntityAttribute(String code) {
        return "Y".equalsIgnoreCase(code);
    }
}

@Convert(converter = BooleanToYNConverter.class)
private Boolean active;

Q: Why should you avoid @Enumerated(EnumType.ORDINAL)?
A: ORDINAL stores enum position (0, 1, 2...). If any enum value is
   inserted, renamed, or reordered, all existing database rows silently
   map to the wrong enum constants. STRING stores the name itself,
   which is stable regardless of ordering changes.

Q: What is an AttributeConverter and when do you use it?
A: An AttributeConverter<JavaType, DbType> converts between a Java type
   and a DB column type at the JPA layer. Use it when you need to store
   data differently than JPA defaults: custom enum codes, encrypted fields,
   comma-separated lists, or mapping custom value objects.

Q: What does autoApply=true do on @Converter?
A: It tells JPA to apply the converter automatically to ALL fields of
   the specified Java type across all entities — without needing an
   explicit @Convert annotation on each field.

Q: How would you store a List<String> in a single DB column with JPA?
A: Implement AttributeConverter<List<String>, String> that joins the list
   with a delimiter on save and splits on load. Mark it with @Converter and
   apply with @Convert on the field. Caveat: no individual element indexing
   or querying in SQL.

Q: How do you map a PostgreSQL JSONB column with Hibernate 6?
A: Use @JdbcTypeCode(SqlTypes.JSON) along with
   @Column(columnDefinition = "jsonb"). Hibernate 6 handles serialization
   via Jackson automatically when the jackson-databind dependency is present.
