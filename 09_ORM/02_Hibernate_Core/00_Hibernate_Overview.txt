1. WHAT IS HIBERNATE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Hibernate is the most widely used ORM framework for Java. It:
  - Implements the JPA specification (EntityManager backed by Hibernate Session)
  - Provides many features BEYOND the JPA spec
  - Is the DEFAULT JPA provider in Spring Boot
  - Has its own native API (Session, SessionFactory) predating JPA

History:
  2001  → Gavin King creates Hibernate as JPA precursor
  2003  → Hibernate 2 widely adopted
  2005  → Hibernate 3 (annotations + EJB 3 / JPA 1.0)
  2010  → Hibernate 4 (JPA 2.0)
  2015  → Hibernate 5 (JPA 2.1)
  2022  → Hibernate 6 (JPA 3.1, Jakarta namespace, major rewrite)

Spring Boot → Hibernate version mapping:
  Spring Boot 2.x → Hibernate 5.x (javax.persistence.*)
  Spring Boot 3.x → Hibernate 6.x (jakarta.persistence.*)

3. KEY HIBERNATE-SPECIFIC FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Feature                  | Description
─────────────────────────|───────────────────────────────────────────
First-Level Cache        | Session-level cache; always enabled
Second-Level Cache       | SessionFactory-level cache; configurable
Query Cache              | Cache query results; for read-heavy data
HQL                      | Hibernate Query Language (JPQL superset)
Dirty Checking           | Auto-detect changed fields, issue UPDATE
Batch Processing         | hibernate.jdbc.batch_size, batch INSERT/UPDATE
Natural ID               | @NaturalId for business key queries
Soft Deletes             | @SQLDelete + @Where to filter deleted rows
Filters                  | @FilterDef + @Filter: dynamic WHERE clauses
Envers                   | @Audited: automatic audit history tables
Multi-tenancy            | Schema/database per tenant
Statistics               | Query count, hit/miss rates, timing
Spatial/GIS              | hibernate-spatial for geometry types
Custom Types             | UserType for non-standard type mappings
Proxy Objects            | Lazy loading via CGLIB/ByteBuddy proxy subclasses

4. JPA API vs HIBERNATE NATIVE API
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

JPA (Standard)                 | Hibernate Native
───────────────────────────────|────────────────────────────────
EntityManagerFactory           | SessionFactory
EntityManager                  | Session
EntityTransaction              | Transaction
@Entity, @Id, @Column          | Same (JPA annotations)
JPQL                           | HQL (superset of JPQL)
CriteriaBuilder                | Same (JPA standard)
@NamedQuery                    | Same
@Version                       | Same
PersistenceContext             | Hibernate Session (same concept)

Accessing Hibernate Session from JPA EntityManager:
  Session hibernateSession = entityManager.unwrap(Session.class);
  // Now can use Hibernate-specific features:
  hibernateSession.enableFilter("activeFilter");
  hibernateSession.setDefaultReadOnly(true);

5. HIBERNATE DIALECTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Dialects tell Hibernate which SQL features are available and how to
generate DB-specific SQL (LIMIT, sequences, DDL, locks, etc.)

Common dialects:
  spring.jpa.properties.hibernate.dialect=...
  
  org.hibernate.dialect.MySQLDialect             (MySQL 8+)
  org.hibernate.dialect.MariaDBDialect           (MariaDB)
  org.hibernate.dialect.PostgreSQLDialect        (PostgreSQL 10+)
  org.hibernate.dialect.OracleDialect            (Oracle 12c+)
  org.hibernate.dialect.SQLServerDialect         (SQL Server 2012+)
  org.hibernate.dialect.H2Dialect                (H2 in-memory)

Spring Boot 3 (Hibernate 6) auto-detects dialect from the JDBC URL.
You rarely need to set it manually.

7. HIBERNATE STATISTICS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Enable in properties:
  spring.jpa.properties.hibernate.generate_statistics=true

Access at runtime:
  @Autowired
  EntityManagerFactory emf;

  Statistics stats = emf.unwrap(SessionFactory.class).getStatistics();
  System.out.println("Queries executed: " + stats.getQueryExecutionCount());
  System.out.println("Entity loads: " + stats.getEntityLoadCount());
  System.out.println("2L cache hit ratio: " + stats.getSecondLevelCacheHitCount());
  stats.logSummary();

Or use Micrometer / Actuator for production monitoring.

Q: What is Hibernate and how does it relate to JPA?
A: Hibernate is an ORM framework that implements the JPA specification.
   JPA defines the standard API (interfaces and annotations); Hibernate
   provides the implementation. Spring Boot uses Hibernate as the default
   JPA provider.

Q: What are some features Hibernate provides beyond JPA?
A: First/second-level caching, @NaturalId, Envers (audit), soft delete
   (@SQLDelete/@Where), @Filter for dynamic WHERE clauses, batch processing
   configuration, Statistics API, and Hibernate-specific HQL extensions.

Q: How do you access Hibernate-specific features when using JPA API?
A: Unwrap the Hibernate session from the EntityManager:
   Session session = entityManager.unwrap(Session.class);
   Then use Hibernate-specific methods on the Session.

Q: What is a Hibernate dialect?
A: A class that tells Hibernate which SQL features the database supports
   and how to generate DB-specific SQL. Spring Boot 3 auto-detects it
   from the JDBC URL, but you can set it manually via
   spring.jpa.properties.hibernate.dialect.
