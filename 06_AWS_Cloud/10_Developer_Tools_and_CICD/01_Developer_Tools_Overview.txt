1. DEVELOPER TOOLS OVERVIEW
================================================================

  AWS provides a fully managed CI/CD toolchain:
  
  ┌──────────────────┬────────────────────────────────────────────────┐
  │ Service          │ Purpose                                        │
  ├──────────────────┼────────────────────────────────────────────────┤
  │ CodeCommit       │ Managed Git repository (deprecated 2024)       │
  │ CodeBuild        │ Managed build and test service                 │
  │ CodeDeploy       │ Automated application deployment               │
  │ CodePipeline     │ Orchestrate CI/CD workflows                    │
  │ CodeArtifact     │ Managed artifact repository (Maven/npm/PyPI)   │
  │ CloudFormation   │ Infrastructure as Code (IaC)                   │
  │ CDK              │ Define IaC with programming languages (Java)   │
  │ SAM              │ Serverless Application Model (Lambda/API GW)   │
  └──────────────────┴────────────────────────────────────────────────┘

2. CI/CD PIPELINE OVERVIEW
================================================================

  TYPICAL AWS CI/CD PIPELINE:
  
  Developer → GitHub/GitLab (source) → CodePipeline
  
  Stage 1: SOURCE
    → GitHub, CodeCommit, S3, ECR
  
  Stage 2: BUILD (CodeBuild)
    → mvn package / docker build
    → Unit tests, code coverage
    → Security scans (SAST)
    → Push artifact to S3 or Docker image to ECR
  
  Stage 3: TEST
    → Integration tests (CodeBuild)
    → Load tests
    → DAST security scans
  
  Stage 4: DEPLOY (CodeDeploy or CloudFormation or ECS Deploy)
    → Deploy to staging
    → Smoke tests
  
  Stage 5: APPROVAL
    → Manual approval gate before production
  
  Stage 6: DEPLOY PRODUCTION
    → Blue/Green or canary deployment
    → Automated rollback on CloudWatch alarm

3. CODECOMMIT (NOTE: DEPRECATED JULY 2024)
================================================================

  AWS announced no new customers for CodeCommit in July 2024.
  Existing customers can continue using it.
  
  For interviews: Know CodeCommit was a managed Git service 
  (S3-backed, IAM authentication, HTTPS/SSH). The replacement 
  is using GitHub, GitLab, or Bitbucket as source in CodePipeline.

4. CODEARTIFACT
================================================================

  Managed software artifact repository for:
    - Maven / Gradle (Java)
    - npm (JavaScript)
    - PyPI (Python)
    - NuGet (.NET)
  
  USE CASES:
    - Proxy/cache public repositories (Maven Central, npm)
    - Store internal packages
    - Enforce use of approved packages (block direct internet access)
  
  Configure Maven to use CodeArtifact:
  # Get auth token (expires in 12 hours)
  export CODEARTIFACT_TOKEN=$(aws codeartifact get-authorization-token \
    --domain my-domain \
    --domain-owner 123456789012 \
    --query authorizationToken \
    --output text)
  
  # settings.xml
  <server>
    <id>codeartifact</id>
    <username>aws</username>
    <password>${env.CODEARTIFACT_TOKEN}</password>
  </server>

5. INTERVIEW QUESTIONS (OVERVIEW)
================================================================

Q: What is the difference between CodeBuild and CodeDeploy?
A: CodeBuild compiles source code, runs tests, and produces artifacts (JAR, Docker image).
   It runs on managed build servers — you pay per build minute, no servers to manage.
   
   CodeDeploy takes an already-built artifact and deploys it to compute resources 
   (EC2, Lambda, ECS). It manages deployment strategies (rolling, blue/green) and 
   handles rollback on failure.
   
   In a pipeline: CodeBuild runs first to produce the artifact → CodeDeploy takes 
   that artifact and deploys it. They are complementary, not alternatives.

Q: Why would you use CodeArtifact instead of downloading directly from Maven Central?
A: (1) Security: scan packages before use, block unapproved packages, meet compliance 
   requirements (SBOM). (2) Availability: if Maven Central is down, cached packages 
   are still available in CodeArtifact. (3) Cost control: reduce internet data transfer 
   costs — packages cached in same region. (4) IAM access control: only IAM-authorized 
   services can pull packages. (5) Audit: CodeTrail logs every package download. 
   Combine with VPC interface endpoints to ensure traffic never leaves AWS network.
