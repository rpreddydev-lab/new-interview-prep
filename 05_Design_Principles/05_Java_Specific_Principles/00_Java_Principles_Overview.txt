================================================================
  JAVA-SPECIFIC PRINCIPLES — OVERVIEW
================================================================

  These principles apply generally to OOP but are especially
  important, concrete, and frequently tested in Java interviews.

================================================================
QUICK REFERENCE
================================================================

  Principle                           Core Idea
  ----------------------------------  ---------------------------------
  Program to Interface                Declare types as interfaces/abstract
                                      not concrete classes
  Favor Immutability                  Objects that cannot change after
                                      construction are thread-safe and
                                      predictable
  Effective Java Key Items            Joshua Bloch's canonical Java idioms:
                                      static factory, builder, singleton enum,
                                      composition, generics, lambdas
  Java Naming Conventions             camelCase/PascalCase/ALL_CAPS rules
                                      for classes, methods, constants
  Fail Fast                           Validate inputs at the earliest
                                      possible point and throw immediately
  Checked vs Unchecked Exceptions     When to use which; Joshua Bloch's
                                      guidance on exception design

================================================================
WHY JAVA-SPECIFIC?
================================================================

  Java's type system, generics, exceptions, and idioms create
  specific opportunities and pitfalls that don't appear in all languages.

  An interviewer asking "Java best practices" expects knowledge of:
  - The interface/implementation distinction (polymorphism properly used)
  - Java memory model implications of mutability
  - The exception model (checked vs unchecked decision)
  - Language-level idioms (records, Optional, streams, lambdas)
  - Effective Java recommendations (widely known as canonical Java wisdom)

================================================================
INTERVIEW FREQUENCY
================================================================

  Very High:  Program to Interface, Fail Fast, Exception design
  High:       Immutability, Effective Java items (Builder, static factory)
  Medium:     Naming conventions (usually a side-note in code reviews)
