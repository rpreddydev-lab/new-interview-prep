INTEGRATION TESTING — WIREMOCK: TESTING EXTERNAL SERVICES
Complete Interview Preparation Guide
================================================================

1. WHAT IS WIREMOCK?
================================================================

WireMock is a mock HTTP server for testing services that call external APIs.
It intercepts outbound HTTP calls and returns pre-configured responses.

Real Scenario:
  OrderService ──calls──► PaymentGateway API (external)
  In tests:
  OrderService ──calls──► WireMock server (returns stubbed response)

Benefits:
  - No real external calls in tests (fast, isolated, deterministic)
  - Simulate any HTTP response (200, 500, timeout, connection error)
  - Verify that your service makes the correct HTTP requests
  - Support for stateful stubs (simulate workflows)

3. BASIC SETUP — @WireMockTest
================================================================

  @SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
  @WireMockTest(httpPort = 8089)  // fixed port, or use random with @WireMockTest
  class PaymentGatewayClientTest {
      
      @Autowired PaymentGatewayClient paymentClient;
      
      @Test
      void shouldChargeCardSuccessfully() {
          // Stub: when POST /v1/charges → return 200 with JSON
          stubFor(post(urlEqualTo("/v1/charges"))
              .withHeader("Authorization", matching("Bearer .*"))
              .withRequestBody(containing("\"amount\":1000"))
              .willReturn(aResponse()
                  .withStatus(200)
                  .withHeader("Content-Type", "application/json")
                  .withBody("""
                      {
                          "id": "ch_test_123",
                          "status": "succeeded",
                          "amount": 1000
                      }
                  """)
              )
          );
          
          // Act
          ChargeResponse response = paymentClient.charge(new ChargeRequest("tok_visa", 1000));
          
          // Assert response
          assertEquals("ch_test_123", response.getId());
          assertEquals("succeeded", response.getStatus());
          
          // Verify the request WAS made exactly once
          verify(exactly(1), postRequestedFor(urlEqualTo("/v1/charges"))
              .withRequestBody(matchingJsonPath("$.currency", equalTo("USD")))
          );
      }
  }

4. URL AND BODY MATCHING
================================================================

  // Exact URL
  stubFor(get(urlEqualTo("/api/users/42")))
  
  // URL pattern (regex)
  stubFor(get(urlMatching("/api/users/[0-9]+")))
  
  // URL path + query params
  stubFor(get(urlPathEqualTo("/api/products"))
      .withQueryParam("category", equalTo("electronics"))
      .withQueryParam("limit", matching("[0-9]+"))
  )
  
  // Request body patterns
  stubFor(post(urlEqualTo("/api/orders"))
      .withRequestBody(equalToJson("""
          {"productId": "P-1", "quantity": 3}
      """))                                  // exact JSON match
      .withRequestBody(matchingJsonPath("$.productId"))   // JSON path exists
      .withRequestBody(matchingJsonPath("$.quantity", equalTo(3)))  // JSON path value
      .withRequestBody(containing("productId"))           // substring
      .withRequestBody(matchingJsonPath("$.items[?(@.sku == 'SKU-001')]"))  // JSONPath expr
  )
  
  // Header matching
  stubFor(post(anyUrl())
      .withHeader("Content-Type", containing("application/json"))
      .withHeader("X-Api-Key", equalTo("test-key-123"))
  )

5. RESPONSE CONFIGURATION
================================================================

  // 200 OK with JSON body
  .willReturn(ok().withBody(jsonBody).withHeader("Content-Type", "application/json"))
  
  // Using okJson shorthand
  .willReturn(okJson("""{"status": "ok"}"""))
  
  // Custom status code
  .willReturn(aResponse().withStatus(422).withBody("""{"error": "invalid_card"}"""))
  
  // 404 Not Found
  .willReturn(notFound())
  
  // 503 Service Unavailable
  .willReturn(serviceUnavailable())
  
  // With delay (simulate slow external service)
  .willReturn(aResponse()
      .withStatus(200)
      .withFixedDelay(2000)    // 2 second delay
      .withBody("{\"ok\": true}")
  )
  
  // Random delay (more realistic)
  .willReturn(aResponse()
      .withStatus(200)
      .withRandomDelay(new UniformDistribution(100, 500))
      .withBody("{\"ok\": true}")
  )
  
  // Connection reset (simulate network failure)
  .willReturn(aResponse().withFault(Fault.CONNECTION_RESET_BY_PEER))
  
  // Empty response (simulate malformed response)
  .willReturn(aResponse().withFault(Fault.EMPTY_RESPONSE))

6. VERIFYING OUTBOUND REQUESTS
================================================================

  // Verify a POST was made exactly once
  verify(exactly(1), postRequestedFor(urlEqualTo("/api/charges")));
  
  // Verify at least once
  verify(moreThanOrExactly(1), getRequestedFor(urlMatching("/api/products/.*")));
  
  // Verify with specific headers/body
  verify(exactly(1), postRequestedFor(urlEqualTo("/api/orders"))
      .withHeader("Authorization", matching("Bearer .*"))
      .withRequestBody(matchingJsonPath("$.amount", equalTo(1500)))
  );
  
  // Verify no calls were made
  verify(0, getRequestedFor(urlEqualTo("/api/private")));
  
  // Get all requests made (for custom assertions)
  List<LoggedRequest> requests = findAll(postRequestedFor(urlEqualTo("/api/charges")));
  assertEquals(1, requests.size());
  String body = requests.get(0).getBodyAsString();
  assertTrue(body.contains("\"currency\":\"USD\""));

7. FULL INTEGRATION TEST EXAMPLE
================================================================

  @SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
  @WireMockTest(httpPort = 9090)
  class OrderCheckoutServiceIT {
      
      @Autowired OrderCheckoutService checkoutService;
      @Autowired OrderRepository orderRepository;
      
      @BeforeEach
      void setup() {
          // stub inventory check
          stubFor(get(urlMatching("/api/inventory/.*"))
              .willReturn(okJson("""
                  {"sku": "SKU-001", "available": 10}
              """))
          );
          
          // stub payment charge
          stubFor(post(urlEqualTo("/api/payments/charge"))
              .willReturn(okJson("""
                  {"chargeId": "ch_test_999", "status": "CAPTURED"}
              """))
          );
      }
      
      @Test
      void shouldCompleteCheckoutSuccessfully() {
          CheckoutRequest req = new CheckoutRequest("cust-1", "SKU-001", 2, 5000);
          
          CheckoutResult result = checkoutService.checkout(req);
          
          // Verify response
          assertTrue(result.isSuccess());
          assertEquals("ch_test_999", result.getChargeId());
          
          // Verify order persisted
          Optional<Order> saved = orderRepository.findByChargeId("ch_test_999");
          assertTrue(saved.isPresent());
          
          // Verify outbound calls were made correctly
          verify(getRequestedFor(urlEqualTo("/api/inventory/SKU-001")));
          
          verify(postRequestedFor(urlEqualTo("/api/payments/charge"))
              .withRequestBody(matchingJsonPath("$.amount", equalTo(5000)))
              .withRequestBody(matchingJsonPath("$.currency", equalTo("USD")))
          );
      }
      
      @Test
      void shouldHandlePaymentFailure() {
          // Override payment stub to fail
          stubFor(post(urlEqualTo("/api/payments/charge"))
              .willReturn(aResponse()
                  .withStatus(402)
                  .withBody("""{"error": "card_declined"}""")
              )
          );
          
          CheckoutRequest req = new CheckoutRequest("cust-1", "SKU-001", 1, 1000);
          
          assertThrows(PaymentFailedException.class, () -> checkoutService.checkout(req));
          
          // Verify no order was persisted
          assertEquals(0, orderRepository.count());
      }
      
      @Test
      void shouldHandleSlowPaymentGateway() {
          // Stub with 3 second delay — assuming timeout is 2 seconds
          stubFor(post(urlEqualTo("/api/payments/charge"))
              .willReturn(aResponse()
                  .withStatus(200)
                  .withFixedDelay(3000)
                  .withBody("""{"chargeId": "ch_slow"}""")
              )
          );
          
          CheckoutRequest req = new CheckoutRequest("cust-1", "SKU-001", 1, 1000);
          
          assertThrows(PaymentTimeoutException.class, () -> checkoutService.checkout(req));
      }
  }

8. STATEFUL STUBS — SCENARIOS
================================================================

Simulate workflows where the response changes across calls.

  @Test
  void shouldRetryOnTransientFailureThenSucceed() {
      // First call: 503
      // Second call: 200
      stubFor(post(urlEqualTo("/api/payments/charge"))
          .inScenario("payment-retry")
          .whenScenarioStateIs(Scenario.STARTED)  // initial state
          .willReturn(serviceUnavailable())
          .willSetStateTo("RETRY")
      );
      
      stubFor(post(urlEqualTo("/api/payments/charge"))
          .inScenario("payment-retry")
          .whenScenarioStateIs("RETRY")
          .willReturn(okJson("""{"chargeId": "ch_retry_ok", "status": "CAPTURED"}"""))
      );
      
      // Service has retry logic: should succeed on 2nd attempt
      ChargeResponse response = paymentClient.chargeWithRetry(new ChargeRequest(1000));
      
      assertEquals("ch_retry_ok", response.getChargeId());
      
      // Verify exactly 2 POST calls were made
      verify(exactly(2), postRequestedFor(urlEqualTo("/api/payments/charge")));
  }

9. WIREMOCK WITH @SpringBootTest AND @DynamicPropertySource
================================================================

  @SpringBootTest
  @AutoConfigureWireMock(port = 0)  // random port
  class PaymentClientAutoWireMockTest {
      
      @Value("${wiremock.server.port}") int wireMockPort;
      
      @DynamicPropertySource
      static void properties(DynamicPropertyRegistry reg) {
          reg.add("payment.api.base-url", 
              () -> "http://localhost:" + wireMockPort);
      }
      
      // tests...
  }
  
  // OR with manual WireMockServer
  class PaymentClientTest {
      
      private static WireMockServer wireMockServer;
      
      @BeforeAll
      static void startWireMock() {
          wireMockServer = new WireMockServer(wireMockConfig().dynamicPort());
          wireMockServer.start();
          WireMock.configureFor(wireMockServer.port());
      }
      
      @AfterAll
      static void stopWireMock() {
          wireMockServer.stop();
      }
      
      @AfterEach
      void resetStubs() {
          wireMockServer.resetAll();
      }
  }

10. LOADING STUB MAPPINGS FROM JSON FILES
================================================================

  src/test/resources/
    __files/
      payment-success-response.json   ← response body files
    mappings/
      payment-charge.json             ← stub mapping files (auto-loaded)

  payment-charge.json:
  {
    "request": {
      "method": "POST",
      "url": "/api/payments/charge",
      "bodyPatterns": [
        {"matchesJsonPath": "$.amount"}
      ]
    },
    "response": {
      "status": 200,
      "bodyFileName": "payment-success-response.json",
      "headers": {
        "Content-Type": "application/json"
      }
    }
  }
  
  // Load from body file in code
  stubFor(post(urlEqualTo("/api/charge"))
      .willReturn(aResponse()
          .withBodyFile("payment-success-response.json")  // from __files/
          .withHeader("Content-Type", "application/json")
      )
  );

11. INTERVIEW QUESTIONS
================================================================

Q: What problem does WireMock solve?
A: When your service calls external APIs (payment gateways, notification
   services, third-party APIs), tests can't depend on those real services
   (flaky, slow, costly). WireMock starts a real HTTP server that intercepts
   those calls and returns pre-configured responses.

Q: How do you verify that your service made the correct HTTP request?
A: WireMock records all incoming requests. Use verify() with request matchers:
   verify(exactly(1), postRequestedFor(urlEqualTo("/api/charge"))
       .withRequestBody(matchingJsonPath("$.amount", equalTo(1500))));

Q: How do you test a retry mechanism with WireMock?
A: Use WireMock Scenarios (stateful stubs). Define that the first call returns
   503 and transitions to "RETRY" state, then the second call (in "RETRY"
   state) returns 200. Verify exactly 2 calls were made.

Q: How do you simulate network failures with WireMock?
A: Use .willReturn(aResponse().withFault(Fault.CONNECTION_RESET_BY_PEER)) 
   for connection reset. Use .withFixedDelay() to simulate timeouts.
   Use .withFault(Fault.EMPTY_RESPONSE) for malformed responses.

Q: What is the difference between @WireMockTest and @AutoConfigureWireMock?
A: @WireMockTest is from wiremock-spring-boot and provides a clean, modern
   Spring Boot integration. @AutoConfigureWireMock is Spring Cloud Contract's
   WireMock integration. Both start a WireMock server and inject the port.
   The key difference is the dependency and slight configuration differences.

Q: How do you inject the WireMock port into Spring Boot's application context?
A: Use @DynamicPropertySource to set the external service URL to point to
   WireMock's host:port. For @WireMockTest, the port is available as
   ${wiremock.server.port}. The application.yml would reference this via
   property placeholders.
