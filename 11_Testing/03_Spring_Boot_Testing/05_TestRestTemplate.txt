Complete Interview Preparation Guide

1. WHAT IS TestRestTemplate?
================================================================

TestRestTemplate is a REST client for integration tests that make REAL
HTTP requests to an embedded server.

Key characteristics:
  - Works with @SpringBootTest(webEnvironment = RANDOM_PORT or DEFINED_PORT)
  - Wraps RestTemplate with test-friendly defaults
  - Does NOT follow redirects by default (testable 3xx responses)
  - Does NOT throw exceptions for 4xx/5xx responses (returns ResponseEntity)
  - Auto-configured by Spring Boot when webEnvironment is set

When to use TestRestTemplate vs MockMvc:
  
  TestRestTemplate:
    ✅ Real HTTP stack (serialization, HTTP headers, cookies)
    ✅ Can test response codes 4xx/5xx without exceptions
    ✅ Tests the complete HTTP pipeline
    ✅ Good for end-to-end API contract tests
    ❌ Slower — starts a real embedded server
    ❌ Cannot inspect internal MVC model/view
  
  MockMvc:
    ✅ No real server — faster
    ✅ Can inspect model, view, handler info
    ✅ Spring Security easier to configure
    ❌ Does not test real HTTP serialization pipeline
    ❌ Requires @WebMvcTest or @SpringBootTest + @AutoConfigureMockMvc

2. BASIC SETUP
================================================================

  @SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
  class UserApiIT {
      
      @LocalServerPort
      int port;  // randomly assigned port
      
      @Autowired
      TestRestTemplate restTemplate;  // auto-configured
      
      @MockBean EmailService emailService;  // mock external dependencies
      
      private String baseUrl;
      
      @BeforeEach
      void setUp() {
          baseUrl = "http://localhost:" + port + "/api/v1";
      }
  }

OR use the helper base URL:
  @SpringBootTest(webEnvironment = WebEnvironment.RANDOM_PORT)
  class UserApiIT {
      
      @Autowired TestRestTemplate restTemplate;
      // TestRestTemplate already knows the base URL (localhost:randomPort)
      
      @Test
      void shouldGetUser() {
          // No need to prefix with localhost:port — it's included automatically
          ResponseEntity<UserDto> response = restTemplate.getForEntity(
              "/api/v1/users/user-1", UserDto.class
          );
      }
  }

3. GET REQUESTS
================================================================

  @Test
  void getUser_shouldReturn200WithUserData() {
      ResponseEntity<UserDto> response = restTemplate.getForEntity(
          "/api/v1/users/{id}", UserDto.class, "user-1"
      );
      
      assertEquals(HttpStatus.OK, response.getStatusCode());
      assertNotNull(response.getBody());
      assertEquals("user-1", response.getBody().getId());
      assertEquals("alice@test.com", response.getBody().getEmail());
  }
  
  @Test
  void getUser_shouldReturn404WhenNotFound() {
      ResponseEntity<ErrorResponse> response = restTemplate.getForEntity(
          "/api/v1/users/nonexistent", ErrorResponse.class
      );
      
      assertEquals(HttpStatus.NOT_FOUND, response.getStatusCode());
      assertEquals("USER_NOT_FOUND", response.getBody().getCode());
  }

GET WITH QUERY PARAMETERS:
  @Test
  void searchUsers_shouldReturnPagedResults() {
      String url = "/api/v1/users?role=ADMIN&page=0&size=10";
      
      ResponseEntity<PageResponse<UserDto>> response = restTemplate.exchange(
          url,
          HttpMethod.GET,
          null,
          new ParameterizedTypeReference<PageResponse<UserDto>>() {}
      );
      
      assertEquals(HttpStatus.OK, response.getStatusCode());
      assertNotNull(response.getBody());
      assertTrue(response.getBody().getContent().stream()
          .allMatch(u -> u.getRole().equals("ADMIN")));
  }

GET OBJECT DIRECTLY (throws if not 200):
  UserDto user = restTemplate.getForObject("/api/v1/users/user-1", UserDto.class);
  assertEquals("alice@test.com", user.getEmail());

DELETE:
  @Test
  void deleteUser_shouldReturn204() {
      ResponseEntity<Void> response = restTemplate.exchange(
          "/api/v1/users/{id}",
          HttpMethod.DELETE,
          null,
          Void.class,
          "user-1"
      );
      
      assertEquals(HttpStatus.NO_CONTENT, response.getStatusCode());

          "/api/v1/users/user-1", UserDto.class

      assertEquals(HttpStatus.NOT_FOUND, getResponse.getStatusCode());

6. AUTHENTICATION — BASIC AUTH AND BEARER TOKEN
================================================================

BASIC AUTH:
  @SpringBootTest(webEnvironment = RANDOM_PORT)
  class AdminApiIT {
      
      @Autowired TestRestTemplate restTemplate;
      
      TestRestTemplate adminTemplate;
      TestRestTemplate userTemplate;
      
      @BeforeEach
      void setUp() {
          // Create pre-authenticated templates
          adminTemplate = restTemplate.withBasicAuth("admin@test.com", "admin-password");
          userTemplate = restTemplate.withBasicAuth("user@test.com", "user-password");
      }
      
      @Test
      void adminEndpoint_shouldReturn200ForAdmin() {
          ResponseEntity<String> response = adminTemplate.getForEntity(
              "/api/v1/admin/stats", String.class
          );
          assertEquals(HttpStatus.OK, response.getStatusCode());
      }
      
      @Test
      void adminEndpoint_shouldReturn403ForRegularUser() {
          ResponseEntity<String> response = userTemplate.getForEntity(
              "/api/v1/admin/stats", String.class
          );
          assertEquals(HttpStatus.FORBIDDEN, response.getStatusCode());
      }
  }

BEARER TOKEN:
  private HttpHeaders bearerTokenHeaders(String token) {
      HttpHeaders headers = new HttpHeaders();
      headers.setBearerAuth(token);
      headers.setContentType(MediaType.APPLICATION_JSON);
      return headers;
  }
  
  @Test
  void securedEndpoint_shouldReturn200WithValidToken() {
      String token = jwtService.generateToken("alice@test.com", List.of("ROLE_USER"));
      
      ResponseEntity<UserDto> response = restTemplate.exchange(
          "/api/v1/profile",
          HttpMethod.GET,
          new HttpEntity<>(bearerTokenHeaders(token)),
          UserDto.class
      );
      
      assertEquals(HttpStatus.OK, response.getStatusCode());
  }
  
  @Test
  void securedEndpoint_shouldReturn401WithoutToken() {
      ResponseEntity<ErrorResponse> response = restTemplate.getForEntity(
          "/api/v1/profile", ErrorResponse.class
      );
      assertEquals(HttpStatus.UNAUTHORIZED, response.getStatusCode());
  }

      );
      
      assertFalse(response.getBody().isEmpty());
  }
  
  @Test
  void searchUsers_shouldReturnPage() {
      ResponseEntity<RestPage<UserDto>> response = restTemplate.exchange(
          "/api/v1/users?page=0&size=10",
          HttpMethod.GET,
          null,
          new ParameterizedTypeReference<RestPage<UserDto>>() {}
      );
      
      assertEquals(HttpStatus.OK, response.getStatusCode());
      assertNotNull(response.getBody().getContent());
  }
  
  // Helper class for deserialization of Spring Page:
  @JsonIgnoreProperties(ignoreUnknown = true)
  public static class RestPage<T> extends PageImpl<T> {
      @JsonCreator(mode = JsonCreator.Mode.PROPERTIES)
      public RestPage(@JsonProperty("content") List<T> content,
                      @JsonProperty("number") int number,
                      @JsonProperty("size") int size,
                      @JsonProperty("totalElements") Long totalElements) {
          super(content, PageRequest.of(number, size), totalElements);
      }
  }

8. END-TO-END FLOW TEST
================================================================

  @SpringBootTest(webEnvironment = WebEnvironment.RANDOM_PORT)
  @ActiveProfiles("test")
  @Testcontainers
  class OrderFlowIT {
      
      @Container
      static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:15");
      
      @DynamicPropertySource
      static void datasourceProps(DynamicPropertyRegistry r) {
          r.add("spring.datasource.url", postgres::getJdbcUrl);
          r.add("spring.datasource.username", postgres::getUsername);
          r.add("spring.datasource.password", postgres::getPassword);
      }
      
      @Autowired TestRestTemplate restTemplate;
      @MockBean PaymentGateway paymentGateway;
      @MockBean EmailService emailService;
      
      @BeforeEach
      void setUp() {
          when(paymentGateway.charge(any())).thenReturn(PaymentResult.success("ch_123"));
      }
      
      @Test
      void completeOrderFlow() {
          // 1. Create user
          CreateUserRequest userReq = new CreateUserRequest("alice@test.com", "Alice");
          ResponseEntity<UserDto> userResponse = restTemplate.postForEntity(
              "/api/v1/users", userReq, UserDto.class);
          assertEquals(HttpStatus.CREATED, userResponse.getStatusCode());
          String userId = userResponse.getBody().getId();
          
          // 2. Create cart
          ResponseEntity<CartDto> cartResponse = restTemplate.postForEntity(
              "/api/v1/users/{userId}/cart", 
              new AddToCartRequest("SKU-001", 2), 
              CartDto.class, userId);
          assertEquals(HttpStatus.OK, cartResponse.getStatusCode());
          
          // 3. Place order
          ResponseEntity<OrderDto> orderResponse = restTemplate.postForEntity(
              "/api/v1/orders",
              new PlaceOrderRequest(userId, "pm_card_visa"),
              OrderDto.class);
          assertEquals(HttpStatus.CREATED, orderResponse.getStatusCode());
          
          String orderId = orderResponse.getBody().getId();
          assertEquals("CONFIRMED", orderResponse.getBody().getStatus());
          
          // 4. Verify order persisted
          ResponseEntity<OrderDto> getOrder = restTemplate.getForEntity(
              "/api/v1/orders/{orderId}", OrderDto.class, orderId);
          assertEquals(HttpStatus.OK, getOrder.getStatusCode());
          assertEquals("CONFIRMED", getOrder.getBody().getStatus());
          
          // 5. Verify mocks called correctly
          verify(paymentGateway).charge(any());
          verify(emailService).sendOrderConfirmation(eq(userId), anyString());
      }
  }

9. INTERVIEW QUESTIONS
================================================================

Q: What is TestRestTemplate and when should you use it?
A: TestRestTemplate is a convenience wrapper around RestTemplate for use
   in @SpringBootTest integration tests. It makes real HTTP requests to
   the embedded server. Use it when you want to test the complete HTTP
   pipeline — real serialization, real headers, real status codes.

Q: What is the difference between TestRestTemplate and MockMvc?
A: MockMvc dispatches to Spring's DispatcherServlet without a real server.
   TestRestTemplate makes real HTTP requests to an embedded server.
   MockMvc is faster; TestRestTemplate tests the full stack.

Q: Why doesn't TestRestTemplate throw exceptions for 4xx/5xx responses?
A: It's designed for testing. Unlike RestTemplate which throws
   HttpClientErrorException for 4xx, TestRestTemplate returns a
   ResponseEntity with the error status and body so you can assert on it.

Q: How do you test authenticated endpoints with TestRestTemplate?
A: Use restTemplate.withBasicAuth(username, password) to create a
   pre-authenticated template for basic auth.
   For JWT/Bearer, use an HttpEntity with Authorization header.

Q: How do you deserialize a Spring Page<T> response in TestRestTemplate?
A: Spring's PageImpl doesn't have a Jackson-compatible constructor.
   Create a custom RestPage<T> class that extends PageImpl<T> with
   @JsonCreator constructor, and use ParameterizedTypeReference.

Q: What is @LocalServerPort?
A: It injects the port number that the embedded server is running on.
   Used with WebEnvironment.RANDOM_PORT to construct base URLs.
   The TestRestTemplate auto-configures itself with this port.
