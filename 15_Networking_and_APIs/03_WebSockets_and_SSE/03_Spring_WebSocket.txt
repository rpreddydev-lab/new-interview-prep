SPRING WEBSOCKET MODULE
------------------------
Spring provides two levels of WebSocket abstraction:
  1. Low-level WebSocket API (@EnableWebSocket + WebSocketHandler)
  2. High-level messaging with STOMP over WebSocket (@EnableWebSocketMessageBroker)

The STOMP-based approach is recommended for most applications because it adds
messaging semantics (publish/subscribe, point-to-point, message routing) on top
of the raw WebSocket connection.

================================================================================
1. RAW WEBSOCKET API (without STOMP)
================================================================================

HANDLER:
  public class RawWebSocketHandler extends AbstractWebSocketHandler {

      private static final Map<String, WebSocketSession> SESSIONS = 
          new ConcurrentHashMap<>();

      @Override
      public void afterConnectionEstablished(WebSocketSession session) {
          // Extract auth info from handshake
          URI uri = session.getUri();
          String userId = extractUserId(session);
          SESSIONS.put(userId, session);
          
          sendMessage(session, Map.of("type", "connected", "sessionId", session.getId()));
      }

      @Override
      protected void handleTextMessage(WebSocketSession session, TextMessage message) 
              throws Exception {
          String payload = message.getPayload();
          IncomingMessage msg = objectMapper.readValue(payload, IncomingMessage.class);
          
          switch (msg.getType()) {
              case "ping" -> sendMessage(session, Map.of("type", "pong"));
              case "echo" -> sendMessage(session, Map.of("type", "echo", "data", msg.getData()));
              default    -> sendMessage(session, Map.of("type", "error", "code", "UNKNOWN_TYPE"));
          }
      }

      @Override
      protected void handleBinaryMessage(WebSocketSession session, BinaryMessage message) {
          ByteBuffer buf = message.getPayload();
          // Handle binary data
      }

      @Override
      public void afterConnectionClosed(WebSocketSession session, CloseStatus status) {
          SESSIONS.values().remove(session);
      }

      @Override
      public void handleTransportError(WebSocketSession session, Throwable exception) {
          log.error("Transport error for session {}", session.getId(), exception);
          SESSIONS.values().remove(session);
      }

      public void sendToUser(String userId, Object payload) {
          WebSocketSession session = SESSIONS.get(userId);
          if (session != null && session.isOpen()) {
              sendMessage(session, payload);
          }
      }

      public void broadcast(Object payload) {
          String json = toJson(payload);
          SESSIONS.values().stream()
              .filter(WebSocketSession::isOpen)
              .forEach(s -> {
                  try { s.sendMessage(new TextMessage(json)); }
                  catch (IOException e) { /* remove from map */ }
              });
      }

      private void sendMessage(WebSocketSession session, Object payload) {
          try {
              session.sendMessage(new TextMessage(objectMapper.writeValueAsString(payload)));
          } catch (IOException e) {
              log.error("Failed to send message to session {}", session.getId(), e);
          }
      }
  }

CONFIGURATION:
  @Configuration
  @EnableWebSocket
  public class RawWebSocketConfig implements WebSocketConfigurer {

      @Override
      public void registerWebSocketHandlers(WebSocketHandlerRegistry registry) {
          registry.addHandler(rawWebSocketHandler(), "/ws")
              .addInterceptors(authHandshakeInterceptor())
              .setAllowedOriginPatterns("https://*.example.com");
          
          // SockJS fallback
          registry.addHandler(rawWebSocketHandler(), "/ws-sockjs")
              .addInterceptors(authHandshakeInterceptor())
              .withSockJS()
              .setHeartbeatTime(25_000);
      }

      @Bean public RawWebSocketHandler rawWebSocketHandler() {
          return new RawWebSocketHandler();
      }
  }

HANDSHAKE INTERCEPTOR (extract auth):
  @Component
  public class AuthHandshakeInterceptor implements HandshakeInterceptor {

      @Override
      public boolean beforeHandshake(ServerHttpRequest request, ServerHttpResponse response,
              WebSocketHandler wsHandler, Map<String, Object> attributes) {
          
          // Extract JWT from query param
          String query = request.getURI().getQuery(); // "token=eyJhb..."
          String token = extractToken(query);
          
          try {
              Claims claims = jwtService.validateToken(token);
              attributes.put("userId", claims.getSubject());
              attributes.put("roles", claims.get("roles"));
              return true; // allow connection
          } catch (JwtException e) {
              response.setStatusCode(HttpStatus.UNAUTHORIZED);
              return false; // reject connection
          }
      }

      @Override
      public void afterHandshake(...) { }
  }

2. STOMP OVER WEBSOCKET (Recommended)
================================================================================

STOMP adds messaging semantics:
  /app/*   → messages routed to @MessageMapping methods
  /topic/* → pub/sub broadcast to all subscribers
  /queue/* → point-to-point (user-specific) messages
  /user/*  → prefix for user-specific destinations

CONFIGURATION:
  @Configuration
  @EnableWebSocketMessageBroker
  public class StompWebSocketConfig implements WebSocketMessageBrokerConfigurer {

      @Override
      public void configureMessageBroker(MessageBrokerRegistry registry) {
          // Enable simple in-memory broker for /topic and /queue
          registry.enableSimpleBroker("/topic", "/queue")
              .setHeartbeatValue(new long[]{10_000, 10_000})
              .setTaskScheduler(heartbeatScheduler());
          
          // Client messages to /app/* are routed to @MessageMapping methods
          registry.setApplicationDestinationPrefixes("/app");
          
          // User-specific messages (for SimpMessagingTemplate.convertAndSendToUser)
          registry.setUserDestinationPrefix("/user");
      }

      @Override
      public void registerStompEndpoints(StompEndpointRegistry registry) {
          registry.addEndpoint("/ws-stomp")
              .setAllowedOriginPatterns("https://*.example.com")
              .addInterceptors(authHandshakeInterceptor())
              .withSockJS();
      }

      @Override
      public void configureClientInboundChannel(ChannelRegistration registration) {
          // Add security / auth interceptor for STOMP messages
          registration.interceptors(stompAuthInterceptor());
      }

      @Bean
      public TaskScheduler heartbeatScheduler() {
          return new ThreadPoolTaskScheduler();
      }
  }

3. MESSAGING CONTROLLERS
================================================================================

  @Controller
  public class ChatController {

      private final SimpMessagingTemplate messagingTemplate;

      // Broadcast: all subscribers of /topic/chat receive this
      @MessageMapping("/chat.send")           // client sends to /app/chat.send
      @SendTo("/topic/chat")                  // server broadcasts to /topic/chat
      public ChatMessage handleMessage(ChatMessage message, Principal principal) {
          message.setSender(principal.getName());
          message.setTimestamp(Instant.now());
          return message;
      }

      // Point-to-point: only recipient on /user/{userId}/queue/private
      @MessageMapping("/chat.private")
      public void handlePrivateMessage(PrivateMessage message, Principal principal) {
          // Send to specific user
          messagingTemplate.convertAndSendToUser(
              message.getRecipientId(),          // user ID
              "/queue/private",                  // destination suffix
              new PrivateMessage(principal.getName(), message.getContent())
          );
      }

      // Exception handling in @MessageMapping methods
      @MessageExceptionHandler
      @SendToUser("/queue/errors")
      public ErrorResponse handleException(Exception ex) {
          return new ErrorResponse(ex.getMessage());
      }
  }

  // Broadcast from anywhere in the application (e.g., from a service)
  @Service
  public class NotificationService {

      private final SimpMessagingTemplate messagingTemplate;

      public void notifyAll(String event, Object payload) {
          messagingTemplate.convertAndSend("/topic/notifications",
              Map.of("event", event, "data", payload));
      }

      public void notifyUser(String userId, String event, Object payload) {
          messagingTemplate.convertAndSendToUser(userId, "/queue/notifications",
              Map.of("event", event, "data", payload));
      }
  }

4. STOMP AUTH INTERCEPTOR
================================================================================

  @Component
  public class StompAuthInterceptor implements ChannelInterceptor {

      @Override
      public Message<?> preSend(Message<?> message, MessageChannel channel) {
          StompHeaderAccessor accessor = 
              MessageHeaderAccessor.getAccessor(message, StompHeaderAccessor.class);
          
          if (StompCommand.CONNECT.equals(accessor.getCommand())) {
              // Extract token from STOMP CONNECT headers
              String token = accessor.getFirstNativeHeader("Authorization");
              if (token != null && token.startsWith("Bearer ")) {
                  token = token.substring(7);
                  try {
                      UserDetails user = jwtService.loadUserFromToken(token);
                      accessor.setUser(new UsernamePasswordAuthenticationToken(
                          user, null, user.getAuthorities()));
                  } catch (JwtException e) {
                      throw new MessagingException("Invalid token");
                  }
              }
          }
          return message;
      }
  }

Client STOMP CONNECT frame with token:
  client.connect(
      { Authorization: 'Bearer ' + jwtToken },
      (frame) => { console.log('Connected: ' + frame); }
  );

5. STOMP EXTERNAL BROKER (RabbitMQ / ActiveMQ for cluster)
================================================================================

For multi-node deployment, replace in-memory broker with a real message broker:

  @Override
  public void configureMessageBroker(MessageBrokerRegistry registry) {
      registry.enableStompBrokerRelay("/topic", "/queue")
          .setRelayHost("rabbitmq.internal")
          .setRelayPort(61613)                  // RabbitMQ STOMP plugin port
          .setClientLogin("guest")
          .setClientPasscode("guest")
          .setSystemLogin("system")
          .setSystemPasscode("system")
          .setSystemHeartbeatSendInterval(5_000)
          .setSystemHeartbeatReceiveInterval(4_000);
      
      registry.setApplicationDestinationPrefixes("/app");
      registry.setUserDestinationPrefix("/user");
  }

Benefits:
  - Messages persist if broker is restarted
  - Any app node can send/receive for any connected client
  - Native pub/sub scaling
  - Dead letter queues for undelivered messages

6. JAVASCRIPT CLIENT
================================================================================

Using @stomp/stompjs (modern browser client):

  import { Client } from '@stomp/stompjs';
  import SockJS from 'sockjs-client';

  const client = new Client({
      webSocketFactory: () => new SockJS('https://api.example.com/ws-stomp'),
      connectHeaders: {
          Authorization: 'Bearer ' + getAccessToken()
      },
      heartbeatIncoming: 10000,
      heartbeatOutgoing: 10000,
      reconnectDelay: 5000,    // auto-reconnect after 5 seconds
      
      onConnect: (frame) => {
          console.log('STOMP Connected');
          
          // Subscribe to public topic
          client.subscribe('/topic/chat', (message) => {
              const chat = JSON.parse(message.body);
              displayMessage(chat);
          });
          
          // Subscribe to user-specific queue
          client.subscribe('/user/queue/notifications', (message) => {
              const notification = JSON.parse(message.body);
              showNotification(notification);
          });
      },
      
      onStompError: (frame) => {
          console.error('STOMP error', frame.headers.message);
      }
  });

  client.activate();

  // Send a message
  client.publish({
      destination: '/app/chat.send',
      body: JSON.stringify({ content: 'Hello everyone!' })
  });

  // Graceful disconnect
  client.deactivate();

7. SPRING WEBSOCKET INTERVIEW QUESTIONS
================================================================================

Q1: What is the difference between @EnableWebSocket and @EnableWebSocketMessageBroker?
    @EnableWebSocket enables raw WebSocket support with WebSocketHandler —
    you handle all message parsing and routing yourself. Good for simple
    binary protocols or custom messaging formats.
    @EnableWebSocketMessageBroker adds STOMP messaging support on top of
    WebSocket — provides pub/sub (topics), point-to-point (queues), message
    routing to @MessageMapping controllers, user-specific messaging, and
    optional external broker integration. Recommended for most apps.

Q2: How does Spring route messages with STOMP?
    The applicationDestinationPrefix (/app) routes messages to @MessageMapping
    controller methods. Messages to /topic/* and /queue/* bypass application
    code and go directly to the message broker (in-memory or external).
    @SendTo("/topic/...") on a @MessageMapping method publishes the return value.
    SimpMessagingTemplate.convertAndSend() can publish from anywhere (services,
    listeners). convertAndSendToUser() targets a specific user's /user/queue/...

Q3: How do you scale Spring WebSocket across multiple nodes?
    Replace enableSimpleBroker with enableStompBrokerRelay pointing to
    RabbitMQ or ActiveMQ with STOMP plugin. All app nodes connect to the
    same external broker. When any node receives a message on /app/*, it
    processes it and publishes to the broker. The broker delivers to all
    subscribers regardless of which node they're connected to.

Q4: How does Spring WebSocket security integrate with Spring Security?
    Extend AbstractSecurityWebSocketMessageBrokerConfigurer and override
    configureInbound() to set authorization rules on STOMP destinations.
    Use ChannelInterceptor (StompAuthInterceptor) to validate JWT tokens
    on CONNECT frames and set Principal on the session accessor. After that,
    principal is available in @MessageMapping method parameters. Spring
    Security CSRF protection must be disabled for WebSocket (use token auth).

Q5: What is SockJS and when should you use it?
    SockJS is a JavaScript library that provides a WebSocket-like API but
    falls back to other transports (XHR streaming, long polling) when WebSocket
    is unavailable (corporate firewalls, old browsers, proxies).
    Enable with .withSockJS() on the Spring endpoint registration.
    Use SockJS when you need maximum compatibility, especially in enterprise
    environments. If you can guarantee modern browsers and infrastructure,
    native WebSocket is simpler and more efficient.
