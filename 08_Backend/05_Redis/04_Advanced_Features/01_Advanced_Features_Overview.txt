REDIS ADVANCED FEATURES — OVERVIEW FOR INTERVIEWS
================================================================================

1. WHAT MAKES REDIS "ADVANCED"
────────────────────────────────
Beyond key-value storage, Redis provides server-side compute capabilities:
  - Pub/Sub:              Message broadcasting to subscribers
  - Lua Scripting:        Atomic multi-step operations
  - Transactions:         MULTI/EXEC batching
  - Pipelining:           Network optimization
  - Keyspace Notifications: Event-driven architecture
  - Geospatial:           Location-based queries

These features let Redis serve as more than a cache.

                        │ Distance calculation           │ GEODIST, GEOPOS


3. ATOMICITY IN REDIS
──────────────────────
  Command level: EVERY single command is atomic (single-threaded execution)
  Multi-command atomic: Use Lua scripts (all commands in script run atomically)
  Batch (not truly atomic): MULTI/EXEC — commands queued, executed as a unit,
                            but no rollback on partial failure

  Key question: "Is INCR atomic in Redis?"
  Yes — because the single-threaded event loop ensures no interleaving.

  Key question: "How do you make a multi-step operation atomic?"
  Lua script — the entire script executes in a single event loop iteration.
  No other command can run between script steps.
