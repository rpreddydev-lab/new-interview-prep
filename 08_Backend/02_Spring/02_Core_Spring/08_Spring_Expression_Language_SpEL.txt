================================================================
  SPRING EXPRESSION LANGUAGE (SpEL) — IN DEPTH
================================================================

================================================================
WHAT IS SpEL?
================================================================

  Spring Expression Language is a powerful expression language
  integrated into the Spring framework. It supports:
    • Property access and navigation
    • Method invocation
    • Arithmetic, relational, logical operators
    • Regular expressions
    • Collection projection and selection
    • Bean references
    • Conditional expressions

  Used in:
    @Value("#{...}")                    -- inject computed values
    @Query("... WHERE id = ?#{...}")    -- Spring Data queries
    @PreAuthorize("#{...}")             -- Spring Security expressions
    @Cacheable(condition="#{...}")      -- Cache conditions
    XML: <property value="#{...}"/>

================================================================
SpEL SYNTAX BASICS
================================================================

  SpEL expressions are wrapped in:
    #{ expression }   -- SpEL
    ${ property }     -- Property placeholder (NOT SpEL)

  They are often mixed:
    @Value("#{${max.retries} * 2}")     // property inside SpEL

================================================================
PROGRAMMATIC SpEL EVALUATION
================================================================

  // Basic evaluation
  ExpressionParser parser = new SpelExpressionParser();
  Expression expr = parser.parseExpression("'Hello ' + 'World'");
  String result = (String) expr.getValue();    // "Hello World"

  // With target object
  Order order = new Order(100.0, "PENDING");
  Expression e = parser.parseExpression("amount * 1.1");
  Double total = e.getValue(order, Double.class);   // 110.0

  // With EvaluationContext (variables, functions)
  StandardEvaluationContext context = new StandardEvaluationContext(order);
  context.setVariable("taxRate", 0.08);
  Double taxed = parser.parseExpression("amount * (1 + #taxRate)")
                       .getValue(context, Double.class);

================================================================
PROPERTY ACCESS
================================================================

  // Bean property: uses getter
  @Value("#{systemProperties['user.home']}")
  private String userHome;

  // Nested property
  @Value("#{order.customer.address.city}")
  private String city;

  // Null-safe navigation (like Kotlin's ?.)
  @Value("#{order?.customer?.name}")
  private String name;    // null instead of NullPointerException

  // Array / List index
  @Value("#{list[0]}")
  private String first;

  // Map access
  @Value("#{map['keyName']}")
  private String value;

================================================================
METHOD INVOCATION
================================================================

  @Value("#{'hello world'.toUpperCase()}")
  private String upper;   // "HELLO WORLD"

  @Value("#{T(java.lang.Math).random() * 100}")
  private double rand;

  @Value("#{T(java.util.UUID).randomUUID().toString()}")
  private String uuid;

  // T() operator references a type for static methods / constants
  @Value("#{T(java.lang.Integer).MAX_VALUE}")
  private int maxInt;

================================================================
OPERATORS
================================================================

  Category    | SpEL          | Example
  ------------|---------------|------------------------------------
  Arithmetic  | + - * / % ^  | #{a + b}, #{a ^ 2}
  Comparison  | == != < > <= >= lt gt le ge eq ne
              |               | #{age >= 18}
  Logical     | and or not !  | #{age >= 18 and verified}
  String      | +             | #{'Hello ' + name}
  Ternary     | ? :           | #{age >= 18 ? 'adult' : 'minor'}
  Elvis       | ?:            | #{name ?: 'Anonymous'}  (null coalescing)
  Regex       | matches       | #{email matches '.*@.*\\..*'}
  instanceof  | instanceof    | #{bean instanceof T(MyClass)}

================================================================
COLLECTION OPERATIONS
================================================================

  // Selection: filter collection
  @Value("#{orders.?[amount > 100]}")
  private List<Order> bigOrders;     // all where amount > 100

  // Selection: first match
  @Value("#{orders.^[amount > 100]}")
  private Order firstBig;

  // Selection: last match
  @Value("#{orders.$[amount > 100]}")
  private Order lastBig;

  // Projection: extract field from each element
  @Value("#{orders.![customer.name]}")
  private List<String> customerNames;

  // Aggregate
  @Value("#{orders.size()}")
  private int count;

================================================================
SpEL IN SPRING SECURITY
================================================================

  @PreAuthorize("hasRole('ADMIN')")
  public void deleteUser(Long id) { ... }

  @PreAuthorize("hasRole('ADMIN') or #userId == authentication.principal.id")
  public UserDto getUser(Long userId) { ... }

  @PostAuthorize("returnObject.userId == authentication.principal.id")
  public Order getOrder(Long id) { ... }

  @PreFilter("filterObject.userId == authentication.principal.id")
  public List<Order> processOrders(List<Order> orders) { ... }

  Built-in variables in security SpEL:
    authentication  -- current Authentication object
    principal       -- authentication.getPrincipal()
    hasRole(role)   -- checks granted authority
    hasAnyRole(...)
    isAuthenticated()
    isAnonymous()
    permitAll()
    denyAll()

================================================================
SpEL IN SPRING DATA @QUERY
================================================================

  // Bind method parameter by name (requires @Param)
  @Query("SELECT u FROM User u WHERE u.email = :#{#email}")
  User findByEmail(@Param("email") String email);

  // Access Spring Security principal inside query
  @Query("SELECT o FROM Order o WHERE o.userId = ?#{principal.id}")
  List<Order> findMyOrders();

================================================================
SpEL IN @Cacheable
================================================================

  // Cache key based on method argument
  @Cacheable(value = "products", key = "#id")
  public Product findById(Long id) { ... }

  // Conditional caching
  @Cacheable(value = "users",
             condition = "#id > 0",
             unless = "#result == null")
  public User findById(Long id) { ... }

  // Composite key
  @Cacheable(value = "orders", key = "#userId + '_' + #status")
  public List<Order> findByUserAndStatus(Long userId, String status) { ... }

================================================================
INTERVIEW QUESTIONS — SpEL
================================================================

  Q: What is SpEL and when would you use it?
  A: Spring Expression Language is a runtime expression language for
     dynamic property injection, security rules, cache keys, and query
     conditions. It's used wherever you need computed or conditional
     values rather than static configuration.

  Q: What is the difference between #{...} and ${...}?
  A: ${...} is a property placeholder resolved from properties files.
     #{...} is a SpEL expression evaluated at runtime with access to
     beans, system properties, math, etc.

  Q: What is the T() operator in SpEL?
  A: T(ClassName) references a Java type, enabling access to static
     methods and constants: T(Math).sqrt(4), T(Integer).MAX_VALUE.

  Q: How does SpEL work with Spring Security @PreAuthorize?
  A: Spring Security evaluates the SpEL expression with variables like
     authentication, principal, hasRole(), etc. If the expression
     evaluates to false, access is denied with 403.

  Q: How do you filter a collection using SpEL?
  A: Use the selection operator .?[condition] for all matches,
     .^[condition] for first, .$[condition] for last.
