@RequestMapping — FULL REFERENCE
================================================================

  @RequestMapping(
      value    = "/api/users/{id}",    // URL pattern(s)
      method   = RequestMethod.GET,    // HTTP methods
      params   = "!deleted",           // must/must-not have param
      headers  = "X-API-Version=2",    // required header
      consumes = "application/json",   // request Content-Type
      produces = "application/json"    // response Accept type
  )

  Can be on class (shared prefix) AND method (specific):
  @RestController
  @RequestMapping(value = "/api/v2/orders", produces = "application/json")
  public class OrderController {

      @GetMapping                        // → GET /api/v2/orders
      public List<Order> list() { ... }

      @GetMapping("/{id}")               // → GET /api/v2/orders/{id}
      public Order get(@PathVariable Long id) { ... }

      @PostMapping(consumes = "application/json")
      public Order create(@RequestBody Order order) { ... }
  }

PATH VARIABLE PATTERNS
================================================================

  @GetMapping("/{id}")
  public User getById(@PathVariable("id") Long userId) { ... }

  // Variable name matches parameter name → @PathVariable without value
  @GetMapping("/{id}")
  public User getById(@PathVariable Long id) { ... }

  // Multiple variables
  @GetMapping("/{category}/{productId}")
  public Product get(@PathVariable String category,
                     @PathVariable Long productId) { ... }

  // Optional path variable
  @GetMapping({"/users", "/users/{id}"})
  public Object getUser(
      @PathVariable(required = false) Long id) {
      return id != null ? findById(id) : findAll();
  }

  // AntPath patterns
  @GetMapping("/files/**")       // matches /files/a/b/c.pdf
  @GetMapping("/users/{id:\\d+}") // regex: digits only

ResponseEntity — FULL RESPONSE CONTROL
================================================================

  // 200 OK with body
  return ResponseEntity.ok(user);

  // 201 Created with Location header
  URI uri = uriBuilder.path("/users/{id}").build(user.getId());
  return ResponseEntity.created(uri).body(user);

  // 204 No Content
  return ResponseEntity.noContent().build();

  // 404 Not Found
  return ResponseEntity.notFound().build();

  // Custom status + headers + body
  return ResponseEntity
      .status(HttpStatus.UNPROCESSABLE_ENTITY)
      .header("X-Error-Code", "VALIDATION_FAILED")
      .contentType(MediaType.APPLICATION_JSON)
      .body(errorDetails);

  // 304 Not Modified (ETag / caching)
  return ResponseEntity.status(HttpStatus.NOT_MODIFIED)
      .eTag("\"abc123\"")
      .build();

ASYNC CONTROLLERS
================================================================

  // DeferredResult — non-blocking, result set from another thread
  @GetMapping("/async")
  public DeferredResult<String> async() {
      DeferredResult<String> result = new DeferredResult<>(5000L, "timeout");
      executor.submit(() -> {
          String value = expensiveOperation();
          result.setResult(value);
      });
      return result;
  }

  // Callable — Spring TaskExecutor handles threading
  @GetMapping("/callable")
  public Callable<String> callable() {
      return () -> expensiveOperation();  // runs in mvc task executor
  }

  // CompletableFuture
  @GetMapping("/cf")
  public CompletableFuture<User> future(@PathVariable Long id) {
      return CompletableFuture.supplyAsync(() -> userService.findById(id));
  }

  // Streaming response (Server-Sent Events)
  @GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
  public SseEmitter stream() {
      SseEmitter emitter = new SseEmitter();
      executor.submit(() -> {
          for (int i = 0; i < 10; i++) {
              emitter.send(SseEmitter.event().data("Event " + i));
              Thread.sleep(1000);
          }
          emitter.complete();
      });
      return emitter;
  }

@ModelAttribute — FORM BINDING
================================================================

  // Populate model before each method in this controller
  @ModelAttribute("categories")
  public List<Category> populateCategories() {
      return categoryService.findAll();
  }

  // Bind form to POJO
  @PostMapping("/products")
  public String createProduct(@Valid @ModelAttribute ProductForm form,
                               BindingResult result,
                               RedirectAttributes attrs) {
      if (result.hasErrors()) {
          return "product-form";  // re-render form with errors
      }
      productService.create(form);
      attrs.addFlashAttribute("message", "Product created!");
      return "redirect:/products";
  }

URI CONSTRUCTION WITH UriComponentsBuilder
================================================================

  @PostMapping("/users")
  public ResponseEntity<UserDto> create(
          @Valid @RequestBody CreateUserRequest req,
          UriComponentsBuilder ucb) {
      UserDto user = userService.create(req);

      URI location = ucb
          .path("/api/users/{id}")
          .buildAndExpand(user.getId())
          .toUri();

      return ResponseEntity.created(location).body(user);
  }

================================================================
INTERVIEW QUESTIONS — CONTROLLERS
================================================================

  Q: What is the difference between @RequestMapping and @GetMapping?
  A: @GetMapping is a composed annotation equivalent to
     @RequestMapping(method = RequestMethod.GET). @RequestMapping
     can handle any/all HTTP methods.

  Q: What is ResponseEntity and when would you use it?
  A: ResponseEntity gives full control over HTTP status code,
     headers, and body. Use it when you need to return custom
     status codes, add Location headers, or conditionally
     return 404 vs 200.

  Q: How do you handle optional path variables?
  A: Map multiple URL patterns: @GetMapping({"/users", "/users/{id}"})
     with @PathVariable(required=false) Long id.

  Q: What is DeferredResult and why use it?
  A: DeferredResult allows a controller to return immediately while
     computation happens on another thread. The request is held open
     (non-blocking) and the response is written when setResult() is called.
     Useful for long-polling and async service calls.

  Q: What does @Valid do on @RequestBody?
  A: Triggers Bean Validation (JSR-303/380) on the deserialized object.
     Validation errors result in MethodArgumentNotValidException (400).
