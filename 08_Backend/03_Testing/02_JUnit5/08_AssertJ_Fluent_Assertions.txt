ASSERTJ — FLUENT ASSERTIONS
============================

=== WHY ASSERTJ ===

AssertJ provides a fluent, discoverable assertion API for Java tests.
Included by default in spring-boot-starter-test (no extra dependency needed).

JUnit 5 assertEquals (old way):
  assertEquals("John", user.getName());          // not discoverable
  assertTrue(list.size() > 0);                   // unclear error message

AssertJ (modern way):
  assertThat(user.getName()).isEqualTo("John");  // fluent, IDE-discoverable
  assertThat(list).isNotEmpty();                 // reads like English

Import:
  import static org.assertj.core.api.Assertions.*;
  import static org.assertj.core.api.Assertions.assertThat;

=== BASIC ASSERTIONS ===

// Object equality
assertThat(actual).isEqualTo(expected);
assertThat(actual).isNotEqualTo(other);
assertThat(actual).isNull();
assertThat(actual).isNotNull();
assertThat(actual).isSameAs(expected);          // reference equality

// Boolean
assertThat(result).isTrue();
assertThat(result).isFalse();

// Numbers
assertThat(42).isGreaterThan(10);
assertThat(3.14).isCloseTo(3.14159, within(0.01));
assertThat(age).isBetween(18, 65);

// Strings
assertThat(name).isEqualTo("Alice");
assertThat(email).contains("@");
assertThat(email).endsWith(".com");
assertThat(email).startsWith("user");
assertThat(name).isEqualToIgnoringCase("alice");
assertThat(name).matches("[A-Z][a-z]+");
assertThat(empty).isEmpty();
assertThat(blank).isBlank();

=== COLLECTION ASSERTIONS ===

List<String> names = List.of("Alice", "Bob", "Charlie");

assertThat(names).isNotEmpty();
assertThat(names).hasSize(3);
assertThat(names).contains("Alice", "Bob");              // in any order
assertThat(names).containsExactly("Alice", "Bob", "Charlie"); // exact order
assertThat(names).containsExactlyInAnyOrder("Bob", "Alice", "Charlie");
assertThat(names).doesNotContain("Dave");
assertThat(names).allMatch(n -> n.length() > 2);
assertThat(names).anyMatch(n -> n.startsWith("A"));
assertThat(names).noneMatch(n -> n.isEmpty());

// Extracting fields from objects
List<User> users = List.of(new User("Alice", 30), new User("Bob", 25));
assertThat(users)
    .extracting(User::getName)
    .containsExactly("Alice", "Bob");

assertThat(users)
    .extracting("name", "age")   // field names as strings
    .containsExactly(
        tuple("Alice", 30),
        tuple("Bob", 25)
    );

// Filter before assert
assertThat(users)
    .filteredOn(u -> u.getAge() > 20)
    .hasSize(2)
    .extracting(User::getName)
    .contains("Alice");

=== MAP ASSERTIONS ===

Map<String, Integer> scores = Map.of("Alice", 95, "Bob", 87);

assertThat(scores).containsKey("Alice");
assertThat(scores).containsEntry("Alice", 95);
assertThat(scores).doesNotContainKey("Charlie");
assertThat(scores).hasSize(2);

=== EXCEPTION ASSERTIONS ===

// assertThatThrownBy — preferred
assertThatThrownBy(() -> service.process(null))
    .isInstanceOf(IllegalArgumentException.class)
    .hasMessage("Input cannot be null")
    .hasMessageContaining("null");

// assertThatExceptionOfType — more explicit
assertThatExceptionOfType(UserNotFoundException.class)
    .isThrownBy(() -> userService.findById(999L))
    .withMessage("User not found: 999");

// assertThatCode — assert no exception
assertThatCode(() -> service.save(validRequest))
    .doesNotThrowAnyException();

// catchThrowable — capture and inspect
Throwable thrown = catchThrowable(() -> service.process(badInput));
assertThat(thrown)
    .isInstanceOf(ValidationException.class)
    .hasFieldOrPropertyWithValue("field", "email");

=== SOFT ASSERTIONS ===

All assertions run even if some fail — full failure report:

@Test
void softAssertionsExample() {
    // Method 1: SoftAssertions object
    SoftAssertions softly = new SoftAssertions();
    softly.assertThat(user.getName()).isEqualTo("Alice");
    softly.assertThat(user.getEmail()).contains("@");
    softly.assertThat(user.getAge()).isGreaterThan(18);
    softly.assertAll();  // throws with ALL failures at once

    // Method 2: BDD-style (recommended)
    BDDSoftAssertions then = new BDDSoftAssertions();
    then.then(user.getName()).isEqualTo("Alice");
    then.then(user.getEmail()).contains("@");
    then.assertAll();
}

// Method 3: @ExtendWith (JUnit 5 extension)
@ExtendWith(SoftAssertionsExtension.class)
class UserTest {
    @Test
    void test(SoftAssertions softly) {    // injected automatically
        softly.assertThat(user.getName()).isEqualTo("Alice");
        softly.assertThat(user.getAge()).isGreaterThan(0);
        // No assertAll() needed — extension calls it
    }
}

=== CUSTOM ASSERTIONS ===

@Test
void withCustomAssertion() {
    assertThat(order)
        .satisfies(o -> {
            assertThat(o.getStatus()).isEqualTo(OrderStatus.CONFIRMED);
            assertThat(o.getItems()).hasSize(2);
            assertThat(o.getTotal()).isGreaterThan(BigDecimal.ZERO);
        });
}

// Custom AbstractAssert for domain objects
public class UserAssert extends AbstractAssert<UserAssert, User> {
    public UserAssert(User actual) {
        super(actual, UserAssert.class);
    }
    public static UserAssert assertThat(User user) {
        return new UserAssert(user);
    }
    public UserAssert hasValidEmail() {
        isNotNull();
        if (!actual.getEmail().contains("@")) {
            failWithMessage("Expected user to have valid email but was <%s>",
                            actual.getEmail());
        }
        return this;
    }
    public UserAssert isAdult() {
        isNotNull();
        assertThat(actual.getAge()).isGreaterThanOrEqualTo(18);
        return this;
    }
}

// Usage:
assertThat(user).hasValidEmail().isAdult();

=== ASSERTJ VS JUNIT 5 ASSERTIONS ===

JUnit 5 assertions:                          AssertJ equivalent:
assertEquals(a, b)                           assertThat(b).isEqualTo(a)
assertNotNull(obj)                           assertThat(obj).isNotNull()
assertThrows(Ex.class, () -> ...)            assertThatThrownBy(() -> ...).isInstanceOf(Ex.class)
assertAll(assertions...)                     SoftAssertions (more powerful)

AssertJ advantages:
  - Fluent API → IDE auto-completion
  - Better error messages
  - More assertions available
  - Soft assertions (JUnit 5 assertAll is limited)
