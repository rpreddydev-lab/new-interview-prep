1. WHAT IS PLAYWRIGHT
================================================================================

Playwright is a Node.js-based E2E testing framework from Microsoft.
It controls browsers via the DevTools Protocol from outside the browser.

KEY FEATURES:
  - Cross-browser: Chromium, Firefox, WebKit (Safari engine)
  - Cross-platform: Windows, macOS, Linux
  - Auto-waits: All interactions wait for elements automatically
  - Multiple pages / browser contexts in one test
  - API testing support (request context)
  - Built-in trace viewer, screenshot, and video recording
  - TypeScript support out of the box (no extra config needed)
  - Parallel test execution by default
  - Visual comparisons (toHaveScreenshot)
  - Test generator (codegen) to record interactions

COMPARED TO CYPRESS:
  ✅ True cross-browser testing (Safari support)
  ✅ Out-of-process (no iFrame restrictions)
  ✅ Better multi-tab testing
  ✅ Faster parallel execution
  ❌ Less mature ecosystem than Cypress
  ❌ No Cypress-style time-travel debugger (Trace Viewer instead)
  ❌ No real-time interactive reloading

ARCHITECTURE:
  Test Code (Node.js) → WebSocket/CDP → Browser Process
  Tests run in Node.js; browser runs as a separate process.
  This allows: true cross-browser, multi-tab, full isolation.

2. INSTALLATION AND SETUP
================================================================================

INSTALL:
  npm init playwright@latest
  # Interactive setup: picks browsers, TypeScript, CI config

MANUAL INSTALL:
  npm install --save-dev @playwright/test
  npx playwright install   # Downloads browser binaries

FIRST LAUNCH — Creates:
  playwright.config.ts     ← Configuration
  tests/
  ├── example.spec.ts      ← Example test
  tests-examples/          ← More examples
  .github/workflows/playwright.yml ← GitHub Actions workflow

BROWSERS INSTALLED:
  npx playwright install             # All browsers
  npx playwright install chromium    # Only Chromium
  npx playwright install --with-deps # Install OS dependencies too

4. WRITING YOUR FIRST TEST
================================================================================

  import { test, expect } from '@playwright/test';

  test.describe('Login Flow', () => {
    test.beforeEach(async ({ page }) => {
      await page.goto('/login');
    });

    test('logs in with valid credentials', async ({ page }) => {
      await page.getByLabel('Email').fill('alice@example.com');
      await page.getByLabel('Password').fill('password123');
      await page.getByRole('button', { name: 'Sign In' }).click();

      await expect(page).toHaveURL('/dashboard');
      await expect(page.getByText('Welcome, Alice')).toBeVisible();
    });

    test('shows error for invalid password', async ({ page }) => {
      await page.getByLabel('Email').fill('alice@example.com');
      await page.getByLabel('Password').fill('wrongpassword');
      await page.getByRole('button', { name: 'Sign In' }).click();

      await expect(page.getByRole('alert')).toContainText('Invalid credentials');
      await expect(page).toHaveURL('/login');
    });
  });

IMPORTANT: ALL ACTIONS ARE ASYNC — always use await.
Unlike Cypress, Playwright uses standard async/await — no special queue.

5. LOCATORS (THE PLAYWRIGHT WAY)
================================================================================

Playwright locators are recommended over raw selectors.
They auto-wait, auto-retry, and are strict (throw if multiple matches).

PREFERRED LOCATORS (in priority order):
  page.getByRole(role, { name })        → By ARIA role
  page.getByLabel(text)                 → By label text
  page.getByPlaceholder(text)           → By placeholder
  page.getByText(text)                  → By text content
  page.getByAltText(text)               → By alt attribute
  page.getByTitle(text)                 → By title attribute
  page.getByTestId(id)                  → By data-testid

EXAMPLES:
  // Role + name:
  page.getByRole('button', { name: 'Submit' })
  page.getByRole('heading', { name: /dashboard/i, level: 1 })
  page.getByRole('checkbox', { name: 'Remember me' })
  page.getByRole('link', { name: 'Home' })
  page.getByRole('combobox', { name: 'Country' })
  page.getByRole('textbox', { name: /email/i })

  // Label:
  page.getByLabel('Email Address')       // Finds input associated with this label
  page.getByLabel(/email/i)             // Regex match

  // Text:
  page.getByText('Click here')           // Exact by default
  page.getByText('partial', { exact: false })
  page.getByText(/hello/i)              // Regex

  // Test ID:
  page.getByTestId('submit-btn')        // data-testid="submit-btn"

CSS / XPATH SELECTORS (use as last resort):
  page.locator('[data-testid="submit"]')  → CSS attribute
  page.locator('#email-input')            → ID
  page.locator('.submit-button')          → Class (fragile!)
  page.locator('text=Submit')             → Text selector
  page.locator('xpath=//button[@type="submit"]') → XPath

CHAINING LOCATORS:
  // Find an element within another:
  const nav = page.getByRole('navigation');
  const homeLink = nav.getByRole('link', { name: 'Home' });

  // Or using .locator().locator():
  page.locator('[data-testid="user-card"]').getByRole('button', { name: 'Delete' });

FILTERING LOCATORS:
  page.getByRole('listitem').filter({ hasText: 'Alice' })
  page.getByRole('listitem').filter({ has: page.getByRole('button') })
  page.getByRole('listitem').nth(0)    // First item
  page.getByRole('listitem').first()   // First item
  page.getByRole('listitem').last()    // Last item

6. ACTIONS (INTERACTIONS)
================================================================================

CLICK:
  await page.getByRole('button', { name: 'Submit' }).click();
  await page.getByText('Cancel').click({ button: 'right' }); // Right-click
  await page.getByTestId('item').dblclick();                  // Double-click
  await page.getByRole('button').click({ force: true });      // Force click

FILL (TYPE):
  await page.getByLabel('Email').fill('alice@example.com');   // Fast fill (sets value)
  await page.getByLabel('Name').type('Alice');                // Type character by character
  await page.getByLabel('Name').clear();                      // Clear first
  await page.getByLabel('Name').pressSequentially('Alice');   // Keystroke by keystroke

  // Special keys:
  await page.getByRole('textbox').press('Enter');
  await page.getByRole('textbox').press('Tab');
  await page.keyboard.press('Escape');
  await page.keyboard.type('Hello World');

CHECKBOXES AND RADIOS:
  await page.getByRole('checkbox', { name: 'Agree' }).check();
  await page.getByRole('checkbox', { name: 'Agree' }).uncheck();
  await page.getByRole('radio', { name: 'Monthly' }).check();

SELECT:
  await page.getByRole('combobox', { name: 'Country' }).selectOption('US');
  await page.getByRole('combobox').selectOption({ label: 'United States' });
  await page.getByRole('combobox').selectOption(['Option1', 'Option2']); // Multi

HOVER:
  await page.getByRole('button', { name: 'Help' }).hover();

SCROLL:
  await page.mouse.wheel(0, 500);           // Scroll down 500px
  await page.getByTestId('container').scrollIntoViewIfNeeded();
  await page.evaluate(() => window.scrollTo(0, 500));

DRAG AND DROP:
  await page.getByTestId('drag-source').dragTo(page.getByTestId('drop-target'));

FILE UPLOAD:
  await page.getByLabel('Upload').setInputFiles('path/to/file.pdf');
  await page.getByLabel('Upload').setInputFiles([
    'path/to/file1.pdf',
    'path/to/file2.pdf',
  ]);

7. ASSERTIONS (expect)
================================================================================

Playwright uses expect() from @playwright/test (auto-waits built in).

ELEMENT ASSERTIONS:
  await expect(locator).toBeVisible();
  await expect(locator).toBeHidden();
  await expect(locator).toBeEnabled();
  await expect(locator).toBeDisabled();
  await expect(locator).toBeChecked();
  await expect(locator).toBeEmpty();
  await expect(locator).toBeFocused();
  await expect(locator).toBeEditable();

TEXT ASSERTIONS:
  await expect(locator).toHaveText('Exact text');
  await expect(locator).toHaveText(/partial/i);
  await expect(locator).toContainText('partial');
  await expect(locator).toHaveValue('input value');
  await expect(locator).toHaveAttribute('href', '/home');
  await expect(locator).toHaveClass('active');

COUNT ASSERTIONS:
  await expect(locator).toHaveCount(5);
  await expect(page.getByRole('listitem')).toHaveCount(3);

PAGE ASSERTIONS:
  await expect(page).toHaveURL('/dashboard');
  await expect(page).toHaveURL(/dashboard/);
  await expect(page).toHaveTitle('My App - Dashboard');
  await expect(page).toHaveTitle(/My App/);

VISUAL ASSERTION (screenshot comparison):
  await expect(page).toHaveScreenshot('home-page.png');
  await expect(locator).toHaveScreenshot('widget.png', { maxDiffPixels: 10 });

SOFT ASSERTIONS (don't stop on failure):
  await expect.soft(locator).toBeVisible(); // Continues even if this fails
  await expect.soft(page).toHaveURL('/home');
  // All soft failures reported at end of test

8. HOOKS AND FIXTURES
================================================================================

HOOKS (same as Jest/Mocha):
  test.describe('Suite', () => {
    test.beforeAll(async ({ browser }) => { ... });   // Runs once per worker
    test.afterAll(async () => { ... });               // Runs once per worker
    test.beforeEach(async ({ page }) => { ... });     // Before each test
    test.afterEach(async ({ page }) => { ... });      // After each test
  });

PLAYWRIGHT FIXTURES:
  Fixtures are Playwright's way of sharing setup between tests.
  Built-in fixtures: page, browser, context, browserName, request

  CUSTOM FIXTURES:
  // fixtures/myFixtures.ts
  import { test as base, expect } from '@playwright/test';
  import { LoginPage } from './pages/LoginPage';

  type MyFixtures = {
    loginPage: LoginPage;
    loggedInPage: Page;
  };

  export const test = base.extend<MyFixtures>({
    loginPage: async ({ page }, use) => {
      const loginPage = new LoginPage(page);
      await use(loginPage);
    },

    loggedInPage: async ({ page }, use) => {
      await page.goto('/login');
      await page.getByLabel('Email').fill('alice@example.com');
      await page.getByLabel('Password').fill('password123');
      await page.getByRole('button', { name: 'Sign In' }).click();
      await page.waitForURL('/dashboard');
      await use(page);
    },
  });

  export { expect } from '@playwright/test';

  // In test:
  import { test, expect } from '../fixtures/myFixtures';

  test('dashboard is accessible when logged in', async ({ loggedInPage }) => {
    await expect(loggedInPage.getByRole('heading', { name: 'Dashboard' })).toBeVisible();
  });

AUTHENTICATION SETUP (reuse login across tests):
  // playwright.config.ts:
  export default defineConfig({
    globalSetup: './global-setup.ts',
    use: { storageState: 'playwright/.auth/user.json' },
  });

  // global-setup.ts:
  import { chromium } from '@playwright/test';

  async function globalSetup() {
    const browser = await chromium.launch();
    const page = await browser.newPage();
    await page.goto('http://localhost:3000/login');
    await page.getByLabel('Email').fill('alice@example.com');
    await page.getByLabel('Password').fill('password123');
    await page.getByRole('button', { name: 'Sign In' }).click();
    await page.context().storageState({ path: 'playwright/.auth/user.json' });
    await browser.close();
  }

  export default globalSetup;

9. PAGE OBJECT MODEL (POM)
================================================================================

Page Objects encapsulate interactions with a page, reducing duplication.

  // tests/pages/LoginPage.ts
  import { Page, Locator, expect } from '@playwright/test';

  export class LoginPage {
    readonly page: Page;
    readonly emailInput: Locator;
    readonly passwordInput: Locator;
    readonly submitButton: Locator;
    readonly errorAlert: Locator;

    constructor(page: Page) {
      this.page = page;
      this.emailInput = page.getByLabel(/email/i);
      this.passwordInput = page.getByLabel(/password/i);
      this.submitButton = page.getByRole('button', { name: /sign in/i });
      this.errorAlert = page.getByRole('alert');
    }

    async goto() {
      await this.page.goto('/login');
    }

    async login(email: string, password: string) {
      await this.emailInput.fill(email);
      await this.passwordInput.fill(password);
      await this.submitButton.click();
    }

    async expectError(message: string) {
      await expect(this.errorAlert).toContainText(message);
    }
  }

  // In test:
  import { test, expect } from '@playwright/test';
  import { LoginPage } from '../pages/LoginPage';

  test('shows error for invalid credentials', async ({ page }) => {
    const loginPage = new LoginPage(page);
    await loginPage.goto();
    await loginPage.login('alice@example.com', 'wrongpassword');
    await loginPage.expectError('Invalid credentials');
  });

10. NETWORK INTERCEPTION (route, fulfill)
================================================================================

page.route() intercepts network requests.

STUB A RESPONSE:
  await page.route('/api/users', async (route) => {
    await route.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify([{ id: 1, name: 'Alice' }]),
    });
  });

ABORT A REQUEST (simulate network error):
  await page.route('/api/flaky', (route) => route.abort());

MODIFY REQUEST:
  await page.route('/api/users', async (route) => {
    const request = route.request();
    console.log(request.url(), request.method());
    await route.continue({ headers: { ...request.headers(), 'X-Custom': 'test' } });
  });

MODIFY RESPONSE:
  await page.route('/api/config', async (route) => {
    const response = await route.fetch();
    const body = await response.json();
    body.featureFlag = true; // Modify response
    await route.fulfill({ response, body: JSON.stringify(body) });
  });

WAIT FOR A REQUEST:
  const [request] = await Promise.all([
    page.waitForRequest('/api/checkout'),
    page.getByRole('button', { name: 'Checkout' }).click(),
  ]);
  expect(request.postDataJSON()).toMatchObject({ cartId: '123' });

WAIT FOR A RESPONSE:
  const [response] = await Promise.all([
    page.waitForResponse('/api/users'),
    page.getByRole('button', { name: 'Load Users' }).click(),
  ]);
  expect(response.status()).toBe(200);

11. BROWSER CONTEXTS AND MULTIPLE PAGES
================================================================================

BROWSER CONTEXT = Isolated browser session (separate cookies, storage).
Each test gets a fresh context by default.

MULTIPLE PAGES IN ONE TEST:
  test('admin can invite user who then sees invite email', async ({ page, context }) => {
    // Admin page:
    await page.goto('/admin/invite');
    await page.getByLabel('Email').fill('newuser@example.com');
    await page.getByRole('button', { name: 'Send Invite' }).click();

    // New page in same context (simulates email link click):
    const invitePage = await context.newPage();
    await invitePage.goto('/accept-invite?token=abc123');
    await expect(invitePage.getByText('Set up your account')).toBeVisible();
  });

MULTI-USER SCENARIO (two separate contexts):
  test('two users can collaborate', async ({ browser }) => {
    const aliceContext = await browser.newContext();
    const bobContext = await browser.newContext();

    const alicePage = await aliceContext.newPage();
    const bobPage = await bobContext.newPage();

    await alicePage.goto('/login');
    // ... Alice logs in

    await bobPage.goto('/login');
    // ... Bob logs in

    // Alice sends message, Bob sees it
    await alicePage.getByLabel('Message').fill('Hello Bob!');
    await alicePage.getByRole('button', { name: 'Send' }).click();

    await expect(bobPage.getByText('Hello Bob!')).toBeVisible({ timeout: 5000 });

    await aliceContext.close();
    await bobContext.close();
  });

12. CONFIGURATION (playwright.config.ts)
================================================================================

  import { defineConfig, devices } from '@playwright/test';

  export default defineConfig({
    testDir: './tests',
    fullyParallel: true,          // Run tests in parallel
    forbidOnly: !!process.env.CI, // Fail if test.only() in CI
    retries: process.env.CI ? 2 : 0, // Retry on CI
    workers: process.env.CI ? 1 : undefined, // Parallel workers
    reporter: [['html'], ['line']], // Output reporters
    timeout: 30_000,              // 30s per test
    expect: {
      timeout: 5_000,             // Assertion auto-wait timeout
    },
    use: {
      baseURL: 'http://localhost:3000',
      trace: 'on-first-retry',    // Capture trace on failure
      screenshot: 'only-on-failure',
      video: 'on-first-retry',
      storageState: 'playwright/.auth/user.json', // Reuse auth
    },
    projects: [
      {
        name: 'chromium',
        use: { ...devices['Desktop Chrome'] },
      },
      {
        name: 'firefox',
        use: { ...devices['Desktop Firefox'] },
      },
      {
        name: 'webkit',
        use: { ...devices['Desktop Safari'] },
      },
      // Mobile:
      {
        name: 'Mobile Chrome',
        use: { ...devices['Pixel 5'] },
      },
      // Auth setup project:
      {
        name: 'setup',
        testMatch: /.*\.setup\.ts/,
      },
    ],
    webServer: {
      command: 'npm run dev',
      url: 'http://localhost:3000',
      reuseExistingServer: !process.env.CI,
    },
  });

13. RUNNING TESTS
================================================================================

RUN ALL TESTS:
  npx playwright test

RUN WITH BROWSER UI (headed mode):
  npx playwright test --headed

RUN SPECIFIC FILE:
  npx playwright test tests/auth/login.spec.ts

RUN IN SPECIFIC BROWSER:
  npx playwright test --project=chromium
  npx playwright test --project=firefox

DEBUG MODE (step through tests):
  npx playwright test --debug
  PWDEBUG=1 npx playwright test  # Opens browser with Inspector

UI MODE (interactive, like Cypress GUI):
  npx playwright test --ui

VIEW HTML REPORT:
  npx playwright show-report

CODEGEN (record your interactions as test code):
  npx playwright codegen http://localhost:3000
  # Opens browser + records actions as Playwright code

TRACE VIEWER:
  npx playwright show-trace trace.zip

PACKAGE.JSON SCRIPTS:
  {
    "scripts": {
      "test:e2e": "playwright test",
      "test:e2e:ui": "playwright test --ui",
      "test:e2e:headed": "playwright test --headed",
      "test:e2e:debug": "playwright test --debug",
      "test:e2e:report": "playwright show-report"
    }
  }
