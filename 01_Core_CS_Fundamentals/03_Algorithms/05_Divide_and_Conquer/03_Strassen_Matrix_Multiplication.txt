================================================================
  STRASSEN MATRIX MULTIPLICATION
================================================================

----------------------------------------------------------------
PROBLEM
----------------------------------------------------------------
Multiply two n x n matrices. Naive: O(n^3).
Can we do better using Divide and Conquer?

----------------------------------------------------------------
NAIVE DIVIDE AND CONQUER (still O(n^3))
----------------------------------------------------------------
Split each n x n matrix into four n/2 x n/2 submatrices:
  A = [A11 A12]   B = [B11 B12]
      [A21 A22]       [B21 B22]

  C11 = A11*B11 + A12*B21   (2 multiplications, 1 addition)
  C12 = A11*B12 + A12*B22   (2 multiplications, 1 addition)
  C21 = A21*B11 + A22*B21   (2 multiplications, 1 addition)
  C22 = A21*B12 + A22*B22   (2 multiplications, 1 addition)

  8 recursive multiplications + 4 additions:
  T(n) = 8T(n/2) + O(n^2)  -> Master Theorem Case 1 -> O(n^3)
  Same as naive! The division didn't help.

----------------------------------------------------------------
STRASSEN'S KEY INSIGHT (7 multiplications)
----------------------------------------------------------------
Reduce from 8 to 7 recursive multiplications at the cost of
more additions. (Additions are O(n^2), cheaper than multiplications.)

  Compute 7 intermediate products:
  M1 = (A11 + A22) * (B11 + B22)
  M2 = (A21 + A22) * B11
  M3 = A11 * (B12 - B22)
  M4 = A22 * (B21 - B11)
  M5 = (A11 + A12) * B22
  M6 = (A21 - A11) * (B11 + B12)
  M7 = (A12 - A22) * (B21 + B22)

  Reconstruct C:
  C11 = M1 + M4 - M5 + M7
  C12 = M3 + M5
  C21 = M2 + M4
  C22 = M1 - M2 + M3 + M6

  7 multiplications + 18 additions:
  T(n) = 7T(n/2) + O(n^2)
  c_crit = log_2(7) ≈ 2.807
  --> T(n) = O(n^2.807)  [vs O(n^3) naive]

  For large n: significant improvement.
  Strassen's algorithm breaks the O(n^3) barrier.

----------------------------------------------------------------
PRACTICAL CONSIDERATIONS
----------------------------------------------------------------
  FASTER THAN O(n^3):
    Strassen: O(n^2.807)
    Coppersmith-Winograd: O(n^2.376)
    Current best: O(n^2.371) (Le Gall 2014)

  IN PRACTICE:
    - Strassen has larger constant factor
    - Poor cache behavior due to irregular access
    - Numerical instability (floating point accumulates errors)
    - Used in LAPACK for n > 1000
    - For small n: naive is faster
    - Hybrid: Strassen until n = ~64, then naive

  JAVA:
    No built-in Strassen. Use Apache Commons Math or EJML libraries.
    For competitive programming: implement manually for giant matrices.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Key insight: reduce 8 multiplications to 7 using algebraic
     identities -- additions are cheaper
  2. T(n) = 7T(n/2) + O(n^2) -> O(n^log2(7)) = O(n^2.807)
  3. Rarely asked to implement -- usually asked conceptually:
     "How can we do better than O(n^3) for matrix multiplication?"
  4. Practical: Strassen beats naive around n=64-100 depending
     on hardware and implementation
  5. D&C principle: reducing the number of subproblems (8->7)
     is more impactful than reducing the combination cost
