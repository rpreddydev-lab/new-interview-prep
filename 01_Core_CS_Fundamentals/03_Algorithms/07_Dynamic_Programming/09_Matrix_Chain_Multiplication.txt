================================================================
  MATRIX CHAIN MULTIPLICATION
================================================================

----------------------------------------------------------------
PROBLEM
----------------------------------------------------------------
Given n matrices A1, A2, ..., An to multiply in order,
find the parenthesization that minimizes scalar multiplications.

  Matrix sizes: p[0]*p[1], p[1]*p[2], ..., p[n-1]*p[n]
  To multiply Ai (a x b) by Aj (b x c): cost = a * b * c

  Example: p = [10, 30, 5, 60]
    A1: 10x30, A2: 30x5, A3: 5x60
    (A1*A2)*A3: (10*30*5) + (10*5*60) = 1500 + 3000 = 4500
    A1*(A2*A3): (30*5*60) + (10*30*60) = 9000 + 18000 = 27000
    Optimal: 4500

----------------------------------------------------------------
DP FORMULATION
----------------------------------------------------------------
  State: dp[i][j] = min cost to multiply matrices i through j
  Transition: try all split points k (i <= k < j)
    dp[i][j] = min over k of: dp[i][k] + dp[k+1][j] + p[i]*p[k+1]*p[j+1]
  Base: dp[i][i] = 0 (single matrix, no multiplication)
  Fill order: increasing INTERVAL LENGTH (diagonal filling)

  int matrixChain(int[] p) {
    int n = p.length - 1;  // number of matrices
    int[][] dp = new int[n][n];
    // len = chain length from 2 to n
    for (int len = 2; len <= n; len++) {
      for (int i = 0; i <= n - len; i++) {
        int j = i + len - 1;
        dp[i][j] = Integer.MAX_VALUE;
        for (int k = i; k < j; k++) {
          int cost = dp[i][k] + dp[k+1][j] + p[i] * p[k+1] * p[j+1];
          dp[i][j] = Math.min(dp[i][j], cost);
        }
      }
    }
    return dp[0][n-1];
  }

  Time: O(n^3)  Space: O(n^2)

----------------------------------------------------------------
INTERVAL DP PATTERN
----------------------------------------------------------------
Matrix Chain is the canonical INTERVAL DP problem.
Interval DP: optimize over contiguous subarrays/segments.
  State: dp[i][j] = answer for interval [i, j]
  Fill order: increasing interval length
  Transition: split at every possible point k

  Other Interval DP problems:
    Burst Balloons (LC 312)
    Palindrome Partitioning II (LC 132)
    Strange Printer (LC 664)
    Minimum Cost Tree from Leaf Values (LC 1130)
    Zuma Game

----------------------------------------------------------------
BURST BALLOONS (LC 312) -- Interval DP
----------------------------------------------------------------
Burst all balloons to maximize coins. Balloon[i] * Balloon[left] * Balloon[right].

  Key insight: think of LAST balloon in range [i..j] to burst (not first).
  dp[i][j] = max coins for range (i..j) exclusive (i and j are boundaries).
  Transition: for each k in (i..j) as last to burst:
    dp[i][j] = max(dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])

  int maxCoins(int[] nums) {
    int n = nums.length;
    int[] a = new int[n + 2];       // add boundary 1s
    a[0] = a[n+1] = 1;
    for (int i = 0; i < n; i++) a[i+1] = nums[i];
    int m = n + 2;
    int[][] dp = new int[m][m];     // dp[i][j]: open interval (i..j)
    for (int len = 2; len < m; len++)
      for (int i = 0; i + len < m; i++) {
        int j = i + len;
        for (int k = i+1; k < j; k++)
          dp[i][j] = Math.max(dp[i][j], dp[i][k] + dp[k][j] + a[i]*a[k]*a[j]);
      }
    return dp[0][m-1];
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Matrix Chain = classic O(n^3) interval DP
  2. Key: fill by INTERVAL LENGTH (len=2 to n), not row by row
  3. Burst Balloons: think of LAST balloon burst (not first)
     This is the key insight that makes the subproblems non-overlapping
  4. Interval DP template: dp[i][j], length outer, split k inner
  5. When to use interval DP: operations on subarrays/substrings where
     splitting at different points gives different costs
