================================================================
  GCD, LCM, AND EUCLIDEAN ALGORITHM
================================================================

----------------------------------------------------------------
GCD (GREATEST COMMON DIVISOR)
----------------------------------------------------------------
Euclidean algorithm: gcd(a, b) = gcd(b, a % b)  until b = 0.
  Base case: gcd(a, 0) = a.

  int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }
  // Iterative:
  while (b != 0) { int t = b; b = a % b; a = t; }
  // a is now gcd

  Time: O(log(min(a,b)))  --  number of steps <= 2 * log_phi(min(a,b))
  Java built-in: java.math.BigInteger.gcd() (for large numbers)

  GCD properties:
    gcd(a, 0) = a
    gcd(a, b) = gcd(b, a % b)
    gcd(a, b) = gcd(b, a)  (commutative)
    gcd divides both a and b

----------------------------------------------------------------
LCM (LEAST COMMON MULTIPLE)
----------------------------------------------------------------
  lcm(a, b) = a / gcd(a, b) * b   (divide first to avoid overflow)
  Note: (a * b) / gcd(a, b) can overflow for large a, b.
  Safe: (long)a / gcd(a,b) * b

  long lcm(long a, long b) { return a / gcd(a, b) * b; }

  LCM of array: reduce pairwise. lcm(a[0], a[1], ...) = lcm(lcm(a[0],a[1]), a[2], ...)

----------------------------------------------------------------
EXTENDED EUCLIDEAN ALGORITHM
----------------------------------------------------------------
Finds x, y such that: a*x + b*y = gcd(a, b) (Bezout's identity).
Used for modular inverse when gcd(a, m) = 1.

  int[] extGcd(int a, int b) {
    if (b == 0) return new int[]{a, 1, 0};  // gcd, x, y
    int[] res = extGcd(b, a % b);
    return new int[]{res[0], res[2], res[1] - (a / b) * res[2]};
  }
  // extGcd(a, m)[1] % m = modular inverse of a mod m (if gcd(a,m)==1)

----------------------------------------------------------------
COMMON APPLICATIONS
----------------------------------------------------------------
  Greatest Common Divisor of Strings (LC 1071):
    "ABC"+"ABCABC" == "ABCABC"+"ABC" -> gcd string length = gcd(len1,len2)

  Water Jug Problem (LC 365):
    Can measure z liters with jugs x and y?
    z % gcd(x, y) == 0 (Bezout's identity)

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Euclidean gcd: elegant 1-liner; O(log n)
  2. LCM: always divide before multiply to avoid overflow
  3. GCD strings (LC 1071): elegant solution with concatenation check + gcd
  4. Extended Euclidean gives modular inverse -- needed for modular division
  5. gcd(array) = gcd reduce pairwise; stops when gcd = 1 (early termination)
