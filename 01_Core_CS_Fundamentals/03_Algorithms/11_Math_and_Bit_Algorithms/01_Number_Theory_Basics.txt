PRIME NUMBERS
----------------------------------------------------------------
  Primality test (trial division):
    boolean isPrime(int n) {
      if (n < 2) return false;
      for (int i = 2; i * i <= n; i++)  // only check up to sqrt(n)
        if (n % i == 0) return false;
      return true;
    }
    Time: O(sqrt(n))

  Why sqrt(n)? If n = a * b and a <= b, then a <= sqrt(n).
  If no factor up to sqrt(n), then n is prime.

  Count primes up to n: Sieve of Eratosthenes (file 02) -- O(n log log n)

----------------------------------------------------------------
PRIME FACTORIZATION
----------------------------------------------------------------
  Map<Integer, Integer> primeFactors(int n) {
    Map<Integer, Integer> factors = new HashMap<>();
    for (int d = 2; d * d <= n; d++) {
      while (n % d == 0) {
        factors.merge(d, 1, Integer::sum);
        n /= d;
      }
    }
    if (n > 1) factors.put(n, 1);  // n itself is prime
    return factors;
  }
  Time: O(sqrt(n))

----------------------------------------------------------------
DIVISOR COUNT AND SUM
----------------------------------------------------------------
  Divisors come in pairs (d, n/d). Count up to sqrt(n).
  If d * d == n: one divisor (d itself), add once.

  int countDivisors(int n) {
    int count = 0;
    for (int d = 1; d * d <= n; d++) {
      if (n % d == 0) {
        count += (d * d == n) ? 1 : 2;
      }
    }
    return count;
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Prime check: loop i up to sqrt(n); use i*i<=n to avoid sqrt()
  2. 1 is NOT prime; 2 is the only even prime
  3. Integer Break: break into 3s for maximum product
     (never break into 1; 2*2 > 1*1*1*1; 3*3 > 2*2*2)
  4. Overflow: for large n, use long; i*i can overflow if i is int
     -- safer: i <= n/i instead of i*i <= n
  5. Perfect square check: (int)Math.sqrt(n)^2 == n (but watch float precision)
     safer: binary search or Newton's method
