================================================================
  SELECTION SORT
================================================================

----------------------------------------------------------------
HOW IT WORKS
----------------------------------------------------------------
Find the minimum element in the unsorted portion and swap it
to the beginning of the unsorted portion.

  void selectionSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
      int minIdx = i;
      for (int j = i + 1; j < n; j++)
        if (arr[j] < arr[minIdx]) minIdx = j;
      int tmp = arr[i]; arr[i] = arr[minIdx]; arr[minIdx] = tmp;
    }
  }

  Time:  O(n^2) always (no early exit)   Space: O(1)
  In-place: Yes   Stable: No (swap can displace equal elements)

  Number of swaps: exactly n-1 (one per pass) -- MINIMUM possible.
  This makes Selection Sort good when WRITES are expensive
  (e.g., EEPROM / flash memory with limited write cycles).

----------------------------------------------------------------
SELECTION SORT vs INSERTION SORT
----------------------------------------------------------------
  Feature                Selection Sort    Insertion Sort
  -------------------------------------------------------
  Comparisons            O(n^2) always     O(n^2) worst, O(n) best
  Swaps/writes           O(n)              O(n^2) worst
  Stability              No                Yes
  Adaptive               No                Yes (sorted input = O(n))
  Best for               Write-expensive   Nearly sorted input

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Selection Sort's advantage: minimum number of writes (O(n))
     -- useful when writes are costly (hardware contexts)
  2. NOT adaptive -- O(n^2) even on sorted array
  3. NOT stable -- the swap can move an element past equal elements
  4. In practice: insertion sort is better for small n
