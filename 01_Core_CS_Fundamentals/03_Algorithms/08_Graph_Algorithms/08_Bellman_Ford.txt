================================================================
  BELLMAN-FORD ALGORITHM
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Single-source shortest path that handles NEGATIVE WEIGHT EDGES.
Also detects NEGATIVE WEIGHT CYCLES.

  Relax ALL edges (V-1) times.
  V-1 iterations = longest possible shortest path has V-1 edges.
  After V-1 iterations, if any edge can still be relaxed --> negative cycle.

  Time: O(V * E)  Space: O(V)
  Slower than Dijkstra but handles negative weights.

----------------------------------------------------------------
IMPLEMENTATION
----------------------------------------------------------------
  int[] bellmanFord(int n, int[][] edges, int src) {
    // edges: [u, v, weight]
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;

    for (int i = 0; i < n - 1; i++) {    // relax V-1 times
      for (int[] edge : edges) {
        int u = edge[0], v = edge[1], w = edge[2];
        if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v])
          dist[v] = dist[u] + w;
      }
    }

    // Check for negative cycles: if any edge can still be relaxed
    for (int[] edge : edges) {
      int u = edge[0], v = edge[1], w = edge[2];
      if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v])
        throw new RuntimeException("Negative cycle detected");
    }
    return dist;
  }

----------------------------------------------------------------
BELLMAN-FORD WITH K ITERATIONS (LC 787 -- Cheapest Flights)
----------------------------------------------------------------
Run only K+1 iterations of Bellman-Ford for at-most-K-stops constraint.
  IMPORTANT: use a COPY of dist array per iteration to avoid
  using same-round updates (Bellman-Ford relaxes in order within iteration).

  for (int i = 0; i <= k; i++) {
    int[] temp = Arrays.copyOf(dist, n);
    for (int[] flight : flights)
      if (dist[flight[0]] != Integer.MAX_VALUE)
        temp[flight[1]] = Math.min(temp[flight[1]], dist[flight[0]] + flight[2]);
    dist = temp;    // apply updates for this iteration
  }

----------------------------------------------------------------
BELLMAN-FORD vs DIJKSTRA
----------------------------------------------------------------
  Feature             Dijkstra                  Bellman-Ford
  -------             --------                  ------------
  Negative weights    NO                        YES
  Negative cycles     NO (incorrect result)     Detects them
  Time complexity     O((V+E) log V)            O(VE)
  Data structure      Priority Queue            Array only
  Use case            Road networks             Arbitrage detection

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Bellman-Ford: use when negative weights possible or cycle detection needed
  2. V-1 iterations guaranteed to find shortest paths (if no negative cycle)
  3. The K-iteration variant is key for LC 787 type problems
  4. COPY dist array per iteration in K-stops variant to prevent
     chaining updates within one iteration
  5. Negative cycle in finance = arbitrage opportunity (classic application)
