================================================================
  STRONGLY CONNECTED COMPONENTS: KOSARAJU'S ALGORITHM
================================================================

----------------------------------------------------------------
CORE CONCEPT
----------------------------------------------------------------
Strongly Connected Component (SCC): a maximal subset of vertices
such that every vertex is reachable from every other vertex.

Kosaraju's Algorithm -- Two-pass DFS:
  Pass 1: Run DFS on original graph. Push nodes to stack in
          FINISH ORDER (post-order).
  Pass 2: Reverse all edges. Pop nodes from stack, run DFS on
          reversed graph. Each DFS tree = one SCC.

  Key insight: on the reversed graph, if we start from a node
  that finished LAST in pass 1, we can only reach nodes in its SCC.

  Time: O(V + E)  Space: O(V + E)

----------------------------------------------------------------
IMPLEMENTATION
----------------------------------------------------------------
  List<List<Integer>> kosaraju(int n, List<List<Integer>> adj) {
    // Pass 1: DFS on original, record finish order
    boolean[] visited = new boolean[n];
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < n; i++)
      if (!visited[i]) dfs1(adj, visited, stack, i);

    // Build reversed graph
    List<List<Integer>> rev = new ArrayList<>();
    for (int i = 0; i < n; i++) rev.add(new ArrayList<>());
    for (int u = 0; u < n; u++) for (int v : adj.get(u)) rev.get(v).add(u);

    // Pass 2: DFS on reversed graph in reverse finish order
    Arrays.fill(visited, false);
    List<List<Integer>> sccs = new ArrayList<>();
    while (!stack.isEmpty()) {
      int node = stack.pop();
      if (!visited[node]) {
        List<Integer> scc = new ArrayList<>();
        dfs2(rev, visited, scc, node);
        sccs.add(scc);
      }
    }
    return sccs;
  }

  void dfs1(List<List<Integer>> adj, boolean[] vis, Deque<Integer> stack, int node) {
    vis[node] = true;
    for (int nb : adj.get(node)) if (!vis[nb]) dfs1(adj, vis, stack, nb);
    stack.push(node);  // push AFTER all children (post-order)
  }

  void dfs2(List<List<Integer>> rev, boolean[] vis, List<Integer> scc, int node) {
    vis[node] = true;
    scc.add(node);
    for (int nb : rev.get(node)) if (!vis[nb]) dfs2(rev, vis, scc, nb);
  }

----------------------------------------------------------------
APPLICATIONS
----------------------------------------------------------------
  - Count SCCs: the result of Kosaraju's / Tarjan's gives count
  - Condensation graph: condense each SCC to single node -> DAG
  - LC 1192: Critical Connections (bridges) -- use Tarjan's
  - 2-SAT problem: boolean satisfiability with 2-literal clauses

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Kosaraju's = 2 DFS passes (original + reversed graph)
  2. Key: push to stack in POST-ORDER (after all children processed)
  3. Alternative: Tarjan's SCC (single DFS, uses discovery time + low link)
  4. SCC count useful: problems where "how many independent groups?"
  5. For bridge/articulation point problems: use Tarjan's (file 12)
