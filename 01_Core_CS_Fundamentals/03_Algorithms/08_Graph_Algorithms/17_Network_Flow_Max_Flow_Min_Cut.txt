NETWORK FLOW: MAX FLOW AND MIN CUT
====================================

INTRODUCTION
-------------
  Network flow models problems involving routing a "commodity" (data,
  water, traffic) through a directed graph with capacity constraints.

  Key concepts:
  - Flow Network: directed graph G = (V, E)
  - Each edge (u,v) has capacity c(u,v) ≥ 0
  - Source s: where flow originates
  - Sink t: where flow terminates
  - Flow f(u,v): amount flowing along edge (u,v), 0 ≤ f(u,v) ≤ c(u,v)
  - Flow conservation: for every node v ≠ s,t:
      Σ f(u,v) = Σ f(v,w)  (inflow = outflow)
  - Max flow: maximize total flow from s to t

─────────────────────────────────────────────────────────────
MAX FLOW — MIN CUT THEOREM
─────────────────────────────────────────────────────────────
  Max-Flow Min-Cut Theorem (Ford & Fulkerson, 1956):
    Maximum flow from s to t  =  Minimum s-t cut capacity

  An s-t CUT is a partition of vertices into set S (contains s) and
  T (contains t). The cut capacity = Σ c(u,v) for edges (u→v) crossing S→T.

  Intuition: the bottleneck of a network is its minimum cut —
  the smallest total capacity of edges you'd need to remove to
  disconnect s from t.

─────────────────────────────────────────────────────────────
FORD-FULKERSON METHOD
─────────────────────────────────────────────────────────────
  General framework (not a specific algorithm):
  1. Start with zero flow
  2. While there exists an AUGMENTING PATH from s to t in the residual graph:
     - Find the bottleneck capacity along the path
     - Augment flow by that amount (forward edge +, backward edge -)
  3. Return total flow

  Residual Graph:
    For each edge (u,v) with capacity c and flow f:
    - Forward edge: remaining capacity = c - f
    - Backward edge: allows "undoing" flow = f (enables rerouting)

  Time complexity: O(E × |max_flow|) with DFS — depends on flow values,
  can be slow with non-integer capacities.

─────────────────────────────────────────────────────────────
EDMONDS-KARP ALGORITHM (BFS-based)
─────────────────────────────────────────────────────────────
  Ford-Fulkerson using BFS to find shortest augmenting paths.
  Time: O(V × E²) — polynomial, independent of flow values.

  Java Implementation:
  ---------------------
  class MaxFlow {
      int[][] cap;   // capacity matrix
      int n;

      MaxFlow(int n) {
          this.n = n;
          cap = new int[n][n];
      }

      void addEdge(int u, int v, int c) {
          cap[u][v] += c;  // support multi-edges
      }

      int bfs(int s, int t, int[] parent) {
          Arrays.fill(parent, -1);
          parent[s] = s;
          Queue<int[]> queue = new LinkedList<>();
          queue.offer(new int[]{s, Integer.MAX_VALUE});

          while (!queue.isEmpty()) {
              int[] cur = queue.poll();
              int node = cur[0], flow = cur[1];
              for (int next = 0; next < n; next++) {
                  if (parent[next] == -1 && cap[node][next] > 0) {
                      parent[next] = node;
                      int newFlow = Math.min(flow, cap[node][next]);
                      if (next == t) return newFlow;
                      queue.offer(new int[]{next, newFlow});
                  }
              }
          }
          return 0;
      }

      int maxFlow(int s, int t) {
          int flow = 0;
          int[] parent = new int[n];
          int newFlow;
          while ((newFlow = bfs(s, t, parent)) > 0) {
              flow += newFlow;
              // Update residual capacities along the path
              int cur = t;
              while (cur != s) {
                  int prev = parent[cur];
                  cap[prev][cur] -= newFlow;
                  cap[cur][prev] += newFlow;  // reverse edge
                  cur = prev;
              }
          }
          return flow;
      }
  }

  Usage:
    MaxFlow mf = new MaxFlow(6);
    mf.addEdge(0, 1, 10); mf.addEdge(0, 2, 10);
    mf.addEdge(1, 2, 2);  mf.addEdge(1, 3, 4);
    mf.addEdge(1, 4, 8);  mf.addEdge(2, 4, 9);
    mf.addEdge(3, 5, 10); mf.addEdge(4, 3, 6);
    mf.addEdge(4, 5, 10);
    System.out.println(mf.maxFlow(0, 5));  // 19

─────────────────────────────────────────────────────────────
DINIC'S ALGORITHM (Most Practical for Interviews)
─────────────────────────────────────────────────────────────
  Faster: O(V² × E). For unit capacity graphs: O(E × √V).
  Key idea:
  1. Build a level graph using BFS (layered by distance from source)
  2. Find blocking flow using DFS on level graph
  3. Repeat until no path from s to t in level graph

  Much faster in practice — used in competitive programming.
  Know conceptually; Edmonds-Karp is sufficient for most interviews.

─────────────────────────────────────────────────────────────
COMPLEXITY COMPARISON
─────────────────────────────────────────────────────────────
  Algorithm          | Time Complexity    | Notes
  ───────────────────┼────────────────────┼────────────────────────────
  Ford-Fulkerson DFS | O(E × |f|)         | Bad for large/non-integer f
  Edmonds-Karp BFS   | O(V × E²)          | Practical for most problems
  Dinic's            | O(V² × E)          | Best general-purpose
  Dinic's (unit cap) | O(E × √V)          | Great for bipartite matching

─────────────────────────────────────────────────────────────
MAX FLOW APPLICATIONS (REDUCTIONS)
─────────────────────────────────────────────────────────────
  Many classical problems reduce to max flow:

  1. Bipartite Matching:
     Add source s connected to all left nodes (cap 1),
     all right nodes connected to sink t (cap 1),
     bipartite edges with cap 1.
     Max flow = maximum matching.

  2. Maximum Independent Set (Bipartite):
     By König's Theorem: Max Independent Set = n - Max Matching

  3. Minimum Vertex Cover (Bipartite):
     Min Vertex Cover = Max Matching (König's Theorem)

  4. Maximum Flow with Lower Bounds:
     Circulation problems with supply/demand constraints.

  5. Project Selection (closure problem):
     Given projects with profits and machine costs (shared between projects),
     find subset of projects maximizing profit - cost.
     Models as min-cut problem.

─────────────────────────────────────────────────────────────
COMMON INTERVIEW QUESTIONS
─────────────────────────────────────────────────────────────
  Q: State the Max-Flow Min-Cut theorem.
  A: The maximum flow from source s to sink t equals the minimum capacity
     of any s-t cut. This means the bottleneck of any flow network is
     determined by the minimum capacity set of edges separating s from t.

  Q: What is a residual graph?
  A: For each directed edge (u,v) with capacity c and current flow f:
     - Add forward edge with remaining capacity c - f
     - Add backward edge with capacity f (allows undoing flow)
     Augmenting paths are found in the residual graph.

  Q: Why do we need backward edges?
  A: To allow the algorithm to "reroute" flow. Without backward edges,
     a greedy choice of one path can block a better combination.
     Backward edges let us undo suboptimal decisions.

  Q: How does maximum bipartite matching relate to max flow?
  A: Model the bipartite graph as a flow network with a source connected
     to all left nodes and all right nodes connected to a sink (all capacities 1).
     The max flow equals the max matching (each unit of flow = one matched pair).

  Q: What is the time complexity of Edmonds-Karp?
  A: O(V × E²). It uses BFS to always find the shortest augmenting path,
     which guarantees at most O(V × E) augmentations each taking O(E) time.
