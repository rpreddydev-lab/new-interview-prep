SCHEDULE JOBS TO MINIMIZE LATE JOBS
----------------------------------------------------------------
Each job has a deadline[i] and profit[i]. Only one job per time slot.
Maximize profit by selecting jobs and scheduling within deadlines.

  Algorithm:
    1. Sort jobs by PROFIT descending
    2. For each job (greedily take highest profit):
       Find latest available time slot within its deadline
       If slot found: schedule the job

  int[] jobScheduling(int[][] jobs) {
    // jobs[i] = {deadline, profit}
    Arrays.sort(jobs, (a, b) -> b[1] - a[1]);  // by profit desc
    int maxDeadline = Arrays.stream(jobs).mapToInt(j -> j[0]).max().getAsInt();
    int[] slots = new int[maxDeadline + 1];  // 0 = empty
    int totalProfit = 0, count = 0;
    for (int[] job : jobs) {
      for (int t = job[0]; t >= 1; t--) {  // find latest free slot
        if (slots[t] == 0) {
          slots[t] = 1;
          totalProfit += job[1];
          count++;
          break;
        }
      }
    }
    return new int[]{count, totalProfit};
  }

  Time: O(n^2)  -- can be optimized to O(n log n) with DSU

JOB SCHEDULING WITH PROFIT (LC 1235)
----------------------------------------------------------------
LeetCode 1235: each job has startTime, endTime, profit.
Find non-overlapping jobs with maximum profit.
This is DP + binary search, NOT pure greedy.

  int jobScheduling(int[] startTime, int[] endTime, int[] profit) {
    int n = startTime.length;
    int[][] jobs = new int[n][3];
    for (int i = 0; i < n; i++) jobs[i] = new int[]{startTime[i], endTime[i], profit[i]};
    Arrays.sort(jobs, (a, b) -> a[1] - b[1]);  // sort by end time
    int[] dp = new int[n + 1];  // dp[i] = max profit using first i jobs
    int[] ends = new int[n];
    for (int i = 0; i < n; i++) ends[i] = jobs[i][1];
    for (int i = 0; i < n; i++) {
      // Find latest job that ends by jobs[i].start
      int lo = 0, hi = i;
      while (lo < hi) {
        int mid = (lo + hi) / 2;
        if (ends[mid] <= jobs[i][0]) lo = mid + 1; else hi = mid;
      }
      dp[i + 1] = Math.max(dp[i], dp[lo] + jobs[i][2]);
    }
    return dp[n];
  }

  Time: O(n log n)  Space: O(n)

TASK SCHEDULER (LC 621)
----------------------------------------------------------------
Given tasks with frequencies and cooldown n: CPU must wait n slots
between same-task executions. Find minimum total time.

  Greedy: always schedule the MOST FREQUENT remaining task.
  Math insight: answer = max(tasks.length, (maxFreq-1)*(n+1) + countMaxFreq)

  int leastInterval(char[] tasks, int n) {
    int[] freq = new int[26];
    for (char t : tasks) freq[t-'A']++;
    int maxFreq = Arrays.stream(freq).max().getAsInt();
    int countMax = 0;
    for (int f : freq) if (f == maxFreq) countMax++;
    return Math.max(tasks.length, (maxFreq - 1) * (n + 1) + countMax);
  }

  Insight: the most frequent task creates "frames" of size n+1.
  Other tasks fill the frames; if not enough tasks: idle slots needed.
  If total tasks > frame slots: no idle, answer = tasks.length.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Deadline scheduling: greedy by profit desc + find latest slot
  2. Non-overlapping job profit (LC 1235): DP + binary search
     (NOT pure greedy -- future choices depend on current)
  3. Task Scheduler (LC 621): count-based math formula
     (maxFreq-1)*(n+1)+countMax -- derive by drawing the frame structure
  4. Distinguish: maximize count of jobs vs maximize total profit
     The approaches differ!
  5. For "minimum slots with cooldown": think about the dominant
     (most frequent) task as driving the schedule structure
