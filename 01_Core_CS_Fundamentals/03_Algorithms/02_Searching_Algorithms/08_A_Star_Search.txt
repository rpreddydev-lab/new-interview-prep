A* SEARCH ALGORITHM
====================

INTRODUCTION
-------------
  A* (pronounced "A-star") is a best-first search algorithm that finds
  the SHORTEST PATH from a source to a target in a weighted graph.

  It combines the benefits of:
  - Dijkstra's Algorithm (guarantees shortest path)
  - Greedy Best-First Search (uses a heuristic to guide search direction)

  Key formula:
    f(n) = g(n) + h(n)

  where:
    g(n) = actual cost from start to node n
    h(n) = heuristic estimate of cost from n to goal
    f(n) = estimated total cost through node n

  A* always expands the node with the LOWEST f(n) first.

─────────────────────────────────────────────────────────────
HOW IT WORKS
─────────────────────────────────────────────────────────────
  Uses two sets:
  - Open Set (priority queue): nodes to be evaluated, ordered by f(n)
  - Closed Set (visited): nodes already evaluated

  Algorithm:
    1. Add start node to open set with f(start) = h(start)
    2. While open set is not empty:
       a. Pop node n with lowest f(n)
       b. If n == goal → reconstruct and return path
       c. Move n to closed set
       d. For each neighbor nb of n:
          - If nb in closed set → skip
          - new_g = g(n) + cost(n, nb)
          - If nb not in open set OR new_g < g(nb):
              g(nb) = new_g
              f(nb) = g(nb) + h(nb)
              parent(nb) = n
              Add nb to open set (or update priority)
    3. Return "no path found"

─────────────────────────────────────────────────────────────
HEURISTIC FUNCTION h(n) — THE KEY TO A*
─────────────────────────────────────────────────────────────
  The heuristic MUST be ADMISSIBLE:
    h(n) ≤ actual cost from n to goal  (never overestimate)

  If admissible, A* is guaranteed to find the optimal (shortest) path.

  Common admissible heuristics:
  ┌─────────────────────────────────────────────────────────────────┐
  │ Domain          │ Heuristic          │ Formula                  │
  ├─────────────────┼────────────────────┼──────────────────────────┤
  │ 2D Grid (4-dir) │ Manhattan distance │ |dx| + |dy|              │
  │ 2D Grid (8-dir) │ Chebyshev distance │ max(|dx|, |dy|)          │
  │ Any graph       │ Euclidean distance │ sqrt(dx²+dy²)            │
  │ Unweighted      │ h(n) = 0           │ (degenerates to Dijkstra)│
  └─────────────────┴────────────────────┴──────────────────────────┘

  CONSISTENCY (Monotonicity) — stronger than admissibility:
    h(n) ≤ cost(n, nb) + h(nb)  for every edge (n → nb)
  If consistent, A* never needs to revisit nodes → more efficient.

─────────────────────────────────────────────────────────────
JAVA IMPLEMENTATION
─────────────────────────────────────────────────────────────
  // Example: shortest path on a 2D grid with obstacles
  // (0 = open, 1 = blocked)

  import java.util.*;

  public class AStar {

      record Point(int r, int c) {}

      public static List<Point> astar(int[][] grid, Point start, Point goal) {
          int rows = grid.length, cols = grid[0].length;
          int[][] g = new int[rows][cols];
          for (int[] row : g) Arrays.fill(row, Integer.MAX_VALUE);
          g[start.r()][start.c()] = 0;

          Map<Point, Point> parent = new HashMap<>();

          // PQ ordered by f = g + h
          PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
          pq.offer(new int[]{heuristic(start, goal), start.r(), start.c()});

          int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

          while (!pq.isEmpty()) {
              int[] curr = pq.poll();
              Point p = new Point(curr[1], curr[2]);

              if (p.equals(goal)) return reconstructPath(parent, start, goal);

              for (int[] d : dirs) {
                  int nr = p.r() + d[0], nc = p.c() + d[1];
                  if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
                  if (grid[nr][nc] == 1) continue;  // obstacle

                  int newG = g[p.r()][p.c()] + 1;
                  if (newG < g[nr][nc]) {
                      g[nr][nc] = newG;
                      Point nb = new Point(nr, nc);
                      parent.put(nb, p);
                      int f = newG + heuristic(nb, goal);
                      pq.offer(new int[]{f, nr, nc});
                  }
              }
          }
          return Collections.emptyList();  // no path
      }

      private static int heuristic(Point a, Point b) {
          // Manhattan distance (admissible for 4-directional grid)
          return Math.abs(a.r() - b.r()) + Math.abs(a.c() - b.c());
      }

      private static List<Point> reconstructPath(Map<Point,Point> parent,
                                                  Point start, Point goal) {
          LinkedList<Point> path = new LinkedList<>();
          Point curr = goal;
          while (!curr.equals(start)) {
              path.addFirst(curr);
              curr = parent.get(curr);
          }
          path.addFirst(start);
          return path;
      }
  }

─────────────────────────────────────────────────────────────
COMPLEXITY ANALYSIS
─────────────────────────────────────────────────────────────
  Time:  O(b^d) in the worst case
         where b = branching factor, d = depth of optimal solution
         With a good heuristic, much faster in practice.

  Space: O(b^d) — stores all nodes in open/closed sets

  Compared to Dijkstra (h=0): A* explores fewer nodes by focusing toward goal.
  If h is perfect (equals actual cost): A* explores only the optimal path.

  Bidirectional A*  | ✅       | ❌       | ✅        | Single | Very long paths

─────────────────────────────────────────────────────────────
COMMON INTERVIEW QUESTIONS
─────────────────────────────────────────────────────────────
  Q: What makes A* optimal (finds shortest path)?
  A: The admissibility of the heuristic — h(n) never overestimates the
     true cost. This guarantees the first time A* reaches the goal, it
     has taken the shortest path.

  Q: What happens when h(n) = 0 for all nodes?
  A: A* degenerates into Dijkstra's algorithm — explores all nodes by
     increasing cost without any directional guidance.

  Q: What happens when h(n) = actual cost?
  A: A* explores only nodes on the optimal path — perfectly efficient.
     Rarely achievable in practice.

  Q: Can A* handle negative edge weights?
  A: No — like Dijkstra, A* assumes non-negative edge costs.
     For negative weights, use Bellman-Ford.

  Q: What is the difference between A* and greedy best-first search?
  A: Greedy BFS only uses h(n) — fast but not optimal (may take longer path).
     A* uses f(n) = g(n) + h(n) — balances actual cost and estimate,
     guaranteeing the optimal path.
