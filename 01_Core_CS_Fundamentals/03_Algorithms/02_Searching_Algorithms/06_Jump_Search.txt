----------------------------------------------------------------
WHAT IS JUMP SEARCH?
----------------------------------------------------------------
Jump Search works on SORTED arrays by jumping ahead by fixed
steps, then doing a linear search when the target range is found.

  Step size: sqrt(n)  (optimal -- minimizes total comparisons)

  Algorithm:
    1. Jump by sqrt(n) until arr[step] >= target
    2. Linear search backward from prev step to current step

  int jumpSearch(int[] arr, int target) {
    int n = arr.length;
    int step = (int) Math.sqrt(n);
    int prev = 0;
    while (arr[Math.min(step, n)-1] < target) {
      prev = step;
      step += (int) Math.sqrt(n);
      if (prev >= n) return -1;
    }
    while (arr[prev] < target) {
      prev++;
      if (prev == Math.min(step, n)) return -1;
    }
    if (arr[prev] == target) return prev;
    return -1;
  }

  Time: O(sqrt(n))   Space: O(1)

----------------------------------------------------------------
JUMP SEARCH vs BINARY SEARCH
----------------------------------------------------------------
  Feature           Jump Search        Binary Search
  -----------------------------------------------
  Time              O(sqrt(n))         O(log n)
  Space             O(1)               O(1)
  Access pattern    Forward only       Random access
  Linked list?      Possible (one dir) Not useful
  Cache friendly    Yes (sequential)   Less so (jumps around)

  sqrt(n) > log n for all n > 1, so binary search is FASTER.
  Jump search is ONLY preferred when:
    - Random access is expensive (magnetic disk, tape)
    - Forward-only access is required
    - In practice: almost never in modern software

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Jump search almost never appears in interviews; know the
     concept but don't spend time on it vs binary search
  2. Optimal step = sqrt(n): forward jumps = sqrt(n),
     linear steps within block = sqrt(n), total = 2*sqrt(n)
  3. The only meaningful advantage is forward-only access;
     in all other cases, binary search is better
  4. If asked "when would you use jump search?": hardware
     where random access is expensive or forward-only media
