===================================================================
PART 1: FUNCTIONAL INTERFACES (the types behind lambdas)
===================================================================

Interface            | Signature                  | Used in
---------------------|----------------------------|-------------------------
Predicate<T>         | boolean test(T t)          | filter(), anyMatch()
Function<T,R>        | R apply(T t)               | map(), flatMap()
BiFunction<T,U,R>    | R apply(T t, U u)          | toMap(), reduce()
Consumer<T>          | void accept(T t)           | forEach(), peek()
BiConsumer<T,U>      | void accept(T t, U u)      | forEach on Map entries
Supplier<T>          | T get()                    | orElseGet(), generate()
UnaryOperator<T>     | T apply(T t)               | replaceAll(), iterate()
BinaryOperator<T>    | T apply(T t, T u)          | reduce()
Comparator<T>        | int compare(T o1, T o2)    | sorted(), min(), max()

// Primitive-specialized (no boxing):
IntPredicate, IntFunction<R>, IntConsumer, IntSupplier, IntUnaryOperator
IntBinaryOperator, ToIntFunction<T>, IntToLongFunction …  (same for Long, Double)

// Custom @FunctionalInterface:
@FunctionalInterface
interface Transformer<A, B> {
    B transform(A input);
}
Transformer<String, Integer> len = String::length;  // method reference

PART 2: LAMBDA SYNTAX & METHOD REFERENCES
===================================================================

// Lambda forms:
x -> x * 2                          // single param, expression body
(x, y) -> x + y                     // multiple params
(String s) -> { return s.trim(); }  // explicit type, block body
() -> 42                            // no params

// Method references — 4 kinds:
ClassName::staticMethod             // Integer::parseInt
instance::instanceMethod            // System.out::println
ClassName::instanceMethod           // String::toLowerCase  (first arg = receiver)
ClassName::new                      // ArrayList::new  (constructor ref)

// Examples:
list.stream().map(Integer::parseInt).collect(Collectors.toList());
list.stream().forEach(System.out::println);
list.stream().sorted(String::compareTo).collect(Collectors.toList());
Stream.generate(ArrayList::new);

PART 3: STREAM CREATION
===================================================================

// From collections
list.stream()
set.stream()
map.entrySet().stream()
map.values().stream()
map.keySet().stream()

// From arrays
Arrays.stream(arr)                  // IntStream for int[], LongStream for long[]
Arrays.stream(arr, from, to)        // range slice
Stream.of("a", "b", "c")           // varargs
Arrays.stream(objArr)              // Stream<Object>

// Numeric ranges
IntStream.range(0, 10)             // 0,1,...,9
IntStream.rangeClosed(1, 10)       // 1,2,...,10
LongStream.range(0L, n)

// Infinite / generated streams
Stream.iterate(0, n -> n + 2)                        // 0,2,4,6,...  (infinite)
Stream.iterate(0, n -> n < 100, n -> n + 2)          // Java 9+: with hasNext predicate
Stream.generate(Math::random)                         // infinite random doubles

// Other sources
"hello world".chars()              // IntStream of char codes
"a,b,c".lines()                    // Stream<String> (Java 11+)
Files.lines(Path.of("file.txt"))   // Stream<String> lines (must close!)
Collections.singletonList(x).stream()
Stream.empty()
Stream.concat(stream1, stream2)

// Boxed / unboxed conversions
IntStream.range(0, 5).boxed()       // IntStream → Stream<Integer>
list.stream().mapToInt(Integer::intValue)  // Stream<Integer> → IntStream

===================================================================
PART 4: INTERMEDIATE OPERATIONS (lazy — nothing executes until terminal)
===================================================================

--- FILTER ---
.filter(x -> x > 0)
.filter(Objects::nonNull)
.filter(s -> !s.isEmpty())

--- MAP (transform each element) ---
.map(String::toUpperCase)
.map(x -> x * x)
.mapToInt(String::length)          // Stream<T> → IntStream (no boxing)
.mapToLong(...)
.mapToDouble(...)
.mapToObj(i -> "val" + i)         // IntStream → Stream<String>

--- FLATMAP (one-to-many — flattens nested streams) ---
// List<List<Integer>> → flat Stream<Integer>
listOfLists.stream()
    .flatMap(Collection::stream)
    .collect(Collectors.toList());

// "hello world".chars() splits string into chars; flatMap can split words into chars:
Arrays.stream(text.split(" "))
    .flatMap(word -> word.chars().mapToObj(c -> (char) c + ""))
    .collect(Collectors.toList());

// IntStream.flatMap for int arrays:
Arrays.stream(arr2d).flatMapToInt(Arrays::stream).toArray();  // 2D → 1D

--- DISTINCT / SORTED / LIMIT / SKIP ---
.distinct()                         // uses equals/hashCode
.sorted()                           // natural order (must implement Comparable)
.sorted(Comparator.reverseOrder())
.sorted(Comparator.comparing(Person::getAge).thenComparing(Person::getName))
.limit(5)                           // first 5 elements
.skip(3)                            // drop first 3

--- PEEK (debug without consuming) ---
.peek(x -> System.out.println("before: " + x))
.filter(x -> x > 0)
.peek(x -> System.out.println("after:  " + x))

--- TAKEWHILE / DROPWHILE (Java 9+) ---
Stream.of(1,2,3,4,5).takeWhile(x -> x < 4)   // 1,2,3
Stream.of(1,2,3,4,5).dropWhile(x -> x < 4)   // 4,5

===================================================================
PART 5: TERMINAL OPERATIONS
===================================================================

--- FOREACH / FOREACHORDERED ---
.forEach(System.out::println)          // order not guaranteed for parallel
.forEachOrdered(System.out::println)   // encounter order guaranteed

--- COLLECT (most powerful terminal op — see Part 6 for Collectors) ---
.collect(Collectors.toList())
.collect(Collectors.toSet())
.collect(Collectors.toMap(...))

--- REDUCE ---
// reduce(identity, accumulator) — always returns T
int sum = IntStream.rangeClosed(1, 10).reduce(0, Integer::sum);

// reduce(accumulator) — returns Optional<T> (stream may be empty)
Optional<Integer> product = list.stream().reduce((a, b) -> a * b);

// reduce(identity, accumulator, combiner) — for parallel streams with type change
int sumOfLengths = words.stream()
    .reduce(0, (acc, w) -> acc + w.length(), Integer::sum);

--- COUNT / SUM / MIN / MAX / AVERAGE ---
long count   = list.stream().count();
int  sum     = list.stream().mapToInt(Integer::intValue).sum();
int  max     = list.stream().mapToInt(x -> x).max().getAsInt();
int  min     = list.stream().mapToInt(x -> x).min().getAsInt();
double avg   = list.stream().mapToInt(x -> x).average().orElse(0.0);

// With Optional for object streams:
Optional<String> longest = list.stream()
    .max(Comparator.comparingInt(String::length));

--- MATCH ---
boolean anyOver100 = list.stream().anyMatch(x -> x > 100);   // short-circuits
boolean allPos     = list.stream().allMatch(x -> x > 0);     // short-circuits
boolean noneNull   = list.stream().noneMatch(Objects::isNull);

--- FIND ---
Optional<String> first = list.stream().filter(s -> s.startsWith("A")).findFirst();
Optional<String> any   = list.stream().filter(s -> s.startsWith("A")).findAny(); // parallel-friendly

--- TOINTARRAY / TOARRAY ---
int[]      arr  = IntStream.range(0, 5).toArray();
String[]   sarr = list.stream().toArray(String[]::new);
Integer[]  iarr = list.stream().toArray(Integer[]::new);

--- ITERATOR / SPLITERATOR (rare — only when you must loop manually) ---
Iterator<String> it = list.stream().iterator();

===================================================================
PART 6: COLLECTORS — THE DEEP DIVE
===================================================================

--- BASIC COLLECTORS ---
Collectors.toList()                                  // ArrayList (mutable)
Collectors.toUnmodifiableList()                      // Java 10+ immutable
Collectors.toSet()                                   // HashSet
Collectors.toUnmodifiableSet()
Collectors.joining()                                 // concatenate strings
Collectors.joining(", ")                             // with delimiter
Collectors.joining(", ", "[", "]")                  // prefix + suffix: [a, b, c]
Collectors.counting()                                // Long count
Collectors.summingInt(fn)                            // sum by mapping fn
Collectors.averagingInt(fn)                          // average (Double)
Collectors.summarizingInt(fn)                        // IntSummaryStatistics

--- toMap ---
// toMap(keyMapper, valueMapper)
Map<String, Integer> nameLenMap = list.stream()
    .collect(Collectors.toMap(s -> s, String::length));

// toMap with merge function (handles duplicate keys)
Map<String, Integer> freq = list.stream()
    .collect(Collectors.toMap(s -> s, s -> 1, Integer::sum));

// toMap with specific map type
Map<String, Integer> sorted = list.stream()
    .collect(Collectors.toMap(s -> s, String::length,
             (a, b) -> a, TreeMap::new));

--- groupingBy ---
// groupingBy(classifier) → Map<K, List<T>>
Map<Integer, List<String>> byLength = list.stream()
    .collect(Collectors.groupingBy(String::length));

// groupingBy with downstream collector
Map<Integer, Long> countByLength = list.stream()
    .collect(Collectors.groupingBy(String::length, Collectors.counting()));

Map<Integer, List<String>> byLengthUpper = list.stream()
    .collect(Collectors.groupingBy(
        String::length,
        Collectors.mapping(String::toUpperCase, Collectors.toList())));

Map<String, Optional<Employee>> topEarnerByDept = employees.stream()
    .collect(Collectors.groupingBy(
        Employee::getDepartment,
        Collectors.maxBy(Comparator.comparingInt(Employee::getSalary))));

// groupingBy → then count → then sort (a very common interview chain):
Map<Character, Long> charFreq = s.chars()
    .mapToObj(c -> (char) c)
    .collect(Collectors.groupingBy(c -> c, Collectors.counting()));

// Most frequent character:
char mostFreq = charFreq.entrySet().stream()
    .max(Map.Entry.comparingByValue())
    .get().getKey();

--- partitioningBy ---
// Splits into exactly two groups: true and false
Map<Boolean, List<Integer>> evenOdd = list.stream()
    .collect(Collectors.partitioningBy(x -> x % 2 == 0));
List<Integer> evens = evenOdd.get(true);

// partitioningBy with downstream:
Map<Boolean, Long> evenOddCount = list.stream()
    .collect(Collectors.partitioningBy(x -> x % 2 == 0, Collectors.counting()));

--- toCollection ---
// When you need a specific collection type:
Deque<String> deque = list.stream()
    .collect(Collectors.toCollection(ArrayDeque::new));
TreeSet<String> treeSet = list.stream()
    .collect(Collectors.toCollection(TreeSet::new));

--- collectingAndThen ---
// Applies a finishing function after collecting
List<String> unmodifiable = list.stream()
    .collect(Collectors.collectingAndThen(Collectors.toList(),
             Collections::unmodifiableList));

// Get the single element from a one-element stream:
String only = list.stream()
    .collect(Collectors.collectingAndThen(Collectors.toList(),
             l -> l.get(0)));

--- teeing (Java 12+) ---
// Apply two collectors simultaneously and merge results
Map.Entry<Long, Optional<Integer>> result = list.stream()
    .collect(Collectors.teeing(
        Collectors.counting(),
        Collectors.maxBy(Integer::compare),
        Map::entry));

===================================================================
PART 7: OPTIONAL — AVOID NULL POINTER EXCEPTIONS
===================================================================

Optional<String> opt = Optional.of("hello");          // throws if null
Optional<String> optN = Optional.ofNullable(value);   // null → empty
Optional<String> empty = Optional.empty();

// Check & get
opt.isPresent()
opt.isEmpty()                           // Java 11+
opt.get()                               // throws NoSuchElementException if empty!

// Safe retrieval
opt.orElse("default")                   // return default if empty
opt.orElseGet(() -> computeDefault())   // lazy default (only calls fn if empty)
opt.orElseThrow()                       // Java 10+: throw NoSuchElementException
opt.orElseThrow(IllegalStateException::new)

// Transform if present
opt.map(String::toUpperCase)            // Optional<String>
opt.flatMap(s -> Optional.of(s.trim())) // avoid Optional<Optional<T>>
opt.filter(s -> s.length() > 3)        // Optional<String> or empty
opt.ifPresent(System.out::println)      // side-effect if present
opt.ifPresentOrElse(                    // Java 9+
    s -> System.out.println(s),
    () -> System.out.println("empty"));

// Common idiom: chain map + orElse
String upper = opt.map(String::toUpperCase).orElse("N/A");

// IntStream-specific ops (no boxing overhead):
IntStream.of(1, 2, 3, 4, 5)

// Common: sum of int array
int sum = Arrays.stream(nums).sum();

int[] digits = String.valueOf(n).chars()
    .map(c -> c - '0')
    .toArray();

// Common: array of squares
int[] squares = IntStream.rangeClosed(1, n).map(i -> i * i).toArray();

PART 9: INTERVIEW CODING PATTERNS USING STREAMS
===================================================================

--- PATTERN 1: Frequency map of characters ---
Map<Character, Long> freq = s.chars()
    .mapToObj(c -> (char) c)
    .collect(Collectors.groupingBy(c -> c, Collectors.counting()));

// Alternative (faster, int array):
int[] freq = new int[26];
s.chars().forEach(c -> freq[c - 'a']++);

--- PATTERN 2: Top K frequent elements ---
List<Integer> topK = freq.entrySet().stream()
    .sorted(Map.Entry.<Integer, Integer>comparingByValue().reversed())
    .limit(k)
    .map(Map.Entry::getKey)
    .collect(Collectors.toList());

--- PATTERN 3: Word frequency from text ---
Map<String, Long> wordFreq = Arrays.stream(text.split("\\s+"))
    .collect(Collectors.groupingBy(String::toLowerCase, Collectors.counting()));

--- PATTERN 4: Anagram grouping ---
Map<String, List<String>> groups = Arrays.stream(words)
    .collect(Collectors.groupingBy(w -> {
        char[] c = w.toCharArray(); Arrays.sort(c); return new String(c);
    }));

--- PATTERN 5: Flatten and deduplicate ---
List<Integer> flat = lists.stream()
    .flatMap(Collection::stream)
    .distinct()
    .sorted()
    .collect(Collectors.toList());

--- PATTERN 6: Partition numbers into evens and odds ---
Map<Boolean, List<Integer>> parts = nums.stream()
    .collect(Collectors.partitioningBy(n -> n % 2 == 0));

--- PATTERN 7: Maximum by custom key ---
Employee topEarner = employees.stream()
    .max(Comparator.comparingInt(Employee::getSalary))
    .orElseThrow();

--- PATTERN 8: Sum of squares ---
int sumSq = IntStream.rangeClosed(1, n).map(i -> i * i).sum();

--- PATTERN 9: Convert List<String> to comma-separated String ---
String csv = list.stream().collect(Collectors.joining(", "));

--- PATTERN 10: Reverse a list using streams (not in-place) ---
List<Integer> rev = IntStream.range(0, list.size())
    .mapToObj(i -> list.get(list.size() - 1 - i))
    .collect(Collectors.toList());
// Simpler: Collections.reverse(list); — O(n) in-place

--- PATTERN 11: Count distinct characters in a string ---
long distinct = s.chars().distinct().count();

--- PATTERN 12: Check if two strings are anagrams ---
boolean anagram = s.chars().sorted().toArray()[0] ==
                  t.chars().sorted().toArray()[0]  // wrong – just first char
// CORRECT:
boolean anagram = Arrays.equals(s.chars().sorted().toArray(),
                                t.chars().sorted().toArray());

--- PATTERN 13: Build adjacency list from edge list ---
Map<Integer, List<Integer>> graph = new HashMap<>();
Arrays.stream(edges).forEach(e -> {
    graph.computeIfAbsent(e[0], k -> new ArrayList<>()).add(e[1]);
    graph.computeIfAbsent(e[1], k -> new ArrayList<>()).add(e[0]);
});

--- PATTERN 14: Map values transformation ---
Map<String, Integer> uppercasedLen = original.entrySet().stream()
    .collect(Collectors.toMap(
        e -> e.getKey().toUpperCase(),
        Map.Entry::getValue));

--- PATTERN 15: Running cumulative sum using iterate (Java 9+) ---
int[] prefix = new int[nums.length + 1];
IntStream.range(0, nums.length).forEach(i -> prefix[i+1] = prefix[i] + nums[i]);

PART 10: PARALLEL STREAMS
===================================================================

// Activate parallel processing:
list.parallelStream()
list.stream().parallel()

// Convert back to sequential:
stream.sequential()

// When to use parallel:
// ✅ Large data sets (> 10,000 elements)
// ✅ CPU-bound, stateless operations
// ✅ No shared mutable state
// ❌ Small collections (thread overhead dominates)
// ❌ Ordered operations (forEachOrdered needed)
// ❌ I/O-bound tasks (use virtual threads instead)
// ❌ When order of side effects matters

// Example:
long count = LongStream.rangeClosed(1, 1_000_000L)
    .parallel()
    .filter(n -> n % 2 == 0)
    .count();

// Thread-safe collection with parallel:
List<String> result = list.parallelStream()
    .filter(s -> s.startsWith("A"))
    .collect(Collectors.toList());  // Collectors are thread-safe

// DANGER: never use non-thread-safe collection in parallel forEach:
// BAD:  parallelStream().forEach(result::add)  ← ArrayList is not thread-safe

===================================================================
PART 11: COMMON MISTAKES WITH STREAMS
===================================================================

MISTAKE 1: Reusing a stream
  Stream<String> s = list.stream();
  s.forEach(...);
  s.forEach(...);  // ← IllegalStateException: stream has already been operated upon
  FIX: get a fresh stream each time

MISTAKE 2: Modifying the source during stream operation
  list.stream().filter(x -> list.remove(x));  // ← ConcurrentModificationException
  FIX: collect first, then operate on the result

MISTAKE 3: Calling .get() on Optional without checking
  opt.get()  // ← throws if empty
  FIX: use orElse / orElseThrow / ifPresent

MISTAKE 4: Forgetting flatMap when dealing with nested structures
  // Stream<List<Integer>> — map gives Stream<Stream<Integer>>
  stream.map(Collection::stream)    // WRONG — gives Stream<Stream<Integer>>
  stream.flatMap(Collection::stream) // CORRECT — gives Stream<Integer>

MISTAKE 5: Using stateful lambdas in parallel streams
  List<Integer> bad = new ArrayList<>();
  list.parallelStream().filter(x -> x > 0).forEach(bad::add); // NOT thread-safe
  FIX: collect(Collectors.toList())

MISTAKE 6: Expecting streams to be lazy with no terminal op
  list.stream().filter(x -> x > 0);  // Nothing executes — no terminal op!
  FIX: always end with terminal operation

MISTAKE 7: Using sorted() before filter() unnecessarily
  // Sorting is O(n log n); filter first to reduce elements:
  stream.filter(...).sorted()  // BETTER than  stream.sorted().filter(...)

===================================================================
PART 12: QUICK DECISION TABLE — Stream vs. Loop
===================================================================

Use STREAM when:                          Use LOOP when:
------------------------------------------|----------------------------------
Readable one-liner transformations        | Need to break/continue mid-iteration
Collecting/grouping/partitioning data     | Modifying loop variable or index
Chaining multiple filter/map steps        | Need index (i) during iteration
Parallel processing of large data         | Checked exceptions inside body
Avoiding null with Optional chaining      | Tiny arrays (< 20 items) — loop is faster
Writing functional-style data pipelines   | Multiple lists mutated simultaneously

// Index workaround in streams:
IntStream.range(0, list.size())
    .filter(i -> list.get(i).startsWith("A"))
    .forEach(i -> System.out.println(i + ": " + list.get(i)));
