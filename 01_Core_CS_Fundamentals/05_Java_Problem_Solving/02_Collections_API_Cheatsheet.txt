===================================================================
  JAVA COLLECTIONS API CHEATSHEET FOR PROBLEM SOLVING
===================================================================
Covers: List, ArrayList, LinkedList, ArrayDeque, PriorityQueue,
        HashMap, LinkedHashMap, TreeMap, HashSet, LinkedHashSet, TreeSet
===================================================================

KEY RULES TO MEMORIZE
-----------------------
1. Use ArrayList  → random access, most problems
2. Use LinkedList → when you need addFirst/removeLast frequently
3. Use ArrayDeque → BFS queue, DFS stack, sliding window deque
4. Use PriorityQueue → Top-K, Dijkstra, merge sorted lists
5. Use HashMap    → frequency, memoization, index lookup
6. Use TreeMap    → sorted keys, range queries, floor/ceiling
7. Use HashSet    → deduplication, O(1) contains check
8. Use TreeSet    → sorted unique elements, floor/ceiling/higher

===================================================================

--- ArrayList ---
List<Integer> list = new ArrayList<>();
List<Integer> list = new ArrayList<>(initialCapacity);
List<Integer> list = new ArrayList<>(otherCollection);

list.subList(from, to)      O(1) view, [from, to)
list.clear()                O(n)
list.sort(Comparator)       O(n log n)
list.iterator()             → Iterator<E>
list.listIterator()         → ListIterator<E>

// Create from array
List<String> list = new ArrayList<>(Arrays.asList("a","b","c"));
// Create fixed-size (no add/remove)
List<String> fixed = Arrays.asList("a","b","c");

LinkedList<Integer> ll = new LinkedList<>();

SECTION 2: DEQUE (Double-Ended Queue)  — USE ArrayDeque
===================================================================
Deque<Integer> deque = new ArrayDeque<>();
Stack<Integer> stack = new ArrayDeque<>();   // use as stack
Queue<Integer> queue = new ArrayDeque<>();   // use as queue

--- As STACK (LIFO) ---
deque.push(val)             → addFirst(val)
deque.pop()                 → removeFirst()  throws if empty
deque.peek()                → peekFirst()    null if empty

--- As QUEUE (FIFO) ---
deque.offer(val)            → addLast(val)
deque.poll()                → removeFirst()  null if empty
deque.peek()                → peekFirst()    null if empty

--- Full Deque API ---
deque.offerFirst(val)       add to front, returns boolean
deque.offerLast(val)        add to back, returns boolean
deque.pollFirst()           remove front, null if empty
deque.pollLast()            remove back, null if empty
deque.peekFirst()           view front
deque.peekLast()            view back
deque.isEmpty()
deque.size()
deque.contains(val)         O(n)

// Monotonic deque pattern (sliding window max/min)
Deque<Integer> mono = new ArrayDeque<>();  // stores indices

// NOTE: ArrayDeque does NOT allow null elements

SECTION 3: PRIORITY QUEUE (Min-Heap by default)
===================================================================
// Min-Heap (smallest on top)
PriorityQueue<Integer> minH = new PriorityQueue<>();
// Max-Heap (largest on top)
PriorityQueue<Integer> maxH = new PriorityQueue<>(Comparator.reverseOrder());
// Custom heap
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
// Pre-sized
PriorityQueue<Integer> pq = new PriorityQueue<>(n);

pq.offer(val)               O(log n) — add
pq.poll()                   O(log n) — remove top (null if empty)
pq.peek()                   O(1)     — view top (null if empty)
pq.size()
pq.isEmpty()
pq.contains(val)            O(n)
pq.remove(val)              O(n)     — remove specific element

// Convert collection to heap
PriorityQueue<Integer> pq = new PriorityQueue<>(list);

// Top-K smallest pattern
PriorityQueue<Integer> maxH = new PriorityQueue<>(Comparator.reverseOrder());
for (int num : nums) {
    maxH.offer(num);
    if (maxH.size() > k) maxH.poll();  // evict largest
}
// maxH now contains K smallest elements

// Top-K largest pattern
PriorityQueue<Integer> minH = new PriorityQueue<>();
for (int num : nums) {
    minH.offer(num);
    if (minH.size() > k) minH.poll();  // evict smallest
}

SECTION 4: HASHMAP
===================================================================
Map<String, Integer> map = new HashMap<>();
Map<String, Integer> map = new HashMap<>(initialCapacity);
Map<String, Integer> map = new LinkedHashMap<>();   // insertion-ordered
Map<String, Integer> map = new TreeMap<>();          // sorted by key

map.put(key, val)           O(1) avg
map.get(key)                O(1) avg — null if missing
map.getOrDefault(key, def)  O(1) avg
map.containsKey(key)        O(1) avg
map.containsValue(val)      O(n)
map.remove(key)             O(1) avg — returns removed val
map.size()
map.isEmpty()
map.clear()
map.keySet()                → Set<K>
map.values()                → Collection<V>
map.entrySet()              → Set<Map.Entry<K,V>>

// Safe update patterns
map.put(k, map.getOrDefault(k, 0) + 1);  // frequency++
map.merge(k, 1, Integer::sum);            // same, cleaner
map.putIfAbsent(k, new ArrayList<>());   // init if missing
map.computeIfAbsent(k, x -> new ArrayList<>()).add(v); // init+use

// Iterate
for (Map.Entry<String, Integer> e : map.entrySet()) {
    String k = e.getKey();
    int v = e.getValue();
}
map.forEach((k, v) -> System.out.println(k + "=" + v));

// Remove while iterating (safe)
Iterator<Map.Entry<K,V>> it = map.entrySet().iterator();
while (it.hasNext()) {
    Map.Entry<K,V> e = it.next();
    if (condition) it.remove();
}

SECTION 5: TREEMAP (Sorted Map)
===================================================================
TreeMap<Integer, String> tm = new TreeMap<>();
TreeMap<Integer, String> tm = new TreeMap<>(Comparator.reverseOrder());

// Same as HashMap +
tm.firstKey()               smallest key
tm.lastKey()                largest key
tm.floorKey(k)              largest key ≤ k   (null if none)
tm.ceilingKey(k)            smallest key ≥ k  (null if none)
tm.lowerKey(k)              largest key < k   (null if none)
tm.higherKey(k)             smallest key > k  (null if none)
tm.floorEntry(k)            Map.Entry for floorKey
tm.ceilingEntry(k)          Map.Entry for ceilingKey
tm.headMap(toKey)           keys < toKey  (view)
tm.tailMap(fromKey)         keys ≥ fromKey (view)
tm.subMap(from, to)         keys in [from, to)
tm.pollFirstEntry()         remove & return smallest entry
tm.pollLastEntry()          remove & return largest entry
tm.descendingKeySet()       reverse-order key set

// Pattern: count elements in range [lo, hi]
tm.subMap(lo, true, hi, true).size()

SECTION 8: COMPLEXITY SUMMARY
===================================================================

Structure       | Access | Search | Insert | Delete | Notes
----------------|--------|--------|--------|--------|------------------
ArrayList       | O(1)   | O(n)   | O(1)*  | O(n)   | *amortized append
LinkedList      | O(n)   | O(n)   | O(1)†  | O(1)†  | †at known position
ArrayDeque      | O(1)‡  | O(n)   | O(1)   | O(1)   | ‡front/back only
PriorityQueue   | O(1)   | O(n)   | O(logn)| O(logn)| peek=O(1)
HashMap         | -      | O(1)   | O(1)   | O(1)   | avg case
TreeMap         | -      | O(logn)| O(logn)| O(logn)| sorted
HashSet         | -      | O(1)   | O(1)   | O(1)   | avg case
TreeSet         | -      | O(logn)| O(logn)| O(logn)| sorted

===================================================================
SECTION 9: CHOOSING THE RIGHT COLLECTION
===================================================================

Problem Pattern                   → Best Choice
------------------------------------------
Need fast lookup by key           → HashMap
Need sorted keys + range queries  → TreeMap
Unique elements, fast lookup      → HashSet
Unique elements, sorted           → TreeSet
Sliding window / monotonic        → ArrayDeque
BFS (process level by level)      → ArrayDeque (as queue)
DFS (iterative)                   → ArrayDeque (as stack)
Top-K elements                    → PriorityQueue
Merge K sorted lists              → PriorityQueue<int[]>
Ordered insertion + fast lookup   → LinkedHashMap
LRU Cache                         → LinkedHashMap (accessOrder=true)
Frequency count                   → HashMap<K, Integer>
Anagram grouping                  → HashMap<String, List<String>>
