instanceof AND CASTING
=======================

TYPE CASTING IN JAVA
--------------------
Casting changes the type of a reference to treat an object as a different type.

Two kinds:
  1. Upcasting   (widening)  — subtype → supertype — always safe, implicit
  2. Downcasting (narrowing) — supertype → subtype — risky, explicit, can throw ClassCastException

UPCASTING (Implicit, Always Safe)
-----------------------------------
  Dog d = new Dog();
  Animal a = d;         // implicit upcast — Dog IS-A Animal, always valid
  // OR:
  Animal a = new Dog(); // also an upcast — same Dog object, referenced as Animal

  After upcast: you can only access Animal methods through `a`, even though the actual
  object is a Dog. The runtime still has the full Dog object — just the reference is narrowed.

  Use case: polymorphism — List<Animal> animals; animals.add(new Dog()); animals.add(new Cat());

DOWNCASTING (Explicit, Risky)
------------------------------
  Animal a = new Dog();           // upcast
  Dog d = (Dog) a;                // explicit downcast — VALID because actual object is Dog

  Animal a2 = new Cat();          // upcast
  Dog d2 = (Dog) a2;              // ClassCastException at RUNTIME — Cat is not a Dog!

  Downcasting is necessary when you need access to subclass-specific methods.

instanceof OPERATOR
--------------------
Tests whether an object is an instance of a given type (or its subtypes).
Returns boolean. Returns false (NOT NPE) for null references.

  Animal a = new Dog();
  a instanceof Dog     // true
  a instanceof Animal  // true  (Dog IS-A Animal)
  a instanceof Cat     // false

  null instanceof Dog  // false  (no exception)

SAFE DOWNCASTING PATTERN (Classic)
-------------------------------------
  if (a instanceof Dog) {
      Dog d = (Dog) a;
      d.bark();
  }
  // Two steps: check + cast — redundant but pre-Java 16 requirement

PATTERN MATCHING FOR instanceof (Java 16+)
-------------------------------------------
  Combines the instanceof check AND cast into a single expression.

  if (a instanceof Dog d) {     // `d` is declared AND cast in one step
      d.bark();                 // use d directly — no explicit cast needed
  }

  // Works with else:
  if (a instanceof Dog d) {
      d.bark();
  } else if (a instanceof Cat c) {
      c.purr();
  }

  // Works with switch (Java 21 — standard):
  switch (a) {
      case Dog d -> d.bark();
      case Cat c -> c.purr();
      default    -> System.out.println("Unknown animal");
  }

  // Guarded patterns (Java 21):
  if (a instanceof Dog d && d.getAge() > 2) {
      System.out.println("Adult dog: " + d.getName());
  }

ClassCastException
-------------------
Thrown at RUNTIME when you cast an object to an incompatible type:

  Object o = "hello";
  Integer i = (Integer) o;  // ClassCastException: String cannot be cast to Integer

  Always use instanceof before downcasting to avoid it.

CASTING WITH PRIMITIVES
------------------------
Primitive casting is different from object casting:

  int i = 42;
  long l = i;       // widening: int → long, implicit, no data loss
  double d = i;     // widening: int → double, implicit

  double x = 3.99;
  int y = (int) x;  // narrowing: explicit, truncates decimal: y = 3 (NOT rounded)

  int big = 1000;
  byte b = (byte) big;  // narrowing: data loss — 1000 % 256 = -24 (overflow)

  IMPORTANT: int → char is a narrowing conversion; char → int is widening.
  char c = 'A';
  int n = c;        // widening: n = 65 (Unicode codepoint)
  char c2 = (char) 65;  // narrowing cast: '

COMMON INTERVIEW QUESTIONS
---------------------------
Q: What is the difference between upcasting and downcasting?
A: Upcasting: subtype reference assigned to supertype variable — implicit, always safe.
   Downcasting: supertype reference cast back to subtype — explicit, must be verified with
   instanceof first. Wrong downcast throws ClassCastException at runtime.

Q: What does instanceof return for a null reference?
A: false — it never throws NPE. (null instanceof AnyType == false always.)

Q: What is pattern matching for instanceof (Java 16)?
A: instanceof T varName declares a local variable of type T and casts in one step if the
   instanceof check succeeds. Eliminates the redundant check + cast pattern and reduces
   the chance of bugs where check and cast use different variables.

Q: When would a ClassCastException be thrown?
A: When you force-cast an object to an incompatible type without instanceof checking:
     Animal a = new Cat();
     Dog d = (Dog) a;  // ClassCastException at runtime
   The compiler CANNOT catch this (it only sees Animal reference).
   Always guard with: if (a instanceof Dog) before casting.

Q: Can you cast unrelated classes?
A: No — if two classes don't share an inheritance hierarchy or interface in common,
   the compiler rejects the cast at compile time ("inconvertible types").
   Exception: Object can be cast to/from anything (deferred to runtime check).

Q: What is the output of (int) 3.9?
A: 3 — primitive narrowing truncates toward zero (does NOT round). To round: Math.round(3.9) = 4.
