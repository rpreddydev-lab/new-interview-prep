JAVA 8 METHOD REFERENCES
=========================

WHAT ARE METHOD REFERENCES?
-----------------------------
  A method reference is a shorthand syntax for a lambda that calls a single method.
  When a lambda does nothing but forward its arguments to an existing method, a
  method reference is cleaner and more readable.

  // Lambda form:
  list.forEach(s -> System.out.println(s));

  // Method reference (equivalent):
  list.forEach(System.out::println);

  Syntax: ClassName::methodName  or  instance::methodName

FOUR TYPES OF METHOD REFERENCES
---------------------------------

  1. STATIC METHOD REFERENCE
     ClassName::staticMethod
     Lambda: (args) -> ClassName.staticMethod(args)

     // Example:
     Function<String, Integer> parseInt = Integer::parseInt;
     parseInt.apply("42"); // 42

     List<String> nums = List.of("3", "1", "2");
     nums.stream().mapToInt(Integer::parseInt).sum();

     // Comparator:
     Stream<String> sorted = Stream.of("banana","apple","cherry")
         .sorted(String::compareTo);  // String.compareTo is the static comparator

  2. INSTANCE METHOD REFERENCE (ON A SPECIFIC INSTANCE)
     instance::instanceMethod
     Lambda: (args) -> specificInstance.instanceMethod(args)

     // Example:
     String prefix = "Hello, ";
     Function<String, String> greet = prefix::concat;
     greet.apply("World"); // "Hello, World"

     // PrintStream.println on System.out:
     Consumer<String> printer = System.out::println;
     printer.accept("test");

  3. INSTANCE METHOD REFERENCE (ON AN ARBITRARY INSTANCE OF THE TYPE)
     ClassName::instanceMethod
     Lambda: (instance, args) -> instance.instanceMethod(args)

     // The first argument to the lambda becomes the target object.
     // Example:
     Function<String, String> toUpper = String::toUpperCase;
     toUpper.apply("hello"); // "HELLO" — same as s -> s.toUpperCase()

     // Predicate:
     Predicate<String> isEmpty = String::isEmpty;
     list.stream().filter(String::isEmpty).count();

     // BiFunction — first arg is instance, second is parameter:
     BiFunction<String, String, Boolean> startsWith = String::startsWith;
     startsWith.apply("Hello", "He"); // true

     // Comparator:
     list.sort(String::compareToIgnoreCase);

  4. CONSTRUCTOR REFERENCE
     ClassName::new
     Lambda: (args) -> new ClassName(args)

     // Example:
     Supplier<ArrayList<String>> listFactory = ArrayList::new;
     ArrayList<String> newList = listFactory.get();

     // Function:
     Function<String, StringBuilder> sbFactory = StringBuilder::new;
     StringBuilder sb = sbFactory.apply("Hello");

     // In stream — converting to objects:
     List<String> names = List.of("Alice", "Bob");
     List<Person> people = names.stream()
         .map(Person::new)        // assumes Person(String name) constructor
         .collect(Collectors.toList());

COMPARISON TABLE
-----------------
  | Type                          | Syntax                  | Lambda Equivalent                     |
  |-------------------------------|-------------------------|---------------------------------------|
  | Static method                 | ClassName::staticMethod | (args) -> ClassName.staticMethod(args)|
  | Instance (specific object)    | obj::instanceMethod     | (args) -> obj.instanceMethod(args)    |
  | Instance (arbitrary of type)  | ClassName::instMethod   | (obj, args) -> obj.instMethod(args)   |
  | Constructor                   | ClassName::new          | (args) -> new ClassName(args)         |

WHEN TO USE METHOD REFERENCES VS LAMBDAS
-----------------------------------------
  Use method reference when:
  - The lambda body simply delegates to an existing named method with no modification
  - It improves readability (names give semantic meaning)
  - You're using it repeatedly (no inline expressions)

  Use lambda when:
  - The logic goes beyond a single method call
  - You need to combine expressions: s -> s.trim().toLowerCase()
  - The method reference would be ambiguous or harder to read

  // Method reference — clear intent:
  stream.filter(String::isEmpty)

  // Lambda needed — multi-step transformation:
  stream.map(s -> s.trim().toLowerCase())

PRACTICAL EXAMPLES
-------------------
  // Sorting with method references:
  people.sort(Comparator.comparing(Person::getName));
  people.sort(Comparator.comparing(Person::getAge).reversed());
  people.sort(Comparator.comparing(Person::getLastName)
                        .thenComparing(Person::getFirstName));

  // Collectors.toMap with constructor ref:
  Map<String, Person> map = people.stream()
      .collect(Collectors.toMap(Person::getName, Function.identity()));

  // Stream to array:
  String[] arr = list.stream().toArray(String[]::new);

  // Custom exception factory:
  Optional.ofNullable(value)
      .orElseThrow(IllegalStateException::new);

  // Grouping:
  Map<Department, List<Person>> byDept = employees.stream()
      .collect(Collectors.groupingBy(Employee::getDepartment));

COMMON INTERVIEW QUESTIONS
---------------------------
Q: What are the four types of method references in Java 8?
A: (1) Static method reference (ClassName::staticMethod): replaces a lambda that calls
   a static method. (2) Instance method reference on a specific object
   (instance::method): replaces a lambda that calls a method on a captured variable.
   (3) Instance method reference on an arbitrary instance of a type
   (ClassName::instanceMethod): replaces a lambda where the lambda's first argument
   is the target. (4) Constructor reference (ClassName::new): replaces a lambda that
   calls a constructor.

Q: What is the difference between String::toUpperCase and str::toUpperCase?
A: String::toUpperCase is an instance method reference on an arbitrary instance of
   String. The lambda equivalent is (s) -> s.toUpperCase() — the first argument
   becomes the target. It matches Function<String, String>. str::toUpperCase (where
   str is a specific String variable) is an instance method reference on a specific
   captured object. The lambda equivalent is () -> str.toUpperCase() — it takes no
   argument; it matches Supplier<String>.

Q: When would you use a constructor reference?
A: When you need a factory that creates instances of a type and the creation is handled
   by an existing constructor. Examples: passing ClassName::new as a Supplier, creating
   objects from stream elements with .map(ClassName::new), or using stream.toArray(String[]::new)
   to create a typed array. Constructor references are cleaner than new ClassName() in lambdas
   because they express intent (this is a factory/constructor) without unnecessary boilerplate.
