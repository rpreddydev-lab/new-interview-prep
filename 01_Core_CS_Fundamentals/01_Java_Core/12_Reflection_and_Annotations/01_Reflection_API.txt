1. WHAT IS REFLECTION?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Reflection is the ability of a Java program to inspect and manipulate its
own structure at RUNTIME — including classes, methods, fields, constructors,
and annotations — without knowing them at compile time.

Package: java.lang.reflect

Key classes:
  - Class<T>         → represents a class or interface
  - Method           → represents a method
  - Field            → represents a field (instance or static)
  - Constructor<T>   → represents a constructor
  - Modifier         → utility for decoding access modifiers
  - Proxy            → creates dynamic proxy instances
  - AnnotatedElement → super-interface for Class/Method/Field

2. OBTAINING A Class<?> OBJECT — THREE WAYS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// 1. Class literal (compile-time known)
Class<String> clazz1 = String.class;

// 2. getClass() on an instance
String s = "hello";
Class<?> clazz2 = s.getClass();

// 3. Class.forName() — runtime, dynamic loading
Class<?> clazz3 = Class.forName("com.example.MyService");

Note: Class.forName() triggers class initialization (static blocks run).

3. INSPECTING CLASS METADATA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Class<?> clazz = MyService.class;

clazz.getName()             // "com.example.MyService"
clazz.getSimpleName()       // "MyService"
clazz.getPackageName()      // "com.example"
clazz.getSuperclass()       // parent class
clazz.getInterfaces()       // directly implemented interfaces
clazz.getModifiers()        // int bitmask → Modifier.isPublic(mod)
clazz.isInterface()
clazz.isEnum()
clazz.isAnnotation()
clazz.isRecord()            // Java 16+
clazz.getAnnotations()      // runtime annotations

4. FIELDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// getFields()         → public fields (including inherited)
// getDeclaredFields() → all fields of this class (including private)

Field[] fields = clazz.getDeclaredFields();
for (Field field : fields) {
    field.setAccessible(true);          // bypass private/protected
    Object value = field.get(instance); // read value
    field.set(instance, newValue);      // write value
}

// Specific field
Field nameField = clazz.getDeclaredField("name");
nameField.setAccessible(true);
String name = (String) nameField.get(obj);

USE CASE: Dependency injection frameworks (Spring), ORM (Hibernate field access).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. METHODS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// getMethods()         → public methods (including inherited)
// getDeclaredMethods() → all methods of this class

Method[] methods = clazz.getDeclaredMethods();

// Get specific method
Method method = clazz.getDeclaredMethod("processOrder", String.class, int.class);
method.setAccessible(true);

// Invoke method
Object result = method.invoke(instance, "ORD-123", 5);

// Static method invocation (instance = null)
Method staticMethod = clazz.getDeclaredMethod("getInstance");
Object singleton = staticMethod.invoke(null);

// Inspect method metadata
method.getName();
method.getReturnType();
method.getParameterTypes();
method.getExceptionTypes();
method.getAnnotations();
Modifier.isStatic(method.getModifiers());

6. CONSTRUCTORS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// getConstructors()         → public constructors
// getDeclaredConstructors() → all constructors

// Create instance using no-arg constructor
Constructor<?> ctor = clazz.getDeclaredConstructor();
ctor.setAccessible(true);
Object instance = ctor.newInstance();

// Create instance with args
Constructor<?> ctor2 = clazz.getDeclaredConstructor(String.class, int.class);
Object obj = ctor2.newInstance("Alice", 30);

USE CASE: Spring BeanFactory, Jackson deserialization, test frameworks.

7. ANNOTATIONS VIA REFLECTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// Check if annotation present
if (clazz.isAnnotationPresent(Service.class)) { ... }

// Get annotation and read its attributes
Transactional tx = method.getAnnotation(Transactional.class);
if (tx != null) {
    System.out.println(tx.propagation()); // Propagation.REQUIRED
    System.out.println(tx.readOnly());
}

// Get all annotations
Annotation[] annotations = method.getDeclaredAnnotations();

USE CASE: Spring processes @Autowired, @Transactional, @RequestMapping via reflection.

8. GENERICS AND REFLECTION — ParameterizedType
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Due to type erasure, generic type info is erased at runtime for LOCAL variables.
However, it IS retained in:
  - Field declarations:       List<String> names;
  - Method return types:      List<User> getUsers()
  - Method parameters:        void save(List<Order> orders)
  - Superclass declarations:  class Repo extends BaseRepo<User>

// Read generic type of a field
Field field = clazz.getDeclaredField("names");
Type genericType = field.getGenericType();
if (genericType instanceof ParameterizedType pt) {
    Type[] typeArgs = pt.getActualTypeArguments(); // [String.class]
}

// Get generic superclass type argument (common pattern in frameworks)
Type superclass = clazz.getGenericSuperclass();
if (superclass instanceof ParameterizedType pt) {
    Type entityType = pt.getActualTypeArguments()[0]; // e.g. User.class
}

USE CASE: Spring Data resolves repository entity type using this technique.

9. DYNAMIC PROXY (java.lang.reflect.Proxy)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Dynamic proxies intercept method calls on interfaces at runtime.

// InvocationHandler
InvocationHandler handler = (proxy, method, args) -> {
    System.out.println("Before: " + method.getName());
    Object result = method.invoke(realService, args);
    System.out.println("After: " + method.getName());
    return result;
};

// Create proxy
MyService proxy = (MyService) Proxy.newProxyInstance(
    MyService.class.getClassLoader(),
    new Class<?>[] { MyService.class },
    handler
);

proxy.processOrder("ORD-1"); // → invokes handler

KEY POINT: Proxy only works with INTERFACES.
For class-based proxying → Spring uses CGLIB (subclass-based proxy).

USE CASE: Spring AOP (@Transactional, @Cacheable), logging, security.

10. setAccessible(true) AND THE MODULE SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Java 9+ introduced the Module System which restricts reflective access:
  - Deep reflection (accessing private fields of other modules) is blocked
    unless the module opens its packages.
  - InaccessibleObjectException is thrown if not opened.

module-info.java to allow reflection access:
  opens com.example.model;           // open to all modules
  opens com.example.model to spring.core;  // open to specific module

JVM flags (temporary workaround):
  --add-opens java.base/java.lang=ALL-UNNAMED

11. PERFORMANCE CONSIDERATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Reflection is SLOW compared to direct method calls due to:
  1. Type checking bypassed — no compile-time optimization
  2. JIT cannot inline reflective calls easily
  3. setAccessible() has security manager checks (pre-Java 17)
  4. Object[] boxing for varargs method invocation

Mitigation strategies:
  - Cache Method/Field/Constructor objects — lookup is expensive
  - Use MethodHandles (java.lang.invoke) — faster, JIT-friendly
  - Use code generation (ByteBuddy, ASM, Javassist) for hot paths
  - Consider annotation processors at compile time instead

// MethodHandle — faster alternative to Method.invoke()
MethodHandles.Lookup lookup = MethodHandles.lookup();
MethodHandle mh = lookup.findVirtual(MyService.class, "process",
                    MethodType.methodType(void.class, String.class));
mh.invoke(instance, "data");

12. COMMON FRAMEWORK USE CASES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SPRING FRAMEWORK:
  - @Autowired → field/constructor injection via reflection
  - @Value     → reads annotated fields and injects property values
  - @Transactional → creates JDK proxy or CGLIB proxy
  - ApplicationContext.getBeansWithAnnotation() → scans annotated classes

HIBERNATE / JPA:
  - Reads @Entity, @Column, @Id annotations
  - Field-level access (AccessType.FIELD) uses reflection directly
  - Proxies entities for lazy loading using Javassist/ByteBuddy

JACKSON (JSON):
  - Reads field names via reflection to map JSON ↔ Java objects
  - Detects @JsonProperty, @JsonIgnore, @JsonSerialize

JUNIT 5:
  - Discovers @Test, @BeforeEach, @ExtendWith via reflection
  - Instantiates test classes using getDeclaredConstructor().newInstance()

13. INTERVIEW QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What is reflection in Java and when would you use it?
A: Reflection is runtime introspection of class structure. Used in
   frameworks for DI, serialization, proxies, testing tools.

Q: How does Spring's @Transactional work under the hood?
A: Spring uses reflection to detect the annotation, then wraps the bean
   in a JDK Proxy (interface) or CGLIB proxy (class) that intercepts calls
   and wraps them in a transaction.

Q: What is the difference between getFields() and getDeclaredFields()?
A: getFields() returns all PUBLIC fields including inherited ones.
   getDeclaredFields() returns ALL fields (any visibility) of THAT class
   only — does not include inherited fields.

Q: How can you access a private field via reflection?
A: Call field.setAccessible(true) before field.get(instance).
   In Java 9+, the module must open its package for this to work.

Q: What is the performance impact of reflection?
A: Reflective calls are 10-100x slower than direct calls. Cache Method/Field
   objects, or use MethodHandles for better JIT optimization.

Q: How does Spring Data JPA know the entity type of a Repository?
A: It reads the generic superclass (ParameterizedType) of the repository
   interface at runtime using reflection.

Q: What is a JDK Dynamic Proxy? How is it different from CGLIB?
A: JDK proxy requires an interface; it creates a proxy class at runtime.
   CGLIB creates a subclass of the target class; works without interfaces.
   Spring uses JDK proxy when the target implements an interface, CGLIB otherwise.

Q: Can reflection break encapsulation?
A: Yes — setAccessible(true) bypasses private/protected access.
   Java 9+ module system provides stronger encapsulation via opens directives.
