================================================================
  BINARY SEARCH ON ANSWER
  (Minimize/Maximize with Feasibility Check)
================================================================

----------------------------------------------------------------
CONCEPT
----------------------------------------------------------------

  Instead of binary searching on array indices, binary search on the
  ANSWER VALUE ITSELF.

  The answer lies in a range [lo, hi]. For a given mid:
    - If mid is a valid answer: maybe try smaller (for minimize) --> hi = mid
    - If mid is not valid:      must go bigger (for minimize)    --> lo = mid + 1

  This works because the "is mid valid?" predicate is MONOTONE:
    false, false, ..., false, TRUE, true, ..., true
    (for minimization: invalid below threshold, valid above)

  TEMPLATE (minimize):
    int lo = minValue, hi = maxValue;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (isValid(mid)) hi = mid;    // mid might be the answer
        else lo = mid + 1;             // mid too small, go higher
    }
    return lo;

  TEMPLATE (maximize):
    int lo = minValue, hi = maxValue;
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;  // round UP (avoid infinite loop)
        if (isValid(mid)) lo = mid;    // mid might be the answer
        else hi = mid - 1;             // mid too large, go lower
    }
    return lo;

  IMPORTANT: For maximize, use (lo + hi + 1) / 2 to round up.
  Otherwise, when lo = hi - 1 and isValid(mid) is true:
    mid = lo (rounded down), lo = mid = lo --> infinite loop.

----------------------------------------------------------------
PROBLEM 1: KOKO EATING BANANAS (LC 875)
----------------------------------------------------------------

  Piles of bananas. Koko eats at speed k per hour.
  Must finish all piles within h hours.
  Find minimum k.

  For each pile p: time needed = ceil(p / k) = (p + k - 1) / k.
  Total time = sum of ceil(p/k) for all piles.

  isValid(k): total time <= h?

  Range: lo = 1 (slowest possible), hi = max(piles) (fastest needed).

  Java:
    public int minEatingSpeed(int[] piles, int h) {
        int lo = 1, hi = 0;
        for (int p : piles) hi = Math.max(hi, p);

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (canFinish(piles, mid, h)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    private boolean canFinish(int[] piles, int speed, int h) {
        long hours = 0;
        for (int p : piles) {
            hours += (p + speed - 1) / speed;
        }
        return hours <= h;
    }

  Time: O(n log(max(piles)))
  Space: O(1)

  Note: Use long for hours to avoid overflow when piles values are large.

PROBLEM 2: CAPACITY TO SHIP PACKAGES (LC 1011)
----------------------------------------------------------------

  Ship all weights within D days.
  Each day, ship contiguous packages in order, total <= capacity.
  Find minimum capacity.

  isValid(capacity): can we ship all within D days greedy?
  Greedy: add weights to current day as long as total <= capacity.

  Range: lo = max(weights) (must carry the heaviest), hi = sum(weights).

  Java:
    public int shipWithinDays(int[] weights, int days) {
        int lo = 0, hi = 0;
        for (int w : weights) {
            lo = Math.max(lo, w);
            hi += w;
        }

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (canShip(weights, mid, days)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    private boolean canShip(int[] weights, int capacity, int days) {
        int daysNeeded = 1, currentLoad = 0;
        for (int w : weights) {
            if (currentLoad + w > capacity) {
                daysNeeded++;
                currentLoad = 0;
            }
            currentLoad += w;
        }
        return daysNeeded <= days;
    }

  Time: O(n log(sum))
  Space: O(1)

PROBLEM 3: SPLIT ARRAY LARGEST SUM (LC 410)
----------------------------------------------------------------

  Split nums into k non-empty contiguous subarrays.
  Minimize the largest sum among subarrays.

  Same structure as LC 1011 (replace "days" with "k groups").

  isValid(maxSum): can we split into <= k groups each with sum <= maxSum?

  Java:
    public int splitArray(int[] nums, int k) {
        int lo = 0, hi = 0;
        for (int n : nums) {
            lo = Math.max(lo, n);
            hi += n;
        }

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (canSplit(nums, mid, k)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    private boolean canSplit(int[] nums, int maxSum, int k) {
        int groups = 1, currentSum = 0;
        for (int n : nums) {
            if (currentSum + n > maxSum) {
                groups++;
                currentSum = 0;
            }
            currentSum += n;
        }
        return groups <= k;
    }

  Time: O(n log(sum))

PROBLEM 4: MINIMUM NUMBER OF DAYS TO MAKE BOUQUETS (LC 1482)
----------------------------------------------------------------

  bloomDay[i] = day flower i blooms.
  Each bouquet needs k consecutive bloomed flowers.
  Need m bouquets. Find minimum day. Return -1 if impossible.

  If m * k > n (total flowers): impossible, return -1.

  isValid(day): can we make m bouquets on this day?
    Count consecutive bloomed flowers. Each run of k makes one bouquet.

  Range: lo = min(bloomDay), hi = max(bloomDay).

  Java:
    public int minDays(int[] bloomDay, int m, int k) {
        if ((long) m * k > bloomDay.length) return -1;
        int lo = Integer.MAX_VALUE, hi = Integer.MIN_VALUE;
        for (int d : bloomDay) {
            lo = Math.min(lo, d);
            hi = Math.max(hi, d);
        }

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (canMake(bloomDay, mid, m, k)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    private boolean canMake(int[] bloomDay, int day, int m, int k) {
        int bouquets = 0, consecutive = 0;
        for (int d : bloomDay) {
            if (d <= day) {
                consecutive++;
                if (consecutive == k) {
                    bouquets++;
                    consecutive = 0;
                }
            } else {
                consecutive = 0;
            }
        }
        return bouquets >= m;
    }

  Time: O(n log(max_day))

PROBLEM 5: MINIMIZE MAX DISTANCE TO GAS STATION (LC 774)
----------------------------------------------------------------

  Given sorted gas station positions and k new stations to add,
  minimize the maximum gap between any two adjacent stations.

  isValid(maxDist): can we keep all gaps <= maxDist by adding at most k stations?
  For each gap g: need ceil(g / maxDist) - 1 new stations.

  Note: This requires binary search on a REAL-VALUED answer (float).

  Java (floating point binary search):
    public double minmaxGasDist(int[] stations, int k) {
        double lo = 0, hi = 1e8;
        for (int i = 0; i < 100; i++) {  // fixed iterations for precision
            double mid = (lo + hi) / 2;
            if (canAchieve(stations, mid, k)) hi = mid;
            else lo = mid;
        }
        return lo;
    }

    private boolean canAchieve(int[] stations, double maxDist, int k) {
        int count = 0;
        for (int i = 1; i < stations.length; i++) {
            count += (int)((stations[i] - stations[i-1]) / maxDist);
        }
        return count <= k;
    }

  Fixed-iteration approach: after 100 iterations, precision is 1e8 / 2^100 ≈ 0.
  Alternatively, use eps-based termination: while (hi - lo > 1e-6).

----------------------------------------------------------------
HOW TO IDENTIFY "BINARY SEARCH ON ANSWER" PROBLEMS
----------------------------------------------------------------

  Signals in the problem statement:
    - "Find the MINIMUM ... such that ..."
    - "Find the MAXIMUM ... such that ..."
    - "Minimize the maximum ..."
    - "Maximize the minimum ..."
    - There's a clear numeric range for the answer
    - Brute force is O(n * range), and range is large

  Steps to solve:
    1. Identify the answer range [lo, hi].
    2. Write isValid(mid): given mid as the answer, is it feasible?
    3. Verify isValid is monotone (below threshold=false, above=true).
    4. Apply binary search template.

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. Wrong lo and hi bounds.
     For capacity/speed: lo = max element (you must handle the largest),
                         hi = sum of all elements (one day/group = ship all).

  2. Off-by-one in isValid: using < vs <= for conditions.
     For groups: if currentSum + n > maxSum, start new group.
     (Not >= or strict <).

  3. Integer overflow in isValid: when adding many elements, use long.
     E.g., hours in Koko, total sum in ship packages.

  4. For maximize: forgetting to use ceil((lo+hi+1)/2) to avoid infinite loop.

  5. Float binary search: using lo < hi comparison (wrong for doubles).
     Use fixed iterations or while (hi - lo > eps).

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: How do you determine lo and hi for the answer range?
  A: Think about the minimum and maximum possible answers.
     Min speed (Koko): 1. Max speed: max pile (no need to eat faster).
     Min capacity (ship): max single weight. Max: total sum.

  Q: How do you verify isValid is monotone?
  A: If isValid(mid) is true, is isValid(mid+1) always true?
     For "can finish in h hours at speed k": faster speed = fewer hours
     = still feasible. Yes, monotone. ✓

  Q: What's the time complexity?
  A: O(n * log(hi - lo)) where n is cost of isValid, (hi-lo) is answer range.
     E.g., O(n log sum) for shipping/splitting.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Identify the answer range first, before coding.
  - Verify monotonicity by reasoning: "if mid works, does mid+1 also work?"
  - Write the isValid helper as a clean separate function.
  - Trace isValid on a simple example before binary searching.
  - Mention integer overflow guard (long) when summing large arrays.
