================================================================
  ALL PATHS FROM SOURCE TO TARGET (LC 797)
================================================================

  Given a DAG (Directed Acyclic Graph) of n nodes (0 to n-1),
  find all possible paths from node 0 to node n-1.

  Input:  graph = [[1,2],[3],[3],[]]
  Output: [[0,1,3],[0,2,3]]

  Input:  graph = [[4,3,1],[3,2,4],[3],[4],[]]
  Output: [[0,4],[0,3,4],[0,1,3,4],[0,1,2,3,4],[0,1,4]]

----------------------------------------------------------------
APPROACH: DFS WITH BACKTRACKING
----------------------------------------------------------------

  Explore all paths using DFS. When we reach node n-1, record the path.
  Backtrack after each recursive call.

  Java:
    public List<List<Integer>> allPathsSourceTarget(int[][] graph) {
        List<List<Integer>> result = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        path.add(0);
        dfs(graph, 0, path, result);
        return result;
    }

    private void dfs(int[][] graph, int node, List<Integer> path, List<List<Integer>> result) {
        if (node == graph.length - 1) {
            result.add(new ArrayList<>(path));   // copy path
            return;
        }

        for (int next : graph[node]) {
            path.add(next);
            dfs(graph, next, path, result);
            path.remove(path.size() - 1);  // BACKTRACK
        }
    }

  Time: O(2^n * n)  -- up to 2^n paths, each path length up to n
  Space: O(n)        -- recursion depth + path

----------------------------------------------------------------
TRACED EXAMPLE: graph = [[1,2],[3],[3],[]]
----------------------------------------------------------------

  n=4, target=3.

  dfs(0, [0]):
    next=1: dfs(1, [0,1])
              next=3: dfs(3, [0,1,3]) -- node==target=3, add [0,1,3]
              backtrack: path=[0,1]
            backtrack: path=[0]
    next=2: dfs(2, [0,2])
              next=3: dfs(3, [0,2,3]) -- add [0,2,3]
              backtrack: path=[0,2]
            backtrack: path=[0]

  Result: [[0,1,3],[0,2,3]] ✓

----------------------------------------------------------------
WHY NO VISITED ARRAY NEEDED (DAG PROPERTY)
----------------------------------------------------------------

  This is a DAG (no cycles). Each path terminates at node n-1 or
  hits a dead end. No infinite loops possible.

  If the graph HAD cycles, we'd need a visited set to avoid infinite DFS.
  Since DAG is given, we skip the visited array.

  If problem doesn't guarantee DAG, add:
    boolean[] inPath = new boolean[n];

    void dfs(int node, ...) {
        if (inPath[node]) return;  // cycle guard
        inPath[node] = true;
        // recurse
        inPath[node] = false;    // backtrack
    }

----------------------------------------------------------------
VARIANT: ALL PATHS WITH CONSTRAINTS
----------------------------------------------------------------

  LC 1059 All Paths from Source Lead to Destination:
    All paths from source eventually reach destination (no cycles,
    no paths that bypass destination).

  DFS with 3-color state:
    WHITE=0 (unvisited), GRAY=1 (in current path), BLACK=2 (safe)

    boolean dfs(int node, int dest) {
        if (color[node] == 1) return false;   // cycle
        if (color[node] == 2) return true;    // already verified safe
        if (graph[node].length == 0) return node == dest;  // leaf
        color[node] = 1;
        for (int next : graph[node]) {
            if (!dfs(next, dest)) { color[node] = 0; return false; }
        }
        color[node] = 2;  // mark safe
        return true;
    }

----------------------------------------------------------------
VARIANT: COUNT PATHS IN GRID (LC 62 UNIQUE PATHS)
----------------------------------------------------------------

  All paths from top-left to bottom-right in a grid moving only right/down.
  DP is optimal, but DFS with memoization also works.

  Java (DFS with memo):
    int[][] memo;
    public int uniquePaths(int m, int n) {
        memo = new int[m][n];
        return dfs(0, 0, m, n);
    }

    int dfs(int r, int c, int m, int n) {
        if (r == m-1 && c == n-1) return 1;
        if (r >= m || c >= n) return 0;
        if (memo[r][c] != 0) return memo[r][c];
        return memo[r][c] = dfs(r+1, c, m, n) + dfs(r, c+1, m, n);
    }

  DP is cleaner: dp[i][j] = dp[i-1][j] + dp[i][j-1]
  Time: O(m*n)   Space: O(m*n) or O(n) with 1D DP

----------------------------------------------------------------
VARIANT: PATH EXISTS CHECK (LC 1971)
----------------------------------------------------------------

  Find if a valid path exists in an undirected graph.
  Simple DFS from source, check if destination is reachable.

  Java:
    public boolean validPath(int n, int[][] edges, int source, int destination) {
        if (source == destination) return true;
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        boolean[] visited = new boolean[n];
        return dfs(source, destination, adj, visited);
    }

    boolean dfs(int curr, int dest, List<List<Integer>> adj, boolean[] visited) {
        if (curr == dest) return true;
        visited[curr] = true;
        for (int next : adj.get(curr)) {
            if (!visited[next] && dfs(next, dest, adj, visited)) return true;
        }
        return false;
    }

----------------------------------------------------------------
DFS ALL-PATHS COMPLEXITY
----------------------------------------------------------------

  Why O(2^n * n)?
    In the worst case (fully connected DAG), the number of paths from
    source to target is exponential (2^n).
    Each path has length at most n.
    Recording each path takes O(n) to copy.
    Total: O(2^n * n).

  This is unavoidable if we must output all paths.

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why do we copy the path when adding to result?
  A: The path list is mutated during backtracking. If we add the list
     reference, it will be empty at the end. We must capture a snapshot.

  Q: Is there a non-backtracking approach for all paths?
  A: Iterative DFS with explicit stack and path copying works:
     Push (node, pathSoFar) onto the stack.
     But path copying makes it O(n^2) memory in the worst case.
     Backtracking is more space-efficient.

  Q: Can this be done with BFS?
  A: Yes. Queue stores (node, currentPath). But BFS paths accumulate in
     the queue, causing high memory usage. DFS is preferred for all-paths.

  Q: For DAG problems, do we always skip the visited set?
  A: Yes, if we're guaranteed no cycles. For undirected/cyclic graphs,
     we need visited tracking. The DAG guarantee is crucial.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - State: "Since it's a DAG, no visited set needed."
  - The backtrack pattern: add -> recurse -> remove last.
  - Always copy path when recording: new ArrayList<>(path).
  - The time complexity O(2^n * n) is the expected answer for all-paths problems.
  - For follow-up: "How would you handle cycles?" -- add inPath boolean array.
