================================================================
  PATTERN CHEAT SHEET
  Quick-Reference for All 17 Core Patterns
================================================================

----------------------------------------------------------------
01. TWO POINTERS
----------------------------------------------------------------
  When:  Sorted array or string. Finding pairs, triplets,
         palindrome check, removing duplicates.
  Keys:  l=0, r=n-1 (opposite) OR l=0, r=0 (same direction)
  Time:  O(n)  Space: O(1)
  Problems: Two Sum II, 3Sum, Container With Most Water,
            Trapping Rain Water, Valid Palindrome

  Template (opposite):
    while (l < r) {
      if (condition_met) { update; l++; r--; }
      else if (too_small) l++;
      else r--;
    }

----------------------------------------------------------------
02. SLIDING WINDOW
----------------------------------------------------------------
  When:  Contiguous subarray/substring with constraint.
         "Longest / shortest / count" of window satisfying X.
  Keys:  Expand right; shrink left when invalid.
  Time:  O(n)  Space: O(k) where k = alphabet/window size
  Problems: Longest Substring Without Repeat, Min Window
            Substring, Max Sum Subarray of size K

  Template (variable):
    int l = 0; Map/array for window state;
    for (int r = 0; r < n; r++) {
      add s[r] to window;
      while (window invalid) { remove s[l++]; }
      update answer;
    }

----------------------------------------------------------------
03. FAST & SLOW POINTERS
----------------------------------------------------------------
  When:  Linked list cycle, finding middle, happy number.
  Keys:  slow moves 1 step, fast moves 2 steps.
  Time:  O(n)  Space: O(1)
  Problems: LC 141 (cycle), LC 142 (cycle start),
            LC 876 (middle), LC 202 (happy number)

  Template:
    slow = head; fast = head;
    while (fast != null && fast.next != null) {
      slow = slow.next; fast = fast.next.next;
    }

----------------------------------------------------------------
04. PREFIX SUM
----------------------------------------------------------------
  When:  Range sum queries, subarray sum = k, 2D range sum.
  Keys:  prefix[i] = sum of first i elements.
         sum(l,r) = prefix[r+1] - prefix[l]
  Time:  O(n) build, O(1) query  Space: O(n)
  Problems: Subarray Sum = K (LC 560), Range Sum Query,
            2D Matrix Prefix Sum (LC 304)

  HashMap variant: prefix sum + map for count of subarrays.
    map.put(0, 1);  // empty prefix
    for each element: currSum += val; count += map.get(currSum - k);
                      map.merge(currSum, 1, Integer::sum);

----------------------------------------------------------------
05. BINARY SEARCH (on answer)
----------------------------------------------------------------
  When:  "Minimize the maximum" / "Maximize the minimum" /
         answer is monotone (if X works, X+1 also works).
  Keys:  Define feasible(mid). Binary search on answer space.
  Time:  O(n log(range))  Space: O(1)
  Problems: Koko Eating Bananas (LC 875), Capacity to Ship
            (LC 1011), Split Array Largest Sum (LC 410)

  Template:
    int lo = min_answer, hi = max_answer;
    while (lo < hi) {
      int mid = lo + (hi - lo) / 2;
      if (feasible(mid)) hi = mid;
      else lo = mid + 1;
    }
    return lo;

----------------------------------------------------------------
06. MERGE INTERVALS
----------------------------------------------------------------
  When:  Overlapping intervals, scheduling, meeting rooms.
  Keys:  Sort by start. If curr.start <= prev.end: merge.
  Time:  O(n log n)  Space: O(n)
  Problems: LC 56 (merge), LC 57 (insert), LC 435 (min remove),
            LC 252/253 (meeting rooms)

----------------------------------------------------------------
07. MONOTONIC STACK
----------------------------------------------------------------
  When:  Next greater/smaller element, largest rectangle,
         span/temperature problems.
  Keys:  Maintain stack in increasing or decreasing order.
         Pop when invariant breaks.
  Time:  O(n)  Space: O(n)
  Problems: LC 739 (daily temp), LC 84 (histogram),
            LC 496 (next greater), LC 42 (rain water)

  Template (next greater):
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
      while (!stack.isEmpty() && nums[stack.peek()] < nums[i])
        result[stack.pop()] = nums[i];
      stack.push(i);
    }

----------------------------------------------------------------
08. TOP K ELEMENTS (HEAP)
----------------------------------------------------------------
  When:  Kth largest/smallest, top K frequent, merge K lists.
  Keys:  Min-heap of size k for "top k largest".
         Max-heap for "smallest k".
  Time:  O(n log k)  Space: O(k)
  Problems: LC 215 (kth largest), LC 347 (top k freq),
            LC 973 (k closest), LC 295 (median stream)

----------------------------------------------------------------
09. BFS PATTERN
----------------------------------------------------------------
  When:  Shortest path (unweighted), level order, multi-source.
  Keys:  Queue + visited set. Level loop with size snapshot.
  Time:  O(V + E)  Space: O(V)
  Problems: LC 102 (level order), LC 994 (rotten oranges),
            LC 127 (word ladder), LC 1091 (shortest binary path)

----------------------------------------------------------------
10. DFS PATTERN
----------------------------------------------------------------
  When:  Exhaustive search, connected components, cycle detection,
         all paths, topological sort.
  Keys:  Recursion or stack. Mark visited.
  Time:  O(V + E)  Space: O(V)
  Problems: LC 200 (islands), LC 133 (clone graph),
            LC 113 (path sum II), LC 797 (all paths)

----------------------------------------------------------------
11. BACKTRACKING
----------------------------------------------------------------
  When:  Generate all combinations/permutations/subsets.
         Constraint satisfaction (N-Queens, Sudoku).
  Keys:  choose -> recurse -> unchoose (backtrack).
  Time:  O(2^n) or O(n!)  Space: O(n)
  Problems: LC 78 (subsets), LC 46 (permutations),
            LC 39 (combo sum), LC 51 (N-Queens)

  Template:
    void backtrack(int start, List<Integer> current) {
      result.add(new ArrayList<>(current));  // add snapshot
      for (int i = start; i < nums.length; i++) {
        current.add(nums[i]);
        backtrack(i + 1, current);
        current.remove(current.size() - 1);  // undo
      }
    }

----------------------------------------------------------------
12. DYNAMIC PROGRAMMING
----------------------------------------------------------------
  When:  Optimal substructure + overlapping subproblems.
         Count/min/max over choices.
  Keys:  Define state, write recurrence, choose top-down or bottom-up.
  Time:  Varies O(n) to O(n^3)  Space: O(n) to O(n^2)
  Problems: LC 322 (coin change), LC 300 (LIS),
            LC 1143 (LCS), LC 416 (partition), LC 72 (edit dist)

  Key sub-patterns:
    Linear DP      -- dp[i] depends on dp[i-1] or small lookback
    Interval DP    -- dp[i][j] for subranges; fill by length
    Knapsack DP    -- include/exclude item; reverse for 0-1
    String DP      -- dp[i][j] for two-string problems

----------------------------------------------------------------
13. GREEDY
----------------------------------------------------------------
  When:  Locally optimal = globally optimal (provable).
         Interval scheduling, minimum operations.
  Keys:  Sort by some criterion. Make greedy choice at each step.
  Time:  O(n log n) usually  Space: O(1)
  Problems: LC 435 (intervals), LC 55/45 (jump game),
            LC 860 (lemonade), LC 134 (gas station)

----------------------------------------------------------------
14. UNION-FIND
----------------------------------------------------------------
  When:  Dynamic connectivity, number of components,
         cycle detection in undirected graph.
  Keys:  find() with path compression. union() with rank.
  Time:  O(alpha(n)) per op (near O(1))  Space: O(n)
  Problems: LC 684 (redundant connection), LC 547 (provinces),
            LC 721 (accounts merge), LC 1584 (min cost)

----------------------------------------------------------------
15. TRIE
----------------------------------------------------------------
  When:  Prefix searches, word dictionary, auto-complete,
         maximum XOR.
  Keys:  26-ary tree (lowercase) or binary (XOR).
  Time:  O(L) per op where L = word length  Space: O(26*N*L)
  Problems: LC 208 (implement trie), LC 212 (word search II),
            LC 421 (max XOR), LC 648 (replace words)

----------------------------------------------------------------
16. BIT MANIPULATION
----------------------------------------------------------------
  When:  Subsets, counting bits, single number, power of 2.
  Keys:  x & (x-1) removes lowest bit. x ^ x = 0.
  Time:  O(1) or O(n)  Space: O(1)
  Problems: LC 136/137/260 (single number), LC 338 (count bits),
            LC 78 (subsets via bitmask), LC 191 (hamming weight)

----------------------------------------------------------------
17. MATH & SIMULATION
----------------------------------------------------------------
  When:  Matrix manipulation (spiral, rotate), number theory,
         modular arithmetic.
  Keys:  Transpose + reflect for rotation. Direction array for spiral.
  Time:  O(n^2) for matrix  Space: O(1) in-place
  Problems: LC 54 (spiral), LC 48 (rotate), LC 73 (set zeroes),
            LC 13 (roman to integer)

----------------------------------------------------------------
PATTERN SELECTION PRIORITY (when unsure)
----------------------------------------------------------------
  1. Can I use TWO POINTERS?      (sorted + pairs -> yes, O(n))
  2. Is it a WINDOW problem?      (contiguous + constraint -> yes)
  3. Can I use BINARY SEARCH?     (monotone predicate -> yes)
  4. Is PREFIX SUM enough?        (range sum / count -> yes)
  5. Does it need exhaustive?     (all combinations -> backtracking)
  6. Do subproblems OVERLAP?      (yes -> DP instead of backtracking)
  7. Is it a GRAPH problem?       (BFS for shortest, DFS for all paths)
  8. Is it TOP K?                 (heap)
  9. Is it CONNECTIVITY?          (union-find)
  10. None of the above?          (simulate / math)
