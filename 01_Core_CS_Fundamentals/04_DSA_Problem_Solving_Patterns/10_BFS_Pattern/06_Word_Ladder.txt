================================================================
  WORD LADDER (LC 127)
================================================================

  Transform beginWord to endWord by changing one letter at a time.
  Each intermediate word must exist in wordList.
  Return the length of the shortest transformation sequence.
  Return 0 if no such sequence exists.

  Input:  beginWord="hit", endWord="cog",
          wordList=["hot","dot","dog","lot","log","cog"]
  Output: 5  (hit->hot->dot->dog->cog)

  Input:  beginWord="hit", endWord="cog",
          wordList=["hot","dot","dog","lot","log"]
  Output: 0  (cog not in wordList)

----------------------------------------------------------------
APPROACH: BFS ON WORD GRAPH
----------------------------------------------------------------

  Each word is a node. Two words are connected if they differ by one letter.
  BFS finds the shortest path from beginWord to endWord.

  Naive neighbor generation: O(26 * L) per word (try replacing each letter).

  Java:
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> wordSet = new HashSet<>(wordList);
        if (!wordSet.contains(endWord)) return 0;

        Queue<String> queue = new ArrayDeque<>();
        queue.offer(beginWord);
        wordSet.remove(beginWord);  // mark visited by removing from set

        int steps = 1;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                String curr = queue.poll();
                char[] chars = curr.toCharArray();

                for (int j = 0; j < chars.length; j++) {
                    char orig = chars[j];
                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == orig) continue;
                        chars[j] = c;
                        String next = new String(chars);
                        if (next.equals(endWord)) return steps + 1;
                        if (wordSet.contains(next)) {
                            wordSet.remove(next);   // mark visited
                            queue.offer(next);
                        }
                    }
                    chars[j] = orig;  // restore
                }
            }
            steps++;
        }
        return 0;
    }

  Time: O(M² * N)  where M = word length, N = wordList size
    -- M positions * 26 letters = O(26M) neighbors per word
    -- new String(chars) = O(M) copy
  Space: O(M * N)

----------------------------------------------------------------
TRACED EXAMPLE
----------------------------------------------------------------

  beginWord="hit", endWord="cog"
  wordSet={"hot","dot","dog","lot","log","cog"}

  queue=[hit], steps=1

  Process "hit":
    h_t: aat,abt,...hot -> wordSet has hot! remove hot, add hot
    hi_: hia..hiz, hiz-zip... none in set
    _it: ait..zit... none
  queue=[hot], steps=2

  Process "hot":
    _ot: aot..dot -> dot in set! lot in set! remove, add both
    h_t: hat, hbt..hzt... none
    ho_: hoa..hoz... none
  queue=[dot,lot], steps=3

  Process "dot":
    _ot: lot already removed, bot...none
    d_t: dat,dbt..dzt... none
    do_: doa..doz... dog in set! remove, add
  Process "lot":
    _ot: none (dot gone)
    lo_: log in set! remove, add
  queue=[dog,log], steps=4

  Process "dog":
    do_: dog->cog? no, do_ = doa..doz. Actually _og: bog..cog! cog = endWord! return 4+1=5 ✓

----------------------------------------------------------------
BIDIRECTIONAL BFS (OPTIMIZATION FOR LC 127)
----------------------------------------------------------------

  Search from both beginWord and endWord simultaneously.
  When a word from one frontier appears in the other, we found the path.
  Cuts search space from O(b^d) to O(b^(d/2)).

  Java:
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> wordSet = new HashSet<>(wordList);
        if (!wordSet.contains(endWord)) return 0;

        Set<String> beginSet = new HashSet<>(), endSet = new HashSet<>();
        beginSet.add(beginWord);
        endSet.add(endWord);
        int steps = 1;

        while (!beginSet.isEmpty() && !endSet.isEmpty()) {
            // Always expand the smaller set (optimization)
            if (beginSet.size() > endSet.size()) {
                Set<String> tmp = beginSet; beginSet = endSet; endSet = tmp;
            }

            Set<String> nextSet = new HashSet<>();
            for (String word : beginSet) {
                char[] chars = word.toCharArray();
                for (int j = 0; j < chars.length; j++) {
                    char orig = chars[j];
                    for (char c = 'a'; c <= 'z'; c++) {
                        chars[j] = c;
                        String next = new String(chars);
                        if (endSet.contains(next)) return steps + 1;  // MEET!
                        if (wordSet.contains(next)) {
                            wordSet.remove(next);
                            nextSet.add(next);
                        }
                    }
                    chars[j] = orig;
                }
            }
            beginSet = nextSet;
            steps++;
        }
        return 0;
    }

  Time: O(M² * N) but constant factor is much smaller in practice.

----------------------------------------------------------------
VARIANT: WORD LADDER II (LC 126) — ALL SHORTEST PATHS
----------------------------------------------------------------

  Return ALL shortest transformation sequences.

  Approach:
    1. BFS to find shortest distance from each word to endWord (reverse BFS from end).
    2. DFS from beginWord, only move to neighbors with dist-1 in reverse BFS tree.

  Java (BFS part):
    Map<String, Integer> dist = new HashMap<>();
    // BFS from endWord backward
    queue.offer(endWord); dist.put(endWord, 0);
    while (!queue.isEmpty()) {
        String curr = queue.poll();
        for (String neighbor : getNeighbors(curr, wordSet)) {
            if (!dist.containsKey(neighbor)) {
                dist.put(neighbor, dist.get(curr) + 1);
                queue.offer(neighbor);
            }
        }
    }

  Then DFS from beginWord, building paths:
    if (curr.equals(endWord)) { result.add(new ArrayList<>(path)); return; }
    for (String neighbor : getNeighbors(curr, wordSet)) {
        if (dist.containsKey(neighbor) && dist.get(neighbor) == dist.get(curr) - 1) {
            path.add(neighbor);
            dfs(neighbor, endWord, wordSet, dist, path, result);
            path.remove(path.size()-1);
        }
    }

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. Forgetting to check if endWord is in wordList.
  2. Not removing visited words from wordSet (TLE or infinite loop).
  3. Returning steps instead of steps+1 when endWord is found as neighbor.
  4. For bidirectional BFS: when sets are swapped, remember the
     beginSet/endSet roles -- "endSet" is always the OTHER frontier to check against.

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why remove visited words from wordSet instead of a separate visited set?
  A: wordSet removal does double duty: marks word as visited AND removes it
     from future consideration. A separate visited set works too but uses
     extra space.

  Q: How much does bidirectional BFS help?
  A: If branching factor is b and shortest path length is d:
     One-direction BFS: O(b^d) nodes explored.
     Bidirectional BFS: O(2 * b^(d/2)) = much smaller for large d.
     Example: b=26, d=10: 26^10 vs 2*26^5.

  Q: For Word Ladder II, why do BFS from end instead of from start?
  A: We want to know the distance from each word to the END. This lets us
     prune DFS paths that don't lead toward the end.

  Q: What's the time complexity?
  A: O(M² * N): M = word length, N = dictionary size.
     For each of N words, we generate O(26M) neighbors, each costing O(M)
     for the string copy. Total: N * 26M * M = O(M²N).

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - State the BFS approach first, then mention bidirectional BFS optimization.
  - The key trick: generate neighbors by trying all 26 replacements for each position.
  - Mark visited by removing from wordSet -- elegant and avoids extra set.
  - For Word Ladder II (all paths), mention BFS + DFS two-phase approach.
  - The "check if endWord is in wordList" guard at the start is easy to forget.
