================================================================
  ROTTING ORANGES — MULTI-SOURCE BFS (LC 994)
================================================================

  Grid with: 0 = empty, 1 = fresh orange, 2 = rotten orange.
  Each minute, a rotten orange infects adjacent (4-directional) fresh oranges.
  Return minimum minutes until no fresh oranges remain.
  Return -1 if impossible.

  Input:
    2 1 1
    1 1 0
    0 1 1
  Output: 4

  Input:
    2 1 1
    0 1 1
    1 0 1
  Output: -1  (bottom-left orange is isolated)

  Input:
    0 2
  Output: 0  (no fresh oranges)

----------------------------------------------------------------
MULTI-SOURCE BFS APPROACH
----------------------------------------------------------------

  All rotten oranges start infecting simultaneously.
  Add ALL rotten oranges to queue at the beginning.
  BFS expands by level -- each level = one minute passed.

  Java:
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Queue<int[]> queue = new ArrayDeque<>();
        int freshCount = 0;

        // Initialize: add all rotten oranges, count fresh
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 2) queue.offer(new int[]{r, c});
                else if (grid[r][c] == 1) freshCount++;
            }
        }

        if (freshCount == 0) return 0;  // no fresh oranges

        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        int minutes = 0;

        while (!queue.isEmpty() && freshCount > 0) {
            minutes++;
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int[] curr = queue.poll();
                for (int[] dir : dirs) {
                    int nr = curr[0]+dir[0], nc = curr[1]+dir[1];
                    if (nr>=0 && nr<m && nc>=0 && nc<n && grid[nr][nc]==1) {
                        grid[nr][nc] = 2;       // infect
                        freshCount--;
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
        }

        return freshCount == 0 ? minutes : -1;
    }

  Time: O(m*n)   Space: O(m*n)

----------------------------------------------------------------
TRACED EXAMPLE
----------------------------------------------------------------

  Grid:           Fresh count = 6
    2 1 1
    1 1 0
    0 1 1

  Init queue: [(0,0)]. freshCount=6. minutes=0.

  Minute 1: process (0,0):
    Infect (0,1)=1 --> 2. freshCount=5. Add (0,1).
    Infect (1,0)=1 --> 2. freshCount=4. Add (1,0).
    queue=[(0,1),(1,0)]

  Minute 2: process (0,1):
    Infect (0,2)=1 --> 2. freshCount=3. Add (0,2).
    (1,1)=1 --> 2. freshCount=2. Add (1,1).
  process (1,0):
    (1,1) already 2. (2,0)=0 skip. Others: already rotten.
    queue=[(0,2),(1,1)]

  Minute 3: process (0,2): (1,2)=0 skip. No new.
  process (1,1): (2,1)=1 --> 2. freshCount=1. Add (2,1).
    queue=[(2,1)]

  Minute 4: process (2,1): (2,2)=1 --> 2. freshCount=0. Add (2,2).
    queue=[(2,2)]. freshCount=0 so loop ends.

  Return minutes=4 ✓

----------------------------------------------------------------
EDGE CASES
----------------------------------------------------------------

  1. No fresh oranges at start: return 0 immediately.
  2. No rotten oranges but fresh exist: queue empty from start.
     Loop doesn't execute, minutes=0, freshCount>0 --> return -1.
  3. All oranges are rotten: freshCount=0 --> return 0.
  4. Fresh orange surrounded by empty cells: unreachable, return -1.

  Checking freshCount==0 BEFORE and AFTER BFS handles cases 1 and 4.

----------------------------------------------------------------
WHY LEVEL-BY-LEVEL (INT SIZE FREEZE) MATTERS HERE
----------------------------------------------------------------

  Without freezing size:
    All cells infected in arbitrary order.
    We'd increment minutes for each cell, not each "wave."

  With freezing (int size = queue.size()):
    Each wave (one minute) processed before moving to next.
    Minutes counted correctly.

  Alternative: store time in the queue cell itself:
    queue.offer(new int[]{r, c, 0});  // 0 = time when this orange became rotten
    int time = curr[2];
    // infected neighbors have time+1
    minutes = Math.max(minutes, time+1);

  Both approaches work. Level-by-level with size freeze is simpler.

----------------------------------------------------------------
GENERAL MULTI-SOURCE BFS TEMPLATE
----------------------------------------------------------------

  Problem patterns where multi-source BFS applies:
    - Rotting Oranges: all rotten oranges
    - 01 Matrix (LC 542): all cells with value 0
    - Walls and Gates (LC 286): all gates
    - Maps: all fire sources, all "infected" nodes
    - Treasure hunt: nearest treasure from multiple locations

  Template:
    1. Identify all "sources" (initial state).
    2. Add ALL sources to queue, mark all as visited.
    3. BFS normally -- each level represents one unit of time/distance.
    4. Each cell's distance = distance from NEAREST source.

----------------------------------------------------------------
VARIANT: TIME NEEDED TO INFORM ALL EMPLOYEES (LC 1376)
----------------------------------------------------------------

  Tree of employees. Manager informs direct reports, who inform theirs.
  Each edge has a delay (informTime). Find total time.

  BFS from root (headID), tracking cumulative time.
  State: (employee, time_reached).

  DFS is more natural here, but BFS with time tracking works too.

  Java:
    public int numOfMinutes(int n, int headID, int[] manager, int[] informTime) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int i = 0; i < n; i++)
            if (manager[i] != -1) adj.get(manager[i]).add(i);

        int maxTime = 0;
        Queue<int[]> queue = new ArrayDeque<>();  // [employee, time_to_reach]
        queue.offer(new int[]{headID, 0});

        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int emp = curr[0], t = curr[1];
            maxTime = Math.max(maxTime, t);
            for (int sub : adj.get(emp)) {
                queue.offer(new int[]{sub, t + informTime[emp]});
            }
        }
        return maxTime;
    }

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why add ALL rotten oranges before starting BFS (not process one by one)?
  A: If we process one at a time, the order matters, giving wrong minutes count.
     Multi-source BFS simulates all spreading simultaneously, which matches
     the "each minute" semantics of the problem.

  Q: Why check freshCount == 0 before starting BFS?
  A: If there are no fresh oranges, the answer is 0 regardless of
     whether there are rotten oranges. Saves a BFS run.

  Q: How do you detect the impossible case?
  A: After BFS, if freshCount > 0, some fresh orange was unreachable.
     Return -1.

  Q: Can you solve this without counting minutes explicitly?
  A: Yes. Store time in the queue tuple. Track max time reached.
     minutes = max time when any orange becomes rotten.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - State the multi-source approach upfront: "start all rotten oranges at once."
  - The minutes counter only increments when the queue processes a full level.
  - The two tricky checks: freshCount==0 before BFS AND after BFS.
  - This problem is a classic multi-source BFS template — know it cold.
