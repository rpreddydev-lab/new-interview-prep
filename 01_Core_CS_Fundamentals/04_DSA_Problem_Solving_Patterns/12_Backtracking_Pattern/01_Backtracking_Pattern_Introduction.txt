================================================================
  BACKTRACKING PATTERN — INTRODUCTION
================================================================

  Backtracking = DFS + undo.
  Build a solution incrementally. At each step, make a choice.
  If the choice leads to no valid solution, UNDO it (backtrack)
  and try the next option.

  Problems: generate all subsets, permutations, combinations.
  Also: constraint satisfaction (N-Queens, Sudoku).

----------------------------------------------------------------
UNIVERSAL BACKTRACKING TEMPLATE
----------------------------------------------------------------

  Java:
    void backtrack(state, choices, result) {
        if (isSolution(state)) {
            result.add(copy of state);
            return;
        }

        for (each choice) {
            if (isValid(choice)) {
                makeChoice(state, choice);     // CHOOSE
                backtrack(state, choices, result);  // EXPLORE
                undoChoice(state, choice);     // UN-CHOOSE
            }
        }
    }

  The THREE parts of backtracking:
    1. Choose:     add to current state
    2. Explore:    recurse deeper
    3. Un-choose:  remove from current state (backtrack)

----------------------------------------------------------------
BACKTRACKING VISUALIZATION
----------------------------------------------------------------

  For subsets of [1,2,3]:

               []
          /         \
        [1]          []
       /   \        /   \
    [1,2]  [1]   [2]    []
    /  \   / \   / \    / \
  [1,2,3][1,2][1,3][1][2,3][2][3][]

  At each node, we decide: include current element or not.
  Leaf nodes = complete subsets.

----------------------------------------------------------------
BACKTRACKING DECISION TREE
----------------------------------------------------------------

  Key question for each problem: "What are the choices at each step?"

  Subsets:         For each element: include or not.
  Permutations:    For each position: which unused element to place.
  Combinations:    From remaining elements: pick k of them.
  String partition:  For each starting index: how far to extend the piece.
  N-Queens:        For each row: which column to place the queen.

----------------------------------------------------------------
PRUNING
----------------------------------------------------------------

  Backtracking without pruning = brute force.
  Pruning: skip choices that can't possibly lead to valid solutions.

  Examples:
    Combination Sum: if curr_sum > target, stop adding.
    N-Queens: if position is under attack, skip.
    Palindrome partitioning: if substring is not palindrome, skip.

  Pruning reduces the number of recursive calls drastically.

----------------------------------------------------------------
CHOOSING STARTING INDEX vs FULL RANGE
----------------------------------------------------------------

  Combinations (no repeat, order doesn't matter):
    Start next recursion from (i+1) -- avoid revisiting earlier elements.

  Combination Sum (can reuse elements):
    Start next recursion from (i) -- can revisit same element.

  Permutations (order matters):
    Use a boolean[] used array. Each call considers ALL unused elements.

  Subsets (each element used 0 or 1 time):
    Either bit-mask or start index approach.

----------------------------------------------------------------
AVOIDING DUPLICATES
----------------------------------------------------------------

  When input has duplicates and we want unique results:
    1. Sort the input first.
    2. Skip element if it equals the previous element AND the previous
       element was NOT used in the current branch.

  Java:
    Arrays.sort(nums);
    // In backtrack:
    for (int i = start; i < nums.length; i++) {
        if (i > start && nums[i] == nums[i-1]) continue;  // skip duplicates
        // ...
    }

  This ensures we only use the first occurrence of each value
  at each position in the tree.

----------------------------------------------------------------
COMPLEXITY OF BACKTRACKING
----------------------------------------------------------------

  Subsets:         O(2^n * n)  -- 2^n subsets, O(n) to copy each
  Permutations:    O(n! * n)   -- n! permutations, O(n) to copy each
  Combinations:    O(C(n,k) * k)
  Combination Sum: O(n^(target/min))  exponential

  Space: O(n) recursion depth + O(n) for current state
