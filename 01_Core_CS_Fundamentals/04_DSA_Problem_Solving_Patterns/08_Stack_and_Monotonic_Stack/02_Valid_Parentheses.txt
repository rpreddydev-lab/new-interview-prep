PROBLEM (LC 20): VALID PARENTHESES
----------------------------------------------------------------

  Given a string with '(', ')', '{', '}', '[', ']',
  determine if it's valid. Rules:
  - Open brackets must be closed by the same type.
  - Open brackets must be closed in the correct order.
  - Empty string is valid.

  Example:
    "()"       --> true
    "()[]{}"   --> true
    "(]"       --> false
    "([)]"     --> false
    "{[]}"     --> true

----------------------------------------------------------------
JAVA SOLUTION
----------------------------------------------------------------

  public boolean isValid(String s) {
      Deque<Character> stack = new ArrayDeque<>();

      for (char c : s.toCharArray()) {
          if (c == '(' || c == '{' || c == '[') {
              stack.push(c);
          } else {
              if (stack.isEmpty()) return false;
              char top = stack.pop();
              if (c == ')' && top != '(') return false;
              if (c == '}' && top != '{') return false;
              if (c == ']' && top != '[') return false;
          }
      }
      return stack.isEmpty();
  }

  Time: O(n)  Space: O(n)

  Key conditions:
    - Empty stack when closing bracket arrives --> false
    - Stack not empty at end --> false (unmatched open brackets)

  Cleaner with a map:
    Map<Character, Character> map = Map.of(')', '(', '}', '{', ']', '[');
    for (char c : s.toCharArray()) {
        if (!map.containsKey(c)) {
            stack.push(c);
        } else if (stack.isEmpty() || stack.pop() != map.get(c)) {
            return false;
        }
    }
    return stack.isEmpty();

----------------------------------------------------------------
TRACED EXAMPLE: s="{[]}"
----------------------------------------------------------------

  i=0: '{' --> push. stack=[{]
  i=1: '[' --> push. stack=[{, []
  i=2: ']' --> pop '[', ']' matches '[' ✓. stack=[{]
  i=3: '}' --> pop '{', '}' matches '{' ✓. stack=[]
  stack empty --> true ✓

PROBLEM (LC 32): LONGEST VALID PARENTHESES
----------------------------------------------------------------

  Find the length of the longest valid (well-formed) parentheses substring.

  Input: "(()"  --> 2
  Input: ")()())" --> 4
  Input: "()()" --> 4

  Approach: Use a stack to track indices.
  Push the index of '(' onto the stack.
  For ')': pop the top; if stack is empty, push current index as new "base".
  At each step: length = current_index - stack_top (if not empty).

  Java:
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);  // base index
        int maxLen = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();  // pop matched '(' or base
                if (stack.isEmpty()) {
                    stack.push(i);  // new base
                } else {
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        return maxLen;
    }

  Time: O(n)  Space: O(n)

  Trace: ")()())"  indices: 0 1 2 3 4 5
    stack=[-1]
    i=0: ')' pop -1, stack empty, push 0. stack=[0]
    i=1: '(' push 1. stack=[0,1]
    i=2: ')' pop 1, stack=[0], maxLen=max(0, 2-0)=2
    i=3: '(' push 3. stack=[0,3]
    i=4: ')' pop 3, stack=[0], maxLen=max(2, 4-0)=4
    i=5: ')' pop 0, stack empty, push 5. stack=[5]
    Answer: 4 ✓

PROBLEM (LC 1249): MINIMUM REMOVE TO MAKE VALID PARENTHESES
----------------------------------------------------------------

  Remove minimum number of parentheses to make a string valid.
  Return the result string.

  Input: "lee(t(c)o)de)"  --> "lee(t(c)o)de"
  Input: "a)b(c)d"       --> "ab(c)d"

  Approach:
    1. Use stack to find indices of unmatched parentheses.
    2. Build result skipping those indices.

  Java:
    public String minRemoveToMakeValid(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        Set<Integer> toRemove = new HashSet<>();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                stack.push(i);
            } else if (c == ')') {
                if (stack.isEmpty()) {
                    toRemove.add(i);  // unmatched ')'
                } else {
                    stack.pop();  // matched
                }
            }
        }
        // Remaining in stack = unmatched '('
        while (!stack.isEmpty()) toRemove.add(stack.pop());

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            if (!toRemove.contains(i)) sb.append(s.charAt(i));
        }
        return sb.toString();
    }

  Time: O(n)  Space: O(n)

PROBLEM (LC 856): SCORE OF PARENTHESES
----------------------------------------------------------------

  Balanced string: () = 1, concatenation AB = A+B, nesting (A) = 2*A.

  Input: "()"       --> 1
  Input: "(())"     --> 2
  Input: "()()"     --> 2
  Input: "(()(()))" --> 6

  Approach: count the "depth" contribution.
  Each ')(' pair contributes 2^depth where depth = nesting level.

  Actually simpler: track current depth.
  When we see "()", its contribution is 2^(current_depth - 1).
  But we need to know when we see "()" vs deep nesting.

  Stack approach: push 0 when seeing '('.
  When seeing ')':
    - Pop the top v.
    - If v == 0: this is a "()" pair. Add 2^depth to PARENT (or 1 if depth=0).
      Actually: if v==0, contribution = max(1, 2*top_parent). But it's cleaner:
    - Push the result back up to the running sum.

  Simpler: stack of integers.
    stack = [0]  // one 0 to start
    '(': push 0
    ')': v = pop. stack[-1] += max(2*v, 1)

  Java:
    public int scoreOfParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);

        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(0);
            } else {
                int v = stack.pop();
                int parent = stack.pop();
                stack.push(parent + Math.max(2 * v, 1));
            }
        }
        return stack.pop();
    }

  Time: O(n)  Space: O(n)

  Trace: "(())"
    stack=[0]
    '(': [0, 0]
    '(': [0, 0, 0]
    ')': v=0, parent=0, max(2*0,1)=1, push 1. [0, 1]
    ')': v=1, parent=0, max(2*1,1)=2, push 2. [2]
    Result: 2 ✓

----------------------------------------------------------------
COMMON PATTERN: USING STACK INDEX
----------------------------------------------------------------

  Many bracket problems benefit from storing INDICES (not characters):
    - Allows computing spans/lengths (i - stack.peek())
    - Allows marking positions for removal
    - More flexible than just tracking open/close characters

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. Not checking stack.isEmpty() before stack.pop() / peek().
     Always guard: if (stack.isEmpty()) return false.

  2. Final check: return stack.isEmpty() (not just true).
     Unmatched open brackets at the end make the string invalid.

  3. For LC 32: initializing stack with -1 as the "base" index.
     Forgetting to push -1 causes wrong results for strings like ")".

  4. For LC 1249: need to remove ALL unmatched brackets (both '(' and ')').
     After processing ')' cases, the stack still holds unmatched '(' indices.

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why use a stack for bracket matching?
  A: Brackets have nested structure — the most recently opened bracket
     must be closed first (LIFO). A stack naturally models this.

  Q: What does it mean if the stack is non-empty at the end?
  A: There are unmatched open brackets. The string is invalid.

  Q: Can we solve Valid Parentheses without a stack for single bracket type?
  A: Yes — use a counter. Increment on '(', decrement on ')'.
     If counter goes negative, invalid. If counter != 0 at end, invalid.
     But for multiple bracket types, a stack is required.
