RESERVOIR SAMPLING PATTERN
===========================

INTRODUCTION
-------------
  Reservoir Sampling is an algorithm for randomly selecting k items
  from a stream of n items where n is UNKNOWN or VERY LARGE,
  using only O(k) memory.

  Core guarantee:
  Every item in the stream has an EQUAL probability of k/n of being
  selected — regardless of the order items appear.

  Use cases:
  - Random sample from a large database/file without loading all data
  - Stream processing — pick k random tweets from a live feed
  - A/B testing — randomly assign users to buckets
  - Distributed sampling from logs

─────────────────────────────────────────────────────────────
SIMPLE RESERVOIR SAMPLING (k = 1)
─────────────────────────────────────────────────────────────
  Select 1 item uniformly at random from a stream.

  Algorithm:
    result = stream[0]
    for i from 1 to n-1:
        j = random(0, i)      // random int in [0, i] inclusive
        if j == 0:
            result = stream[i]

  Why this works (proof by induction):
    After 1 item:  item 1 selected with prob 1/1 ✅
    After 2 items: item 1 kept with prob 1 × (1/2 not picked) = 1/2
                   item 2 selected with prob 1/2 ✅
    After i items: each item has prob 1/i ✅

  Java implementation:
    public static <T> T reservoirSampleOne(List<T> stream) {
        Random rand = new Random();
        T result = stream.get(0);
        for (int i = 1; i < stream.size(); i++) {
            if (rand.nextInt(i + 1) == 0) {
                result = stream.get(i);
            }
        }
        return result;
    }

─────────────────────────────────────────────────────────────
GENERAL RESERVOIR SAMPLING (k items) — Algorithm R
─────────────────────────────────────────────────────────────
  Select k items uniformly at random from a stream of n items.

  Algorithm (Vitter's Algorithm R):
    1. Fill reservoir[] with first k items
    2. For each subsequent item i (from k to n-1):
         j = random(0, i)        // random int in [0, i] inclusive
         if j < k:
             reservoir[j] = stream[i]  // replace a random reservoir item

  Java implementation:
  ----------------------
  public static <T> List<T> reservoirSample(List<T> stream, int k) {
      Random rand = new Random();
      List<T> reservoir = new ArrayList<>(stream.subList(0, k));

      for (int i = k; i < stream.size(); i++) {
          int j = rand.nextInt(i + 1);  // [0, i]
          if (j < k) {
              reservoir.set(j, stream.get(i));
          }
      }
      return reservoir;
  }

  // For true streaming (Iterator-based):
  public static <T> List<T> reservoirSample(Iterator<T> stream, int k) {
      Random rand = new Random();
      List<T> reservoir = new ArrayList<>(k);

      int i = 0;
      while (stream.hasNext()) {
          T item = stream.next();
          if (i < k) {
              reservoir.add(item);
          } else {
              int j = rand.nextInt(i + 1);
              if (j < k) {
                  reservoir.set(j, item);
              }
          }
          i++;
      }
      return reservoir;
  }

─────────────────────────────────────────────────────────────
PROBABILITY PROOF (k items)
─────────────────────────────────────────────────────────────
  Claim: After processing all n items, each item has exactly k/n probability
  of being in the reservoir.

  For item i (0-indexed):
  - If i < k (first k items): probability of being in reservoir after
    processing all n = product of survival at each step
    P(item i in final) = k/n  (by induction / symmetry argument)

  - If i ≥ k: probability of entering = k/(i+1)
    Probability of NOT being replaced by any later item j:
      = ∏(j=i+1 to n-1) [1 - 1/(j+1) × 1/k × k] = ... = (i+1)/n
    Total = k/(i+1) × (i+1)/n = k/n ✅

─────────────────────────────────────────────────────────────
WEIGHTED RESERVOIR SAMPLING
─────────────────────────────────────────────────────────────
  When items have weights (some items should appear more often):

  Efraimidis-Spirakis Algorithm (Algorithm A-Res):
    For each item with weight w:
      key = random^(1/w)   // or equivalently: key = -ln(random) / w
    Select k items with HIGHEST keys.

  Java approach (min-heap of size k):
    PriorityQueue<double[]> minHeap = new PriorityQueue<>(
        Comparator.comparingDouble(a -> a[0])
    );

    for (Item item : stream) {
        double key = Math.pow(rand.nextDouble(), 1.0 / item.weight);
        if (minHeap.size() < k) {
            minHeap.offer(new double[]{key, item.id});
        } else if (key > minHeap.peek()[0]) {
            minHeap.poll();
            minHeap.offer(new double[]{key, item.id});
        }
    }
    // minHeap contains the k selected items

─────────────────────────────────────────────────────────────
COMPLEXITY
─────────────────────────────────────────────────────────────
  Time:  O(n) — single pass through stream
  Space: O(k) — only the reservoir is stored

      Return a uniformly random node from a singly linked list
      → Reservoir sampling with k=1 while traversing the list

  - LC 398: Random Pick Index
      Given an array with duplicates, pick a random index of a given target
      → Reservoir sampling with k=1, counting only target occurrences

  - LC 384: Shuffle an Array (Fisher-Yates — related)

  LC 382 Solution:
    class Solution {
        ListNode head;
        Random rand = new Random();

        public Solution(ListNode head) { this.head = head; }

        public int getRandom() {
            int result = -1, i = 1;
            ListNode curr = head;
            while (curr != null) {
                if (rand.nextInt(i) == 0) result = curr.val;
                curr = curr.next;
                i++;
            }
            return result;
        }
    }

─────────────────────────────────────────────────────────────
WHEN TO IDENTIFY THIS PATTERN
─────────────────────────────────────────────────────────────
  Triggers:
  ✅ "Select k random items from a stream / unknown-size list"
  ✅ "Cannot load all data into memory"
  ✅ "Uniform random sample from large dataset"
  ✅ "Find random node/element with single pass"

  Compare with:
  - Shuffle (Fisher-Yates): requires all items in memory — O(n) space
  - Reservoir sampling: O(k) space — works on streams

─────────────────────────────────────────────────────────────
INTERVIEW QUESTIONS
─────────────────────────────────────────────────────────────
  Q: How would you randomly pick a line from a file without knowing its size?
  A: Reservoir sampling with k=1. For each line i (1-indexed), keep it
     with probability 1/i (replace current result with probability 1/i).
     After reading all lines, the result is a uniform random selection.

  Q: Prove that each item has equal probability in reservoir sampling.
  A: After n items with k=1: P(item i selected) = 1/i × ∏(j=i+1 to n) (1 - 1/j)
     = 1/i × i/(i+1) × (i+1)/(i+2) × ... × (n-1)/n = 1/n. ✅

  Q: What if items have different weights?
  A: Use weighted reservoir sampling (Efraimidis-Spirakis). Assign each item
     a key = random^(1/weight) and keep top k keys. Higher weight → higher
     probability of selection.
