DATA STRUCTURE OPERATIONS
----------------------------------------------------------------
  Structure         Access    Search    Insert    Delete    Space
  ---------------------------------------------------------------
  Array             O(1)      O(n)      O(n)      O(n)      O(n)
  Dynamic Array     O(1)      O(n)      O(1)*     O(n)      O(n)
  Singly Linked     O(n)      O(n)      O(1)^     O(1)^     O(n)
  Doubly Linked     O(n)      O(n)      O(1)^     O(1)^     O(n)
  Stack             O(n)      O(n)      O(1)      O(1)      O(n)
  Queue             O(n)      O(n)      O(1)      O(1)      O(n)
  HashMap           O(1)*     O(1)*     O(1)*     O(1)*     O(n)
  TreeMap           O(log n)  O(log n)  O(log n)  O(log n)  O(n)
  HashSet           --        O(1)*     O(1)*     O(1)*     O(n)
  TreeSet           --        O(log n)  O(log n)  O(log n)  O(n)
  Binary Heap       O(1)~     O(n)      O(log n)  O(log n)  O(n)
  BST (balanced)    O(log n)  O(log n)  O(log n)  O(log n)  O(n)
  BST (unbalanced)  O(n)      O(n)      O(n)      O(n)      O(n)
  Trie              --        O(k)      O(k)      O(k)      O(n*k)

  * = average case (worst case O(n) due to hash collisions)
  ^ = given reference to the node
  ~ = peek only (top/min/max element)
  k = length of the key/string

GRAPH ALGORITHM COMPLEXITY
----------------------------------------------------------------
  Algorithm                   Time            Space
  ---------------------------------------------------------------
  BFS                         O(V + E)        O(V)
  DFS                         O(V + E)        O(V)
  Dijkstra (binary heap)      O((V+E) log V)  O(V)
  Bellman-Ford                O(V * E)        O(V)
  Floyd-Warshall              O(V³)           O(V²)
  Prim's MST (binary heap)    O((V+E) log V)  O(V)
  Kruskal's MST               O(E log E)      O(V)
  Topological Sort (DFS)      O(V + E)        O(V)
  Union-Find (path compress)  O(α(n)) ~O(1)   O(V)

  V = number of vertices, E = number of edges
  α = inverse Ackermann function (practically constant)

COMMON INTERVIEW PATTERNS AND THEIR COMPLEXITY
----------------------------------------------------------------

  Two Pointers
    Time: O(n)    Space: O(1)
    Used for: sorted array problems, palindrome check,
              pair sum, removing duplicates

  Sliding Window
    Time: O(n)    Space: O(1) or O(k)
    Used for: subarray/substring problems with constraint k

  Binary Search (on answer)
    Time: O(log n * cost of check)   Space: O(1)
    Used for: min/max feasibility problems

  BFS (shortest path, level order)
    Time: O(V + E)    Space: O(V) for queue

  DFS (path finding, backtracking)
    Time: O(V + E)    Space: O(h) for stack/recursion

  Dynamic Programming (1D)
    Time: O(n)    Space: O(n) or O(1) with optimization

  Dynamic Programming (2D)
    Time: O(n * m)    Space: O(n * m) or O(m) optimized

  Heap / Priority Queue
    Time: O(n log k) for top-k problems
    Space: O(k)

  Monotonic Stack
    Time: O(n)    Space: O(n)
    Used for: next greater element, histogram problems

  Union-Find
    Time: O(α(n)) per operation ~O(1)
    Space: O(n)
    Used for: connected components, cycle detection

  Trie
    Time: O(k) per insert/search  (k = key length)
    Space: O(n * k) total
    Used for: prefix search, autocomplete, word problems

  Backtracking
    Time: O(b^d)  b = branching factor, d = depth
    Space: O(d) recursion stack
    Used for: permutations, combinations, N-Queens, Sudoku

COMPLEXITY BY PROBLEM TYPE (INTERVIEW GUIDE)
----------------------------------------------------------------

  Problem Type                      Expected Complexity
  ---------------------------------------------------------------
  Find element in unsorted array    O(n) time, O(1) space
  Find element in sorted array      O(log n) time, O(1) space
  Count frequencies                 O(n) time, O(n) space
  Two sum in sorted array           O(n) time, O(1) space (2ptr)
  Two sum in unsorted array         O(n) time, O(n) space (map)
  Reverse array/string in-place     O(n) time, O(1) space
  Merge two sorted arrays           O(n + m) time, O(n + m) space
  Detect cycle in linked list       O(n) time, O(1) space (Floyd)
  Find kth largest element          O(n log k) time, O(k) space
  Top k frequent elements           O(n log k) time, O(n) space
  Longest substring without repeat  O(n) time, O(k) space
  Validate BST                      O(n) time, O(h) space
  LCA in BST                        O(h) time, O(h) space
  Level order traversal             O(n) time, O(n) space
  Shortest path (unweighted)        O(V + E) time, O(V) space
  Shortest path (weighted)          O((V+E) log V), O(V) space
  Generate all subsets              O(2^n) time, O(n) space
  Generate all permutations         O(n!) time, O(n) space
  Edit distance (DP)                O(n*m) time, O(n*m) space
  Coin change (DP)                  O(n*amount) time, O(amount)
