  1. MONGODB OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MongoDB is a document-oriented NoSQL database:
  - Stores data as BSON (Binary JSON) documents
  - Schema-less (flexible structure per document)
  - Horizontal scaling via sharding
  - Rich query language, secondary indexes, aggregation pipeline
  - No JOINs — embed related data or use $lookup

Hierarchy:
  Database → Collection → Document (≈ DB → Table → Row)

  3. DOCUMENT MAPPING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

@Document(collection = "products")
public class Product {

    @Id                           // maps to _id field (ObjectId)
    private String id;            // String, ObjectId, or UUID

    @Field("product_name")        // custom BSON field name
    private String name;

    private BigDecimal price;

    @DBRef                        // reference to another document (lazy)
    private Category category;    // stores DBRef, resolves on access

    @Indexed(unique = true)       // creates a MongoDB index
    private String sku;

    @TextIndexed                  // for text search ($text operator)
    private String description;

    private List<Tag> tags;       // embedded array — not a separate collection

    private Map<String, Object> metadata;  // flexible key-value pairs

    // ...
}

@Document
public class Tag {
    private String name;
    private String color;
}

  4. REPOSITORY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

public interface ProductRepository
        extends MongoRepository<Product, String> {

    // Derived query methods work the same way as JPA
    List<Product> findByName(String name);
    List<Product> findByPriceLessThan(BigDecimal maxPrice);
    List<Product> findByTagsNameIn(List<String> tagNames);   // nested field
    Page<Product> findByCategory_Name(String catName, Pageable p);

    // Custom @Query with MongoDB JSON query syntax
    @Query("{ 'price': { $gt: ?0, $lt: ?1 } }")
    List<Product> findInPriceRange(BigDecimal min, BigDecimal max);

    @Query(fields = "{ 'name': 1, 'price': 1 }")  // projection
    List<Product> findNameAndPriceByCategory(String category);

    // Existence / count
    boolean existsBySku(String sku);
    long countByCategory_Name(String catName);
}

  5. MongoTemplate — ADVANCED OPERATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MongoTemplate provides full MongoDB API access:

@Service
public class ProductService {

    private final MongoTemplate mongoTemplate;

    // INSERT
    public Product create(Product p) {
        return mongoTemplate.insert(p);
    }

    // FIND with Criteria
    public List<Product> findCheapElectronics(BigDecimal maxPrice) {
        Query query = new Query(
            Criteria.where("category.name").is("Electronics")
                    .and("price").lt(maxPrice)
        );
        query.with(Sort.by("price").ascending());
        query.limit(20);
        return mongoTemplate.find(query, Product.class);
    }

    // UPDATE (partial)
    public void applyDiscount(String id, double discount) {
        Query query = new Query(Criteria.where("_id").is(id));
        Update update = new Update()
            .multiply("price", 1 - discount)
            .set("discounted", true)
            .currentDate("updatedAt");
        mongoTemplate.updateFirst(query, update, Product.class);
    }

    // UPSERT
    public void upsertStock(String sku, int quantity) {
        Query query = new Query(Criteria.where("sku").is(sku));
        Update update = new Update().set("stock", quantity);
        mongoTemplate.upsert(query, update, Product.class);
    }

    // DELETE
    public void delete(String id) {
        mongoTemplate.remove(
            new Query(Criteria.where("_id").is(id)), Product.class);
    }
}

// Total revenue per category
Aggregation agg = Aggregation.newAggregation(
    Aggregation.match(Criteria.where("status").is("COMPLETED")),
    Aggregation.group("category")
        .sum("total").as("revenue")
        .count().as("orderCount"),
    Aggregation.sort(Sort.by(Sort.Direction.DESC, "revenue")),
    Aggregation.limit(10)
);

AggregationResults<CategoryRevenue> results =
    mongoTemplate.aggregate(agg, "orders", CategoryRevenue.class);

List<CategoryRevenue> data = results.getMappedResults();

// Lookup (JOIN equivalent)
Aggregation withLookup = Aggregation.newAggregation(
    Aggregation.lookup("categories", "categoryId", "_id", "categoryDetails"),
    Aggregation.unwind("categoryDetails")
);

  8. TRANSACTIONS IN MONGODB
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Multi-document ACID transactions require:
  - MongoDB 4.0+ replica set (or 4.2+ sharded)

@Transactional works with MongoTransactionManager:

  @Bean
  public MongoTransactionManager txManager(MongoDatabaseFactory dbFactory) {
      return new MongoTransactionManager(dbFactory);
  }

  @Transactional
  public void transferFunds(String fromId, String toId, BigDecimal amount) {
      mongoTemplate.updateFirst(
          Query.query(Criteria.where("_id").is(fromId)),
          new Update().inc("balance", amount.negate()),
          Account.class);
      mongoTemplate.updateFirst(
          Query.query(Criteria.where("_id").is(toId)),
          new Update().inc("balance", amount),
          Account.class);
  }

Q: When would you choose MongoDB over a relational DB?
A: MongoDB suits: flexible/evolving schema, document-centric data
   (e.g., product catalogs with varying attributes), hierarchical
   data, high write throughput, and when horizontal scaling is needed.
   RDBMS suits: strict ACID requirements across many entities,
   complex relational queries, strong consistency needs.

Q: What is the difference between @DBRef and embedding in MongoDB?
A: Embedding stores related data inside the same document (one read,
   atomic updates). @DBRef stores a reference to another document
   (requires a second read to resolve). Prefer embedding for data
   always read together; use references for shared/independent data.

Q: What is MongoTemplate vs MongoRepository?
A: MongoRepository provides Spring Data derived queries and CRUD.
   MongoTemplate gives lower-level access to the full MongoDB driver
   API — aggregation pipelines, complex updates, bulk operations, index
   management. Both can be used together in the same application.

Q: How does TTL index work in MongoDB?
A: A TTL index on a Date field automatically deletes documents a
   specified number of seconds after the date value. Useful for
   session storage, OTP tokens, cache documents. In Spring:
   @Indexed(expireAfterSeconds = N) on a Date field.

Q: Does MongoDB support ACID transactions?
A: Yes, since MongoDB 4.0 (single replica set) and 4.2 (sharded
   clusters). However, they are more expensive than single-document
   operations. Prefer embedding related data to avoid multi-document
   transactions where possible.
