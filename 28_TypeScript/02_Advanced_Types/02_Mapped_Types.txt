1. WHAT ARE MAPPED TYPES?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Mapped types create a new type by ITERATING over the keys of an existing type
and transforming each key's value type. They use the `in` operator at the type
level to loop over a union of keys.

  type MappedType<T> = {
    [K in keyof T]: <transformed type>
  }

This is how TypeScript's built-in utility types (Partial, Readonly, Pick, etc.)
are implemented.

2. BASIC MAPPED TYPE SYNTAX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  type Source = { a: string; b: number; c: boolean };

  // Map each property to a new type:
  type Stringified<T> = {
    [K in keyof T]: string;  // all values become string
  };
  type StringifiedSource = Stringified<Source>;
  // { a: string; b: string; c: string }

  // Preserve original types (identity mapped type):
  type Copy<T> = {
    [K in keyof T]: T[K];  // same as T
  };

  // Wrap each value in an array:
  type Arrayed<T> = {
    [K in keyof T]: T[K][];
  };
  type ArrayedSource = Arrayed<Source>;
  // { a: string[]; b: number[]; c: boolean[] }

3. PROPERTY MODIFIERS IN MAPPED TYPES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Add/remove `readonly` and `?` (optional) using + and - prefixes.

  // Add optional (?):
  type Partial<T> = { [K in keyof T]?: T[K] };
  // Equivalent to: [K in keyof T]+?: T[K]

  // Remove optional (-?):
  type Required<T> = { [K in keyof T]-?: T[K] };

  // Add readonly:
  type Readonly<T> = { +readonly [K in keyof T]: T[K] };

  // Remove readonly (make mutable):
  type Mutable<T> = { -readonly [K in keyof T]: T[K] };

  type ReadonlyUser = { readonly id: number; readonly name: string };
  type MutableUser = Mutable<ReadonlyUser>;
  // { id: number; name: string } — readonly removed

  // Combine both modifiers:
  type ReadonlyPartial<T> = { +readonly [K in keyof T]+?: T[K] };
  type MutableRequired<T> = { -readonly [K in keyof T]-?: T[K] };

4. KEY REMAPPING WITH `as` CLAUSE (TypeScript 4.1+)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  The `as` clause in a mapped type lets you RENAME or FILTER keys.

  Syntax: [K in keyof T as <new key type>]: T[K]

  a) Rename keys with template literals:
     ────────────────────────────────────
     type Getters<T> = {
       [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
     };

     type Setters<T> = {
       [K in keyof T as `set${Capitalize<string & K>}`]: (val: T[K]) => void;
     };

     type User = { name: string; age: number };
     type UserGetters = Getters<User>;
     // { getName: () => string; getAge: () => number }

     type UserSetters = Setters<User>;
     // { setName: (val: string) => void; setAge: (val: number) => void }

  b) Filter keys (map to never to exclude):
     ─────────────────────────────────────────
     // Only keep string-valued properties:
     type StringProps<T> = {
       [K in keyof T as T[K] extends string ? K : never]: string;
     };

     type User = { id: number; name: string; active: boolean; email: string };
     type StringUserProps = StringProps<User>;
     // { name: string; email: string }

     // Exclude keys starting with underscore:
     type PublicProps<T> = {
       [K in keyof T as K extends `_${string}` ? never : K]: T[K];
     };

  c) Extract keys by type:
     ──────────────────────
     type FilterByValueType<T, ValueType> = {
       [K in keyof T as T[K] extends ValueType ? K : never]: T[K];
     };

     type User = { id: number; name: string; admin: boolean; role: string };
     type StringFields = FilterByValueType<User, string>;
     // { name: string; role: string }

5. MAPPING OVER SPECIFIC KEY UNIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  You're not limited to `keyof T` — you can map over any union:

  type EventHandlers = {
    [K in "click" | "focus" | "blur"]: (event: Event) => void;
  };
  // { click: (event: Event) => void; focus: ...; blur: ... }

  type BooleanRecord<K extends string> = {
    [P in K]: boolean;
  };
  type Flags = BooleanRecord<"isActive" | "isAdmin" | "isVerified">;
  // { isActive: boolean; isAdmin: boolean; isVerified: boolean }

  // Record<K, V> is essentially:
  type Record<K extends keyof any, V> = { [P in K]: V };

6. HOMOMORPHIC MAPPED TYPES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  A HOMOMORPHIC mapped type iterates over `keyof T` (directly over a type param)
  and PRESERVES the modifiers (optional/readonly) of the original type.

  type Partial<T> = { [K in keyof T]?: T[K] };      // homomorphic
  type Readonly<T> = { readonly [K in keyof T]: T[K] }; // homomorphic

  NON-HOMOMORPHIC mapped types iterate over a different union (not keyof T directly)
  and do NOT preserve modifiers:

  type Record<K extends string, V> = { [P in K]: V }; // NOT homomorphic

  Example of preserved modifiers (homomorphic):
  interface A {
    readonly x: number;
    y?: string;
  }

  type P = Partial<A>;
  // { readonly x?: number; y?: string }
  // readonly preserved on x, optional added to both

7. PRACTICAL MAPPED TYPE RECIPES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

a) Nullable — all properties can be null:
   type Nullable<T> = { [K in keyof T]: T[K] | null };

b) Functions (all values become functions returning that type):
   type Lazy<T> = { [K in keyof T]: () => T[K] };
   type LazyUser = Lazy<User>; // { id: () => number; name: () => string; ... }

c) Promises (all values become promises):
   type Promised<T> = { [K in keyof T]: Promise<T[K]> };

d) Validation schema (all values become validator functions):
   type Schema<T> = { [K in keyof T]: (val: unknown) => val is T[K] };

e) DeepReadonly:
   type DeepReadonly<T> = {
     readonly [K in keyof T]: T[K] extends Record<string, unknown>
       ? DeepReadonly<T[K]>
       : T[K];
   };

f) DeepPartial:
   type DeepPartial<T> = {
     [K in keyof T]?: T[K] extends object ? DeepPartial<T[K]> : T[K];
   };

g) PartialBy — make only specified keys optional:
   type PartialBy<T, K extends keyof T> =
     Omit<T, K> & Partial<Pick<T, K>>;

h) RequiredBy — make only specified keys required:
   type RequiredBy<T, K extends keyof T> =
     Omit<T, K> & Required<Pick<T, K>>;

i) Flatten nested object to event strings (advanced):
   type FlattenPaths<T, Prefix extends string = ""> = {
     [K in keyof T]: K extends string
       ? T[K] extends object
         ? FlattenPaths<T[K], `${Prefix}${K}.`>
         : `${Prefix}${K}`
       : never;
   }[keyof T];

8. MAPPED TYPES WITH CONDITIONAL TYPES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Combining mapped types with conditional types creates very powerful tools:

  // Wrap in Promise only if not already a Promise:
  type Promisify<T> = {
    [K in keyof T]: T[K] extends Promise<any> ? T[K] : Promise<T[K]>;
  };

  // Make array properties readonly:
  type ReadonlyArrays<T> = {
    [K in keyof T]: T[K] extends any[] ? Readonly<T[K]> : T[K];
  };

  // Mark all function properties as optional:
  type OptionalMethods<T> = {
    [K in keyof T]: T[K] extends Function ? T[K] | undefined : T[K];
  };

  // Transform object — replace function values with their return types:
  type ReturnValues<T> = {
    [K in keyof T]: T[K] extends (...args: any[]) => infer R ? R : T[K];
  };

9. COMMON INTERVIEW QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: What is a mapped type in TypeScript?
    A mapped type creates a new type by iterating over the keys of an existing
    type and transforming each key's type. It uses [K in keyof T] syntax.
    All built-in utility types like Partial, Readonly, and Pick are implemented
    as mapped types.

Q2: How do you implement Readonly<T> as a mapped type?
    type Readonly<T> = { readonly [K in keyof T]: T[K] };
    The `readonly` modifier is added to every property.

Q3: How do you implement Partial<T> as a mapped type?
    type Partial<T> = { [K in keyof T]?: T[K] };
    The `?` makes every property optional. Equivalent to [K in keyof T]+?:

Q4: What is the difference between +? and -? in mapped types?
    +? adds the optional modifier (same as ?)
    -? removes the optional modifier (makes required)
    type Required<T> = { [K in keyof T]-?: T[K] }; // removes ? from all props

Q5: What is key remapping with `as` in mapped types?
    The `as` clause allows renaming or filtering keys in a mapped type:
    [K in keyof T as `get${Capitalize<string & K>}`] renames each key K
    to `getK`. Mapping to `never` removes the key from the output.

Q6: What is a homomorphic mapped type?
    A mapped type that iterates directly over `keyof T` (not a computed union)
    and preserves the original optional/readonly modifiers from T.
    Partial<T> and Readonly<T> are homomorphic. Record<K, V> is not.

Q7: How do you filter properties of a type using mapped types?
    Map the key to `never` to exclude it:
    type StringOnly<T> = { [K in keyof T as T[K] extends string ? K : never]: T[K] }
    Properties where T[K] doesn't extend string are excluded (mapped to never).

Q8: How would you create a "Mutable" utility type that removes readonly?
    type Mutable<T> = { -readonly [K in keyof T]: T[K] };
    The -readonly removes the readonly modifier from all properties.

Q9: Can you use mapped types with non-object types?
    Mapped types work best with object types. You can map over union of string
    literals too: [K in "a" | "b" | "c"]: number creates { a: number; b: number; c: number }
    For primitives, mappings typically produce empty objects or `never`.

Q10: How do you create a deep (recursive) version of Partial<T>?
     type DeepPartial<T> = {
       [K in keyof T]?: T[K] extends object ? DeepPartial<T[K]> : T[K];
     };
     This recursively makes ALL nested object properties optional too.
