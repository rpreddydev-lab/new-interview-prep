================================================================================
EVALUATING JOB OFFERS: A COMPLETE FRAMEWORK
================================================================================
Purpose: Receiving an offer is only the beginning. The decision of whether
         to accept, negotiate, or decline has enormous long-term financial and
         career consequences. This guide gives you a rigorous framework.
================================================================================

--------------------------------------------------------------------------------
1. TOTAL COMPENSATION (TC): UNDERSTANDING THE FULL PICTURE
--------------------------------------------------------------------------------

Most engineers focus only on base salary. This is a mistake. TC has multiple
components and they must all be evaluated together.

TC COMPONENTS:
  1. BASE SALARY
     - Guaranteed annual cash; paid biweekly or semi-monthly
     - Most straightforward component

  2. SIGNING BONUS
     - One-time cash payment; often paid in first paycheck
     - Usually has a CLAWBACK clause: if you leave within 1-2 years, repay it
     - Read the clawback terms carefully
     - Not part of "annualized" TC; divide by vesting period for comparison

  3. ANNUAL BONUS
     - Discretionary (0-100%+ of target); target percentage varies by level
     - Performance-based: individual performance × company performance
     - IC3/junior: 5-10% target; senior: 10-15%; staff/principal: 15-25%+
     - Not guaranteed; don't rely on it for fixed expenses

  4. EQUITY (RSUs / Stock Options)
     RSUs (Restricted Stock Units):
       - Company stock granted to you; vests over time
       - Typical FAANG vesting: 4-year vest, 1-year cliff
         (0% at month 11, 25% at month 12, then monthly/quarterly after)
       - At vest, RSUs are treated as ordinary income (taxed immediately)
       - VALUE = (number of shares × current stock price) at vest date
       - Refreshes: top performers get new RSU grants annually

     Stock Options (ISO/NSO):
       - Right to buy shares at a fixed "strike price"
       - Value = current stock price − strike price (intrinsic value)
       - Common at pre-IPO startups; can be worth 0 or life-changing
       - 90-day exercise window after leaving: a critical detail to understand

  5. BENEFITS
     - Health, dental, vision (premium: how much does employer cover?)
     - 401(k) match (free money: max this out first)
     - HSA/FSA contribution
     - Life/disability insurance
     - Parental leave (weeks paid at what percentage?)
     - Education budget, learning stipend
     - Home office allowance, internet stipend (WFH companies)
     - Gym membership, commuter benefits

TC CALCULATION:
  Annual TC = Base + (Signing Bonus / years of clawback) + Annual Bonus (target) + (Total Equity / vesting years)

  Example:
    Base:          $180,000
    Signing:       $30,000 (1-year clawback) → $30,000/year for year 1
    Target bonus:  15% → $27,000
    RSUs:          $400,000 total, 4-year vest → $100,000/year
    Year 1 TC:     $180,000 + $30,000 + $27,000 + $100,000 = $337,000
    Year 2-4 TC:   $180,000 + $27,000 + $100,000 = $307,000

2. BEYOND THE NUMBERS: QUALITATIVE FACTORS
--------------------------------------------------------------------------------

Rate each of the following from 1-5 for the offer you're evaluating:

ROLE AND GROWTH:
  [ ] Is the scope of work interesting and challenging? (1-5)
  [ ] Does this role build skills in the direction I want to grow? (1-5)
  [ ] Is there a clear promotion path and how long does it typically take? (1-5)
  [ ] Will I be working on problems I'm proud of? (1-5)

TEAM AND CULTURE:
  [ ] Did I like the people I met in interviews? (1-5)
  [ ] Does the manager seem invested in their reports' growth? (1-5)
  [ ] Is the culture collaborative or high-blame? (1-5)
  [ ] Do Glassdoor reviews paint a consistent picture? (1-5)

COMPANY HEALTH AND STABILITY:
  [ ] Is the company financially healthy? (profitable/funded runway)
  [ ] Is the equity potentially valuable? (growth trajectory)
  [ ] Are layoffs a near-term risk? (check recent news/Blind)
  [ ] Is the product/market fit strong? (1-5)

WORK-LIFE BALANCE:
  [ ] What are the expected working hours? (ask directly)
  [ ] On-call requirements and frequency?
  [ ] Remote/hybrid/in-office policy and your preference alignment?
  [ ] Travel requirements?

CAREER SIGNALING:
  [ ] Does this company name on your resume open future doors? (brand value)
  [ ] Does this role put you closer to your 5-year goal?

TOTAL SCORE: ___/100

Combine with TC to make a holistic decision.

3. OFFER COMPARISON FRAMEWORK
--------------------------------------------------------------------------------

When comparing multiple offers, use this matrix:

  | FACTOR                    | OFFER A       | OFFER B       | OFFER C       |
  |---------------------------|---------------|---------------|---------------|
  | Base Salary               |               |               |               |
  | Annual Bonus (target)     |               |               |               |
  | Signing Bonus             |               |               |               |
  | Equity (annualized)       |               |               |               |
  | Year 1 Total TC           |               |               |               |
  | Year 2-4 Total TC (avg)   |               |               |               |
  | COLA-adjusted TC*         |               |               |               |
  | Role/Growth Score (1-5)   |               |               |               |
  | Team/Culture Score (1-5)  |               |               |               |
  | WLB Score (1-5)           |               |               |               |
  | Company Stability (1-5)   |               |               |               |
  | Career Signal Score (1-5) |               |               |               |
  | QUALITATIVE TOTAL (/25)   |               |               |               |

*COLA (Cost of Living Adjustment): San Francisco and New York TC must be adjusted
for higher cost of living. Use a COL index (Numbeo, NerdWallet) to compare.
$250K in LCOL city can have higher purchasing power than $350K in SF.

Rule of thumb: don't sacrifice more than 10-15% TC for qualitative factors UNLESS
the non-TC benefits are exceptional (equity at a pre-IPO rocket ship, dream role, etc.)

--------------------------------------------------------------------------------
4. UNDERSTANDING YOUR OFFER LETTER
--------------------------------------------------------------------------------

WHAT TO READ CAREFULLY:
  - Effective date and start date (note any gap)
  - At-will employment language (standard in the US)
  - Non-compete clause: Are you prohibited from working at competitors?
    (These are often unenforceable in California but enforced in other states)
  - Non-solicitation clause: Cannot recruit current employees after leaving
  - IP assignment: Everything you build (even on personal time?) belongs to company?
    If you have side projects, request a carveout in writing
  - Equity grant details: number of shares, exercise price, vesting schedule, cliff
  - Clawback terms on signing bonus
  - Arbitration clause: disputes resolved in arbitration, not court

RED FLAGS IN OFFER LETTERS:
  - Very broad IP assignment with no carveout
  - Non-compete that covers a wide geography and long duration
  - Equity vesting with no acceleration on acquisition (double trigger is standard)
  - "Employment at will" paired with a long clawback period on signing bonus

--------------------------------------------------------------------------------
5. QUESTIONS TO ASK BEFORE ACCEPTING
--------------------------------------------------------------------------------

ASK YOUR RECRUITER:
  "What is the typical equity refresh policy for strong performers?"
  "What has been the trajectory of the stock price / 409A valuation?"
  "How is the annual bonus determined? What percentage of engineers hit target?"
  "What is the standard promotion timeline for this level?"
  "Can you clarify the non-compete scope in the offer letter?"
  "Is the signing bonus subject to a clawback? For how long?"

ASK YOUR FUTURE MANAGER (if you have a call):
  "What are the top two priorities for this role in the first 90 days?"
  "How does the team approach on-call rotations?"
  "What does a typical week look like for someone in this role?"
  "What's the biggest challenge the team is facing right now?"
  "How do you typically give feedback and support career growth?"

6. EVALUATING STARTUP EQUITY
--------------------------------------------------------------------------------

Startup equity is complex. Most engineers undervalue or overvalue it.

KEY NUMBERS TO GET:
  - How many shares are you being granted?
  - What is the current preferred share price (409A valuation)?
  - How many total shares are outstanding (fully diluted)?
  - What is your ownership percentage? (your shares / total shares)
  - What is the current valuation of the company?
  - What is the most recent round size and post-money valuation?
  - What liquidation preference do the preferred investors have?

HOW TO ESTIMATE VALUE:
  Option value = (exit price per share − strike price) × number of options
  Ownership = your shares / total diluted shares × 100%
  Your cut of exit = ownership % × exit valuation − liquidation preference

  EXAMPLE:
    You are granted 50,000 options at a $2 strike price.
    Company has 10M fully diluted shares.
    Ownership: 50,000 / 10,000,000 = 0.5%
    If company exits at $1B: 0.5% × $1B = $5M
    Minus strike: 50,000 × $2 = $100,000
    Pre-tax gain ≈ $5M − $100K = $4.9M

  BUT: liquidation preferences can eat into your share.
  If investors have 2× preference: $200M+ exit before common shareholders (you) see anything.

STARTUP RISK ADJUSTMENT:
  Most startups fail or exit for less than last valuation.
  Apply a discount: 25-50% for Series A/B; 50-75% for pre-seed/seed.
  Don't count on startup equity for planning; treat it as a lottery ticket.
