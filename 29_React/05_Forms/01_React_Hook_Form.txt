1. WHY REACT HOOK FORM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problems with manually-written controlled forms:
  - One state variable and onChange per input
  - Manual validation logic scattered through the component
  - Re-renders on every keystroke even for large forms
  - Boilerplate increases with form size

React Hook Form (RHF) solves this:
  - Minimal re-renders (uses uncontrolled inputs internally with refs)
  - Built-in validation (required, min, max, pattern, validate)
  - Integrates with Yup, Zod, and other schema validators
  - TypeScript-first
  - ~10KB gzipped

  Install:
    npm install react-hook-form

2. useForm — CORE API
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  import { useForm } from 'react-hook-form';

  function LoginForm() {
    const {
      register,        // connect input to RHF
      handleSubmit,    // wraps submit, prevents default, validates first
      formState: { errors, isSubmitting, isDirty, isValid },
      watch,           // watch field values reactively
      reset,           // reset form to defaults
      setValue,        // programmatically set a field's value
      getValues,       // read field values imperatively
    } = useForm({
      defaultValues: { email: '', password: '' },
      mode: 'onBlur',    // when to validate: onChange | onBlur | onSubmit (default) | all
    });

    const onSubmit = async (data) => {
      // data = { email: '...', password: '...' }
      await loginUser(data);
    };

    return (
      <form onSubmit={handleSubmit(onSubmit)}>

        <input
          type="email"
          {...register('email', {
            required: 'Email is required',
            pattern: { value: /\S+@\S+\.\S+/, message: 'Invalid email' },
          })}
        />
        {errors.email && <span>{errors.email.message}</span>}

        <input
          type="password"
          {...register('password', {
            required: 'Password is required',
            minLength: { value: 8, message: 'Min 8 characters' },
          })}
        />
        {errors.password && <span>{errors.password.message}</span>}

        <button type="submit" disabled={isSubmitting}>
          {isSubmitting ? 'Logging in...' : 'Login'}
        </button>
      </form>
    );
  }

  register() spreads: { name, ref, onChange, onBlur }
  These connect the input element to RHF's internal uncontrolled tracking.

3. VALIDATION RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  register('fieldName', {
    required: 'This field is required',              // boolean or string (error message)
    minLength: { value: 3, message: 'Too short' },
    maxLength: { value: 50, message: 'Too long' },
    min: { value: 0, message: 'Must be positive' },   // for number inputs
    max: { value: 100, message: 'Must be ≤ 100' },
    pattern: { value: /^\d+$/, message: 'Numbers only' },
    validate: (value) => value !== 'admin' || 'Username "admin" not allowed',
    // OR multiple validators:
    validate: {
      notEmpty: (v) => v.trim().length > 0 || 'Cannot be whitespace',
      noSpaces: (v) => !v.includes(' ') || 'No spaces allowed',
    },
  })

a DOM ref. Use <Controller> to wrap them.

  import ReactSelect from 'react-select';

    name="country"
    control={control}          // from useForm()

6. SCHEMA VALIDATION WITH ZOD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  npm install zod @hookform/resolvers

  import { z } from 'zod';
  import { zodResolver } from '@hookform/resolvers/zod';

  const schema = z.object({
    email: z.string().email('Invalid email').min(1, 'Required'),
    password: z.string().min(8, 'Min 8 characters'),
    age: z.number({ invalid_type_error: 'Must be a number' }).min(18, 'Must be 18+'),
  });

  const { register, handleSubmit, formState: { errors } } = useForm({
    resolver: zodResolver(schema),
    defaultValues: { email: '', password: '', age: undefined },
  });

  // errors.email.message, errors.password.message come from Zod schema

7. PERFORMANCE: WHY RHF IS FAST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Traditional controlled form: Re-renders the entire form on every keystroke.
  React Hook Form: Stores values in refs (not state). No re-renders while typing.
  Re-renders only happen when:
  - Validation errors change
  - Form submission starts/ends
  - You explicitly call watch() on a field (subscribes to that field's updates)

8. COMMON INTERVIEW QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Why is React Hook Form more performant than manual controlled forms?
A: RHF uses uncontrolled inputs (refs) internally. Values are stored in refs,
   not state, so typing doesn't trigger re-renders. Only validation errors and
   form state (isSubmitting, etc.) cause re-renders, not every keystroke.

Q: What does register() do?
A: It returns { name, ref, onChange, onBlur } spread onto an input. This
   connects the input element to React Hook Form's tracking system without
   making it a controlled input.

Q: When would you use Controller instead of register?
A: When using third-party input components that don't expose a DOM ref (like
   react-select, DatePicker, MUI components). Controller wraps them and
   provides value/onChange in a controlled manner.

Q: What is the mode option in useForm?
A: It controls when validation runs: onSubmit (default), onChange (on every
   keystroke), onBlur (when input loses focus), all (both onChange and onBlur).
   Use onBlur for the best balance of UX and performance.

Q: How do you integrate Zod or Yup with React Hook Form?
A: Install the @hookform/resolvers package. Pass zodResolver(schema) or
   yupResolver(schema) as the resolver option to useForm(). Validation
   messages from the schema appear in formState.errors.
