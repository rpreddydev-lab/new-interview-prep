PATTERN SELECTION QUICK GUIDE
------------------------------
Problem clue                             → Pattern / File
-----------------------------------------|-----------------------------
"top N per group"                        → ROW_NUMBER + CTE          (01)
"rank / nth highest salary"              → DENSE_RANK / subquery      (01, 06)
"running total / cumulative"             → SUM() OVER (ORDER BY)      (01, 02)
"compare row to previous/next row"       → LAG / LEAD                 (01, 02)
"find duplicates"                        → GROUP BY + HAVING COUNT > 1(01)
"delete duplicates, keep one"            → ROW_NUMBER + DELETE CTE    (01, 06)
"employees with no manager / no orders"  → LEFT JOIN + IS NULL        (01)
"department with max/min salary"         → GROUP BY + subquery / RANK (01)
"consecutive rows / sequences / streak"  → id - ROW_NUMBER island     (01, 06)
"pivot / transpose rows to columns"      → CASE + GROUP BY            (01)
"hierarchical / org chart"               → Recursive CTE              (01)
"percentage / ratio within group"        → SUM() OVER (PARTITION BY)  (02)
"orders this month / last 30 days"       → Date range filter          (04)
"month-over-month / year-over-year"      → LAG or self-JOIN on period  (04)
"missing dates / gaps in sequence"       → Calendar CTE + LEFT JOIN   (04)
"NULL salary / missing data"             → COALESCE / IS NULL         (05)
"divide by zero risk"                    → NULLIF(denom, 0)           (05)
"NOT IN with possible NULLs"             → NOT EXISTS instead         (05)
"3+ consecutive rows above threshold"    → id - ROW_NUMBER island     (06)
"cancellation / completion rate"         → CASE WHEN + SUM/COUNT      (06)
