================================================================
  WINDOW FUNCTIONS: OVERVIEW
================================================================

  Window functions compute a value for each row based on a set
  of related rows (the "window") WITHOUT collapsing them into groups.

  Unlike GROUP BY (which reduces rows), window functions return
  the SAME number of rows as the input, with an extra computed column.

================================================================
SYNTAX
================================================================

  function_name(args) OVER (
      [PARTITION BY partition_cols]
      [ORDER BY order_cols [ASC|DESC]]
      [ROWS|RANGE BETWEEN frame_start AND frame_end]
  )

  PARTITION BY: like GROUP BY, but for window (no row reduction)
  ORDER BY:     order within each partition (required for ranking/lag/lead)
  FRAME:        defines which rows are in the "window" for each row

================================================================
WINDOW FUNCTION CATEGORIES
================================================================

  Category           Functions
  -----------------  ---------------------------------------------------
  Ranking            ROW_NUMBER, RANK, DENSE_RANK, NTILE
  Value              LAG, LEAD, FIRST_VALUE, LAST_VALUE, NTH_VALUE
  Aggregate          SUM, AVG, COUNT, MIN, MAX (used with OVER)
  Statistical        PERCENT_RANK, CUME_DIST

================================================================
AGGREGATE vs WINDOW FUNCTION
================================================================

  Aggregate (collapses rows):
  SELECT department_id, AVG(salary) AS avg_sal
  FROM employees
  GROUP BY department_id;
  -- Returns one row per department

  Window (keeps all rows, adds computed column):
  SELECT name, salary, department_id,
         AVG(salary) OVER (PARTITION BY department_id) AS dept_avg
  FROM employees;
  -- Returns all employees + dept average on each row
  -- Enables: salary > dept_avg comparison per row

================================================================
WINDOW FRAME
================================================================

  Default frame for ORDER BY functions: RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
  Useful for running totals.

  Explicit frames:
  ROWS BETWEEN 2 PRECEDING AND CURRENT ROW     -- 3-row sliding window
  ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW  -- running total
  ROWS BETWEEN CURRENT ROW AND UNBOUNDED FOLLOWING  -- running from current
  ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING     -- centered 3-row moving avg

  ROWS: physical row count
  RANGE: logical range of values (can include ties)

================================================================
INTERVIEW FREQUENCY
================================================================

  Function             Frequency
  -------------------  ---------
  ROW_NUMBER           Very High
  RANK / DENSE_RANK    Very High
  LAG / LEAD           High
  SUM OVER             High
  PARTITION BY         Very High
  FIRST_VALUE          Medium
  NTILE                Low
