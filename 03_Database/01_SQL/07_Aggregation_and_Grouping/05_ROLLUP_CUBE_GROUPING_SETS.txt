================================================================
  ROLLUP, CUBE, GROUPING SETS
================================================================

  These are extensions to GROUP BY for generating subtotals
  and cross-tabulation in a single query.

================================================================
GROUPING SETS
================================================================

  Generates multiple GROUP BY results combined in one query:
  GROUP BY GROUPING SETS ((col1, col2), (col1), ())

  SELECT region, product, SUM(sales)
  FROM orders
  GROUP BY GROUPING SETS (
      (region, product),   -- subtotal per region+product
      (region),            -- subtotal per region
      ()                   -- grand total (empty group = all rows)
  );

  Equivalent to UNION ALL of three separate GROUP BY queries,
  but more efficient (one pass over data).

================================================================
ROLLUP
================================================================

  Generates subtotals hierarchically from left to right:
  GROUP BY ROLLUP(col1, col2, col3)
  is equivalent to GROUPING SETS: (col1,col2,col3), (col1,col2), (col1), ()

  SELECT
      EXTRACT(YEAR  FROM date) AS year,
      EXTRACT(MONTH FROM date) AS month,
      SUM(revenue)             AS total_revenue
  FROM daily_sales
  GROUP BY ROLLUP(
      EXTRACT(YEAR FROM date),
      EXTRACT(MONTH FROM date)
  );

  Result rows:
  year  month  total_revenue
  2024  1      12000         -- monthly total Jan 2024
  2024  2      15000         -- monthly total Feb 2024
  2024  NULL   27000         -- yearly total 2024  (month rolled up)
  NULL  NULL   27000         -- grand total (year rolled up)

================================================================
CUBE
================================================================

  Generates ALL possible grouping combinations:
  GROUP BY CUBE(col1, col2)
  is equivalent to GROUPING SETS: (col1,col2), (col1), (col2), ()

  SELECT region, product, SUM(sales)
  FROM orders
  GROUP BY CUBE(region, product);

  Useful for full cross-tabulation / pivot analysis.
  Number of grouping sets = 2^n (for n columns in CUBE).

================================================================
IDENTIFYING SUBTOTAL ROWS WITH GROUPING()
================================================================

  Subtotal rows have NULL in rolled-up columns.
  But real NULL values in data also show as NULL.
  Use GROUPING(col) to distinguish:
  Returns 1 if the NULL is from ROLLUP/CUBE; 0 if real NULL.

  SELECT
      CASE GROUPING(region) WHEN 1 THEN 'ALL REGIONS' ELSE region END AS region,
      CASE GROUPING(product) WHEN 1 THEN 'ALL PRODUCTS' ELSE product END AS product,
      SUM(sales) AS total_sales
  FROM orders
  GROUP BY ROLLUP(region, product);

================================================================
PRACTICAL USE: SALES REPORT DASHBOARD
================================================================

  WITH regional_report AS (
      SELECT
          region,
          category,
          SUM(amount) AS revenue,
          GROUPING(region)   AS region_total_flag,
          GROUPING(category) AS category_total_flag
      FROM sales
      GROUP BY ROLLUP(region, category)
  )
  SELECT
      CASE region_total_flag WHEN 1 THEN 'Grand Total' ELSE region END,
      CASE category_total_flag WHEN 1 THEN 'Subtotal' ELSE category END,
      revenue
  FROM regional_report
  ORDER BY region, category;

================================================================
INTERVIEW Q&A
================================================================

  Q: What does ROLLUP do?
  A: Generates hierarchical subtotals. For GROUP BY ROLLUP(a,b,c),
     it produces groupings at (a,b,c), (a,b), (a), and () grand total.

  Q: What is the difference between ROLLUP and CUBE?
  A: ROLLUP generates subtotals along one hierarchy (left to right).
     CUBE generates ALL combinations of groupings (2^n sets).

  Q: How do you distinguish ROLLUP NULLs from real NULLs?
  A: Use the GROUPING(col) function. Returns 1 if NULL was produced
     by ROLLUP/CUBE (a subtotal row), 0 if it is a real NULL value.
