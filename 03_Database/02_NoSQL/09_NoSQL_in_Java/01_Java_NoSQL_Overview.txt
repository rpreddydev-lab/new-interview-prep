================================================================
SPRING DATA ECOSYSTEM
================================================================

  Spring Data provides a consistent programming model across different
  data stores. Each NoSQL database has a Spring Data module:

  Module                     | Database
  ---------------------------|---------------------------
  spring-data-mongodb        | MongoDB
  spring-data-redis          | Redis
  spring-data-cassandra      | Apache Cassandra
  spring-data-elasticsearch  | Elasticsearch
  spring-data-neo4j          | Neo4j

  Common patterns across all modules:
  - Repository interface extending CrudRepository / ListCrudRepository
  - @Document / @Table / @Node / @RedisHash annotation on entity
  - Derived query methods: findByEmailAndStatus(String, String)
  - Custom @Query annotation for native queries
  - ReactiveRepository variants for reactive streams

COMMON REPOSITORY PATTERNS
================================================================

  public interface ProductRepository extends MongoRepository<Product, String> {
      List<Product> findByCategory(String category);
      List<Product> findByPriceBetween(double min, double max);
      Optional<Product> findBySkuCode(String skuCode);
      @Query("{ 'price': { $lt: ?0 }, 'category': ?1 }")
      List<Product> findCheapByCategory(double maxPrice, String category);
  }

  Derived query method naming:
  findBy[Field][Condition] : findByNameStartingWith, findByStatusIn
  countBy / deleteBy / existsBy
  Top/First: findTop5ByOrderByPriceAsc
  Distinct: findDistinctByCategory
