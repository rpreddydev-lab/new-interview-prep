================================================================
  CASE EXPRESSION
================================================================

  CASE is SQL's conditional expression — like if/else in a query.
  Can be used in SELECT, WHERE, ORDER BY, HAVING, and UPDATE.

================================================================
TWO FORMS
================================================================

  SEARCHED CASE (most flexible — any condition):
  CASE
      WHEN condition1 THEN result1
      WHEN condition2 THEN result2
      ...
      ELSE default_result
  END

  SIMPLE CASE (equality matching on one expression):
  CASE expression
      WHEN value1 THEN result1
      WHEN value2 THEN result2
      ...
      ELSE default_result
  END

================================================================
CASE IN SELECT
================================================================

  Category labels:
  SELECT
      id,
      total,
      CASE
          WHEN total >= 1000 THEN 'HIGH VALUE'
          WHEN total >= 500  THEN 'MEDIUM VALUE'
          WHEN total >= 100  THEN 'LOW VALUE'
          ELSE 'MICRO'
      END AS order_tier
  FROM orders;

  Simple form:
  SELECT
      id,
      status,
      CASE status
          WHEN 'PENDING'   THEN 'Waiting for confirmation'
          WHEN 'CONFIRMED' THEN 'Order confirmed'
          WHEN 'SHIPPED'   THEN 'On the way'
          WHEN 'DELIVERED' THEN 'Delivered'
          ELSE 'Unknown status'
      END AS status_description
  FROM orders;

================================================================
CASE IN AGGREGATION — CONDITIONAL AGGREGATION
================================================================

  One of the most powerful uses: pivot-like aggregation.

  Count orders by status in a single row:
  SELECT
      COUNT(*)                                           AS total_orders,
      COUNT(CASE WHEN status = 'PENDING'   THEN 1 END)  AS pending_count,
      COUNT(CASE WHEN status = 'SHIPPED'   THEN 1 END)  AS shipped_count,
      COUNT(CASE WHEN status = 'DELIVERED' THEN 1 END)  AS delivered_count,
      SUM(CASE WHEN status = 'DELIVERED' THEN total ELSE 0 END) AS delivered_revenue
  FROM orders;

  Equivalent with FILTER (PostgreSQL only, cleaner):
  COUNT(*) FILTER (WHERE status = 'PENDING') AS pending_count

  Monthly revenue pivot:
  SELECT
      EXTRACT(YEAR FROM created_at) AS year,
      SUM(CASE WHEN EXTRACT(MONTH FROM created_at) = 1 THEN total ELSE 0 END) AS jan,
      SUM(CASE WHEN EXTRACT(MONTH FROM created_at) = 2 THEN total ELSE 0 END) AS feb,
      SUM(CASE WHEN EXTRACT(MONTH FROM created_at) = 3 THEN total ELSE 0 END) AS mar
  FROM orders
  GROUP BY year;

================================================================
CASE IN ORDER BY
================================================================

  Custom sort order:
  SELECT * FROM orders
  ORDER BY
      CASE status
          WHEN 'URGENT'    THEN 1
          WHEN 'PENDING'   THEN 2
          WHEN 'CONFIRMED' THEN 3
          WHEN 'SHIPPED'   THEN 4
          ELSE 5
      END;

================================================================
CASE IN UPDATE
================================================================

  Conditional bulk update:
  UPDATE products
  SET price =
      CASE
          WHEN category_id = 1 THEN price * 1.10   -- 10% increase for cat 1
          WHEN category_id = 2 THEN price * 0.95   -- 5% decrease for cat 2
          ELSE price                                -- no change for others
      END
  WHERE category_id IN (1, 2);

================================================================
CASE IN WHERE
================================================================

  Rare but valid — dynamic filtering based on parameter:
  -- In a stored procedure or dynamic query:
  SELECT * FROM orders
  WHERE
      CASE :filter_type
          WHEN 'HIGH_VALUE' THEN total
          ELSE 0
      END >= 500;

================================================================
COALESCE AS SHORTHAND
================================================================

  COALESCE returns the first non-NULL value:
  COALESCE(col, 'default')   is equivalent to:
  CASE WHEN col IS NOT NULL THEN col ELSE 'default' END

  NULLIF(a, b) returns NULL if a = b, else a:
  NULLIF(discount, 0)   -- returns NULL if discount is 0

  Full coverage in 07_NULL_Handling_COALESCE_NULLIF.txt.

================================================================
INTERVIEW Q&A
================================================================

  Q: What is a CASE expression in SQL?
  A: A conditional expression (like if/else) that can be used in SELECT,
     ORDER BY, WHERE, HAVING, and UPDATE. Searched form uses WHEN conditions;
     simple form matches equality against one expression.

  Q: What is conditional aggregation?
  A: Using CASE inside aggregate functions (SUM, COUNT) to aggregate
     subsets of data in a single query. Avoids multiple subqueries.
     Example: COUNT(CASE WHEN status = 'SHIPPED' THEN 1 END)

  Q: Can CASE expressions be nested?
  A: Yes, but it gets hard to read. Prefer breaking into CTEs or views
     for complex nested conditions.

  Q: What is the ELSE clause for in CASE?
  A: The fallback if no WHEN matches. If ELSE is omitted and no WHEN matches,
     CASE returns NULL (not an error). Always include ELSE explicitly for clarity.
