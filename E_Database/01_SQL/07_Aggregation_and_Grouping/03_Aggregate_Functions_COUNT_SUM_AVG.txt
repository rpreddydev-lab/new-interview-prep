================================================================
  AGGREGATE FUNCTIONS: COUNT, SUM, AVG, MIN, MAX
================================================================

================================================================
COUNT
================================================================

  COUNT(*)        Count ALL rows (includes NULLs)
  COUNT(col)      Count non-NULL values in col
  COUNT(DISTINCT col)  Count distinct non-NULL values

  SELECT
      COUNT(*)            AS total_orders,
      COUNT(shipped_at)   AS shipped_count,    -- NULL shipped_at excluded
      COUNT(DISTINCT customer_id) AS unique_customers
  FROM orders;

  Trap: COUNT(*) = COUNT(id) when id is NOT NULL.
  But COUNT(nullable_col) < COUNT(*) when nulls exist.

================================================================
SUM
================================================================

  SUM(col) -- total of non-NULL values. Returns NULL if all NULLs.
  Use COALESCE to get 0 instead:
  COALESCE(SUM(col), 0)

  Total revenue by category:
  SELECT category_id, SUM(price * qty) AS revenue
  FROM order_items
  GROUP BY category_id;

  Conditional SUM:
  SUM(CASE WHEN status = 'DELIVERED' THEN total ELSE 0 END) AS delivered_total

================================================================
AVG
================================================================

  AVG(col) -- arithmetic mean, ignores NULLs.
  Denominator = count of non-NULL rows, not total rows.

  SELECT AVG(salary) FROM employees WHERE department_id = 3;

  Weighted average:
  SELECT SUM(price * qty) / NULLIF(SUM(qty), 0) AS weighted_avg_price
  FROM order_items;

  Trap: AVG(nullable_col) with many NULLs gives inflated result.
  AVG(COALESCE(rating, 0)) -- treat NULL as 0 for fair average.

================================================================
MIN / MAX
================================================================

  MIN / MAX work on numbers, strings (lexicographic), and dates.

  SELECT MIN(created_at), MAX(created_at) FROM orders;  -- date range
  SELECT MIN(name), MAX(name) FROM products;            -- alphabetical first/last

  Per group:
  SELECT department_id, MIN(salary), MAX(salary)
  FROM employees
  GROUP BY department_id;

================================================================
STRING AGGREGATION
================================================================

  PostgreSQL:
  SELECT department_id,
         STRING_AGG(name, ', ' ORDER BY name) AS members
  FROM employees
  GROUP BY department_id;

  MySQL:
  SELECT department_id,
         GROUP_CONCAT(name ORDER BY name SEPARATOR ', ') AS members
  FROM employees
  GROUP BY department_id;

================================================================
PERCENTILE (PostgreSQL)
================================================================

  -- Median salary per department:
  SELECT
      department_id,
      PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY salary) AS median_salary
  FROM employees
  GROUP BY department_id;

  PERCENTILE_DISC returns an actual value from the dataset.
  PERCENTILE_CONT interpolates between two values.

================================================================
NULL BEHAVIOR SUMMARY
================================================================

  Function    NULL rows   Returns if all NULL
  ---------   ----------  -------------------
  COUNT(col)  Excluded    0
  COUNT(*)    Included    (never 0 for non-empty table)
  SUM         Excluded    NULL
  AVG         Excluded    NULL
  MIN/MAX     Excluded    NULL
  STRING_AGG  Excluded    NULL

================================================================
INTERVIEW Q&A
================================================================

  Q: What is the difference between COUNT(*) and COUNT(col)?
  A: COUNT(*) counts all rows including those where col is NULL.
     COUNT(col) counts only rows where col is NOT NULL.

  Q: What does AVG return if all values are NULL?
  A: NULL. Use COALESCE(AVG(col), 0) to get 0 in that case.

  Q: How do you calculate a median in SQL?
  A: Standard SQL lacks a MEDIAN function. Use PERCENTILE_CONT(0.5)
     in PostgreSQL/SQL Server. MySQL requires subquery with ROW_NUMBER().

  Q: Can you use SUM on a result of a CASE expression?
  A: Yes. SUM(CASE WHEN condition THEN 1 ELSE 0 END) is conditional
     aggregation -- one of the most common SQL interview patterns.
