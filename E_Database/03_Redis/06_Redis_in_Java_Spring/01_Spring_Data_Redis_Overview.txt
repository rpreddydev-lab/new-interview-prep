SPRING DATA REDIS — OVERVIEW
================================================================================

1. WHAT IS SPRING DATA REDIS?
───────────────────────────────
  Spring Data Redis is the Spring framework module for integrating Redis.
  It provides:
    - Connection factories (Lettuce, Jedis)
    - RedisTemplate: low-level Redis access with serialization
    - Repository support: @RedisHash entities
    - @Cacheable integration via RedisCacheManager
    - Spring Session: HTTP session storage in Redis
    - Reactive support (ReactiveRedisTemplate)

  Libraries:
    Lettuce: default, async-capable, Netty-based, Cluster + Sentinel aware
    Jedis:   classic, synchronous, thread-safe via connection pool


2. MAVEN DEPENDENCIES
──────────────────────
  <!-- Spring Boot Redis Starter (includes Lettuce) -->
  <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
  </dependency>

  <!-- Optional: use Jedis instead of Lettuce -->
  <dependency>
    <groupId>redis.clients</groupId>
    <artifactId>jedis</artifactId>
  </dependency>
  <!-- Exclude Lettuce if using Jedis -->
  <exclusions>
    <exclusion>
      <groupId>io.lettuce</groupId>
      <artifactId>lettuce-core</artifactId>
    </exclusion>
  </exclusions>

  <!-- Redisson (for distributed locks, advanced patterns) -->
  <dependency>
    <groupId>org.redisson</groupId>
    <artifactId>redisson-spring-boot-starter</artifactId>
    <version>3.24.3</version>
  </dependency>


3. CONNECTION CONFIGURATION
─────────────────────────────
  Standalone (application.yml):
    spring:
      redis:
        host: localhost
        port: 6379
        password: secret
        database: 0
        timeout: 2000ms
        lettuce:
          pool:
            max-active: 8
            max-idle: 8
            min-idle: 0
            max-wait: -1ms

  Sentinel:
    spring:
      redis:
        sentinel:
          master: mymaster
          nodes:
            - sentinel1:26379
            - sentinel2:26379
            - sentinel3:26379
        password: secret

  Cluster:
    spring:
      redis:
        cluster:
          nodes:
            - node1:6379
            - node2:6379
            - node3:6379
          max-redirects: 3
        password: secret


4. JAVA CONFIGURATION CLASS
──────────────────────────────
  @Configuration
  public class RedisConfig {

      // Standalone
      @Bean
      public RedisConnectionFactory redisConnectionFactory() {
          RedisStandaloneConfiguration config =
              new RedisStandaloneConfiguration("localhost", 6379);
          config.setPassword(RedisPassword.of("secret"));
          return new LettuceConnectionFactory(config);
      }

      // Or: Sentinel
      @Bean
      public RedisConnectionFactory sentinelConnectionFactory() {
          RedisSentinelConfiguration sentinelConfig =
              new RedisSentinelConfiguration("mymaster",
                  Set.of("sentinel1:26379", "sentinel2:26379", "sentinel3:26379"));
          sentinelConfig.setPassword(RedisPassword.of("secret"));
          return new LettuceConnectionFactory(sentinelConfig);
      }

      // StringRedisTemplate (String keys + values)
      @Bean
      public StringRedisTemplate stringRedisTemplate(
              RedisConnectionFactory factory) {
          return new StringRedisTemplate(factory);
      }

      // RedisTemplate with JSON serialization
      @Bean
      public RedisTemplate<String, Object> redisTemplate(
              RedisConnectionFactory factory) {
          RedisTemplate<String, Object> template = new RedisTemplate<>();
          template.setConnectionFactory(factory);
          template.setKeySerializer(new StringRedisSerializer());
          template.setHashKeySerializer(new StringRedisSerializer());
          template.setValueSerializer(new GenericJackson2JsonRedisSerializer());
          template.setHashValueSerializer(new GenericJackson2JsonRedisSerializer());
          template.afterPropertiesSet();
          return template;
      }
  }


5. SERIALIZATION OPTIONS
──────────────────────────
  StringRedisSerializer      → key/value as plain UTF-8 strings
  GenericJackson2JsonRedisSerializer → serialize any object as JSON (includes type info)
  Jackson2JsonRedisSerializer<T>     → typed JSON (no type info in JSON, more compact)
  JdkSerializationRedisSerializer    → Java native serialization (NOT recommended: slow, bloated, version-sensitive)
  OxmSerializer                      → XML serialization (rare)
  ByteArrayRedisSerializer           → raw bytes

  Best practice:
    Keys: StringRedisSerializer (human-readable, debuggable in redis-cli)
    Values: GenericJackson2JsonRedisSerializer or Jackson2JsonRedisSerializer
    Avoid JdkSerializationRedisSerializer in production


6. REDIS OPERATIONS INTERFACES
────────────────────────────────
  RedisTemplate exposes typed operation objects:

  opsForValue()   → ValueOperations<K,V>         (Strings)
  opsForList()    → ListOperations<K,V>           (Lists)
  opsForSet()     → SetOperations<K,V>            (Sets)
  opsForZSet()    → ZSetOperations<K,V>           (Sorted Sets)
  opsForHash()    → HashOperations<K,HK,HV>       (Hashes)
  opsForGeo()     → GeoOperations<K,V>            (Geo)
  opsForHyperLogLog() → HyperLogLogOperations<K,V>
  opsForStream()  → StreamOperations<K,HK,HV>

  Bound operations (key-specific, avoid repeating key):
  boundValueOps(key)  → BoundValueOperations<K,V>
  boundListOps(key)   → BoundListOperations<K,V>
  etc.


7. INTERVIEW QUESTIONS & ANSWERS
──────────────────────────────────
  Q: What's the difference between RedisTemplate and StringRedisTemplate?
  A: StringRedisTemplate is a pre-configured RedisTemplate<String, String>
     with StringRedisSerializer for both keys and values. RedisTemplate<K, V>
     is generic — you configure serializers for different key/value types.
     Use StringRedisTemplate for simple String operations, RedisTemplate<String, Object>
     with JSON serializer for storing complex objects.

  Q: What serializer should you use for Redis values in Spring?
  A: GenericJackson2JsonRedisSerializer is the most common choice — serializes
     objects as JSON including type information, enabling deserialization without
     knowing the type upfront. Avoid JdkSerializationRedisSerializer (binary,
     Java version-sensitive, unreadable in redis-cli). Use StringRedisSerializer
     for keys always — human-readable and efficient.

  Q: What's the difference between Lettuce and Jedis?
  A: Lettuce is the default in Spring Boot 2.x+. It uses Netty (async I/O),
     supports reactive programming, and is thread-safe with a single connection
     shared across threads. Jedis is synchronous, one connection per thread
     (requires connection pool), simpler but more resource-intensive at scale.
     Both support Sentinel and Cluster. Lettuce is preferred for modern Spring apps.
