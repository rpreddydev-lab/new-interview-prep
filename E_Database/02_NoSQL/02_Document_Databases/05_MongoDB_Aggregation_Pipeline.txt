================================================================
  MONGODB AGGREGATION PIPELINE
================================================================

  The aggregation pipeline transforms documents through a series of stages.
  Each stage outputs documents that become input to the next stage.
  Equivalent to SQL GROUP BY, JOIN, WHERE, HAVING, LIMIT combined.

================================================================
PIPELINE SYNTAX
================================================================

  db.collection.aggregate([
      { $stage1: { ... } },
      { $stage2: { ... } },
      { $stage3: { ... } }
  ])

================================================================
CORE STAGES
================================================================

  $match      Filter documents (like SQL WHERE / HAVING)
  $group      Group and aggregate (like SQL GROUP BY)
  $project    Select/transform fields (like SQL SELECT columns)
  $sort       Sort documents (like SQL ORDER BY)
  $limit      Limit number of results (like SQL LIMIT)
  $skip       Skip documents (like SQL OFFSET)
  $unwind     Flatten an array field into multiple documents
  $lookup     Left outer join another collection
  $addFields  Add computed fields
  $count      Count documents in pipeline
  $out        Write results to a collection
  $merge      Merge results into a collection (upsert)

================================================================
EXAMPLE 1 -- REVENUE BY CATEGORY
================================================================

  SQL:
  SELECT category, SUM(price * quantity) AS revenue, COUNT(*) AS order_count
  FROM order_items
  GROUP BY category
  HAVING SUM(price * quantity) > 10000
  ORDER BY revenue DESC;

  MongoDB:
  db.order_items.aggregate([
      { $group: {
          _id: "$category",
          revenue: { $sum: { $multiply: ["$price", "$quantity"] } },
          orderCount: { $sum: 1 }
      }},
      { $match: { revenue: { $gt: 10000 } } },
      { $sort: { revenue: -1 } }
  ])

================================================================
EXAMPLE 2 -- UNWIND ARRAYS
================================================================

  Document:
  { _id: "ORD001", customer: "Alice", items: ["Laptop", "Mouse", "Pad"] }

  db.orders.aggregate([
      { $unwind: "$items" }
  ])

  Output (3 documents):
  { _id: "ORD001", customer: "Alice", items: "Laptop" }
  { _id: "ORD001", customer: "Alice", items: "Mouse"  }
  { _id: "ORD001", customer: "Alice", items: "Pad"    }

================================================================
EXAMPLE 3 -- $lookup (JOIN)
================================================================

  -- Join orders with customers:
  db.orders.aggregate([
      { $lookup: {
          from: "customers",
          localField: "customer_id",
          foreignField: "_id",
          as: "customer_info"
      }},
      { $unwind: "$customer_info" },
      { $project: {
          order_id: "$_id",
          total: 1,
          customer_name: "$customer_info.name"
      }}
  ])

================================================================
EXAMPLE 4 -- COMPLEX PIPELINE
================================================================

  Top 5 customers by revenue in the last 30 days:

  db.orders.aggregate([
      { $match: {
          order_date: { $gte: new Date(Date.now() - 30*24*60*60*1000) },
          status: { $ne: "CANCELLED" }
      }},
      { $group: {
          _id: "$customer_id",
          total_revenue: { $sum: "$total" },
          order_count: { $sum: 1 }
      }},
      { $sort: { total_revenue: -1 } },
      { $limit: 5 },
      { $lookup: {
          from: "customers",
          localField: "_id",
          foreignField: "_id",
          as: "customer"
      }},
      { $unwind: "$customer" },
      { $project: {
          customer_name: "$customer.name",
          total_revenue: 1,
          order_count: 1
      }}
  ])

================================================================
$group ACCUMULATORS
================================================================

  $sum       Sum of values: { $sum: "$price" }; count: { $sum: 1 }
  $avg       Average: { $avg: "$price" }
  $min       Minimum: { $min: "$price" }
  $max       Maximum: { $max: "$price" }
  $first     First value in group (needs $sort before $group)
  $last      Last value in group
  $push      Array of all values: { $push: "$productName" }
  $addToSet  Array of distinct values
  $count     Count of documents (MongoDB 5.0+)

================================================================
SPRING DATA AGGREGATION
================================================================

  @Autowired AggregationOperation, MongoTemplate

  Aggregation agg = Aggregation.newAggregation(
      Aggregation.match(Criteria.where("status").ne("CANCELLED")),
      Aggregation.group("category")
                 .sum("total").as("revenue")
                 .count().as("orderCount"),
      Aggregation.sort(Sort.Direction.DESC, "revenue"),
      Aggregation.limit(10)
  );

  AggregationResults<RevenueDto> results =
      mongoTemplate.aggregate(agg, "orders", RevenueDto.class);

================================================================
INTERVIEW Q&A
================================================================

  Q: What is the aggregation pipeline in MongoDB?
  A: A series of stages that transform documents.
     Each stage processes the output of the previous one.
     Replaces SQL GROUP BY, JOIN, HAVING, ORDER BY in document form.

  Q: What does $unwind do?
  A: Deconstructs an array field, creating one output document
     per array element. Needed before $group or $lookup on array data.

  Q: How is $lookup different from SQL JOIN?
  A: $lookup performs a left outer join between collections.
     It's less efficient than SQL JOINs (not optimized at the storage layer).
     If joins are frequent, reconsider schema (embed instead of reference).
