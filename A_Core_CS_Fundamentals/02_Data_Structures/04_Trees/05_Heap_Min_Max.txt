HEAP AS A TREE STRUCTURE
----------------------------------------------------------------
A heap is a COMPLETE BINARY TREE stored in an array.

  Complete binary tree properties:
    - All levels fully filled except possibly the last
    - Last level filled left to right
    - Height = O(log n)

  Array representation (0-indexed):
    Parent of i:    (i - 1) / 2
    Left child:     2 * i + 1
    Right child:    2 * i + 2

  MIN-HEAP property:
    Every node <= both its children.
    Root = global minimum.

  MAX-HEAP property:
    Every node >= both its children.
    Root = global maximum.

  Visualization (min-heap):
          1          index 0
         / \
        3   2        index 1, 2
       / \ / \
      7  4 5  6     index 3, 4, 5, 6

  Array: [1, 3, 2, 7, 4, 5, 6]

----------------------------------------------------------------
KEY OPERATIONS
----------------------------------------------------------------
  Operation         Time        Notes
  -----------------------------------------
  Insert            O(log n)    Add at end, sift up
  Delete min/max    O(log n)    Swap root with last, sift down
  Peek min/max      O(1)        Root element
  Heapify array     O(n)        Build heap from arbitrary array
  Search            O(n)        No ordering guarantee except root

----------------------------------------------------------------
JAVA PRIORITY QUEUE (HEAP API)
----------------------------------------------------------------
  Min-heap (default):
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();

  Max-heap:
    PriorityQueue<Integer> maxHeap =
        new PriorityQueue<>(Collections.reverseOrder());

  Custom comparator (sort by second element of int[]):
    PriorityQueue<int[]> pq =
        new PriorityQueue<>((a, b) -> a[1] - b[1]);
    WARNING: a[1] - b[1] can overflow for large values.
    Safe version: Integer.compare(a[1], b[1])

  Key methods:
    offer(x)        -- O(log n) insert
    poll()          -- O(log n) remove and return min
    peek()          -- O(1) view min without removal
    size()          -- O(1)
    isEmpty()       -- O(1)
    contains(x)     -- O(n) linear scan
    remove(x)       -- O(n) remove specific element

  Java PriorityQueue does NOT support decrease-key directly.
  For Dijkstra, use lazy deletion (add updated entry,
  skip stale entries when popping).

----------------------------------------------------------------
HEAP SORT
----------------------------------------------------------------
  1. Build max-heap from array: O(n)
  2. Repeatedly extract max (swap root with last, shrink, sift): O(n log n)
  Result: sorted in-place, O(1) extra space.

  Why Java doesn't use heap sort:
    Poor cache performance (sift-down accesses array far apart).
    Java's Arrays.sort uses Dual-Pivot Quicksort for primitives
    and TimSort for objects.

  Heap sort is O(n log n) worst case unlike quicksort O(n^2),
  which is why some interviewers prefer it as a guaranteed sort.
