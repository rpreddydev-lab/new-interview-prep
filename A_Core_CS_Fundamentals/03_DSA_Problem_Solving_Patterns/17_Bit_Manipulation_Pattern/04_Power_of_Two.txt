================================================================
  POWER OF TWO / FOUR / THREE — LC 231 / LC 342 / LC 326
  AND BIT-BASED DIVISIBILITY TRICKS
================================================================

  LC 231: Given integer n, return true if n is a power of two.
  LC 342: Given integer n, return true if n is a power of four.
  LC 326: Given integer n, return true if n is a power of three.

----------------------------------------------------------------
LC 231 — POWER OF TWO
----------------------------------------------------------------

  A power of 2 has exactly ONE set bit in binary.
  e.g. 1=001, 2=010, 4=100, 8=1000.

  Key: n > 0 AND n & (n-1) == 0.
    n & (n-1) removes the lowest set bit.
    If n was a power of 2 (single set bit), result is 0.

  Java:
    public boolean isPowerOfTwo(int n) {
        return n > 0 && (n & (n - 1)) == 0;
    }

  Alternative: n > 0 && Integer.bitCount(n) == 1.
  Alternative: n > 0 && (Integer.MAX_VALUE & n) == n && Integer.highestOneBit(n) == n.

  Trace:
    n=4:  4 & 3 = 100 & 011 = 000 = 0. ✓ power of 2.
    n=6:  6 & 5 = 110 & 101 = 100 = 4 ≠ 0. ✗ not power of 2.
    n=-4: n > 0 fails. ✗ (negative numbers can't be power of 2)

  Time: O(1)  Space: O(1)

----------------------------------------------------------------
LC 342 — POWER OF FOUR
----------------------------------------------------------------

  Power of 4: 1, 4, 16, 64, 256...
  In binary: 000001, 000100, 010000, 1000000...
  Pattern: single set bit AND that bit is at an EVEN position (0, 2, 4, 6...).

  Check 1: n > 0 && (n & (n-1)) == 0  → power of 2.
  Check 2: bit is at an even position → n & 0xAAAAAAAA == 0.
    0xAAAAAAAA = binary 10101010...1010 (bits at ODD positions set).
    If n is a power of 4, its single bit is at even position, so n & 0xAAAAAAAA == 0.

  Java:
    public boolean isPowerOfFour(int n) {
        return n > 0 && (n & (n - 1)) == 0 && (n & 0xAAAAAAAA) == 0;
    }

  Alternative: Use modulo.
    Powers of 4 mod 3: 4^k mod 3 = (3+1)^k mod 3 = 1^k = 1.
    But powers of 2 that aren't powers of 4: 2^(2k+1) mod 3 = 2.

  Java (math approach):
    public boolean isPowerOfFour(int n) {
        return n > 0 && (n & (n-1)) == 0 && n % 3 == 1;
    }

  Trace:
    n=16=10000: 16&15=0 ✓ (power of 2). 16 & 0xAAAAAAAA = 10000 & ...101010 = 0 ✓.
    n=8=1000:   8&7=0 ✓. 8 & 0xAAAAAAAA = 1000 & ...101010 = 1000 ≠ 0 ✗.

  Time: O(1)  Space: O(1)

----------------------------------------------------------------
LC 326 — POWER OF THREE
----------------------------------------------------------------

  3 is NOT a power of 2, so bit tricks don't apply directly.
  Two approaches:

  Approach 1: Loop dividing by 3.
  Java:
    public boolean isPowerOfThree(int n) {
        if (n <= 0) return false;
        while (n % 3 == 0) n /= 3;
        return n == 1;
    }

  Approach 2: Math trick — 3^19 = 1162261467 is the largest power of 3 within int range.
    If n is a power of 3, it must divide 3^19.
  Java:
    public boolean isPowerOfThree(int n) {
        return n > 0 && 1162261467 % n == 0;
    }

  Why this works: Any power of 3 divides 3^19 (prime base, so only 3^k divides 3^19 for k≤19).

  Time: O(log n) for approach 1. O(1) for approach 2.

----------------------------------------------------------------
GENERAL POWER OF B CHECK
----------------------------------------------------------------

  For prime base b: check if b^max_k % n == 0 where max_k = max power in int range.

  For non-prime base (e.g., 6 = 2*3):
    6^k is divisible by both 2 and 3.
    Must also check n is divisible by 2 and 3 specifically.
    Use loop approach for non-prime bases.

----------------------------------------------------------------
RELATED BIT DIVISIBILITY TRICKS
----------------------------------------------------------------

  Check if n is even:          n & 1 == 0
  Check if n is odd:           n & 1 == 1
  Check if n is divisible by 4: n & 3 == 0  (same as n & 0x3 == 0)
  Check if n is divisible by 8: n & 7 == 0

  Why: 4 = 100 in binary. For n divisible by 4, last 2 bits must be 00.
       n & (4-1) = n & 3 checks last 2 bits.

----------------------------------------------------------------
LC 29 — DIVIDE TWO INTEGERS (BIT SHIFTING)
----------------------------------------------------------------

  Divide a / b without using * / %. Use bit shifting.

  Strategy: For each bit position from high to low,
            check if (b << i) <= a. If yes, subtract and accumulate.

  Java:
    public int divide(int dividend, int divisor) {
        if (dividend == Integer.MIN_VALUE && divisor == -1) return Integer.MAX_VALUE;
        long a = Math.abs((long)dividend), b = Math.abs((long)divisor);
        int result = 0;
        for (int i = 31; i >= 0; i--) {
            if ((a >> i) >= b) {
                result += (1 << i);
                a -= b << i;
            }
        }
        return (dividend > 0) == (divisor > 0) ? result : -result;
    }

  Time: O(log(dividend))  Space: O(1)

  Edge case: INT_MIN / -1 overflows to INT_MAX.

----------------------------------------------------------------
LC 371 — SUM OF TWO INTEGERS WITHOUT + OR -
----------------------------------------------------------------

  Use bit manipulation:
    XOR gives sum without carry.
    AND << 1 gives the carry bits.
    Repeat until carry is 0.

  Java:
    public int getSum(int a, int b) {
        while (b != 0) {
            int carry = (a & b) << 1;
            a = a ^ b;
            b = carry;
        }
        return a;
    }

  Trace for a=2 (10), b=3 (11):
    Round 1: carry=(10&11)<<1=(10)<<1=100=4. a=10^11=01=1. b=4.
    Round 2: carry=(01&100)<<1=000<<1=0. a=01^100=101=5. b=0.
    Return 5. ✓

  Time: O(32) = O(1)  Space: O(1)

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why does n & (n-1) == 0 check for power of 2?
  A: Powers of 2 have exactly one set bit. n-1 flips all bits from that set bit downward.
     ANDing clears that bit and gives 0. Any non-power-of-2 has multiple set bits
     or no bits, and this fails.

  Q: What is 0xAAAAAAAA in binary and why is it used for power of 4?
  A: 0xAAAAAAAA = 10101010...10101010. It has 1s at all ODD bit positions.
     Powers of 4 have their single set bit at EVEN positions (0, 2, 4...).
     So (n & 0xAAAAAAAA) == 0 verifies the bit is at an even position.

  Q: Why does the 3^19 trick work for power of 3 but not power of 6?
  A: 3 is prime. Only divisors of 3^19 of the form 3^k are valid.
     6 = 2*3 is not prime. 6^19's divisors include non-powers-of-6 (e.g., 2, 4).

  Q: Why use `long` in LC 29?
  A: Integer.MIN_VALUE = -2^31. Math.abs(Integer.MIN_VALUE) overflows int. Use long.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Power of 2: one liner `n > 0 && (n & (n-1)) == 0`. Memorize it.
  - Power of 4: if interviewer asks, show the 0xAAAAAAAA mask OR the n%3==1 trick.
  - Power of 3: the max-power modulo trick is clever — explain why it works for prime bases.
  - For LC 371: dry-run the trace (a=2, b=3) to show understanding.
  - Note: LC 371 in Python may have issues with 32-bit masking; Java int overflow handles it.
