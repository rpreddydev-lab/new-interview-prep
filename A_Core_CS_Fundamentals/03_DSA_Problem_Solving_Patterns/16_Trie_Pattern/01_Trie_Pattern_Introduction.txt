================================================================
  TRIE (PREFIX TREE) PATTERN — INTRODUCTION
================================================================

  A Trie (pronounced "try") is a tree data structure for storing strings
  where each node represents a character. Paths from root to nodes spell
  out prefixes; paths to marked nodes spell complete words.

  Key properties:
    - Root is empty.
    - Each node has up to 26 children (lowercase English letters).
    - isEnd flag marks end of a word.
    - Prefix sharing: "cap", "cat", "car" all share root → 'c' → 'a'.

----------------------------------------------------------------
TRIE STRUCTURE VISUALIZATION
----------------------------------------------------------------

  Words: ["cat", "car", "card", "care", "dog"]

              root
             /    \
            c      d
            |      |
            a      o
           / \     |
          t   r    g(*)
         (*)  |
             a
            / \
           d   e
          (*) (*)

  (*) = isEnd = true

  find "car":  root → c → a → r. isEnd at 'r'? No → "car" not in trie.
  find "card": root → c → a → r → d. isEnd? Yes → found.
  prefix "ca": root → c → a. Found prefix.

----------------------------------------------------------------
TRIE NODE IMPLEMENTATION
----------------------------------------------------------------

  Java:
    class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean isEnd = false;
    }

  OR with HashMap for non-English chars:
    class TrieNode {
        Map<Character, TrieNode> children = new HashMap<>();
        boolean isEnd = false;
    }

----------------------------------------------------------------
TRIE CLASS — FULL IMPLEMENTATION
----------------------------------------------------------------

  Java:
    class Trie {
        private TrieNode root = new TrieNode();

        public void insert(String word) {
            TrieNode node = root;
            for (char c : word.toCharArray()) {
                int idx = c - 'a';
                if (node.children[idx] == null) {
                    node.children[idx] = new TrieNode();
                }
                node = node.children[idx];
            }
            node.isEnd = true;
        }

        public boolean search(String word) {
            TrieNode node = getNode(word);
            return node != null && node.isEnd;
        }

        public boolean startsWith(String prefix) {
            return getNode(prefix) != null;
        }

        private TrieNode getNode(String s) {
            TrieNode node = root;
            for (char c : s.toCharArray()) {
                int idx = c - 'a';
                if (node.children[idx] == null) return null;
                node = node.children[idx];
            }
            return node;
        }
    }

  insert: O(L)   search: O(L)   startsWith: O(L)   where L = word length.
  Space: O(ALPHABET_SIZE * N * L) in worst case (no sharing).

----------------------------------------------------------------
COMMON TRIE OPERATIONS SUMMARY
----------------------------------------------------------------

  Operation        Description                         Time
  -------------    --------------------------------    ------
  insert(word)     Add word to trie                    O(L)
  search(word)     Check if word exists                O(L)
  startsWith(pre)  Check if any word has prefix        O(L)
  delete(word)     Remove word (complex — see below)   O(L)
  getAllWords()     Collect all words (DFS)             O(N*L)
  countWords(pre)  Count words with given prefix       O(N*L)

----------------------------------------------------------------
DELETE OPERATION (TRICKY)
----------------------------------------------------------------

  Deletion must only remove nodes that are NOT shared by other words.

  Java:
    public void delete(String word) {
        delete(root, word, 0);
    }

    private boolean delete(TrieNode node, String word, int idx) {
        if (idx == word.length()) {
            if (!node.isEnd) return false;   // word not present
            node.isEnd = false;
            return isEmpty(node);             // can we delete this node?
        }
        int i = word.charAt(idx) - 'a';
        if (node.children[i] == null) return false;
        boolean shouldDelete = delete(node.children[i], word, idx + 1);
        if (shouldDelete) {
            node.children[i] = null;
            return !node.isEnd && isEmpty(node);  // delete this node too if unused
        }
        return false;
    }

    private boolean isEmpty(TrieNode node) {
        for (TrieNode child : node.children) if (child != null) return false;
        return true;
    }

----------------------------------------------------------------
WHEN TO USE A TRIE
----------------------------------------------------------------

  Use Trie when:
    - Need prefix-based lookup (autocomplete, IP routing)
    - Large number of strings with shared prefixes
    - Need to find all words with a given prefix
    - Word validation against a dictionary
    - Spell-check, search suggestions

  Don't use Trie when:
    - Simple contains check (use HashSet: O(1) avg)
    - Very few strings (overhead not worth it)
    - Memory is extremely constrained (Trie can use more memory than HashMap for sparse data)

----------------------------------------------------------------
TRIE VS HASHSET/HASHMAP
----------------------------------------------------------------

  Feature           Trie                    HashSet
  -----------       -------------------     ----------------------
  exact search      O(L)                    O(L) avg
  prefix search     O(L) ✓                  O(N*L) worst case ✗
  sorted traversal  Yes (DFS in order) ✓    No (unordered) ✗
  memory            High (26 pointers/node) Lower for sparse
  wildcard search   Possible (with mods) ✓  Very hard ✗

----------------------------------------------------------------
ADDITIONAL TRIE FEATURES
----------------------------------------------------------------

  1. Count words with prefix:
     Store count at each node (increment on insert, decrement on delete).

  2. Longest common prefix of all words:
     Traverse trie while exactly one child exists and isEnd is false.

  3. Wildcard search (LC 211):
     '.' matches any char. DFS all children at '.' node.

  4. Ranked autocomplete:
     Store (word, rank) in TrieNode at isEnd. Use PriorityQueue.

----------------------------------------------------------------
COMPLEXITY REFERENCE
----------------------------------------------------------------

  N = number of words, L = average word length, A = alphabet size (26).

  Time:
    insert / search / startsWith  : O(L)
    Build trie from N words       : O(N * L)
    DFS to get all words          : O(N * L)

  Space:
    Worst case (no prefix sharing): O(A * N * L)   [all unique chars]
    Best case (many shared):        O(A * L)        [all words share prefix]

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why use a Trie over a HashSet for word problems?
  A: Trie supports prefix queries in O(L); HashSet needs O(N*L) to scan all words.
     Also allows wildcard matching and autocomplete.

  Q: Can Trie store non-lowercase letters?
  A: Yes — use HashMap<Character, TrieNode> instead of array[26]. Slower but flexible.

  Q: What's the space tradeoff?
  A: Arrays (children[26]) are fast but waste memory for sparse alphabets.
     HashMaps save memory but have higher constant overhead.

  Q: How to find the longest word in dictionary that is a prefix of searchWord?
  A: Traverse trie along searchWord characters. Track last node with isEnd=true.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Always draw the trie visually when explaining.
  - Mention: each node = character, isEnd = complete word.
  - For array[26], show index = char - 'a'.
  - State time/space upfront: O(L) per operation, O(A*N*L) space.
  - Know the wildcard DFS variation (needed for LC 211, LC 212).
