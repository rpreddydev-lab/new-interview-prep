================================================================
  INTERVAL DP PATTERN
================================================================

  Interval DP: dp[i][j] = optimal answer for subproblem on range [i..j].
  Solved bottom-up by increasing interval length.
  Innermost loop picks a split point k within [i..j].

  Template:
    for (int len = 2; len <= n; len++) {           // interval length
        for (int i = 0; i + len - 1 < n; i++) {   // left endpoint
            int j = i + len - 1;                   // right endpoint
            dp[i][j] = WORST;
            for (int k = i; k < j; k++) {          // split point
                dp[i][j] = BEST(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i,k,j));
            }
        }
    }

  Base case: dp[i][i] = value for single element (often 0 or trivial).

----------------------------------------------------------------
BURST BALLOONS (LC 312)
----------------------------------------------------------------

  Given nums with n balloons. Burst balloon i → gain nums[i-1]*nums[i]*nums[i+1].
  Find max coins to burst all balloons.

  Key insight: think LAST balloon to burst in range [i..j].
  When k is last in [i..j]: neighbors are nums[i-1] and nums[j+1] (both still alive).
  Pad array: nums = [1] + nums + [1] to handle boundaries.

  dp[i][j] = max coins bursting all balloons in (i,j) (open interval, not including i,j).
  Transition: for k in (i,j): dp[i][j] = max(dp[i][k] + nums[i]*nums[k]*nums[j] + dp[k][j])

  Java:
    public int maxCoins(int[] nums) {
        int n = nums.length;
        int[] arr = new int[n + 2];
        arr[0] = arr[n + 1] = 1;
        for (int i = 0; i < n; i++) arr[i + 1] = nums[i];
        int N = n + 2;

        int[][] dp = new int[N][N];
        // len = number of balloons in open interval (i,j), so j - i - 1 balloons
        for (int len = 2; len < N; len++) {
            for (int i = 0; i + len < N; i++) {
                int j = i + len;
                for (int k = i + 1; k < j; k++) {  // k is last to burst in (i,j)
                    dp[i][j] = Math.max(dp[i][j],
                        dp[i][k] + arr[i] * arr[k] * arr[j] + dp[k][j]);
                }
            }
        }
        return dp[0][N - 1];
    }

  Time: O(n^3)   Space: O(n^2)

  Example: nums = [3,1,5,8] → padded: [1,3,1,5,8,1]
  Answer: 167

  Trace for range (0,5) [full]:
    len=2: dp[0][2]=1*3*1=3, dp[1][3]=3*1*5=15, dp[2][4]=1*5*8=40, dp[3][5]=5*8*1=40
    len=3: dp[0][3]=max(dp[0][1]+1*3*5+dp[1][3], dp[0][2]+1*1*5+dp[2][3])=...
    ...
    dp[0][5] = 167 ✓

MATRIX CHAIN MULTIPLICATION
----------------------------------------------------------------

  Matrices M1..Mn. Minimize scalar multiplications to compute M1*M2*...*Mn.
  dp[i][j] = minimum cost to multiply matrices i through j.
  Split at k: cost = dp[i][k] + dp[k+1][j] + dims[i-1]*dims[k]*dims[j]

  Java:
    public int matrixChain(int[] dims) {
        int n = dims.length - 1;  // n matrices
        int[][] dp = new int[n + 1][n + 1];
        for (int len = 2; len <= n; len++) {
            for (int i = 1; i + len - 1 <= n; i++) {
                int j = i + len - 1;
                dp[i][j] = Integer.MAX_VALUE;
                for (int k = i; k < j; k++) {
                    int cost = dp[i][k] + dp[k+1][j] + dims[i-1] * dims[k] * dims[j];
                    dp[i][j] = Math.min(dp[i][j], cost);
                }
            }
        }
        return dp[1][n];
    }

  dims = [10, 30, 5, 60]: matrices 10x30, 30x5, 5x60.
  Optimal: (M1*M2)*M3 = (10*30*5) + (10*5*60) = 1500+3000 = 4500.
  vs M1*(M2*M3) = (30*5*60) + (10*30*60) = 9000+18000 = 27000.

PALINDROME PARTITION MINIMUM CUTS (LC 132) — INTERVAL DP VIEW

    dp[i][j] = min cuts to partition s[i..j] into all palindromes.

STRANGE PRINTER (LC 664)
----------------------------------------------------------------

  Printer prints one character at a time across a range.
  Once started, it repeats the same character until turning.
  dp[i][j] = minimum turns to print s[i..j].

  Transitions:
    Base: dp[i][i] = 1 (single char)
    If s[i] == s[j]: dp[i][j] = dp[i][j-1]  (last char free — extend first turn)
    Otherwise: dp[i][j] = min(dp[i][k] + dp[k+1][j]) for k in [i..j-1]

  Java:
    public int strangePrinter(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];
        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                dp[i][j] = dp[i][j-1] + 1;  // always safe: print s[j] separately
                for (int k = i; k < j; k++) {
                    if (s.charAt(k) == s.charAt(j)) {
                        dp[i][j] = Math.min(dp[i][j], dp[i][k] + (k+1 <= j-1 ? dp[k+1][j-1] : 0));
                    }
                }
            }
        }
        return dp[0][n - 1];
    }

MINIMUM COST TREE FROM LEAF VALUES (LC 1130)
----------------------------------------------------------------

  Given arr of positive integers (leaves in inorder), form a binary tree.
  Internal node value = product of max leaves in left and right subtrees.
  Minimize sum of all internal node values.

  dp[i][j] = min sum of internal nodes in subtree spanning leaves i..j.
  max[i][j] = max leaf value in range i..j (precompute).
  Split at k: dp[i][j] = min(dp[i][k] + dp[k+1][j] + max[i][k]*max[k+1][j])

  Java:
    public int mctFromLeafValues(int[] arr) {
        int n = arr.length;
        int[][] dp = new int[n][n];
        int[][] maxVal = new int[n][n];

        // Precompute max values
        for (int i = 0; i < n; i++) {
            maxVal[i][i] = arr[i];
            for (int j = i + 1; j < n; j++) {
                maxVal[i][j] = Math.max(maxVal[i][j-1], arr[j]);
            }
        }

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                dp[i][j] = Integer.MAX_VALUE;
                for (int k = i; k < j; k++) {
                    dp[i][j] = Math.min(dp[i][j], dp[i][k] + dp[k+1][j] + maxVal[i][k] * maxVal[k+1][j]);
                }
            }
        }
        return dp[0][n - 1];
    }

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. Loop order: must iterate length (outer), then start index i (inner).
     Cannot iterate i then j without fixing length — subproblems not ready.

  2. Burst Balloons: treating boundaries incorrectly.
     Padding with 1s and using OPEN intervals (i,j) is key.

  3. Off-by-one: j = i + len - 1 vs j = i + len. Depends on whether
     interval is inclusive or exclusive. Be consistent.

  4. Initialization: dp[i][j] = 0 for minimization problems when 0 means "no cost" is wrong.
     Should be Integer.MAX_VALUE initially.

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why iterate by length in interval DP?
  A: dp[i][j] depends on dp[i][k] and dp[k+1][j] (smaller intervals).
     Increasing-length ordering ensures all smaller subproblems are solved first.

  Q: Why does Burst Balloons use LAST balloon (not first)?
  A: If we think about the first balloon burst, we don't know its neighbors
     (they haven't been burst yet). Thinking about LAST to burst means its
     neighbors are exactly i and j (the boundary), which we know.

  Q: Time complexity for all interval DP problems?
  A: O(n^3): n^2 states (i,j) × n split points k.

  Q: What's the space complexity?
  A: O(n^2) for the dp table. Can't easily reduce further.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Draw the "last to burst/split" framing for Burst Balloons.
  - For any interval DP: "I fix the split point k, recurse on left and right halves."
  - Mention the length-first loop order explicitly — interviewers check this.
  - For Burst Balloons, pad the array with 1s first before writing code.
