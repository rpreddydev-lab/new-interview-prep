================================================================
  N-QUEENS (LC 51, 52) AND SUDOKU SOLVER (LC 37)
================================================================

  LC 51: Place n queens on an n×n chessboard such that no two queens
         attack each other. Return all distinct solutions (board configs).
  LC 52: Return the number of distinct solutions.

  LC 37: Solve a Sudoku puzzle (9×9 board with some cells filled in).

  Input (LC 51):  n = 4
  Output: two solutions (board as list of strings)

----------------------------------------------------------------
N-QUEENS: CORE INSIGHT
----------------------------------------------------------------

  Since no two queens can share the same row, place exactly one queen per row.
  Use backtracking: row by row, try each column.

  Attack conditions:
    Same column:      col[c] is taken
    Same diagonal ↘:  (row - col) is constant  →  track row-col values
    Same anti-diagonal ↗:  (row + col) is constant  →  track row+col values

  Java:
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> result = new ArrayList<>();
        boolean[] cols = new boolean[n];
        boolean[] diag = new boolean[2 * n];      // row - col, offset by n
        boolean[] antiDiag = new boolean[2 * n];  // row + col
        int[] queens = new int[n];  // queens[row] = column of queen in that row
        Arrays.fill(queens, -1);
        backtrack(0, n, queens, cols, diag, antiDiag, result);
        return result;
    }

    private void backtrack(int row, int n, int[] queens,
                            boolean[] cols, boolean[] diag, boolean[] antiDiag,
                            List<List<String>> result) {
        if (row == n) {
            result.add(buildBoard(queens, n));
            return;
        }
        for (int col = 0; col < n; col++) {
            if (cols[col] || diag[row - col + n] || antiDiag[row + col]) continue;
            // Place queen
            queens[row] = col;
            cols[col] = true;
            diag[row - col + n] = true;
            antiDiag[row + col] = true;
            // Recurse to next row
            backtrack(row + 1, n, queens, cols, diag, antiDiag, result);
            // Remove queen
            queens[row] = -1;
            cols[col] = false;
            diag[row - col + n] = false;
            antiDiag[row + col] = false;
        }
    }

    private List<String> buildBoard(int[] queens, int n) {
        List<String> board = new ArrayList<>();
        for (int row = 0; row < n; row++) {
            char[] line = new char[n];
            Arrays.fill(line, '.');
            line[queens[row]] = 'Q';
            board.add(new String(line));
        }
        return board;
    }

  Time: O(n!)    Space: O(n) for arrays + O(n^2) for output

  Key: `row - col + n` as diagonal index (offset by n to avoid negative index).

----------------------------------------------------------------
LC 52: TOTAL N-QUEENS
----------------------------------------------------------------

  Same backtracking, but count solutions instead of building boards.

  Java:
    int count = 0;

    public int totalNQueens(int n) {
        backtrack(0, n, new boolean[n], new boolean[2*n], new boolean[2*n]);
        return count;
    }

    private void backtrack(int row, int n, boolean[] cols, boolean[] diag, boolean[] anti) {
        if (row == n) { count++; return; }
        for (int col = 0; col < n; col++) {
            if (cols[col] || diag[row-col+n] || anti[row+col]) continue;
            cols[col] = diag[row-col+n] = anti[row+col] = true;
            backtrack(row+1, n, cols, diag, anti);
            cols[col] = diag[row-col+n] = anti[row+col] = false;
        }
    }

  No queens[] array needed, no buildBoard needed. Just increment count.

----------------------------------------------------------------
SUDOKU SOLVER (LC 37)
----------------------------------------------------------------

  Fill empty cells ('.') with digits 1-9.
  Constraints: each digit appears at most once per row, column, and 3×3 box.

  Track what's used: `rows[r][d]`, `cols[c][d]`, `boxes[b][d]` where b = (r/3)*3 + c/3.
  Backtrack: find next empty cell, try 1-9, recurse.

  Java:
    public void solveSudoku(char[][] board) {
        boolean[][] rows = new boolean[9][10];
        boolean[][] cols = new boolean[9][10];
        boolean[][] boxes = new boolean[9][10];

        // Initialize with given values
        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                if (board[r][c] != '.') {
                    int d = board[r][c] - '0';
                    int b = (r/3)*3 + (c/3);
                    rows[r][d] = cols[c][d] = boxes[b][d] = true;
                }
            }
        }
        backtrack(board, rows, cols, boxes, 0, 0);
    }

    private boolean backtrack(char[][] board, boolean[][] rows, boolean[][] cols,
                               boolean[][] boxes, int r, int c) {
        // Advance to next empty cell
        while (r < 9 && board[r][c] != '.') {
            c++;
            if (c == 9) { c = 0; r++; }
        }
        if (r == 9) return true;  // all cells filled

        int b = (r/3)*3 + (c/3);
        for (int d = 1; d <= 9; d++) {
            if (rows[r][d] || cols[c][d] || boxes[b][d]) continue;
            board[r][c] = (char)('0' + d);
            rows[r][d] = cols[c][d] = boxes[b][d] = true;

            if (backtrack(board, rows, cols, boxes, r, c)) return true;

            board[r][c] = '.';
            rows[r][d] = cols[c][d] = boxes[b][d] = false;
        }
        return false;  // no digit worked → backtrack
    }

  Time: O(9^m) where m = number of empty cells. With backtracking, much faster in practice.
  Space: O(1) extra (board modified in-place).

  Box index: `(r/3)*3 + (c/3)` maps each 3×3 box to 0-8.

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. N-Queens: not offsetting diagonal index → negative array index.
     Fix: `row - col + n` (offset by n).

  2. N-Queens: forgetting to reset after backtracking (not un-placing queen).

  3. Sudoku: not scanning for next empty cell correctly (linear scan).
     When c reaches 9, reset c=0 and r++.

  4. Sudoku: returning false at end of for loop (no digit fits) vs returning true
     at r==9. The return values drive the entire recursive solving.

  5. Both: using nested loops to check attack/validity inline instead of O(1) booleans.

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why can we place one queen per row (instead of trying all cells)?
  A: Queens attack along entire rows. Any valid solution has exactly one queen
     per row (by pigeonhole). This reduces search space from O(n^2)! to O(n!).

  Q: What's the significance of `row - col + n` for diagonal?
  A: All cells on the same ↘ diagonal have the same (row - col) value.
     It ranges from -(n-1) to (n-1), so we offset by n to get index 1 to 2n-1.

  Q: Time complexity of N-Queens?
  A: O(n!): row 0 has n choices, row 1 has at most n-1, etc. Actual solutions
     are much fewer due to pruning. For n=8 there are 92 solutions.

  Q: How many N-Queens solutions are there for small n?
     n=1: 1, n=2: 0, n=3: 0, n=4: 2, n=5: 10, n=6: 4, n=7: 40, n=8: 92

  Q: Why does Sudoku Solver return a boolean?
  A: To short-circuit once a solution is found. Once backtrack returns true,
     all callers propagate true upward — no further exploration needed.

INTERVIEW TIPS

  - Both problems are canonical examples of backtracking with O(1) constraint checks.
