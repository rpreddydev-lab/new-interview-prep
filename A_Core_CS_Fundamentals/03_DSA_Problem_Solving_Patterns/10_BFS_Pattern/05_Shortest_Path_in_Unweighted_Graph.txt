================================================================
  SHORTEST PATH IN UNWEIGHTED GRAPH
================================================================

  In an unweighted graph, BFS guarantees the shortest path
  because it explores all nodes at distance d before d+1.

  Key guarantee: when a node is first DEQUEUED from the BFS queue,
  the distance stored for it is the shortest path distance.

  (In weighted graphs, use Dijkstra's algorithm instead.)

----------------------------------------------------------------
SHORTEST PATH: SINGLE SOURCE
----------------------------------------------------------------

  Find shortest path from source to all other nodes.

  Java:
    public int[] shortestPath(int n, List<List<Integer>> adj, int src) {
        int[] dist = new int[n];
        Arrays.fill(dist, -1);

        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(src);
        dist[src] = 0;

        while (!queue.isEmpty()) {
            int curr = queue.poll();
            for (int neighbor : adj.get(curr)) {
                if (dist[neighbor] == -1) {  // unvisited
                    dist[neighbor] = dist[curr] + 1;
                    queue.offer(neighbor);
                }
            }
        }
        return dist;  // dist[i] = shortest path from src to i, -1 if unreachable
    }

----------------------------------------------------------------
SHORTEST PATH: SPECIFIC TARGET (EARLY TERMINATION)
----------------------------------------------------------------

  Java:
    public int shortestPath(int n, List<List<Integer>> adj, int src, int target) {
        if (src == target) return 0;

        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(src);
        visited[src] = true;
        int steps = 0;

        while (!queue.isEmpty()) {
            steps++;
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int curr = queue.poll();
                for (int neighbor : adj.get(curr)) {
                    if (neighbor == target) return steps;
                    if (!visited[neighbor]) {
                        visited[neighbor] = true;
                        queue.offer(neighbor);
                    }
                }
            }
        }
        return -1;
    }

RECONSTRUCT THE ACTUAL PATH
----------------------------------------------------------------

  Store parent[] array during BFS. Backtrack from target to source.

  Java:
    public List<Integer> shortestPathWithTrace(int n, List<List<Integer>> adj, int src, int target) {
        int[] parent = new int[n];
        Arrays.fill(parent, -1);
        boolean[] visited = new boolean[n];

        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(src);
        visited[src] = true;

        while (!queue.isEmpty()) {
            int curr = queue.poll();
            if (curr == target) break;
            for (int neighbor : adj.get(curr)) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    parent[neighbor] = curr;
                    queue.offer(neighbor);
                }
            }
        }

        // Reconstruct path
        if (!visited[target]) return Collections.emptyList();
        List<Integer> path = new ArrayList<>();
        for (int v = target; v != -1; v = parent[v]) path.add(v);
        Collections.reverse(path);
        return path;
    }

PROBLEM: SHORTEST PATH WITH K OBSTACLES REMOVED (LC 1293)
----------------------------------------------------------------

  Grid with 0s (open) and 1s (obstacles). Remove at most k obstacles.
  Find shortest path from (0,0) to (m-1,n-1).

  State = (row, col, obstacles_remaining).
  Visited = boolean[][][] of size m * n * (k+1).

  Java:
    public int shortestPath(int[][] grid, int k) {
        int m = grid.length, n = grid[0].length;
        if (m==1 && n==1) return 0;

        // State: [row, col, remaining removals]
        boolean[][][] visited = new boolean[m][n][k+1];
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0, k, 0});  // row, col, remaining_k, steps
        visited[0][0][k] = true;

        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int r=curr[0], c=curr[1], rem=curr[2], steps=curr[3];

            for (int[] dir : dirs) {
                int nr=r+dir[0], nc=c+dir[1];
                if (nr<0 || nr>=m || nc<0 || nc>=n) continue;

                int newRem = rem - grid[nr][nc];  // obstacle costs 1 removal
                if (newRem < 0) continue;         // can't pass

                if (nr==m-1 && nc==n-1) return steps+1;

                if (!visited[nr][nc][newRem]) {
                    visited[nr][nc][newRem] = true;
                    queue.offer(new int[]{nr, nc, newRem, steps+1});
                }
            }
        }
        return -1;
    }

  Time: O(m*n*k)   Space: O(m*n*k)

  Key insight: same cell (r,c) can be visited multiple times with
  DIFFERENT remaining k. The full state must include k remaining.

PROBLEM: SNAKES AND LADDERS (LC 909)
----------------------------------------------------------------

  On an n*n board numbered 1 to n². Snakes/ladders teleport from cell to cell.
  Find minimum moves from cell 1 to cell n².

  BFS on cell numbers 1..n². State = current cell.
  From cell c, can move to c+1..c+6. Apply snake/ladder if applicable.

  Java (cell number to board coordinates):
    int[] boardToPos(int cell, int n) {
        cell--;  // 0-indexed
        int row = cell / n;
        int col = cell % n;
        // Row 0 of board is bottom row: row n-1 in matrix
        // Alternate direction: even rows left-to-right, odd rows right-to-left
        int r = n - 1 - row;
        int c = (row % 2 == 0) ? col : n - 1 - col;
        return new int[]{r, c};
    }

    public int snakesAndLadders(int[][] board) {
        int n = board.length;
        boolean[] visited = new boolean[n*n+1];
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(1);
        visited[1] = true;
        int moves = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int curr = queue.poll();
                if (curr == n*n) return moves;
                for (int dice = 1; dice <= 6 && curr+dice <= n*n; dice++) {
                    int next = curr + dice;
                    int[] pos = boardToPos(next, n);
                    if (board[pos[0]][pos[1]] != -1) next = board[pos[0]][pos[1]];
                    if (!visited[next]) {
                        visited[next] = true;
                        queue.offer(next);
                    }
                }
            }
            moves++;
        }
        return -1;
    }

SHORTEST PATH IN WEIGHTED GRAPH (DIJKSTRA OVERVIEW)
----------------------------------------------------------------

  For weighted graphs, use Dijkstra's with a min-heap (priority queue).
  BFS is correct only for unweighted (or uniform weight = 1) graphs.

  Dijkstra:
    PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[1]-b[1]);  // [node, dist]
    dist[src] = 0;
    pq.offer(new int[]{src, 0});

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int u = curr[0], d = curr[1];
        if (d > dist[u]) continue;  // stale entry

        for (int[] edge : adj.get(u)) {
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{v, dist[v]});
            }
        }
    }

  Time: O((V+E) log V)

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why does BFS guarantee shortest path in unweighted graphs?
  A: BFS processes nodes in non-decreasing distance order (FIFO queue).
     When a node is first reached (dequeued), all shorter paths have already
     been explored. The first time we reach the target = shortest path.

  Q: What if the graph has weights?
  A: BFS fails for weighted graphs because a path with more hops can have
     smaller total weight. Use Dijkstra's algorithm with a min-heap.

  Q: How do you handle state-space search (state = tuple)?
  A: Use a visited set of states, not just nodes. For (row, col, k),
     use a 3D boolean array or HashSet<String> for the visited set.

  Q: Can BFS find all shortest paths (not just one)?
  A: Yes. Track parent as a List (multiple parents per node). When a node
     is reached at equal distance, add the additional parent. Then
     backtrack all paths.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Make clear: "BFS guarantees shortest path ONLY for unweighted graphs."
  - For complex states: encode the state clearly (e.g., int[] {r,c,k}).
  - When asked for actual path (not just length): use parent[] array.
  - Dijkstra is BFS with a min-heap instead of a plain queue.
