================================================================
  FIND FIRST AND LAST POSITION OF ELEMENT IN SORTED ARRAY
  (LC 34)
================================================================

----------------------------------------------------------------
PROBLEM STATEMENT
----------------------------------------------------------------

  Given a sorted array of integers (possibly with duplicates) and
  a target value, return the first and last positions (indices)
  of target in the array. Return [-1, -1] if not found.

  Example:
    nums = [5, 7, 7, 8, 8, 10], target = 8
    Output: [3, 4]

    nums = [5, 7, 7, 8, 8, 10], target = 6
    Output: [-1, -1]

  Requirement: O(log n) time.

----------------------------------------------------------------
APPROACH: TWO BINARY SEARCHES
----------------------------------------------------------------

  Run binary search TWICE:
    1. Find FIRST occurrence (leftmost index where nums[i] == target)
    2. Find LAST occurrence  (rightmost index where nums[i] == target)

  Both use the "find boundary" template (Template 2 from introduction).

  FIND FIRST: binary search for leftmost position where nums[i] >= target.
    Then check if nums[lo] == target.

  FIND LAST: binary search for leftmost position where nums[i] > target.
    Then subtract 1.

  This is equivalent to "lower_bound" and "upper_bound" from C++ STL.

----------------------------------------------------------------
JAVA SOLUTION
----------------------------------------------------------------

  public int[] searchRange(int[] nums, int target) {
      int first = lowerBound(nums, target);
      if (first == nums.length || nums[first] != target) {
          return new int[]{-1, -1};
      }
      int last = lowerBound(nums, target + 1) - 1;
      return new int[]{first, last};
  }

  // Returns: first index where nums[i] >= target
  private int lowerBound(int[] nums, int target) {
      int lo = 0, hi = nums.length;
      while (lo < hi) {
          int mid = lo + (hi - lo) / 2;
          if (nums[mid] < target) lo = mid + 1;
          else hi = mid;
      }
      return lo;
  }

  Time: O(log n)  Space: O(1)

----------------------------------------------------------------
ALTERNATIVE: EXPLICIT FIRST/LAST HELPERS
----------------------------------------------------------------

  // Find first occurrence of target, or -1
  private int findFirst(int[] nums, int target) {
      int lo = 0, hi = nums.length - 1, result = -1;
      while (lo <= hi) {
          int mid = lo + (hi - lo) / 2;
          if (nums[mid] == target) {
              result = mid;
              hi = mid - 1;  // keep searching left
          } else if (nums[mid] < target) {
              lo = mid + 1;
          } else {
              hi = mid - 1;
          }
      }
      return result;
  }

  // Find last occurrence of target, or -1
  private int findLast(int[] nums, int target) {
      int lo = 0, hi = nums.length - 1, result = -1;
      while (lo <= hi) {
          int mid = lo + (hi - lo) / 2;
          if (nums[mid] == target) {
              result = mid;
              lo = mid + 1;  // keep searching right
          } else if (nums[mid] < target) {
              lo = mid + 1;
          } else {
              hi = mid - 1;
          }
      }
      return result;
  }

  public int[] searchRange(int[] nums, int target) {
      return new int[]{findFirst(nums, target), findLast(nums, target)};
  }

  Both approaches are O(log n). The lowerBound version is more concise
  and reuses the same function with a target+1 trick.

----------------------------------------------------------------
TRACED EXAMPLE: nums=[5,7,7,8,8,10], target=8
----------------------------------------------------------------

  FINDING FIRST (lowerBound for 8):
    lo=0, hi=6
    mid=3: nums[3]=8 >= 8  --> hi=3
    lo=0, hi=3
    mid=1: nums[1]=7 < 8   --> lo=2
    lo=2, hi=3
    mid=2: nums[2]=7 < 8   --> lo=3
    lo=3, hi=3  EXIT --> return 3

  FINDING LAST (lowerBound for 9, then -1):
    lo=0, hi=6
    mid=3: nums[3]=8 < 9   --> lo=4
    lo=4, hi=6
    mid=5: nums[5]=10 >= 9 --> hi=5
    lo=4, hi=5
    mid=4: nums[4]=8 < 9   --> lo=5
    lo=5, hi=5  EXIT --> return 5
    last = 5 - 1 = 4

  Answer: [3, 4] ✓

----------------------------------------------------------------
RELATED PROBLEM: SEARCH INSERT POSITION (LC 35)
----------------------------------------------------------------

  Given sorted array and target, return the index where target is
  or would be inserted.

  This is exactly lowerBound(nums, target).

  public int searchInsert(int[] nums, int target) {
      int lo = 0, hi = nums.length;
      while (lo < hi) {
          int mid = lo + (hi - lo) / 2;
          if (nums[mid] < target) lo = mid + 1;
          else hi = mid;
      }
      return lo;
  }

  Note: hi = nums.length (not length-1) because target might be
  inserted at the end.

----------------------------------------------------------------
RELATED PROBLEM: COUNT OCCURRENCES OF TARGET
----------------------------------------------------------------

  count = last - first + 1  (if target exists)
         = 0               (if target not found)

  Using lowerBound:
    int first = lowerBound(nums, target);
    int count = lowerBound(nums, target + 1) - first;

  count = (upper_bound position) - (lower_bound position)
        = number of elements equal to target.

----------------------------------------------------------------
RELATED PROBLEM: FIRST BAD VERSION (LC 278)
----------------------------------------------------------------

  The isBadVersion(version) API returns true for all versions >= first_bad.
  Find the first bad version.

  This is a direct application of lowerBound / Template 2 binary search.

  public int firstBadVersion(int n) {
      int lo = 1, hi = n;
      while (lo < hi) {
          int mid = lo + (hi - lo) / 2;
          if (isBadVersion(mid)) hi = mid;
          else lo = mid + 1;
      }
      return lo;
  }

  Pattern: predicate is isBadVersion(mid). First true = answer.

----------------------------------------------------------------
UNDERSTANDING LOWER_BOUND / UPPER_BOUND
----------------------------------------------------------------

  lower_bound(target): first position where element >= target
    - If target exists: points to first occurrence
    - If target absent: points to where it would be inserted

  upper_bound(target): first position where element > target
    - Always points to one past the last occurrence of target
    - If target absent: same as lower_bound (no gap between them)

  COUNT(target) = upper_bound(target) - lower_bound(target)

  Visualization for [5,7,7,8,8,10], target=7:
    Index:      0  1  2  3  4  5
    Values:     5  7  7  8  8 10
                   ^        ^
               lower=1   upper=3
    Count = 3 - 1 = 2 ✓ (two 7s)

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. Off-by-one in hi: use hi = nums.length (not length-1) for
     the boundary search templates.

  2. Forgetting to check nums[first] == target after lowerBound.
     lowerBound returns a valid index OR nums.length (target not found).

  3. Using lo <= hi loop for boundary search (Template 1 for finding boundary).
     This can cause lo to overshoot. Use lo < hi.

  4. Using target + 1 for upper bound: works for integers, not for
     floats or general objects. Be careful about data type.

  5. When finding last occurrence with explicit method: updating result
     in the wrong direction (setting result=mid then hi=mid-1 for last
     instead of lo=mid+1).

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why use lowerBound(target + 1) - 1 instead of a separate findLast?
  A: More concise and reuses the same function. The upper bound of target
     is the lower bound of target+1, so last position = upperBound - 1.

  Q: What does lowerBound return when target is not in the array?
  A: The index where target would be inserted to keep the array sorted.
     Equivalently, the first index where nums[i] >= target.

  Q: When does lowerBound return nums.length?
  A: When target is greater than all elements (insertion at end).

  Q: How do you adapt this for counting occurrences of any value?
  A: count = lowerBound(target + 1) - lowerBound(target).
     This is the O(log n) way using two binary searches.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Know both lowerBound and upperBound cold.
  - Explain: lowerBound is "first >= target", upperBound is "first > target".
  - Trace through the double-binary-search approach step by step.
  - Mention LC 35 as a simpler version of the same pattern.
  - The count-occurrences formula (upperBound - lowerBound) is useful to
    mention as a follow-up.
