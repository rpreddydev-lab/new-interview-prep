================================================================
  MAXIMUM SUM SUBARRAY PROBLEMS
  (Sliding Window + Kadane's Algorithm)
================================================================

Two related but distinct problems:
  1. Max sum subarray of FIXED size k  --> Sliding Window
  2. Max sum subarray of ANY size       --> Kadane's Algorithm

----------------------------------------------------------------
PART 1: MAX SUM SUBARRAY OF SIZE K (Sliding Window)
----------------------------------------------------------------

  Use a fixed-size window. Maintain running sum.

  Input:  nums = [2, 1, 5, 1, 3, 2], k = 3
  Output: 9

  Java:
    public int maxSumSubarrayK(int[] nums, int k) {
        int sum = 0;
        for (int i = 0; i < k; i++) sum += nums[i];
        int maxSum = sum;
        for (int i = k; i < nums.length; i++) {
            sum += nums[i] - nums[i - k];
            maxSum = Math.max(maxSum, sum);
        }
        return maxSum;
    }

  Time: O(n)  Space: O(1)

----------------------------------------------------------------
PART 2: MAXIMUM SUBARRAY (LC 53) -- Kadane's Algorithm
----------------------------------------------------------------

  Find the contiguous subarray (at least one element) with
  the largest sum.

  Input:  nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
  Output: 6  (subarray [4, -1, 2, 1])

  KADANE'S ALGORITHM:
    At each position, either:
      A) Extend the previous subarray (current + prev_sum), OR
      B) Start fresh from the current element (current alone)

    Whichever is larger becomes the new running sum.

  Java:
    public int maxSubArray(int[] nums) {
        int current = nums[0];  // max sum ending at current position
        int global = nums[0];   // overall max

        for (int i = 1; i < nums.length; i++) {
            current = Math.max(nums[i], current + nums[i]);
            global = Math.max(global, current);
        }
        return global;
    }

  Time: O(n)  Space: O(1)

  Key insight: `current = Math.max(nums[i], current + nums[i])`
    - If `current` is negative: restart from nums[i] (current = nums[i])
    - If `current` is non-negative: extend (current += nums[i])

----------------------------------------------------------------
TRACE THROUGH KADANE'S
----------------------------------------------------------------

  nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]

  i  nums[i]  current                    global
  0  -2       -2                         -2
  1   1       max(1, -2+1) = max(1,-1)=1  1
  2  -3       max(-3, 1-3) = max(-3,-2)= -2  1
  3   4       max(4, -2+4) = max(4,2) = 4   4
  4  -1       max(-1, 4-1) = max(-1,3) = 3  4
  5   2       max(2, 3+2)  = max(2,5)  = 5  5
  6   1       max(1, 5+1)  = max(1,6)  = 6  6
  7  -5       max(-5, 6-5) = max(-5,1) = 1  6
  8   4       max(4, 1+4)  = max(4,5)  = 5  6

  Answer: 6 (subarray [4,-1,2,1] from index 3 to 6)

----------------------------------------------------------------
VARIANT: RETURN SUBARRAY INDICES
----------------------------------------------------------------

  Track start, end, and tempStart.

  Java:
    public int[] maxSubArrayWithIndices(int[] nums) {
        int current = nums[0], global = nums[0];
        int start = 0, end = 0, tempStart = 0;

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > current + nums[i]) {
                current = nums[i];
                tempStart = i;  // potential new start
            } else {
                current = current + nums[i];
            }
            if (current > global) {
                global = current;
                start = tempStart;
                end = i;
            }
        }
        return new int[]{start, end, global};
    }

----------------------------------------------------------------
VARIANT: MAXIMUM CIRCULAR SUBARRAY SUM (LC 918)
----------------------------------------------------------------

  The subarray can wrap around the ends.

  Two cases:
    Case 1: Max subarray does NOT wrap  --> Kadane's as normal
    Case 2: Max subarray WRAPS         --> total_sum - min_subarray_sum
      (taking the "ends" = total minus the "middle minimum")

  Java:
    public int maxSubarraySumCircular(int[] nums) {
        int totalSum = 0;
        int maxSum = nums[0], curMax = 0;
        int minSum = nums[0], curMin = 0;

        for (int num : nums) {
            curMax = Math.max(curMax + num, num);
            maxSum = Math.max(maxSum, curMax);
            curMin = Math.min(curMin + num, num);
            minSum = Math.min(minSum, curMin);
            totalSum += num;
        }

        // If all negative, return maxSum (case 1 only)
        return maxSum > 0 ? Math.max(maxSum, totalSum - minSum) : maxSum;
    }

  Time: O(n)  Space: O(1)

  Why `maxSum > 0` check?
  If all elements are negative, totalSum - minSum would compute
  totalSum - totalSum = 0, which is wrong. The answer should be
  the least negative element (maxSum).

----------------------------------------------------------------
VARIANT: MAXIMUM SUM WITH NO ADJACENT ELEMENTS (LC 198)
  (House Robber -- DP, not sliding window, but related)
----------------------------------------------------------------

  Java:
    public int rob(int[] nums) {
        if (nums.length == 1) return nums[0];
        int prev2 = 0, prev1 = 0;
        for (int num : nums) {
            int curr = Math.max(prev1, prev2 + num);
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }

  Time: O(n)  Space: O(1)

----------------------------------------------------------------
VARIANT: MAXIMUM PRODUCT SUBARRAY (LC 152)
----------------------------------------------------------------

  Products can be negative. A negative * negative = positive!
  Track both max AND min product ending at each position.

  Java:
    public int maxProduct(int[] nums) {
        int maxProd = nums[0], minProd = nums[0], result = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int temp = maxProd;
            maxProd = Math.max(nums[i], Math.max(maxProd * nums[i], minProd * nums[i]));
            minProd = Math.min(nums[i], Math.min(temp * nums[i], minProd * nums[i]));
            result = Math.max(result, maxProd);
        }
        return result;
    }

  Time: O(n)  Space: O(1)

  Key: when a new negative number appears, max and min SWAP roles.
  So track both and take max(current, maxProd*num, minProd*num) each step.

----------------------------------------------------------------
COMPARISON TABLE
----------------------------------------------------------------

  Problem                    Approach       Time  Space
  -------                    --------       ----  -----
  Max sum, size k            Fixed window   O(n)  O(1)
  Max sum, any size          Kadane's       O(n)  O(1)
  Max circular sum           Kadane + total O(n)  O(1)
  Max product                Track min+max  O(n)  O(1)
  Max sum, no adjacent       DP (rob)       O(n)  O(1)

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why does Kadane's work? What's the invariant?
  A: `current` at index i = max subarray sum ending exactly at i.
     The recurrence `current = max(nums[i], current + nums[i])` is
     the optimal substructure: either start fresh or extend.
     `global` = max over all i of current[i].

  Q: What if all elements are negative?
  A: Return the maximum (least negative) element. Kadane's handles
     this correctly since we initialize with nums[0] and take max.

  Q: Why must the subarray be non-empty?
  A: The problem requires at least one element. That's why we
     initialize current = nums[0], not 0.

  Q: How do you find the actual subarray, not just the sum?
  A: Track tempStart (potential start index) and update start, end
     when global is updated. See the variant above.

  Q: What's the difference between LC 53 and LC 918?
  A: LC 53 = linear array, non-wrapping. LC 918 = circular array,
     subarray can include the "joint" (wrap from end to start).

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - For Kadane's: explain the two choices at each step
    (extend vs restart) and the invariant.
  - Trace through the example clearly.
  - Know the circular variant (LC 918) for follow-ups.
  - Mention that max product needs to track both max and min
    because negative * negative = positive.
