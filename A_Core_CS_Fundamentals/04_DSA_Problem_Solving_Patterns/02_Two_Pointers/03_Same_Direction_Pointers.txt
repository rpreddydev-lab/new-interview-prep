================================================================
  SAME DIRECTION TWO POINTERS
  (Slow/Fast Write Pointer)
================================================================

Both pointers start at the beginning and move right, but at
different speeds or under different conditions.
Used for in-place array manipulation and partition problems.

----------------------------------------------------------------
CORE PATTERN
----------------------------------------------------------------

  slow = 0  (write pointer / boundary of valid region)
  fast = 0  (read pointer / scanning pointer)

  for (fast = 0; fast < n; fast++) {
      if (condition is met for nums[fast]) {
          nums[slow] = nums[fast];
          slow++;
      }
  }
  // nums[0..slow-1] is the valid region

  The region [0, slow) holds valid elements.
  The region [slow, fast) holds invalid/skipped elements.

----------------------------------------------------------------
VISUALIZATION
----------------------------------------------------------------

  Remove all 3s from [3, 1, 2, 3, 4, 3]

  slow   fast   Array state
  ----   ----   -----------
   0      0     [3, 1, 2, 3, 4, 3]  nums[0]=3 skip, fast=1
   0      1     [3, 1, 2, 3, 4, 3]  nums[1]=1 write, slow=1, fast=2
   1      2     [1, 1, 2, 3, 4, 3]  nums[2]=2 write, slow=2, fast=3
   2      3     [1, 2, 2, 3, 4, 3]  nums[3]=3 skip, fast=4
   2      4     [1, 2, 2, 3, 4, 3]  nums[4]=4 write, slow=3, fast=5
   3      5     [1, 2, 4, 3, 4, 3]  nums[5]=3 skip, fast=6

  Return slow = 3.  Valid: [1, 2, 4]

----------------------------------------------------------------
PROBLEM 1: REMOVE ELEMENT (LC 27)
----------------------------------------------------------------

  Java:
    public int removeElement(int[] nums, int val) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != val) {
                nums[slow++] = nums[fast];
            }
        }
        return slow;
    }

  Time: O(n)  Space: O(1)

----------------------------------------------------------------
PROBLEM 2: REMOVE DUPLICATES FROM SORTED ARRAY (LC 26)
----------------------------------------------------------------

  Keep only the first occurrence of each element.
  Condition: write when nums[fast] != nums[slow - 1]

  Java:
    public int removeDuplicates(int[] nums) {
        if (nums.length == 0) return 0;
        int slow = 1;
        for (int fast = 1; fast < nums.length; fast++) {
            if (nums[fast] != nums[slow - 1]) {
                nums[slow++] = nums[fast];
            }
        }
        return slow;
    }

  Time: O(n)  Space: O(1)

  Variant: Allow at most k duplicates (LC 80, k=2):
    Condition: nums[fast] != nums[slow - k]
    Start slow = k

  Java (at most 2):
    public int removeDuplicates(int[] nums) {
        int slow = 2;
        for (int fast = 2; fast < nums.length; fast++) {
            if (nums[fast] != nums[slow - 2]) {
                nums[slow++] = nums[fast];
            }
        }
        return slow;
    }

----------------------------------------------------------------
PROBLEM 3: MOVE ZEROS (LC 283)
----------------------------------------------------------------

  Move all non-zero elements to front, maintain relative order.
  Zeros fill the tail.

  Java:
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) {
                nums[slow++] = nums[fast];
            }
        }
        while (slow < nums.length) {
            nums[slow++] = 0;
        }
    }

  Alternative (swap, preserves fewer writes):
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) {
                int tmp = nums[slow];
                nums[slow++] = nums[fast];
                nums[fast] = tmp;
            }
        }
    }

  Time: O(n)  Space: O(1)

----------------------------------------------------------------
PROBLEM 4: SORT COLORS / DUTCH NATIONAL FLAG (LC 75)
----------------------------------------------------------------

  Three-way partition: 0s, 1s, 2s in one pass.
  Three pointers: lo, mid, hi

  Invariant:
    [0..lo-1]  = all 0s
    [lo..mid-1] = all 1s
    [mid..hi]  = unprocessed
    [hi+1..n-1] = all 2s

  Java:
    public void sortColors(int[] nums) {
        int lo = 0, mid = 0, hi = nums.length - 1;
        while (mid <= hi) {
            if (nums[mid] == 0) {
                swap(nums, lo++, mid++);
            } else if (nums[mid] == 1) {
                mid++;
            } else {
                swap(nums, mid, hi--);
                // do NOT increment mid: need to check swapped element
            }
        }
    }
    private void swap(int[] a, int i, int j) {
        int t = a[i]; a[i] = a[j]; a[j] = t;
    }

  Time: O(n)  Space: O(1)

----------------------------------------------------------------
PROBLEM 5: SQUARES OF SORTED ARRAY (LC 977)
----------------------------------------------------------------

  [-4, -1, 0, 3, 10] --> [0, 1, 9, 16, 100]

  Key: largest squares come from either end (largest absolute values).
  Fill result from the BACK.

  Java:
    public int[] sortedSquares(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        int l = 0, r = n - 1, pos = n - 1;
        while (l <= r) {
            int lSq = nums[l] * nums[l];
            int rSq = nums[r] * nums[r];
            if (lSq > rSq) {
                result[pos--] = lSq;
                l++;
            } else {
                result[pos--] = rSq;
                r--;
            }
        }
        return result;
    }

  Time: O(n)  Space: O(n)

----------------------------------------------------------------
PATTERN GENERALIZATION
----------------------------------------------------------------

  Slow/fast write pointer works when:
    - You want to FILTER elements in-place
    - You want to PARTITION elements into groups
    - You need to maintain RELATIVE ORDER of kept elements

  General template:
    int slow = 0;
    for (int fast = 0; fast < n; fast++) {
        if (KEEP_CONDITION(nums[fast])) {
            nums[slow++] = nums[fast];
        }
    }

  KEEP_CONDITION examples:
    != val               --> remove element
    != nums[slow-1]      --> remove consecutive duplicates
    != 0                 --> move zeros
    > 0                  --> move negatives to end

----------------------------------------------------------------
COMPLEXITY
----------------------------------------------------------------

  All same-direction two pointer problems:
  Time:  O(n)
  Space: O(1) (no extra allocation)

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why use slow/fast instead of creating a new array?
  A: In-place modification saves O(n) space. Many problems
     explicitly require in-place, or the interviewer will ask
     for constant extra space.

  Q: What happens if we increment slow even when we skip?
  A: We lose track of the valid boundary. slow must only advance
     when we successfully write a valid element.

  Q: Can we use this for strings?
  A: Java strings are immutable, so we'd convert to char[],
     apply the same logic, and convert back.

  Q: Dutch Flag vs regular slow/fast -- when to use each?
  A: Use Dutch Flag (3-pointer) when there are 3 categories.
     Use 2-pointer slow/fast for 2 categories (keep / skip).

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Draw the invariant explicitly: "[0..slow) = valid, [slow..fast) = invalid"
  - For Dutch Flag, trace all three cases (0, 1, 2) in your example
  - Emphasize the in-place modification and O(1) space advantage
  - When asked about time complexity: "One pass, O(n), because each
    element is visited at most once by the fast pointer"
