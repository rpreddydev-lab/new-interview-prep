================================================================
  STRING DP PATTERN
================================================================

  String DP: dp[i][j] = answer for subproblem involving s1[0..i-1] and s2[0..j-1].
  Row i represents first i characters of s1, column j represents first j of s2.
  Base cases: dp[0][j] and dp[i][0] (empty string prefix).

  Core problems: LCS, Edit Distance, Longest Palindromic Subsequence,
  Shortest Common Supersequence, Interleaving String, Distinct Subsequences.

----------------------------------------------------------------
LONGEST COMMON SUBSEQUENCE (LC 1143)
----------------------------------------------------------------

  LCS of two strings. Not necessarily contiguous.

  dp[i][j] = length of LCS of s1[0..i-1] and s2[0..j-1].

  Transition:
    If s1[i-1] == s2[j-1]: dp[i][j] = dp[i-1][j-1] + 1
    Else:                   dp[i][j] = max(dp[i-1][j], dp[i][j-1])

  Java:
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i-1) == text2.charAt(j-1)) {
                    dp[i][j] = dp[i-1][j-1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
                }
            }
        }
        return dp[m][n];
    }

  Time: O(m*n)   Space: O(m*n) or O(min(m,n)) with rolling row.

  Example: text1="abcde", text2="ace"
    dp table (0-indexed rows=text1, cols=text2):
           ""  a  c  e
        ""  0  0  0  0
        a   0  1  1  1
        b   0  1  1  1
        c   0  1  2  2
        d   0  1  2  2
        e   0  1  2  3
    LCS = 3 ✓ ("ace")

EDIT DISTANCE (LC 72)
----------------------------------------------------------------

  Minimum operations (insert, delete, replace) to convert word1 to word2.

  dp[i][j] = min ops to convert word1[0..i-1] to word2[0..j-1].

  Base:
    dp[0][j] = j (insert j chars from empty)
    dp[i][0] = i (delete i chars to empty)

  Transition:
    If word1[i-1] == word2[j-1]: dp[i][j] = dp[i-1][j-1]  (no op needed)
    Else: dp[i][j] = 1 + min(
              dp[i-1][j],    // delete from word1
              dp[i][j-1],    // insert into word1
              dp[i-1][j-1]   // replace
          )

  Java:
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 0; i <= m; i++) dp[i][0] = i;
        for (int j = 0; j <= n; j++) dp[0][j] = j;
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i-1) == word2.charAt(j-1)) {
                    dp[i][j] = dp[i-1][j-1];
                } else {
                    dp[i][j] = 1 + Math.min(dp[i-1][j-1],
                                   Math.min(dp[i-1][j], dp[i][j-1]));
                }
            }
        }
        return dp[m][n];
    }

  Example: word1="horse", word2="ros"
           ""  r  o  s
        ""  0  1  2  3
        h   1  1  2  3
        o   2  2  1  2
        r   3  2  2  2
        s   4  3  3  2
        e   5  4  4  3
    Answer: 3 ✓ (horse→rorse→rose→ros)

LONGEST PALINDROMIC SUBSEQUENCE (LC 516)
----------------------------------------------------------------

  Length of longest palindromic subsequence.
  Key insight: LPS(s) = LCS(s, reverse(s)).

  OR: dp[i][j] = LPS length in s[i..j].

  Transition:
    If s[i] == s[j]: dp[i][j] = dp[i+1][j-1] + 2
    Else: dp[i][j] = max(dp[i+1][j], dp[i][j-1])

  Java:
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];
        for (int i = 0; i < n; i++) dp[i][i] = 1;  // single char
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i+1][j-1] + 2;
                } else {
                    dp[i][j] = Math.max(dp[i+1][j], dp[i][j-1]);
                }
            }
        }
        return dp[0][n-1];
    }

  Time: O(n^2)   Space: O(n^2)

  Example: s = "bbbab"
    LPS = 4 ("bbbb") ✓

SHORTEST COMMON SUPERSEQUENCE (LC 1092)
----------------------------------------------------------------

  SCS(s1, s2): shortest string containing both as subsequences.
  Length = len(s1) + len(s2) - LCS(s1, s2).

  To construct the actual supersequence: trace back dp table.
    At dp[i][j]:
      if chars match → add char, move diagonal
      if dp[i-1][j] > dp[i][j-1] → take s1[i], move up
      else → take s2[j], move left
    Append remaining chars.

  Java (length only):
    public int shortestCommonSupersequence(String str1, String str2) {
        // compute LCS length, then answer = m + n - lcs
        return str1.length() + str2.length() - lcs(str1, str2);
    }

INTERLEAVING STRING (LC 97)
----------------------------------------------------------------

  Is s3 formed by interleaving s1 and s2?

  dp[i][j] = can s3[0..i+j-1] be formed by interleaving s1[0..i-1] and s2[0..j-1].

  Transition:
    dp[i][j] = (dp[i-1][j] && s1[i-1]==s3[i+j-1])
            || (dp[i][j-1] && s2[j-1]==s3[i+j-1])

  Java:
    public boolean isInterleave(String s1, String s2, String s3) {
        int m = s1.length(), n = s2.length();
        if (m + n != s3.length()) return false;
        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;
        for (int i = 1; i <= m; i++) dp[i][0] = dp[i-1][0] && s1.charAt(i-1) == s3.charAt(i-1);
        for (int j = 1; j <= n; j++) dp[0][j] = dp[0][j-1] && s2.charAt(j-1) == s3.charAt(j-1);
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                dp[i][j] = (dp[i-1][j] && s1.charAt(i-1) == s3.charAt(i+j-1))
                         || (dp[i][j-1] && s2.charAt(j-1) == s3.charAt(i+j-1));
            }
        }
        return dp[m][n];
    }

DISTINCT SUBSEQUENCES (LC 115)
----------------------------------------------------------------

  Count distinct ways to form t from s by deleting characters.

  dp[i][j] = number of ways to form t[0..j-1] from s[0..i-1].

  Base:
    dp[i][0] = 1 (empty t is always a subsequence)
    dp[0][j] = 0 for j>0 (can't form non-empty t from empty s)

  Transition:
    If s[i-1] != t[j-1]: dp[i][j] = dp[i-1][j]
    If s[i-1] == t[j-1]: dp[i][j] = dp[i-1][j-1] + dp[i-1][j]
      (use this match) + (skip this match, look at earlier s)

  Java:
    public int numDistinct(String s, String t) {
        int m = s.length(), n = t.length();
        long[][] dp = new long[m + 1][n + 1];
        for (int i = 0; i <= m; i++) dp[i][0] = 1;
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                dp[i][j] = dp[i-1][j];
                if (s.charAt(i-1) == t.charAt(j-1)) {
                    dp[i][j] += dp[i-1][j-1];
                }
            }
        }
        return (int) dp[m][n];
    }

  Use long to avoid overflow (input can yield huge counts).

REGULAR EXPRESSION MATCHING (LC 10)
----------------------------------------------------------------

  '.' matches any single character. '*' matches zero or more of preceding element.

  dp[i][j] = true if s[0..i-1] matches p[0..j-1].

  Base:
    dp[0][0] = true
    dp[0][j] = dp[0][j-2] if p[j-1]=='*' (zero occurrences)

  Transition:
    If p[j-1]=='*':
      dp[i][j] = dp[i][j-2]  (zero occurrences of p[j-2])
              || (dp[i-1][j] && (s[i-1]==p[j-2] || p[j-2]=='.'))  (one+ occurrences)
    Else if p[j-1]=='.' || s[i-1]==p[j-1]:
      dp[i][j] = dp[i-1][j-1]
    Else:
      dp[i][j] = false

  Time: O(m*n)   Space: O(m*n)

----------------------------------------------------------------
COMMON MISTAKES
----------------------------------------------------------------

  1. String indexing: dp[i][j] refers to first i chars of s1 (index i-1 in string).
     When accessing: s1.charAt(i-1) (1-indexed dp, 0-indexed string).

  2. Edit Distance: forgetting to initialize dp[i][0]=i and dp[0][j]=j.

  3. LPS: must iterate by length (like interval DP), not simply i/j.

  4. Distinct Subsequences: missing dp[i][0]=1 initialization
     (empty t is always achievable).

  5. Regex: dp[0][j] for '*' patterns (can match zero).

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: What's the relationship between LPS and LCS?
  A: LPS(s) = LCS(s, reverse(s)). The palindrome must match from both ends,
     which is exactly matching s against its reverse.

  Q: In Edit Distance, what does each cell represent?
  A: dp[i][j] = min operations to transform word1[0..i-1] into word2[0..j-1].
     The three operations: delete (from word1), insert (into word1), replace.

  Q: Why does Distinct Subsequences overflow with int?
  A: For strings like "aaa...a" (m a's) matching t="aa", the count can reach
     C(m,2) which grows quickly. Use long to be safe.

  Q: How do you reconstruct the actual LCS string?
  A: Backtrack from dp[m][n]: if chars match, include that char and go diagonal.
     If dp[i-1][j] > dp[i][j-1], go up; else go left. Build string backwards.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - State clearly: "dp[i][j] = answer for s1[0..i-1] and s2[0..j-1]."
  - Always handle empty string base cases before the main nested loop.
  - For LCS-based problems, deriving SCS, LPS etc. from LCS shows depth.
  - Trace the dp table for a small example (3x3) to verify transitions.
  - Space reduction: rolling row — dp[i][j] only needs dp[i-1] row.
