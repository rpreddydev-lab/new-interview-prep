================================================================
  SUBSETS VIA BITMASK AND BITMASK ENUMERATION
================================================================

  For a set of n elements, there are 2^n subsets.
  Each subset can be represented by an n-bit integer (bitmask):
    bit i = 1 means element i is in the subset.
    bit i = 0 means element i is NOT in the subset.

  Enumerate all subsets: loop mask from 0 to (1 << n) - 1.

  Key: Feasible only when n ≤ 20-25 (2^20 ≈ 1M, 2^25 ≈ 33M).

----------------------------------------------------------------
LC 78 — SUBSETS (BITMASK APPROACH)
----------------------------------------------------------------

  Java:
    public List<List<Integer>> subsets(int[] nums) {
        int n = nums.length;
        List<List<Integer>> result = new ArrayList<>();
        for (int mask = 0; mask < (1 << n); mask++) {
            List<Integer> subset = new ArrayList<>();
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) subset.add(nums[i]);
            }
            result.add(subset);
        }
        return result;
    }

  Trace for nums=[1,2,3], n=3:
    mask=000(0): {} empty
    mask=001(1): {1}   (bit 0 set)
    mask=010(2): {2}   (bit 1 set)
    mask=011(3): {1,2} (bits 0,1 set)
    mask=100(4): {3}   (bit 2 set)
    mask=101(5): {1,3}
    mask=110(6): {2,3}
    mask=111(7): {1,2,3}

  Total: 8 = 2^3 subsets. ✓

  Time: O(2^n * n)   Space: O(2^n * n) for output.

----------------------------------------------------------------
BITMASK OPERATIONS FOR SUBSETS
----------------------------------------------------------------

  Operation                  Code                     Meaning
  -----------------------    ---------------------    -------------------------
  Include element i          mask | (1 << i)          add i to subset
  Exclude element i          mask & ~(1 << i)         remove i from subset
  Check if i is in mask      (mask >> i) & 1          test bit i
  Number of elements         Integer.bitCount(mask)   popcount
  Iterate subsets of mask    for sub=mask; sub>0; sub=(sub-1)&mask  see below

----------------------------------------------------------------
ENUMERATE ALL SUBSETS OF A GIVEN MASK
----------------------------------------------------------------

  Common in bitmask DP: iterate all subsets of a given mask.

  Java:
    for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
        // process 'sub' as a subset of 'mask'
    }
    // also process sub=0 (empty subset) after the loop

  Why it works: sub - 1 flips the lowest set bit of sub to 0 and sets all lower bits.
               AND with mask keeps only bits from the original mask.
               Guaranteed to visit every subset of mask exactly once.

  Time: O(3^n) to enumerate all subsets of all masks (sum = 3^n total).
        (By counting: each bit is "in mask but not sub", "in both", or "in neither" → 3 states)

  Example: mask=5 (101): subsets = 101(5), 100(4), 001(1), 000(0).
    sub=5: (5-1)&5=4&5=4.
    sub=4: (4-1)&5=3&5=1.
    sub=1: (1-1)&5=0&5=0 → exit loop.
    (Process sub=0 separately if needed.)

----------------------------------------------------------------
BITMASK DP — BEAUTIFUL ARRANGEMENT (LC 526)
----------------------------------------------------------------

  Numbers 1..n, find # permutations where for position i (1-indexed),
  perm[i] % i == 0 OR i % perm[i] == 0.

  State: dp[mask] = number of valid arrangements using exactly the elements in mask.
  Position = Integer.bitCount(mask) (1-indexed).

  Java:
    public int countArrangement(int n) {
        int[] dp = new int[1 << n];
        dp[0] = 1;
        for (int mask = 0; mask < (1 << n); mask++) {
            int pos = Integer.bitCount(mask);  // current position (1-indexed)
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 0) {  // element i+1 not yet used
                    int num = i + 1;
                    if (num % (pos + 1) == 0 || (pos + 1) % num == 0) {
                        dp[mask | (1 << i)] += dp[mask];
                    }
                }
            }
        }
        return dp[(1 << n) - 1];
    }

  Time: O(2^n * n)  Space: O(2^n)

----------------------------------------------------------------
BITMASK DP — TSP (MINIMUM COST VISITING ALL NODES)
----------------------------------------------------------------

  dp[mask][i] = min cost to visit all nodes in mask, ending at node i.
  Transition: dp[mask | (1<<j)][j] = min(dp[mask][i] + cost[i][j]) for all j not in mask.

  Java skeleton:
    int[][] dp = new int[1 << n][n];
    for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
    dp[1][0] = 0;  // start at node 0
    for (int mask = 1; mask < (1 << n); mask++) {
        for (int i = 0; i < n; i++) {
            if ((mask >> i & 1) == 0 || dp[mask][i] == Integer.MAX_VALUE/2) continue;
            for (int j = 0; j < n; j++) {
                if ((mask >> j & 1) == 0) {
                    int newMask = mask | (1 << j);
                    dp[newMask][j] = Math.min(dp[newMask][j], dp[mask][i] + cost[i][j]);
                }
            }
        }
    }
    int ans = Integer.MAX_VALUE;
    int fullMask = (1 << n) - 1;
    for (int i = 0; i < n; i++) {
        ans = Math.min(ans, dp[fullMask][i] + cost[i][0]);  // return to start
    }

  Time: O(2^n * n²)   Space: O(2^n * n)
  Feasible for n ≤ 20.

LC 1986 — MINIMUM NUMBER OF WORK SESSIONS (BITMASK DP)
----------------------------------------------------------------

  tasks[] with durations. A session can hold tasks summing ≤ sessionTime.
  Find minimum sessions to finish all tasks.

  State: dp[mask] = min sessions to complete tasks in mask.

  Java:
    public int minSessions(int[] tasks, int sessionTime) {
        int n = tasks.length;
        int[] dp = new int[1 << n];
        int[] time = new int[1 << n];  // remaining time in last session
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 1; time[0] = sessionTime;
        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) continue;  // already done
                int newMask = mask | (1 << i);
                if (time[mask] >= tasks[i]) {
                    // fit in current session
                    if (dp[mask] < dp[newMask] ||
                        (dp[mask] == dp[newMask] && time[mask]-tasks[i] > time[newMask])) {
                        dp[newMask] = dp[mask];
                        time[newMask] = time[mask] - tasks[i];
                    }
                } else {
                    // need new session
                    if (dp[mask] + 1 < dp[newMask]) {
                        dp[newMask] = dp[mask] + 1;
                        time[newMask] = sessionTime - tasks[i];
                    }
                }
            }
        }
        return dp[(1 << n) - 1];
    }

----------------------------------------------------------------
BITMASK CONSTRAINTS REFERENCE
----------------------------------------------------------------

  n       2^n            Feasibility
  -----   ----------     ------------------------------------------
  ≤ 10    ≤ 1024         Always fast
  ≤ 15    ≤ 32768        Fast
  ≤ 20    ≤ 1,048,576    Feasible (O(2^n * n))
  ≤ 22    ≤ 4,194,304    Tight (O(2^n * n²) might TLE)
  ≤ 30    ≤ 10^9         int mask fits, but 2^30 is too large for most DPs
  ≤ 64    ≤ 2^64         long mask, only O(n) per mask ops feasible

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why is bitmask enumeration of subsets O(3^n) total?
  A: 3^n = sum over all masks of (number of subsets of mask).
     Each element is in exactly 3 states: not in mask, in mask but not subset, in both.

  Q: Can we use bitmask for large n?
  A: Generally n ≤ 20. For n ≤ 64, can use long, but time complexity must be O(n) per state.

  Q: What distinguishes bitmask DP from bitmask backtracking?
  A: DP caches results per state (mask) to avoid recomputation.
     Backtracking explores paths without caching.

  Q: How to iterate subsets of a mask?
  A: `for (int sub = mask; sub > 0; sub = (sub-1) & mask)`, then handle sub=0 if needed.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - Explain: "mask bit i = 1 means element i is selected."
  - For LC 78 bitmask: show the mapping between mask value and subset contents.
  - For TSP: emphasize dp[mask][i] = "visited exactly 'mask' cities, currently at i."
  - Complexity check: always mention 2^n or 3^n and state the max n constraint.
  - Subset enumeration loop `(sub-1)&mask` is a classic interview trick — practice explaining it.
