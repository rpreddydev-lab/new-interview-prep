================================================================
  PALINDROME PARTITIONING (LC 131, 132)
================================================================

  LC 131: Given a string s, partition it so that every substring is a palindrome.
          Return all possible palindrome partitioning.

  LC 132: Return the minimum number of cuts for palindrome partitioning.

  Input (LC 131):  s = "aab"
  Output: [["a","a","b"],["aa","b"]]

  Input (LC 132):  s = "aab"
  Output: 1 (one cut: "aa" | "b")

----------------------------------------------------------------
LC 131: BACKTRACKING SOLUTION
----------------------------------------------------------------

  At each start position, try all possible end positions.
  If s[start..end] is a palindrome, recurse from end+1.
  When start == s.length(), add current partition to result.

  Java:
    public List<List<String>> partition(String s) {
        List<List<String>> result = new ArrayList<>();
        backtrack(s, 0, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(String s, int start, List<String> current, List<List<String>> result) {
        if (start == s.length()) {
            result.add(new ArrayList<>(current));  // full partition found
            return;
        }
        for (int end = start; end < s.length(); end++) {
            if (isPalindrome(s, start, end)) {
                current.add(s.substring(start, end + 1));  // choose
                backtrack(s, end + 1, current, result);     // explore from end+1
                current.remove(current.size() - 1);         // un-choose
            }
        }
    }

    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left++) != s.charAt(right--)) return false;
        }
        return true;
    }

  Time: O(n * 2^n)   -- 2^n subsets of cut positions, each palindrome check O(n)
  Space: O(n) recursion depth

----------------------------------------------------------------
TRACED EXAMPLE: s = "aab"
----------------------------------------------------------------

  backtrack(0, []):
    end=0: "a" isPalin → current=["a"]
      backtrack(1, ["a"]):
        end=1: "a" isPalin → current=["a","a"]
          backtrack(2, ["a","a"]):
            end=2: "b" isPalin → current=["a","a","b"]
              backtrack(3, ["a","a","b"]): start==3 → ADD ["a","a","b"]
            remove "b". current=["a","a"]
          return
          remove "a". current=["a"]
        end=2: "ab" → not palindrome. skip.
        return
        remove "a". current=[]
    end=1: "aa" isPalin → current=["aa"]
      backtrack(2, ["aa"]):
        end=2: "b" isPalin → current=["aa","b"]
          backtrack(3): ADD ["aa","b"]
        remove "b". current=["aa"]
      return
      remove "aa". current=[]
    end=2: "aab" → not palindrome. skip.

  Result: [["a","a","b"],["aa","b"]] ✓

----------------------------------------------------------------
OPTIMIZATION: PRECOMPUTE PALINDROME TABLE (DP)
----------------------------------------------------------------

  Instead of checking palindrome each time (O(n)), precompute a 2D boolean table.
  dp[i][j] = true if s[i..j] is a palindrome.

  dp[i][i] = true (single char)
  dp[i][i+1] = s[i] == s[i+1] (two chars)
  dp[i][j] = dp[i+1][j-1] && s[i] == s[j]

  Java:
    public List<List<String>> partition(String s) {
        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        for (int i = n-1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                dp[i][j] = (s.charAt(i) == s.charAt(j)) &&
                            (j - i <= 2 || dp[i+1][j-1]);
            }
        }

        List<List<String>> result = new ArrayList<>();
        backtrack(s, 0, dp, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(String s, int start, boolean[][] dp,
                            List<String> current, List<List<String>> result) {
        if (start == s.length()) {
            result.add(new ArrayList<>(current));
            return;
        }
        for (int end = start; end < s.length(); end++) {
            if (dp[start][end]) {
                current.add(s.substring(start, end + 1));
                backtrack(s, end + 1, dp, current, result);
                current.remove(current.size() - 1);
            }
        }
    }

  Time: O(n^2) to build dp, then O(n * 2^n) for backtracking.
  Space: O(n^2) for dp table.

  DP recurrence: dp[i][j] = s[i]==s[j] AND (j-i<=2 OR dp[i+1][j-1])
    j-i<=2 handles: single char (j==i), two chars (j==i+1), three chars (j==i+2).

----------------------------------------------------------------
DP TABLE EXAMPLE: s = "aab"
----------------------------------------------------------------

  Indices:   0='a', 1='a', 2='b'

  Fill bottom-up (i from n-1 to 0):
    i=2: dp[2][2] = ('b'=='b') && (0<=2) = T
    i=1: dp[1][1] = T
         dp[1][2] = ('a'=='b') = F
    i=0: dp[0][0] = T
         dp[0][1] = ('a'=='a') && (1-0<=2) = T
         dp[0][2] = ('a'=='b') = F

  Table:
           0    1    2
        0[ T    T    F ]
        1[ -    T    F ]
        2[ -    -    T ]

  Palindromes: "a"(0,0), "a"(1,1), "b"(2,2), "aa"(0,1) ✓

----------------------------------------------------------------
LC 132: MINIMUM CUTS (DP)
----------------------------------------------------------------

  cuts[i] = minimum cuts needed for s[0..i].
  If s[0..i] is a palindrome → cuts[i] = 0 (no cut needed).
  Otherwise: cuts[i] = min(cuts[j-1] + 1) for all j where s[j..i] is palindrome.

  Java:
    public int minCut(String s) {
        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        for (int i = n-1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                dp[i][j] = (s.charAt(i) == s.charAt(j)) && (j - i <= 2 || dp[i+1][j-1]);
            }
        }

        int[] cuts = new int[n];
        for (int i = 0; i < n; i++) {
            if (dp[0][i]) {
                cuts[i] = 0;  // entire s[0..i] is a palindrome, no cut needed
            } else {
                cuts[i] = i;  // worst case: cut every character
                for (int j = 1; j <= i; j++) {
                    if (dp[j][i]) {
                        cuts[i] = Math.min(cuts[i], cuts[j-1] + 1);
                    }
                }
            }
        }
        return cuts[n-1];
    }

  Time: O(n^2)   Space: O(n^2) for dp table, O(n) for cuts array.

  Example: s = "aab"
    cuts[0]='a': dp[0][0]=T → cuts[0]=0
    cuts[1]='aa': dp[0][1]=T → cuts[1]=0
    cuts[2]='aab': dp[0][2]=F → init cuts[2]=2
      j=1: dp[1][2]? 'a'=='b'? F → skip
      j=2: dp[2][2]=T → cuts[2]=min(2, cuts[1]+1)=min(2,1)=1
    return cuts[2]=1 ✓

----------------------------------------------------------------
INTERVIEW Q&A
----------------------------------------------------------------

  Q: Why fill the DP table from i = n-1 downward?
  A: dp[i][j] depends on dp[i+1][j-1] (inner substring), so inner positions
     must be computed before outer. i from n-1 to 0 ensures dp[i+1] is ready.

  Q: What's the time complexity of the backtracking solution?
  A: O(n * 2^n) — there are 2^(n-1) possible ways to insert cuts (each gap
     between characters is either cut or not), and each partition takes O(n)
     to copy to result.

  Q: How does the DP precomputation improve it?
  A: The palindrome check in the loop drops from O(n) to O(1), reducing the
     constant factor but not the exponential output size.

  Q: Why is `j - i <= 2` a base case in the DP?
  A: For length 1 (j==i) and 2 (j==i+1): single char always palindrome;
     two chars: check s[i]==s[j] only.
     For length 3 (j==i+2): dp[i+1][j-1] = dp[i+1][i+1] = true (single char),
     so checking s[i]==s[j] is sufficient. The `<=2` covers all these safely.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------

  - State the DP precomputation optimization before the interviewer asks.
  - Draw the DP table fill order (i decreasing, j increasing).
  - For LC 132, clarify: "minimum cuts" means minimum number of cut operations,
    not segments (segments = cuts + 1).
  - Always handle edge case: if s is already a palindrome → answer is 0.
