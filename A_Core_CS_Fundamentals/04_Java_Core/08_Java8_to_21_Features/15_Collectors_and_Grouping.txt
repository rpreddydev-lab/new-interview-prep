JAVA COLLECTORS AND GROUPING
==============================

COLLECTORS OVERVIEW
---------------------
  Collectors is the companion class to Stream.collect() — it provides factory methods
  for common mutable reduction operations. A Collector<T,A,R> specifies:
  - T: type of input elements
  - A: type of accumulator (intermediate result)
  - R: type of result

  Stream.collect(Collector) is the terminal operation that uses it.

BASIC COLLECTORS
-----------------
  // Collecting to a specific collection:
  List<String>  list  = stream.collect(Collectors.toList());        // mutable list (old)
  List<String>  list2 = stream.toList();                            // unmodifiable (Java 16+)
  Set<String>   set   = stream.collect(Collectors.toSet());         // mutable set
  List<String>  ulist = stream.collect(Collectors.toUnmodifiableList()); // unmodifiable

  // toCollection — specify the collection type:
  LinkedList<String> linked = stream.collect(Collectors.toCollection(LinkedList::new));
  TreeSet<String>    sorted = stream.collect(Collectors.toCollection(TreeSet::new));

  // Counting:
  long count = stream.collect(Collectors.counting());
  // Equivalent to stream.count() — useful as a downstream collector

  // Joining strings:
  String joined = stream.collect(Collectors.joining());           // "abcdef"
  String csv    = stream.collect(Collectors.joining(", "));       // "a, b, c"
  String full   = stream.collect(Collectors.joining(", ", "[", "]")); // "[a, b, c]"

MAPPING TO MAP
---------------
  // toMap — must handle duplicate keys or provide merge function:
  Map<String, Integer> map = names.stream()
      .collect(Collectors.toMap(
          Function.identity(),     // key: the name itself
          String::length           // value: its length
      ));

  // Duplicate key — must provide merge function or throw:
  // Default toMap throws IllegalStateException on duplicate keys
  Map<String, Integer> merged = names.stream()
      .collect(Collectors.toMap(
          Function.identity(),
          String::length,
          (existing, replacement) -> existing  // keep first on duplicate
      ));

  // With specific map type:
  LinkedHashMap<String, Integer> linked = names.stream()
      .collect(Collectors.toMap(
          Function.identity(),
          String::length,
          (a, b) -> a,
          LinkedHashMap::new
      ));

GROUPING AND PARTITIONING
--------------------------
  // groupingBy — groups elements into a Map<K, List<T>>:
  Map<Integer, List<String>> byLength = names.stream()
      .collect(Collectors.groupingBy(String::length));
  // {"Alice"=[5, "Belle"], "Bob"=[3, "Dan"], ...}  — wait, actually groups by length int:
  // {5=["Alice","Belle"], 3=["Bob","Dan"], 7=["Charlie"]}

  // groupingBy with downstream collector:
  Map<Integer, Long> countByLength = names.stream()
      .collect(Collectors.groupingBy(String::length, Collectors.counting()));

  Map<Integer, Set<String>> setsByLength = names.stream()
      .collect(Collectors.groupingBy(String::length, Collectors.toSet()));

  Map<Department, Double> avgSalaryByDept = employees.stream()
      .collect(Collectors.groupingBy(
          Employee::getDepartment,
          Collectors.averagingDouble(Employee::getSalary)
      ));

  // Multi-level grouping:
  Map<String, Map<String, List<Employee>>> byDeptAndCity = employees.stream()
      .collect(Collectors.groupingBy(
          Employee::getDepartment,
          Collectors.groupingBy(Employee::getCity)
      ));

  // partitioningBy — groups by boolean predicate into Map<Boolean, List<T>>:
  Map<Boolean, List<String>> partitioned = names.stream()
      .collect(Collectors.partitioningBy(n -> n.length() > 4));
  // {true=["Alice","Charlie"], false=["Bob","Dan"]}

  // partitioningBy with downstream:
  Map<Boolean, Long> counts = names.stream()
      .collect(Collectors.partitioningBy(n -> n.length() > 4, Collectors.counting()));

SUMMARIZING COLLECTORS
-----------------------
  // summarizingInt/Long/Double — returns statistics:
  IntSummaryStatistics stats = numbers.stream()
      .collect(Collectors.summarizingInt(Integer::intValue));
  stats.getCount();    // count
  stats.getSum();      // sum
  stats.getMin();      // min
  stats.getMax();      // max
  stats.getAverage();  // average

  // Convenience:
  double avg = numbers.stream().collect(Collectors.averagingInt(Integer::intValue));
  int    sum = numbers.stream().collect(Collectors.summingInt(Integer::intValue));
  Optional<Integer> min = numbers.stream().collect(Collectors.minBy(Integer::compare));
  Optional<Integer> max = numbers.stream().collect(Collectors.maxBy(Integer::compare));

REDUCING COLLECTOR
-------------------
  // Collectors.reducing — general-purpose reduction as a downstream:
  Map<String, Optional<Employee>> highestPaidByDept = employees.stream()
      .collect(Collectors.groupingBy(
          Employee::getDepartment,
          Collectors.reducing((e1, e2) -> e1.getSalary() >= e2.getSalary() ? e1 : e2)
      ));

MAPPING AND FLAT MAPPING DOWNSTREAM
-------------------------------------
  // Collectors.mapping — transform before collecting downstream:
  Map<Integer, List<String>> upperByLength = names.stream()
      .collect(Collectors.groupingBy(
          String::length,
          Collectors.mapping(String::toUpperCase, Collectors.toList())
      ));

  // Collectors.flatMapping (Java 9+) — flatten before collecting:
  Map<String, List<String>> orderItemsByUser = orders.stream()
      .collect(Collectors.groupingBy(
          Order::getUserId,
          Collectors.flatMapping(
              o -> o.getItems().stream(),
              Collectors.toList()
          )
      ));

  // Collectors.filtering (Java 9+) — filter within group:
  Map<Integer, List<String>> longNamesByLength = names.stream()
      .collect(Collectors.groupingBy(
          String::length,
          Collectors.filtering(s -> s.contains("a"), Collectors.toList())
      ));

COLLECTORS.TEEING (JAVA 12)
-----------------------------
  Collects into two collectors simultaneously and merges results.
  Useful for computing two aggregates over the same stream in one pass:

  // Min and max in one pass:
  record MinMax(Optional<Integer> min, Optional<Integer> max) {}
  MinMax result = Stream.of(3,1,4,1,5,9,2,6)
      .collect(Collectors.teeing(
          Collectors.minBy(Integer::compare),
          Collectors.maxBy(Integer::compare),
          MinMax::new
      ));

  // Count and sum in one pass:
  record CountSum(long count, long sum) {}
  CountSum cs = numbers.stream()
      .collect(Collectors.teeing(
          Collectors.counting(),
          Collectors.summingLong(Long::longValue),
          CountSum::new
      ));

COMMON INTERVIEW QUESTIONS
---------------------------
Q: What is the difference between groupingBy and partitioningBy?
A: groupingBy(Function<T,K>) groups elements by an arbitrary key of any type, returning
   Map<K, List<T>>. The key can be any derived value (String, Integer, enum, etc.), and
   there can be any number of groups. partitioningBy(Predicate<T>) groups elements by
   a boolean predicate, returning Map<Boolean, List<T>> — always exactly two groups
   (true and false). partitioningBy is a specialization of groupingBy for the boolean case
   and guarantees both keys (true and false) are always present in the result.

Q: What is a downstream collector?
A: A downstream collector is a second Collector passed to groupingBy, partitioningBy,
   or teeing to process the elements within each group or partition. Instead of getting
   List<T> per group, you can get count, sum, average, set, or any other collection/reduction.
   Example: groupingBy(Employee::getDept, Collectors.counting()) returns Map<Dept, Long>
   with the count of employees per department.

Q: What does Collectors.teeing() do and when would you use it?
A: teeing(c1, c2, mergeFunction) collects the stream into two collectors simultaneously
   and then merges their results using the merge function — all in one pass over the data.
   Use it when you need two different aggregate operations over the same elements and don't
   want to iterate the stream twice. Common use cases: computing min and max together,
   count and sum, or separate filtering results merged into a single structure.

Q: How do you collect to an unmodifiable list and what options exist?
A: (1) Collectors.toUnmodifiableList() — Java 10+, collect to unmodifiable list.
   (2) Stream.toList() — Java 16+, shorter syntax. (3) List.copyOf(stream.collect(...))
   — explicit copy. Note: Collectors.toList() returns a modifiable list; never assume
   the type of list returned (could be ArrayList in practice, but not guaranteed by spec).
   Use toUnmodifiableList() or toList() when immutability is required.
