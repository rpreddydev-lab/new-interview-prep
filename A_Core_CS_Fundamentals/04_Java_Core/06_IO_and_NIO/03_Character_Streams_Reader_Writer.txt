CHARACTER STREAMS: Reader AND Writer
======================================

WHY CHARACTER STREAMS?
------------------------
  Byte streams work with raw bytes (0–255).
  Text characters require ENCODING: mapping between Unicode code points and byte sequences.
  Character streams (Reader/Writer) handle this encoding/decoding automatically.

  - Reader converts bytes → chars using a specified or default charset
  - Writer converts chars → bytes using a specified or default charset

  Using byte streams for text:
    FileInputStream fis = new FileInputStream("text.txt"); // ❌ reads raw bytes, ignores encoding

  Using character streams:
    Reader r = new InputStreamReader(new FileInputStream("text.txt"), StandardCharsets.UTF_8);
    // ✅ bytes automatically decoded to chars using UTF-8

Reader — READING CHARACTERS
------------------------------
  Reader is the abstract base class for all character input streams.
  Core methods:

    int read()                     — read 1 char, returns it as int (0–65535), or -1 at EOF
    int read(char[] cbuf)          — read up to cbuf.length chars
    int read(char[] cbuf, int off, int len) — read up to len chars starting at off
    long skip(long n)              — skip n characters
    boolean ready()                — true if stream ready to read without blocking
    void close()                   — release resources
    void mark(int readAheadLimit)  — mark position (if markSupported())
    void reset()                   — reset to last marked position

  Read loop:
    try (Reader reader = new FileReader("file.txt", StandardCharsets.UTF_8)) {
        char[] buffer = new char[1024];
        int charsRead;
        while ((charsRead = reader.read(buffer)) != -1) {
            String chunk = new String(buffer, 0, charsRead);
            process(chunk);
        }
    }

Writer — WRITING CHARACTERS
------------------------------
  Writer is the abstract base class for all character output streams.
  Core methods:

    void write(int c)                         — write 1 char
    void write(char[] cbuf)                   — write entire char array
    void write(char[] cbuf, int off, int len) — write len chars starting at off
    void write(String str)                    — write a String
    void write(String str, int off, int len)  — write portion of a String
    Writer append(CharSequence csq)           — append (returns this, for chaining)
    void flush()                              — flush buffered data
    void close()                              — flush and release

FileReader / FileWriter
-------------------------
  Convenience classes for reading/writing files as text.
  WARNING: FileReader and FileWriter use the PLATFORM DEFAULT charset if no charset is specified.
  This makes them non-portable. Always specify a charset explicitly.

  // ❌ Platform-dependent:
  Reader r = new FileReader("file.txt");
  Writer w = new FileWriter("out.txt");

  // ✅ Explicit charset (Java 11+):
  Reader r = new FileReader("file.txt", StandardCharsets.UTF_8);
  Writer w = new FileWriter("out.txt", StandardCharsets.UTF_8);

  // ✅ Or via InputStreamReader (works in all Java 7+ versions):
  Reader r = new InputStreamReader(new FileInputStream("file.txt"), StandardCharsets.UTF_8);
  Writer w = new OutputStreamWriter(new FileOutputStream("out.txt"), StandardCharsets.UTF_8);

  // FileWriter append mode:
  Writer w = new FileWriter("log.txt", StandardCharsets.UTF_8, true); // append = true

InputStreamReader / OutputStreamWriter (BRIDGE CLASSES)
---------------------------------------------------------
  Convert between byte streams and character streams.
  They are the bridge between the byte world and the character world.

  // Read a file: bytes → chars (with explicit charset):
  try (InputStreamReader isr = new InputStreamReader(
          new FileInputStream("utf8.txt"), StandardCharsets.UTF_8);
       BufferedReader br = new BufferedReader(isr)) {

      String line;
      while ((line = br.readLine()) != null) {
          System.out.println(line);
      }
  }

  // Write to a file: chars → bytes (with explicit charset):
  try (OutputStreamWriter osw = new OutputStreamWriter(
          new FileOutputStream("output.txt"), StandardCharsets.UTF_8);
       BufferedWriter bw = new BufferedWriter(osw)) {

      bw.write("Hello, World!");
      bw.newLine();  // writes OS-appropriate line separator
  }

BufferedReader
----------------
  Wraps any Reader with a buffer. Key addition: readLine() method.

  try (BufferedReader br = new BufferedReader(
          new InputStreamReader(new FileInputStream("file.txt"), StandardCharsets.UTF_8))) {

      String line;
      while ((line = br.readLine()) != null) {  // returns null at EOF (not "-1")
          System.out.println(line);
      }
  }

  // Java 8+: stream of lines
  try (BufferedReader br = Files.newBufferedReader(Path.of("file.txt"), StandardCharsets.UTF_8)) {
      br.lines()
        .filter(line -> !line.isEmpty())
        .map(String::trim)
        .forEach(System.out::println);
  }

BufferedWriter
----------------
  Wraps any Writer with a buffer. Key addition: newLine() method.
  newLine() writes System.lineSeparator() — OS-appropriate (\n on Unix, \r\n on Windows).

  try (BufferedWriter bw = Files.newBufferedWriter(Path.of("output.txt"), StandardCharsets.UTF_8)) {
      bw.write("Line 1");
      bw.newLine();
      bw.write("Line 2");
      bw.newLine();
  }

PrintWriter
-------------
  Character-based output with formatted printing. Similar to PrintStream but for text.
  Does NOT throw IOException on write operations — errors set an internal error flag.

  PrintWriter pw = new PrintWriter(
      new BufferedWriter(new FileWriter("report.txt", StandardCharsets.UTF_8)));
  pw.println("Report generated: " + LocalDate.now());
  pw.printf("Total: %,.2f%n", totalAmount);
  pw.printf("Count: %d%n", count);
  pw.flush();
  pw.close();

StringReader / StringWriter
------------------------------
  In-memory character streams — read from/write to a String in memory.
  Useful for testing and buffering text content.

  // StringWriter — collect characters into a String:
  StringWriter sw = new StringWriter();
  sw.write("Hello");
  sw.write(", World!");
  String result = sw.toString();   // "Hello, World!"

  // StringReader — read characters from a String:
  StringReader sr = new StringReader("Hello, World!");
  BufferedReader br = new BufferedReader(sr);
  String line = br.readLine();  // "Hello, World!"

COMPARISON: Byte Streams vs Character Streams
-----------------------------------------------
  Aspect              | Byte Streams              | Character Streams
  --------------------|---------------------------|---------------------------
  Base classes        | InputStream / OutputStream| Reader / Writer
  Unit                | byte (8-bit)              | char (16-bit Unicode)
  Encoding            | None — raw bytes          | Automatic (charset)
  Use for             | Binary data               | Text data
  readLine()          | No                        | Yes (BufferedReader)
  printf/println      | PrintStream               | PrintWriter
  Bridge to bytes     | N/A                       | InputStreamReader / OutputStreamWriter

COMMON INTERVIEW QUESTIONS
---------------------------
Q: What is the difference between FileInputStream and FileReader?
A: FileInputStream reads raw bytes from a file — it has no knowledge of character encoding.
   FileReader reads characters from a file, automatically decoding bytes to chars using a
   charset (platform default if not specified; always specify explicitly for portability).
   Use FileReader (wrapped in BufferedReader) for text files, FileInputStream for binary files.

Q: What is InputStreamReader and why is it needed?
A: InputStreamReader is a bridge between byte streams and character streams. It wraps any
   InputStream and decodes bytes to characters using a specified charset.
   It's needed because network connections, sockets, and process streams provide byte streams
   (InputStream), but when you need to process text from those sources, you need a Reader.
   new BufferedReader(new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8))
   is a classic pattern for reading text from a socket.

Q: What does BufferedReader.readLine() return at end of stream?
A: null (not -1). This is unlike InputStream.read() which returns -1 at EOF.
   The standard loop is: String line; while ((line = br.readLine()) != null) { ... }.
   readLine() strips the newline characters (\n, \r, or \r\n) and returns just the content.
