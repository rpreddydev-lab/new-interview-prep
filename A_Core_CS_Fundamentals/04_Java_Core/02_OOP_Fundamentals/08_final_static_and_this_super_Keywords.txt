final, static, this, AND super KEYWORDS
=========================================

THE `final` KEYWORD
--------------------
`final` means "cannot be changed/extended/overridden."

1. final VARIABLE
   - Cannot be reassigned after initialization.
   - Local final variable: must be assigned exactly once before use.
   - Instance final field: must be assigned in constructor (or field declaration).
   - Static final field: a constant — by convention UPPER_SNAKE_CASE.

   final int MAX = 100;
   MAX = 200;  // compile error

   public static final double PI = 3.14159;  // constant

   Blank final field (assigned in constructor):
     class Circle {
         private final double radius;
         Circle(double r) { this.radius = r; }  // must assign in constructor
     }

   NOTE: final on an OBJECT REFERENCE means the reference can't be reassigned,
   but the OBJECT itself can still be mutated:
     final List<String> list = new ArrayList<>();
     list.add("ok");   // fine — mutating the object
     list = new ArrayList<>();  // compile error — reassigning the reference

2. final METHOD
   - Cannot be overridden by subclasses.
   - Used when you need guaranteed behavior (e.g., clone, getClass).
   - All private methods are implicitly final (can't override what you can't see).

   public final void critical() { ... }

3. final CLASS
   - Cannot be subclassed.
   - Used for security and immutability guarantees.
   - Examples: String, Integer, Double, System.
   public final class String { ... }

THE `static` KEYWORD
---------------------
`static` means "belongs to the class, not to any instance."

1. static FIELD
   - Single copy shared across ALL instances.
   - Lives in Metaspace (class memory), not on the heap per-object.
   - Convention: static final = constant (UPPER_SNAKE_CASE).

   class Counter {
       static int count = 0;  // shared
       Counter() { count++; }
   }

2. static METHOD
   - Called on the class, not on an instance: ClassName.method()
   - Cannot use `this` or `super`.
   - Cannot access instance fields/methods directly.
   - Common for utility/factory methods: Math.abs(), Integer.parseInt()

3. static BLOCK (static initializer)
   - Runs once when the class is first loaded by the ClassLoader.
   - Used for complex static field initialization.

   class Config {
       static final Map<String, String> SETTINGS;
       static {
           SETTINGS = new HashMap<>();
           SETTINGS.put("host", "localhost");
           SETTINGS.put("port", "8080");
       }
   }

4. static NESTED CLASS
   - A nested class declared static. Does NOT hold a reference to the outer class instance.
   - Can be instantiated without an outer class object.
   - Commonly used for builder classes, helper classes.

   class Outer {
       static class StaticNested { ... }
   }
   Outer.StaticNested sn = new Outer.StaticNested();

static vs instance — Quick Reference:
  Method/field   static             instance
  Access via     ClassName.x        object.x (or just x inside class)
  `this`         ❌ not available   ✅ available
  Instance fields ❌ can't access   ✅ can access

THE `this` KEYWORD
------------------
`this` refers to the CURRENT OBJECT INSTANCE.

Uses:
  1. Disambiguate field vs parameter:
       this.name = name;

  2. Call another constructor in the same class (must be first statement):
       public Employee(String name) { this(name, 0); }
       public Employee(String name, int age) { ... }

  3. Pass current object as argument:
       register(this);

  4. Return current object (fluent/builder pattern):
       public Builder setName(String n) { this.name = n; return this; }

  ❌ Cannot be used in static context (static methods have no "current instance").

THE `super` KEYWORD
-------------------
`super` refers to the PARENT CLASS.

Uses:
  1. Call parent class constructor (must be first statement in constructor):
       class Dog extends Animal {
           Dog(String name) { super(name); }  // Animal(String)
       }

  2. Call parent class method (after it has been overridden):
       @Override
       public void eat() {
           super.eat();  // Animal.eat()
           System.out.println("Dog eats kibble");
       }

  3. Access parent class field (when shadowed):
       class Child extends Parent {
           int x = 20;
           void show() { System.out.println(super.x + " " + x); }
       }

  If no super() call is written, Java implicitly adds super() (no-arg) as first statement.
  If parent has no no-arg constructor, compile error unless you explicitly call super(args).

COMMON INTERVIEW QUESTIONS
---------------------------
Q: Can a static method access instance variables?
A: No. Static methods belong to the class, not any object instance. There's no `this` reference
   in a static method, so instance variables (which live per-object) cannot be accessed.

Q: What is a blank final variable?
A: A final instance field that is not initialized at declaration but is assigned exactly once
   in every constructor. It must be assigned before the constructor returns.

Q: What is the difference between static and instance methods?
A: Static: called on class, no `this`, can only access static members directly.
   Instance: called on object, has `this`, can access both static and instance members.

Q: Can you override a final method?
A: No. The compiler prevents it. final method = sealed behavior, guaranteed not to change.

Q: When would you use `super.method()` inside an overriding method?
A: To extend (not replace) the parent's behavior. Common in lifecycle methods:
   call super.init() to run the parent's initialization, then add your own.

Q: What happens if you write `this()` and `super()` in the same constructor?
A: Compile error. Both must be the first statement, so only one is allowed.
