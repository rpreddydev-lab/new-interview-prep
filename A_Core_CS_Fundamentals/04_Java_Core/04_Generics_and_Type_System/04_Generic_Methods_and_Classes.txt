GENERIC METHODS AND CLASSES
=============================

GENERIC CLASS — COMPLETE PATTERNS
------------------------------------
  A generic class parameterizes over one or more types.
  All non-static methods and fields can use the class's type parameters.

  // Single type parameter — immutable wrapper
  public final class Optional<T> {
      private final T value;

      private Optional(T value) { this.value = value; }

      public static <T> Optional<T> of(T value) {
          if (value == null) throw new NullPointerException();
          return new Optional<>(value);
      }

      public static <T> Optional<T> empty() {
          return new Optional<>(null);
      }

      public T get() {
          if (value == null) throw new NoSuchElementException();
          return value;
      }

      public boolean isPresent() { return value != null; }

      public T orElse(T other) { return value != null ? value : other; }
  }

  // Two type parameters — generic Pair
  public class Pair<A, B> {
      private final A first;
      private final B second;

      public Pair(A first, B second) { this.first = first; this.second = second; }
      public A getFirst() { return first; }
      public B getSecond() { return second; }

      public Pair<B, A> swap() { return new Pair<>(second, first); }

      @Override
      public String toString() { return "(" + first + ", " + second + ")"; }
  }

  Pair<String, Integer> p = new Pair<>("Alice", 30);
  Pair<Integer, String> swapped = p.swap(); // (30, Alice)

  // Bounded type parameter in class
  public class NumberBox<T extends Number> {
      private T value;
      public NumberBox(T value) { this.value = value; }
      public double doubleValue() { return value.doubleValue(); } // can call Number methods
  }

  NumberBox<Integer> nb = new NumberBox<>(42);
  NumberBox<Double> nd = new NumberBox<>(3.14);
  // NumberBox<String> ns = new NumberBox<>("x"); // ❌ String not extends Number

GENERIC METHODS — COMPLETE PATTERNS
--------------------------------------
  A generic method declares its own type parameters before the return type.
  The type parameter is local to that method.

  // Static factory method — common pattern
  public static <T> List<T> singletonList(T element) {
      List<T> list = new ArrayList<>();
      list.add(element);
      return list;
  }

  // Type inference from arguments:
  List<String> ls = singletonList("hello"); // T inferred as String
  List<Integer> li = singletonList(42);     // T inferred as Integer

  // Generic method with bounded parameter
  public static <T extends Comparable<T>> T clamp(T value, T min, T max) {
      if (value.compareTo(min) < 0) return min;
      if (value.compareTo(max) > 0) return max;
      return value;
  }
  System.out.println(clamp(15, 0, 10)); // 10
  System.out.println(clamp(5, 0, 10));  // 5

  // Generic method returning generic type
  public static <K, V> Map<V, K> invert(Map<K, V> original) {
      Map<V, K> inverted = new HashMap<>();
      original.forEach((k, v) -> inverted.put(v, k));
      return inverted;
  }

  // Generic method with wildcard parameter
  public static <T> void copy(List<T> dest, List<? extends T> src) {
      for (T item : src) dest.add(item);
  }

EXPLICIT TYPE WITNESS
----------------------
  Usually the compiler infers type arguments from the arguments or context.
  When it can't (e.g., no arguments), you can provide explicit type arguments:

  // No arguments — compiler can't infer T
  List<String> empty = Collections.<String>emptyList(); // explicit type witness

  // Chained calls (Java 7 diamond inference can fail in some cases)
  Map<String, List<Integer>> map = Collections.<String, List<Integer>>emptyMap();

GENERIC CLASS INHERITANCE
--------------------------
  Four patterns when subclassing a generic class:

  1. Preserve the type parameter:
     class NumberList<T extends Number> extends ArrayList<T> {}

  2. Bind the type parameter:
     class StringList extends ArrayList<String> {}  // T fixed to String

  3. Add more type parameters:
     class BiMap<K, V, W> extends HashMap<K, V> {}

  4. Use raw type (avoid!):
     class BadList extends ArrayList {}  // raw — loses type safety

  // Interface implementations:
  class StringComparator implements Comparator<String> {
      @Override
      public int compare(String a, String b) { return a.compareTo(b); }
  }

GENERIC INTERFACE PATTERNS
---------------------------
  // Functional interface pattern
  @FunctionalInterface
  public interface Transformer<T, R> {
      R transform(T input);
  }

  Transformer<String, Integer> length = String::length;
  System.out.println(length.transform("hello")); // 5

  // Builder pattern with generics (for fluent API)
  public abstract class Builder<T, B extends Builder<T, B>> {
      @SuppressWarnings("unchecked")
      protected B self() { return (B) this; }
      public abstract T build();
  }

  public class PersonBuilder extends Builder<Person, PersonBuilder> {
      private String name;
      public PersonBuilder name(String name) { this.name = name; return self(); }
      @Override public Person build() { return new Person(name); }
  }

COMMON PATTERNS IN JAVA STANDARD LIBRARY
------------------------------------------
  // Collections.sort — generic method with bounded wildcard
  public static <T extends Comparable<? super T>> void sort(List<T> list) { ... }

  // Enum — self-referential bound (recursive generic)
  public abstract class Enum<E extends Enum<E>> implements Comparable<E> { ... }
  // Each enum class IS a subtype of Enum<itself>

  // Comparable — self-referential
  public interface Comparable<T> {
      int compareTo(T o);
  }
  // Integer implements Comparable<Integer> — compares with instances of itself

GENERIC ARRAY WORKAROUND
-------------------------
  Cannot do: T[] arr = new T[10];  // ❌

  Workarounds:
  1. Use List<T> instead of T[]
  2. Pass Class<T> token and use Array.newInstance:
     @SuppressWarnings("unchecked")
     public static <T> T[] createArray(Class<T> type, int size) {
         return (T[]) java.lang.reflect.Array.newInstance(type, size);
     }
     String[] arr = createArray(String.class, 10);

  3. Create Object[] and cast:
     @SuppressWarnings("unchecked")
     T[] arr = (T[]) new Object[10]; // ← most common internal approach (ArrayList does this)

COMMON INTERVIEW QUESTIONS
---------------------------
Q: How do you write a generic method that returns the maximum of two elements?
A: Use a bounded type parameter with Comparable:
     public static <T extends Comparable<? super T>> T max(T a, T b) {
         return a.compareTo(b) >= 0 ? a : b;
     }
   The <? super T> in Comparable's bound allows T to use compareTo defined on its supertype.

Q: What is a recursive type bound? Give an example.
A: A recursive type bound is when a type parameter is bounded by a generic type that uses
   the same type parameter as an argument.
   Example: <T extends Comparable<T>> means T must implement Comparable<T> — T can compare
   with objects of its OWN type.
   More flexible form: <T extends Comparable<? super T>> — T's compareTo can be defined
   in a supertype, allowing subclasses to inherit the natural ordering.

Q: What is the difference between generic method and a generic class?
A: Generic class: the type parameter applies to the entire class — all instance methods
   and fields can use it. Declared after the class name: class Box<T>.
   Generic method: the type parameter is scoped to that one method — declared just before
   the return type. Can appear in non-generic classes. Type is usually inferred from arguments.
   Use generic method when: the type relationship is specific to that method,
   or you need a static factory without a generic class context.

Q: Can a static method use the type parameter of its enclosing generic class?
A: No. Static methods belong to the class itself, not to any instance. Since the class-level
   type parameter T is per-instance (Box<String> vs Box<Integer>), static methods cannot
   reference it. Static methods can declare their own type parameters:
     class Box<T> {
         static <T> Box<T> of(T val) { return new Box<>(val); } // own T, not class T
     }
