JAVA OVERVIEW
=============

WHAT IS JAVA?
-------------
Java is a high-level, class-based, object-oriented programming language designed to have as few
implementation dependencies as possible. It follows the WORA principle:
  Write Once, Run Anywhere — compiled bytecode runs on any JVM regardless of underlying OS/hardware.

KEY CHARACTERISTICS
-------------------
1. Object-Oriented      — Everything (except primitives) is an object. Supports OOP: encapsulation,
                          inheritance, polymorphism, abstraction.
2. Platform Independent — Source (.java) → Bytecode (.class) → JVM executes on any platform.
3. Strongly Typed       — Every variable must have a declared type; type mismatches caught at compile time.
4. Automatic Memory Mgmt— JVM handles memory allocation/deallocation via Garbage Collection.
5. Multithreaded        — Built-in support for concurrent execution via java.lang.Thread and java.util.concurrent.
6. Robust               — Strong type checking, exception handling, no pointer arithmetic.
7. Secure               — Bytecode verifier, security manager, no direct memory access.
8. Distributed          — Built-in support for networking (java.net), RMI, EJB.
9. High Performance     — JIT (Just-In-Time) compiler converts bytecode to native machine code at runtime.
10. Dynamic             — Can load classes at runtime via Class.forName(), reflection.

JAVA EXECUTION FLOW
-------------------
  MyProgram.java
      │
      ▼  javac (Java Compiler)
  MyProgram.class   ← bytecode (platform-independent)
      │
      ▼  JVM (Java Virtual Machine)
  Machine Code      ← platform-specific execution

  javac HelloWorld.java   → produces HelloWorld.class
  java HelloWorld         → JVM loads and executes

JAVA VERSIONS OVERVIEW
-----------------------
  Java 1.0  (1996) — Initial release
  Java 1.2  (1998) — Collections Framework, Swing
  Java 5    (2004) — Generics, enums, autoboxing, for-each, varargs, annotations
  Java 6    (2006) — Performance improvements, scripting API
  Java 7    (2011) — Try-with-resources, diamond operator, NIO2
  Java 8    (2014) — Lambdas, Streams, Optional, default methods [LTS]
  Java 9    (2017) — Module system (Jigsaw), JShell
  Java 11   (2018) — Local-var syntax for lambdas, HTTP Client [LTS]
  Java 17   (2021) — Sealed classes, records, pattern matching [LTS]
  Java 21   (2023) — Virtual threads, structured concurrency, sequenced collections [LTS]

COMMON INTERVIEW QUESTIONS ON THIS TOPIC
-----------------------------------------
Q: What is the difference between Java and C++?
A: Java has no pointers, no manual memory management, automatic GC, platform independence via JVM,
   no multiple inheritance of classes (but multiple interface inheritance). C++ has manual memory
   management, pointers, direct hardware access, no JVM overhead.

Q: Is Java fully object-oriented?
A: No — Java has primitive types (int, char, boolean, etc.) which are not objects. This is why
   wrapper classes (Integer, Character, Boolean) exist.

Q: What does "platform independent" mean in Java?
A: Java source code is compiled to bytecode (.class), which is OS/hardware-neutral. The JVM
   installed on each platform interprets/executes the bytecode. The JVM itself is platform-specific,
   but the bytecode is not.

Q: What are the main features introduced in Java 8?
A: Lambda expressions, Stream API, Optional, default/static interface methods, new Date/Time API
   (java.time), method references, functional interfaces.
