STRING METHODS AND INTERVIEW TRAPS
====================================

ESSENTIAL String METHODS
--------------------------
  String s = "Hello, World!";

  LENGTH AND ACCESS:
    s.length()               → 13
    s.charAt(0)              → 'H'
    s.indexOf('o')           → 4      (first occurrence)
    s.lastIndexOf('o')       → 8      (last occurrence)
    s.indexOf("World")       → 7
    s.indexOf("xyz")         → -1     (not found)

  SUBSTRING:
    s.substring(7)           → "World!"   (from index 7 to end)
    s.substring(7, 12)       → "World"    (from 7 inclusive to 12 exclusive)

  COMPARISON:
    s.equals("Hello, World!")        → true   (case-sensitive)
    s.equalsIgnoreCase("hello, world!") → true
    s.compareTo("Hello, World!")     → 0      (lexicographic, 0 = equal)
    s.startsWith("Hello")            → true
    s.endsWith("!")                  → true
    s.contains("World")              → true

  SEARCH AND REPLACE:
    s.replace('l', 'r')          → "Herro, Worrd!"   (char)
    s.replace("World", "Java")   → "Hello, Java!"    (String)
    s.replaceAll("[aeiou]", "*") → regex replace
    s.replaceFirst("[A-Z]", "*") → replaces first match

  CASE:
    s.toUpperCase()   → "HELLO, WORLD!"
    s.toLowerCase()   → "hello, world!"

  WHITESPACE:
    "  hi  ".trim()    → "hi"     (removes leading/trailing whitespace — ASCII only)
    "  hi  ".strip()   → "hi"     (Java 11+ — Unicode-aware, preferred)
    "  hi  ".stripLeading()  → "hi  "
    "  hi  ".stripTrailing() → "  hi"
    "  ".isBlank()     → true     (Java 11+ — true if empty or only whitespace)
    "".isEmpty()       → true     (only true if length == 0)

  SPLITTING AND JOINING:
    "a,b,c".split(",")       → ["a", "b", "c"]
    "a,,b".split(",")        → ["a", "", "b"]
    "a,,b".split(",", -1)    → ["a", "", "b"] (keep trailing empty strings)
    String.join("-", "a", "b", "c")  → "a-b-c"
    String.join(", ", list)          → join from collection

  CHAR ARRAY:
    s.toCharArray()          → char[]
    new String(charArray)    → String from char[]

  FORMATTING:
    String.format("Name: %s, Age: %d", "Alice", 30)  → "Name: Alice, Age: 30"
    "Hello %s".formatted("World")  // Java 15+ — same as String.format

  TYPE CONVERSION:
    String.valueOf(42)         → "42"  (any primitive or object)
    String.valueOf(true)       → "true"
    Integer.parseInt("42")     → 42
    Integer.valueOf("42")      → Integer(42)
    Double.parseDouble("3.14") → 3.14

  OTHER:
    s.intern()     → pool reference
    s.isEmpty()    → s.length() == 0
    s.isBlank()    → Java 11+, blank if whitespace only
    s.repeat(3)    → Java 11+, "abc".repeat(3) → "abcabcabc"
    s.lines()      → Java 11+, Stream<String> of lines

INTERVIEW TRAPS
---------------

TRAP 1: == vs .equals()
  String a = "hello";
  String b = "hello";
  String c = new String("hello");
  a == b       // true  (both pooled)
  a == c       // false (c is a new heap object)
  a.equals(c)  // true

TRAP 2: substring() creates a new String (Java 7+)
  Pre-Java 7: substring shared the underlying char[] (memory leak risk).
  Java 7+: substring creates a fully independent copy.

TRAP 3: split() drops trailing empty strings
  "a,,".split(",")     → ["a"]        (trailing empty strings dropped)
  "a,,".split(",", -1) → ["a", "", ""] (negative limit keeps them)

TRAP 4: + with null
  String s = null;
  "Hello " + s    → "Hello null"    (null converted to "null" string)
  s.equals("hi")  → NullPointerException
  "hi".equals(s)  → false (safe)

TRAP 5: charAt() vs substring() for single char
  s.charAt(0)         → 'H'  (char primitive)
  s.substring(0, 1)   → "H"  (String object)
  These are NOT interchangeable in comparisons.

TRAP 6: String.valueOf() vs toString()
  Integer i = null;
  String.valueOf(i)   → "null" (safe — returns "null" string)
  i.toString()        → NullPointerException!

TRAP 7: compareTo() returns int, not boolean
  "abc".compareTo("abd")  → -1 (a < b lexicographically)
  "abc".compareTo("abc")  → 0
  "abd".compareTo("abc")  → 1

TRAP 8: indexOf returns -1 for not found
  s.indexOf("xyz") → -1   (not -1 is truthy check pattern in other languages)
  Always check: if (s.indexOf("x") != -1) { ... }

COMMON INTERVIEW QUESTIONS
---------------------------
Q: How do you check if a String is empty or null?
A: if (str == null || str.isEmpty())  — covers both
   Or Java 11+: if (str == null || str.isBlank())  — covers whitespace-only too
   Or use: StringUtils.isBlank(str) from Apache Commons.

Q: What is the difference between trim() and strip() (Java 11)?
A: trim() removes only ASCII whitespace (chars <= '\u0020').
   strip() (Java 11+) removes Unicode whitespace — uses Character.isWhitespace() which
   handles full Unicode space characters. Prefer strip() for Java 11+ code.

Q: How does split() behave with trailing delimiters?
A: Default: trailing empty strings are discarded.
   "a,,".split(",") → ["a"]. Use split(",", -1) to keep trailing empty strings.

Q: What does String.format() do vs printf()?
A: String.format() returns a formatted String. System.out.printf() directly prints it.
   Same format specifiers: %s (String), %d (int), %f (float), %n (newline).
   Java 15+ alternative: "Hello %s".formatted(name) — instance method, same result.

Q: Reverse a String without StringBuilder?
A: char[] arr = str.toCharArray();
   for (int i = 0, j = arr.length - 1; i < j; i++, j--) {
       char tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
   }
   return new String(arr);
