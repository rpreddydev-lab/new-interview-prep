BYTE STREAMS: InputStream AND OutputStream
============================================

InputStream — READING BYTES
-----------------------------
  InputStream is the abstract base class for all byte input streams.
  Key abstract method: int read() — reads one byte, returns -1 at end-of-stream.

  Core methods:
    int read()                     — read 1 byte (0–255), or -1 if EOF
    int read(byte[] b)             — read up to b.length bytes into array
    int read(byte[] b, int off, int len) — read up to len bytes into b starting at off
    long skip(long n)              — skip n bytes
    int available()                — estimate of bytes that can be read without blocking
    void close()                   — release resources
    void mark(int readlimit)       — mark current position (if markSupported())
    void reset()                   — return to marked position
    boolean markSupported()        — whether mark/reset are supported

  Reading loop patterns:
    // Pattern 1: byte by byte (slow — use only for learning)
    int b;
    while ((b = inputStream.read()) != -1) {
        process((byte) b);
    }

    // Pattern 2: buffered chunk reading (preferred)
    byte[] buffer = new byte[8192];  // 8KB buffer
    int bytesRead;
    while ((bytesRead = inputStream.read(buffer)) != -1) {
        process(buffer, 0, bytesRead);
    }

OutputStream — WRITING BYTES
------------------------------
  OutputStream is the abstract base class for all byte output streams.
  Key abstract method: void write(int b) — writes one byte.

  Core methods:
    void write(int b)                        — write 1 byte (low 8 bits of int)
    void write(byte[] b)                     — write entire array
    void write(byte[] b, int off, int len)   — write len bytes from array starting at off
    void flush()                             — force any buffered bytes to the underlying sink
    void close()                             — flush and release resources

FileInputStream / FileOutputStream
------------------------------------
  // Copy a file using byte streams:
  try (FileInputStream fis = new FileInputStream("source.bin");
       FileOutputStream fos = new FileOutputStream("dest.bin")) {

      byte[] buffer = new byte[8192];
      int bytesRead;
      while ((bytesRead = fis.read(buffer)) != -1) {
          fos.write(buffer, 0, bytesRead);
      }
  }
  // Both streams are auto-closed

  // FileOutputStream append mode:
  FileOutputStream fos = new FileOutputStream("log.txt", true); // true = append

ByteArrayInputStream / ByteArrayOutputStream
-----------------------------------------------
  Work with byte arrays in memory — useful for testing and buffering:

  // ByteArrayOutputStream — collect bytes in memory:
  ByteArrayOutputStream baos = new ByteArrayOutputStream();
  baos.write("Hello".getBytes(StandardCharsets.UTF_8));
  baos.write(", ".getBytes(StandardCharsets.UTF_8));
  baos.write("World".getBytes(StandardCharsets.UTF_8));
  byte[] result = baos.toByteArray();  // get accumulated bytes
  String text = baos.toString(StandardCharsets.UTF_8);  // convert to String

  // ByteArrayInputStream — read from a byte array:
  byte[] data = {72, 101, 108, 108, 111}; // "Hello"
  ByteArrayInputStream bais = new ByteArrayInputStream(data);
  int b;
  while ((b = bais.read()) != -1) {
      System.out.print((char) b);
  }

DataInputStream / DataOutputStream
-------------------------------------
  Read and write Java primitive types in a portable binary format.
  The written format is big-endian and portable across platforms.

  // Write primitives:
  try (DataOutputStream dos = new DataOutputStream(
          new BufferedOutputStream(new FileOutputStream("data.bin")))) {
      dos.writeInt(42);
      dos.writeDouble(3.14);
      dos.writeBoolean(true);
      dos.writeUTF("Hello");  // writes length-prefixed modified UTF-8
  }

  // Read primitives back — MUST read in the same order:
  try (DataInputStream dis = new DataInputStream(
          new BufferedInputStream(new FileInputStream("data.bin")))) {
      int i = dis.readInt();          // 42
      double d = dis.readDouble();    // 3.14
      boolean b = dis.readBoolean();  // true
      String s = dis.readUTF();       // "Hello"
  }

BufferedInputStream / BufferedOutputStream
--------------------------------------------
  Wrap any stream with an internal byte array buffer.
  Reduces system calls — instead of one call per byte, one call per buffer-fill.
  Default buffer size: 8192 bytes. Can specify: new BufferedInputStream(is, 16384).

  // Always use Buffered wrappers for FileInput/OutputStream:
  try (InputStream is = new BufferedInputStream(new FileInputStream("large.bin"))) {
      // reading is now buffered — much faster for sequential reads
  }

  // ALWAYS flush before close when using BufferedOutputStream:
  BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("out.bin"));
  bos.write(data);
  bos.flush(); // ← ensures buffered bytes are written; close() calls flush() too
  bos.close();

INPUTSTREAM TRANSFER TO OUTPUTSTREAM (JAVA 9+)
-------------------------------------------------
  Java 9 added InputStream.transferTo(OutputStream out):
  Reads all bytes and writes them to the output stream — a file copy in one line.

  try (InputStream in = new FileInputStream("source.bin");
       OutputStream out = new FileOutputStream("dest.bin")) {
      long bytesTransferred = in.transferTo(out);
  }

  // Also useful for reading InputStream into a byte[]:
  byte[] bytes = inputStream.readAllBytes();  // Java 9+ — reads entire stream

COMMON STREAM SOURCES AND SINKS
-----------------------------------
  Source                           | InputStream class
  ----------------------------------|---------------------------
  File on disk                      | FileInputStream
  Byte array in memory              | ByteArrayInputStream
  Network socket                    | socket.getInputStream()
  Inter-thread pipe                 | PipedInputStream
  Compressed (gzip) data            | GZIPInputStream (wraps another IS)
  Encrypted data                    | CipherInputStream (javax.crypto)

  Sink                              | OutputStream class
  ----------------------------------|---------------------------
  File on disk                      | FileOutputStream
  Byte array in memory              | ByteArrayOutputStream
  Network socket                    | socket.getOutputStream()
  Inter-thread pipe                 | PipedOutputStream
  Compressed output                 | GZIPOutputStream (wraps another OS)

COMMON INTERVIEW QUESTIONS
---------------------------
Q: Why does InputStream.read() return int instead of byte?
A: Because byte in Java is signed (-128 to 127), but read() needs to return values
   0–255 for valid bytes AND -1 for end-of-stream. Using int allows all 256 byte values
   (0–255) to be distinguished from the sentinel -1. If read() returned byte, -1 would
   be ambiguous (it's a valid byte value: 0xFF = -1 as signed byte).

Q: What is the purpose of flush() on OutputStream?
A: Buffered streams (BufferedOutputStream, PrintStream, etc.) accumulate bytes in an
   internal buffer before writing them to the underlying stream (to reduce system calls).
   flush() forces any buffered data to be written immediately to the underlying destination.
   close() calls flush() automatically, but if you need data written before closing
   (e.g., sending data over a network socket before reading a response), call flush() explicitly.

Q: What is the difference between FileInputStream and BufferedInputStream?
A: FileInputStream reads directly from disk — every read() call may be a system call.
   BufferedInputStream wraps another InputStream and maintains an internal buffer (8KB by default).
   When data is requested, it reads a large chunk from the underlying stream and serves
   subsequent reads from the buffer until it empties. This dramatically reduces the number
   of system calls and is much faster for sequential reads. Always wrap FileInputStream
   with BufferedInputStream for any non-trivial file reading.
