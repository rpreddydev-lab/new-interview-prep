JAVA TEXT BLOCKS
=================

WHAT ARE TEXT BLOCKS?
----------------------
  Text Blocks (Java 15 — JEP 378, preview in Java 13/14) are a multiline string
  literal that avoids most escape sequences and automatically strips incidental
  indentation.

  // Before text blocks:
  String json = "{\n" +
                "  \"name\": \"Alice\",\n" +
                "  \"age\": 30\n" +
                "}";

  // With text block:
  String json = """
          {
            "name": "Alice",
            "age": 30
          }
          """;

  The opening """ must be followed by a newline (no content on the same line).
  The closing """ determines indentation stripping.

INDENTATION STRIPPING
----------------------
  The compiler strips "incidental" whitespace — the common leading whitespace shared
  by all content lines and the closing delimiter line.

  // The closing """ position controls the baseline:
  String s = """
      Line 1
      Line 2
      """;
  // Closing """ is at 4 spaces indent — so 4 spaces stripped from each line
  // Result: "Line 1\nLine 2\n"

  // Closing """ further right means less stripping:
  String s2 = """
      Line 1
      Line 2
  """;           // closing """ at 0 indent
  // All 4 spaces of "    Line 1" are kept:
  // Result: "    Line 1\n    Line 2\n"

  // Use String.stripIndent() to apply the same algorithm programmatically.

ESCAPING AND SPECIAL SEQUENCES
--------------------------------
  // Text blocks support standard escape sequences:
  String s = """
      First line
      Second line\twith tab
      """;

  // Embedded quotes — single " and "" are fine; """ needs escaping:
  String html = """
      <p class="main">Hello "World"</p>
      """;
  // Only """ requires \":
  String tricky = """
      He said: \"Hello\"""
      """;

  // Line continuation — \  at end of line joins the next line (no newline inserted):
  String oneLineWithNoNewline = """
      The quick brown \
      fox jumps""";
  // Result: "The quick brown fox jumps"

  // \s — explicit space (prevents trailing whitespace stripping):
  String aligned = """
      alpha  \s
      beta   \s
      gamma  \s
      """;
  // The \s preserves trailing spaces (otherwise they'd be stripped)

TRAILING NEWLINE
-----------------
  A text block always ends with the content of the last content line.
  If the closing """ is on its own line, there IS a trailing newline.
  If the closing """ is on the same line as the last content, there is NOT:

  String withNewline    = """
      Hello
      """;       // ends with \n

  String withoutNewline = """
      Hello""";  // no trailing \n

FORMATTED() METHOD
-------------------
  Text blocks work well with String.formatted() (Java 15+, equivalent to String.format()):

  String template = """
      SELECT *
      FROM %s
      WHERE id = %d
      """.formatted("users", 42);
  // Result:
  // SELECT *
  // FROM users
  // WHERE id = 42

  // Or use String.format with text block:
  String query = String.format("""
      SELECT *
      FROM %s
      WHERE name = '%s'
      """, tableName, userName);

USE CASES
----------
  // SQL:
  String sql = """
      SELECT u.name, o.total
      FROM users u
      JOIN orders o ON u.id = o.user_id
      WHERE u.active = true
      ORDER BY o.total DESC
      """;

  // JSON:
  String json = """
      {
        "status": "ok",
        "items": [1, 2, 3]
      }
      """;

  // HTML:
  String html = """
      <html>
        <body>
          <p>Hello, World!</p>
        </body>
      </html>
      """;

  // GraphQL:
  String gql = """
      query GetUser($id: ID!) {
        user(id: $id) {
          name
          email
        }
      }
      """;

TEXT BLOCK METHODS (String)
-----------------------------
  stripIndent()     — programmatically strip common leading whitespace (same algorithm as text block)
  translateEscapes() — interpret escape sequences in a string (e.g., turn \\n into actual \n)

  These are mainly for cases where you receive strings from external sources and want to
  apply the same normalization a text block would.

COMMON INTERVIEW QUESTIONS
---------------------------
Q: What is a text block and how does it differ from a regular string literal?
A: A text block (Java 15) is a multi-line string literal delimited by triple quotes (""").
   It differs from regular strings by: (1) automatically stripping incidental leading
   whitespace based on the position of the closing """; (2) not requiring escape sequences
   for embedded single or double quotes; (3) allowing natural line breaks without \n;
   (4) supporting new escape sequences like \s (explicit space) and \ (line continuation).
   The resulting String is the same type — text blocks are purely a source-code convenience.

Q: How does indentation stripping work in text blocks?
A: The compiler finds the minimum indentation among all non-blank content lines and the
   closing """ line, then strips that many leading spaces from every line. The position of
   the closing """ controls how much is stripped. Placing the closing """ at the left margin
   (column 0) preserves all indentation. Placing it aligned with the content strips the
   common indent, leaving the content flush.

Q: What is the \s escape sequence in text blocks?
A: \s is a new escape introduced with text blocks. It represents a single space character
   but signals to the compiler that the trailing whitespace up to and including this point
   should be preserved. Without \s, trailing whitespace on content lines is stripped.
   This is useful when you need aligned or padded content with trailing spaces that must
   not be removed.

Q: Can text blocks be used with String.format() / formatted()?
A: Yes. A text block is just a String, so String.format(textBlock, args) works normally.
   Java 15 also introduced the instance method formatted() on String, which is equivalent:
   """...""".formatted(arg1, arg2). This is cleaner for templates because the format
   string and its call are adjacent.
