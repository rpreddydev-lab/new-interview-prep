FUNCTIONAL INTERFACES: FUNCTION, PREDICATE, CONSUMER, SUPPLIER
================================================================

OVERVIEW
---------
  java.util.function provides standard functional interfaces for the most common
  function patterns. Using these standard interfaces avoids defining custom ones
  and enables interoperability with the Java API (streams, Optional, CompletableFuture).

  Four fundamental families:
  - Function<T,R>    — transforms T to R
  - Predicate<T>     — tests T, returns boolean
  - Consumer<T>      — consumes T, no return
  - Supplier<T>      — produces T, no input

FUNCTION<T, R>
---------------
  @FunctionalInterface
  interface Function<T, R> {
      R apply(T t);

      // Composition (default methods):
      default <V> Function<T, V> andThen(Function<R, V> after);  // apply → after
      default <V> Function<V, R> compose(Function<V, T> before); // before → apply
      static <T>  Function<T, T> identity();                     // returns input unchanged
  }

  Function<String, Integer> length = String::length;
  length.apply("Hello");  // 5

  // andThen chains: apply THEN after
  Function<Integer, String> intToStr = i -> "Number: " + i;
  Function<String, String> pipeline = length.andThen(intToStr);
  pipeline.apply("Hello");  // "Number: 5"

  // compose chains: before THEN apply
  Function<String, String> trim = String::trim;
  Function<String, Integer> trimThenLen = length.compose(trim);
  trimThenLen.apply("  Hi  ");  // 2

  // identity() — useful in Collectors.toMap:
  Map<String, String> map = list.stream()
      .collect(Collectors.toMap(Function.identity(), String::toUpperCase));

VARIANTS
---------
  BiFunction<T,U,R>   — two inputs → R:   apply(T t, U u)
  UnaryOperator<T>    — T → T (extends Function<T,T>):  identity(), apply
  BinaryOperator<T>   — T,T → T (extends BiFunction<T,T,T>): reduce candidate
  ToIntFunction<T>    — T → int (avoids boxing)
  ToLongFunction<T>   — T → long
  ToDoubleFunction<T> — T → double
  IntFunction<R>      — int → R
  IntUnaryOperator    — int → int
  IntBinaryOperator   — int,int → int

  // BinaryOperator for reduction:
  BinaryOperator<Integer> sum = Integer::sum;
  Optional<Integer> total = Stream.of(1,2,3,4).reduce(sum);

PREDICATE<T>
-------------
  @FunctionalInterface
  interface Predicate<T> {
      boolean test(T t);

      // Logical composition:
      default Predicate<T> and(Predicate<T> other);    // this && other (short-circuits)
      default Predicate<T> or(Predicate<T> other);     // this || other (short-circuits)
      default Predicate<T> negate();                   // !this
      static <T> Predicate<T> not(Predicate<T> target); // Java 11+: Predicate.not()
      static <T> Predicate<T> isEqual(Object target);  // Objects.equals based
  }

  Predicate<String> notBlank = s -> !s.isBlank();
  Predicate<String> longEnough = s -> s.length() >= 3;

  // Compose:
  Predicate<String> valid = notBlank.and(longEnough);
  list.stream().filter(valid).collect(Collectors.toList());

  // negate():
  Predicate<String> isBlank = notBlank.negate();

  // Predicate.not (Java 11+):
  list.stream().filter(Predicate.not(String::isBlank)).forEach(System.out::println);

  // BiPredicate<T,U>:
  BiPredicate<String, Integer> longerThan = (s, n) -> s.length() > n;
  longerThan.test("Hello", 3);  // true

CONSUMER<T>
------------
  @FunctionalInterface
  interface Consumer<T> {
      void accept(T t);
      default Consumer<T> andThen(Consumer<T> after); // run this, then after
  }

  Consumer<String> print = System.out::println;
  Consumer<String> log = s -> logger.info(s);

  // Chain consumers:
  Consumer<String> printAndLog = print.andThen(log);
  list.forEach(printAndLog);

  // In stream:
  list.stream().forEach(s -> System.out.println(s.toUpperCase()));

  // BiConsumer<T,U>:
  BiConsumer<String, Integer> printEntry = (key, value) -> System.out.println(key + "=" + value);
  map.forEach(printEntry);  // Map.forEach takes BiConsumer

  // Variants:
  IntConsumer, LongConsumer, DoubleConsumer  — primitive-specialized, no boxing

SUPPLIER<T>
------------
  @FunctionalInterface
  interface Supplier<T> {
      T get();
  }

  Supplier<LocalDate> today = LocalDate::now;
  today.get();  // current date each time called — evaluated lazily

  // Common use — lazy default values:
  Optional.ofNullable(value).orElseGet(() -> computeExpensiveDefault());

  // Factory pattern:
  Supplier<List<String>> listFactory = ArrayList::new;
  List<String> newList = listFactory.get();

  // Deferred computation:
  Supplier<Connection> dbConn = () -> dataSource.getConnection();

  // Variants:
  BooleanSupplier  — boolean getAsBoolean()
  IntSupplier      — int getAsInt()
  LongSupplier     — long getAsLong()
  DoubleSupplier   — double getAsDouble()

STANDARD FUNCTIONAL INTERFACES SUMMARY TABLE
---------------------------------------------
  | Interface              | Signature           | Primary Method  |
  |------------------------|---------------------|-----------------|
  | Function<T,R>          | T → R               | apply(T)        |
  | BiFunction<T,U,R>      | T,U → R             | apply(T,U)      |
  | UnaryOperator<T>       | T → T               | apply(T)        |
  | BinaryOperator<T>      | T,T → T             | apply(T,T)      |
  | Predicate<T>           | T → boolean         | test(T)         |
  | BiPredicate<T,U>       | T,U → boolean       | test(T,U)       |
  | Consumer<T>            | T → void            | accept(T)       |
  | BiConsumer<T,U>        | T,U → void          | accept(T,U)     |
  | Supplier<T>            | () → T              | get()           |
  | Runnable               | () → void           | run()           |
  | Callable<V>            | () → V (throws)     | call()          |
  | Comparator<T>          | T,T → int           | compare(T,T)    |

COMPOSING COMPLEX PIPELINES
-----------------------------
  // Chaining Function, Predicate, Consumer:
  Function<String, String> normalize = s -> s.trim().toLowerCase();
  Predicate<String> isValid = s -> !s.isEmpty() && s.matches("[a-z]+");
  Consumer<String> persist = s -> db.save(s);

  list.stream()
      .map(normalize)
      .filter(isValid)
      .forEach(persist);

  // Reusing composed predicates:
  Predicate<Integer> positive = n -> n > 0;
  Predicate<Integer> even = n -> n % 2 == 0;
  Predicate<Integer> positiveEven = positive.and(even);

  List<Integer> result = numbers.stream()
      .filter(positiveEven)
      .collect(Collectors.toList());

COMMON INTERVIEW QUESTIONS
---------------------------
Q: What is the difference between Function and UnaryOperator?
A: UnaryOperator<T> extends Function<T,T> — it's a specialization for the case where
   the input and output type are the same. Function<T,R> is general-purpose where T and
   R can differ. UnaryOperator is useful when transforming a value in-place (e.g.,
   String → String, Integer → Integer). BinaryOperator<T> similarly extends BiFunction<T,T,T>
   for same-type binary operations, commonly used in Stream.reduce.

Q: What is the difference between Consumer and Function?
A: Function<T,R> transforms its input and returns a result; Consumer<T> accepts an input
   and returns void — it's purely for side effects (printing, logging, persisting).
   Consumers are chained with andThen; Functions can be chained with both compose and andThen.

Q: Why do primitive-specialized functional interfaces exist (e.g., IntFunction, ToIntFunction)?
A: Java's generics don't support primitive types — Function<Integer, R> would box every
   int into an Integer object, causing performance overhead. Primitive-specialized interfaces
   (IntFunction<R>, ToIntFunction<T>, IntUnaryOperator, etc.) use primitive types directly,
   avoiding boxing/unboxing. In performance-sensitive code or large streams, using
   mapToInt with ToIntFunction instead of map with Function<T,Integer> can be significant.

Q: Explain Predicate composition with and, or, negate.
A: Predicates can be combined logically without subclassing. and(other) returns a new
   Predicate that is true only when BOTH this and other return true (short-circuits — other
   is not called if this returns false). or(other) returns a Predicate true when EITHER is
   true (short-circuits — other not called if this is true). negate() returns the logical
   negation. Predicate.not(pred) (Java 11) is equivalent to pred.negate() but works as a
   static utility useful in method references: Predicate.not(String::isBlank).
