JAVA 12 TO 17 FEATURES
=======================

JAVA 12
--------
  1. SWITCH EXPRESSIONS (PREVIEW — JEP 325)
  ------------------------------------------
  Traditional switch was a statement with fall-through semantics and verbose code.
  Switch expressions allow switch to produce a value and use arrow (->) labels:

  // Old switch statement (still works):
  int days;
  switch (month) {
      case JANUARY: case MARCH: days = 31; break;
      default:                  days = 30;
  }

  // New switch expression (arrow labels — no fall-through):
  int days = switch (month) {
      case JANUARY, MARCH, MAY, JULY, AUGUST, OCTOBER, DECEMBER -> 31;
      case APRIL, JUNE, SEPTEMBER, NOVEMBER                      -> 30;
      case FEBRUARY                                              -> 28;
  };

  // With a block and yield:
  int result = switch (mode) {
      case "fast" -> 1;
      case "slow" -> {
          System.out.println("Slow mode");
          yield 2;         // yield returns value from a block
      }
      default -> throw new IllegalArgumentException("Unknown mode: " + mode);
  };

  2. Collectors.teeing() — Java 12+
  ------------------------------------
  Collects into two collectors simultaneously, then merges results:

  record MinMax(Optional<Integer> min, Optional<Integer> max) {}

  MinMax result = Stream.of(3,1,4,1,5,9,2,6)
      .collect(Collectors.teeing(
          Collectors.minBy(Integer::compare),
          Collectors.maxBy(Integer::compare),
          MinMax::new
      ));

JAVA 13
--------
  1. TEXT BLOCKS (PREVIEW — JEP 355)

JAVA 14
--------
  1. HELPFUL NULLPOINTEREXCEPTIONS (JEP 358) — Finalized
  --------------------------------------------------------
  Before: NullPointerException with no info about WHICH reference was null.
  Now: NPE messages include details:
    "Cannot invoke "String.length()" because "str" is null"
    "Cannot store to int array because "array" is null"

  2. RECORDS (PREVIEW — JEP 359)
  Immutable data classes (finalized Java 16 — see 10_Records.txt).

  3. PATTERN MATCHING FOR instanceof (PREVIEW)
  See 12_Pattern_Matching_instanceof_switch.txt.

--------------
  1. SEALED CLASSES (FINALIZED — JEP 409)

  RandomGenerator rng = RandomGeneratorFactory.of("L64X128MixRandom").create();
  int n = rng.nextInt(100);

SWITCH EXPRESSIONS — FULL SUMMARY (JAVA 14 FINAL)
---------------------------------------------------
  Key rules:
  - Arrow labels (->) do NOT fall through (unlike colon labels)
  - Colon labels (:) still fall through (backward compat)
  - yield exits a block and provides the value
  - switch expressions must be exhaustive (all cases covered or default)
  - Can pattern match on types (Java 21+) — see 12_Pattern_Matching file

  // Traditional colon style switch expression (also valid):
  int val = switch (x) {
      case 1: yield 10;
      case 2: yield 20;
      default: yield 0;
  };

COMMON INTERVIEW QUESTIONS
---------------------------
Q: What is the difference between switch statements and switch expressions?
A: Switch statements execute code for a case and can have fall-through. Switch
   expressions (Java 14) produce a value, support arrow labels that don't fall through,
   and must be exhaustive. Arrow syntax: case X -> value or case X -> { ... yield v; }.
   Colon syntax with yield is also supported. Switch expressions make switch usable
   as a right-hand-side value: int x = switch (mode) { ... };

Q: What is yield in switch expressions?
A: yield is the keyword used inside a block arm of a switch expression to provide the
   value. With arrow labels, the value after -> is returned directly. With block arms
   (when you need multiple statements), yield acts like return but for switch:
   case X -> { doSomething(); yield computedValue; }

Q: What features were introduced in the Java 12–17 era that are now commonly used?
A: Records (Java 16) — immutable data classes. Sealed classes (Java 17) — restricted
   class hierarchies. Pattern matching for instanceof (Java 16) — removes explicit
   casts. Switch expressions (Java 14) — value-returning switch with no fall-through.
   Text blocks (Java 15) — multiline strings. Helpful NPEs (Java 14) — better error
   messages. Stream.toList() (Java 16) — short form of collect(Collectors.toList()).

Q: What is the difference between List.of() and Stream.toList()?
A: Both return unmodifiable lists that reject null. List.of() creates a list from
   explicit varargs. Stream.toList() (Java 16) collects all elements of a stream into
   an unmodifiable list. The difference is the source: List.of() is a static factory;
   Stream.toList() is a terminal stream operation equivalent to
   collect(Collectors.toUnmodifiableList()).
