SUBSETS (LC 78) -- no duplicates in input
----------------------------------------------------------------
Generate all 2^n subsets.

  APPROACH 1: Backtracking (start index prevents re-picking earlier elements)
    List<List<Integer>> subsets(int[] nums) {
      List<List<Integer>> res = new ArrayList<>();
      backtrack(nums, 0, new ArrayList<>(), res);
      return res;
    }
    void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
      res.add(new ArrayList<>(path));  // add current subset (including empty)
      for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        backtrack(nums, i + 1, path, res);  // i+1: no reuse
        path.remove(path.size() - 1);       // backtrack
      }
    }

  APPROACH 2: Bit manipulation -- each of 2^n bitmasks represents a subset
    for (int mask = 0; mask < (1 << n); mask++) {
      List<Integer> subset = new ArrayList<>();
      for (int j = 0; j < n; j++)
        if ((mask >> j & 1) == 1) subset.add(nums[j]);
      res.add(subset);
    }

  Time: O(n * 2^n)  Space: O(n) recursion depth + O(n * 2^n) result

----------------------------------------------------------------
SUBSETS II (LC 90) -- with duplicates in input
----------------------------------------------------------------
Sort first, then skip duplicates at the same recursion level.

  void backtrack(int[] nums, int start, ...) {
    res.add(new ArrayList<>(path));
    for (int i = start; i < nums.length; i++) {
      if (i > start && nums[i] == nums[i-1]) continue;  // skip duplicate
      path.add(nums[i]);
      backtrack(nums, i + 1, path, res);
      path.remove(path.size() - 1);
    }
  }
  // Must sort nums[] first: Arrays.sort(nums);

  Key insight: `i > start` (not `i > 0`) -- we allow using the same VALUE
  in different recursion levels, just not at the SAME level.

PERMUTATIONS (LC 46) -- no duplicates
----------------------------------------------------------------
Generate all n! permutations.

  APPROACH: boolean used[] array, try each unused element
    void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
      if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
      for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        backtrack(nums, used, path, res);
        path.remove(path.size() - 1);
        used[i] = false;  // backtrack
      }
    }

  Time: O(n * n!)  Space: O(n) depth + O(n * n!) result

  APPROACH 2: Swap-based (in-place, no extra array)
    void permute(int[] nums, int start, List<List<Integer>> res) {
      if (start == nums.length) { res.add(...); return; }
      for (int i = start; i < nums.length; i++) {
        swap(nums, start, i);           // choose nums[i] at position start
        permute(nums, start + 1, res);
        swap(nums, start, i);           // backtrack
      }
    }

----------------------------------------------------------------
PERMUTATIONS II (LC 47) -- with duplicates
----------------------------------------------------------------
Sort, use `used[]`, skip if same value and previous not used.

  for (int i = 0; i < nums.length; i++) {
    if (used[i]) continue;
    // Skip duplicate: same value as previous AND previous was not used in this path
    if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;
    used[i] = true;
    path.add(nums[i]);
    backtrack(nums, used, path, res);
    path.remove(path.size() - 1);
    used[i] = false;
  }

  Why `!used[i-1]`? We enforce that equal elements are always used
  in order (index i-1 must be used before index i). When the previous
  occurrence of the same value has been backtracked (!used[i-1]) and
  we're at i, we'd generate a duplicate branch -- skip it.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Subsets use `start` index to prevent re-picking earlier elements
  2. Permutations use `used[]` because order matters (all elements usable)
  3. Duplicate handling: sort first, then skip `nums[i] == nums[i-1]`
     at same level (subsets) or with `!used[i-1]` (permutations)
  4. Copy path before adding to results: `new ArrayList<>(path)`
  5. Subsets: add result at EVERY node; Permutations: only at LEAF
