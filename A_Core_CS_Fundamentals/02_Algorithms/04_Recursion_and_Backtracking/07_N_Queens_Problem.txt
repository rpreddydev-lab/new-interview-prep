================================================================
  N-QUEENS PROBLEM (LC 51 / 52)
================================================================

----------------------------------------------------------------
PROBLEM
----------------------------------------------------------------
Place n queens on an n x n chessboard such that no two queens
attack each other (no two share same row, column, or diagonal).

Return all valid board configurations (LC 51) or just count (LC 52).

----------------------------------------------------------------
KEY INSIGHTS
----------------------------------------------------------------
  1. Place ONE queen per row (since no two queens in same row)
  2. Track three sets to detect conflicts:
     - cols: occupied columns
     - diag1: occupied diagonals (row - col = constant)
     - diag2: occupied anti-diagonals (row + col = constant)

----------------------------------------------------------------
IMPLEMENTATION
----------------------------------------------------------------
  List<List<String>> solveNQueens(int n) {
    List<List<String>> res = new ArrayList<>();
    int[] queens = new int[n];   // queens[row] = column of queen in this row
    Arrays.fill(queens, -1);
    Set<Integer> cols   = new HashSet<>();
    Set<Integer> diag1  = new HashSet<>();  // row - col
    Set<Integer> diag2  = new HashSet<>();  // row + col
    backtrack(0, n, queens, cols, diag1, diag2, res);
    return res;
  }

  void backtrack(int row, int n, int[] queens,
                 Set<Integer> cols, Set<Integer> diag1, Set<Integer> diag2,
                 List<List<String>> res) {
    if (row == n) {
      res.add(buildBoard(queens, n));
      return;
    }
    for (int col = 0; col < n; col++) {
      if (cols.contains(col)) continue;
      if (diag1.contains(row - col)) continue;
      if (diag2.contains(row + col)) continue;
      // Place queen
      queens[row] = col;
      cols.add(col);
      diag1.add(row - col);
      diag2.add(row + col);
      backtrack(row + 1, n, queens, cols, diag1, diag2, res);
      // Remove queen (backtrack)
      queens[row] = -1;
      cols.remove(col);
      diag1.remove(row - col);
      diag2.remove(row + col);
    }
  }

  List<String> buildBoard(int[] queens, int n) {
    List<String> board = new ArrayList<>();
    for (int r = 0; r < n; r++) {
      char[] row = new char[n];
      Arrays.fill(row, '.');
      row[queens[r]] = 'Q';
      board.add(new String(row));
    }
    return board;
  }

----------------------------------------------------------------
BITMASK OPTIMIZATION
----------------------------------------------------------------
Use integers as bitmasks instead of HashSets for O(1) checks.

  void backtrack(int row, int n, int colMask, int diag1Mask, int diag2Mask, ...) {
    if (row == n) { count++; return; }
    int available = ((1 << n) - 1) & ~(colMask | diag1Mask | diag2Mask);
    while (available != 0) {
      int bit = available & (-available);  // lowest set bit
      available &= available - 1;          // clear lowest set bit
      int col = Integer.numberOfTrailingZeros(bit);
      backtrack(row + 1, n, colMask | bit,
                (diag1Mask | bit) << 1,   // shift for next row
                (diag2Mask | bit) >> 1,   // shift for next row
                ...);
    }
  }

  This is the fastest N-Queens solution, commonly seen in competitive programming.

----------------------------------------------------------------
COMPLEXITY
----------------------------------------------------------------
  Time: O(n!) in worst case (backtracking prunes heavily)
  Actual solutions for n=8: 92, n=12: 14200, n=15: ~2M
  Space: O(n) for the recursion depth + sets

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Diagonal trick: row-col constant for same diagonal;
     row+col constant for same anti-diagonal -- this is KEY
  2. One queen per row: iterate rows, try each column position
  3. Three conflict sets: cols, diag1 (row-col), diag2 (row+col)
  4. For LC 52 (just count): eliminate board building; count++
  5. Bitmask version: mention as optimization but implement
     HashSet version first for clarity in interviews
