================================================================
  CLOSEST PAIR OF POINTS
================================================================

----------------------------------------------------------------
PROBLEM
----------------------------------------------------------------
Given n points in 2D space, find the pair of points with the
smallest Euclidean distance between them.

  Naive: O(n^2) -- check all pairs
  D&C:   O(n log n)

----------------------------------------------------------------
DIVIDE AND CONQUER ALGORITHM
----------------------------------------------------------------
  1. SORT points by x-coordinate: O(n log n)

  2. DIVIDE at midpoint (median x): left half and right half

  3. CONQUER: find closest pair in each half
     d_left = closestPair(left half)
     d_right = closestPair(right half)
     d = min(d_left, d_right)

  4. COMBINE (the tricky part):
     The closest pair might span both halves.
     These must be within distance d of the dividing line (strip).
     - Collect points in strip: |x - midX| < d
     - Sort strip by y-coordinate
     - For each strip point, check at most 7 following points:
       (proven: in a d x 2d rectangle, at most 8 points can fit
        if all pairwise distances >= d)
     - O(n) per level -> O(n log n) total

  double closestPairRec(Point[] pts, int left, int right) {
    if (right - left <= 3) return bruteForce(pts, left, right);
    int mid = (left + right) / 2;
    double midX = pts[mid].x;
    double d = Math.min(
      closestPairRec(pts, left, mid),
      closestPairRec(pts, mid + 1, right)
    );
    // Build strip
    List<Point> strip = new ArrayList<>();
    for (int i = left; i <= right; i++)
      if (Math.abs(pts[i].x - midX) < d) strip.add(pts[i]);
    strip.sort((a, b) -> Double.compare(a.y, b.y));
    // Check strip
    for (int i = 0; i < strip.size(); i++)
      for (int j = i+1; j < strip.size() && strip.get(j).y - strip.get(i).y < d; j++)
        d = Math.min(d, dist(strip.get(i), strip.get(j)));
    return d;
  }

  Time: T(n) = 2T(n/2) + O(n log n)  ->  O(n log^2 n)
  With pre-sorted y array passed down: O(n log n)

----------------------------------------------------------------
WHY AT MOST 7 POINTS IN STRIP
----------------------------------------------------------------
In a d x 2d rectangle (d = current best distance), divide it
into 8 cells of d/2 x d/2 each. By pigeonhole, if 9 points are
in the rectangle, at least 2 are in the same cell, and their
distance <= sqrt(2) * d/2 < d -- contradiction (all distances >= d).
So at most 8 points. In practice: checking 7 subsequent is enough.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. The combine step is the key insight: strip of width 2d,
     only check 7 subsequent points per strip point
  2. Pre-sort by x once; maintain a y-sorted array alongside
     for O(n log n) total
  3. Floating point: use squared distances to avoid sqrt() computation
  4. Edge case: duplicate points -> distance = 0
  5. This is a classic example where D&C's combine step requires
     careful analysis (the "7 points" proof)
