================================================================
  FAST POWER (EXPONENTIATION BY SQUARING)
================================================================

----------------------------------------------------------------
PROBLEM
----------------------------------------------------------------
Compute x^n efficiently. Naive: O(n) multiplications.
D&C approach: O(log n) multiplications.

----------------------------------------------------------------
KEY INSIGHT
----------------------------------------------------------------
  x^n = x^(n/2) * x^(n/2)       if n is even  (squaring)
  x^n = x * x^(n/2) * x^(n/2)   if n is odd

  Only need to compute x^(n/2) ONCE and square it.
  Reduces multiplications from n to log2(n).

----------------------------------------------------------------
RECURSIVE IMPLEMENTATION
----------------------------------------------------------------
  double fastPow(double x, long n) {
    if (n == 0) return 1.0;
    if (n < 0) return 1.0 / fastPow(x, -n);  // handle negative exponent
    if (n % 2 == 0) {
      double half = fastPow(x, n / 2);
      return half * half;                     // only ONE recursive call!
    } else {
      return x * fastPow(x, n - 1);           // or: x * fastPow(x, n/2)^2
    }
  }

  Time: O(log n)   Space: O(log n) call stack

  Note: n is long to handle n = Integer.MIN_VALUE without overflow
  when negating (Integer.MIN_VALUE negated overflows int range).

----------------------------------------------------------------
ITERATIVE IMPLEMENTATION (no stack)
----------------------------------------------------------------
  double fastPow(double x, long n) {
    if (n < 0) { x = 1.0 / x; n = -n; }
    double result = 1.0;
    while (n > 0) {
      if ((n & 1) == 1) result *= x;  // if current bit is 1: multiply
      x *= x;                         // square for next bit
      n >>= 1;                        // shift to next bit
    }
    return result;
  }

  Example: x^13, n = 13 = 1101 in binary
    bit 1 (n&1=1): result *= x    -> result = x,    x = x^2, n=6
    bit 0 (n&1=0): result *= 1    -> result = x,    x = x^4, n=3
    bit 1 (n&1=1): result *= x^4  -> result = x^5,  x = x^8, n=1
    bit 1 (n&1=1): result *= x^8  -> result = x^13, x = x^16, n=0
    Final: x^13

----------------------------------------------------------------
MODULAR EXPONENTIATION
----------------------------------------------------------------
For large n, compute (x^n) mod m to prevent overflow.

  long modPow(long x, long n, long mod) {
    long result = 1;
    x %= mod;
    while (n > 0) {
      if ((n & 1) == 1) result = result * x % mod;
      x = x * x % mod;
      n >>= 1;
    }
    return result;
  }

  Used in: cryptography (RSA), competitive programming,
  Fibonacci in O(log n) via matrix exponentiation.

----------------------------------------------------------------
MATRIX EXPONENTIATION
----------------------------------------------------------------
Extend fast power to matrices. Enables computing:
  - Fibonacci(n) in O(log n)
  - Linear recurrences in O(log n)

  [[1,1],[1,0]]^n = [[F(n+1), F(n)], [F(n), F(n-1)]]

  // Matrix multiply mod m

  long[][] matPow(long[][] M, long n, long mod) {
    // Same fast-power structure but with matrix multiplication
  }

  Time: O(k^3 * log n)  where k = matrix dimension (k=2 for Fibonacci)

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Fast power (Pow(x, n) LC 50) is a very common interview problem
  2. Always handle n < 0: return 1.0 / fastPow(x, -n)
  3. Use long for n to handle Integer.MIN_VALUE edge case
  4. Iterative version preferred: no stack overflow risk
  5. Modular exponentiation: take mod at every multiplication step
     to prevent 64-bit integer overflow
  6. Matrix exponentiation: mention for Fibonacci in O(log n) --
     impressive to know in interviews
