----------------------------------------------------------------
FORMULAS
----------------------------------------------------------------
  P(n, k) = n! / (n-k)!      = number of ordered selections of k from n
  C(n, k) = n! / (k! * (n-k)!) = number of unordered selections of k from n
  C(n, k) = C(n-1, k-1) + C(n-1, k)  (Pascal's rule)
  C(n, k) = C(n, n-k)  (symmetry)

  Catalan number: C(n) = C(2n,n) / (n+1) = 1,1,2,5,14,42,...
    Applications: balanced parentheses, BST shapes, polygon triangulation

----------------------------------------------------------------
COMPUTING C(n, k) EFFICIENTLY
----------------------------------------------------------------
  // Using Pascal's triangle: O(n*k) time, O(n*k) space
  long[][] C = new long[n+1][k+1];
  C[0][0] = 1;
  for (int i = 1; i <= n; i++)
    for (int j = 0; j <= Math.min(i, k); j++)
      C[i][j] = (j==0 ? 1 : C[i-1][j-1]) + (j==i ? 0 : C[i-1][j]);

  // Direct with modular arithmetic (modular inverse)
  long comb(int n, int k, long mod) {
    long num = 1, den = 1;
    for (int i = 0; i < k; i++) {
      num = num * ((n - i) % mod) % mod;
      den = den * (i + 1) % mod;
    }
    return num * modPow(den, mod-2, mod) % mod;  // Fermat's little theorem
  }
  // Works only when mod is prime

----------------------------------------------------------------
CATALAN NUMBER APPLICATIONS
----------------------------------------------------------------
  C(0)=1, C(1)=1, C(2)=2, C(3)=5, C(4)=14
  - Number of valid parenthesizations of n+1 factors
  - Number of distinct BSTs with n nodes
  - Number of full binary trees with n+1 leaves
  - Paths in grid that don't cross diagonal

  catalan(n) = C(2n, n) / (n + 1)

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. C(n,k) = C(n, n-k): use smaller k for efficiency
  2. Pascal's triangle precomputation: useful for multiple queries
  3. Modular C(n,k): use Fermat's little theorem for inverse when mod is prime
  4. Catalan numbers: whenever problem asks "how many structures" for n elements,
     think Catalan
  5. Overflow: even C(20,10) = 184756 fits in int; C(40,20) needs long
