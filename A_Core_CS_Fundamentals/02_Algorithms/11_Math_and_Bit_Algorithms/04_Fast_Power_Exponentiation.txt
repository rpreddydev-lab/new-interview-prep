================================================================
  FAST POWER (BINARY EXPONENTIATION)
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Compute x^n in O(log n) instead of O(n).
  x^n = (x^(n/2))^2 if n is even
  x^n = x * (x^((n-1)/2))^2 if n is odd

  Recursive:
  double myPow(double x, int n) {
    if (n == 0) return 1.0;
    if (n < 0) return 1.0 / myPow(x, -(long)n);  // handle INT_MIN overflow
    if (n % 2 == 0) { double half = myPow(x, n/2); return half * half; }
    return x * myPow(x, n-1);
  }

  Iterative (binary representation):
  double fastPow(double x, long n) {
    if (n < 0) { x = 1.0/x; n = -n; }
    double result = 1.0;
    while (n > 0) {
      if ((n & 1) == 1) result *= x;  // if current bit is 1
      x *= x;  // square x
      n >>= 1; // next bit
    }
    return result;
  }

  Key insight: n in binary = sum of powers of 2.
  x^13 = x^(1101_2) = x^8 * x^4 * x^1 (bit 3, 2, 0 are set)

----------------------------------------------------------------
MODULAR EXPONENTIATION
----------------------------------------------------------------
  long modPow(long base, long exp, long mod) {
    long result = 1;
    base %= mod;
    while (exp > 0) {
      if ((exp & 1) == 1) result = result * base % mod;
      base = base * base % mod;
      exp >>= 1;
    }
    return result;
  }

  Applications: RSA encryption, competitive programming,
  large number computations (e.g., 2^31 mod 10^9+7).

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Handle n < 0: x^(-n) = 1/x^n; use long n to avoid INT_MIN overflow
  2. Handle n == INT_MIN: -(int)INT_MIN = INT_MIN (overflow!) -- cast to long
  3. Iterative fast power is preferred over recursive (no stack overhead)
  4. Modular exponentiation: take mod at every multiply step to prevent overflow
  5. Matrix exponentiation: O(k^3 log n) for k*k matrices; use for
     tribonacci (3x3) and other linear recurrences
