  SIEVE OF ERATOSTHENES
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Find all primes up to n in O(n log log n) time.
Mark all multiples of each prime as composite.

  boolean[] sieve(int n) {
    boolean[] isPrime = new boolean[n + 1];
    Arrays.fill(isPrime, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i * i <= n; i++) {   // only up to sqrt(n)
      if (isPrime[i]) {
        for (int j = i * i; j <= n; j += i)  // start at i^2 (smaller already marked)
          isPrime[j] = false;
      }
    }
    return isPrime;
  }
  Time: O(n log log n)  Space: O(n)

  Collect primes: for (int i=2; i<=n; i++) if (isPrime[i]) primes.add(i);

  Why start inner loop at i*i?
  All smaller multiples (i*2, i*3, ..., i*(i-1)) were already
  marked by smaller primes (2, 3, ..., i-1).

----------------------------------------------------------------
SEGMENTED SIEVE (for large ranges)
----------------------------------------------------------------
Find primes in [L, R] where R is very large but R-L is manageable.
  1. Sieve up to sqrt(R) to get small primes.
  2. For each small prime p: mark multiples in [L, R].

  Time: O(sqrt(R) log log sqrt(R) + (R-L) log log sqrt(R))

----------------------------------------------------------------
COUNT PRIMES (LC 204)
----------------------------------------------------------------
  int countPrimes(int n) {
    boolean[] notPrime = new boolean[n];
    int count = 0;
    for (int i = 2; i < n; i++) {
      if (!notPrime[i]) {
        count++;
        for (long j = (long)i*i; j < n; j += i) notPrime[(int)j] = true;
      }
    }
    return count;
  }
  // Use long for j = i*i to avoid overflow when i is large

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Sieve: outer loop to sqrt(n); inner loop starts at i*i
  2. Use notPrime (mark composites) or isPrime (mark primes) -- same logic
  3. LC 204: j = (long)i*i to prevent int overflow (i can be up to sqrt(10^6))
  4. Sieve gives O(1) primality query after O(n log log n) preprocessing
  5. For n up to 10^7: sieve is fast; for n > 10^8: segmented sieve needed
