================================================================
  XOR TRICKS
================================================================

----------------------------------------------------------------
XOR PROPERTIES
----------------------------------------------------------------
  a ^ a = 0        (self-cancellation)
  a ^ 0 = a        (identity)
  a ^ b = b ^ a    (commutative)
  (a^b)^c = a^(b^c) (associative)

  Consequence: XOR of all elements where each appears twice = 0.
  If one element appears once, XOR of all = that element.

----------------------------------------------------------------
SINGLE NUMBER (LC 136)
----------------------------------------------------------------
Every element appears twice except one. Find it.
  int singleNumber(int[] nums) {
    int result = 0;
    for (int n : nums) result ^= n;
    return result;  // all pairs cancel; only unique remains
  }
  Time: O(n)  Space: O(1)

----------------------------------------------------------------
SINGLE NUMBER II (LC 137) -- appears 3 times except one
----------------------------------------------------------------
Count bits modulo 3. Bit that doesn't cancel = the unique number's bit.
  int singleNumber2(int[] nums) {
    int ones = 0, twos = 0;
    for (int n : nums) {
      ones = (ones ^ n) & ~twos;
      twos = (twos ^ n) & ~ones;
    }
    return ones;
  }

----------------------------------------------------------------
SINGLE NUMBER III (LC 260) -- two unique numbers
----------------------------------------------------------------
Two numbers appear once, rest appear twice.
  1. XOR all: result = a ^ b (where a, b are the unique numbers)
  2. Find any set bit in result (say lowest: diff = diff & (-diff))
  3. Partition numbers into two groups by that bit
  4. XOR each group = a or b

  int[] singleNumber3(int[] nums) {
    int diff = 0;
    for (int n : nums) diff ^= n;  // diff = a ^ b
    diff &= -diff;  // lowest set bit (a and b differ here)
    int[] res = {0, 0};
    for (int n : nums) {
      if ((n & diff) == 0) res[0] ^= n;
      else res[1] ^= n;
    }
    return res;
  }

----------------------------------------------------------------
XOR MAXIMUM SUBARRAY (LC 1310)
----------------------------------------------------------------
XOR queries on array range: use prefix XOR.
  prefix[i] = nums[0] ^ nums[1] ^ ... ^ nums[i-1]
  XOR(l, r) = prefix[r+1] ^ prefix[l]
  (same idea as prefix sum for range sum queries)

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. XOR of duplicates = 0; XOR of all = single non-duplicate
  2. "Appears k times except one" -> count bits modulo k
  3. Two unique numbers: XOR gives a^b; split by any differing bit
  4. XOR range query: prefix XOR array, then prefix[r+1]^prefix[l]
  5. Maximum XOR of two numbers: binary Trie (greedy from MSB)
     For each number, greedily choose opposite bit in Trie (LC 421)
