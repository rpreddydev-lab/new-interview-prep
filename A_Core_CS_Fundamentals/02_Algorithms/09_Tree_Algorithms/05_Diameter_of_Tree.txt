================================================================
  DIAMETER OF BINARY TREE
================================================================

----------------------------------------------------------------
CORE CONCEPT
----------------------------------------------------------------
Diameter = longest path between any two nodes (may not pass through root).
Length is measured in NUMBER OF EDGES.

  At each node: path through this node = left_height + right_height.
  Global answer = max over all nodes of (left_height + right_height).

  int maxDiameter = 0;
  int diameterOfBinaryTree(TreeNode root) {
    depth(root);
    return maxDiameter;
  }
  int depth(TreeNode node) {
    if (node == null) return 0;
    int left = depth(node.left);
    int right = depth(node.right);
    maxDiameter = Math.max(maxDiameter, left + right);  // update global
    return 1 + Math.max(left, right);                   // return to parent
  }
  Time: O(n)  Space: O(h)

  KEY INSIGHT: Return value (height) and answer updated (diameter) are DIFFERENT.

----------------------------------------------------------------
DIAMETER OF N-ARY TREE
----------------------------------------------------------------
  For N-ary tree: at each node, take top 2 children heights.
  int[] top2 = {0, 0};  // two largest heights
  for (Node child : node.children) {
    int h = depth(child);
    if (h > top2[0]) { top2[1] = top2[0]; top2[0] = h; }
    else if (h > top2[1]) { top2[1] = h; }
  }
  diameter = Math.max(diameter, top2[0] + top2[1]);

----------------------------------------------------------------
BINARY TREE MAXIMUM PATH SUM (LC 124)
----------------------------------------------------------------
Related: max sum path. Same pattern but with values.
  int maxSum = Integer.MIN_VALUE;
  int maxPathSum(TreeNode root) { gain(root); return maxSum; }
  int gain(TreeNode node) {
    if (node == null) return 0;
    int left = Math.max(0, gain(node.left));   // discard negative
    int right = Math.max(0, gain(node.right));
    maxSum = Math.max(maxSum, node.val + left + right);  // path through node
    return node.val + Math.max(left, right);             // best single branch
  }

  Note: max(0, gain) discards paths that decrease the sum.
  If all values negative: single node = answer (MIN_VALUE init).

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Diameter: return HEIGHT, but update DIAMETER (left+right at node)
  2. This split-return-vs-update pattern appears in many tree problems
  3. Max Path Sum: same pattern but add max(0, ...) to discard negatives
  4. Always initialize global to MIN_VALUE for path sum (all negative case)
  5. Edge case: single node tree -> diameter = 0, max path = that node's value
