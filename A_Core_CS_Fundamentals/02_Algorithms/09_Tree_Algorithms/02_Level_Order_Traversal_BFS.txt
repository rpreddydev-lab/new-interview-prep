================================================================
  LEVEL ORDER TRAVERSAL (BFS ON TREES)
================================================================

----------------------------------------------------------------
STANDARD LEVEL ORDER
----------------------------------------------------------------
  List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
      int size = queue.size();  // snapshot: current level count
      List<Integer> level = new ArrayList<>();
      for (int i = 0; i < size; i++) {
        TreeNode node = queue.poll();
        level.add(node.val);
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
      }
      result.add(level);
    }
    return result;
  }
  Time: O(n)  Space: O(n) -- at most n/2 nodes at last level

----------------------------------------------------------------
VARIANTS
----------------------------------------------------------------
  Zigzag Level Order (LC 103):
    Use boolean leftToRight flag. Flip each level.
    Or use Deque: add to front when right-to-left, back when left-to-right.

  Bottom-up Level Order (LC 107):
    Run normal level order, then Collections.reverse(result).

  Right Side View (LC 199):
    Take LAST element of each level (or BFS rightmost first).

  Average of Levels (LC 637):
    Sum all values in level, divide by size.

  Vertical Order Traversal (LC 987):
    BFS with (node, col, row). Sort by (col, row, val).

  N-ary Tree Level Order (LC 429):
    Same pattern; add all children instead of left/right.

----------------------------------------------------------------
CONNECT NEXT POINTERS (LC 116/117)
----------------------------------------------------------------
Connect next pointers for perfect binary tree (LC 116):
  Process level by level. For each node in level:
    - Connect left.next = right
    - Connect right.next = node.next.left (if node.next exists)
  O(1) space using already-established next pointers.

  void connect(Node root) {
    if (root == null) return;
    Node leftmost = root;
    while (leftmost.left != null) {
      Node curr = leftmost;
      while (curr != null) {
        curr.left.next = curr.right;
        if (curr.next != null) curr.right.next = curr.next.left;
        curr = curr.next;
      }
      leftmost = leftmost.left;
    }
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Level order: snapshot queue.size() at start of each level's loop
  2. Zigzag: flip addFirst/addLast using a boolean flag, or deque
  3. Right Side View: track last element per level
  4. All level-order variants share the same BFS skeleton -- practice once, adapt
  5. Space: queue holds at most width of tree; O(n) for complete binary tree
