================================================================
  HEIGHT AND DEPTH OF TREE
================================================================

----------------------------------------------------------------
DEFINITIONS
----------------------------------------------------------------
  Height of node: length of LONGEST path from node DOWN to a leaf.
  Depth of node: length of path from ROOT DOWN to the node.
  Height of tree = height of root = max depth of any leaf.

  Leaf node: height = 0, or sometimes defined as 1 (varies by problem).
  Be careful: LeetCode uses height = 0 for leaf in some problems,
  height = 1 in others. Read problem carefully.

----------------------------------------------------------------
HEIGHT (RECURSIVE)
----------------------------------------------------------------
  int height(TreeNode node) {
    if (node == null) return -1;  // or 0 if counting nodes
    return 1 + Math.max(height(node.left), height(node.right));
  }
  Time: O(n)  Space: O(h) recursion stack

----------------------------------------------------------------
BALANCED BINARY TREE (LC 110)
----------------------------------------------------------------
A tree is height-balanced if at every node,
|height(left) - height(right)| <= 1.

Naive: O(n^2) -- check balance at every node recursively.
Optimal: O(n) -- return -1 as sentinel for "unbalanced".

  boolean isBalanced(TreeNode root) { return checkHeight(root) != -1; }
  int checkHeight(TreeNode node) {
    if (node == null) return 0;
    int left = checkHeight(node.left);
    if (left == -1) return -1;  // early termination
    int right = checkHeight(node.right);
    if (right == -1) return -1;
    if (Math.abs(left - right) > 1) return -1;  // unbalanced here
    return 1 + Math.max(left, right);
  }

----------------------------------------------------------------
MINIMUM DEPTH (LC 111)
----------------------------------------------------------------
Shortest path from root to nearest LEAF.
  NOTE: If only one child exists, must go that way (leaf requires both null).

  int minDepth(TreeNode root) {
    if (root == null) return 0;
    if (root.left == null && root.right == null) return 1;  // leaf
    if (root.left == null) return 1 + minDepth(root.right);  // must go right
    if (root.right == null) return 1 + minDepth(root.left); // must go left
    return 1 + Math.min(minDepth(root.left), minDepth(root.right));
  }

  BFS is optimal for min depth (stops at first leaf found).

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Height: return -1 for null (edge count) or 0 for null (node count)
     -- clarify with interviewer which convention
  2. Balanced check: use -1 sentinel to short-circuit -- O(n) vs O(n^2)
  3. Min depth pitfall: don't return 0 for missing child (must traverse
     to the existing child)
  4. Max depth (LC 104) = height of root = classic recursion
  5. For min depth: BFS preferred over DFS (exits early at first leaf)
