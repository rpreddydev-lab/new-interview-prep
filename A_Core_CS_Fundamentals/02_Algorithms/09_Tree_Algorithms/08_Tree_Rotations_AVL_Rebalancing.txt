================================================================
  TREE ROTATIONS AND AVL REBALANCING
================================================================

----------------------------------------------------------------
CORE CONCEPT
----------------------------------------------------------------
Rotations change tree structure without violating BST property.
Used by AVL trees and Red-Black trees to maintain balance.

Balance Factor (BF) = height(left) - height(right).
AVL tree maintains |BF| <= 1 at every node.

----------------------------------------------------------------
RIGHT ROTATION
----------------------------------------------------------------
Apply when left-heavy (BF > 1).

  Before:      After:
       y             x
      /             / \
     x             A   y
    / \               / \
   A   B             B   C

  TreeNode rotateRight(TreeNode y) {
    TreeNode x = y.left;
    TreeNode B = x.right;
    x.right = y;
    y.left = B;
    y.height = 1 + Math.max(height(y.left), height(y.right));
    x.height = 1 + Math.max(height(x.left), height(x.right));
    return x;
  }

----------------------------------------------------------------
LEFT ROTATION
----------------------------------------------------------------
Apply when right-heavy (BF < -1).

  Before:      After:
     x               y
      \             / \
       y           x   C
      / \         / \
     B   C       A   B

  TreeNode rotateLeft(TreeNode x) {
    TreeNode y = x.right;
    TreeNode B = y.left;
    y.left = x;
    x.right = B;
    x.height = 1 + Math.max(height(x.left), height(x.right));
    y.height = 1 + Math.max(height(y.left), height(y.right));
    return y;
  }

----------------------------------------------------------------
AVL REBALANCING CASES
----------------------------------------------------------------
  Case               Condition             Fix
  -----              ---------             ---
  Left-Left (LL)     BF > 1, leftBF >= 0   rotateRight(node)
  Left-Right (LR)    BF > 1, leftBF < 0    rotateLeft(left), rotateRight(node)
  Right-Right (RR)   BF < -1, rightBF <= 0 rotateLeft(node)
  Right-Left (RL)    BF < -1, rightBF > 0  rotateRight(right), rotateLeft(node)

  TreeNode rebalance(TreeNode node) {
    int bf = getBalance(node);
    if (bf > 1) {
      if (getBalance(node.left) < 0) node.left = rotateLeft(node.left);  // LR
      return rotateRight(node);  // LL or LR after fixing
    }
    if (bf < -1) {
      if (getBalance(node.right) > 0) node.right = rotateRight(node.right);  // RL
      return rotateLeft(node);  // RR or RL after fixing
    }
    return node;
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Rotations preserve BST property (inorder stays the same)
  2. LL/RR = single rotation; LR/RL = double rotation (straighten then rotate)
  3. Balance factor: positive = left-heavy, negative = right-heavy
  4. In practice: Java uses TreeMap (Red-Black tree), not AVL -- but know AVL for interviews
  5. After any insert/delete in AVL: update heights bottom-up and rebalance
