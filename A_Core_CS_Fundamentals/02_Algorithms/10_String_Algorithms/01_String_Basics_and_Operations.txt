================================================================
  STRING BASICS AND OPERATIONS IN JAVA
================================================================

----------------------------------------------------------------
JAVA STRING FUNDAMENTALS
----------------------------------------------------------------
  String:        immutable; concatenation creates new String object
  StringBuilder: mutable, O(1) amortized append; use for building strings
  char[]:        low-level; use when modifying individual chars

  Key methods:
    s.length()                 O(1)
    s.charAt(i)                O(1)
    s.substring(i, j)          O(j-i) -- creates new String
    s.indexOf(ch)              O(n)
    s.equals(t)                O(n)
    s.compareTo(t)             O(n) -- lexicographic
    s.toCharArray()            O(n)
    s.toLowerCase()            O(n)
    s.trim()                   O(n)
    s.split(regex)             O(n)
    s.replace(old, new)        O(n)
    String.valueOf(char[])     O(n)
    new String(char[])         O(n)

  StringBuilder ops:
    sb.append(x)               O(1) amortized
    sb.insert(i, x)            O(n)
    sb.delete(i, j)            O(n)
    sb.reverse()               O(n)
    sb.toString()              O(n)

----------------------------------------------------------------
CHARACTER OPERATIONS
----------------------------------------------------------------
  Character.isLetter(c)        -- is letter
  Character.isDigit(c)         -- is 0-9
  Character.isLetterOrDigit(c) -- alphanumeric
  Character.toLowerCase(c)     -- to lower
  c - 'a'                      -- letter to 0-25 index
  c - '0'                      -- digit char to int

  Frequency array: int[] freq = new int[26]; freq[c - 'a']++;

----------------------------------------------------------------
COMMON STRING PATTERNS
----------------------------------------------------------------
  1. TWO POINTERS for palindrome check:
     int l = 0, r = s.length() - 1;
     while (l < r) if (s.charAt(l++) != s.charAt(r--)) return false;

  2. SLIDING WINDOW for substring problems:
     Track character counts with frequency array or HashMap.

  3. FREQUENCY MAP for anagram problems:
     int[] count = new int[26];
     for (char c : s.toCharArray()) count[c-'a']++;
     for (char c : t.toCharArray()) count[c-'a']--;
     for (int x : count) if (x != 0) return false;

  4. REVERSE WORDS:
     String[] words = s.trim().split("\\s+");
     Reverse array, join with " ".

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Always use StringBuilder (not +) for O(n) string building vs O(n^2)
  2. String is immutable in Java -- each concatenation is new allocation
  3. Use char[] or int[26] frequency arrays for O(1) lookup in char problems
  4. substring() is O(k) in Java 8+ (was O(1) with offset sharing in Java 6/7)
  5. split() with regex ',' is simple; split("\\.") needs escape for dot
