================================================================
  KMP PATTERN MATCHING
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Find all occurrences of pattern P in text T in O(n + m) time.
Naive approach: O(n*m). KMP avoids redundant comparisons.

KEY: Build the FAILURE FUNCTION (partial match table, LPS array).
  lps[i] = length of longest proper prefix of P[0..i] that is also a suffix.
  lps[] tells us how far to skip when a mismatch occurs.

  "Proper" = not the full string itself.
  Example: P = "AABAAB"
    lps = [0, 1, 0, 1, 2, 3]

----------------------------------------------------------------
BUILD LPS ARRAY
----------------------------------------------------------------
  int[] buildLPS(String pattern) {
    int m = pattern.length();
    int[] lps = new int[m];
    int len = 0;  // length of previous longest prefix suffix
    int i = 1;
    while (i < m) {
      if (pattern.charAt(i) == pattern.charAt(len)) {
        lps[i++] = ++len;
      } else {
        if (len != 0) len = lps[len - 1];  // don't increment i
        else lps[i++] = 0;
      }
    }
    return lps;
  }

----------------------------------------------------------------
KMP SEARCH
----------------------------------------------------------------
  List<Integer> kmpSearch(String text, String pattern) {
    int n = text.length(), m = pattern.length();
    int[] lps = buildLPS(pattern);
    List<Integer> matches = new ArrayList<>();
    int i = 0, j = 0;  // i for text, j for pattern
    while (i < n) {
      if (text.charAt(i) == pattern.charAt(j)) { i++; j++; }
      if (j == m) {
        matches.add(i - j);  // match found at index i-j
        j = lps[j - 1];      // continue looking for more matches
      } else if (i < n && text.charAt(i) != pattern.charAt(j)) {
        if (j != 0) j = lps[j - 1];  // skip using lps
        else i++;                      // no skip possible, advance text
      }
    }
    return matches;
  }

  Time: O(n + m)  Space: O(m)

----------------------------------------------------------------
KMP APPLICATIONS
----------------------------------------------------------------
  1. Shortest Palindrome (LC 214):
     Append reverse: s + '#' + reverse(s). Build LPS.
     lps[last] = length of longest palindromic prefix.

  2. Repeated String Match (LC 686):
     KMP to check if B is substring of repeated A.

  3. String is rotation of another:
     A is rotation of B if A+A contains B (check with KMP).

  4. Minimum period of string:
     Period = m - lps[m-1] (if m % period == 0).

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. LPS[i] = longest proper prefix that is also suffix for P[0..i]
  2. When mismatch: j = lps[j-1] (don't restart from 0)
  3. KMP is O(n+m); Robin-Karp also O(n+m) average with hashing
  4. Separator '#' in concatenation prevents lps from crossing boundary
  5. Most interviews accept O(n*m) naive; mention KMP for bonus points
