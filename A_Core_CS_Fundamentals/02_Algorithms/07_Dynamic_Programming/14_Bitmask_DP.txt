================================================================
  BITMASK DP
================================================================

----------------------------------------------------------------
CORE CONCEPT
----------------------------------------------------------------
Use an integer as a bitmask to represent a SET of elements.
Bitmask DP: dp[mask] = answer when the set of visited/chosen
elements corresponds to `mask`.

  Useful when n is small (typically n <= 20, since 2^20 = 1M states).
  Enables polynomial-time solutions to problems that would otherwise
  be factorial.

  Bit operations:
    mask | (1 << i)     = add element i to set
    mask & ~(1 << i)    = remove element i from set
    (mask >> i) & 1     = check if element i is in set
    mask & (mask - 1)   = remove lowest set bit
    mask & (-mask)      = keep only lowest set bit
    Integer.bitCount(mask) = count elements in set

----------------------------------------------------------------
TRAVELING SALESMAN PROBLEM (TSP) -- O(n^2 * 2^n)
----------------------------------------------------------------
Find shortest Hamiltonian cycle through all n cities.

  dp[mask][i] = min cost to visit all cities in `mask`,
                ending at city i
  Transition: dp[mask][i] = min over j in mask (j != i):
              dp[mask ^ (1<<i)][j] + dist[j][i]
  Base: dp[1<<i][i] = dist[0][i] (start from city 0)
  Answer: min over i of: dp[(1<<n)-1][i] + dist[i][0]

  int tsp(int[][] dist) {
    int n = dist.length;
    int full = (1 << n) - 1;
    int[][] dp = new int[1 << n][n];
    for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
    dp[1][0] = 0;  // start at city 0, visited = {0}
    for (int mask = 1; mask < (1 << n); mask++) {
      for (int u = 0; u < n; u++) {
        if ((mask & (1 << u)) == 0) continue;  // u not in mask
        if (dp[mask][u] == Integer.MAX_VALUE / 2) continue;
        for (int v = 0; v < n; v++) {
          if ((mask & (1 << v)) != 0) continue;  // v already visited
          int nextMask = mask | (1 << v);
          dp[nextMask][v] = Math.min(dp[nextMask][v], dp[mask][u] + dist[u][v]);
        }
      }
    }
    int res = Integer.MAX_VALUE;
    for (int u = 1; u < n; u++)
      res = Math.min(res, dp[full][u] + dist[u][0]);
    return res;
  }

  Time: O(n^2 * 2^n)  Space: O(n * 2^n)

----------------------------------------------------------------
ASSIGN COOKIES / ASSIGN TASKS
----------------------------------------------------------------
Assign workers to jobs to minimize total cost.
  dp[mask] = min cost to complete jobs represented by mask
             using the first bitCount(mask) workers.

  int assignWork(int[][] cost, int n) {
    int[] dp = new int[1 << n];
    Arrays.fill(dp, Integer.MAX_VALUE);
    dp[0] = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
      if (dp[mask] == Integer.MAX_VALUE) continue;
      int worker = Integer.bitCount(mask);  // which worker is next
      if (worker == n) continue;
      for (int job = 0; job < n; job++) {
        if ((mask & (1 << job)) != 0) continue;  // job already assigned
        dp[mask | (1 << job)] = Math.min(
          dp[mask | (1 << job)], dp[mask] + cost[worker][job]);
      }
    }
    return dp[(1 << n) - 1];
  }

  LC 1947: Maximum Compatibility Score Sum uses this exact pattern.

----------------------------------------------------------------
SUBSET ENUMERATION IN MASK DP
----------------------------------------------------------------
Enumerate all subsets of a given mask:
  for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // process subset `sub` of `mask`
  }
  Total across all masks: O(3^n) (each element is in superset, subset, or neither)

  Used in: SOS DP (Sum over Subsets), optimal partitioning problems.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Bitmask DP when n <= 20; for n <= 15: very fast in practice
  2. TSP is the canonical bitmask DP problem; know it
  3. State: (mask, last_vertex) or (mask, worker) depending on problem
  4. worker = Integer.bitCount(mask) = elegant trick to determine
     which worker to assign next
  5. Subset enumeration `(sub-1) & mask` pattern: O(3^n) total
     -- mention for problems involving all subsets of all subsets
