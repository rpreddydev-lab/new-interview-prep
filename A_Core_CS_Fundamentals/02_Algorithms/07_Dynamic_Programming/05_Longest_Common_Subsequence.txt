================================================================
  LONGEST COMMON SUBSEQUENCE (LCS)
================================================================

----------------------------------------------------------------
PROBLEM
----------------------------------------------------------------
Given strings s1 and s2, find the length of their longest common
subsequence (not necessarily contiguous).

  s1 = "ABCBDAB", s2 = "BDCAB" -> LCS = "BCAB" or "BDAB", length 4

----------------------------------------------------------------
DP FORMULATION
----------------------------------------------------------------
  State: dp[i][j] = LCS length of s1[0..i-1] and s2[0..j-1]
  Transition:
    If s1[i-1] == s2[j-1]: dp[i][j] = dp[i-1][j-1] + 1  (extend match)
    Else: dp[i][j] = max(dp[i-1][j], dp[i][j-1])         (skip one char)
  Base: dp[0][j] = 0, dp[i][0] = 0
  Answer: dp[m][n]

  int lcs(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++)
      for (int j = 1; j <= n; j++)
        if (s1.charAt(i-1) == s2.charAt(j-1))
          dp[i][j] = dp[i-1][j-1] + 1;
        else
          dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
    return dp[m][n];
  }

  Time: O(mn)  Space: O(mn) -- can reduce to O(n) with rolling array

  Space optimization:
    Only need previous row -> use two 1D arrays or single rolling array.

----------------------------------------------------------------
LCS VARIANTS
----------------------------------------------------------------
  Shortest Common Supersequence (SCS):
    Minimum length string containing both s1 and s2 as subsequences.
    SCS length = m + n - LCS(s1, s2)
    LC 1092: reconstruct SCS -- trace back DP table.

  Delete Operations for Two Strings (LC 583):
    Min deletions to make s1 == s2.
    Answer: m + n - 2 * LCS(s1, s2)

  Minimum Insertions/Deletions (LC 712 variant):
    Same idea: LCS = common core; rest must be deleted/inserted.

  Longest Common Substring (contiguous, not subsequence):
    dp[i][j] = length of longest common substring ending at s1[i-1], s2[j-1]
    dp[i][j] = dp[i-1][j-1] + 1  if s1[i-1] == s2[j-1],  else 0
    Track running max separately.

----------------------------------------------------------------
TRACEBACK TO RECONSTRUCT LCS
----------------------------------------------------------------
  String reconstructLCS(String s1, String s2, int[][] dp) {
    int i = s1.length(), j = s2.length();
    StringBuilder sb = new StringBuilder();
    while (i > 0 && j > 0) {
      if (s1.charAt(i-1) == s2.charAt(j-1)) {
        sb.append(s1.charAt(i-1));  // this char is in LCS
        i--; j--;
      } else if (dp[i-1][j] > dp[i][j-1]) {
        i--;          // came from dp[i-1][j]
      } else {
        j--;          // came from dp[i][j-1]
      }
    }
    return sb.reverse().toString();
  }

----------------------------------------------------------------
INTERVIEW QUESTIONS
----------------------------------------------------------------

Q: What is the difference between LCS and Longest Common Substring?
A: LCS (subsequence): characters don't need to be contiguous;
   they just need to appear in the same order. Length 4 in
   "ABCBDAB" and "BDCAB" (e.g., "BCAB").
   Longest Common Substring: characters must be contiguous in
   both strings. The DP state differs:
   LCS: dp[i][j] = max LCS considering full prefixes
   LCS-substring: dp[i][j] = length of common suffix at i,j;
   reset to 0 when mismatch, track global max separately.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. LCS recurrence: match -> diagonal+1; mismatch -> max(up, left)
  2. LCS length is used in many edit distance variants
  3. SCS length = m + n - LCS (inclusion-exclusion)
  4. Delete operations = m + n - 2*LCS
  5. Rolling 1D array for O(n) space:
     iterate j from n to 0 when updating, or use two alternating rows
