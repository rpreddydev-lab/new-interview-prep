WORD BREAK I (LC 139) -- Can string be segmented?
----------------------------------------------------------------
Given a string s and a wordDict, determine if s can be segmented
into space-separated dictionary words.

  DP:
  dp[i] = true if s[0..i-1] can be segmented.
  dp[0] = true (empty string)
  Transition: dp[i] = true if exists j (0 <= j < i) such that
              dp[j] == true AND s[j..i-1] is in wordDict.

  boolean wordBreak(String s, List<String> wordDict) {
    Set<String> dict = new HashSet<>(wordDict);
    int n = s.length();
    boolean[] dp = new boolean[n + 1];
    dp[0] = true;
    for (int i = 1; i <= n; i++)
      for (int j = 0; j < i; j++)
        if (dp[j] && dict.contains(s.substring(j, i))) {
          dp[i] = true;
          break;   // optimization: stop once dp[i] = true
        }
    return dp[n];
  }

  Time: O(n^2 * L) where L = avg word length for substring comparison
       With Trie: O(n^2) for trie traversal
  Space: O(n)

  Optimization: limit j to (i - maxWordLen) to avoid checking
  substrings longer than any word in dictionary.

----------------------------------------------------------------
WORD BREAK II (LC 140) -- Find all segmentations
----------------------------------------------------------------
Return all possible sentence segmentations.

  Use memoized DFS (backtracking + memo):
    Map<Integer, List<String>> memo = new HashMap<>();
    List<String> dfs(String s, int start, Set<String> dict, Map memo):
      if (start == s.length()) return [""]
      if memo contains start: return memo.get(start)
      result = []
      for end from start+1 to n:
        word = s[start..end-1]
        if dict.contains(word):
          for each sentence in dfs(s, end, dict, memo):
            result.add(word + (sentence.isEmpty() ? "" : " " + sentence))
      memo.put(start, result)
      return result

  Time: O(n^2 * 2^n) worst case (exponential in answer size)
  Space: O(n * 2^n) for results

  For LC 140, always check with LC 139 first -- if no solution exists,
  LC 140 returns empty list (DP check helps avoid TLE from DFS).

----------------------------------------------------------------
CONCATENATED WORDS (LC 472)
----------------------------------------------------------------
Find all words in a list that are formed by concatenating shorter words.
  Sort by length. For each word: run wordBreak with smaller words.
  or use Trie for efficiency.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Word Break I: O(n^2) DP; Word Break II: exponential worst case
  2. Optimization: track maxWordLen to limit inner loop range
  3. Word Break I should be checked before II to short-circuit
     when no solution exists
  4. Substring creation is O(L): total time O(n^2 * L);
     use Trie to reduce to O(n * L) for trie traversal
  5. The dp[j] && dict.contains check is the core of many
     string segmentation DP problems
