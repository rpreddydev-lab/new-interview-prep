================================================================
  Z-ALGORITHM
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Z[i] = length of longest substring starting from s[i] that is
also a PREFIX of s.
Z[0] is undefined (or set to n by convention).

  Example: s = "aabxaa"
    Z = [_, 1, 0, 0, 2, 1]

  Time: O(n)  Space: O(n)

----------------------------------------------------------------
Z-ARRAY CONSTRUCTION
----------------------------------------------------------------
  int[] buildZ(String s) {
    int n = s.length();
    int[] Z = new int[n];
    int l = 0, r = 0;   // [l, r] = rightmost Z-box seen so far
    for (int i = 1; i < n; i++) {
      if (i < r) Z[i] = Math.min(r - i, Z[i - l]);  // use existing Z info
      while (i + Z[i] < n && s.charAt(Z[i]) == s.charAt(i + Z[i]))
        Z[i]++;   // extend
      if (i + Z[i] > r) { l = i; r = i + Z[i]; }  // update Z-box
    }
    return Z;
  }

----------------------------------------------------------------
PATTERN MATCHING WITH Z-ALGORITHM
----------------------------------------------------------------
Concatenate: P + '#' + T (# = sentinel not in alphabet).
Build Z-array on concatenated string.
For positions in T section: if Z[i] == |P|, then P matches at that position.

  List<Integer> zSearch(String text, String pattern) {
    String concat = pattern + "#" + text;
    int[] Z = buildZ(concat);
    int m = pattern.length();
    List<Integer> res = new ArrayList<>();
    for (int i = m + 1; i < concat.length(); i++)
      if (Z[i] == m) res.add(i - m - 1);
    return res;
  }

----------------------------------------------------------------
Z vs KMP
----------------------------------------------------------------
  Feature          Z-Algorithm         KMP
  -------          -----------         ---
  Array built      Z[i]                lps[i]
  Meaning          Prefix match len    Suffix-prefix match len
  Time             O(n)                O(n)
  Pattern search   Concat + search     Direct
  Code simplicity  Simpler loop        More state management

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Z[i] tells you: starting at position i, how many chars match the prefix
  2. Pattern search: P + '#' + T trick (same separator trick as KMP)
  3. Z is simpler to implement than KMP for many people
  4. Applications: period detection (period = n - Z[period] if n % period == 0),
     count prefix occurrences, string factorization
  5. '#' separator ensures Z[i] can never exceed |P| in the T section
