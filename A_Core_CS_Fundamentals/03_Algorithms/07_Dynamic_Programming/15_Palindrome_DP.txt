LONGEST PALINDROMIC SUBSTRING (LC 5)
----------------------------------------------------------------
Find the longest substring that is a palindrome.

  APPROACH 1: EXPAND AROUND CENTER -- O(n^2) time, O(1) space
  For each center (n odd centers + n-1 even centers = 2n-1 total):
  expand outward while chars match.

  String longestPalindrome(String s) {
    int start = 0, maxLen = 1;
    for (int i = 0; i < s.length(); i++) {
      int len1 = expand(s, i, i);     // odd length
      int len2 = expand(s, i, i+1);  // even length
      int len = Math.max(len1, len2);
      if (len > maxLen) {
        maxLen = len;
        start = i - (len - 1) / 2;   // calculate start
      }
    }
    return s.substring(start, start + maxLen);
  }
  int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
    return r - l - 1;
  }

  APPROACH 2: DP -- O(n^2) time, O(n^2) space
  dp[i][j] = true if s[i..j] is palindrome
  dp[i][j] = dp[i+1][j-1] && s[i] == s[j]
  Fill by increasing length.

  APPROACH 3: MANACHER'S ALGORITHM -- O(n) time, O(n) space
  Complex; rarely asked in interviews but mention it exists.

----------------------------------------------------------------
LONGEST PALINDROMIC SUBSEQUENCE (LC 516)
----------------------------------------------------------------
Not substring -- subsequence (non-contiguous).
  dp[i][j] = length of LPS in s[i..j]
  If s[i] == s[j]: dp[i][j] = dp[i+1][j-1] + 2
  Else: dp[i][j] = max(dp[i+1][j], dp[i][j-1])
  Base: dp[i][i] = 1

  int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = 0; i < n; i++) dp[i][i] = 1;
    for (int len = 2; len <= n; len++)
      for (int i = 0; i + len - 1 < n; i++) {
        int j = i + len - 1;
        if (s.charAt(i) == s.charAt(j))
          dp[i][j] = (len == 2 ? 0 : dp[i+1][j-1]) + 2;
        else
          dp[i][j] = Math.max(dp[i+1][j], dp[i][j-1]);
      }
    return dp[0][n-1];
  }
  Time: O(n^2)  Space: O(n^2)

  Note: LPS(s) = LCS(s, reverse(s)) -- elegant alternative.
  Minimum deletions to make palindrome = n - LPS(s).

----------------------------------------------------------------
PALINDROME PARTITIONING II (LC 132)
----------------------------------------------------------------
Min cuts to partition string into palindromes.
  cuts[i] = min cuts for s[0..i]
  Optimize with DP precompute of isPalin[i][j].

  int minCut(String s) {
    int n = s.length();
    boolean[][] isPalin = new boolean[n][n];
    for (int i = n-1; i >= 0; i--)
      for (int j = i; j < n; j++)
        isPalin[i][j] = s.charAt(i) == s.charAt(j)
                     && (j - i <= 2 || isPalin[i+1][j-1]);
    int[] cuts = new int[n];
    for (int i = 0; i < n; i++) {
      if (isPalin[0][i]) { cuts[i] = 0; continue; }  // whole prefix is palindrome
      cuts[i] = i;  // max cuts = i (cut every char)
      for (int j = 1; j <= i; j++)
        if (isPalin[j][i]) cuts[i] = Math.min(cuts[i], cuts[j-1] + 1);
    }
    return cuts[n-1];
  }
  Time: O(n^2)  Space: O(n^2)

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Palindrome substring: expand-around-center O(n^2) O(1) is simplest
     DP is O(n^2) O(n^2) -- more space for same time
  2. LPS (subsequence) != LCS substring -- different recurrences
  3. LPS = LCS(s, reversed(s)) -- elegant 2-line insight
  4. Palindrome Partitioning II: precompute isPalin first, then min cuts
  5. Always clarify: substring (contiguous) vs subsequence (non-contiguous)
     in palindrome problems
