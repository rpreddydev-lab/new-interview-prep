================================================================
  CYCLE DETECTION: UNDIRECTED GRAPHS
================================================================

----------------------------------------------------------------
METHOD 1: DFS WITH PARENT TRACKING
----------------------------------------------------------------
In undirected DFS, we see each edge twice (u->v and v->u).
A cycle exists if we visit an ALREADY VISITED node that is NOT our parent.

  boolean hasCycleUndirected(int n, List<List<Integer>> adj) {
    boolean[] visited = new boolean[n];
    for (int i = 0; i < n; i++)
      if (!visited[i] && dfs(adj, visited, i, -1)) return true;
    return false;
  }
  boolean dfs(List<List<Integer>> adj, boolean[] visited, int node, int parent) {
    visited[node] = true;
    for (int neighbor : adj.get(node)) {
      if (!visited[neighbor]) {
        if (dfs(adj, visited, neighbor, node)) return true;
      } else if (neighbor != parent) {  // visited and not parent = back edge = cycle
        return true;
      }
    }
    return false;
  }

  Time: O(V + E)  Space: O(V)

  Edge case: multigraph (multiple edges between same pair of nodes).
  Use parent-count instead of parent-node to handle parallel edges.

----------------------------------------------------------------
METHOD 2: UNION-FIND
----------------------------------------------------------------
For each edge (u, v): if find(u) == find(v) --> cycle.
  Otherwise: union(u, v).

  boolean hasCycleUnionFind(int n, int[][] edges) {
    int[] parent = new int[n];
    for (int i = 0; i < n; i++) parent[i] = i;
    for (int[] edge : edges) {
      int pu = find(parent, edge[0]), pv = find(parent, edge[1]);
      if (pu == pv) return true;  // same component: cycle
      parent[pu] = pv;
    }
    return false;
  }
  int find(int[] parent, int x) {
    return parent[x] == x ? x : (parent[x] = find(parent, parent[x]));
  }

  Preferred when edges are given directly (not adjacency list).

----------------------------------------------------------------
REDUNDANT CONNECTION (LC 684)
----------------------------------------------------------------
Find the edge that, when removed, results in a tree.
  Use Union-Find: return the FIRST edge (u,v) where find(u) == find(v).

  int[] findRedundantConnection(int[][] edges) {
    int n = edges.length;
    int[] parent = new int[n + 1];
    for (int i = 1; i <= n; i++) parent[i] = i;
    for (int[] edge : edges) {
      int pu = find(parent, edge[0]), pv = find(parent, edge[1]);
      if (pu == pv) return edge;
      parent[pu] = pv;
    }
    return new int[]{};
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Undirected cycle detection: DFS with parent, or Union-Find
  2. Key difference from directed: check `neighbor != parent` (not color states)
  3. Union-Find preferred when processing edge list; DFS for adjacency list
  4. Redundant Connection = Union-Find cycle detection -- first cycle edge
  5. For directed graph: use 3-color DFS (0/1/2 states)
