================================================================
  LOWEST COMMON ANCESTOR (LCA)
================================================================

----------------------------------------------------------------
CORE CONCEPT
----------------------------------------------------------------
Lowest Common Ancestor (LCA) of p and q: the deepest node that
is an ancestor of BOTH p and q (a node is its own ancestor).

----------------------------------------------------------------
LCA OF BINARY TREE (LC 236)
----------------------------------------------------------------
  TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;  // p and q in different subtrees
    return left != null ? left : right;              // both in same subtree
  }
  Time: O(n)  Space: O(h)

  Logic:
  - If we find p or q, return it (it could be the ancestor).
  - If both left and right return non-null: root is the LCA.
  - If only one side returns non-null: LCA is in that subtree.

----------------------------------------------------------------
LCA OF BST (LC 235) -- O(h) using BST property
----------------------------------------------------------------
  BST property: LCA is the node where p and q diverge.
  - If both < root: LCA in left subtree.
  - If both > root: LCA in right subtree.
  - Otherwise (or one equals root): root is LCA.

  TreeNode lowestCommonAncestorBST(TreeNode root, TreeNode p, TreeNode q) {
    if (p.val < root.val && q.val < root.val) return lowestCommonAncestorBST(root.left, p, q);
    if (p.val > root.val && q.val > root.val) return lowestCommonAncestorBST(root.right, p, q);
    return root;  // diverge here
  }

  Iterative (O(1) space):
    while (root != null) {
      if (p.val < root.val && q.val < root.val) root = root.left;
      else if (p.val > root.val && q.val > root.val) root = root.right;
      else return root;
    }

----------------------------------------------------------------
LCA WITH PARENT POINTERS
----------------------------------------------------------------
If each node has a parent pointer:
  1. Record all ancestors of p in a Set.
  2. Walk up from q until you hit a node in the set = LCA.
  Time: O(h)  Space: O(h)

  Or: find depths; advance deeper pointer; advance both until equal.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Binary Tree LCA: the "both sides non-null" logic is key
  2. BST LCA: O(h) exploiting BST property -- much faster than O(n)
  3. If parent pointers given: ancestor set approach is simplest
  4. LCA can be used to compute path between any two nodes
  5. For LCA of multiple nodes: find LCA iteratively (LCA(a,b), then LCA(result,c))
