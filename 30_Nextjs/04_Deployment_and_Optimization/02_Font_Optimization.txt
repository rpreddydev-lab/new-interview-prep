1. WHY next/font?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problems with traditional font loading (Google Fonts <link> tag):
  ✗ Network request to Google's CDN (latency, privacy concern)
  ✗ Cumulative Layout Shift (CLS) — page "jumps" when font loads
  ✗ Flash of Invisible Text (FOIT) — text invisible until font loads
  ✗ Flash of Unstyled Text (FOUT) — system font shown then swapped
  ✗ No font subsetting by default (loading all characters)

next/font solves all of these:
  ✓ Downloads fonts at BUILD TIME, self-hosts them on your server
  ✓ Zero external network requests at runtime (no Google CDN call)
  ✓ Automatic CSS size-adjust to minimize layout shift
  ✓ Automatic font subsetting (only characters you need)
  ✓ font-display: swap built in
  ✓ Zero performance impact (fonts served from same origin)

  // app/layout.tsx
  import { Inter, Roboto_Mono } from 'next/font/google';

  // Configure fonts at module level (runs at build time)
  const inter = Inter({
    subsets: ['latin'],           // only include latin characters
    weight: ['400', '500', '700'], // only include needed weights
    style: ['normal', 'italic'],
    display: 'swap',              // font-display: swap (default)
    variable: '--font-inter',     // CSS custom property (optional)
  });

  const robotoMono = Roboto_Mono({
    subsets: ['latin'],
    variable: '--font-roboto-mono',
  });

  export default function RootLayout({ children }: { children: React.ReactNode }) {
    return (
      // Apply className to <html> to scope font to entire app
      <html lang="en" className={`${inter.className} ${robotoMono.variable}`}>
        <body>{children}</body>
      </html>
    );
  }

  // inter.className — applies font-family directly
  // inter.variable  — exposes font as CSS var (--font-inter) for Tailwind

  const inter = Inter({
    subsets: ['latin'],
    variable: '--font-inter',  // exposes as CSS var
  });

  // Step 2: Apply to html element
  <html className={inter.variable}>

  // Step 3: Configure Tailwind to use the variable
  // tailwind.config.ts
  module.exports = {
    theme: {
      extend: {
        fontFamily: {
          sans: ['var(--font-inter)'],      // font-sans → Inter
          mono: ['var(--font-roboto-mono)'],
        },
      },
    },
  };

  // Step 4: Use in components
  <p className="font-sans">This uses Inter</p>
  <code className="font-mono">This uses Roboto Mono</code>

5. FONT OPTIONS REFERENCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  const font = Inter({
    subsets: ['latin'],               // Required for Google fonts
    weight: ['400', '700'],           // Weights to include ('variable' for variable fonts)
    style: ['normal', 'italic'],      // Styles to include
    display: 'swap',                  // font-display: auto|block|swap|fallback|optional
    preload: true,                    // Preload font (default: true)
    fallback: ['system-ui', 'arial'], // Fallback fonts
    adjustFontFallback: true,         // Auto-generate size-adjust to prevent CLS
    variable: '--font-inter',         // CSS custom property name
  });

  // font-display values:
  //  auto     → browser default
  //  block    → invisible until font loads (FOIT) — never use
  //  swap     → show fallback, then swap (FOUT) — most common
  //  fallback → short FOIT, then fallback forever if slow — good
  //  optional → short FOIT, uses fallback if font not already cached — best for performance

7. HOW next/font WORKS UNDER THE HOOD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

At build time:
  1. Next.js downloads the font files from Google Fonts (or uses local files)
  2. Generates a unique hash-based filename: inter-abc123.woff2
  3. Copies the font to .next/static/media/
  4. Generates CSS with @font-face declaration referencing the local file
  5. Injects CSS into the page <head> (no external request needed at runtime)
  6. Calculates size-adjust value for fallback font to minimize CLS

At runtime:
  - No Google CDN request (privacy-preserving)
  - Font served from /_next/static/media/ (same origin, fast)
  - CSS custom property (if variable used) available in all descendant elements
  - font-display: swap prevents invisible text

8. COMMON INTERVIEW QUESTIONS & ANSWERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: What problem does next/font solve?
A:  Traditional font loading with a Google Fonts <link> tag has three issues:
    (1) External network request to Google CDN on every page load (latency + privacy),
    (2) CLS — page layout shifts when the font loads and replaces the fallback,
    (3) FOIT/FOUT — text is invisible or styled with fallback font temporarily.
    next/font downloads fonts at build time, self-hosts them, generates CLS-
    preventing CSS size-adjust, and handles font-display settings.

Q2: What is the difference between font.className and font.variable?
A:  font.className is a generated class name that directly applies the font-family
    to the element. font.variable is a CSS custom property name (e.g. --font-inter)
    that can be used in CSS or Tailwind config to reference the font anywhere.
    Use className for direct application, variable for CSS/Tailwind integration.

Q3: Does next/font make any external requests at runtime?
A:  No. For Google Fonts, Next.js downloads the font files at BUILD time and
    self-hosts them in .next/static/media/. The browser requests the font from
    your own origin, not Google's CDN. This improves performance and privacy
    (no Google tracking via font requests).

Q4: What is font-display: swap and when would you use optional instead?
A:  swap: show fallback font immediately, swap to web font when it loads.
    This prevents FOIT (invisible text) but can cause FOUT (text jumps).
    optional: very short block period, then if font isn't cached, use fallback
    forever for that page load. Best for performance-critical apps where
    layout stability is more important than brand font consistency.

Q5: How do you use next/font with Tailwind CSS?
A:  (1) Configure font with variable option: variable: '--font-inter'
    (2) Apply font.variable className to <html> or parent element
    (3) In tailwind.config.ts, extend fontFamily with var(--font-inter)
    (4) Use Tailwind class like font-sans to apply the font

Q6: Can you use multiple Google fonts in one Next.js project?
A:  Yes. Import multiple fonts from 'next/font/google', each configured
    independently. Apply font.className or font.variable to different elements.
    Best practice: define all font configurations in a separate fonts.ts file and
    import them where needed to avoid duplication.
