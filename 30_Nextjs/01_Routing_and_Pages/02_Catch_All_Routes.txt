1. WHAT ARE CATCH-ALL ROUTES?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Catch-all routes match any number of URL path segments beyond a point.
They use the spread syntax inside brackets: [...slug] or [[...slug]]

  [...slug]    → Required catch-all (must have at least one segment)
  [[...slug]]  → Optional catch-all (matches the base path too)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. REQUIRED CATCH-ALL: [...slug]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pages Router: pages/docs/[...slug].tsx
App Router:   app/docs/[...slug]/page.tsx

  URL                  → slug value
  /docs/intro          → ['intro']
  /docs/api/reference  → ['api', 'reference']
  /docs/a/b/c/d        → ['a', 'b', 'c', 'd']
  /docs                → 404 (base path NOT matched by required catch-all)

Pages Router access:
  import { useRouter } from 'next/router';
  const router = useRouter();
  const { slug } = router.query;
  // slug is string[] when multiple segments, string when one
  // IMPORTANT: could be undefined on first render (before hydration)

App Router access:
  // Server Component
  export default async function DocsPage({ params }) {
    const { slug } = params;  // string[]
    const path = slug.join('/');  // 'api/reference'
    return <div>Reading: {path}</div>;
  }

3. OPTIONAL CATCH-ALL: [[...slug]]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pages Router: pages/docs/[[...slug]].tsx
App Router:   app/docs/[[...slug]]/page.tsx

  URL                  → slug value
  /docs                → undefined (base path IS matched)
  /docs/intro          → ['intro']
  /docs/api/reference  → ['api', 'reference']

  // Handle optional slug
  export default function DocsPage({ params }) {
    const slug = params.slug ?? [];       // default to empty array
    const path = slug.length ? slug.join('/') : 'home';
    return <div>Reading: {path}</div>;
  }

A) DOCUMENTATION SITES
   Structure: /docs/[...slug]
   - /docs/getting-started
   - /docs/api/components/button
   - /docs/guides/authentication/oauth
   Slug maps directly to file path in content/ directory.

   // app/docs/[...slug]/page.tsx
   export default async function DocPage({ params }) {
     const filePath = path.join(process.cwd(), 'content', ...params.slug) + '.mdx';
     const content = await readFile(filePath, 'utf-8');
     return <MDXRenderer content={content} />;
   }

B) CMS / HEADLESS CMS PAGE BUILDER
   Structure: /[[...slug]]
   - / → homepage
   - /about
   - /blog/2024/my-post
   All pages driven by CMS; catch-all handles any depth.

C) FILE EXPLORER / DIRECTORY BROWSER
   Structure: /files/[...path]
   - /files/photos/vacation/2024
   Each segment = subdirectory

D) WILDCARD REDIRECTS / PROXIES
   Use in middleware.ts to rewrite arbitrary paths to an external service.

5. FULL EXAMPLE — DOCS SITE WITH CATCH-ALL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  // app/docs/[...slug]/page.tsx
  import { notFound } from 'next/navigation';
  import { getDoc } from '@/lib/docs';

  interface Props {
    params: { slug: string[] };
  }

  export async function generateStaticParams() {
    const allDocs = await getAllDocSlugs();
    return allDocs.map(slug => ({ slug }));
    // e.g. [{ slug: ['intro'] }, { slug: ['api', 'reference'] }]
  }

  export async function generateMetadata({ params }: Props) {
    const doc = await getDoc(params.slug);
    if (!doc) return { title: 'Not Found' };
    return { title: doc.title };
  }

  export default async function DocPage({ params }: Props) {
    const doc = await getDoc(params.slug);
    if (!doc) notFound();
    return (
      <article>
        <h1>{doc.title}</h1>
        <div dangerouslySetInnerHTML={{ __html: doc.content }} />
      </article>
    );
  }

  // lib/docs.ts
  export async function getDoc(slug: string[]) {
    const filePath = path.join('content/docs', ...slug, 'index.md');
    try {
      const raw = await fs.readFile(filePath, 'utf-8');
      return parseMDX(raw);
    } catch {
      return null;
    }
  }

6. CATCH-ALL vs DYNAMIC SEGMENT vs NESTED ROUTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌────────────────────────────────┬──────────────────────────────────────────┐
│ Pattern                        │ Matches                                  │
├────────────────────────────────┼──────────────────────────────────────────┤
│ /blog/[id]                     │ /blog/123 (single segment only)          │
│ /blog/[id]/[comment]           │ /blog/123/comments (exactly 2 segments)  │
│ /blog/[...slug]                │ /blog/a, /blog/a/b, /blog/a/b/c          │
│ /blog/[[...slug]]              │ /blog, /blog/a, /blog/a/b/c              │
└────────────────────────────────┴──────────────────────────────────────────┘

Priority order (when multiple could match):
  1. Static routes          → /blog/featured
  2. Dynamic routes         → /blog/[id]
  3. Catch-all routes       → /blog/[...slug]

7. GOTCHAS & EDGE CASES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. slug is ALWAYS an array (even with one segment):
   /docs/intro → slug = ['intro'], NOT 'intro'
   Always use slug.join('/') or slug[0]

2. Pages Router: router.query.slug might be undefined on first render
   because of hydration. Always check: if (!router.isReady) return null;

3. Optional catch-all and required catch-all CANNOT coexist in same directory.

4. Catch-all does not match the base path by itself in required form:
   pages/docs/[...slug].tsx does NOT match /docs → use [[...slug]] instead.

5. Query strings are separate:
   /docs/api?version=2 → slug = ['api'], query = { version: '2' }
   Query string is NOT included in the catch-all segment.

8. COMMON INTERVIEW QUESTIONS & ANSWERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: What is the difference between [id], [...slug], and [[...slug]]?
A:  [id] — matches exactly one URL segment
    [...slug] — matches one or more segments (required)
    [[...slug]] — matches zero or more segments (optional, also matches base)

Q2: How do you access the catch-all params value?
A:  It's always an array. In Pages Router: router.query.slug (string[]).
    In App Router Server Component: params.slug (string[]).
    For /docs/api/reference, slug = ['api', 'reference'].

Q3: Why would you use a catch-all route for a documentation site?
A:  Documentation can have arbitrary nesting depth (/docs/a/b/c/d/...).
    Using a catch-all, you map the entire slug array to a file path in your
    content directory. One component handles all doc pages; the slug tells it
    which file to load.

Q4: What happens if you have both /docs/intro (static) and /docs/[...slug]?
A:  Static routes take priority. /docs/intro always matches the static page.
    /docs/advanced/feature matches the catch-all.

Q5: How do you generate static pages for catch-all routes?
A:  In App Router: export async function generateStaticParams() returning
    arrays of slug arrays, e.g., { slug: ['api', 'reference'] }.
    In Pages Router: getStaticPaths with paths like
    [{ params: { slug: ['api', 'reference'] } }].

================================================================================
  KEY INSIGHT: Catch-all routes are the backbone of CMS-driven sites and
  documentation platforms where the URL depth is variable and content is
  file-system or database-driven.
