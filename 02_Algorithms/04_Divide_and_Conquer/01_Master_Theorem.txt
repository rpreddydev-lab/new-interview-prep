================================================================
  MASTER THEOREM
================================================================

----------------------------------------------------------------
THEOREM STATEMENT
----------------------------------------------------------------
For recurrences of the form:
  T(n) = a * T(n/b) + f(n),  a >= 1, b > 1, f(n) asymptotically positive

  Let c_crit = log_b(a)  (critical exponent)

  CASE 1: f(n) = O(n^(c_crit - epsilon)) for some epsilon > 0
          --> T(n) = Theta(n^c_crit)
          Work dominated by subproblems (leaves of recursion tree)

  CASE 2: f(n) = Theta(n^c_crit * log^k(n)) for k >= 0
          --> T(n) = Theta(n^c_crit * log^(k+1)(n))
          Most common: k=0 -> T(n) = Theta(n^c_crit * log n)
          Work evenly distributed across all levels

  CASE 3: f(n) = Omega(n^(c_crit + epsilon)) AND
          a*f(n/b) <= c*f(n) for some c < 1 and large n
          --> T(n) = Theta(f(n))
          Work dominated by top level (root)

----------------------------------------------------------------
QUICK REFERENCE -- COMMON RECURRENCES
----------------------------------------------------------------
  Recurrence          a   b   f(n)      c_crit    Case   T(n)
  -------------------------------------------------------------------
  T=2T(n/2)+O(n)      2   2   n         1         2      O(n log n)  [Merge Sort]
  T=T(n/2)+O(1)       1   2   1         0         2      O(log n)    [Binary Search]
  T=T(n/2)+O(n)       1   2   n         0         3      O(n)        [Partition step]
  T=2T(n/2)+O(1)      2   2   1         1         1      O(n)        [Tree traversal]
  T=4T(n/2)+O(n)      4   2   n         2         1      O(n^2)
  T=4T(n/2)+O(n^2)    4   2   n^2       2         2      O(n^2 log n)
  T=4T(n/2)+O(n^3)    4   2   n^3       2         3      O(n^3)
  T=7T(n/2)+O(n^2)    7   2   n^2       2.807     1      O(n^2.807)  [Strassen]
  T=3T(n/2)+O(n)      3   2   n         1.585     1      O(n^1.585)  [Karatsuba]
  T=2T(n/2)+O(n log n) 2  2  n log n    1         2      O(n log^2 n)

----------------------------------------------------------------
APPLYING THE THEOREM (STEP BY STEP)
----------------------------------------------------------------
Example: T(n) = 3T(n/4) + O(n^2)

  Step 1: Identify a=3, b=4, f(n)=n^2
  Step 2: c_crit = log_4(3) = log(3)/log(4) ≈ 0.79
  Step 3: Compare f(n)=n^2 with n^(c_crit)=n^0.79
          n^2 grows faster than n^0.79 -> epsilon = 2 - 0.79 = 1.21
  Step 4: Case 3 check: a*f(n/b) = 3*(n/4)^2 = 3n^2/16 <= (3/4)*n^2 = c*f(n) with c=3/4 < 1
          Regularity condition satisfied
  Result: T(n) = Theta(n^2)

----------------------------------------------------------------
WHEN MASTER THEOREM DOESN'T APPLY
----------------------------------------------------------------
  - f(n) is not polynomial (e.g., f(n) = log n): use substitution
  - Subproblems of DIFFERENT sizes: T(n) = T(n/3) + T(2n/3) + O(n)
    --> Use recursion tree method
  - Non-recursive additions: T(n) = 2T(n-1) + O(1)
    --> Not divide and conquer form (b=1 not valid)
    --> Use unrolling: T(n) = O(2^n)

  Special recurrences:
    T(n) = T(n-1) + O(1)    -> O(n)     [linear recursion]
    T(n) = T(n-1) + O(n)    -> O(n^2)   [bubble sort]
    T(n) = 2T(n-1) + O(1)   -> O(2^n)   [Hanoi]
    T(n) = T(sqrt(n)) + O(1) -> O(log log n) [special]

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Master Theorem applies only when subproblems have EQUAL size (n/b)
  2. Most common: Case 2 with k=0 -> Theta(n^c_crit * log n)
  3. Memorize: Merge Sort T(n)=2T(n/2)+n -> O(n log n)
  4. For non-standard recurrences: recursion tree or substitution method
  5. c_crit = log_b(a): this tells you whether leaves, root, or
     intermediate levels dominate the total work
