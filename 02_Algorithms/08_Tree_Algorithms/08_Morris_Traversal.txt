================================================================
  MORRIS TRAVERSAL (O(1) SPACE TREE TRAVERSAL)
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Traverse binary tree WITHOUT recursion or stack: O(1) extra space.
Temporarily modifies tree structure (restores before finishing).

Key: use the right pointer of inorder PREDECESSOR to create
temporary "thread" back to current node.

  Inorder predecessor of current node = rightmost node in left subtree.

----------------------------------------------------------------
MORRIS INORDER TRAVERSAL
----------------------------------------------------------------
  void morrisInorder(TreeNode root) {
    TreeNode curr = root;
    while (curr != null) {
      if (curr.left == null) {
        System.out.print(curr.val + " ");  // visit
        curr = curr.right;   // move right
      } else {
        // Find inorder predecessor
        TreeNode pred = curr.left;
        while (pred.right != null && pred.right != curr) pred = pred.right;

        if (pred.right == null) {
          pred.right = curr;  // create thread
          curr = curr.left;
        } else {
          pred.right = null;  // remove thread (restore)
          System.out.print(curr.val + " ");  // visit
          curr = curr.right;
        }
      }
    }
  }

  Time: O(n) -- each node visited at most 3 times
  Space: O(1) -- no stack or recursion

----------------------------------------------------------------
MORRIS PREORDER TRAVERSAL
----------------------------------------------------------------
Same as inorder but print BEFORE going left (when creating thread):
  if (pred.right == null) {
    System.out.print(curr.val + " ");  // visit BEFORE going left
    pred.right = curr;
    curr = curr.left;
  } else {
    pred.right = null;
    curr = curr.right;  // DON'T print again
  }
  // Also print when no left child:
  System.out.print(curr.val + " ");
  curr = curr.right;

----------------------------------------------------------------
APPLICATIONS
----------------------------------------------------------------
  - Recover BST (LC 99): two swapped nodes -- Morris inorder,
    find inversions (where smaller node comes after larger).
  - Kth Smallest in BST (LC 230): Morris inorder, count k steps.
  - Flatten Binary Tree to Linked List (LC 114):
    Use Morris-like approach with preorder threading.

  RECOVER BST (LC 99):
    During Morris inorder, track prev node.
    Find two places where prev.val > curr.val (the swapped pair).
    Swap their values back.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Morris traversal = O(1) space inorder without modifying input
     (threads are temporary and fully restored)
  2. Two-step logic: first visit = create thread; second visit = remove thread + process
  3. Ask before using: "may I modify the tree temporarily?" (threads modify right pointers)
  4. Recover BST: first inversion = first swapped node; last inversion = second
  5. Rarely asked in interviews but impresses when mentioned for O(1) space requirement
