================================================================
  MODULAR ARITHMETIC
================================================================

----------------------------------------------------------------
FUNDAMENTAL RULES
----------------------------------------------------------------
  (a + b) % m = ((a % m) + (b % m)) % m
  (a - b) % m = ((a % m) - (b % m) + m) % m  // +m prevents negative
  (a * b) % m = ((a % m) * (b % m)) % m
  (a / b) % m = (a * modInverse(b, m)) % m    // NOT (a%m)/(b%m)

  COMMON MISTAKE: (a - b) % m can be negative in Java.
  Always add m: ((a - b) % m + m) % m

  MOD = 10^9 + 7 (= 1_000_000_007) is a common prime modulus in problems.

----------------------------------------------------------------
MODULAR INVERSE
----------------------------------------------------------------
Inverse of a mod m = a^(-1) mod m = a^(m-2) mod m (Fermat's little theorem).
  Requires m is prime AND gcd(a, m) = 1.

  long modInverse(long a, long mod) {
    return modPow(a, mod - 2, mod);  // Fermat's: a^(mod-1) = 1 mod prime
  }

  Alternative: Extended Euclidean (works for non-prime mod too)
    int[] res = extGcd((int)a, (int)mod);
    return ((long)res[1] % mod + mod) % mod;

----------------------------------------------------------------
MODULAR EXPONENTIATION (REMINDER)
----------------------------------------------------------------
  long modPow(long base, long exp, long mod) {
    long result = 1; base %= mod;
    while (exp > 0) {
      if ((exp & 1) == 1) result = result * base % mod;
      base = base * base % mod; exp >>= 1;
    }
    return result;
  }

----------------------------------------------------------------
OVERFLOW PREVENTION
----------------------------------------------------------------
  In Java: int max = 2^31 - 1 ≈ 2.1 * 10^9
           long max = 2^63 - 1 ≈ 9.2 * 10^18

  When multiplying two numbers < 10^9+7: product can be up to ~10^18.
  Always use LONG for intermediate products before taking mod.

  Danger: a * b % mod where a, b are long up to 10^9+7
    --> a * b can be ~10^18, close to long overflow!
  Safe range: values up to ~3*10^9 for multiplication (product < Long.MAX)

----------------------------------------------------------------
CHINESE REMAINDER THEOREM (CRT)
----------------------------------------------------------------
Solve system of congruences:
  x ≡ r1 (mod m1)
  x ≡ r2 (mod m2)
  If m1 and m2 are coprime: unique solution mod (m1 * m2).

  Used in: contest problems, competitive programming.
  Rarely needed in standard interviews.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Subtraction: add mod to prevent negative result
  2. Division mod prime: use modular inverse (Fermat's: a^(p-2) mod p)
  3. MOD = 10^9+7: standard prime; use it in any "return answer mod 10^9+7" problem
  4. Multiply using long: even if values fit in int, cast to long before multiply
  5. Precompute factorials and inverse factorials for repeated C(n,k) queries
     fact[i] = (fact[i-1] * i) % MOD
     inv_fact[n] = modPow(fact[n], MOD-2, MOD)
     Then C(n,k) = fact[n] * inv_fact[k] % MOD * inv_fact[n-k] % MOD
