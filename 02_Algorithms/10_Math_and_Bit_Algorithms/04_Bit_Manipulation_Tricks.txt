================================================================
  BIT MANIPULATION TRICKS
================================================================

----------------------------------------------------------------
FUNDAMENTAL OPERATIONS
----------------------------------------------------------------
  x & (x-1)         remove lowest set bit  (check if power of 2: x & (x-1) == 0)
  x & (-x)          isolate lowest set bit  (also: x & ~(x-1))
  x | (x-1)         set all bits below lowest set bit
  x ^ x             = 0  (XOR with itself cancels)
  x ^ 0             = x
  x >> k            arithmetic right shift (preserves sign)
  x >>> k           logical right shift (fills with 0)
  x << k            left shift (multiply by 2^k)
  ~x                bitwise NOT
  Integer.bitCount(x)    count set bits (popcount)
  Integer.highestOneBit  highest bit
  Integer.numberOfTrailingZeros  trailing zeros

----------------------------------------------------------------
COMMON TRICKS
----------------------------------------------------------------
  Check bit k:       (x >> k) & 1
  Set bit k:         x | (1 << k)
  Clear bit k:       x & ~(1 << k)
  Toggle bit k:      x ^ (1 << k)

  Multiply/divide by 2: x << 1, x >> 1
  Check even/odd:    (x & 1) == 0  (even)
  Absolute value:    int mask = x >> 31; (x + mask) ^ mask
  Swap two vars:     a ^= b; b ^= a; a ^= b; (XOR swap)

  Count set bits (Brian Kernighan):
    int count = 0;
    while (x != 0) { x &= (x-1); count++; }

  Round up to power of 2:
    n--; n|=n>>1; n|=n>>2; n|=n>>4; n|=n>>8; n|=n>>16; n++;

----------------------------------------------------------------
NUMBER OF 1 BITS (LC 191)
----------------------------------------------------------------
  int hammingWeight(int n) {
    int count = 0;
    while (n != 0) { n &= (n-1); count++; }
    return count;
  }
  // or: Integer.bitCount(n)

----------------------------------------------------------------
COUNTING BITS (LC 338) -- dp approach
----------------------------------------------------------------
  int[] countBits(int n) {
    int[] dp = new int[n + 1];
    for (int i = 1; i <= n; i++)
      dp[i] = dp[i >> 1] + (i & 1);  // bits(i) = bits(i/2) + last bit
    return dp;
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. x & (x-1) removes lowest set bit -- classic for power of 2 check
  2. x & (-x) isolates lowest set bit -- used in Fenwick Tree, subset enum
  3. Brian Kernighan: count bits by repeatedly removing lowest set bit
  4. Counting Bits DP: dp[i] = dp[i>>1] + (i&1) -- elegant O(n)
  5. XOR swap: works but obscure -- prefer temp variable in production code
