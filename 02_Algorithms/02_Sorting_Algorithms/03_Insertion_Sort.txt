================================================================
  INSERTION SORT
================================================================

----------------------------------------------------------------
HOW IT WORKS
----------------------------------------------------------------
Build the sorted portion one element at a time. For each new
element, shift larger sorted elements right to insert it correctly.

  void insertionSort(int[] arr) {
    int n = arr.length;
    for (int i = 1; i < n; i++) {
      int key = arr[i];
      int j = i - 1;
      while (j >= 0 && arr[j] > key) {
        arr[j + 1] = arr[j];  // shift right (no swap needed)
        j--;
      }
      arr[j + 1] = key;       // insert at correct position
    }
  }

  Time:  O(n^2) worst/average,  O(n) best (already sorted)
  Space: O(1)   In-place: Yes   Stable: Yes   Adaptive: Yes

  Shifting vs swapping: Insertion sort does SHIFTS (1 write per step)
  rather than swaps (2 writes per step), making it faster in practice
  for small arrays.

----------------------------------------------------------------
WHY INSERTION SORT IS IMPORTANT
----------------------------------------------------------------
  1. Fastest simple sort for small n (n < 10-20)
     TimSort uses Insertion Sort for runs of length < 64
     Java's Arrays.sort for small arrays uses Insertion Sort

  2. Adaptive: O(n) for nearly-sorted arrays
     Number of operations proportional to inversions (out-of-order pairs)

  3. Online: can sort as data arrives (one element at a time)

  4. In-place and stable

----------------------------------------------------------------
BINARY INSERTION SORT
----------------------------------------------------------------
Use binary search to find the insertion position: O(log n) comparisons.
But shifting still takes O(n) time -> O(n^2) total.
Useful when comparisons are expensive but shifts are cheap.

  for (int i = 1; i < n; i++) {
    int key = arr[i];
    int pos = upperBound(arr, 0, i, key);  // binary search in sorted prefix
    System.arraycopy(arr, pos, arr, pos+1, i - pos);  // shift right
    arr[pos] = key;
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. "TimSort uses Insertion Sort" -- important Java fact
  2. Insertion Sort is optimal for nearly-sorted or small arrays
  3. Online sorting: can handle streaming input
  4. Fewer comparisons than Bubble Sort on average;
     fewer writes than Bubble Sort by factor ~2
  5. The inner loop counts inversions: each element passes through
     all larger elements to its left -> O(inversions) total ops
