================================================================
  BUBBLE SORT
================================================================

----------------------------------------------------------------
HOW IT WORKS
----------------------------------------------------------------
Repeatedly swap adjacent elements that are in the wrong order.
After each pass, the largest unsorted element "bubbles up" to
its correct position at the end.

  void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
      boolean swapped = false;
      for (int j = 0; j < n - i - 1; j++) {
        if (arr[j] > arr[j + 1]) {
          int tmp = arr[j]; arr[j] = arr[j+1]; arr[j+1] = tmp;
          swapped = true;
        }
      }
      if (!swapped) break;  // already sorted -- O(n) best case
    }
  }

  Time:  O(n^2) avg/worst,  O(n) best (already sorted)
  Space: O(1)   In-place: Yes   Stable: Yes

  Optimization: track last swap position to reduce inner loop range.
  Adaptive: flag early exit when no swaps occur in a pass.

----------------------------------------------------------------
WHY IT MATTERS (Interview Angle)
----------------------------------------------------------------
  - Demonstrates stable in-place sort with early exit
  - The "swapped" flag optimization makes it adaptive (O(n) for sorted)
  - Rarely used in production but teaches the concept of passes
  - Multiple passes guarantees: after k passes, last k elements are sorted

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Always mention the early-exit optimization with `swapped` flag
  2. Bubble sort is O(n^2) -- never recommend for production use
  3. Stable: equal elements never swap, so relative order preserved
  4. Most swaps of any O(n^2) sort: O(n^2) swaps worst case
     vs Insertion Sort which has O(n^2) comparisons but fewer swaps
