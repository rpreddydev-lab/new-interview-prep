================================================================
  RABIN-KARP AND ROLLING HASH
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Hash each window of length m. Compare hash first; if match, verify char by char.
ROLLING HASH: slide window in O(1) per step instead of O(m).

  hash(s[i..i+m-1]) = hash(s[i-1..i+m-2]) - s[i-1]*base^(m-1)
                                            + s[i+m-1]

  Choose large prime MOD to reduce collisions.
  BASE = 31 (for lowercase letters) or 131 (for ASCII).

  Time: O(n + m) average, O(nm) worst (all hash collisions)
  Space: O(1)

----------------------------------------------------------------
ROLLING HASH IMPLEMENTATION
----------------------------------------------------------------
  List<Integer> rabinKarp(String text, String pattern) {
    int n = text.length(), m = pattern.length();
    long MOD = 1_000_000_007L, BASE = 31L;
    long h = 1;  // BASE^(m-1) mod MOD
    for (int i = 0; i < m - 1; i++) h = h * BASE % MOD;

    long patHash = 0, winHash = 0;
    for (int i = 0; i < m; i++) {
      patHash = (patHash * BASE + (pattern.charAt(i) - 'a' + 1)) % MOD;
      winHash = (winHash * BASE + (text.charAt(i) - 'a' + 1)) % MOD;
    }
    List<Integer> res = new ArrayList<>();
    for (int i = 0; i <= n - m; i++) {
      if (winHash == patHash && text.substring(i, i+m).equals(pattern))
        res.add(i);
      if (i < n - m) {
        winHash = (winHash - (text.charAt(i) - 'a' + 1) * h % MOD + MOD) % MOD;
        winHash = (winHash * BASE + (text.charAt(i + m) - 'a' + 1)) % MOD;
      }
    }
    return res;
  }

----------------------------------------------------------------
DOUBLE HASHING (reduce false positives)
----------------------------------------------------------------
Use two different (BASE, MOD) pairs.
Probability of false positive drops from ~1/MOD to ~1/MOD^2.

  Useful for: Longest Duplicate Substring (LC 1044),
              Longest Common Substring.

----------------------------------------------------------------
ROLLING HASH APPLICATIONS
----------------------------------------------------------------
  1. Longest Duplicate Substring (LC 1044): binary search on length
     + rolling hash to check if any substring of that length repeats.
  2. Rabin-Fingerprint for plagiarism detection.
  3. Multiple pattern matching: store all pattern hashes in HashSet.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Rolling hash = add new char, remove old char in O(1)
  2. Always verify on hash match (avoid false positives)
  3. Use MOD = 10^9+7 (prime); BASE = 31 or 31^1 for lowercase alpha
  4. Double hashing for competitive programming; single usually ok in interviews
  5. Rabin-Karp shines in multiple-pattern search (all patterns hashed at once)
