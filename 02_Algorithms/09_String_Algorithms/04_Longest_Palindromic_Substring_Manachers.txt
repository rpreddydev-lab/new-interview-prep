================================================================
  MANACHER'S ALGORITHM -- O(n) LONGEST PALINDROMIC SUBSTRING
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Find longest palindromic substring in O(n) time and space.
Transform string: "abc" --> "#a#b#c#" (handle even/odd uniformly).
For each center, track P[i] = radius of palindrome centered at i.

  Using a "current rightmost palindrome" trick:
  If center c has rightmost extent r, and i is within [c-r, r]:
    P[i] = min(P[mirror of i], r - i)  // use mirror info
  Then expand from there.

----------------------------------------------------------------
IMPLEMENTATION
----------------------------------------------------------------
  String longestPalindromeManacher(String s) {
    // Transform: insert # between and around chars
    StringBuilder t = new StringBuilder("#");
    for (char c : s.toCharArray()) { t.append(c); t.append('#'); }
    String T = t.toString();
    int n = T.length();
    int[] P = new int[n];   // P[i] = radius of palindrome centered at i
    int c = 0, r = 0;      // center and right boundary of rightmost palindrome

    for (int i = 0; i < n; i++) {
      int mirror = 2 * c - i;
      if (i < r) P[i] = Math.min(r - i, P[mirror]);
      // Try expanding
      while (i + P[i] + 1 < n && i - P[i] - 1 >= 0
             && T.charAt(i + P[i] + 1) == T.charAt(i - P[i] - 1))
        P[i]++;
      // Update rightmost palindrome
      if (i + P[i] > r) { c = i; r = i + P[i]; }
    }
    // Find max P[i]
    int maxLen = 0, centerIdx = 0;
    for (int i = 0; i < n; i++) if (P[i] > maxLen) { maxLen = P[i]; centerIdx = i; }
    int start = (centerIdx - maxLen) / 2;  // map back to original string
    return s.substring(start, start + maxLen);
  }

  Time: O(n)  Space: O(n)

----------------------------------------------------------------
WHEN TO USE MANACHER'S vs EXPAND-AROUND-CENTER
----------------------------------------------------------------
  Expand-around-center: O(n^2), O(1) space, simple to implement.
  Manacher's:           O(n), O(n) space, complex to implement.

  For interviews: implement expand-around-center first;
  mention Manacher's as O(n) improvement.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Manacher's is O(n) but complex -- mention it, implement expand-around-center
  2. Transformation '#a#b#c#' handles odd/even palindromes uniformly
  3. P[i] in transformed string = actual palindrome radius (length = P[i])
  4. Mirror trick: if i < r, use mirror = 2*c-i to initialize P[i]
  5. Map back: start = (centerIdx - maxLen) / 2 in original string
