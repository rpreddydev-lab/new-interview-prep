FIND PEAK ELEMENT (LC 162)
----------------------------------------------------------------
A peak element is greater than its neighbors. Array may have
multiple peaks; return any.

  Key insight: if nums[mid] < nums[mid+1], then there's a peak
  to the RIGHT (either mid+1 or something further right).
  Otherwise, there's a peak to the LEFT.

  int findPeakElement(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
      int mid = left + (right - left) / 2;
      if (nums[mid] < nums[mid + 1]) left = mid + 1;
      else right = mid;
    }
    return left;
  }
  Time: O(log n)

FIND MINIMUM IN ROTATED SORTED ARRAY (LC 153)
----------------------------------------------------------------
  int findMin(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
      int mid = left + (right - left) / 2;
      if (nums[mid] > nums[right]) left = mid + 1;  // min is in right half
      else right = mid;                              // min is mid or left half
    }
    return nums[left];
  }
  Time: O(log n)

  Key: compare mid with RIGHT (not left) to determine rotation.
  If nums[mid] > nums[right]: pivot (minimum) is in right half.

SEARCH IN ROTATED SORTED ARRAY WITH DUPLICATES (LC 81)
----------------------------------------------------------------
  When duplicates are present (nums[left] == nums[mid] == nums[right]),
  we cannot determine which half is sorted.
  Solution: shrink both sides by 1 (left++, right--).
  Worst case: O(n) when all elements are duplicates.

  boolean search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
      int mid = left + (right - left) / 2;
      if (nums[mid] == target) return true;
      if (nums[left] == nums[mid] && nums[mid] == nums[right]) {
        left++; right--;  // can't determine which half
      } else if (nums[left] <= nums[mid]) {  // left sorted
        if (nums[left] <= target && target < nums[mid]) right = mid - 1;
        else left = mid + 1;
      } else {  // right sorted
        if (nums[mid] < target && target <= nums[right]) left = mid + 1;
        else right = mid - 1;
      }
    }
    return false;
  }

SQRT(x) WITHOUT DIVISION (LC 69)
----------------------------------------------------------------
  int mySqrt(int x) {
    if (x < 2) return x;
    int left = 1, right = x / 2;  // sqrt(x) <= x/2 for x >= 4
    while (left < right) {
      long mid = left + (right - left + 1) / 2;  // upper mid to avoid infinite loop
      if (mid * mid <= x) left = (int) mid;
      else right = (int) mid - 1;
    }
    return left;
  }
  Note: use long to avoid overflow in mid*mid.
  Note: biasing mid UP (+1) in the "find maximum" template.

FIND K CLOSEST ELEMENTS (LC 658)
----------------------------------------------------------------
  Find k closest elements to x in sorted array.
  Binary search for the left boundary of the window.

  List<Integer> findClosestElements(int[] arr, int k, int x) {
    int left = 0, right = arr.length - k;
    while (left < right) {
      int mid = left + (right - left) / 2;
      // Compare distances from both ends of the window
      if (x - arr[mid] > arr[mid + k] - x) left = mid + 1;
      else right = mid;
    }
    List<Integer> result = new ArrayList<>();
    for (int i = left; i < left + k; i++) result.add(arr[i]);
    return result;
  }

MEDIAN OF TWO SORTED ARRAYS (LC 4) -- Hard
----------------------------------------------------------------
  Binary search on partition of smaller array.
  T: O(log(min(m,n)))  S: O(1)

  double findMedianSortedArrays(int[] nums1, int[] nums2) {
    if (nums1.length > nums2.length) return findMedianSortedArrays(nums2, nums1);
    int m = nums1.length, n = nums2.length;
    int lo = 0, hi = m;
    while (lo <= hi) {
      int i = lo + (hi - lo) / 2;  // partition of nums1
      int j = (m + n + 1) / 2 - i; // partition of nums2
      int maxLeft1 = (i == 0) ? Integer.MIN_VALUE : nums1[i-1];
      int minRight1 = (i == m) ? Integer.MAX_VALUE : nums1[i];
      int maxLeft2 = (j == 0) ? Integer.MIN_VALUE : nums2[j-1];
      int minRight2 = (j == n) ? Integer.MAX_VALUE : nums2[j];
      if (maxLeft1 <= minRight2 && maxLeft2 <= minRight1) {
        if ((m + n) % 2 == 1) return Math.max(maxLeft1, maxLeft2);
        return (Math.max(maxLeft1, maxLeft2) + Math.min(minRight1, minRight2)) / 2.0;
      } else if (maxLeft1 > minRight2) hi = i - 1;
      else lo = i + 1;
    }
    return 0;
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Finding peak/minimum in rotated: key is comparing mid with RIGHT
  2. Duplicates in rotated array: degrade to O(n) worst case --
     must mention this when discussing complexity
  3. Sqrt: use long for mid*mid to prevent int overflow
  4. Upper-mid bias (right - left + 1): needed for "find maximum"
     templates to avoid infinite loop when left = right - 1
  5. Median of two sorted arrays is O(log n) -- one of the
     hardest binary search problems; practice it separately
