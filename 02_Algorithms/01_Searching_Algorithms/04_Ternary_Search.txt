----------------------------------------------------------------
WHAT IS TERNARY SEARCH?
----------------------------------------------------------------
Ternary Search divides the search space into THREE parts each
iteration. Used to find the minimum or maximum of a UNIMODAL
function (one that first increases then decreases, or vice versa).

  Unimodal function:
    Strictly increases then strictly decreases (inverted V shape)
    OR strictly decreases then strictly increases (V shape)

  Binary search: works on sorted (monotonic) arrays -> find exact value
  Ternary search: works on unimodal functions -> find min/max

  At each step:
    m1 = left + (right - left) / 3
    m2 = right - (right - left) / 3
    Compare f(m1) and f(m2) to eliminate one third.

----------------------------------------------------------------
ALGORITHM (find minimum of unimodal function)
----------------------------------------------------------------
  double ternarySearch(double left, double right) {
    while (right - left > 1e-9) {  // precision threshold
      double m1 = left + (right - left) / 3.0;
      double m2 = right - (right - left) / 3.0;
      if (f(m1) < f(m2)) right = m2;  // min is not in [m2, right]
      else left = m1;                 // min is not in [left, m1]
    }
    return (left + right) / 2.0;
  }

  Convergence: each iteration reduces range by factor of 2/3.
  Iterations needed: log_{3/2}(initial_range / precision)
  Time: O(log n) -- similar to binary search

  Note: Binary Search is more efficient per comparison (halves vs
  reduces by 1/3) and is preferred when applicable. Ternary search
  makes 2 comparisons per step vs 1 for binary search.

----------------------------------------------------------------
TERNARY SEARCH ON INTEGERS (discrete)
----------------------------------------------------------------
  For finding peak in unimodal integer sequence:

  int ternarySearchInt(int[] arr) {
    int left = 0, right = arr.length - 1;
    while (right - left > 2) {
      int m1 = left + (right - left) / 3;
      int m2 = right - (right - left) / 3;
      if (arr[m1] < arr[m2]) left = m1 + 1;
      else right = m2 - 1;
    }
    // Check remaining elements
    int maxIdx = left;
    for (int i = left + 1; i <= right; i++)
      if (arr[i] > arr[maxIdx]) maxIdx = i;
    return maxIdx;
  }

  Note: For "Find Peak Element" (LC 162), binary search is better.
  Ternary search shines for continuous functions.

----------------------------------------------------------------
WHEN TO USE TERNARY SEARCH
----------------------------------------------------------------
  - Competitive programming: optimize a continuous unimodal function
  - Finding peak/valley when the function is smooth
  - Geometric problems: minimize distance from a point to a parabola

  When NOT to use:
  - Discrete arrays with a peak: use binary search (LC 162)
  - Sorted arrays: use binary search
  - Most interview problems: binary search is more common

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Ternary search rarely appears in standard coding interviews;
     more common in competitive programming
  2. For unimodal problems in interviews: binary search on the
     slope (nums[mid] vs nums[mid+1]) achieves the same result
     more efficiently
  3. The key concept: unimodal = single peak or single valley
  4. If asked about ternary vs binary search: binary is O(log n)
     with 1 comparison; ternary is O(log n) with 2 comparisons;
     binary is more efficient per comparison but both converge
