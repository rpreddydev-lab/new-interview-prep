COMBINATION SUM (LC 39) -- reuse elements, unique candidates
----------------------------------------------------------------
Find all combinations summing to target. Candidates can be reused.

  void backtrack(int[] candidates, int target, int start, List<Integer> path, ...) {
    if (target == 0) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i < candidates.length; i++) {
      if (candidates[i] > target) break;  // pruning (sorted array)
      path.add(candidates[i]);
      backtrack(candidates, target - candidates[i], i, path, res);  // i (not i+1): reuse
      path.remove(path.size() - 1);
    }
  }
  // Arrays.sort(candidates) first for pruning

  Note: `i` (not `i+1`) in recursive call allows reusing same element.

----------------------------------------------------------------
COMBINATION SUM II (LC 40) -- no reuse, duplicates in input
----------------------------------------------------------------
Each candidate used at most once. Skip duplicates at same level.

  void backtrack(int[] candidates, int target, int start, ...) {
    if (target == 0) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i < candidates.length; i++) {
      if (i > start && candidates[i] == candidates[i-1]) continue;  // skip dup
      if (candidates[i] > target) break;   // prune
      path.add(candidates[i]);
      backtrack(candidates, target - candidates[i], i + 1, path, res);  // i+1: no reuse
      path.remove(path.size() - 1);
    }
  }

----------------------------------------------------------------
COMBINATIONS k of n (LC 77)
----------------------------------------------------------------
Choose k numbers from [1, n].

  void backtrack(int n, int k, int start, List<Integer> path, ...) {
    if (path.size() == k) { res.add(new ArrayList<>(path)); return; }
    // Pruning: need k - path.size() more, must have i..n enough elements
    int need = k - path.size();
    for (int i = start; i <= n - need + 1; i++) {  // n - need + 1: pruning
      path.add(i);
      backtrack(n, k, i + 1, path, res);
      path.remove(path.size() - 1);
    }
  }

  Key pruning: if remaining positions = k - path.size(), we need at least
  that many numbers left: i <= n - (k - path.size()) + 1

----------------------------------------------------------------
COMBINATION SUM IV (LC 377) -- ORDER MATTERS (not backtracking!)
----------------------------------------------------------------
Count ways to reach target where order matters (different orders count).
This is NOT combinations -- it's a DP problem.

  int combinationSum4(int[] nums, int target) {
    int[] dp = new int[target + 1];
    dp[0] = 1;
    for (int t = 1; t <= target; t++)
      for (int num : nums)
        if (t >= num) dp[t] += dp[t - num];
    return dp[target];
  }

  Distinguish: Combination Sum (LC 39) = backtracking, no order
               Combination Sum IV (LC 377) = DP, order matters

COMPARISON TABLE
----------------------------------------------------------------
  Problem                   Reuse?  Duplicates?  Order?  Approach
  ---------------------------------------------------------------
  Combination Sum (39)      Yes     No           No      Backtrack, i (reuse)
  Combination Sum II (40)   No      Yes          No      Backtrack + skip dup
  Combinations (77)         No      No           No      Backtrack, prune i<=n-need+1
  Combination Sum IV (377)  Yes     No           Yes     DP (unbounded knapsack)
  Subsets (78)              No      No           No      Backtrack, add at each node

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Reuse allowed: pass `i` (not `i+1`) in recursive call
  2. No reuse: pass `i+1`
  3. Duplicates: sort + `if (i > start && nums[i] == nums[i-1]) continue`
  4. Pruning for sorted arrays: `if (candidates[i] > target) break`
  5. Order matters -> DP not backtracking (Combination Sum IV)
