================================================================
  SUDOKU SOLVER (LC 37)
================================================================

----------------------------------------------------------------
PROBLEM
----------------------------------------------------------------
Fill a 9x9 grid following Sudoku rules:
  - Each row: digits 1-9, no repeats
  - Each column: digits 1-9, no repeats
  - Each 3x3 box: digits 1-9, no repeats
Cells containing '.' must be filled. Guaranteed unique solution.

----------------------------------------------------------------
IMPLEMENTATION
----------------------------------------------------------------
  // Track used digits with boolean arrays for O(1) validation
  boolean[][] rows  = new boolean[9][10];  // rows[r][d] = digit d used in row r
  boolean[][] cols  = new boolean[9][10];
  boolean[][] boxes = new boolean[9][10];  // boxes[box][d]
  // box index = (r/3)*3 + c/3

  boolean solve(char[][] board) {
    for (int r = 0; r < 9; r++) {
      for (int c = 0; c < 9; c++) {
        if (board[r][c] != '.') continue;
        int box = (r / 3) * 3 + (c / 3);
        for (char d = '1'; d <= '9'; d++) {
          int dig = d - '0';
          if (rows[r][dig] || cols[c][dig] || boxes[box][dig]) continue;
          // Place digit
          board[r][c] = d;
          rows[r][dig] = cols[c][dig] = boxes[box][dig] = true;
          if (solve(board)) return true;    // solution found
          // Backtrack
          board[r][c] = '.';
          rows[r][dig] = cols[c][dig] = boxes[box][dig] = false;
        }
        return false;  // no valid digit: backtrack further
      }
    }
    return true;  // all cells filled
  }

  // Pre-fill rows/cols/boxes from initial board before calling solve(board)

----------------------------------------------------------------
PREFILL SETUP
----------------------------------------------------------------
  void solveSudoku(char[][] board) {
    boolean[][] rows  = new boolean[9][10];
    boolean[][] cols  = new boolean[9][10];
    boolean[][] boxes = new boolean[9][10];
    for (int r = 0; r < 9; r++)
      for (int c = 0; c < 9; c++)
        if (board[r][c] != '.') {
          int d = board[r][c] - '0';
          int box = (r/3)*3 + c/3;
          rows[r][d] = cols[c][d] = boxes[box][d] = true;
        }
    solve(board, rows, cols, boxes);
  }

----------------------------------------------------------------
ADVANCED: MOST CONSTRAINED CELL FIRST (MRV heuristic)
----------------------------------------------------------------
Minimum Remaining Values: always fill the cell with fewest
valid options. Dramatically reduces backtracking.

  For each empty cell, count valid digits.
  Pick cell with minimum count. Fill it. Repeat.
  This heuristic is used in production Sudoku solvers.

----------------------------------------------------------------
COMPLEXITY
----------------------------------------------------------------
  Worst case: O(9^81) -- 9 choices for each of 81 cells
  Practical: with constraints, much fewer iterations
  With MRV heuristic: human puzzles solved in microseconds

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Box index formula: `(r/3)*3 + c/3` -- memorize this
  2. Pre-initialize constraint arrays from given digits before backtracking
  3. Return true/false from solve() to short-circuit after first solution
  4. MRV heuristic: mention it as an optimization even if not implementing
  5. Similarity to N-Queens: row/column constraints; Sudoku adds box constraint
