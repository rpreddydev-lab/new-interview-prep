================================================================
  COMMON RECURSION PATTERNS
================================================================

----------------------------------------------------------------
1. DECREASE AND CONQUER (subtract 1 each call)
----------------------------------------------------------------
  Problem reduces by 1 each step. T(n) = T(n-1) + O(1) -> O(n)

  Examples:
    Factorial: n! = n * (n-1)!
    Array sum: sum(arr, n) = arr[n-1] + sum(arr, n-1)
    Reverse string: reverse(s) = s.last + reverse(s without last)
    Tower of Hanoi: hanoi(n, from, to, aux)
      hanoi(n, A, C, B) = hanoi(n-1, A, B, C) + move disk A->C + hanoi(n-1, B, C, A)

  Tower of Hanoi -- T(n) = 2T(n-1) + 1 = O(2^n)
    void hanoi(int n, char from, char to, char aux) {
      if (n == 1) { print("Move disk 1 from " + from + " to " + to); return; }
      hanoi(n-1, from, aux, to);
      print("Move disk " + n + " from " + from + " to " + to);
      hanoi(n-1, aux, to, from);
    }

----------------------------------------------------------------
2. DIVIDE AND CONQUER (split into halves)
----------------------------------------------------------------
  T(n) = 2T(n/2) + O(n) -> O(n log n) (merge sort)
  T(n) = T(n/2) + O(1) -> O(log n) (binary search)

  Binary search recursive:
    int binarySearch(int[] arr, int left, int right, int target) {
      if (left > right) return -1;
      int mid = left + (right - left) / 2;
      if (arr[mid] == target) return mid;
      if (arr[mid] > target) return binarySearch(arr, left, mid-1, target);
      return binarySearch(arr, mid+1, right, target);
    }

----------------------------------------------------------------
3. TREE TRAVERSAL PATTERN
----------------------------------------------------------------
  The most important pattern: process node, recurse on children.

  DFS preorder: process node BEFORE children
    void preorder(Node root) {
      if (root == null) return;
      process(root);
      preorder(root.left);
      preorder(root.right);
    }

  DFS postorder: process node AFTER children
    int height(Node root) {
      if (root == null) return 0;
      int leftH = height(root.left);
      int rightH = height(root.right);
      return 1 + Math.max(leftH, rightH);  // use children results
    }

  Accumulate results from subtrees: return-value pattern.
  Pass values down to subtrees: parameter pattern.

----------------------------------------------------------------
4. RETURN VALUE vs PARAMETER PASSING
----------------------------------------------------------------
  Return value (bottom-up): each call returns info to its caller
    int maxDepth(TreeNode root) {
      if (root == null) return 0;
      return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
    }

  Parameter passing (top-down): caller passes accumulated state
    void buildPath(TreeNode node, List<Integer> path, List<List<Integer>> result) {
      if (node == null) return;
      path.add(node.val);
      if (node.left == null && node.right == null) result.add(new ArrayList<>(path));
      buildPath(node.left, path, result);
      buildPath(node.right, path, result);
      path.remove(path.size() - 1);  // backtrack
    }

  Combined: global variable updated with recursive helper return value
    int maxGain;  // global
    int pathSum(TreeNode node) {
      if (node == null) return 0;
      int left = Math.max(0, pathSum(node.left));
      int right = Math.max(0, pathSum(node.right));
      maxGain = Math.max(maxGain, left + right + node.val);  // update global
      return node.val + Math.max(left, right);               // return single path
    }

----------------------------------------------------------------
5. MEMOIZATION (Top-Down DP)
----------------------------------------------------------------
  Recursion + cache = memoization. Transforms exponential to polynomial.

  int fib(int n, int[] memo) {
    if (n <= 1) return n;
    if (memo[n] != 0) return memo[n];
    return memo[n] = fib(n-1, memo) + fib(n-2, memo);
  }

  Without memo: O(2^n)   With memo: O(n)

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. "Trust the recursion" -- assume helper returns correct result
     for smaller input; build answer from it
  2. Postorder (bottom-up) = gather results from children
     Preorder (top-down) = pass data to children via parameters
  3. Add memoization if overlapping subproblems are detected
  4. For tree problems: handle null check first, then recurse
  5. For path problems (root-to-leaf): use parameter list + backtrack
