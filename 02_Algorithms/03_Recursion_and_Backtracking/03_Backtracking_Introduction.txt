  BACKTRACKING -- INTRODUCTION

----------------------------------------------------------------
WHAT IS BACKTRACKING?
----------------------------------------------------------------
Backtracking is a systematic algorithm for exploring all possible
solutions to a problem by:
  1. Making a CHOICE (add element to current solution)
  2. RECURSING on the remaining problem
  3. UNDOING the choice (backtrack) to explore other options

  It builds the solution incrementally and abandons (prunes)
a partial solution as soon as it determines the current path
cannot lead to a valid complete solution.

  Backtracking = Brute Force + Pruning

----------------------------------------------------------------
GENERAL TEMPLATE
----------------------------------------------------------------
  void backtrack(State currentState, List<Solution> results) {
    if (isComplete(currentState)) {
      results.add(new Solution(currentState));  // found valid solution
      return;
    }
    for (Choice choice : getChoices(currentState)) {
      if (!isValid(currentState, choice)) continue;  // pruning
      makeChoice(currentState, choice);              // modify state
      backtrack(currentState, results);              // recurse
      undoChoice(currentState, choice);              // BACKTRACK (undo)
    }
  }

  The KEY operation: undo the choice after recursion returns.
  This is what distinguishes backtracking from simple DFS.

----------------------------------------------------------------
BACKTRACKING vs DFS
----------------------------------------------------------------
  DFS: explore a path; may or may not undo state changes.
  Backtracking: always undo -- explores ALL paths, returns to
    previous state after each branch.

  When the "state" is implicit in the recursion (integers, indices),
  no explicit undo is needed -- the parameters naturally restore.
  When state is mutable (list, board, boolean array), explicit
  undo is required.

----------------------------------------------------------------
PRUNING STRATEGIES
----------------------------------------------------------------
  1. Constraint pruning: skip invalid choices immediately
     (e.g., N-Queens: skip columns already used)

  2. Bound pruning: skip if current partial solution already
     exceeds best known (branch and bound for optimization)

  3. Duplicate pruning: sort + skip same value at same position
     (e.g., Subsets II / Combination Sum II)

  Effective pruning dramatically reduces the search space.
  Poor pruning: O(n!)   Good pruning: much better in practice.

----------------------------------------------------------------
PROBLEMS SUITED FOR BACKTRACKING
----------------------------------------------------------------
  Problem Type                     Example
  ----------------------------------------------------------
  Subsets                          All subsets of [1,2,3]
  Permutations                     All orderings of [1,2,3]
  Combinations                     All size-k subsets
  N-Queens                         Place n queens on n x n board
  Sudoku                           Fill 9x9 grid with constraints
  Word Search                      Find word in 2D grid
  Expression generation            Add operators to digits
  Palindrome Partitioning          Split string into palindromes
  Knight's Tour                    Chess knight visits all squares
  Graph coloring                   Color graph with k colors

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. The undo step is critical -- missing it is the most common bug
     in backtracking implementations
  2. Choice: what options do you have at each step?
     Constraint: what makes a choice invalid?
     Goal: what constitutes a complete solution?
  3. To avoid duplicates: sort input, skip same value at same level
  4. Time complexity: O(choices^depth) at worst -- exponential.
     Pruning is what makes it practical.
  5. In Java: use a Deque/LinkedList for the current path;
     add/removeLast for O(1) backtracking
