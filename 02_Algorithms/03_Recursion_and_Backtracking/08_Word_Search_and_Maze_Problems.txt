  WORD SEARCH & MAZE PROBLEMS

----------------------------------------------------------------
WORD SEARCH (LC 79)
----------------------------------------------------------------
Find if a word exists in a 2D grid by navigating adjacent cells
(up/down/left/right). Cannot reuse the same cell.

  boolean exist(char[][] board, String word) {
    int m = board.length, n = board[0].length;
    for (int r = 0; r < m; r++)
      for (int c = 0; c < n; c++)
        if (dfs(board, word, r, c, 0)) return true;
    return false;
  }

  boolean dfs(char[][] board, String word, int r, int c, int idx) {
    if (idx == word.length()) return true;              // found!
    if (r < 0 || r >= board.length || c < 0 || c >= board[0].length) return false;
    if (board[r][c] != word.charAt(idx)) return false; // mismatch
    char tmp = board[r][c];
    board[r][c] = '#';           // mark visited (backtrack on same path)
    boolean found = dfs(board, word, r+1, c, idx+1)
                 || dfs(board, word, r-1, c, idx+1)
                 || dfs(board, word, r, c+1, idx+1)
                 || dfs(board, word, r, c-1, idx+1);
    board[r][c] = tmp;           // restore (backtrack)
    return found;
  }

  Time: O(m * n * 4^L)  where L = word length
  Space: O(L) recursion depth

  Key: modify board in-place with '#' instead of a separate visited array.
  Restoring board[r][c] = tmp is the backtracking step.

----------------------------------------------------------------
WORD SEARCH II (LC 212) -- multiple words
----------------------------------------------------------------
Find all words from a dictionary that exist in the board.
Use TRIE for efficient multi-word search.

  - Build Trie from all words
  - DFS from each cell, prune when Trie node = null
  - Mark word found when Trie node has `word` field set
  - Remove found words from Trie to avoid duplicates

  Time: O(m * n * 4^L + sum of word lengths for Trie build)

----------------------------------------------------------------
MAZE PROBLEMS
----------------------------------------------------------------
Find path from start to end in a 2D grid with obstacles.

  Has path (DFS):
    boolean hasPath(int[][] maze, int[] start, int[] end, boolean[][] visited) {
      int r = start[0], c = start[1];
      if (r == end[0] && c == end[1]) return true;
      int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
      visited[r][c] = true;
      for (int[] d : dirs) {
        int nr = r + d[0], nc = c + d[1];
        if (nr >= 0 && nr < maze.length && nc >= 0 && nc < maze[0].length
            && !visited[nr][nc] && maze[nr][nc] == 0)
          if (hasPath(maze, new int[]{nr, nc}, end, visited)) return true;
      }
      return false;
    }

  All paths: backtrack + restore visited[r][c] = false after recursion
  Shortest path: use BFS instead of DFS

  Maze II (LC 490): ball rolls until hitting a wall (extend movement loop).

----------------------------------------------------------------
COMMON PATTERNS
----------------------------------------------------------------
  Direction array:  int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
  In-place visited: mark board[r][c] = '#'; restore after backtrack
  Return on success: short-circuit with `||` operator
  All paths: don't short-circuit; always backtrack and continue

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. In-place visited (mark '#') avoids O(m*n) boolean array allocation
  2. Must RESTORE the cell after backtracking -- forgetting this
     prevents exploring other starting paths from the same cell
  3. Word Search II: Trie + DFS is the standard O(m*n*4^L) solution
  4. Shortest path in a maze: always BFS (not DFS)
  5. Short-circuit with `||` for "find any path"; iterate all for "all paths"
