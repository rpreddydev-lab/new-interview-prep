================================================================
  CYCLE DETECTION: DIRECTED GRAPHS
================================================================

----------------------------------------------------------------
METHOD 1: DFS WITH COLOR STATES
----------------------------------------------------------------
  0 = unvisited, 1 = in current path, 2 = fully processed
  A cycle exists if we encounter a GRAY (1) node during DFS.

  boolean hasCycle(int n, List<List<Integer>> adj) {
    int[] state = new int[n];
    for (int i = 0; i < n; i++)
      if (state[i] == 0 && dfs(adj, state, i)) return true;
    return false;
  }
  boolean dfs(List<List<Integer>> adj, int[] state, int node) {
    state[node] = 1;
    for (int neighbor : adj.get(node)) {
      if (state[neighbor] == 1) return true;      // back edge = cycle
      if (state[neighbor] == 0 && dfs(adj, state, neighbor)) return true;
    }
    state[node] = 2;
    return false;
  }

  Time: O(V + E)  Space: O(V)

----------------------------------------------------------------
METHOD 2: KAHN'S ALGORITHM
----------------------------------------------------------------
If topological sort (Kahn's) cannot process all nodes --> cycle exists.
  return kahnTopSort(n, adj).size() != n;  // cycle detected

  Preferred when you also need the topological order.

----------------------------------------------------------------
FIND EVENTUAL SAFE NODES (LC 802)
----------------------------------------------------------------
A node is SAFE if every path from it eventually reaches a terminal node
(or a safe node). Safe = not on a cycle and not leading to a cycle.

  int[] state = new int[n];  // 0=unknown, 1=unsafe(cycle), 2=safe
  boolean isSafe(int[][] graph, int node) {
    if (state[node] != 0) return state[node] == 2;
    state[node] = 1;  // mark as unsafe (in progress)
    for (int next : graph[node])
      if (!isSafe(graph, next)) return false;  // if any path is unsafe
    state[node] = 2;  // all paths are safe
    return true;
  }

  Reverse Kahn's alternative: reverse edges, find nodes with out-degree 0.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Directed cycle detection: use 3-color DFS (0/1/2)
  2. Don't use 2-color DFS (which works for undirected) on directed graphs
     -- it will give false positives for cross edges
  3. Kahn's cycle detection is simpler to implement but doesn't identify
     where the cycle is
  4. Safe nodes (LC 802): 3-color DFS with memoization
  5. For FINDING a cycle (not just detecting): record parent path in DFS
