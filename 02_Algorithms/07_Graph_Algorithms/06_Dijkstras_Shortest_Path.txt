================================================================
  DIJKSTRA'S SHORTEST PATH
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Single-source shortest path for graphs with NON-NEGATIVE weights.
Greedy: always extend the unvisited node with smallest current distance.

  Uses a min-heap (PriorityQueue) for efficient minimum extraction.
  Time: O((V + E) log V) with binary heap.

  Cannot handle NEGATIVE weights -- use Bellman-Ford for those.

----------------------------------------------------------------
IMPLEMENTATION (Adjacency List + PriorityQueue)
----------------------------------------------------------------
  int[] dijkstra(int n, List<List<int[]>> adj, int src) {
    // adj: list of [neighbor, weight] pairs
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
    pq.offer(new int[]{0, src});  // {distance, node}

    while (!pq.isEmpty()) {
      int[] curr = pq.poll();
      int d = curr[0], u = curr[1];
      if (d > dist[u]) continue;  // stale entry: skip (key optimization)
      for (int[] edge : adj.get(u)) {
        int v = edge[0], w = edge[1];
        if (dist[u] + w < dist[v]) {
          dist[v] = dist[u] + w;
          pq.offer(new int[]{dist[v], v});
        }
      }
    }
    return dist;  // dist[i] = shortest distance from src to i
  }

  Time: O((V + E) log V)  Space: O(V + E)

  Key: `if (d > dist[u]) continue;` -- lazy deletion of stale entries.
  Without it, stale entries still work but take extra time.

----------------------------------------------------------------
NETWORK DELAY TIME (LC 743)
----------------------------------------------------------------
  int networkDelayTime(int[][] times, int n, int k) {
    List<List<int[]>> adj = new ArrayList<>();
    for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
    for (int[] t : times) adj.get(t[0]).add(new int[]{t[1], t[2]});
    int[] dist = dijkstra(n+1, adj, k);
    int max = 0;
    for (int i = 1; i <= n; i++) {
      if (dist[i] == Integer.MAX_VALUE) return -1;
      max = Math.max(max, dist[i]);
    }
    return max;
  }

----------------------------------------------------------------
CHEAPEST FLIGHTS WITHIN K STOPS (LC 787) -- Modified Dijkstra / Bellman-Ford
----------------------------------------------------------------
Shortest path with constraint: at most k stops.
  State: (cost, node, stops_remaining)
  Use Bellman-Ford with K+1 iterations instead of Dijkstra.
  Or Dijkstra with state (cost, node, stops) -- but can revisit nodes.

  int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
    int[] prices = new int[n];
    Arrays.fill(prices, Integer.MAX_VALUE);
    prices[src] = 0;
    for (int i = 0; i <= k; i++) {    // k stops = k+1 edges
      int[] temp = Arrays.copyOf(prices, n);
      for (int[] f : flights)
        if (prices[f[0]] != Integer.MAX_VALUE)
          temp[f[1]] = Math.min(temp[f[1]], prices[f[0]] + f[2]);
      prices = temp;
    }
    return prices[dst] == Integer.MAX_VALUE ? -1 : prices[dst];
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Dijkstra: non-negative weights only (negative -> Bellman-Ford)
  2. Pattern: (dist, node) in PQ; stale check `if (d > dist[u]) continue`
  3. For dense graphs: O(V^2) with array (no PQ) is better
  4. For shortest path with constraints (stops, edges): add constraint to state
  5. Dijkstra is a greedy algorithm: correctness relies on non-negative weights
     (negative weight could make a visited node better later)
