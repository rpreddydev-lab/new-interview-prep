----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Add ALL source nodes to the BFS queue BEFORE starting.
This computes the shortest distance from the NEAREST source
to every other node in O(V + E).

  Equivalent to adding a virtual super-source connected to all
  real sources with weight 0, then running single-source BFS.

  // Multi-source BFS template:
  Queue<int[]> queue = new ArrayDeque<>();
  boolean[][] visited = new boolean[m][n];
  // 1. Add all sources first
  for (int r = 0; r < m; r++) for (int c = 0; c < n; c++)
    if (isSource(grid[r][c])) {
      queue.offer(new int[]{r, c, 0});
      visited[r][c] = true;
    }
  // 2. BFS outward
  while (!queue.isEmpty()) {
    int[] curr = queue.poll();
    // process and expand to neighbors
  }

ROTTEN ORANGES (LC 994)
----------------------------------------------------------------
All rotten oranges rot neighbors simultaneously. Find time for all to rot.

  int orangesRotting(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    Queue<int[]> queue = new ArrayDeque<>();
    int fresh = 0;
    for (int r = 0; r < m; r++) for (int c = 0; c < n; c++) {
      if (grid[r][c] == 2) queue.offer(new int[]{r, c, 0});
      else if (grid[r][c] == 1) fresh++;
    }
    int time = 0;
    int[] dr = {0,0,1,-1}, dc = {1,-1,0,0};
    while (!queue.isEmpty()) {
      int[] curr = queue.poll();
      int r = curr[0], c = curr[1], t = curr[2];
      for (int d = 0; d < 4; d++) {
        int nr = r + dr[d], nc = c + dc[d];
        if (nr>=0&&nr<m&&nc>=0&&nc<n&&grid[nr][nc]==1) {
          grid[nr][nc] = 2;
          fresh--;
          time = Math.max(time, t + 1);
          queue.offer(new int[]{nr, nc, t+1});
        }
      }
    }
    return fresh == 0 ? time : -1;
  }

  Optimization: track time with level-by-level BFS (snapshot size)
  instead of storing time in queue element.

----------------------------------------------------------------
01 BFS (DEQUE-BASED BFS FOR 0/1 WEIGHTS)
----------------------------------------------------------------
For graphs where edges have weight 0 or 1, use Deque:
  - Weight 0 edge: add to FRONT of deque (like free teleportation)
  - Weight 1 edge: add to BACK (normal BFS)
  Result: min distance in O(V + E) instead of O((V+E) log V) for Dijkstra.

  int[] dist = new int[n]; Arrays.fill(dist, INF); dist[src] = 0;
  Deque<Integer> deque = new ArrayDeque<>();
  deque.offerFirst(src);
  while (!deque.isEmpty()) {
    int u = deque.pollFirst();
    for (int[] edge : adj.get(u)) {
      int v = edge[0], w = edge[1];
      if (dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        if (w == 0) deque.offerFirst(v); else deque.offerLast(v);
      }
    }
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Multi-source BFS: add ALL sources before starting (not one at a time)
  2. Rotten Oranges: level-by-level BFS elegantly computes time
  3. 01 BFS: deque-based for 0/1 weight edges -- O(V+E) vs Dijkstra O((V+E)logV)
  4. Multi-source BFS computes distance to nearest source for every node
  5. Common pattern: Walls and Gates, Distance to nearest 0 in matrix (LC 542)
