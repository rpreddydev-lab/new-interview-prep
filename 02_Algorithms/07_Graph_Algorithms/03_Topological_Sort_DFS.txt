================================================================
  TOPOLOGICAL SORT: DFS-BASED
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Post-order DFS: add node to result AFTER visiting all descendants.
Reverse the post-order to get topological order.

  Colors / States:
    0 = unvisited
    1 = in current DFS path (gray)
    2 = fully processed (black)
  If we reach a GRAY node during DFS --> cycle detected.

----------------------------------------------------------------
IMPLEMENTATION
----------------------------------------------------------------
  Deque<Integer> result = new ArrayDeque<>();
  boolean hasCycle = false;

  boolean dfsTopSort(int n, List<List<Integer>> adj) {
    int[] state = new int[n];  // 0=unvisited, 1=visiting, 2=done
    for (int i = 0; i < n; i++)
      if (state[i] == 0) dfs(adj, state, i);
    return !hasCycle;
  }

  void dfs(List<List<Integer>> adj, int[] state, int node) {
    if (hasCycle) return;
    state[node] = 1;  // mark as visiting
    for (int neighbor : adj.get(node)) {
      if (state[neighbor] == 1) { hasCycle = true; return; }  // back edge = cycle
      if (state[neighbor] == 0) dfs(adj, state, neighbor);
    }
    state[node] = 2;     // mark as done
    result.push(node);   // add to FRONT (push to stack -> reversal)
  }

  // result (iterated as deque) gives topological order
  // or use ArrayDeque and pollFirst for result.

  Time: O(V + E)  Space: O(V)

----------------------------------------------------------------
DFS TOPOLOGICAL SORT vs KAHN'S
----------------------------------------------------------------
  Feature              DFS Topo Sort          Kahn's (BFS)
  -------              -------------          ------------
  Cycle detection      Yes (gray node)        Yes (result.size < n)
  Implementation       Recursive DFS          Iterative BFS
  Output order         Reverse post-order     Direct queue order
  Preference           SCC algorithms         Course Schedule type

ALL PATHS FROM SOURCE TO TARGET (LC 797)
----------------------------------------------------------------
Find all paths from node 0 to node n-1 in a DAG.
  DFS + path tracking (guaranteed to terminate because DAG has no cycles).

  List<List<Integer>> allPaths(int[][] graph) {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    path.add(0);
    dfsAllPaths(graph, 0, path, res);
    return res;
  }
  void dfsAllPaths(int[][] graph, int node, List<Integer> path, List<List<Integer>> res) {
    if (node == graph.length - 1) { res.add(new ArrayList<>(path)); return; }
    for (int next : graph[node]) {
      path.add(next);
      dfsAllPaths(graph, next, path, res);
      path.remove(path.size() - 1);
    }
  }

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Three-state DFS (0/1/2) elegantly handles cycle detection
  2. A back edge (1 -> 1) = cycle; forward/cross edges are fine for topo sort
  3. Post-order + reverse = topological order
  4. Kahn's is preferred for interview (simpler); DFS needed for Tarjan's/Kosaraju's
  5. In undirected graphs: any revisit from different parent = cycle (not just gray nodes)
