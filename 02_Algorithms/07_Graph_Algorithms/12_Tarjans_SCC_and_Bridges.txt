  TARJAN'S SCC AND BRIDGES / ARTICULATION POINTS

----------------------------------------------------------------
TARJAN'S SCC ALGORITHM
----------------------------------------------------------------
Single-pass DFS using discovery time (disc[]) and low-link (low[]).
low[v] = smallest disc[] reachable from subtree rooted at v via back edges.

A node v is ROOT of SCC if low[v] == disc[v].
  (No back edge escapes to ancestors = it's its own SCC root)

  int[] disc, low;
  boolean[] onStack;
  int timer;
  Deque<Integer> stack;

  void tarjanDFS(int u, List<List<Integer>> adj) {
    disc[u] = low[u] = timer++;
    stack.push(u); onStack[u] = true;
    for (int v : adj.get(u)) {
      if (disc[v] == -1) {
        tarjanDFS(v, adj);
        low[u] = Math.min(low[u], low[v]);
      } else if (onStack[v]) {     // back edge to node on current stack
        low[u] = Math.min(low[u], disc[v]);
      }
    }
    if (low[u] == disc[u]) {  // u is root of SCC: pop until u
      List<Integer> scc = new ArrayList<>();
      while (true) {
        int w = stack.pop(); onStack[w] = false; scc.add(w);
        if (w == u) break;
      }
      // scc is one strongly connected component
    }
  }

  Time: O(V + E)  Space: O(V)

----------------------------------------------------------------
BRIDGES (CRITICAL CONNECTIONS -- LC 1192)
----------------------------------------------------------------
A bridge is an edge whose removal disconnects the graph.
For undirected graph: edge (u,v) is bridge if low[v] > disc[u]
  (v cannot reach u or above via any back edge).

  List<List<Integer>> criticalConnections(int n, List<List<Integer>> connections) {
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
    for (List<Integer> c : connections) {
      adj.get(c.get(0)).add(c.get(1)); adj.get(c.get(1)).add(c.get(0));
    }
    int[] disc = new int[n], low = new int[n];
    Arrays.fill(disc, -1);
    List<List<Integer>> bridges = new ArrayList<>();
    dfs(adj, disc, low, bridges, 0, -1, new int[]{0});
    return bridges;
  }
  void dfs(List<List<Integer>> adj, int[] disc, int[] low, List<List<Integer>> bridges,
           int u, int parent, int[] timer) {
    disc[u] = low[u] = timer[0]++;
    for (int v : adj.get(u)) {
      if (v == parent) continue;
      if (disc[v] == -1) {
        dfs(adj, disc, low, bridges, v, u, timer);
        low[u] = Math.min(low[u], low[v]);
        if (low[v] > disc[u]) bridges.add(Arrays.asList(u, v));  // BRIDGE condition
      } else {
        low[u] = Math.min(low[u], disc[v]);
      }
    }
  }

----------------------------------------------------------------
ARTICULATION POINTS
----------------------------------------------------------------
A node u is articulation point if:
  1. u is root AND has 2+ DFS children (root special case)
  2. u is NOT root AND low[child] >= disc[u] (child can't bypass u)

  Bridge condition: low[v] > disc[u]  (strictly greater)
  Articulation point: low[v] >= disc[u]  (greater or equal)

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. low[v] = min(disc[v], disc of ancestors reachable via back edges)
  2. Bridge: low[v] > disc[u] (strict); Articulation: low[v] >= disc[u]
  3. Tarjan's SCC: low[u] == disc[u] marks SCC root
  4. onStack[] distinguishes back edges (to current path) from cross edges
  5. Critical Connections (LC 1192) = find bridges; very common interview problem
