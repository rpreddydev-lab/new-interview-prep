================================================================
  PRIM'S MINIMUM SPANNING TREE
================================================================

----------------------------------------------------------------
CORE IDEA
----------------------------------------------------------------
Builds MST by greedily adding the CHEAPEST EDGE connecting the
grown MST to a new unvisited vertex.

  Start with any node. Use min-heap of (cost, node).
  Repeatedly extract min-cost, add to MST, add its edges to heap.
  Like Dijkstra but adding edge weight (not path sum) to heap.

  Time: O(E log V)  Space: O(V + E)

  MST = Minimum Spanning TREE: V-1 edges, all V nodes connected,
  minimum total weight, no cycles.

----------------------------------------------------------------
IMPLEMENTATION (Adjacency List + PriorityQueue)
----------------------------------------------------------------
  int primsMST(int n, List<List<int[]>> adj) {
    // adj: list of [neighbor, weight]
    boolean[] inMST = new boolean[n];
    PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
    pq.offer(new int[]{0, 0});  // {cost, node}, start from node 0
    int totalCost = 0, edgesAdded = 0;

    while (!pq.isEmpty() && edgesAdded < n) {
      int[] curr = pq.poll();
      int cost = curr[0], u = curr[1];
      if (inMST[u]) continue;  // already in MST
      inMST[u] = true;
      totalCost += cost;
      edgesAdded++;
      for (int[] edge : adj.get(u)) {
        int v = edge[0], w = edge[1];
        if (!inMST[v]) pq.offer(new int[]{w, v});
      }
    }
    return edgesAdded == n ? totalCost : -1;  // -1 if disconnected
  }

----------------------------------------------------------------
PRIM'S vs KRUSKAL'S
----------------------------------------------------------------
  Feature           Prim's               Kruskal's
  -------           ------               ---------
  Approach          Vertex-based         Edge-based
  Data structure    PQ (min-heap)        Union-Find + sort edges
  Dense graph       O(E log V) better    O(E log E) sorting dominates
  Sparse graph      O(E log V)           O(E log E) similar
  Implementation    BFS-like             Sort + Union-Find
  Disconnected      Detects naturally    Need explicit check

----------------------------------------------------------------
MIN COST TO CONNECT ALL POINTS (LC 1584)
----------------------------------------------------------------
Connect all points with minimum Manhattan distance cost.
  Points are fully connected: E = V^2. Use Prim's (dense graph).

  int minCostConnectPoints(int[][] points) {
    int n = points.length;
    int[] minCost = new int[n];  // min edge cost to add this point to MST
    boolean[] inMST = new boolean[n];
    Arrays.fill(minCost, Integer.MAX_VALUE);
    minCost[0] = 0;
    int totalCost = 0;
    for (int iter = 0; iter < n; iter++) {
      int u = -1;
      for (int i = 0; i < n; i++)  // find min-cost unvisited
        if (!inMST[i] && (u == -1 || minCost[i] < minCost[u])) u = i;
      inMST[u] = true;
      totalCost += minCost[u];
      for (int v = 0; v < n; v++)
        if (!inMST[v]) {
          int dist = Math.abs(points[u][0]-points[v][0]) + Math.abs(points[u][1]-points[v][1]);
          minCost[v] = Math.min(minCost[v], dist);
        }
    }
    return totalCost;
  }
  // O(n^2) Prim's without heap -- better than O(n^2 log n) with heap for dense graph

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Prim's = Dijkstra-like but adds EDGE WEIGHT (not path sum) to PQ
  2. For dense graphs: O(V^2) Prim's (array-based) is better than O(E log V)
  3. For LC 1584: use O(n^2) array Prim's since n points = n^2 edges
  4. MST has exactly V-1 edges; if edgesAdded < n, graph is disconnected
  5. MST applications: network design, cluster analysis, Christofides approximation for TSP
