FIBONACCI (LC 509)
----------------------------------------------------------------
F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)

  NAIVE RECURSION: O(2^n) -- exponential due to overlapping subproblems
  MEMOIZATION: O(n) time, O(n) space
  TABULATION: O(n) time, O(n) space
  SPACE OPTIMIZED: O(n) time, O(1) space

  int fib(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) { int c = a + b; a = b; b = c; }
    return b;
  }

  MATRIX EXPONENTIATION: O(log n) time
    [[F(n+1)], [F(n)]] = [[1,1],[1,0]]^n * [[1],[0]]
    Use fast power on 2x2 matrix multiplication.

  CLOSED FORM (Binet's Formula): O(1) but floating point errors
    F(n) = round((phi^n - psi^n) / sqrt(5))
    phi = (1 + sqrt(5))/2 ≈ 1.618  (golden ratio)
    Not reliable for large n due to floating point precision.

CLIMBING STAIRS (LC 70)
----------------------------------------------------------------
Climb n stairs, can take 1 or 2 steps. How many distinct ways?

  This IS Fibonacci! ways(n) = ways(n-1) + ways(n-2)
  Base: ways(1)=1, ways(2)=2

  int climbStairs(int n) {
    if (n <= 2) return n;
    int prev2 = 1, prev1 = 2;
    for (int i = 3; i <= n; i++) { int cur = prev1 + prev2; prev2 = prev1; prev1 = cur; }
    return prev1;
  }

  GENERALIZATION: k steps allowed
    dp[i] = sum of dp[i-1] + dp[i-2] + ... + dp[i-k]
    Use sliding window sum for O(n) time.

    int climbStairsK(int n, int k) {
      int[] dp = new int[n + 1];
      dp[0] = 1;
      int windowSum = 1;
      for (int i = 1; i <= n; i++) {
        dp[i] = windowSum;
        windowSum += dp[i];
        if (i >= k) windowSum -= dp[i - k];
      }
      return dp[n];
    }

HOUSE ROBBER (LC 198)
----------------------------------------------------------------
Rob houses; can't rob adjacent houses. Maximize money.

  dp[i] = max money from first i houses
  dp[i] = max(dp[i-1], dp[i-2] + nums[i])

  int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;
    for (int num : nums) {
      int cur = Math.max(prev1, prev2 + num);
      prev2 = prev1;
      prev1 = cur;
    }
    return prev1;
  }
  Time: O(n)  Space: O(1)

  House Robber II (LC 213): houses in circle. Solve twice:
    Case 1: rob houses[0..n-2] (exclude last)
    Case 2: rob houses[1..n-1] (exclude first)
    Answer: max(case1, case2)

  House Robber III (LC 337): houses in binary tree.
    For each node: return [rob_this, skip_this]
    rob_this = node.val + skip(left) + skip(right)
    skip_this = max(rob, skip)(left) + max(rob, skip)(right)

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Climbing Stairs = Fibonacci (shifted by 1)
  2. House Robber: O(1) space by tracking only prev2 and prev1
  3. Circular house robber: solve linear twice, take max
  4. Fibonacci in O(log n): matrix exponentiation
  5. These 1D linear DP problems are entry-level;
     master them before attempting 2D DP
