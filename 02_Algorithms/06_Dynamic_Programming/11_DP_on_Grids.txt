UNIQUE PATHS (LC 62)
----------------------------------------------------------------
Count paths from top-left to bottom-right, moving only right or down.

  dp[i][j] = paths to reach (i,j)
  dp[i][j] = dp[i-1][j] + dp[i][j-1]
  Base: dp[0][j] = 1, dp[i][0] = 1 (only one way along edges)

  int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    for (int i = 1; i < m; i++)
      for (int j = 1; j < n; j++)
        dp[j] += dp[j-1];   // dp[j] = old dp[j] (from above) + dp[j-1] (from left)
    return dp[n-1];
  }
  Time: O(mn)  Space: O(n)  [1D rolling]

  Math solution: C(m+n-2, m-1) -- combinatorics

  Unique Paths II (LC 63): obstacles. If obstacle: dp[i][j] = 0.

----------------------------------------------------------------
MINIMUM PATH SUM (LC 64)
----------------------------------------------------------------
Find path (right/down) with minimum sum of values.

  dp[i][j] = min sum to reach (i,j)
  dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])

  int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[] dp = new int[n];
    dp[0] = grid[0][0];
    for (int j = 1; j < n; j++) dp[j] = dp[j-1] + grid[0][j];
    for (int i = 1; i < m; i++) {
      dp[0] += grid[i][0];
      for (int j = 1; j < n; j++)
        dp[j] = grid[i][j] + Math.min(dp[j], dp[j-1]);
    }
    return dp[n-1];
  }
  Time: O(mn)  Space: O(n)

----------------------------------------------------------------
TRIANGLE (LC 120)
----------------------------------------------------------------
Find min path from top to bottom of triangle.
Move from triangle[i][j] to [i+1][j] or [i+1][j+1].

  Bottom-up: start from last row, work up.
  dp[j] = min(dp[j], dp[j+1]) + triangle[i][j]

  int minimumTotal(List<List<Integer>> triangle) {
    int n = triangle.size();
    int[] dp = new int[n];
    for (int j = 0; j < n; j++) dp[j] = triangle.get(n-1).get(j);
    for (int i = n-2; i >= 0; i--)
      for (int j = 0; j <= i; j++)
        dp[j] = triangle.get(i).get(j) + Math.min(dp[j], dp[j+1]);
    return dp[0];
  }
  Time: O(n^2)  Space: O(n)

----------------------------------------------------------------
MAXIMUM SQUARE (LC 221)
----------------------------------------------------------------
Largest square of 1s in a binary matrix. Find side length.

  dp[i][j] = side of largest square with bottom-right at (i,j)
  dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1  if matrix[i][j] == '1'

  Why min? The square is limited by the smallest square among
  three adjacent cells. Beautiful insight.

  int maximalSquare(char[][] matrix) {
    int m = matrix.length, n = matrix[0].length, maxSide = 0;
    int[][] dp = new int[m+1][n+1];
    for (int i = 1; i <= m; i++)
      for (int j = 1; j <= n; j++)
        if (matrix[i-1][j-1] == '1') {
          dp[i][j] = Math.min(dp[i-1][j], Math.min(dp[i][j-1], dp[i-1][j-1])) + 1;
          maxSide = Math.max(maxSide, dp[i][j]);
        }
    return maxSide * maxSide;
  }
  Time: O(mn)  Space: O(mn) -> can reduce to O(n)

INTERVIEW TIPS
----------------------------------------------------------------
  1. Grid DP: always check if 1D rolling array reduces space from O(mn) to O(n)
  2. Unique Paths: combine math (combinatorics) with DP -- mention both
  3. Maximal Square: the `min of three neighbors` is a surprising and
     elegant insight -- explain it clearly
  4. Triangle: in-place bottom-up avoids extra space (use last row as dp)
  5. Most grid DP: only need current row and previous row
     --> roll 1D array with dp[j] = from-above + dp[j-1] = from-left
