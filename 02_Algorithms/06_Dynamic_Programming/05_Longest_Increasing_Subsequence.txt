================================================================
  LONGEST INCREASING SUBSEQUENCE (LIS)
================================================================

----------------------------------------------------------------
PROBLEM
----------------------------------------------------------------
Given an array, find the length of the longest strictly increasing
subsequence (not necessarily contiguous).

  [10, 9, 2, 5, 3, 7, 101, 18] -> LIS = [2, 3, 7, 18] or [2, 5, 7, 18]
  Length = 4

----------------------------------------------------------------
O(n^2) DP SOLUTION
----------------------------------------------------------------
  dp[i] = length of LIS ending at index i
  Transition: dp[i] = max(dp[j] + 1) for all j < i where nums[j] < nums[i]
  Base: dp[i] = 1 (each element alone)
  Answer: max(dp)

  int lengthOfLIS(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    int max = 1;
    for (int i = 1; i < n; i++)
      for (int j = 0; j < i; j++)
        if (nums[j] < nums[i]) { dp[i] = Math.max(dp[i], dp[j] + 1); max = Math.max(max, dp[i]); }
    return max;
  }

  Time: O(n^2)  Space: O(n)

----------------------------------------------------------------
O(n LOG n) PATIENCE SORTING / BINARY SEARCH
----------------------------------------------------------------
Maintain array `tails` where tails[i] = smallest tail of all
increasing subsequences of length i+1.

  `tails` is always sorted -> use binary search.
  - If nums[i] > tails.last: extend LIS by 1
  - Else: binary search for first tail >= nums[i], replace it
    (this maintains the invariant: smallest possible tail for that length)

  int lengthOfLIS(int[] nums) {
    int[] tails = new int[nums.length];
    int size = 0;
    for (int num : nums) {
      int lo = 0, hi = size;
      while (lo < hi) {
        int mid = (lo + hi) / 2;
        if (tails[mid] < num) lo = mid + 1;
        else hi = mid;
      }
      tails[lo] = num;   // replace or extend
      if (lo == size) size++;
    }
    return size;
  }

  Time: O(n log n)  Space: O(n)

  NOTE: `tails` array does NOT store the actual LIS!
  It only gives the correct LENGTH. To reconstruct the actual LIS,
  use the O(n^2) dp approach with parent pointers.

----------------------------------------------------------------
RELATED PROBLEMS
----------------------------------------------------------------
  Number of LIS (LC 673):
    Two arrays: len[i] = LIS length ending at i,
                cnt[i] = count of such LIS
    For each pair (j < i, nums[j] < nums[i]):
      if len[j]+1 > len[i]: len[i] = len[j]+1; cnt[i] = cnt[j]
      if len[j]+1 == len[i]: cnt[i] += cnt[j]

  Russian Doll Envelopes (LC 354):
    Sort by width ascending, height descending for equal widths.
    Then LIS on heights. O(n log n).
    Why descending height for equal width? To prevent using two
    envelopes with same width (LIS requires strictly increasing).

  Increasing Triplet Subsequence (LC 334):
    O(n) O(1): track first and second minimum.
    Return true when third element found > second.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. LIS is O(n^2) DP or O(n log n) with patience sorting
  2. The tails array is NOT the LIS itself -- common mistake!
     It only gives the correct length.
  3. Binary search: lower_bound (first position >= num)
     Use Arrays.binarySearch: if not found, returns -(insertion point)-1
  4. Russian Doll Envelopes: sort width asc + height desc is the key trick
  5. LIS in O(n log n) uses the same idea as patience sorting:
     place each card on the leftmost pile whose top card >= current
