================================================================
  EDIT DISTANCE (LEVENSHTEIN DISTANCE) (LC 72)
================================================================

----------------------------------------------------------------
PROBLEM
----------------------------------------------------------------
Minimum operations (insert, delete, replace) to transform word1 to word2.

  word1 = "horse", word2 = "ros"
  horse -> rorse (replace h with r)
  rorse -> rose  (delete r)
  rose  -> ros   (delete e)
  Edit distance = 3

----------------------------------------------------------------
DP FORMULATION
----------------------------------------------------------------
  State: dp[i][j] = min edit distance between word1[0..i-1] and word2[0..j-1]
  Transition:
    If word1[i-1] == word2[j-1]: dp[i][j] = dp[i-1][j-1]  (no op needed)
    Else:
      dp[i][j] = 1 + min(
        dp[i-1][j],     // delete from word1 (or insert into word2)
        dp[i][j-1],     // insert into word1 (or delete from word2)
        dp[i-1][j-1]    // replace
      )
  Base:
    dp[0][j] = j  (insert j chars to build word2 from empty)
    dp[i][0] = i  (delete i chars to reach empty)

  int minDistance(String w1, String w2) {
    int m = w1.length(), n = w2.length();
    int[][] dp = new int[m+1][n+1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    for (int i = 1; i <= m; i++)
      for (int j = 1; j <= n; j++)
        if (w1.charAt(i-1) == w2.charAt(j-1))
          dp[i][j] = dp[i-1][j-1];
        else
          dp[i][j] = 1 + Math.min(dp[i-1][j-1], Math.min(dp[i-1][j], dp[i][j-1]));
    return dp[m][n];
  }

  Time: O(mn)  Space: O(mn) -> reducible to O(n) with rolling row

----------------------------------------------------------------
VISUALIZATION ("horse" vs "ros")
----------------------------------------------------------------
        ""  r  o  s
  ""  [  0  1  2  3 ]
  h   [  1  1  2  3 ]
  o   [  2  2  1  2 ]
  r   [  3  2  2  2 ]
  s   [  4  3  3  2 ]
  e   [  5  4  4  3 ]  <- answer = 3

----------------------------------------------------------------
EDIT DISTANCE VARIANTS
----------------------------------------------------------------
  Delete Only (LC 583 -- Delete Operations for Two Strings):
    Only delete operations allowed.
    Min deletions = m + n - 2*LCS(w1, w2)

  One Edit Away:
    Return true if strings are at most 1 edit apart.
    Check: if length differs by > 1 -> false.
    Otherwise: find first mismatch, check if rest matches.
    O(n) O(1).

  Wildcard Matching (LC 44):
    '?' matches any single char, '*' matches any sequence.
    dp[i][j] = does pattern p[0..j-1] match s[0..i-1]?

  Regular Expression Matching (LC 10):
    '.' matches any char, '*' matches 0+ of preceding.
    More complex transitions for '*'.

----------------------------------------------------------------
INTERVIEW QUESTIONS
----------------------------------------------------------------

Q: What do the three operations in Edit Distance correspond
   to in the DP table?
A: dp[i-1][j] + 1 = DELETE from word1 (or INSERT into word2)
   moving from position (i-1, j) to (i, j) means we consumed
   one char from word1 without advancing in word2.
   dp[i][j-1] + 1 = INSERT into word1 (or DELETE from word2)
   dp[i-1][j-1] + 1 = REPLACE: we consumed one char from each
   and they don't match, so we replace.
   dp[i-1][j-1] + 0 = MATCH: chars equal, no cost.

----------------------------------------------------------------
INTERVIEW TIPS
----------------------------------------------------------------
  1. Base cases: dp[i][0]=i (delete i chars), dp[0][j]=j (insert j chars)
     -- very easy to forget the base case initialization
  2. Trace through a 2x2 example to verify transitions before coding
  3. Space: O(n) by keeping only previous row (or two rows)
  4. Edit distance is used in spell checkers, DNA sequencing, git diff
  5. Related: LCS = m + n - 2*LCS (deletion only edit distance)
