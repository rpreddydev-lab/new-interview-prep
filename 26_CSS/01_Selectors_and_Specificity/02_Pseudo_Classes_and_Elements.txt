1. PSEUDO-CLASS vs PSEUDO-ELEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pseudo-class (:) — Selects elements based on state or position in the document.
  No new element created. Single colon.
  :hover  :focus  :nth-child()  :first-child  etc.

Pseudo-element (::) — Selects and styles a PART of an element or inserts
  virtual content. Double colon (:: is CSS3; single : is legacy but supported).
  ::before  ::after  ::first-line  ::first-letter  etc.

2. INTERACTION / STATE PSEUDO-CLASSES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

:hover
  • Applies when the user's pointer is over the element
  • Does NOT apply on touch devices (no persistent hover state)
  a:hover { color: blue; text-decoration: underline; }

:focus
  • Applies when an element has keyboard or programmatic focus
  • Visible on form fields, buttons, links after Tab key
  input:focus { outline: 2px solid #0077cc; }

:focus-visible (CSS4)
  • Applies focus styles ONLY when focus is visible (keyboard navigation, not mouse click)
  • Solves the "remove focus ring for mouse users but keep it for keyboard users" problem
  button:focus-visible { outline: 2px solid blue; }
  button:focus:not(:focus-visible) { outline: none; }

:focus-within
  • Applies to a parent element when ANY descendant is focused
  • Great for styling form wrappers, dropdowns, search bars
  .form-group:focus-within label { color: blue; transform: translateY(-20px); }
  .dropdown:focus-within .menu { display: block; }

:active
  • Applies while the element is being pressed/clicked
  button:active { transform: scale(0.98); }

:visited
  • Applies to <a> links that the user has already visited
  • For privacy, only a limited set of CSS properties allowed:
    color, background-color, border-color, outline-color, fill, stroke
  a:visited { color: purple; }

:checked
  • Applies to <input type="checkbox">, <input type="radio">, <option>
  input[type="checkbox"]:checked + label { font-weight: bold; }

:disabled / :enabled
  • Applies to form elements that are disabled/enabled
  input:disabled { background: #f0f0f0; cursor: not-allowed; }

:required / :optional
  input:required { border-color: red; }
  input:optional { border-color: #ccc; }

:read-only / :read-write
  input:read-only { background: #eee; }
  input:read-write { background: white; }

:placeholder-shown
  • Applies when the placeholder text is visible (field is empty)
  input:placeholder-shown { border-color: #ccc; }

:valid / :invalid
  • Based on HTML5 validation
  input:invalid { border-color: red; }
  input:valid   { border-color: green; }

:in-range / :out-of-range
  • For <input type="number" min="1" max="10">
  input:out-of-range { color: red; }

:target
  • Applies to an element whose ID matches the URL hash (#section)
  :target { background: yellow; }
  /* When URL is page.html#about, #about element gets yellow bg */

:lang(code)
  :lang(en) { font-family: 'Georgia'; }
  :lang(ar) { direction: rtl; }

:empty
  • Applies to elements with no children (including text nodes)
  p:empty { display: none; }
  .placeholder:empty::before { content: "Nothing here yet"; color: grey; }

:not(selector)
  li:not(:last-child) { border-bottom: 1px solid; }

:is(selector-list) / :where(selector-list) — see Selectors file

3. STRUCTURAL PSEUDO-CLASSES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

:root
  • Selects the root element of the document (<html>)
  • Higher specificity than html selector (0,0,1,0 vs 0,0,0,1)
  • Ideal for declaring CSS variables
  :root { --color: blue; }

:first-child / :last-child / :only-child
  • :first-child → element IS the first child of its parent
  • :last-child  → element IS the last child of its parent
  • :only-child  → element is the only child of its parent

  li:first-child { border-top: none; }
  li:last-child  { border-bottom: none; }

:nth-child(n) — The most powerful structural pseudo-class:
  The formula: An+B (where n starts at 0)

  :nth-child(1)     → first child
  :nth-child(2)     → second child
  :nth-child(even)  → even children (2, 4, 6...)  equivalent to 2n
  :nth-child(odd)   → odd children  (1, 3, 5...)  equivalent to 2n+1
  :nth-child(3n)    → every 3rd child (3, 6, 9...)
  :nth-child(3n+1)  → 1st, 4th, 7th... (every 3rd, starting at 1)
  :nth-child(n+3)   → from 3rd onwards
  :nth-child(-n+3)  → first 3 only (3, 2, 1)
  :nth-child(2n+1)  → same as odd

  CSS4 :nth-child() with selector argument:
  :nth-child(2 of .highlighted) → every 2nd .highlighted child

  tr:nth-child(even) { background: #f5f5f5; }  /* zebra striping */
  li:nth-child(3n+1):nth-child(-n+9) { ... }   /* first 9, starting at 1 */

:nth-last-child(n)
  • Same as :nth-child but counting from the END
  :nth-last-child(1) → same as :last-child
  :nth-last-child(3) → 3rd from the end
  li:nth-last-child(n+4) { display: none; } /* show only last 3 */

:first-of-type / :last-of-type / :only-of-type
  • Like first/last-child, but scoped to the ELEMENT TYPE
  p:first-of-type { font-size: 1.2em; }
  /* First <p> among siblings, even if it's not the first child */

  img:only-of-type { display: block; margin: 0 auto; }

:nth-of-type(n) / :nth-last-of-type(n)
  • Like nth-child but counts only that type of element

  p:nth-of-type(2) { background: yellow; }
  /* 2nd <p> sibling, not counting other element types */

:root — see above

4. :nth-child vs :nth-of-type — CRITICAL DIFFERENCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HTML:
  <div>
    <span>Item 1</span>   <!-- child 1 -->
    <p>Para 1</p>         <!-- child 2 -->
    <p>Para 2</p>         <!-- child 3 -->
  </div>

  p:nth-child(2)     → "Para 1" (the 2nd child of parent, which IS a p)
  p:nth-child(1)     → nothing (1st child is a span, not a p)
  p:nth-of-type(1)   → "Para 1" (1st p among siblings, regardless of position)
  p:nth-of-type(2)   → "Para 2"

⚠ :nth-child counts ALL children; :nth-of-type counts only matching type.

5. PSEUDO-ELEMENTS — COMPLETE REFERENCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

::before and ::after — Generated content:
  • Creates a virtual element as the FIRST / LAST child
  • REQUIRES content property (can be empty string "")
  • Does NOT appear in DOM; not accessible to screen readers by default
  • Useful for: icons, decorative shapes, tooltips, clearfix, overlays

  .btn::before {
    content: "";
    display: block;
    width: 10px;
    height: 10px;
    background: red;
  }

  /* Tooltip */
  [data-tooltip]::after {
    content: attr(data-tooltip);  /* reads from HTML attribute */
    position: absolute;
    bottom: 100%;
    background: black;
    color: white;
    padding: 4px 8px;
    border-radius: 4px;
    white-space: nowrap;
  }

  /* Overlay effect */
  .hero {
    position: relative;
  }
  .hero::before {
    content: "";
    position: absolute;
    inset: 0;
    background: rgba(0,0,0,0.5);
  }

  /* Clearfix (legacy, Flexbox/Grid are preferred) */
  .clearfix::after {
    content: "";
    display: table;
    clear: both;
  }

  content property values:
    ""            → empty string (common)
    "text"        → literal text
    attr(name)    → value of HTML attribute
    url(img.png)  → image
    counter(name) → counter value
    open-quote / close-quote → quotation marks
    none          → no content (hides ::before/::after)

::first-line:
  • Styles the first rendered line of a block-level element
  • Only a subset of CSS properties work:
    font, color, background, word-spacing, letter-spacing, text-transform,
    text-decoration, line-height, clear, vertical-align (in some cases)

  p::first-line {
    font-weight: bold;
    text-transform: uppercase;
  }

::first-letter:
  • Styles the first letter (drop cap effect)
  • Also supports limited set of properties + float, width, height, margin, padding
  p::first-letter {
    float: left;
    font-size: 3em;
    line-height: 0.8;
    margin-right: 0.1em;
    color: darkred;
  }

::selection:
  • Styles the highlighted/selected text
  • Only a few properties work: color, background-color, cursor, caret-color,
    outline, text-decoration, text-emphasis-color, text-shadow
  ::selection {
    background: #ffeb3b;
    color: black;
  }

::placeholder:
  • Styles placeholder text in <input> and <textarea>
  input::placeholder {
    color: #999;
    font-style: italic;
  }

::marker:
  • Styles the marker/bullet/number of a list item
  li::marker {
    color: red;
    font-size: 1.2em;
    content: "▶ ";   /* custom marker */
  }

::backdrop:
  • Styles the background behind a fullscreen element or <dialog>
  dialog::backdrop {
    background: rgba(0,0,0,0.7);
  }

::spelling-error / ::grammar-error:
  • Style browser-identified spelling/grammar errors (limited support)

6. PRACTICAL PATTERNS WITH PSEUDO-ELEMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pattern 1 — Decorative line/divider:
  h2 {
    position: relative;
    padding-bottom: 12px;
  }
  h2::after {
    content: "";
    position: absolute;
    bottom: 0;
    left: 0;
    width: 60px;
    height: 3px;
    background: blue;
  }

Pattern 2 — Badge/notification dot:
  .avatar {
    position: relative;
  }
  .avatar.online::after {
    content: "";
    position: absolute;
    bottom: 2px;
    right: 2px;
    width: 10px;
    height: 10px;
    background: green;
    border-radius: 50%;
    border: 2px solid white;
  }

Pattern 3 — Custom checkbox:
  input[type="checkbox"] { display: none; }
  label::before {
    content: "";
    display: inline-block;
    width: 16px;
    height: 16px;
    border: 2px solid #333;
    border-radius: 3px;
    margin-right: 8px;
    vertical-align: middle;
  }
  input[type="checkbox"]:checked + label::before {
    background: blue;
    border-color: blue;
    content: "✓";
    color: white;
    text-align: center;
  }

7. KEY INTERVIEW QUESTIONS — PSEUDO-CLASSES/ELEMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What is the difference between :pseudo-class and ::pseudo-element?
A: Pseudo-classes (single colon) select elements in a particular STATE or
   POSITION (e.g., :hover, :nth-child). Pseudo-elements (double colon) select
   a PART of an element or insert virtual content (::before, ::after, ::first-line).

Q: What is required for ::before and ::after to work?
A: The content property must be present (even if empty string ""). These elements
   are inline by default; set display: block or position: absolute for layout use.
   They don't appear in the DOM — not accessible to screen readers.

Q: What is the difference between :nth-child and :nth-of-type?
A: :nth-child(n) counts ALL sibling children.
   :nth-of-type(n) counts only siblings of the SAME element type.
   p:nth-child(2) selects <p> only if it IS the 2nd child (any type counts).
   p:nth-of-type(2) selects the 2nd <p> sibling regardless of other element types.

Q: What does :focus-visible do?
A: It applies focus styles only when the focus was initiated by keyboard or
   accessibility means (not by mouse click). This allows showing a visible focus
   ring for keyboard users while hiding it for mouse users — improving both
   aesthetics and accessibility.

Q: How can you style every 3rd list item using CSS?
A: li:nth-child(3n) { ... }   → selects 3rd, 6th, 9th...
   li:nth-child(3n+1) { ... } → selects 1st, 4th, 7th...

Q: What is :focus-within?
A: :focus-within matches an element if IT or any of its DESCENDANTS has focus.
   Useful for styling form wrappers, floating labels, dropdowns when a child
   inside them receives focus.

Q: Can ::before/::after be used with <img>, <input>, <br>?
A: No. Replaced elements (img, input, select, textarea, br, hr, video, iframe)
   cannot have ::before/::after pseudo-elements because they have no content area.
