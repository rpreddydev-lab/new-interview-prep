SECTION 1 — FLEXBOX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: What are the main axis and cross axis in Flexbox?
A:  Main axis — the primary axis along which items flow. Set by flex-direction.
    flex-direction: row → main axis = horizontal (left to right)
    flex-direction: column → main axis = vertical (top to bottom)
    Cross axis — always perpendicular to the main axis.
    justify-content aligns on the MAIN axis.
    align-items aligns on the CROSS axis.

Q2: What is the difference between justify-content and align-items?
A:  justify-content — distributes space along the MAIN axis (between items)
    align-items     — aligns items on the CROSS axis (all items)
    align-self      — overrides align-items for a SINGLE item
    align-content   — aligns ROWS (only when flex-wrap creates multiple lines)

Q3: What is flex:1 and what does it mean?
A:  flex:1 is shorthand for: flex-grow:1; flex-shrink:1; flex-basis:0%
    It means: grow equally to fill available space, shrink if needed, start
    from zero basis. Used to make flex items share available space equally.
    Compare:
    flex: 1       → grow:1, shrink:1, basis:0 (equal sized, from zero)
    flex: auto    → grow:1, shrink:1, basis:auto (equal sized, from content)
    flex: none    → grow:0, shrink:0, basis:auto (don't flex)
    flex: 0 0 200px → fixed 200px, no grow/shrink

Q4: What is the difference between flex-basis and width?
A:  flex-basis sets the initial size of a flex item on the main axis BEFORE
    flex-grow/shrink is applied. On a row container, it acts like width.
    On a column container, it acts like height.
    If both flex-basis and width are set, flex-basis takes priority (unless
    flex-basis is auto, in which case width is used).

Q5: What does flex-grow and flex-shrink do?
A:  flex-grow controls how much a flex item GROWS to fill extra space.
    A value of 2 grows twice as fast as a value of 1.
    flex-shrink controls how much a flex item SHRINKS when there's too little space.
    A value of 2 shrinks twice as fast. flex-shrink:0 prevents shrinking at all.

Q6: How does auto margin work in Flexbox?
A:  In a flex container, margin:auto consumes all available free space in that
    direction. It pushes items as far as possible.
    .item { margin-left: auto; } → pushes the item (and everything after it)
    to the right end of the row — great for "push-to-end" nav patterns.
    .item { margin: auto; } → centers an item within available space.

Q7: What is the difference between align-items and align-content?
A:  align-items — aligns items within each FLEX LINE (row or column)
    align-content — aligns the flex LINES themselves within the container
    align-content only has an effect when there are multiple lines
    (flex-wrap:wrap is in effect).

Q8: What is the order property in Flexbox?
A:  order changes the visual rendering order of flex items without changing
    DOM order. Default: order:0 for all items. Higher = renders later.
    ⚠️ Accessibility warning: order changes visual order but screen readers
    follow DOM order. Use with care to avoid confusing keyboard navigation.

Q9: How do you create equal-height columns with Flexbox?
A:  By default, flex items on the same row stretch to match the tallest item:
    .container { display: flex; } /* align-items: stretch is the default */
    All items will be equal height to the tallest one. No extra CSS needed.

Q10: How do you create a responsive card grid with Flexbox (no media queries)?
A:  .cards {
      display: flex;
      flex-wrap: wrap;
      gap: 16px;
    }
    .cards > * {
      flex: 1 1 250px;  /* grow, shrink, min-width 250px */
    }
    Cards wrap and grow to fill rows. No media queries needed.

SECTION 2 — CSS GRID
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q11: What is the fr unit in CSS Grid?
A:   fr (fraction unit) represents a fraction of the available free space in
     the grid container. 1fr 1fr 1fr = 3 equal columns sharing all space.
     1fr 2fr = two columns where second is twice as wide as first.
     fr is calculated AFTER non-flexible sizes (px, %, auto) are reserved.
     1fr 200px → the 200px column is fixed; 1fr takes remaining space.

Q12: What is the difference between auto-fill and auto-fit?
A:   Both fill the row with as many columns as will fit given a min-width.
     repeat(auto-fill, minmax(200px, 1fr)): Creates as many columns as possible,
     even if some are empty. Empty columns still take space.
     repeat(auto-fit, minmax(200px, 1fr)): Collapses empty columns to zero width.
     Filled items grow to take all available space.
     → Use auto-fit when you want items to fill the full row width.
     → Use auto-fill when you want a fixed grid regardless of item count.

Q13: What is the difference between explicit and implicit grid?
A:   Explicit grid: defined by grid-template-columns and grid-template-rows.
     Implicit grid: created automatically when items are placed outside the
     explicit grid boundaries. Controlled by grid-auto-rows / grid-auto-columns.
     .grid { grid-auto-rows: 200px; } → implicit rows are 200px tall.

Q14: How do you place an item in a specific grid cell?
A:   Using line numbers: grid-column: 2 / 4 (from line 2 to line 4)
     Shorthand: grid-area: row-start / col-start / row-end / col-end
     Spanning: grid-column: span 2 (span 2 columns from auto placement)
     Named areas: grid-area: header (references a grid-template-areas name)
     Negative lines: grid-column: 1 / -1 (spans full width regardless of count)

Q15: What is grid-template-areas?
A:   A visual text map of the grid layout using named areas:
     grid-template-areas:
       "header header"
       "sidebar main"
       "footer footer";
     Items placed with grid-area: header/sidebar/main/footer.
     Rules: Areas must be rectangles. Use "." for empty cells.
     Auto-generates named lines: header-start, header-end, etc.

SECTION 3 — FLEXBOX VS GRID
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q16: What is the main difference between Flexbox and Grid?
A:   Flexbox = 1D: controls one axis at a time (row OR column).
     Grid = 2D: controls rows AND columns simultaneously.
     Flexbox is content-first (items drive the layout).
     Grid is layout-first (you define the structure, items fill it).

Q17: When would you use Flexbox vs Grid?
A:   Flexbox: navbars, button groups, card internals, single-row/column layouts,
              centering one element, any place with unknown/dynamic item count.
     Grid: page layouts, card grids (row alignment matters), any case where
           items must align on both axes, magazine/dashboard layouts,
           items spanning multiple rows or columns.
     Both are often used together: Grid for macro layout, Flex inside components.

Q18: Can an element be both a flex container and a grid container?
A:   No — display:flex and display:grid cannot both apply. However, an element
     can be a FLEX ITEM (child of flex parent) AND a GRID CONTAINER at the
     same time. Its children would be arranged by Grid, while it participates
     in its parent's Flex layout.

Q19: How do you center an element both horizontally and vertically?
A:   Method 1 (Flexbox):
     parent: display:flex; justify-content:center; align-items:center;

     Method 2 (Grid):
     parent: display:grid; place-items:center;

     Method 3 (Absolute + transform):
     child: position:absolute; top:50%; left:50%; transform:translate(-50%,-50%);

     Method 4 (Absolute + inset + auto margin):
     child: position:absolute; inset:0; margin:auto; width:200px; height:200px;

Q20: How does gap work? Is it the same as margin?
A:   gap (previously grid-gap) adds space BETWEEN items in a flex or grid
     container. It only adds space between items, not outside them.
     Unlike margin, gap doesn't affect the outer edges of the container.
     row-gap sets vertical space between rows.
     column-gap sets horizontal space between columns.
     gap: 16px → both row and column gap = 16px.
     gap: 8px 16px → row gap 8px, column gap 16px.
