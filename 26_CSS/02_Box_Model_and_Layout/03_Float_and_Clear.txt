1. WHAT IS FLOAT?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

float was originally designed for text wrapping around images (like print layout).
It was then overloaded to create multi-column layouts before flexbox/grid existed.

Today: Use flexbox or grid for layout. Use float only for its original purpose —
text wrapping around images.

  float: left;    /* element floats to the left; text flows around its right */
  float: right;   /* element floats to the right; text flows around its left */
  float: none;    /* default */
  float: inline-start; /* logical — left in LTR, right in RTL */
  float: inline-end;

When an element is floated:
  • It's removed from normal flow PARTIALLY — still affects line boxes
  • Block formatting context (BFC) is created for the floated element
  • The floated element shifts to left/right of container
  • Following INLINE content (text, inline elements) wraps around it
  • Following BLOCK elements may slide under the float

2. FLOAT FOR TEXT WRAPPING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  <article>
    <img class="float-left" src="photo.jpg" alt="...">
    <p>This text wraps around the floated image. The text continues flowing
    alongside the image until it passes the bottom of the image...</p>
  </article>

  .float-left {
    float: left;
    margin: 0 16px 16px 0;  /* space between image and text */
    width: 200px;
  }

With shape-outside for non-rectangular wrapping:
  .float-left {
    float: left;
    shape-outside: circle(50%);     /* text wraps in circular shape */
    width: 200px;
    height: 200px;
    border-radius: 50%;
  }

  shape-outside values:
    circle(), ellipse(), polygon(), inset(), url(image.png), margin-box, etc.

3. THE FLOAT COLLAPSE PROBLEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If all children are floated, the parent collapses to zero height:

  <div class="container">          ← height = 0px (collapsed!)
    <div class="float-col">...</div>  ← floated
    <div class="float-col">...</div>  ← floated
  </div>

  .container { background: red; }  /* background disappears! */
  .float-col  { float: left; width: 50%; }

4. THE CLEAR PROPERTY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

clear prevents an element from floating next to a floating element above it:

  clear: left;   /* clears left floats (element goes below any left floats) */
  clear: right;  /* clears right floats */
  clear: both;   /* clears both left and right floats */
  clear: none;   /* default */

  .footer {
    clear: both;   /* starts below all floated siblings */
  }

5. CLEARFIX — SOLVING FLOAT COLLAPSE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Multiple techniques to fix float collapse — listed in historical order:

Method 1 — Empty div (legacy, bad practice):
  <div class="container">
    <div class="floated">...</div>
    <div style="clear: both;"></div>   ← non-semantic hack
  </div>

Method 2 — overflow: hidden (creates BFC):
  .container { overflow: hidden; }
  /* BFC contains floats. Side effect: clips overflow content */

Method 3 — The Clearfix Hack (CSS only, most popular historically):
  /* Micro clearfix */
  .clearfix::after {
    content: "";
    display: table;   /* or display: block; */
    clear: both;
  }

  /* Full clearfix (including IE) */
  .clearfix::before,
  .clearfix::after {
    content: "";
    display: table;
  }
  .clearfix::after {
    clear: both;
  }
  .clearfix { *zoom: 1; }  /* IE6/7 */

Method 4 — display: flow-root (MODERN, preferred):
  .container { display: flow-root; }
  /* Cleanly creates BFC; no clipping, no pseudo-elements needed */

Method 5 — display: flex or grid (MODERN):
  .container { display: flex; }
  /* Flex containers automatically contain floated children */

6. FLOAT LAYOUT (LEGACY — for understanding old codebases)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  /* Two-column layout using float */
  .container { overflow: hidden; }
  .main    { float: left; width: 70%; }
  .sidebar { float: right; width: 28%; }

  /* Three-column layout */
  .col { float: left; width: 33.333%; padding: 0 1rem; }

  /* Grid-like layout */
  .grid-item {
    float: left;
    width: calc(33.333% - 20px);
    margin: 10px;
  }

  Issues with float layout:
  • No natural vertical alignment
  • Complex responsive design
  • Float collapse issues
  • Browser inconsistencies
  → All solved by Flexbox and Grid

7. FLOAT AND BFC INTERACTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BFC elements do NOT overlap floats:

  <div class="float-left">Floated</div>
  <div class="bfc-element">I don't overlap the float</div>

  .float-left { float: left; width: 200px; height: 200px; }
  .bfc-element { overflow: hidden; }  /* creates BFC → won't overlap float */

  This is used to create a two-column layout where text doesn't wrap:
  .sidebar { float: left; width: 200px; }
  .content  { overflow: hidden; /* or display: flow-root */ }

8. KEY INTERVIEW QUESTIONS — FLOAT AND CLEAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What is float and when should you use it today?
A: float originally wraps text around elements (like print media). It was
   commonly misused for multi-column layouts before flexbox/grid.
   Today use float only for wrapping text around images. For all layout purposes,
   use flexbox (1D) or grid (2D) instead.

Q: What is the float collapse problem and how do you fix it?
A: When all children are floated, the parent collapses to zero height because
   floated elements are (partially) removed from normal flow. Solutions:
   (1) clearfix ::after pseudo-element with content:"" display:table clear:both
   (2) overflow: hidden on parent (creates BFC)
   (3) display: flow-root on parent (modern, preferred — no side effects)
   (4) Use flexbox/grid instead (problem doesn't occur)

Q: What is the clearfix hack?
A: A CSS technique that inserts an empty element after floated children using
   ::after pseudo-element with clear:both, forcing the parent to expand and
   contain the floats. Modern equivalent: display: flow-root on the container.

Q: What is the difference between clear:left, clear:right, and clear:both?
A: clear:left → element moves below left floats
   clear:right → element moves below right floats
   clear:both  → element moves below ALL floats (most commonly used)

Q: What does shape-outside do with floats?
A: shape-outside lets you define a non-rectangular shape that inline content
   wraps around. It only works on floated elements.
   shape-outside: circle(50%) → text wraps in a circular path around the floated element.
