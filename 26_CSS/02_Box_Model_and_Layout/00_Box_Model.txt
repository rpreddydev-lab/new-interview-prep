1. WHAT IS THE BOX MODEL?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Every HTML element is represented as a rectangular box. The CSS box model
describes how this box is structured with four areas (from inside out):

  ┌───────────────────────────────────────────────────┐
  │                    MARGIN                         │
  │   ┌───────────────────────────────────────────┐   │
  │   │                  BORDER                   │   │
  │   │   ┌───────────────────────────────────┐   │   │
  │   │   │              PADDING              │   │   │
  │   │   │   ┌───────────────────────────┐   │   │   │
  │   │   │   │         CONTENT           │   │   │   │
  │   │   │   │   width × height          │   │   │   │
  │   │   │   └───────────────────────────┘   │   │   │
  │   │   └───────────────────────────────────┘   │   │
  │   └───────────────────────────────────────────┘   │
  └───────────────────────────────────────────────────┘

Content area   → Where text, images, etc. render
Padding        → Space between content and border (background color shows)
Border         → Surrounds padding and content
Margin         → Space outside the border (transparent — shows parent background)

2. box-sizing: content-box vs border-box
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

box-sizing: content-box (DEFAULT — the old/confusing model):
  The declared width/height applies to the CONTENT AREA ONLY.
  Total rendered width = declared width + left padding + right padding
                       + left border + right border

  Example:
    .box {
      width: 300px;
      padding: 20px;
      border: 2px solid;
    }
    /* Total rendered width = 300 + 20 + 20 + 2 + 2 = 344px */

box-sizing: border-box (RECOMMENDED — modern standard):
  The declared width/height INCLUDES padding and border.
  Content area shrinks to accommodate padding and border.
  Total rendered width = declared width (always)

  Example:
    .box {
      box-sizing: border-box;
      width: 300px;
      padding: 20px;
      border: 2px solid;
    }
    /* Total rendered width = 300px (content = 300 - 20 - 20 - 2 - 2 = 256px) */

Best practice — apply to everything:
  *, *::before, *::after {
    box-sizing: border-box;
  }
  /* This is now standard in most projects/frameworks */

3. MARGIN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  margin: top right bottom left;          /* 4 values */
  margin: top-bottom left-right;          /* 2 values */
  margin: all;                            /* 1 value */
  margin: top left-right bottom;          /* 3 values */

  margin-top: 16px;
  margin-right: auto;
  margin-bottom: 16px;
  margin-left: auto;

  margin: 0 auto;  /* centers block elements horizontally */

Logical properties (writing-mode aware):
  margin-block: 16px;     /* top & bottom */
  margin-inline: auto;    /* left & right */
  margin-block-start:     /* top in LTR */
  margin-block-end:       /* bottom in LTR */
  margin-inline-start:    /* left in LTR */
  margin-inline-end:      /* right in LTR */

Negative margins:
  • Pulls element toward the direction (overlapping)
  • margin-top: -20px pulls element UP (overlaps element above)
  • Useful for design effects, but use carefully
  margin-top: -1px;   /* remove double border in adjacent bordered elements */

4. MARGIN COLLAPSING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Vertical margins (top/bottom) between block-level elements COLLAPSE into a single
margin equal to the LARGER of the two. This ONLY applies vertically.

Case 1 — Adjacent siblings:
  .box1 { margin-bottom: 30px; }
  .box2 { margin-top: 20px; }
  /* Actual gap = 30px (not 50px) — the larger value wins */

Case 2 — Parent and first/last child:
  .parent { margin-top: 20px; }
  .child  { margin-top: 40px; }
  /* Both collapse — the 40px pushes the parent too (unless parent has border/padding/overflow) */

Case 3 — Empty element:
  .empty { margin-top: 20px; margin-bottom: 30px; }
  /* Top and bottom collapse to 30px (larger) */

How to PREVENT margin collapsing (any of these on the parent):
  • Add padding-top: 1px (or any non-zero padding)
  • Add border-top: 1px solid transparent
  • Add overflow: hidden / auto / scroll
  • Display as flex or grid (children in flex/grid don't collapse margins)
  • Add display: flow-root (creates a BFC)

⚠ Horizontal margins NEVER collapse.

5. PADDING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  padding: 10px 20px;         /* top/bottom left/right */
  padding: 10px;              /* all sides */
  padding-top: 16px;
  padding-right: 24px;
  padding-bottom: 16px;
  padding-left: 24px;

  Logical properties:
  padding-block: 16px;
  padding-inline: 24px;

  • Padding is INSIDE the border
  • Background color/image extends through padding area
  • Cannot be negative
  • % values calculated relative to parent's WIDTH (even for top/bottom)

6. BORDER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  border: width style color;
  border: 2px solid #333;
  border: 1px dashed rgba(0,0,0,0.2);

  border-width: 2px;
  border-style: solid | dashed | dotted | double | groove | ridge |
                inset | outset | none | hidden;
  border-color: #333;

  Individual sides:
  border-top: 2px solid red;
  border-right: 0;
  border-bottom: 3px dashed blue;
  border-left: none;

  Logical properties:
  border-block:  2px solid;    /* top and bottom */
  border-inline: 1px solid;    /* left and right */

  border-radius (see CSS3 Features file for detail):
  border-radius: 8px;
  border-radius: 50%;    /* circle */

  outline vs border:
  outline — does NOT affect box model (no space taken)
           → used for focus indicators; never use outline: none without replacement
  border  — IS part of box model (takes space)

  outline: 2px solid blue;
  outline-offset: 4px;    /* space between element edge and outline */

7. WIDTH AND HEIGHT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  width: 300px | 50% | auto | fit-content | min-content | max-content;
  height: 200px | 50vh | auto;

  min-width / max-width:
  min-width: 200px;    /* never shrinks below 200px */
  max-width: 1200px;   /* never grows past 1200px */

  min-height / max-height:
  min-height: 100vh;   /* at least full viewport height */
  max-height: 500px;   /* content scrolls if taller */

  width: auto (default for block):
    Block elements stretch to fill container width
    Inline elements shrink to content width

  width: 100% vs width: auto:
    100% → explicit 100% of parent width (adds to padding/border in content-box)
    auto → fills available space; respects margin (doesn't overflow)

  Intrinsic sizing values:
  width: min-content   → shrinks to minimum non-breaking content size
  width: max-content   → expands to maximum content size (no wrapping)
  width: fit-content   → like max-content but capped at available space
  width: fit-content(300px) → at most 300px, or content width if smaller

8. BLOCK FORMATTING CONTEXT (BFC)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A Block Formatting Context (BFC) is an independent layout region where:
  • Child margins don't collapse with outside
  • Contains floated children (clearfix alternative)
  • Does not overlap floats from siblings

What creates a BFC:
  • overflow: hidden | auto | scroll (NOT visible/clip)
  • display: flow-root       ← modern, preferred way (no side effects)
  • display: flex or grid
  • display: inline-block
  • position: absolute or fixed
  • float: left | right (the floated element itself)
  • contain: layout | content | paint
  • column-count or column-width (not auto)

Best practice to create BFC without side effects:
  .container { display: flow-root; }

9. KEY INTERVIEW QUESTIONS — BOX MODEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What is the CSS box model?
A: Every element is a rectangular box composed of 4 areas (inside out):
   content (text/images), padding (space inside border), border (line around element),
   and margin (space outside border). The box model determines how the element's
   total size is calculated.

Q: What is the difference between box-sizing: content-box and border-box?
A: content-box (default): width/height apply to content only; total size =
   content + padding + border.
   border-box: width/height include padding and border; content shrinks to fit.
   border-box is preferred because you can set width: 300px and know the element
   will always be 300px wide, regardless of padding/border.

Q: What is margin collapsing?
A: When two vertical block margins meet, they collapse into a single margin equal
   to the LARGER of the two (not the sum). This happens between adjacent siblings
   and between parent and first/last child. Horizontal margins never collapse.
   Prevent it with: padding on parent, overflow: hidden, or display: flex/grid.

Q: What is the difference between margin and padding?
A: Padding is INSIDE the border — it's part of the element's clickable/visible area.
   Background color/image extends into padding.
   Margin is OUTSIDE the border — it creates space between elements. It's
   transparent and cannot have a background.

Q: What is a Block Formatting Context (BFC)?
A: A BFC is an isolated layout environment. It prevents margin collapsing between
   parent and children, contains floated elements (without needing clearfix), and
   doesn't overlap sibling floats. Created by overflow: hidden, display: flow-root,
   flex/grid containers, and several other properties.

Q: What is the difference between outline and border?
A: border is part of the box model — it takes up space and affects layout.
   outline is drawn OUTSIDE the border but does NOT take up space — it doesn't
   affect layout. outline is used for focus indicators (keyboard accessibility).
   outline-offset controls the gap between the element and the outline.

Q: How do percentage padding/margin values work?
A: Both percentage margin AND percentage padding are always calculated relative to
   the parent element's WIDTH (even for top/bottom). This enables the aspect ratio
   hack: padding-top: 56.25% = 16:9 ratio box (9/16 = 0.5625 = 56.25%).
