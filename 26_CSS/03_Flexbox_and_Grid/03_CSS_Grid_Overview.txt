1. WHAT IS CSS GRID?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CSS Grid Layout is a TWO-DIMENSIONAL layout system. It handles both rows AND
columns simultaneously, making it ideal for complex page layouts.

Terminology:
  Grid container  → element with display: grid or inline-grid
  Grid items      → DIRECT children of the grid container
  Grid line       → dividing lines forming the grid structure (numbered 1+)
  Grid track      → space between two grid lines (a row or column)
  Grid cell       → intersection of one row track and one column track
  Grid area       → rectangular space made up of one or more grid cells

  display: grid;         /* block-level grid container */
  display: inline-grid;  /* inline-level grid container */

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. DEFINING TRACKS — grid-template-columns and grid-template-rows
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  grid-template-columns: 200px 1fr 1fr;
  /* 3 columns: first is 200px, other two share remaining space equally */

  grid-template-columns: repeat(3, 1fr);
  /* 3 equal columns */

  grid-template-columns: repeat(3, 1fr 2fr);
  /* 6 columns: alternating 1fr 2fr */

  grid-template-rows: auto;
  grid-template-rows: 100px 1fr auto;

  fr unit (fraction):
  The fr unit represents a fraction of the available space in the grid container.
  grid-template-columns: 1fr 2fr 1fr;
  /* Total: 4 parts. col1=25%, col2=50%, col3=25% */

  Auto track sizing:
  grid-template-columns: auto 1fr auto;
  /* auto = shrinks to content width */

  min-content / max-content:
  grid-template-columns: min-content 1fr max-content;

  minmax():
  grid-template-columns: minmax(200px, 1fr) 1fr;
  /* First column: minimum 200px, maximum 1fr */

  repeat() with named counts:
  grid-template-columns: repeat(12, 1fr);  /* 12-column grid */

  auto-fill vs auto-fit (responsive columns without media queries):
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  /* As many 250px+ columns as fit; leftover space remains as empty columns */

  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  /* As many 250px+ columns as fit; empty tracks collapse (items stretch) */

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. auto-fill vs auto-fit
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  auto-fill: creates as many tracks as fit; empty tracks remain (take up space)
  auto-fit:  creates as many tracks as fit; empty tracks COLLAPSE to 0

  With few items on a wide screen:
  auto-fill: [item1] [item2] [    ] [    ]  (empty columns take space)
  auto-fit:  [item1           ] [item2           ]  (items stretch to fill)

  Most common for responsive cards: auto-fit (items stretch to fill the row)
  Use auto-fill when you want to maintain consistent column widths even with few items

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. PLACING ITEMS — EXPLICIT PLACEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Grid lines are numbered starting from 1 (or -1 from the end):

  .item {
    grid-column-start: 1;
    grid-column-end: 3;     /* spans from line 1 to line 3 (2 columns) */
    grid-row-start: 1;
    grid-row-end: 2;
  }

  Shorthand:
  grid-column: 1 / 3;       /* start / end */
  grid-row: 1 / 2;
  grid-column: 1 / -1;      /* span full width (-1 = last line) */

  span keyword:
  grid-column: 2 / span 3;  /* start at line 2, span 3 tracks */
  grid-column: span 2;       /* span 2 columns from auto position */
  grid-row: span 2;          /* span 2 rows */

  grid-area shorthand:
  grid-area: row-start / col-start / row-end / col-end;
  grid-area: 1 / 2 / 3 / 4;

5. GAP / GUTTERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  gap: 16px;            /* equal gap for rows and columns */
  gap: 24px 16px;       /* row-gap 24px, column-gap 16px */
  row-gap: 24px;
  column-gap: 16px;

6. ALIGNMENT IN GRID
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Grid has both ROW and COLUMN alignment, and uses both justify and align.

Container properties:
  justify-items:   start | end | center | stretch  (aligns items in column axis)
  align-items:     start | end | center | stretch  (aligns items in row axis)
  place-items:     <align-items> <justify-items>   (shorthand)
  justify-content: start | end | center | space-between | space-around | space-evenly
                   (aligns the whole grid in the container - column axis)
  align-content:   same values (aligns the whole grid - row axis)
  place-content:   shorthand

Item properties (override container):
  justify-self:   start | end | center | stretch
  align-self:     start | end | center | stretch
  place-self:     shorthand

  /* Perfect centering */
  .grid-center {
    display: grid;
    place-items: center;
  }

  /* Stretch to fill cell (default): */
  .grid { display: grid; }
  /* items are stretched to fill their cell by default */

7. IMPLICIT vs EXPLICIT GRID
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Explicit grid: tracks you define with grid-template-columns/rows
Implicit grid: tracks created automatically when items overflow the explicit grid

  .grid {
    grid-template-columns: repeat(3, 1fr);  /* 3 explicit columns */
    /* More than 3 items → new rows created implicitly */
  }

Controlling implicit tracks:
  grid-auto-rows: 200px;        /* implicit rows = 200px */
  grid-auto-rows: minmax(100px, auto); /* min 100px, grow with content */
  grid-auto-columns: 1fr;       /* implicit columns = 1fr */
  grid-auto-flow: row;          /* default: fill row by row */
  grid-auto-flow: column;       /* fill column by column */
  grid-auto-flow: row dense;    /* fill row by row, fill holes when possible */

8. PRACTICAL GRID PATTERNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pattern 1 — Basic 3-column grid:
  .container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
  }

Pattern 2 — Responsive card grid (NO media queries needed):
  .cards {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 24px;
  }

Pattern 3 — Full page layout (header, sidebar, main, footer):
  .page {
    display: grid;
    grid-template-columns: 240px 1fr;
    grid-template-rows: 60px 1fr 50px;
    min-height: 100vh;
  }
  .header  { grid-column: 1 / -1; }  /* spans all columns */
  .sidebar { grid-row: 2; }
  .main    { grid-row: 2; }
  .footer  { grid-column: 1 / -1; }  /* spans all columns */

Pattern 4 — Magazine/editorial grid:
  .magazine {
    display: grid;
    grid-template-columns: repeat(6, 1fr);
    grid-auto-rows: 200px;
    gap: 8px;
  }
  .feature    { grid-column: span 4; grid-row: span 2; }
  .secondary  { grid-column: span 2; }
  .tertiary   { grid-column: span 2; grid-row: span 2; }

Pattern 5 — Centered content with sidebar:
  .layout {
    display: grid;
    grid-template-columns: 1fr min(65ch, 100%) 1fr;
  }
  .content { grid-column: 2; }          /* max-width 65ch, centered */
  .full-bleed { grid-column: 1 / -1; }  /* break out to full width */

9. KEY INTERVIEW QUESTIONS — CSS GRID
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What is the fr unit in CSS Grid?
A: fr stands for "fraction." It represents a fraction of the available free space
   in the grid container after fixed/auto sizes are accounted for.
   grid-template-columns: 1fr 2fr → col1 gets 1/3 of space, col2 gets 2/3.
   It's like flex-grow but for grid tracks.

Q: What is the difference between auto-fill and auto-fit?
A: Both create as many tracks as fit the container. The difference shows when
   there are fewer items than tracks:
   auto-fill: empty tracks remain and take space (grid columns don't stretch)
   auto-fit: empty tracks collapse to 0 (items expand to fill available space)
   For responsive card layouts: auto-fit is usually preferred.

Q: What is the difference between grid-template-* and grid-auto-*?
A: grid-template-columns/rows defines the EXPLICIT grid — tracks you intentionally create.
   grid-auto-columns/rows defines the size of IMPLICIT tracks — auto-created when items
   overflow the explicit grid. grid-auto-flow controls whether implicit tracks are rows or columns.

Q: What does the span keyword do?
A: span tells a grid item how many tracks to span.
   grid-column: span 3 → item takes 3 column tracks from its auto position.
   grid-column: 2 / span 3 → starts at line 2, spans 3 columns (ends at line 5).

Q: How do you create a responsive grid without media queries?
A: grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
   This creates as many columns as fit at minimum 250px width. At smaller viewports,
   columns wrap automatically. Completely responsive without any breakpoints.

Q: What is the dense keyword in grid-auto-flow?
A: grid-auto-flow: row dense (or column dense) tells the browser to fill in gaps
   in the grid that might be left by spanning items. Items may appear out of DOM
   order to fill holes. Useful for masonry-like layouts.
