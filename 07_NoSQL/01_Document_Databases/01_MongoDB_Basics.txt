================================================================
CORE TERMINOLOGY
================================================================

  SQL Term        MongoDB Term
  -----------     ----------------
  Database        Database
  Table           Collection
  Row             Document
  Column          Field
  Primary Key     _id (auto-generated ObjectId or custom)
  Index           Index
  JOIN            $lookup (aggregation), embedded documents
  Transaction     Session + startTransaction()

================================================================
_id FIELD
================================================================

  Every document must have an _id field.
  MongoDB auto-generates a 12-byte ObjectId if not provided.

  ObjectId structure:
  4 bytes  timestamp (seconds since epoch)
  5 bytes  random (machine + process)
  3 bytes  incrementing counter

  {
      "_id": ObjectId("64a1b2c3d4e5f6a7b8c9d0e1"),
      ...
  }

  ObjectIds are sortable by creation time:
  new ObjectId("64a1b2c3...").getTimestamp() --> Date

================================================================
CONNECTING TO MONGODB (JAVA / SPRING)
================================================================

  <!-- Maven dependency -->
  <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-data-mongodb</artifactId>
  </dependency>

  # application.properties
  spring.data.mongodb.uri=mongodb://localhost:27017/mydb
  spring.data.mongodb.database=mydb

================================================================
DOCUMENT MAPPING (SPRING DATA MONGODB)
================================================================

  @Document(collection = "products")
  public class Product {

      @Id
      private String id;                       // maps to _id

      @Field("product_name")
      private String name;

      private BigDecimal price;
      private String category;
      private List<String> tags;
      private Address address;                 // embedded document

      // getters, setters
  }

  @Document annotation is not required if collection name matches class name.

================================================================
REPOSITORY INTERFACE
================================================================

  public interface ProductRepository extends MongoRepository<Product, String> {

      List<Product> findByCategory(String category);

      List<Product> findByCategoryAndPriceGreaterThan(String cat, BigDecimal price);

      @Query("{ 'tags': { $in: ?0 } }")
      List<Product> findByTagsIn(List<String> tags);
  }

================================================================
INTERVIEW Q&A
================================================================

  Q: What is an ObjectId in MongoDB?
  A: A 12-byte auto-generated unique identifier for every document.
     Encodes creation timestamp + machine + process + counter.
     Sortable by creation time. Used as the default _id.

  Q: How does MongoDB map to SQL concepts?
  A: Database=Database, Collection=Table, Document=Row, Field=Column.
     _id replaces primary key. $lookup replaces JOIN.
     MongoRepository replaces JpaRepository in Spring.
