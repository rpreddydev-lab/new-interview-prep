================================================================
FIND (READ)
================================================================

  -- All documents:
  db.products.find({})

  -- Equality filter:
  db.products.find({ category: "electronics" })

  -- Multiple conditions (implicit AND):
  db.products.find({ category: "electronics", price: { $lt: 100 } })

  -- OR:
  db.products.find({ $or: [ { price: { $lt: 50 } }, { stock: { $gt: 100 } } ] })

  -- Projection (select specific fields):
  db.products.find({ category: "electronics" }, { name: 1, price: 1, _id: 0 })

  -- Sort, limit, skip:
  db.products.find({}).sort({ price: -1 }).limit(10).skip(20)

  -- Find one:
  db.products.findOne({ _id: ObjectId("64a1b2c3...") })

================================================================
QUERY OPERATORS
================================================================

  Comparison:
  $eq    { price: { $eq: 99.99 } }
  $ne    { status: { $ne: "DELETED" } }
  $gt    { price: { $gt: 100 } }
  $gte   { price: { $gte: 100 } }
  $lt    { price: { $lt: 50 } }
  $lte   { price: { $lte: 50 } }
  $in    { category: { $in: ["electronics", "phones"] } }
  $nin   { status: { $nin: ["DELETED", "ARCHIVED"] } }

  Logical:
  $and   { $and: [ {price:{$gt:10}}, {price:{$lt:100}} ] }
  $or    { $or: [ {cat:"A"}, {cat:"B"} ] }
  $not   { price: { $not: { $gt: 1000 } } }
  $nor   { $nor: [ {status:"DELETED"}, {stock:0} ] }

  Element:
  $exists   { discount: { $exists: true } }
  $type     { price: { $type: "double" } }

  Array:
  $all      { tags: { $all: ["electronics", "portable"] } }
  $size     { tags: { $size: 3 } }
  $elemMatch { specs: { $elemMatch: { ram: "16GB", cpu: "i7" } } }

  Text:
  $regex    { name: { $regex: /laptop/i } }

================================================================
UPDATE
================================================================

  -- Update one document:
  db.products.updateOne(
      { _id: ObjectId("64a1...") },
      { $set: { price: 899.99, updatedAt: new Date() } }
  )

  -- Update many:
  db.products.updateMany(
      { category: "electronics", stock: { $lt: 10 } },
      { $set: { status: "LOW_STOCK" } }
  )

  -- Upsert (insert if not found):
  db.products.updateOne(
      { sku: "LAP-001" },
      { $set: { name: "Laptop", price: 999.99 } },
      { upsert: true }
  )

  Update operators:
  $set        Set field value
  $unset      Remove a field: { $unset: { oldField: "" } }
  $inc        Increment: { $inc: { stock: -1 } }
  $push       Append to array: { $push: { tags: "sale" } }
  $pull       Remove from array: { $pull: { tags: "old" } }
  $addToSet   Add if not exists: { $addToSet: { tags: "new" } }
  $rename     Rename field: { $rename: { "old": "new" } }

================================================================
INTERVIEW Q&A
================================================================

  Q: How does MongoDB handle updates to embedded documents?
  A: Use dot notation in $set: { $set: { "address.city": "Dallas" } }
     This updates only the city field inside the embedded address object.

  Q: What is $elemMatch used for?
  A: Matching documents where an array element satisfies multiple conditions.
     Without $elemMatch, MongoDB checks conditions across different elements.
     $elemMatch ensures all conditions apply to the same array element.

  Q: What is upsert in MongoDB?
  A: updateOne/updateMany with { upsert: true } inserts a new document
     if no document matches the filter. Equivalent to SQL UPSERT / ON CONFLICT.
