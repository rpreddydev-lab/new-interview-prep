================================================================
  ADVANCED SQL OVERVIEW
================================================================

  Advanced SQL goes beyond basic SELECT/JOIN/GROUP BY.
  These topics appear frequently in senior engineer interviews
  and production systems.

  01_CTEs_Common_Table_Expressions.txt

     CREATE FUNCTION (returns value); CREATE PROCEDURE (returns nothing);

     pros and cons of stored procs

  05_Triggers.txt
     CREATE TRIGGER; BEFORE/AFTER; ROW vs STATEMENT level;
     trigger function (NEW/OLD); audit log pattern; INSTEAD OF (views);
     cautions (hidden side effects, ordering)

  06_UNION_INTERSECT_EXCEPT.txt
     UNION vs UNION ALL; INTERSECT; EXCEPT;
     ordering and column count rules; performance notes
