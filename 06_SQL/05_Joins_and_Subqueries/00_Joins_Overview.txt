================================================================
  JOINS AND SUBQUERIES: OVERVIEW
================================================================

  JOINs combine rows from two or more tables based on a condition.
  Subqueries nest one SELECT inside another.
  Together they are the core of relational query power.

================================================================
JOIN TYPES SUMMARY
================================================================

  Type              Returns
  ----------------  ------------------------------------------------
  INNER JOIN        Only rows where the join condition matches in BOTH tables
  LEFT OUTER JOIN   All rows from left + matched right (NULL where no match)
  RIGHT OUTER JOIN  All rows from right + matched left (NULL where no match)
  FULL OUTER JOIN   All rows from both; NULL where no match on either side
  CROSS JOIN        Cartesian product -- every row from A × every row from B
  SELF JOIN         A table joined with itself using aliases

================================================================
SUBQUERY TYPES
================================================================

  Scalar subquery   Returns single value; used in SELECT/WHERE
  Row subquery      Returns single row of multiple columns
  Table subquery    Returns multiple rows; used in FROM as derived table
  Correlated        References outer query column; re-evaluated per row
  EXISTS/NOT EXISTS Returns true/false based on subquery result existence

================================================================
CHOOSING JOIN vs SUBQUERY
================================================================

  JOINs are generally preferred when:
  - You need columns from multiple tables in SELECT
  - Performance: query optimizer can choose join strategy
  - Results need to include non-matching rows (OUTER JOIN)

  Subqueries are preferred when:
  - Existence check (EXISTS)
  - Computing an aggregate per outer-query row (correlated)
  - Derived table / CTE for readability
  - The inner result is small and reused

================================================================

  Topic                     Frequency
