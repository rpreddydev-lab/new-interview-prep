================================================================
  FIRST_VALUE, LAST_VALUE, NTH_VALUE
================================================================

  These functions return the value from a specific position
  in the window frame.

================================================================
FIRST_VALUE
================================================================

  Returns the first value in the ordered window frame.

  SELECT
      name,
      department_id,
      salary,
      FIRST_VALUE(name) OVER (
          PARTITION BY department_id ORDER BY salary DESC
      ) AS top_earner_in_dept
  FROM employees;
  -- Every row shows who the highest-paid person in their dept is

================================================================
LAST_VALUE
================================================================

  Returns the last value in the ordered window frame.
  IMPORTANT: Default frame is RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
  This means LAST_VALUE only sees up to the current row, not all rows.
  Must specify explicit frame to get true last value:

  SELECT
      name,
      salary,
      LAST_VALUE(name) OVER (
          PARTITION BY department_id
          ORDER BY salary DESC
          ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
      ) AS lowest_earner_in_dept
  FROM employees;

  Without the explicit ROWS BETWEEN ... frame, LAST_VALUE returns
  the current row's value (not the true last). This is a common mistake.

================================================================
NTH_VALUE
================================================================

  Returns the value from the Nth row in the window frame.

  SELECT
      name, salary, department_id,
      NTH_VALUE(name, 2) OVER (
          PARTITION BY department_id
          ORDER BY salary DESC
          ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
      ) AS second_highest_earner
  FROM employees;

================================================================
COMMON PATTERN: COMPARE TO GROUP LEADER
================================================================

  Show each employee's salary difference from their dept's top earner:
  SELECT
      name,
      salary,
      FIRST_VALUE(salary) OVER (
          PARTITION BY department_id ORDER BY salary DESC
      ) AS top_salary,
      FIRST_VALUE(salary) OVER (
          PARTITION BY department_id ORDER BY salary DESC
      ) - salary AS gap_from_top
  FROM employees;

================================================================
ALTERNATIVE: ROW_NUMBER APPROACH
================================================================

  FIRST_VALUE is cleaner than the ROW_NUMBER trick for many cases:

  ROW_NUMBER approach:
  WITH ranked AS (
      SELECT *, ROW_NUMBER() OVER (PARTITION BY dept ORDER BY salary DESC) rn
      FROM employees
  )
  SELECT e.*, r.name AS top_earner
  FROM employees e
  JOIN ranked r ON e.department_id = r.department_id AND r.rn = 1;

  FIRST_VALUE approach (simpler):
  SELECT *, FIRST_VALUE(name) OVER (PARTITION BY department_id ORDER BY salary DESC)
  FROM employees;

================================================================
INTERVIEW Q&A
================================================================

  Q: What is the LAST_VALUE frame trap?
  A: By default, window frame is RANGE UNBOUNDED PRECEDING TO CURRENT ROW.
     LAST_VALUE returns the current row, not the true last row in partition.
     Fix: ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING.

  Q: How do you get the second-highest salary per department?
  A: NTH_VALUE(salary, 2) OVER (PARTITION BY department_id ORDER BY salary DESC
     ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING)
     Or: DENSE_RANK() = 2 approach in a CTE.
