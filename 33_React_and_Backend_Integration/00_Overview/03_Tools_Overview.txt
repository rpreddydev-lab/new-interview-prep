================================================================
TOOLS OVERVIEW — REACT-BACKEND INTEGRATION ECOSYSTEM
================================================================

A comprehensive guide to every tool, library, and technology used
when integrating React with backend services.

================================================================
1. HTTP CLIENTS
================================================================

A) FETCH API (Built-in Browser)
   - Native browser API, no installation needed
   - Returns Promises
   - No automatic JSON parsing (must call .json())
   - No request/response interceptors
   - No timeout support built-in
   - No automatic error on 4xx/5xx (only network errors reject)

   fetch('/api/users')
     .then(res => {
       if (!res.ok) throw new Error(`HTTP ${res.status}`);
       return res.json();
     })
     .then(data => console.log(data));

B) AXIOS (npm: axios)
   - Promise-based HTTP client
   - Auto JSON serialization/deserialization
   - Interceptors (request and response)
   - Automatic error on 4xx/5xx (rejects the promise)
   - Timeout support
   - Request cancellation via AbortController or CancelToken
   - Upload/download progress events
   - Works in browser AND Node.js
   - Most popular choice for React projects

   npm install axios

C) KY (npm: ky)
   - Tiny fetch-based HTTP client
   - Built on top of native fetch
   - Supports hooks (similar to interceptors)
   - Automatic retries built-in
   - Smaller bundle size than Axios

D) SWR (npm: swr) — by Vercel
   - Data fetching + caching library
   - Stale-While-Revalidate strategy
   - Lightweight alternative to React Query
   - Good for simple read-heavy apps

================================================================
2. SERVER STATE MANAGEMENT
================================================================

A) TANSTACK QUERY / REACT QUERY (npm: @tanstack/react-query)
   THE standard for server state in React (2024+)
   - Automatic caching with configurable staleTime
   - Background refetching
   - Loading, error, success states out of the box
   - Mutation with optimistic updates
   - Infinite queries for pagination
   - Query invalidation
   - Devtools for debugging (@tanstack/react-query-devtools)
   - Works with any fetching library (Axios, fetch, etc.)

   npm install @tanstack/react-query

B) SWR (npm: swr)
   - Simpler API than React Query
   - Auto revalidation on focus, interval, reconnect
   - Good for read-heavy dashboards

C) RTK QUERY (part of @reduxjs/toolkit)
   - Built into Redux Toolkit
   - If already using Redux, RTK Query avoids adding React Query
   - Code generation from OpenAPI/Swagger specs
   - Normalized cache

================================================================
3. AUTHENTICATION LIBRARIES
================================================================

A) AUTH0 REACT SDK (npm: @auth0/auth0-react)
   - Wraps the Auth0 SPA flow
   - Provides useAuth0() hook
   - Handles token storage, refresh, and logout
   - npm install @auth0/auth0-react

B) KEYCLOAK-JS (npm: keycloak-js)
   - Official Keycloak adapter for JavaScript
   - Handles OpenID Connect flow with Keycloak
   - Works with @react-keycloak/web for React integration
   - npm install keycloak-js @react-keycloak/web

C) OIDC-CLIENT-TS (npm: oidc-client-ts)
   - Generic OpenID Connect client
   - Works with any OIDC provider
   - Basis for many OIDC React libraries

D) REACT OAUTH2 PKCE (npm: react-oauth2-pkce)
   - Lightweight OAuth2 PKCE flow
   - No backend needed for the auth flow

E) NEXT-AUTH (npm: next-auth)
   - Authentication for Next.js
   - Supports many providers (Google, GitHub, etc.)
   - Session management built-in

================================================================
4. REAL-TIME COMMUNICATION LIBRARIES
================================================================

A) NATIVE WEBSOCKET API (built-in)
   - No library needed for basic WebSocket
   - Low-level, manual reconnect logic required

B) SOCKET.IO CLIENT (npm: socket.io-client)
   - Works with Socket.io server
   - Automatic reconnection
   - Fallback to long polling
   - Room/namespace support
   - npm install socket.io-client

C) STOMP.JS + SOCKJS (npm: @stomp/stompjs, sockjs-client)
   - STOMP protocol over WebSocket or SockJS
   - Used with Spring Boot's WebSocket support
   - Subscription-based messaging
   - npm install @stomp/stompjs sockjs-client

D) NATIVE SSE (EventSource API — built-in browser)
   - No library needed
   - One-way server-to-client events over HTTP
   - Auto reconnect built into EventSource

E) EVENTSOURCE POLYFILL (npm: eventsource)
   - For environments without native EventSource support

================================================================
5. GRAPHQL CLIENTS
================================================================

A) APOLLO CLIENT (npm: @apollo/client)
   - Full-featured GraphQL client
   - Normalized cache with InMemoryCache
   - useQuery, useMutation, useSubscription hooks
   - Real-time via GraphQL subscriptions over WebSocket
   - Apollo DevTools
   - npm install @apollo/client graphql

B) URQL (npm: urql)
   - Lighter alternative to Apollo Client
   - Extensible with exchanges (plugins)
   - Smaller bundle size

C) TAN STACK QUERY + fetch (manual)
   - Use React Query as the data layer, write GraphQL queries manually
   - Less magic, more control

D) RELAY (by Meta)
   - High-performance GraphQL client
   - Used at Meta scale
   - Steep learning curve
   - Compiler-based (generates optimized queries)

================================================================
6. gRPC FROM BROWSER
================================================================

A) gRPC-WEB (npm: grpc-web)
   - Enables gRPC from browser via HTTP/1.1 or HTTP/2
   - Requires Envoy proxy or gRPC-web compatible server
   - Protocol Buffers for serialization
   - npm install grpc-web google-protobuf

B) CONNECT-WEB (npm: @connectrpc/connect-web)
   - Modern alternative to grpc-web
   - Works with Connect protocol (HTTP/JSON compatible)
   - Easier to set up, no Envoy required

C) TWIRP (npm: twirp-ts)
   - RPC framework built on HTTP/1.1 and JSON or Protobuf
   - Simpler than gRPC for frontend integration

================================================================
7. FORM LIBRARIES (for data submission)
================================================================

A) REACT HOOK FORM (npm: react-hook-form)
   - Minimal re-renders, performant
   - useForm hook, register, handleSubmit
   - Validation with Yup/Zod via resolver
   - npm install react-hook-form

B) FORMIK (npm: formik)
   - Older standard, more opinionated
   - useFormik / <Formik> component
   - npm install formik yup

C) ZOD (npm: zod)
   - TypeScript-first schema validation
   - Use with React Hook Form via @hookform/resolvers/zod
   - npm install zod @hookform/resolvers

================================================================
8. STATE MANAGEMENT (Client State)
================================================================

A) REDUX TOOLKIT (npm: @reduxjs/toolkit)
   - Modern Redux with less boilerplate
   - createSlice, createAsyncThunk
   - Integrated Immer for immutable updates
   - RTK Query for server state

B) ZUSTAND (npm: zustand)
   - Minimalist global state
   - No Provider needed
   - Great for simple global client state

C) JOTAI / RECOIL
   - Atomic state management
   - Fine-grained reactivity

D) CONTEXT API (built-in React)
   - Fine for auth state, theme, locale
   - Not suited for high-frequency updates

================================================================
9. DEVELOPMENT TOOLS
================================================================

A) AXIOS MOCK ADAPTER (npm: axios-mock-adapter)
   - Mocks Axios requests in tests/dev
   - npm install --save-dev axios-mock-adapter

B) MSW — MOCK SERVICE WORKER (npm: msw)
   - Service Worker-based API mocking
   - Intercepts real network requests in browser
   - Same mocks work in Node.js (for tests)
   - npm install --save-dev msw

   msw is the gold standard for mocking in 2024+.

C) REACT QUERY DEVTOOLS (@tanstack/react-query-devtools)
   - Visual browser panel showing cache state
   - See all queries, their status, and data

D) AXIOS LOGGER / DEBUG
   - axios-logger npm package for request/response logging

E) VITE (npm: vite)
   - Fast build tool and dev server
   - Built-in proxy for API calls in development
   - vite.config.js:
     server: {
       proxy: {
         '/api': 'http://localhost:8080'
       }
     }
   - Proxy eliminates CORS in development entirely.

F) VITE PROXY vs CRA PROXY
   CRA: "proxy": "http://localhost:8080" in package.json
   Vite: server.proxy in vite.config.js

================================================================
10. TESTING TOOLS FOR INTEGRATION
================================================================

A) JEST + REACT TESTING LIBRARY
   - Unit and integration tests for React components
   - Test user interactions, not implementation

B) MSW (Mock Service Worker)
   - Mock API in tests without changing production code
   - Example:
     server.use(
       http.get('/api/users', () => HttpResponse.json([
         { id: 1, name: 'Alice' }
       ]))
     );

C) CYPRESS / PLAYWRIGHT
   - End-to-end tests
   - Intercept and mock network requests
   - Cypress: cy.intercept('/api/users', { fixture: 'users.json' })

D) VITEST
   - Vite-native test runner
   - Drop-in Jest replacement for Vite projects

================================================================
11. MONITORING AND OBSERVABILITY
================================================================

A) SENTRY (npm: @sentry/react)
   - Capture JS errors including async/fetch errors
   - Performance monitoring

B) DATADOG RUM (@datadog/browser-rum)
   - Real User Monitoring
   - Track API latency from the frontend

C) OPENTELEMETRY
   - Distributed tracing from React to backend

12. QUICK REFERENCE — WHICH TOOL FOR WHAT
================================================================

Need                          | Tool
------------------------------|-------------------------------------
HTTP calls                    | Axios
Server state / caching        | TanStack Query (React Query)
API mocking in tests          | MSW (Mock Service Worker)
Auth with Auth0               | @auth0/auth0-react
Auth with Keycloak            | keycloak-js + @react-keycloak/web
WebSocket                     | Native WebSocket / socket.io-client
STOMP over WS (Spring Boot)   | @stomp/stompjs + sockjs-client
GraphQL                       | Apollo Client
gRPC from browser             | grpc-web or @connectrpc/connect-web
Form handling + validation    | React Hook Form + Zod
Global client state           | Zustand (simple) / Redux Toolkit
Error reporting               | Sentry
Dev proxy (avoid CORS)        | Vite proxy or CRA proxy
Real-time push (simple)       | EventSource (SSE)
Retry logic                   | axios-retry
Infinite scroll               | React Query useInfiniteQuery
Optimistic UI                 | React Query onMutate
