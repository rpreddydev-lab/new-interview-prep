================================================================
GRAPHQL FROM REACT
================================================================

GraphQL is a query language for APIs that lets the client specify
exactly what data it needs, fetched in a single request.

================================================================
1. CORE CONCEPTS
================================================================

SCHEMA — defines the types and operations:
  type User {
    id: ID!
    name: String!
    email: String!
    posts: [Post!]!
  }

  type Query {
    user(id: ID!): User
    users: [User!]!
  }

  type Mutation {
    createUser(input: CreateUserInput!): User!
    deleteUser(id: ID!): Boolean!
  }

  type Subscription {
    messageAdded(roomId: ID!): Message!
  }

QUERY — reads data (like GET):
  query GetUser($id: ID!) {
    user(id: $id) {
      id
      name
      email
    }
  }

MUTATION — writes data (like POST/PUT/DELETE):
  mutation CreateUser($input: CreateUserInput!) {
    createUser(input: $input) {
      id
      name
    }
  }

SUBSCRIPTION — real-time data over WebSocket:
  subscription OnMessage($roomId: ID!) {
    messageAdded(roomId: $roomId) {
      id
      text
      sender { name }
    }
  }

================================================================
2. MAKING GRAPHQL REQUESTS WITHOUT APOLLO
================================================================

GraphQL runs over HTTP POST:

  async function graphqlRequest(query, variables = {}) {
    const response = await fetch('https://api.example.com/graphql', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${getToken()}`,
      },
      body: JSON.stringify({ query, variables }),
    });
    const { data, errors } = await response.json();
    if (errors) throw new Error(errors[0].message);
    return data;
  }

  // Usage
  const { user } = await graphqlRequest(
    `query GetUser($id: ID!) { user(id: $id) { id name email } }`,
    { id: '123' }
  );

3. APOLLO CLIENT SETUP
================================================================

Install:
  npm install @apollo/client graphql

  // src/apollo/client.js
  import { ApolloClient, InMemoryCache, createHttpLink, from } from '@apollo/client';
  import { setContext } from '@apollo/client/link/context';
  import { onError } from '@apollo/client/link/error';

  const httpLink = createHttpLink({
    uri: import.meta.env.VITE_GRAPHQL_URL,
  });

  const authLink = setContext((_, { headers }) => ({
    headers: {
      ...headers,
      authorization: `Bearer ${getToken()}`,
    },
  }));

  const errorLink = onError(({ graphQLErrors, networkError }) => {
    if (graphQLErrors) {
      graphQLErrors.forEach(({ message, extensions }) => {
        if (extensions?.code === 'UNAUTHENTICATED') {
          // Trigger token refresh or redirect to login
        }
        console.error(`[GraphQL error]: ${message}`);
      });
    }
    if (networkError) {
      console.error(`[Network error]: ${networkError}`);
    }
  });

  export const apolloClient = new ApolloClient({
    link: from([errorLink, authLink, httpLink]),
    cache: new InMemoryCache(),
    defaultOptions: {
      watchQuery: { fetchPolicy: 'cache-and-network' },
    },
  });

  // App.jsx
  import { ApolloProvider } from '@apollo/client';
  function App() {
    return (
      <ApolloProvider client={apolloClient}>
        <RouterProvider router={router} />
      </ApolloProvider>
    );
  }

4. QUERIES WITH useQuery
================================================================

  import { gql, useQuery } from '@apollo/client';

  const GET_USERS = gql`
    query GetUsers($page: Int!, $limit: Int!) {
      users(page: $page, limit: $limit) {
        id
        name
        email
        role
      }
    }
  `;

  function UsersList() {
    const { loading, error, data, refetch } = useQuery(GET_USERS, {
      variables: { page: 1, limit: 20 },
      fetchPolicy: 'cache-and-network', // show cached, refresh in bg
    });

    if (loading && !data) return <Spinner />;
    if (error) return <p>Error: {error.message}</p>;

    return (
      <div>
        <button onClick={() => refetch()}>Refresh</button>
        {data.users.map(user => (
          <UserCard key={user.id} user={user} />
        ))}
      </div>
    );
  }

FETCH POLICIES:
  cache-first       — use cache, only fetch if not cached (default)
  cache-and-network — show cache immediately, always refetch
  network-only      — always fetch, write to cache
  no-cache          — always fetch, never write to cache
  cache-only        — only use cache, error if not present

5. MUTATIONS WITH useMutation
================================================================

  const CREATE_USER = gql`
    mutation CreateUser($input: CreateUserInput!) {
      createUser(input: $input) {
        id
        name
        email
      }
    }
  `;

  function CreateUserForm() {
    const [createUser, { loading, error }] = useMutation(CREATE_USER, {
      // Automatically update the users list cache after mutation
      update(cache, { data: { createUser } }) {
        cache.modify({
          fields: {
            users(existingUsersRefs = []) {
              const newUserRef = cache.writeFragment({
                data: createUser,
                fragment: gql`
                  fragment NewUser on User {
                    id name email
                  }
                `,
              });
              return [...existingUsersRefs, newUserRef];
            },
          },
        });
      },
      onError: (error) => {
        toast.error(error.message);
      },
    });

    const handleSubmit = async (values) => {
      await createUser({ variables: { input: values } });
    };
  }

7. SUBSCRIPTIONS (REAL-TIME)
================================================================

Install:
  npm install @apollo/client subscriptions-transport-ws graphql-ws

  // Add WebSocket link to Apollo
  import { GraphQLWsLink } from '@apollo/client/link/subscriptions';
  import { createClient } from 'graphql-ws';
  import { split, HttpLink } from '@apollo/client';
  import { getMainDefinition } from '@apollo/client/utilities';

  const wsLink = new GraphQLWsLink(
    createClient({
      url: 'wss://api.example.com/graphql',
      connectionParams: {
        authToken: getToken(),
      },
    })
  );

  // Route queries/mutations over HTTP, subscriptions over WS
  const splitLink = split(
    ({ query }) => {
      const definition = getMainDefinition(query);
      return (
        definition.kind === 'OperationDefinition' &&
        definition.operation === 'subscription'
      );
    },
    wsLink,
    authLink.concat(httpLink)
  );

  // Usage in component
  const MESSAGE_ADDED = gql`
    subscription OnMessageAdded($roomId: ID!) {
      messageAdded(roomId: $roomId) {
        id text sender { name }
      }
    }
  `;

  function ChatRoom({ roomId }) {
    const { data } = useSubscription(MESSAGE_ADDED, {
      variables: { roomId },
      onData: ({ data: { data } }) => {
        // data.messageAdded is the new message
      },
    });
  }

    schema: 'https://api.example.com/graphql',
    documents: ['src/**/*.tsx', 'src/**/*.ts'],
    generates: {
      'src/gql/': { preset: 'client' },
    },
  };
  export default config;

  # Run
  npx graphql-codegen

  // build.gradle
  implementation 'org.springframework.boot:spring-boot-starter-graphql'

  // Schema: src/main/resources/graphql/schema.graphqls
  type Query {
    user(id: ID!): User
    users: [User!]!
  }

  // Controller
  @Controller
  public class UserGraphQLController {
    @QueryMapping
    public User user(@Argument String id) {
      return userService.findById(id);
    }

    @QueryMapping
    public List<User> users() {
      return userService.findAll();
    }

    @MutationMapping
    public User createUser(@Argument CreateUserInput input) {
      return userService.create(input);
    }

    @SubscriptionMapping
    public Flux<Message> messageAdded(@Argument String roomId) {
      return messageService.getMessageStream(roomId);
    }
  }

10. INTERVIEW QUESTIONS
================================================================

Q: What problem does GraphQL solve compared to REST?
A: Over-fetching (REST returns fields you don't need) and under-fetching
   (multiple REST calls needed for related data). With GraphQL, the
   client declares exactly what fields it needs, combined across
   any number of types, in one request.

Q: How does Apollo Client's normalized cache work?
A: Apollo stores objects by __typename + id. All queries that return
   the same object (by ID) share one cache entry. Mutations that
   return the updated object automatically update all components
   showing that object, without manual cache updates.

Q: What is the difference between cache-first and cache-and-network?
A: cache-first returns the cached version immediately without making
   a network request (if cache is populated). cache-and-network
   returns cached data immediately AND re-fetches in the background,
   updating the UI when fresh data arrives. Use cache-first for
   rarely-changing data; cache-and-network for data that needs to
   stay fresh.

Q: How do you handle errors in GraphQL vs REST?
A: GraphQL always returns 200 OK (even for errors). Errors are in
   the "errors" array in the response body. Apollo's onError link
   handles them. Partial data is possible: a query might return
   some fields successfully and have errors for others. REST uses
   HTTP status codes (4xx, 5xx).

Q: What is a GraphQL fragment and when do you use it?
A: A fragment is a reusable selection set:
     fragment UserFields on User { id name email }
   Used to: (1) avoid repeating the same fields across queries,
   (2) co-locate data requirements with the component (each component
   defines its own fragment), (3) compose queries from component
   fragments (Relay pattern). Essential for maintainable large-scale
   GraphQL usage.
