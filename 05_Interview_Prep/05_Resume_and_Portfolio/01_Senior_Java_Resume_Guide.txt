================================================================================
SENIOR JAVA DEVELOPER — RESUME GUIDE
================================================================================
Purpose: Build a resume that gets you past ATS filters AND impresses
         engineering managers and senior engineers who review it.
         At 7+ YOE, your resume must communicate IMPACT, not just experience.
================================================================================

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
RESUME STRUCTURE FOR SENIOR JAVA DEVELOPERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RECOMMENDED ORDER:
  1. Header (Name, LinkedIn, GitHub, Email, Location)
  2. Summary / Professional Profile (3-4 lines)
  3. Technical Skills
  4. Professional Experience (reverse chronological)
  5. Education
  6. Certifications (optional, but AWS/GCP certs add signal)
  7. Open Source / Side Projects (optional but powerful)

AVOID:
  ❌ Objective statements ("Looking for a challenging role...")
  ❌ Headshots / personal photos
  ❌ References ("available upon request")
  ❌ Personal interests unless genuinely relevant
  ❌ Tables, columns, graphics — ATS systems can't parse them

LENGTH:
  → 1 page: only appropriate for < 5 years experience
  → 2 pages: ideal for 7-15 years experience
  → NEVER 3+ pages unless you are a researcher/academic

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SECTION 1: HEADER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

INCLUDE:
  Name (large, prominent)
  Email | Phone | LinkedIn URL | GitHub URL
  City, State (no full street address)
  Portfolio URL (if you have one)

EXAMPLE:
  ─────────────────────────────────────────────────
  JOHN SMITH
  john.smith@email.com | (555) 123-4567
  linkedin.com/in/johnsmith | github.com/johnsmith
  Austin, TX | johnsmith.dev
  ─────────────────────────────────────────────────

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SECTION 2: PROFESSIONAL SUMMARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3-4 sentences. Front-load keywords. End with impact.

TEMPLATE:
  "Senior Java/Spring Boot engineer with [X] years of experience
   designing and delivering [type of systems] at scale. Expertise in
   [2-3 specific: distributed systems, event-driven architecture, JVM
   performance tuning, microservices on Kubernetes]. Proven track record
   of [specific achievement with number]. Passionate about [technical area]."

EXAMPLE:
  "Senior Java/Spring Boot engineer with 8 years of experience building
   high-throughput distributed systems for fintech and e-commerce domains.
   Deep expertise in microservices architecture, Kafka event pipelines,
   and JVM performance optimization. Led the migration of a $500M/day payment
   platform from monolith to microservices, improving deployment frequency
   from monthly to daily. AWS Certified Solutions Architect."

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SECTION 3: TECHNICAL SKILLS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FORMAT: Grouped by category. Keywords must match JD language for ATS.

  Languages:    Java (11/17/21), SQL, Python (basic)
  Frameworks:   Spring Boot, Spring Cloud, Spring Security, Hibernate/JPA,
                Spring WebFlux, Spring Batch
  Messaging:    Apache Kafka, RabbitMQ, AWS SQS/SNS
  Databases:    PostgreSQL, MySQL, MongoDB, Redis, DynamoDB, Elasticsearch
  Cloud/DevOps: AWS (EC2, S3, RDS, Lambda, EKS), Docker, Kubernetes, Terraform
  Observability:Prometheus, Grafana, OpenTelemetry, Datadog, ELK Stack
  Testing:      JUnit 5, Mockito, Testcontainers, MockMVC, WireMock
  Tools:        Maven, Gradle, Git, Jenkins, GitHub Actions, Jira

DO:
  ✅ List specific versions when relevant (Java 17, Spring Boot 3.x)
  ✅ Use the same terminology as the job description
  ✅ Group logically — don't just dump a comma-separated list

DON'T:
  ❌ List things you barely know just to fill space
  ❌ Add self-ratings (bars, stars) — they invite challenges you may lose
  ❌ List MS Office, HTML, CSS for a senior Java backend role

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SECTION 4: PROFESSIONAL EXPERIENCE — THE MOST CRITICAL SECTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STRUCTURE PER ROLE:
  Company Name | Job Title | Location | Dates
  [3-6 bullet points per role]

BULLET POINT FORMULA:
  Action Verb + What You Did + Scale/Context + Measurable Result

  ❌ WEAK:  "Responsible for backend development using Spring Boot"
  ✅ STRONG: "Designed and implemented a Spring Boot microservice handling
              15K req/sec, reducing checkout latency from 2.1s to 320ms (85%)"

  ❌ WEAK:  "Worked on improving system performance"
  ✅ STRONG: "Optimized HikariCP connection pool settings and introduced
              query-level caching with Redis, reducing DB query volume by 60%
              and improving p99 latency from 800ms to 95ms under peak load"

  ❌ WEAK:  "Helped migrate the system to microservices"
  ✅ STRONG: "Led architectural migration of 5-year-old payment monolith to
              8 bounded microservices; designed domain boundaries, API contracts,
              and phased rollout strategy — reducing time-to-deploy from
              3 weeks to 2 days and eliminating 4 quarterly outages"

IMPACT METRICS TO INCLUDE:
  → Performance: latency (p50/p95/p99), throughput (req/sec, TPS)
  → Reliability: uptime %, incidents reduced, MTTR improved
  → Scale: users, data volume (GB/TB), records/day
  → Business: revenue impacted ($), cost saved ($), time saved (hours/sprint)
  → Team: engineers mentored, hiring conducted, onboarding improved

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STRONG ACTION VERBS FOR SENIOR ENGINEERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Architecture:   Designed, Architected, Spearheaded, Pioneered, Established
  Leadership:     Led, Directed, Drove, Championed, Mentored, Coached
  Delivery:       Delivered, Shipped, Launched, Executed, Implemented
  Improvement:    Optimized, Reduced, Increased, Improved, Eliminated
  Collaboration:  Partnered, Facilitated, Aligned, Coordinated
  Innovation:     Introduced, Established, Created, Built, Developed

  AVOID: "Helped," "Assisted," "Participated in," "Was responsible for"
  → These signal junior-level contribution

COMMON RESUME MISTAKES FOR SENIOR JAVA DEVELOPERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Technology laundry list — no specifics, no versions, no context
  2. Describing teams' work as your own without clarity on YOUR role
  3. Describing job duties instead of achievements and outcomes
  4. No metrics — "improved performance" says nothing
  5. Listing every tool you've touched in 7 years (overwhelming)
  6. Inconsistent date formats and typos (kill credibility instantly)
  7. Generic summary that doesn't differentiate you from 1000 others
  8. Missing GitHub / portfolio link (especially for senior roles at tech companies)
