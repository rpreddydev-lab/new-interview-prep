ERROR TAXONOMY — CLASSIFY YOUR MISTAKES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Categorizing your errors is more important than counting problems solved.

  E1  WRONG APPROACH — chose wrong algorithm/pattern
  E2  EDGE CASE MISS — empty input, single element, all same values, overflow
  E3  OFF-BY-ONE — index boundary error, loop termination
  E4  COMPLEXITY ERROR — correct solution but wrong time/space analysis
  E5  STUCK > 10 MIN — couldn't progress, needed hint
  E6  IMPLEMENTATION BUG — correct approach, wrong code (pointer, null check)
  E7  COMMUNICATION — solved it but couldn't explain the approach clearly
  E8  TIME OVERRUN — correct but too slow (would fail real interview)
