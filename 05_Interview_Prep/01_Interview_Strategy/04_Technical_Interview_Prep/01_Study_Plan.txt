2. PROBLEM BANK PRIORITIES
--------------------------------------------------------------------------------

TIER 1 — MUST KNOW (the "Blind 75" core)
  Do these before anything else. They are asked directly or as variants
  in 80%+ of FAANG/tier-1 interviews.

  Arrays:
    - Two Sum, Best Time to Buy and Sell Stock, Contains Duplicate
    - Product of Array Except Self, Maximum Subarray, Maximum Product Subarray
    - Find Minimum in Rotated Sorted Array, Search in Rotated Sorted Array
    - 3Sum, Container With Most Water

  Binary Search:
    - Binary Search, Search Insert Position, Kth Smallest in Matrix
    - Find Peak Element, Find First and Last Position

  Linked List:
    - Reverse Linked List, Detect Cycle, Merge Two Sorted Lists
    - Merge K Sorted Lists, Remove Nth Node from End, Reorder List

  Trees:
    - Invert Binary Tree, Maximum Depth, Diameter of Binary Tree
    - Balanced Binary Tree, Same Tree, Subtree of Another Tree
    - Level Order Traversal, Zigzag Level Order, Right Side View
    - Validate BST, Lowest Common Ancestor (BST and general tree)
    - Kth Smallest in BST, Construct from Inorder+Preorder
    - Serialize and Deserialize Binary Tree, Max Path Sum

  Graphs:
    - Number of Islands, Clone Graph, Pacific Atlantic Water Flow
    - Course Schedule I & II (topological sort), Alien Dictionary
    - Word Ladder, Graph Valid Tree, Number of Connected Components

  Dynamic Programming:
    - Climbing Stairs, Coin Change, Longest Increasing Subsequence
    - Unique Paths, Jump Game, Word Break, Combination Sum IV
    - House Robber I & II, Decode Ways, Longest Common Subsequence
    - Edit Distance, Burst Balloons, Regular Expression Matching

  Intervals:
    - Insert Interval, Merge Intervals, Non-Overlapping Intervals
    - Meeting Rooms I & II

  Heaps:
    - Top K Frequent Elements, Kth Largest Element in Array
    - Find Median from Data Stream, Task Scheduler

  Strings:
    - Valid Anagram, Valid Parentheses, Group Anagrams
    - Valid Palindrome, Longest Palindromic Substring
    - Palindromic Substrings, Minimum Window Substring
    - Encode and Decode Strings, Longest Substring Without Repeating Characters

  Tries:
    - Implement Trie, Design Add and Search Words Data Structure
    - Word Search II

TIER 2 — GOOD TO KNOW (depth problems, frequency variants)
  - Segment Trees and Fenwick Trees
  - Union-Find (Disjoint Set Union)
  - Monotonic Stack
  - Floyd-Warshall (All-pairs shortest path)
  - Dijkstra's Algorithm
  - Advanced DP (2D, bitmask DP, digit DP)
  - Advanced backtracking (N-Queens, Sudoku Solver)

3. 8-WEEK STUDY PLAN (COMPREHENSIVE)
--------------------------------------------------------------------------------

WEEK 1: FOUNDATION REFRESH
  Goal: Warm up on core data structures; review time/space complexity.

  Mon:  Arrays, Two Pointers, Prefix Sums — 5 problems
  Tue:  Sliding Window — 5 problems
  Wed:  Binary Search variants — 5 problems
  Thu:  Linked Lists — 5 problems (include cycle detection, reversal)
  Fri:  Stacks and Queues — 5 problems (include min stack, monotonic stack)
  Sat:  Review mistakes from the week; read solutions you didn't get
  Sun:  Rest / light reading (Big-O analysis refresher)

  Target: 25 problems, all Easy-Medium

WEEK 2: TREES
  Goal: Achieve full fluency on binary trees (BFS/DFS/LCA/BST)

  Mon:  Tree traversals (in/pre/post order, level order) — 5 problems
  Tue:  BST problems (search, insert, kth smallest) — 5 problems
  Wed:  LCA problems, path sum problems — 5 problems
  Thu:  Serialization, construction from traversals — 3 problems
  Fri:  Hard tree problems + review week — 3 problems
  Sat:  1 full timed mock interview (2 tree problems in 45 min each)
  Sun:  Review; write out "tree problem cheat sheet"

  Target: 21 problems, mix of Medium/Hard

WEEK 3: GRAPHS
  Goal: Fluent in BFS, DFS, topological sort, Union-Find

  Mon:  BFS on graphs (shortest path, level order traversal) — 5 problems
  Wed:  DFS on graphs (connected components, islands) — 5 problems
  Thu:  Topological Sort (Course Schedule I & II) — 3 problems
  Fri:  Union-Find (number of connected components, graph valid tree) — 3 problems
  Sat:  Hard graph problems (Word Ladder, Alien Dictionary) — 3 problems
  Sun:  Mock: 2 graph problems timed

  Target: 19 problems, majority Medium/Hard

WEEK 4: DYNAMIC PROGRAMMING — PART 1
  Goal: Solidify 1D and basic 2D DP; think in "choices and subproblems"

  Mon:  Classic 1D DP (Fibonacci, Climbing Stairs, House Robber) — 5 problems
  Tue:  Kadane's algorithm variants (max subarray, max product) — 3 problems
  Wed:  Coin Change, Unbounded Knapsack, Word Break — 4 problems
  Thu:  Paths in grids (Unique Paths, Obstacle Grid, Min Path Sum) — 4 problems
  Fri:  LCS, LIS (Longest Common Subsequence, Longest Increasing Subsequence) — 3 problems
  Sat:  Mock: 1 DP Medium + 1 DP Hard
  Sun:  Review; write out DP decision tree

  Target: 19 problems

WEEK 5: DYNAMIC PROGRAMMING — PART 2 + BACKTRACKING
  Goal: Tackle hard DP; master backtracking pattern

  Mon:  Edit Distance, Palindromic Substrings, Decode Ways — 4 problems
  Tue:  0/1 Knapsack, Partition Equal Subset Sum, Target Sum — 3 problems
  Wed:  Interval DP (Burst Balloons, Matrix Chain) — 2 problems
  Thu:  Backtracking fundamentals (Subsets, Permutations, Combinations) — 5 problems
  Fri:  Advanced backtracking (N-Queens, Sudoku Solver, Word Search) — 3 problems
  Sat:  Mock: full 45-min interview (mixed)
  Sun:  Review hardest problems

  Target: 17 problems

WEEK 6: HEAPS, INTERVALS, TRIES + SYSTEM DESIGN INTRO
  Goal: Cover remaining algo topics; start system design

  Mon:  Heaps and Priority Queue (Top K, Merge K Sorted, Kth Largest) — 5 problems
  Tue:  Intervals (Insert, Merge, Non-overlapping, Meeting Rooms) — 5 problems
  Wed:  Tries (Implement Trie, Word Search II, Autocomplete) — 3 problems
  Thu:  System Design: read Grokking SD / Designing Data-Intensive Apps (Ch. 1-4)
        Sketch designs for Twitter, URL Shortener
  Fri:  System Design: design YouTube from scratch (30 min), then read solution
  Sat:  Mock: 1 algo problem + 1 system design problem
  Sun:  Review; algorithm index card review

  Target: 13 algo problems + 2 SD designs

WEEK 7: SYSTEM DESIGN DEEP DIVE + BEHAVIORAL
  Goal: Strengthen system design; polish behavioral stories

  Mon:  System Design: Design a Chat System (WhatsApp)
  Tue:  System Design: Design Instagram/Photo Sharing
  Wed:  System Design: Design a Distributed Cache (like Redis)
  Thu:  System Design: Design Google Drive / Dropbox
  Fri:  Behavioral: write out 8-10 STAR stories (see format below)
  Sat:  Full mock loop: 1 coding + 1 SD + 1 behavioral (simulate 3-hour loop)
  Sun:  Review; refine STAR stories

  STAR STORY FORMAT:
    S — Situation: Set the scene and give context (1-2 sentences)
    T — Task: What was your responsibility? (1 sentence)
    A — Action: What specific actions did YOU take? (3-4 sentences; use "I", not "we")
    R — Result: What was the outcome? Quantify if possible (1-2 sentences)

  STORIES TO PREPARE:
    1. A time you had technical disagreement with a teammate
    2. A project you're most proud of (end-to-end)
    3. A time you failed and what you learned
    4. A time you had to deliver under tight deadline
    5. A time you influenced without authority
    6. A time you went above and beyond for a customer
    7. A time you simplified something complex
    8. A time you prioritized among competing demands
    9. A time you had to give/receive difficult feedback
   10. Why this company? Why this role?

WEEK 8: MOCK INTERVIEWS + FINAL REVIEW
  Goal: Simulate real interviews; fix remaining weak spots; mental prep

  Mon:  Mock Interview #1: Schedule on Pramp or interviewing.io
        Target: LeetCode Medium (25 min) + Hard (25 min)
  Tue:  Review mock; fix mistakes; re-solve problem cleanly
  Wed:  Mock Interview #2: Full system design on Pramp or with a peer
        Target: Design a type-ahead search system
  Thu:  Final sweep: solve 5 problems from your "got wrong" list
  Fri:  Behavioral mock: record yourself answering 5 STAR questions
        Review: Do you ramble? Are results quantified?
  Sat:  Company-specific research: read engineering blog, Glassdoor reviews,
        recent tech talks, product announcements
  Sun:  REST. Light review only. Set up your environment for the week.

  Target: 5 additional problems + 2 mock interviews

4. 4-WEEK ACCELERATED PLAN
--------------------------------------------------------------------------------

WEEK 1: CORE PATTERNS
  - Focus: Arrays, Binary Search, Linked Lists, Stacks, Trees (BFS/DFS)
  - 7 problems/day (50 total)

WEEK 2: GRAPHS + DP
  - Focus: Graph traversals, Topological Sort, 1D DP, Backtracking
  - 6 problems/day (40 total)

WEEK 3: ADVANCED + SYSTEM DESIGN
  - Focus: Hard DP, Heaps, Tries, Intervals
  - System Design: design 3-4 systems from scratch
  - 4 problems/day + 1 SD/day

WEEK 4: MOCKS + REVIEW
  - 3 mock coding interviews
  - 2 mock system design interviews
  - 1 behavioral mock
  - Review top 10 mistakes; re-solve cleanly

--------------------------------------------------------------------------------
5. 2-WEEK INTENSIVE PLAN (PRE-INTERVIEW)
--------------------------------------------------------------------------------

Day 1:   Revise Tree + Graph patterns (5 problems each)
Day 2:   Revise DP patterns (10 problems — 1D, 2D, knapsack)
Day 3:   Revise Backtracking + Heaps (8 problems)
Day 4:   System Design: Twitter + YouTube designs
Day 5:   System Design: WhatsApp + Google Drive designs
Day 6:   Mock interview: coding (full 45 min, hard problem)
Day 7:   Mock interview: system design (full 45 min)
Day 8:   Behavioral: review and rehearse all STAR stories
Day 9:   Company-specific prep: engineering blog, job description alignment
Day 10:  Re-solve your 10 hardest problems cleanly
Day 11:  Full mock loop simulation (coding + SD + behavioral = 3 hours)
Day 12:  Review; light revision only
Day 13:  Rest, hydrate, prepare environment
Day 14:  INTERVIEW DAY

--------------------------------------------------------------------------------
6. DAILY PRACTICE ROUTINE (DURING ANY PLAN)
--------------------------------------------------------------------------------

MORNING (1-2 hours):
  1. Warm-up: 1 Easy problem you've seen before (10 min) — builds flow state
  2. Main: 1-2 Medium problems on today's topic (45-60 min)
  3. Hard: Attempt 1 Hard problem (20 min); look at hint if stuck; finish after

EVENING (30-45 min):
  1. Review solutions from morning (especially editorial for Hard)
  2. Update your "mistake log"
  3. Add new patterns to your cheat sheet

MISTAKE LOG FORMAT:
  Date | Problem Name | Topic | What I Got Wrong | Correct Insight
  Example:
  2024-01 | Median of Two Sorted Arrays | Binary Search | Tried to merge arrays | Binary search on partition index
