SPRING BOOT TESTING — MockMvc WEB LAYER TESTING
Complete Interview Preparation Guide

1. WHAT IS MOCKMVC?
================================================================

MockMvc is a Spring test framework for testing Spring MVC controllers
WITHOUT starting a real HTTP server.

It simulates HTTP requests in the Spring DispatcherServlet context,
testing the full request-response pipeline including:
  - URL mapping
  - Request/response serialization (Jackson)
  - Validation (@Valid, @Validated)
  - Exception handling (@ControllerAdvice)
  - Authentication/Authorization (Spring Security)
  - Response bodies, headers, status codes

FAST: No network, no server — runs in the same JVM as tests.

2. SETUP OPTIONS
================================================================

OPTION 1: @WebMvcTest (recommended for controller unit tests):
  @WebMvcTest(UserController.class)
  class UserControllerTest {
      @Autowired MockMvc mockMvc;
      @MockBean UserService userService;  // service not loaded by @WebMvcTest
      @MockBean JwtTokenService jwtTokenService;
      
      @Autowired ObjectMapper objectMapper;
  }

OPTION 2: @SpringBootTest + @AutoConfigureMockMvc (integration tests):
  @SpringBootTest
  @AutoConfigureMockMvc
  class UserControllerIT {
      @Autowired MockMvc mockMvc;
      // REAL services and repositories — full integration
  }

OPTION 3: Manual MockMvc build (for very specific setups):
  @BeforeEach
  void setUp() {
      mockMvc = MockMvcBuilders
          .standaloneSetup(userController)  // or webAppContextSetup(webAppCtx)
          .addFilter(new JwtFilter())
          .setControllerAdvice(new GlobalExceptionHandler())
          .build();
  }

3. MAKING REQUESTS — perform()
================================================================

  import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.*;
  import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.*;
  import static org.springframework.test.web.servlet.result.MockMvcResultHandlers.*;

GET REQUEST:
  mockMvc.perform(get("/users/{id}", "user-1"))
      .andExpect(status().isOk())
      .andExpect(content().contentType(MediaType.APPLICATION_JSON))
      .andExpect(jsonPath("$.id").value("user-1"))
      .andExpect(jsonPath("$.email").value("alice@test.com"));

GET WITH QUERY PARAMS:
  mockMvc.perform(get("/users")
          .param("email", "alice@test.com")
          .param("page", "0")
          .param("size", "10"))
      .andExpect(status().isOk())
      .andExpect(jsonPath("$.content", hasSize(1)));

POST WITH JSON BODY:
  UserRequest request = new UserRequest("alice@test.com", "Alice", "ADMIN");
  
  mockMvc.perform(post("/users")
          .contentType(MediaType.APPLICATION_JSON)
          .content(objectMapper.writeValueAsString(request)))
      .andExpect(status().isCreated())
      .andExpect(header().string("Location", containsString("/users/")))
      .andExpect(jsonPath("$.id").exists())
      .andExpect(jsonPath("$.email").value("alice@test.com"));

PUT (UPDATE):
  UserUpdateRequest update = new UserUpdateRequest("New Name", "MANAGER");
  
  mockMvc.perform(put("/users/{id}", "user-1")
          .contentType(MediaType.APPLICATION_JSON)
          .content(objectMapper.writeValueAsString(update)))
      .andExpect(status().isOk())
      .andExpect(jsonPath("$.name").value("New Name"));

DELETE:
  mockMvc.perform(delete("/users/{id}", "user-1"))
      .andExpect(status().isNoContent());

PATCH:
  mockMvc.perform(patch("/users/{id}/status", "user-1")
          .contentType(MediaType.APPLICATION_JSON)
          .content("{\"status\": \"ACTIVE\"}"))
      .andExpect(status().isOk());

REQUEST HEADERS:
  mockMvc.perform(get("/admin/users")
          .header("Authorization", "Bearer " + jwtToken)
          .header("X-Correlation-Id", "test-123"))
      .andExpect(status().isOk());

4. RESULT MATCHERS — andExpect()
================================================================

STATUS:
  .andExpect(status().isOk())            // 200
  .andExpect(status().isCreated())        // 201
  .andExpect(status().isNoContent())      // 204
  .andExpect(status().isBadRequest())     // 400
  .andExpect(status().isUnauthorized())   // 401
  .andExpect(status().isForbidden())      // 403
  .andExpect(status().isNotFound())       // 404
  .andExpect(status().isInternalServerError()) // 500
  .andExpect(status().is(HttpStatus.ACCEPTED.value())) // custom

CONTENT TYPE:
  .andExpect(content().contentType(MediaType.APPLICATION_JSON))
  .andExpect(content().contentType("application/json;charset=UTF-8"))
  .andExpect(content().contentTypeCompatibleWith(MediaType.APPLICATION_JSON))

JSON BODY — jsonPath():
  // Simple value check
  .andExpect(jsonPath("$.id").value("user-1"))
  .andExpect(jsonPath("$.email").value("alice@test.com"))
  .andExpect(jsonPath("$.active").value(true))
  
  // Existence
  .andExpect(jsonPath("$.id").exists())
  .andExpect(jsonPath("$.deletedAt").doesNotExist())
  
  // Null / not null
  .andExpect(jsonPath("$.token").isNotEmpty())
  .andExpect(jsonPath("$.error").isEmpty())
  
  // Arrays
  .andExpect(jsonPath("$.items").isArray())
  .andExpect(jsonPath("$.items", hasSize(3)))
  .andExpect(jsonPath("$.items[0].name").value("Apple"))
  .andExpect(jsonPath("$.items[*].price", everyItem(greaterThan(0.0))))
  
  // Nested
  .andExpect(jsonPath("$.address.city").value("London"))
  .andExpect(jsonPath("$.address.zipCode").value("SW1A 1AA"))

HEADERS:
  .andExpect(header().string("Content-Type", containsString("application/json")))
  .andExpect(header().string("Location", startsWith("/users/")))
  .andExpect(header().exists("X-Request-Id"))
  .andExpect(header().doesNotExist("X-Debug"))

COOKIES:
  .andExpect(cookie().exists("session_token"))
  .andExpect(cookie().value("session_token", "abc123"))
  .andExpect(cookie().maxAge("session_token", 3600))

FULL JSON comparison with jsonPath() using Hamcrest:
  import static org.hamcrest.Matchers.*;
  
  .andExpect(jsonPath("$.users", hasSize(greaterThan(0))))
  .andExpect(jsonPath("$.users[0].name", startsWith("Alice")))
  .andExpect(jsonPath("$.total", is(150.0)))

5. RESULT ACTIONS — andDo()
================================================================

PRINT RESULT (debugging):
  mockMvc.perform(get("/users/1"))
      .andDo(print())  // prints full request and response to console
      .andExpect(status().isOk());

LOG RESULT:
  .andDo(log())  // uses MockMvcResultHandlers.log()

SAVE RESULT FOR ASSERTION:
  MvcResult result = mockMvc.perform(get("/users/1"))
      .andReturn();
  
  String body = result.getResponse().getContentAsString();
  User user = objectMapper.readValue(body, User.class);
  
  assertEquals("alice@test.com", user.getEmail());
  assertEquals(200, result.getResponse().getStatus());
  assertNotNull(result.getResponse().getHeader("X-Request-Id"));

6. TESTING EXCEPTION HANDLING
================================================================

  // GlobalExceptionHandler maps exceptions to responses:
  @RestControllerAdvice
  class GlobalExceptionHandler {
      
      @ExceptionHandler(UserNotFoundException.class)
      @ResponseStatus(HttpStatus.NOT_FOUND)
      ProblemDetail handleUserNotFound(UserNotFoundException ex) {
          ProblemDetail pd = ProblemDetail.forStatusAndDetail(
              HttpStatus.NOT_FOUND, ex.getMessage());
          pd.setTitle("User Not Found");
          return pd;
      }
      
      @ExceptionHandler(MethodArgumentNotValidException.class)
      @ResponseStatus(HttpStatus.BAD_REQUEST)
      ProblemDetail handleValidationErrors(MethodArgumentNotValidException ex) { ... }
  }
  
  // Test:
  @Test
  void shouldReturn404WhenUserNotFound() throws Exception {
      when(userService.findById("bad-id"))
          .thenThrow(new UserNotFoundException("bad-id"));
      
      mockMvc.perform(get("/users/bad-id"))
          .andExpect(status().isNotFound())
          .andExpect(jsonPath("$.title").value("User Not Found"))
          .andExpect(jsonPath("$.detail").value(containsString("bad-id")));
  }

VALIDATION ERROR TEST:
  @Test
  void shouldReturn400ForInvalidRequest() throws Exception {
      String invalidJson = "{\"email\": \"not-an-email\", \"name\": \"\"}";
      
      mockMvc.perform(post("/users")
              .contentType(MediaType.APPLICATION_JSON)
              .content(invalidJson))
          .andExpect(status().isBadRequest())
          .andExpect(jsonPath("$.errors[*].field", containsInAnyOrder("email", "name")));
  }

7. TESTING WITH SPRING SECURITY
================================================================

  import static org.springframework.security.test.web.servlet.request.SecurityMockMvcRequestPostProcessors.*;

UNAUTHENTICATED (default):
  @Test
  void shouldReturn401WhenNotAuthenticated() throws Exception {
      mockMvc.perform(get("/admin/users"))
          .andExpect(status().isUnauthorized());
  }

WITH USER (basic setup):
  @Test
  @WithMockUser(username = "alice@test.com", roles = {"USER"})
  void shouldReturnUserProfile() throws Exception {
      mockMvc.perform(get("/profile"))
          .andExpect(status().isOk());
  }

WITH SPECIFIC AUTHORITIES:
  @Test
  @WithMockUser(username = "admin@test.com", authorities = {"ROLE_ADMIN", "READ_USERS"})
  void adminShouldListAllUsers() throws Exception {
      mockMvc.perform(get("/admin/users"))
          .andExpect(status().isOk());
  }

WITH CUSTOM USER DETAILS:
  @Test
  void withCustomSecurityContext() throws Exception {
      mockMvc.perform(get("/profile")
              .with(user("alice@test.com").password("pass").roles("USER", "PREMIUM")))
          .andExpect(status().isOk());
  }

WITH JWT TOKEN (custom post processor):
  @Test
  void withJwtToken() throws Exception {
      String token = jwtService.generateToken("alice@test.com", List.of("ROLE_USER"));
      
      mockMvc.perform(get("/profile")
              .header("Authorization", "Bearer " + token))
          .andExpect(status().isOk());
  }

WITH CSRF (for POST/PUT with CSRF protection):
  @Test
  void shouldCreateUserWithCsrf() throws Exception {
      mockMvc.perform(post("/users")
              .with(csrf())  // inject CSRF token
              .contentType(MediaType.APPLICATION_JSON)
              .content(requestJson))
          .andExpect(status().isCreated());
  }

9. COMPLETE CONTROLLER TEST EXAMPLE
================================================================

  @WebMvcTest(UserController.class)
  class UserControllerTest {
      
      @Autowired MockMvc mockMvc;
      @Autowired ObjectMapper objectMapper;
      @MockBean UserService userService;
      
      private User testUser;
      
      @BeforeEach
      void setUp() {
          testUser = User.builder()
              .id("user-1")
              .email("alice@test.com")
              .name("Alice")
              .role(Role.USER)
              .active(true)
              .build();
      }
      
      @Test
      void getUserById_shouldReturnUser() throws Exception {
          when(userService.findById("user-1")).thenReturn(testUser);
          
          mockMvc.perform(get("/users/{id}", "user-1")
                  .accept(MediaType.APPLICATION_JSON))
              .andDo(print())
              .andExpect(status().isOk())
              .andExpect(content().contentType(MediaType.APPLICATION_JSON))
              .andExpect(jsonPath("$.id").value("user-1"))
              .andExpect(jsonPath("$.email").value("alice@test.com"))
              .andExpect(jsonPath("$.name").value("Alice"))
              .andExpect(jsonPath("$.role").value("USER"))
              .andExpect(jsonPath("$.password").doesNotExist());  // sensitive field hidden
      }
      
      @Test
      void getUserById_shouldReturn404WhenNotFound() throws Exception {
          when(userService.findById("bad-id"))
              .thenThrow(new UserNotFoundException("bad-id"));
          
          mockMvc.perform(get("/users/{id}", "bad-id"))
              .andExpect(status().isNotFound())
              .andExpect(jsonPath("$.title").value("User Not Found"));
      }
      
      @Test
      void createUser_shouldReturn201WithLocation() throws Exception {
          UserCreateRequest req = new UserCreateRequest("bob@test.com", "Bob");
          User created = testUser.toBuilder().id("user-2").email("bob@test.com").build();
          
          when(userService.create(any(UserCreateRequest.class))).thenReturn(created);
          
          mockMvc.perform(post("/users")
                  .contentType(MediaType.APPLICATION_JSON)
                  .content(objectMapper.writeValueAsString(req)))
              .andExpect(status().isCreated())
              .andExpect(header().string("Location", endsWith("/users/user-2")))
              .andExpect(jsonPath("$.id").value("user-2"));
      }
      
      @Test
      void createUser_shouldReturn400ForInvalidEmail() throws Exception {
          String badRequest = "{\"email\":\"not-an-email\",\"name\":\"Bob\"}";
          
          mockMvc.perform(post("/users")
                  .contentType(MediaType.APPLICATION_JSON)
                  .content(badRequest))
              .andExpect(status().isBadRequest())
              .andExpect(jsonPath("$.errors[0].field").value("email"));
          
          verify(userService, never()).create(any());
      }
      
      @Test
      void deleteUser_shouldReturn204() throws Exception {
          doNothing().when(userService).delete("user-1");
          
          mockMvc.perform(delete("/users/{id}", "user-1"))
              .andExpect(status().isNoContent());
          
          verify(userService).delete("user-1");
      }
  }

10. INTERVIEW QUESTIONS
================================================================

Q: What is MockMvc and how does it differ from TestRestTemplate?
A: MockMvc tests controllers without a real HTTP server — it dispatches
   directly to Spring's DispatcherServlet. Fast, no port binding.
   TestRestTemplate makes real HTTP requests to a running embedded server
   (requires RANDOM_PORT or DEFINED_PORT). Slower but more realistic.

Q: What is the difference between @WebMvcTest and @SpringBootTest with @AutoConfigureMockMvc?
A: @WebMvcTest loads only the web layer (controller, ControllerAdvice, filters).
   Services/repos are NOT loaded — must be @MockBean'd. Very fast.
   @SpringBootTest + @AutoConfigureMockMvc loads everything (real services and repos).
   Use for integration tests where you want real service behavior.

Q: How do you test validation failures with MockMvc?
A: Send a request with invalid data (e.g., blank name, invalid email).
   Expect 400 Bad Request and verify the validation error fields in the response.
   verify(service, never()).method(any()) to ensure service wasn't called.

Q: How do you add authentication to MockMvc requests?
A: Use @WithMockUser for simple username/role setup.
   Use .with(user("name").roles("ROLE")) for per-request configuration.
   Use .with(csrf()) for forms requiring CSRF tokens.
   Or pass a real JWT in the Authorization header.

Q: How do you get the full response body after a perform() call?
A: Use .andReturn().getResponse().getContentAsString().
   Or .andReturn() returns MvcResult which has getResponse() and getModelAndView().

Q: What is jsonPath() and how do you use it?
A: jsonPath() is a ResultMatcher using Jayway JsonPath expressions.
   $.field for root field, $.items[0].name for nested arrays.
   Combined with Hamcrest: .andExpect(jsonPath("$.items", hasSize(3))).
