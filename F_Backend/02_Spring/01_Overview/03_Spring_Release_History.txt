================================================================
IMPORTANT MIGRATION NOTES
================================================================

  Spring Boot 2.x → 3.x (BREAKING):
  ├── Java 17 minimum required
  ├── javax.* → jakarta.* package rename (all imports must change)
  ├── Spring Security 5 → 6: SecurityFilterChain replaces WebSecurityConfigurerAdapter
  ├── Micrometer Tracing replaces Spring Cloud Sleuth
  ├── Actuator: some endpoints restructured
  ├── spring.factories → spring/...AutoConfiguration.imports
  └── @SpringBootTest(webEnvironment) defaults changed

  Spring Framework 5.x → 6.x (BREAKING):
  ├── Java 17 baseline
  ├── Jakarta EE 9+ (all javax.* → jakarta.*)
  ├── Hibernate 6.x required (vs Hibernate 5.x)
  ├── Apache HttpClient 5.x for RestTemplate
  └── AOT support for GraalVM native images
