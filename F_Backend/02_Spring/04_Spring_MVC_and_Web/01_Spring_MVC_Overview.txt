================================================================
WHAT IS SPRING MVC?
================================================================

  Spring MVC is Spring's web framework built on the Servlet API.
  It implements the Model-View-Controller design pattern for:
    • REST APIs (returning JSON/XML data)
    • Server-side rendered web pages (Thymeleaf, FreeMarker, JSP)

  Core: DispatcherServlet is the single front controller that
  routes all incoming HTTP requests to the appropriate handler.

================================================================
CORE COMPONENTS
================================================================

  Component                  | Role
  ---------------------------|---------------------------------------------
  DispatcherServlet          | Front controller — entry point
  HandlerMapping             | Maps URL → controller method
  HandlerAdapter             | Calls the mapped method
  ViewResolver               | Resolves view name → View
  MessageConverter           | Converts Java ↔ JSON/XML/etc.
  ExceptionHandlerResolver   | Routes exceptions to @ExceptionHandler
  LocaleResolver             | Resolves request Locale for i18n
  MultipartResolver          | Parses multipart/form-data

================================================================
REQUEST PROCESSING PIPELINE
================================================================

  HTTP Request
       │
       ▼
  DispatcherServlet.doDispatch()
       │
       ├──► HandlerMapping.getHandler()
       │    (returns HandlerExecutionChain: handler + interceptors)
       │
       ├──► HandlerAdapter.handle()
       │    Calls pre/postHandle interceptors + handler method
       │    Runs @RequestMapping-annotated method
       │
       ├──► Return value handling:
       │    @ResponseBody → MessageConverter → JSON response
       │    ModelAndView  → ViewResolver → rendered HTML
       │
       ├──► ExceptionHandlerExceptionResolver (if exception)
       │    Finds matching @ExceptionHandler
       │
       └──► Response committed

================================================================
SPRING MVC ANNOTATION OVERVIEW
================================================================

  ── CONTROLLER STEREOTYPES ──────────────────────────────────────
  @Controller          -- returns view names (or @ResponseBody data)
  @RestController      -- @Controller + @ResponseBody (data only)

  ── MAPPING ─────────────────────────────────────────────────────
  @RequestMapping      -- maps any HTTP method (class or method level)
  @GetMapping          -- GET
  @PostMapping         -- POST
  @PutMapping          -- PUT
  @PatchMapping        -- PATCH
  @DeleteMapping       -- DELETE

  ── REQUEST BINDING ─────────────────────────────────────────────
  @PathVariable        -- URI template variable (/users/{id})
  @RequestParam        -- Query parameter (?name=value)
  @RequestBody         -- Request body (JSON → object via Jackson)
  @RequestHeader       -- HTTP header value
  @CookieValue         -- Cookie value
  @ModelAttribute      -- Bind form data / add model attribute
  @MatrixVariable      -- Matrix variable (/users/1;status=active)

  ── RESPONSE ────────────────────────────────────────────────────
  @ResponseBody        -- Write return value to HTTP response body
  @ResponseStatus      -- Set HTTP status code
  ResponseEntity<T>    -- Full control: status + headers + body

  ── EXCEPTION HANDLING ──────────────────────────────────────────
  @ExceptionHandler    -- Handle exception in controller scope
  @RestControllerAdvice -- Global handler for all controllers

  ── CROSS-CUTTING ───────────────────────────────────────────────
  @CrossOrigin         -- Enable CORS on class/method
  @SessionAttribute    -- Access session attribute
  @RequestAttribute    -- Access request attribute (set by interceptor)

================================================================
MINIMAL REST CONTROLLER EXAMPLE
================================================================

  @RestController
  @RequestMapping("/api/v1/users")
  public class UserController {

      @Autowired
      private UserService userService;

      @GetMapping
      public ResponseEntity<Page<UserDto>> listUsers(
              @RequestParam(defaultValue = "0") int page,
              @RequestParam(defaultValue = "20") int size,
              @RequestParam(required = false) String search) {
          return ResponseEntity.ok(userService.findAll(page, size, search));
      }

      @GetMapping("/{id}")
      public ResponseEntity<UserDto> getUser(@PathVariable Long id) {
          return userService.findById(id)
              .map(ResponseEntity::ok)
              .orElse(ResponseEntity.notFound().build());
      }

      @PostMapping
      public ResponseEntity<UserDto> createUser(
              @Valid @RequestBody CreateUserRequest request,
              UriComponentsBuilder uriBuilder) {
          UserDto created = userService.create(request);
          URI location = uriBuilder.path("/api/v1/users/{id}")
              .buildAndExpand(created.getId()).toUri();
          return ResponseEntity.created(location).body(created);
      }

      @PutMapping("/{id}")
      public ResponseEntity<UserDto> updateUser(
              @PathVariable Long id,
              @Valid @RequestBody UpdateUserRequest request) {
          return ResponseEntity.ok(userService.update(id, request));
      }

      @DeleteMapping("/{id}")
      @ResponseStatus(HttpStatus.NO_CONTENT)
      public void deleteUser(@PathVariable Long id) {
          userService.delete(id);
      }
  }

VIEW RESOLUTION (NON-REST APPS)

  @Controller
  public class HomeController {

      @GetMapping("/")
      public String home(Model model,
                         @RequestParam(required=false) String msg) {
          model.addAttribute("message", msg != null ? msg : "Welcome!");
          model.addAttribute("users", userService.findAll());
          return "home";  // → resolves to /templates/home.html
      }
  }

SPRING MVC AUTO-CONFIGURATION (Spring Boot)
================================================================

  WebMvcAutoConfiguration configures:
    ✓ ContentNegotiationManager
    ✓ Jackson ObjectMapper (JSON)
    ✓ HttpMessageConverters (JSON, XML, plain text, etc.)
    ✓ Static resource serving (/static, /public, /resources, /META-INF/resources)
    ✓ ViewResolver (for Thymeleaf if on classpath)
    ✓ FormattingConversionService (date/number formatting)
    ✓ Validator (JSR-303 if present)

  Disable auto-config and fully control MVC:
    @EnableWebMvc  -- disables Boot's WebMvcAutoConfiguration

  Extend auto-config (preferred):
    Implement WebMvcConfigurer interface

  @Configuration
  public class MvcConfig implements WebMvcConfigurer {

      @Override
      public void addCorsMappings(CorsRegistry registry) {
          registry.addMapping("/api/**")
                  .allowedOrigins("https://example.com")
                  .allowedMethods("GET","POST","PUT","DELETE");
      }

      @Override
      public void addInterceptors(InterceptorRegistry registry) {
          registry.addInterceptor(new RateLimitInterceptor())
                  .addPathPatterns("/api/**");
      }

      @Override
      public void addResourceHandlers(ResourceHandlerRegistry registry) {
          registry.addResourceHandler("/static/**")
                  .addResourceLocations("classpath:/static/");
      }
  }

================================================================
INTERVIEW QUESTIONS — SPRING MVC OVERVIEW
================================================================

  Q: What is DispatcherServlet?
  A: The single front controller in Spring MVC. All HTTP requests
     go through it. It delegates to HandlerMappings, HandlerAdapters,
     ViewResolvers, and ExceptionHandlerExceptionResolvers.

  Q: What is the difference between @Controller and @RestController?
  A: @RestController = @Controller + @ResponseBody. All methods in
     a @RestController write their return value directly to the
     response body via HttpMessageConverters (JSON by default).

  Q: What is WebMvcConfigurer used for?
  A: It provides callback methods to customize Spring MVC without
     disabling auto-configuration: add interceptors, CORS mappings,
     formatters, view controllers, resource handlers, etc.

  Q: What is the difference between @EnableWebMvc and WebMvcConfigurer?
  A: @EnableWebMvc disables Spring Boot's MVC auto-configuration
     and requires you to configure everything. WebMvcConfigurer lets
     you extend/customize the auto-configured MVC setup.

  Q: How does Spring Boot configure Jackson automatically?
  A: JacksonAutoConfiguration creates an ObjectMapper bean with
     sensible defaults. JacksonProperties (spring.jackson.*) allows
     customization of serialization, date formats, etc.
