1. WHAT IS A SYMBOL?
  - Unique and immutable primitive value (ES6)
  - Every Symbol() call creates a guaranteed unique value
  - Used as unique property keys to avoid name collisions

  const s1 = Symbol("description");
  const s2 = Symbol("description");
  s1 === s2          // false — always unique!
  typeof s1          // "symbol"
  s1.toString()      // "Symbol(description)"
  s1.description     // "description"

2. SYMBOL AS PROPERTY KEY
  const ID = Symbol("id");
  const user = {
    name: "Alice",
    [ID]: 123      // computed property with symbol key
  };

  user[ID];         // 123
  user.ID;          // undefined (can't use dot notation for symbol)

  // Symbols are NOT enumerable in:
  Object.keys(user)              // ["name"] — symbol hidden
  Object.values(user)            // ["Alice"]
  for...in loop                  // "name" only
  JSON.stringify(user)           // {"name":"Alice"} — symbol omitted

  // But accessible via:
  Object.getOwnPropertySymbols(user)  // [Symbol(id)]
  Reflect.ownKeys(user)               // ["name", Symbol(id)]

3. GLOBAL SYMBOL REGISTRY
  // Symbol.for() creates/retrieves a SHARED symbol by key:
  const s1 = Symbol.for("app.id");
  const s2 = Symbol.for("app.id");
  s1 === s2           // true — same symbol from registry

  Symbol.keyFor(s1)   // "app.id" — get key from registered symbol

4. WELL-KNOWN SYMBOLS (Built-in symbols to customize JS behavior)
  These allow you to hook into JS language internals:

  Symbol.iterator     – makes object iterable (for...of)
  Symbol.toPrimitive  – customize type coercion
  Symbol.hasInstance  – customize instanceof
  Symbol.toStringTag  – customize Object.prototype.toString output
  Symbol.species      – customize derived class constructors
  Symbol.asyncIterator – async iteration
  Symbol.isConcatSpreadable – customize Array.prototype.concat
  Symbol.match / Symbol.replace / Symbol.search / Symbol.split

  // Symbol.toStringTag example:
  class MyCollection {
    get [Symbol.toStringTag]() { return "MyCollection"; }
  }
  Object.prototype.toString.call(new MyCollection());
  // "[object MyCollection]"

  // Symbol.toPrimitive example:
  const money = {
    amount: 100,
    currency: "USD",
    [Symbol.toPrimitive](hint) {
      if (hint === "number") return this.amount;
      if (hint === "string") return `${this.amount} ${this.currency}`;
      return this.amount;
    }
  };
  +money            // 100
  `${money}`        // "100 USD"
  money + 50        // 150

5. ITERATOR PROTOCOL
  An ITERATOR is any object with a next() method that returns:
  { value: any, done: boolean }

  // Manual iterator:
  const iterator = {
    current: 0,
    last: 3,
    next() {
      if (this.current <= this.last) {
        return { value: this.current++, done: false };
      }
      return { value: undefined, done: true };
    }
  };

  iterator.next();  // { value: 0, done: false }
  iterator.next();  // { value: 1, done: false }
  iterator.next();  // { value: 4, done: true }

6. ITERABLE PROTOCOL
  An ITERABLE is any object with a [Symbol.iterator]() method that returns
  an iterator. Makes it usable with:
  - for...of
  - spread [...iterable]
  - destructuring const [a, b] = iterable
  - Array.from(iterable)

  Built-in iterables: Array, String, Map, Set, NodeList, arguments, generators

  // Custom iterable:
  const range = {
    from: 1,
    to: 5,
    [Symbol.iterator]() {
      let current = this.from;
      const last = this.to;
      return {
        next() {
          if (current <= last) {
            return { value: current++, done: false };
          }
          return { value: undefined, done: true };
        }
      };
    }
  };

  for (const num of range) { console.log(num); }  // 1, 2, 3, 4, 5
  [...range];    // [1, 2, 3, 4, 5]
  const [a, b] = range;  // a=1, b=2

7. GENERATOR FUNCTIONS AS ITERATORS
  Generator functions (function*) automatically implement the iterator protocol:

  function* range(from, to) {
    for (let i = from; i <= to; i++) {
      yield i;
    }
  }

  const gen = range(1, 5);
  gen.next();    // { value: 1, done: false }
  [...gen];      // [2, 3, 4, 5]  (gen already consumed value 1)

  // Infinite iterator:
  function* naturals() {
    let n = 1;
    while (true) yield n++;
  }

  // take() utility:
  function take(iterable, count) {
    const result = [];
    for (const item of iterable) {
      result.push(item);
      if (result.length >= count) break;
    }
    return result;
  }
  take(naturals(), 5);  // [1, 2, 3, 4, 5]

  // yield* delegates to another iterable:
  function* combined() {
    yield* [1, 2, 3];
    yield* "abc";
  }
  [...combined()];  // [1, 2, 3, "a", "b", "c"]

8. ASYNC ITERATORS AND for await...of
  // Async iterator protocol: next() returns Promise<{value, done}>
  
  async function* asyncRange(from, to) {
    for (let i = from; i <= to; i++) {
      await delay(100);  // simulate async work
      yield i;
    }
  }

  // Use with for await...of:
  for await (const num of asyncRange(1, 5)) {
    console.log(num);  // 1, 2, 3, 4, 5 (with 100ms delay each)
  }

  // Paginated API example:
  async function* fetchPages(url) {
    let nextUrl = url;
    while (nextUrl) {
      const res = await fetch(nextUrl);
      const data = await res.json();
      yield data.items;
      nextUrl = data.nextPage;
    }
  }

  for await (const page of fetchPages("/api/items")) {
    processPage(page);
  }

Q: What are Symbols used for?
A: 1. Unique property keys that don't clash with other code's keys.
   2. Implementing well-known symbols to customize JS behavior (Symbol.iterator,
      Symbol.toPrimitive, etc.).
   3. "Private-ish" properties (not truly private but not enumerable).

Q: What is the iterable protocol?
A: An object is iterable if it has a [Symbol.iterator]() method that returns
   an iterator (object with next() returning {value, done}).

Q: What is the difference between an iterator and an iterable?
A: Iterable: has [Symbol.iterator]() method (e.g., arrays, strings, Map, Set).
   Iterator: has next() method returning {value, done}. An iterable's
   [Symbol.iterator]() returns an iterator. Generators are both.

Q: What are the well-known symbols?
A: Special built-in Symbol values that customize JS language behavior:
   Symbol.iterator (for...of), Symbol.toPrimitive (coercion),
   Symbol.hasInstance (instanceof), Symbol.toStringTag (toString output).

Q: What is Symbol.for() vs Symbol()?
A: Symbol() always creates a new unique symbol.
   Symbol.for("key") creates or retrieves a symbol from the global registry.
   Symbol.for("a") === Symbol.for("a") is true.
   Symbol("a") === Symbol("a") is false.

Q: How do generators enable lazy evaluation?
A: Generators pause (yield) and resume on demand. Values are computed only
   when requested via next(). This enables infinite sequences and processing
   large datasets without loading everything into memory.
