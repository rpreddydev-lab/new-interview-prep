1. WHAT IS CSS?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CSS (Cascading Style Sheets) is a style-sheet language used to describe the
presentation of a document written in HTML or XML. CSS controls layout, colors,
fonts, spacing, animations, responsiveness, and much more.

Key points:
  • CSS is NOT a programming language — it is a declarative style language.
  • CSS3 is the current standard, split into individual modules (flexbox, grid, etc.)
  • The "Cascading" refers to the priority scheme that determines which rules apply
    when multiple rules could apply to the same element.

2. HOW CSS WORKS — THE RENDERING PIPELINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Browser parses HTML → builds the DOM (Document Object Model)
2. Browser parses CSS → builds the CSSOM (CSS Object Model)
3. DOM + CSSOM are combined into a Render Tree
4. Layout (Reflow): browser calculates size and position of each element
5. Paint: pixels are drawn on the screen
6. Compositing: layers are combined (GPU-accelerated transforms/opacity)

Understanding this pipeline is critical for performance optimization:
  • Avoid triggering reflow (layout changes) in animations — use transform/opacity
  • Minimize paint operations by using will-change property
  • Use contain: layout | paint to isolate subtrees

3. WAYS TO INCLUDE CSS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A) External Stylesheet (BEST PRACTICE)
   <link rel="stylesheet" href="styles.css">
   • Cached by browser, reusable across pages
   • Keeps HTML clean (separation of concerns)
   • Blocks rendering until loaded (use preload for critical CSS)

B) Internal / Embedded Stylesheet
   <style>
     body { margin: 0; }
   </style>
   • Good for single-page or small components
   • Not cached separately

C) Inline Styles
   <p style="color: red; font-size: 16px;">Hello</p>
   • Highest specificity (after !important)
   • Hard to maintain, should generally be avoided
   • Acceptable for dynamic values set via JavaScript

D) CSS-in-JS (styled-components, Emotion)
   • Styles scoped to components at runtime
   • Enables dynamic styles based on props
   • Adds JS bundle size

4. CSS SYNTAX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

selector {
  property: value;
}

  selector    → targets HTML element(s)
  property    → the style attribute (e.g., color, margin, display)
  value       → the value for the property (e.g., red, 16px, flex)

At-rules:
  @import     — import another stylesheet
  @media      — conditional rules based on viewport/device
  @keyframes  — define animation keyframes
  @supports   — feature query
  @font-face  — load custom fonts
  @layer      — cascade layers (CSS 2022+)

5. THE CASCADE — ORDER OF PRIORITY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When two rules target the same element, the browser uses the cascade to decide:

Priority (highest → lowest):
  1. !important user-agent declarations
  2. !important author declarations
  3. !important user declarations
  4. Animations (@keyframes)
  5. Author declarations (normal)
  6. User declarations (normal)
  7. User-agent (browser default) stylesheet

Within the same origin and importance level:
  a) Specificity (see 01_Specificity_Rules.txt)
  b) Source order (later rules win)

⚠ !important overrides everything — use sparingly, document why.

6. INHERITANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Some CSS properties are INHERITED by child elements from their parent:
  • Inherited by default: color, font-family, font-size, font-weight,
    line-height, text-align, visibility, cursor, list-style, etc.
  • NOT inherited: margin, padding, border, background, width, height,
    display, position, etc.

Explicit inheritance keywords:
  inherit   — force inheritance from parent
  initial   — reset to browser default
  unset     — act as inherit if inherited property, else initial
  revert    — revert to browser/user stylesheet value
  revert-layer — revert to previous cascade layer value

Example:
  .child {
    color: inherit;    /* takes parent's color */
    border: initial;   /* resets border to none */
  }

7. CSS RESET vs NORMALIZE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CSS Reset (e.g., Eric Meyer's Reset):
  • Removes ALL browser default styles
  • Starts from a completely blank slate
  • You must restyle everything manually
  * { margin: 0; padding: 0; box-sizing: border-box; }

Normalize.css:
  • Preserves useful browser defaults
  • Fixes known browser inconsistencies
  • More targeted than a full reset
  • Widely used in production projects

Modern Approach (CSS Reboot — used in Bootstrap):
  • Box-sizing: border-box on everything
  • Remove default margin/padding on headings, p, ul
  • Smooth font rendering

8. CSS PERFORMANCE BEST PRACTICES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • Use shorthand properties (margin: 10px 20px vs 4 separate declarations)
  • Avoid deep descendant selectors (div > ul > li > a → slow to match)
  • Minimize use of universal selector (*)
  • Avoid expensive properties in animations: width, height, top, left
    → Use transform and opacity instead (compositor-only, no reflow/repaint)
  • Use will-change: transform to promote element to its own layer (use sparingly)
  • Extract critical CSS (above-the-fold) and inline it in <head>
  • Defer non-critical CSS with media="print" trick or JS loading
  • Minify CSS in production
  • Use CSS containment: contain: layout paint style

9. CSS ARCHITECTURE METHODOLOGIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BEM (Block Element Modifier) — most popular:
  .block {}
  .block__element {}
  .block--modifier {}
  .block__element--modifier {}

  Example:
    .card {}
    .card__title {}
    .card__image {}
    .card--featured {}
    .card__title--large {}

SMACSS (Scalable and Modular Architecture for CSS):
  Categories: Base, Layout, Module, State, Theme

OOCSS (Object-Oriented CSS):
  Separate structure from skin, separate container from content

ITCSS (Inverted Triangle CSS):
  Order styles from generic → specific:
  Settings → Tools → Generic → Elements → Objects → Components → Trumps

Atomic CSS / Utility-first (Tailwind):
  Single-purpose utility classes: .flex .items-center .p-4

10. CSS @LAYER (Cascade Layers — Modern CSS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Introduced in 2022, @layer lets you explicitly control cascade order:

  @layer base, components, utilities;

  @layer base {
    body { font-family: sans-serif; }
  }

  @layer components {
    .btn { padding: 8px 16px; }
  }

  @layer utilities {
    .mt-4 { margin-top: 1rem; }
  }

  • Layers listed first have LOWER priority
  • Unlayered styles beat ALL layers (regardless of specificity)
  • Solves the "specificity wars" problem in large codebases

11. COMMON INTERVIEW QUESTIONS — CSS BASICS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: What does "cascading" mean in CSS?
A: Cascading means that multiple CSS rules can apply to the same element and the
   browser uses a priority algorithm (origin, importance, specificity, source order)
   to determine which rule wins.

Q: What's the difference between display:none and visibility:hidden?
A: display:none removes the element from the document flow entirely (no space).
   visibility:hidden hides the element visually but it still occupies space.

Q: What is the difference between em, rem, px, %?
A: em   → relative to parent element's font-size
   rem  → relative to root element (<html>) font-size
   px   → absolute pixel unit
   %    → relative to parent element's corresponding property

Q: How does the CSS box model work?
A: Every element is a box: content + padding + border + margin.
   Total width = content width + left/right padding + left/right border + left/right margin
   (unless box-sizing: border-box, where padding+border are included in declared width)

Q: What is the difference between position: relative and position: absolute?
A: relative → offset from its normal position; still in normal flow
   absolute → removed from normal flow; positioned relative to nearest positioned ancestor

Q: How do you center an element horizontally AND vertically?
A: Multiple approaches:
   1. Flexbox:   display:flex; justify-content:center; align-items:center;
   2. Grid:      display:grid; place-items:center;
   3. Absolute:  position:absolute; top:50%; left:50%; transform:translate(-50%,-50%);
   4. Margin auto: display:block; margin: 0 auto; (horizontal only)

Q: What's the difference between inline, block, and inline-block?
A: block       → takes full width, line break before/after, can set width/height
   inline      → only as wide as content, no line break, cannot set width/height
   inline-block→ like inline (in flow) but respects width/height/padding/margin

Q: What is specificity?
A: A weight assigned to a CSS rule based on its selector. Higher specificity wins.
   inline styles (1,0,0,0) > IDs (0,1,0,0) > classes/pseudo-classes (0,0,1,0)
   > elements/pseudo-elements (0,0,0,1)
