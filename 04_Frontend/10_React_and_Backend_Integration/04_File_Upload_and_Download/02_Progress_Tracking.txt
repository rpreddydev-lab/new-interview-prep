================================================================
FILE UPLOAD PROGRESS TRACKING IN REACT
================================================================

Progress tracking shows users how much of a file has been uploaded.
It dramatically improves UX for large file uploads.

================================================================
1. HOW PROGRESS WORKS (XMLHttpRequest / Axios)
================================================================

Axios uses XHR (XMLHttpRequest) under the hood in the browser.
XHR exposes an upload.onprogress event that fires during file transmission.

onUploadProgress receives a ProgressEvent object:
  event.loaded:  bytes sent so far
  event.total:   total bytes to send
  event.lengthComputable: true if total is known

  const percent = Math.round((event.loaded / event.total) * 100);

2. BASIC PROGRESS TRACKING
================================================================

  import { useState } from 'react';
  import apiClient from '../api/axiosConfig';

  function FileUploadWithProgress() {
    const [file, setFile] = useState(null);
    const [progress, setProgress] = useState(0);
    const [status, setStatus] = useState('idle'); // idle|uploading|success|error
    const [error, setError] = useState(null);

    const handleUpload = async () => {
      if (!file) return;

      const formData = new FormData();
      formData.append('file', file);

      setStatus('uploading');
      setProgress(0);
      setError(null);

      try {
        await apiClient.post('/files/upload', formData, {
          onUploadProgress: (event) => {
            if (event.lengthComputable) {
              const percent = Math.round((event.loaded / event.total) * 100);
              setProgress(percent);
            }
          },
        });

        setStatus('success');
        setProgress(100);
      } catch (err) {
        setStatus('error');
        setError(err.response?.data?.message || 'Upload failed');
        setProgress(0);
      }
    };

    return (
      <div>
        <input
          type="file"
          onChange={(e) => setFile(e.target.files[0])}
          disabled={status === 'uploading'}
        />
        <button
          onClick={handleUpload}
          disabled={!file || status === 'uploading'}
        >
          Upload
        </button>

        {status === 'uploading' && (
          <div>
            <div style={{ background: '#eee', borderRadius: '4px', overflow: 'hidden' }}>
              <div style={{
                width: `${progress}%`,
                background: '#007bff',
                height: '8px',
                transition: 'width 0.2s ease',
              }} />
            </div>
            <p>{progress}% uploaded</p>
          </div>
        )}

        {status === 'success' && <p style={{ color: 'green' }}>✅ Upload complete!</p>}
        {status === 'error' && <p style={{ color: 'red' }}>❌ {error}</p>}
      </div>
    );
  }

3. PROGRESS BAR COMPONENT
================================================================

  // src/components/ProgressBar.jsx
  function ProgressBar({ value, showLabel = true, color = '#007bff' }) {
    const clamped = Math.max(0, Math.min(100, value));

    return (
      <div>
        <div
          role="progressbar"
          aria-valuenow={clamped}
          aria-valuemin={0}
          aria-valuemax={100}
          style={{
            background: '#e9ecef',
            borderRadius: '4px',
            overflow: 'hidden',
            height: '8px',
          }}
        >
          <div
            style={{
              width: `${clamped}%`,
              height: '100%',
              background: clamped === 100 ? '#28a745' : color,
              transition: 'width 0.3s ease',
            }}
          />
        </div>
        {showLabel && (
          <p style={{ textAlign: 'right', fontSize: '12px', margin: '4px 0 0' }}>
            {clamped}%
          </p>
        )}
      </div>
    );
  }

4. MULTIPLE FILE UPLOADS WITH INDIVIDUAL PROGRESS

  function MultiFileUpload() {
    const [files, setFiles] = useState([]);
    const [progresses, setProgresses] = useState({});

    const handleFileChange = (e) => {
      const selected = Array.from(e.target.files).map(file => ({
        file,
        id: `${file.name}-${Date.now()}`,
        status: 'pending',
      }));
      setFiles(selected);
    };

    const uploadAll = async () => {
      await Promise.all(
        files.map(({ file, id }) => uploadFile(file, id))
      );
    };

    const uploadFile = async (file, id) => {
      const formData = new FormData();
      formData.append('file', file);

      // Update file status
      setFiles(prev => prev.map(f =>
        f.id === id ? { ...f, status: 'uploading' } : f
      ));

      try {
        await apiClient.post('/files/upload', formData, {
          onUploadProgress: (event) => {
            const percent = Math.round((event.loaded / event.total) * 100);
            setProgresses(prev => ({ ...prev, [id]: percent }));
          },
        });

        setFiles(prev => prev.map(f =>
          f.id === id ? { ...f, status: 'success' } : f
        ));
      } catch {
        setFiles(prev => prev.map(f =>
          f.id === id ? { ...f, status: 'error' } : f
        ));
      }
    };

    return (
      <div>
        <input type="file" multiple onChange={handleFileChange} />
        <button onClick={uploadAll} disabled={files.length === 0}>
          Upload All
        </button>

        {files.map(({ file, id, status }) => (
          <div key={id} style={{ margin: '8px 0' }}>
            <span>{file.name} ({(file.size / 1024).toFixed(0)}KB) — {status}</span>
            {status === 'uploading' && (
              <ProgressBar value={progresses[id] || 0} />
            )}
            {status === 'success' && <span style={{ color: 'green' }}> ✅</span>}
            {status === 'error' && <span style={{ color: 'red' }}> ❌</span>}
          </div>
        ))}
      </div>
    );
  }

5. CANCELLABLE UPLOAD WITH PROGRESS

  function CancellableUpload() {
    const [progress, setProgress] = useState(0);
    const [uploading, setUploading] = useState(false);
    const controllerRef = useRef(null);

    const startUpload = async (file) => {
      const controller = new AbortController();
      controllerRef.current = controller;

      const formData = new FormData();
      formData.append('file', file);

      setUploading(true);
      setProgress(0);

      try {
        await apiClient.post('/files/upload', formData, {
          signal: controller.signal,
          onUploadProgress: (event) => {
            const percent = Math.round((event.loaded / event.total) * 100);
            setProgress(percent);
          },
        });
        setUploading(false);
        alert('Upload complete!');
      } catch (err) {
        if (axios.isCancel(err) || err.name === 'CanceledError') {
          setProgress(0);
        }
        setUploading(false);
      }
    };

    const cancelUpload = () => {
      controllerRef.current?.abort();
      setUploading(false);
      setProgress(0);
    };

    return (
      <div>
        <input
          type="file"
          onChange={(e) => e.target.files[0] && startUpload(e.target.files[0])}
        />
        {uploading && (
          <>
            <ProgressBar value={progress} />
            <button onClick={cancelUpload}>Cancel Upload</button>
          </>
        )}
      </div>
    );
  }

6. CHUNKED UPLOAD FOR VERY LARGE FILES
================================================================

For files > 100MB, upload in chunks to handle network interruptions
and support resume capability.

  const CHUNK_SIZE = 5 * 1024 * 1024; // 5MB per chunk

  async function uploadInChunks(file, onProgress) {
    const totalChunks = Math.ceil(file.size / CHUNK_SIZE);
    const uploadId = `upload-${Date.now()}-${Math.random().toString(36).slice(2)}`;

    for (let chunkIndex = 0; chunkIndex < totalChunks; chunkIndex++) {
      const start = chunkIndex * CHUNK_SIZE;
      const end = Math.min(start + CHUNK_SIZE, file.size);
      const chunk = file.slice(start, end);

      const formData = new FormData();
      formData.append('chunk', chunk);
      formData.append('uploadId', uploadId);
      formData.append('chunkIndex', String(chunkIndex));
      formData.append('totalChunks', String(totalChunks));
      formData.append('filename', file.name);

      await apiClient.post('/files/upload-chunk', formData, {
        onUploadProgress: (event) => {
          // Overall progress
          const chunkProgress = event.loaded / event.total;
          const overallProgress = ((chunkIndex + chunkProgress) / totalChunks) * 100;
          onProgress(Math.round(overallProgress));
        },
      });
    }

    // Notify server to assemble chunks
    await apiClient.post('/files/upload-complete', {
      uploadId,
      filename: file.name,
      totalChunks,
    });
  }

  // src/hooks/useFileUpload.js
  export function useFileUpload(uploadUrl) {
    const [progress, setProgress] = useState(0);
    const [status, setStatus] = useState('idle');
    const [result, setResult] = useState(null);
    const [error, setError] = useState(null);
    const controllerRef = useRef(null);

    const upload = useCallback(async (file, extra = {}) => {
      const controller = new AbortController();
      controllerRef.current = controller;

      const formData = new FormData();
      formData.append('file', file);
      Object.entries(extra).forEach(([k, v]) => formData.append(k, v));

      setStatus('uploading');
      setProgress(0);
      setError(null);

      try {
        const { data } = await apiClient.post(uploadUrl, formData, {
          signal: controller.signal,
          onUploadProgress: (e) => {
            setProgress(Math.round((e.loaded / e.total) * 100));
          },
        });
        setResult(data);
        setStatus('success');
      } catch (err) {
        if (!axios.isCancel(err)) {
          setError(extractErrorMessage(err));
          setStatus('error');
        } else {
          setStatus('idle');
        }
        setProgress(0);
      }
    }, [uploadUrl]);

    const cancel = useCallback(() => {
      controllerRef.current?.abort();
    }, []);

    const reset = useCallback(() => {
      setProgress(0);
      setStatus('idle');
      setResult(null);
      setError(null);
    }, []);

    return { upload, cancel, reset, progress, status, result, error };
  }

  // Usage
  function UploadPage() {
    const { upload, cancel, progress, status, error } =
      useFileUpload('/files/upload');

    return (
      <div>
        <input type="file" onChange={(e) => upload(e.target.files[0])} />
        {status === 'uploading' && (
          <>
            <ProgressBar value={progress} />
            <button onClick={cancel}>Cancel</button>
          </>
        )}
        {status === 'error' && <p>{error}</p>}
        {status === 'success' && <p>Upload complete!</p>}
      </div>
    );
  }

8. INTERVIEW QUESTIONS
================================================================

Q: How do you track file upload progress in React with Axios?
A: Pass an onUploadProgress callback in the Axios request config.
   It receives a ProgressEvent with loaded (bytes sent) and total
   (total bytes). Calculate progress as Math.round((loaded/total)*100)
   and update React state to re-render the progress bar.

Q: How do you cancel an in-progress file upload?
A: Create an AbortController, pass controller.signal to the Axios
   request config. Call controller.abort() to cancel. Check for
   axios.isCancel(err) or err.name === 'CanceledError' in the catch
   block to distinguish cancellation from actual errors.

Q: How do you handle uploads of very large files (500MB+)?
A: Use chunked upload: slice the file into chunks using File.slice(),
   upload each chunk separately with chunk index and upload ID metadata.
   Track overall progress across chunks. The backend assembles chunks
   into the final file. This also enables resume on connection failure.

Q: What is a presigned URL and how does progress tracking work with it?
A: A presigned URL is a direct upload URL to S3/Azure. Progress still
   works using fetch with a ReadableStream or XHR directly. Axios's
   onUploadProgress also works with presigned URL uploads since it
   still uses XHR. The main difference is the traffic doesn't go
   through your backend.

Q: How do you show per-file progress when uploading multiple files?
A: Maintain a progresses state object keyed by a unique file ID
   (generated when files are selected). Use Promise.all to upload
   concurrently. Each upload's onUploadProgress updates only its
   own entry in the progresses state.
