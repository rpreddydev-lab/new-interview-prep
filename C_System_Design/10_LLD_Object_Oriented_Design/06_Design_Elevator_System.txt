1. REQUIREMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CLARIFICATIONS:
  - How many elevators? Multiple (e.g., 4 elevators for 20-floor building)
  - Direction buttons inside each elevator (up/down)
  - Floor request buttons outside (press UP or DOWN at floor)
  - Smart dispatch: which elevator to send for a floor request?
  - Different elevator types? (passenger, freight) → single type initially
  - Capacity limit? Yes, weight sensor triggers "overloaded" state
  - Emergency: emergency stop button per elevator

ENTITIES:
  Building, Floor, Elevator, ElevatorButton, FloorButton,
  ElevatorController (dispatcher), Request, ElevatorState


2. ELEVATOR STATE MACHINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ELEVATOR STATES:
  IDLE: waiting at a floor, no pending requests
  MOVING_UP: traveling upward
  MOVING_DOWN: traveling downward
  DOORS_OPENING: doors in process of opening
  DOORS_OPEN: doors open, passengers boarding/exiting (3-5 second hold)
  DOORS_CLOSING: doors in process of closing
  MAINTENANCE: out of service

TRANSITIONS:
  IDLE → MOVING_UP (new request above current floor)
  IDLE → MOVING_DOWN (new request below current floor)
  MOVING_UP → DOORS_OPENING (arrived at destination floor while going up)
  DOORS_OPENING → DOORS_OPEN (doors fully open)
  DOORS_OPEN → DOORS_CLOSING (timer expired or close button pressed)
  DOORS_CLOSING → MOVING_UP/DOWN/IDLE (next request or no request)
  Any state → MAINTENANCE (fault detected)


3. CLASS DESIGN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

enum ElevatorState { IDLE, MOVING_UP, MOVING_DOWN, DOORS_OPEN, MAINTENANCE }
enum Direction     { UP, DOWN, NONE }

// --- Request ---

class Request {
    private int sourceFloor;    // where request was made
    private int targetFloor;    // destination (if internal button; null if external)
    private Direction direction; // requested direction (external button only)
    private RequestType type;   // INTERNAL (inside elevator) or EXTERNAL (floor button)
    
    // External request (someone at floor 5 wants to go UP)
    Request(int sourceFloor, Direction direction) {
        this.sourceFloor = sourceFloor;
        this.direction = direction;
        this.type = RequestType.EXTERNAL;
    }
    
    // Internal request (person in elevator presses floor 12)
    Request(int targetFloor) {
        this.targetFloor = targetFloor;
        this.type = RequestType.INTERNAL;
    }
}

enum RequestType { INTERNAL, EXTERNAL }

// --- Elevator ---

class Elevator {
    private int elevatorId;
    private int currentFloor;
    private ElevatorState state;
    private Direction direction;
    private int capacity;
    private int currentOccupancy;
    
    // Sorted sets for efficient stop selection
    private TreeSet<Integer> upQueue;    // floors to visit while going UP (ascending)
    private TreeSet<Integer> downQueue;  // floors to visit while going DOWN (descending)
    
    Elevator(int elevatorId, int capacity) {
        this.elevatorId = elevatorId;
        this.capacity = capacity;
        this.currentFloor = 1;
        this.state = ElevatorState.IDLE;
        this.direction = Direction.NONE;
        this.upQueue = new TreeSet<>();
        this.downQueue = new TreeSet<>(Collections.reverseOrder());  // descending
    }
    
    // Add a stop request (called by ElevatorController)
    void addRequest(int targetFloor) {
        if (targetFloor > currentFloor) {
            upQueue.add(targetFloor);
        } else if (targetFloor < currentFloor) {
            downQueue.add(targetFloor);
        }
        if (state == ElevatorState.IDLE) startMoving();
    }
    
    // Move one floor in current direction (called by simulation loop)
    void move() {
        if (state == ElevatorState.MOVING_UP) {
            currentFloor++;
        } else if (state == ElevatorState.MOVING_DOWN) {
            currentFloor--;
        }
        
        checkArrival();
    }
    
    private void checkArrival() {
        if (state == ElevatorState.MOVING_UP && upQueue.contains(currentFloor)) {
            upQueue.remove(currentFloor);
            openDoors();
        } else if (state == ElevatorState.MOVING_DOWN && downQueue.contains(currentFloor)) {
            downQueue.remove(currentFloor);
            openDoors();
        } else {
            // Continue moving, determine next direction
            determineNextAction();
        }
    }
    
    private void openDoors() {
        state = ElevatorState.DOORS_OPEN;
        // Schedule door close after 3 seconds
        // ScheduledExecutorService.schedule(() -> closeDoors(), 3, TimeUnit.SECONDS)
    }
    
    void closeDoors() {
        determineNextAction();
    }
    
    private void determineNextAction() {
        if (direction == Direction.UP && !upQueue.isEmpty()) {
            state = ElevatorState.MOVING_UP;
        } else if (direction == Direction.DOWN && !downQueue.isEmpty()) {
            state = ElevatorState.MOVING_DOWN;
        } else if (!upQueue.isEmpty()) {
            direction = Direction.UP;
            state = ElevatorState.MOVING_UP;
        } else if (!downQueue.isEmpty()) {
            direction = Direction.DOWN;
            state = ElevatorState.MOVING_DOWN;
        } else {
            state = ElevatorState.IDLE;
            direction = Direction.NONE;
        }
    }
    
    private void startMoving() {
        if (!upQueue.isEmpty() && (downQueue.isEmpty() || upQueue.first() < downQueue.first())) {
            direction = Direction.UP;
            state = ElevatorState.MOVING_UP;
        } else if (!downQueue.isEmpty()) {
            direction = Direction.DOWN;
            state = ElevatorState.MOVING_DOWN;
        }
    }
    
    // Cost estimate for dispatch algorithm (see ElevatorController)
    int estimateCostToServe(int requestFloor, Direction requestDirection) {
        // Simple: distance from current floor
        return Math.abs(currentFloor - requestFloor);
    }
    
    // Getters
    int getCurrentFloor()    { return currentFloor; }
    ElevatorState getState() { return state; }
    Direction getDirection() { return direction; }
    boolean isIdle()         { return state == ElevatorState.IDLE; }
    boolean isFull()         { return currentOccupancy >= capacity; }
    int getElevatorId()      { return elevatorId; }
}

// --- ElevatorController (Dispatcher — Strategy Pattern) ---

interface DispatchStrategy {
    Elevator selectElevator(List<Elevator> elevators, int requestFloor, Direction direction);
}

class NearestElevatorStrategy implements DispatchStrategy {
    @Override
    public Elevator selectElevator(List<Elevator> elevators, int requestFloor, Direction direction) {
        return elevators.stream()
            .filter(e -> e.getState() != ElevatorState.MAINTENANCE)
            .filter(e -> !e.isFull())
            .min(Comparator.comparingInt(e -> e.estimateCostToServe(requestFloor, direction)))
            .orElseThrow(() -> new RuntimeException("No available elevators"));
    }
}

// SCAN (Look) Algorithm — more efficient, fewer direction changes
class SCANStrategy implements DispatchStrategy {
    @Override
    public Elevator selectElevator(List<Elevator> elevators, int requestFloor, Direction direction) {
        // Prefer elevator already going in same direction AND hasn't passed request floor yet
        Optional<Elevator> sameDirection = elevators.stream()
            .filter(e -> e.getDirection() == direction)
            .filter(e -> !e.isFull())
            .filter(e -> {
                if (direction == Direction.UP) return e.getCurrentFloor() <= requestFloor;
                return e.getCurrentFloor() >= requestFloor;
            })
            .min(Comparator.comparingInt(e -> e.estimateCostToServe(requestFloor, direction)));
        
        if (sameDirection.isPresent()) return sameDirection.get();
        
        // Fallback: idle elevator or nearest
        return elevators.stream()
            .filter(e -> e.isIdle() && !e.isFull())
            .min(Comparator.comparingInt(e -> e.estimateCostToServe(requestFloor, direction)))
            .orElse(new NearestElevatorStrategy().selectElevator(elevators, requestFloor, direction));
    }
}

class ElevatorController {
    private List<Elevator> elevators;
    private DispatchStrategy strategy;
    
    ElevatorController(int numElevators, int floorsPerBuilding, DispatchStrategy strategy) {
        this.elevators = new ArrayList<>();
        for (int i = 0; i < numElevators; i++) {
            elevators.add(new Elevator(i + 1, 10));  // capacity 10 people
        }
        this.strategy = strategy;
    }
    
    // External request: person at floor presses UP or DOWN
    void handleExternalRequest(int floor, Direction direction) {
        Elevator selected = strategy.selectElevator(elevators, floor, direction);
        selected.addRequest(floor);
    }
    
    // Internal request: person inside elevator presses a floor button
    void handleInternalRequest(int elevatorId, int targetFloor) {
        Elevator elevator = elevators.stream()
            .filter(e -> e.getElevatorId() == elevatorId)
            .findFirst()
            .orElseThrow();
        elevator.addRequest(targetFloor);
    }
    
    // Change dispatch strategy at runtime (Strategy Pattern)
    void setStrategy(DispatchStrategy newStrategy) {
        this.strategy = newStrategy;
    }
    
    List<Elevator> getElevators() { return Collections.unmodifiableList(elevators); }
}

// --- Building ---

class Building {
    private String buildingId;
    private int numFloors;
    private ElevatorController controller;
    private List<Floor> floors;
    
    Building(String buildingId, int numFloors, int numElevators) {
        this.buildingId = buildingId;
        this.numFloors = numFloors;
        this.controller = new ElevatorController(numElevators, numFloors, new SCANStrategy());
        
        floors = new ArrayList<>();
        for (int i = 1; i <= numFloors; i++) {
            floors.add(new Floor(i, numFloors));
        }
    }
    
    void pressFloorButton(int floorNumber, Direction direction) {
        controller.handleExternalRequest(floorNumber, direction);
    }
    
    void pressElevatorButton(int elevatorId, int targetFloor) {
        controller.handleInternalRequest(elevatorId, targetFloor);
    }
}

// --- Floor ---

class Floor {
    private int floorNumber;
    private boolean hasUpButton;      // ground floor has no down button
    private boolean hasDownButton;    // top floor has no up button
    
    Floor(int floorNumber, int totalFloors) {
        this.floorNumber = floorNumber;
        this.hasUpButton = floorNumber < totalFloors;
        this.hasDownButton = floorNumber > 1;
    }
    
    int getFloorNumber() { return floorNumber; }
}


4. DISPATCH ALGORITHMS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

NEAREST ELEVATOR (simple):
  Send elevator closest to requested floor
  Pros: Simple, minimizes wait time per request
  Cons: Doesn't consider direction — may cause many reversals

SCAN/LOOK ALGORITHM (disk scheduling analogy):
  Elevator moves in one direction, servicing all stops
  Reaches end → reverses direction → services stops going back
  
  LOOK variant: reverses when no more requests ahead (not at physical end)
  More efficient than NEAREST for high-traffic buildings (less direction reversals)

DESTINATION DISPATCH (modern buildings):
  User enters destination BEFORE entering elevator (lobby kiosk or phone)
  System groups people going to same floor in same elevator
  Dramatically reduces stops per trip
  Elevator doors open saying "Elevator 2 — floors 5,7,12"


5. DESIGN PATTERNS SUMMARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STATE: Elevator has IDLE/MOVING_UP/MOVING_DOWN/DOORS_OPEN states
  Behavior (what happens on a button press) differs per state
  
STRATEGY: DispatchStrategy interface
  NearestElevatorStrategy, SCANStrategy, DestinationDispatchStrategy
  Swap algorithm at runtime without changing ElevatorController

OBSERVER: Floor display panels observe elevator state
  When elevator arrives at floor → doors display lights up, bell rings

COMMAND: Request encapsulates the button press
  Can queue, log, replay requests


6. INTERVIEW DISCUSSION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WHY TREESET FOR QUEUES?
  TreeSet<Integer> upQueue — auto-sorted ascending
  When going UP: serve floors in order (lowest first) → no random jumps
  TreeSet.first() → next stop while going up (O(log N))

CONCURRENCY:
  Multiple people pressing buttons simultaneously
  ElevatorController.handleExternalRequest() must be synchronized
  Or use ConcurrentLinkedQueue for request queues

EDGE CASES:
  - Elevator at capacity → don't assign more requests
  - Maintenance mode → controller won't dispatch to it
  - Power outage → elevators go to ground floor (design decision)
  - Button pressed but already at that floor → just open doors
