PRIORITY CHEAT SHEET — TOP 35 MUST-KNOW QUESTIONS
================================================================================

JAVA CORE (most asked):
1.  How does HashMap work internally? (hashing, buckets, treeify at 8)
2.  What is the difference between == and equals()? Why override hashCode()?
3.  Explain volatile, synchronized, and when to use each
4.  How does CompletableFuture work? What is supplyAsync? What is thenCompose?
5.  What are virtual threads (Java 21)? How do they differ from platform threads?
6.  Explain streams: lazy evaluation, terminal vs intermediate operations
7.  What is type erasure in generics? What is PECS?
8.  How does the JVM garbage collector work? G1 vs ZGC?
9.  What is the happens-before relationship in the Java Memory Model?
10. Explain Optional: why use it? When NOT to use it?
11. What is Structured Concurrency (Java 21)? How does it differ from CompletableFuture?
12. Explain records and sealed classes. When would you use them?

SYSTEM DESIGN (most asked):
13. Design a rate limiter (token bucket vs leaky bucket vs sliding window)
14. How do you design a notification system at scale?
15. Explain CAP theorem with a practical example
16. What is eventual consistency? Give a real example
17. Kafka vs RabbitMQ vs SQS: when to use each?
18. How do microservices communicate? Sync vs async trade-offs?
19. What is the Saga pattern? Choreography vs orchestration?
20. How would you design the CDR billing pipeline in your current company?
21. Explain CQRS. When is it worth the complexity?
22. How do you handle data consistency across microservices?
23. What is the outbox pattern? How does it solve dual-write problems?

BACKEND AND SECURITY (senior focus):
24. How does Spring @Transactional work? What is self-invocation problem?
25. How does OAuth2 Authorization Code Flow with PKCE work?
26. JWT vs opaque tokens — when do you choose each?
27. How does Redis distributed locking work? (Redisson / SET NX EX)
28. REST vs GraphQL vs gRPC — trade-offs and when to pick each?
29. How does Resilience4j circuit breaker work? States and thresholds?

ENGINEERING PRACTICES (senior focus):
